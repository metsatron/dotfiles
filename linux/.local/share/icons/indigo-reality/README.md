# Indigo Reality

An IRIX-themed icon set from somebody who never used IRIX but really really wanted to.  I had to make up some icons, and make decisions based on screenshots and also my own opinion of what looked good and what didn't.

Some images from Vecteezy.com, freepik.com; N64 controller image from pngitem.com (Salsationgoriska); link image (copyright Orchid) comes from svgrepo.com (MIT license).
