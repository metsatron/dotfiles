# Diet Netscape DotCortex Overlay

This directory is DotCortex-owned sanctuary chrome work layered beside the
upstream Diet Netscape Theme submodule.

Upstream reference:

- `../Diet-Netscape-Theme`
- `https://codeberg.org/wvttlv0vjus2r9/Diet-Netscape-Theme`

The upstream README does not declare a supported Firefox version. Its CSS carries
Firefox-version compatibility comments around Firefox 119-era behavior, while the
current sanctuary Firefox tested here is Firefox 151.0.2. Keep local compatibility
fixes in this overlay instead of editing the upstream submodule directly.
