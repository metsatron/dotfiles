* Ownership

This file is the umbrella for the Emacs installations managed by DotCortex.
Profile-specific implementation belongs in the named source below; do not put
Doom or Spacemacs-only configuration blocks here.

| Source | Ownership |
|--------+-----------|
| [[file:emacs.org][emacs.org]] | Shared vanilla Emacs policy, profile selection, server names, and build/runtime coordination |
| [[file:emacs-doom.org][emacs-doom.org]] | Doom Emacs modules, packages, and private configuration |
| [[file:emacs-spacemacs.org][emacs-spacemacs.org]] | Legacy Spacemacs profile and its tangled initialization files |

* Profile contract

** Vanilla Emacs

Plain =emacs= means the vanilla profile. It must remain independent of Doom
and Spacemacs state.

** Doom Emacs

Launch with =emacs --init-directory ~/.config/emacs=. Its =DOOMDIR= is
=~/.config/doom= and is sourced from the shared DotCortex overlay owned by
[[file:emacs-doom.org][emacs-doom.org]]. Doom uses the named server socket =doom= when it
coexists with another Emacs server.

** Spacemacs

Launch the legacy profile with =emacs --init-directory ~/.emacs.d.spacemacs=.
Its configuration is owned by [[file:emacs-spacemacs.org][emacs-spacemacs.org]] and is retained for
comparison and migration recovery, not as the Doom source of truth.

* Build and runtime law

- A profile change is authored in its owning Org source and tangled before it
  is loaded.
- Shared launch, server, and multi-profile decisions belong here; profile-only
  elisp belongs in the profile source.
- Never edit tangled files under =all/.config/doom/= or
  =all/.spacemacs.d.claude/= directly.
- Verify the target Emacs instance before using =emacsclient=: Doom, Spacemacs,
  and vanilla Emacs may be alive at the same time.
