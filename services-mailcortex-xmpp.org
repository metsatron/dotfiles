* Boundary

XMPP is a face on MailCortex, not a second messaging backbone. MailCortex keeps the one seat registry, the durable Maildir record and the only agent wake path (=services-mailcortex.org=). This module adds two things on the single host that serves the fleet's XMPP:

- A private Prosody server running as the user, not as the Debian system service. Server-to-server federation is disabled, in-band registration is off, client connections require TLS, and the component port listens on loopback only. Mobile clients (Conversations on Android) connect over the tailnet; the TLS certificate is the host's own Tailscale certificate, so there is no public domain and no public CA dependency beyond Tailscale's.
- =mailcortex-xmpp-bridge=, a Prosody external component (XEP-0114). Every mapped seat gets an address =<seat>@<component>=. A chat message from an allowlisted owner becomes one MailCortex mail into that seat's Maildir, and mail delivered to the bridge's own seat goes back out as a chat message from the agent that sent it.

Why a component: the server stamps the sender of every stanza after SASL authentication, federation is off and registration is closed, so the =from= address the bridge sees is authenticated by the server itself. One connection serves every seat address, and no seat needs a password.

No hostnames, addresses, domains, owner identities or secrets live in this public file. The private site layer lives only on the serving host:

- =~/.config/mailcortex/xmpp-private/local.cfg.lua=: the =VirtualHost=, the bridge =Component= with its secret, the client listen interfaces, and the group-room component (=Component "rooms.<domain>" "muc"= with =restrict_room_creation = "local"=, members-only and non-public rooms by default, =muc_mam= history). A component added at runtime is brought up with =prosodyctl shell 'host:activate("<jid>")'=, so no restart is needed.
- =~/.config/mailcortex/xmpp-private/bridge.json=: the owner allowlist, the seat map, the bridge's own MailCortex address and the path of the component secret file.
- =~/.config/mailcortex/xmpp-private/certs/=: the Tailscale certificate and key, named =<domain>.crt= and =<domain>.key=.

The private layer is a sibling directory, never inside =~/.config/mailcortex/xmpp/=: stow folds that directory into a symlink to this repository's tangled tree, so anything written there would land in the public working tree. Nothing starts until both private files exist (the readiness gate in =mailcortex-xmpp-service=).

Push notifications: no push module is enabled. Conversations holds its own connection, so no message metadata reaches a third-party push relay. This is a deliberate first-slice choice, not an omission.

* Narrow additive package apply

The manifest is sourced in =package-nala.org= (=debian/.nala/manifest/mailcortex-xmpp.ssv=). The default is a read-only apt simulation. =--apply= installs only the two manifest packages, refuses removals and upgrades, then stops and disables the Debian =prosody= system service: the fleet's Prosody runs as the user under =mailcortex-xmpp-service=, and the packaged default configuration (federation on, all interfaces) must never stay running. The package's postinst may start that service for a few seconds before it is stopped; it has no accounts in that window.

** Voice upload activation (C2)

The bundled =http_file_share= module stores uploads locally with a 25 MiB
per-file cap, one-day expiry, 250 MiB daily and 1 GiB global quotas. HTTP is
disabled; HTTPS is disabled until the private layer binds only the tailnet
interface and supplies the existing Tailscale certificate. Do not set

live apply. Keep existing VirtualHost/component/room declarations; put the

* Certificate refresh

=tailscale cert= needs root on this fleet, so the helper writes through =sudo -n= into a private temporary directory, then installs the pair into the certs directory owned by the user with mode 600. =--check= reports the days left without touching anything. The bridge does not use TLS (loopback component), so only the client-facing domain needs a certificate.

#+BEGIN_SRC bash :tangle linux/.local/bin/mailcortex-xmpp-cert :shebang "#!/usr/bin/env bash" :tangle-mode (identity #o755)
set -euo pipefail

usage() {
  cat <<'EOF'
Usage: mailcortex-xmpp-cert DOMAIN [--check]
Fetch or renew the host's Tailscale TLS certificate for DOMAIN into
~/.config/mailcortex/xmpp-private/certs/DOMAIN.{crt,key} (mode 600).
--check prints the days of validity left and changes nothing.
EOF
}

case "${1:-}" in
  ''|-h|--help) usage; [ -n "${1:-}" ]; exit $? ;;
esac
domain="$1"; shift
case "$domain" in
  *[!a-z0-9.-]*|.*|*..*) echo "mailcortex-xmpp-cert: invalid domain" >&2; exit 2 ;;
esac
certs="$HOME/.config/mailcortex/xmpp-private/certs"
crt="$certs/$domain.crt"; key="$certs/$domain.key"

if [ "${1:-}" = --check ]; then
  [ -r "$crt" ] || { echo "mailcortex-xmpp-cert: no certificate for $domain" >&2; exit 1; }
  end="$(openssl x509 -noout -enddate -in "$crt" | cut -d= -f2)"
  echo "$(( ( $(date -d "$end" +%s) - $(date +%s) ) / 86400 )) days left ($end)"
  exit 0
fi

sudo -n chown "$(id -u):$(id -g)" "$work/c" "$work/k"
install -m 600 "$work/c" "$crt.new"
install -m 600 "$work/k" "$key.new"
mv -f "$crt.new" "$crt"
mv -f "$key.new" "$key"
echo "mailcortex-xmpp-cert: installed certificate for $domain"

* The bridge

=mailcortex-xmpp-bridge= imports =slixmpp= only when it runs, so =-h= and the fixture tests work on machines without it. All mailbox state changes go through the =mailcortex= CLI (=send=, =inbox=, =read=, =receipt=); the bridge never writes a Maildir itself.

Inbound (chat to mail):
1. The server-stamped sender must be an allowlisted owner (bare address). Anyone else gets no mail, only an error stanza and a log line.
2. A sliding-window rate limit per owner (default 20 per minute) and a persisted stanza-id dedupe stop floods and reconnect replays.
3. The target local part must be a mapped seat; unknown addresses get =item-not-found=.
4. One mail is sent from the bridge's own seat address to the seat's MailCortex address. The body carries the XMPP sender and the reply instruction, so a woken agent answers with =mailcortex send --to <bridge address>=.
5. XEP-0066 OOB URLs (including bodyless stanzas) enter the voice lane and
   retain strict refusal for foreign URLs, HTTP or an unconfigured upload.
   A URL-only body enters that lane only if the configured HTTPS upload
   origin/path accepts it; all other bare links remain ordinary text mail.
   The upload allowlist is checked again before fetching; redirects are refused.
   Downloads have a 25 MiB streaming cap, 5-second socket timeout and
   30-second elapsed budget (at most one socket timeout to observe expiry).
   =~/HelmCortex/FORGE/bin/whisper-transcribe= runs in a worker thread with a
   600-second subprocess timeout (absolute path, independent of cron's PATH). Only nonempty, clean transcripts are mailed with =[xmpp voice]=
   subjects and the original audio via =mailcortex send --attach=.
   Private temporary copies are removed on success and failure. At most two
   voice jobs run concurrently; excess jobs receive a resend diagnostic.
   Failures log and reply once to the owner, never mail an empty transcript.

Outbound (mail to chat):
1. The bridge polls its own seat (=mailcortex inbox=) and handles only =new= messages, oldest first.
2. The mail's =From= must resolve to a mapped seat's mailbox. Matching uses the local part only, because a =.helm= domain is provenance (the machine that sent it), not identity: =seat+x@x230.helm= and =seat+x@kikin-kushi.helm= are one Maildir. The chat message is sent from that seat's XMPP address to every owner. Mail from an unmapped address is marked =handling_rejected= and never relayed.
3. After the message is sent, =mailcortex read= marks it seen and =mailcortex receipt= records =handling_completed=. A message that failed to send stays in =new= and is retried on the next poll.

LOCAL_RE = re.compile(r"^[a-z0-9][a-z0-9._-]{0,63}$")
HOST_RE = re.compile(r"^[a-z0-9][a-z0-9.-]*[a-z0-9]$")

    r"^(?:(consort|seat|machine|sanctuary)\+)?"
    r"([a-z0-9][a-z0-9._-]*)@"
    r"([a-z0-9][a-z0-9.-]*\.helm)$"

class BridgeError(Exception):
    """Configuration or routing failure with a concise diagnostic."""


def config_path() -> Path:
    return Path(os.environ.get(
        "MAILCORTEX_XMPP_CONFIG", "~/.config/mailcortex/xmpp-private/bridge.json")).expanduser()


def state_root() -> Path:
    return Path(os.environ.get(

def bare(jid: str) -> str:
    return str(jid).split("/", 1)[0].strip().lower()


def is_bare_jid(value: str) -> bool:
    if not isinstance(value, str) or value.count("@") != 1 or "/" in value:
        return False
    local, host = value.split("@")
    return bool(LOCAL_RE.match(local)) and bool(HOST_RE.match(host))


def load_config(path: Path) -> dict:
    try:
        data = json.loads(path.read_text(encoding="utf-8"))
    except (OSError, json.JSONDecodeError) as error:
        raise BridgeError(f"cannot read config {path}: {error}") from error
    if not isinstance(data, dict):
        raise BridgeError("config must be a JSON object")
    component = data.get("component_jid")
    if not isinstance(component, str) or "@" in component or not HOST_RE.match(component):
        raise BridgeError("component_jid must be a bare domain")
    owners = data.get("owner_jids")
    if not isinstance(owners, list) or not owners or not all(is_bare_jid(o) for o in owners):
        raise BridgeError("owner_jids must be a non-empty list of bare JIDs")
    address = data.get("bridge_address")
    match = ADDRESS_RE.match(address) if isinstance(address, str) else None
    if not match or match.group(1) != "seat":
        raise BridgeError("bridge_address must be a seat+NAME@HOST.helm address")
    seats = data.get("seats")
    if not isinstance(seats, dict) or not seats:
        raise BridgeError("seats must map XMPP local parts to MailCortex addresses")
    reverse: dict[str, str] = {}
    for local, target in seats.items():
        if not isinstance(local, str) or not LOCAL_RE.match(local):
            raise BridgeError(f"invalid seat local part: {local!r}")
        if not isinstance(target, str) or not ADDRESS_RE.match(target):
            raise BridgeError(f"invalid MailCortex address for {local}: {target!r}")
        if target == address:
            raise BridgeError("a seat may not map to the bridge's own address")
        mailbox = target.split("@")[0]
        if mailbox in reverse:
            raise BridgeError(f"mailbox mapped twice: {mailbox}")
        reverse[mailbox] = local
    secret_file = Path(str(data.get("component_secret_file", ""))).expanduser()
    if not str(data.get("component_secret_file", "")):
        raise BridgeError("component_secret_file is required")
    rate = data.get("rate_per_minute", 20)
    poll = data.get("poll_seconds", 2)
    port = data.get("port", 5347)
    if not isinstance(rate, int) or not 1 <= rate <= 600:
        raise BridgeError("rate_per_minute must be an integer from 1 to 600")
    if not isinstance(poll, (int, float)) or not 0.5 <= poll <= 60:
        raise BridgeError("poll_seconds must be between 0.5 and 60")
    if not isinstance(port, int) or not 1 <= port <= 65535:
        raise BridgeError("port must be a TCP port")
    upload = data.get("upload_base_url", "")
    if not isinstance(upload, str):
        raise BridgeError("upload_base_url must be an HTTPS upload directory")
    if upload:
        parsed = split_upload_url(upload)
        if not parsed.path.endswith("/") or parsed.path == "/":
            raise BridgeError("upload_base_url must name an upload directory")
    return {
        "upload_base_url": upload,
        "component_jid": component,
        "owner_jids": [bare(o) for o in owners],
        "bridge_address": address,
        "bridge_seat": match.group(2),
        "seats": dict(seats),
        "reverse": reverse,
        "component_secret_file": secret_file,
        "server": str(data.get("server", "127.0.0.1")),
        "port": port,
        "rate_per_minute": rate,
        "poll_seconds": float(poll),
    }


def read_secret(path: Path) -> str:
    try:
        info = path.stat()
    except OSError as error:
        raise BridgeError(f"component secret missing: {error}") from error
    if not stat.S_ISREG(info.st_mode) or info.st_mode & 0o077:
        raise BridgeError("component secret must be a regular file with mode 600")
    secret = path.read_text(encoding="utf-8").strip()
    if len(secret) < 24:
        raise BridgeError("component secret is too short")
    return secret


class Gate:
    """Owner allowlist plus a per-sender sliding-window rate limit."""

    def __init__(self, owners: list[str], per_minute: int) -> None:
        self.owners = set(owners)
        self.per_minute = per_minute
        self.windows: dict[str, collections.deque] = {}

    def admit(self, sender: str, now: float) -> str | None:
        sender = bare(sender)
        if sender not in self.owners:
            return "unauthorized"
        window = self.windows.setdefault(sender, collections.deque())
        while window and now - window[0] >= 60:
            window.popleft()
        if len(window) >= self.per_minute:
            return "rate_limited"
        window.append(now)
        return None


class Seen:
    """Persisted stanza-id dedupe so reconnect replays never send mail twice."""

    def __init__(self, path: Path) -> None:
        self.path = path
        self.keys: list[str] = []
        if path.exists():
            try:
                loaded = json.loads(path.read_text(encoding="utf-8"))
                if isinstance(loaded, list):
                    self.keys = [str(k) for k in loaded][-SEEN_CAP:]
            except (OSError, json.JSONDecodeError):
                LOG.warning("dedupe state unreadable; starting empty")
        self.index = set(self.keys)

    def check_and_add(self, key: str | None) -> bool:
        """Return True when the key is new (and record it)."""
        if not key:
            return True
        if key in self.index:
            return False
        self.keys.append(key)
        self.index.add(key)
        if len(self.keys) > SEEN_CAP:
            dropped = self.keys[:-SEEN_CAP]
            self.keys = self.keys[-SEEN_CAP:]
            self.index.difference_update(dropped)
        self.path.parent.mkdir(mode=0o700, parents=True, exist_ok=True)
        temporary = self.path.with_name(f".{self.path.name}.{os.getpid()}.tmp")
        temporary.write_text(json.dumps(self.keys), encoding="utf-8")
        os.chmod(temporary, 0o600)
        os.replace(temporary, self.path)
        return True


def mailcortex(args: list[str], run=subprocess.run) -> str:
    result = run(["mailcortex", *args], capture_output=True, text=True)
    if result.returncode != 0:
        raise BridgeError(f"mailcortex {args[0]} failed: {result.stderr.strip()}")
    return result.stdout


def inbound_mail(cfg: dict, sender: str, local: str, body: str, run=subprocess.run) -> str:
    """Deliver one owner chat message into a seat's Maildir; return the filename."""
    target = cfg["seats"].get(local)
    if target is None:
        raise BridgeError(f"unknown seat: {local}")
    text = body.strip()
    if not text:
        raise BridgeError("empty message")
    if len(text) > MAX_BODY:
        raise BridgeError("message too long")
    first = text.splitlines()[0].strip()
    subject = "[xmpp] " + (first[:70] + "…" if len(first) > 70 else first)
    framed = (
        f"XMPP-From: {bare(sender)}\n"
        f"XMPP-To: {local}@{cfg['component_jid']}\n"
        f"Reply-Via: mailcortex send --from <your address> --to {cfg['bridge_address']}\n"
        "\n"
        f"{text}\n"
    )
    return mailcortex(["send", "--from", cfg["bridge_address"], "--to", target,
                       "--subject", subject, "--body", framed], run).strip()


def split_upload_url(value: str):
    try:
        parsed = urllib.parse.urlsplit(value)
        port = parsed.port
    except ValueError as error:
        raise BridgeError("invalid upload URL") from error
    if (parsed.scheme != "https" or not parsed.hostname or parsed.username
            or parsed.password or parsed.query or parsed.fragment
            or any(c.isspace() or ord(c) < 32 for c in value)):
        raise BridgeError("upload URL must be HTTPS without credentials or query")
    return parsed


def validate_upload_url(cfg: dict, url: str) -> None:
    base = cfg.get("upload_base_url", "")
    if not base:
        raise BridgeError("voice upload is not configured")
    allowed, candidate = split_upload_url(base), split_upload_url(url)
    if ((candidate.hostname, candidate.port or 443) !=
            (allowed.hostname, allowed.port or 443)):
        raise BridgeError("foreign upload host or port refused")
    path = urllib.parse.unquote(candidate.path)
    if (not path.startswith(allowed.path) or path == allowed.path
            or "\\" in path or any(p in {".", ".."} for p in path.split("/"))):
        raise BridgeError("URL is outside the upload directory")


def voice_url(cfg: dict, msg) -> str | None:
    """OOB declares an upload; a bare link needs the upload allowlist first."""
    element = msg.xml.find("{jabber:x:oob}x/{jabber:x:oob}url")
    if element is not None and element.text:
        return element.text.strip()
    body = str(msg["body"]).strip()
    if re.fullmatch(r"https?://\S+", body):
        try:
            validate_upload_url(cfg, body)
        except BridgeError:
            return None  # Ordinary links keep the pre-voice text-mail route.
        return body
    return None


class NoRedirect(urllib.request.HTTPRedirectHandler):
    def redirect_request(self, req, fp, code, msg, headers, newurl):
        raise BridgeError("upload redirects refused")


def download_voice(cfg: dict, url: str, destination: Path, opener=None) -> None:
    validate_upload_url(cfg, url)
    opener = opener or urllib.request.build_opener(
        urllib.request.ProxyHandler({}), NoRedirect()).open
    deadline = time.monotonic() + DOWNLOAD_SECONDS
    request = urllib.request.Request(url, headers={"Accept-Encoding": "identity"})
    try:
        with opener(request, timeout=5) as response:
            if response.status != 200:
                raise BridgeError("upload fetch returned a non-success status")
            length = response.headers.get("Content-Length")
            if length is not None and (int(length) < 0 or int(length) > VOICE_LIMIT):
                raise BridgeError("voice upload exceeds 25 MiB")
            descriptor = os.open(destination, os.O_WRONLY | os.O_CREAT | os.O_EXCL, 0o600)
            with os.fdopen(descriptor, "wb") as stream:
                total = 0
                while True:
                    if time.monotonic() >= deadline:
                        raise BridgeError("voice download timed out")
                    # read1 does not wait to fill a large buffer on trickle streams.
                    chunk = response.read1(min(65536, VOICE_LIMIT - total + 1))
                    if time.monotonic() >= deadline:
                        raise BridgeError("voice download timed out")
                    if not chunk:
                        break
                    total += len(chunk)
                    if total > VOICE_LIMIT:
                        raise BridgeError("voice upload exceeds 25 MiB")
                    stream.write(chunk)
                if not total or (length is not None and total != int(length)):
                    raise BridgeError("voice upload is empty or incomplete")
    except BridgeError:
        raise
    except (OSError, ValueError, urllib.error.URLError) as error:
        raise BridgeError("voice download failed (network, TLS or invalid response)") from error


def transcribe_voice(audio: Path, run=subprocess.run) -> str:
    output = audio.parent / "transcript.md"
    try:
        command = Path.home() / "HelmCortex/FORGE/bin/whisper-transcribe"
        result = run([str(command), str(audio), "--out", str(output)],
                     capture_output=True, text=True, timeout=TRANSCRIBE_SECONDS)
        if result.returncode != 0:
            raise BridgeError("whisper transcription failed or was quality-suspect")
        raw = output.read_text(encoding="utf-8")
    except subprocess.TimeoutExpired as error:
        raise BridgeError("whisper transcription timed out") from error
    except (OSError, UnicodeError) as error:
        raise BridgeError("whisper-transcribe or its transcript is unavailable") from error
    metadata, separator, text = raw.partition("\n---\n")
    text = text.strip()
    if (not metadata.startswith("---\n") or not separator
            or "whisper_quality: clean" not in metadata.splitlines()
            or not text or text in {"[non-speech audio]", "[transcription unavailable]"}):
        raise BridgeError("whisper returned no clean speech transcript")
    if len(text) > MAX_BODY:
        raise BridgeError("voice transcript exceeds the message limit")
    return text


def inbound_voice(cfg: dict, sender: str, local: str, url: str,
                  run=subprocess.run, download=None, transcribe=None) -> str:
    target = cfg["seats"].get(local)
    if target is None:
        raise BridgeError("unknown seat")
    validate_upload_url(cfg, url)  # Before even an injected downloader is called.
    filename = re.sub(r"[^A-Za-z0-9._-]", "_",
                      urllib.parse.unquote(urllib.parse.urlsplit(url).path.rsplit("/", 1)[-1]))
    filename = "voice-" + filename[-100:]
    with tempfile.TemporaryDirectory(prefix="mailcortex-voice.") as directory:
        audio = Path(directory) / filename
        (download or download_voice)(cfg, url, audio)
        text = (transcribe or transcribe_voice)(audio).strip()
        if not text or len(text) > MAX_BODY:
            raise BridgeError("voice transcript is empty or too long")
        framed = (f"XMPP-From: {bare(sender)}\n"
                  f"XMPP-To: {local}@{cfg['component_jid']}\n"
                  f"Reply-Via: mailcortex send --from <your address> --to {cfg['bridge_address']}\n"
                  "Voice-Note: original audio attached\n\n" + text + "\n")
        return mailcortex(["send", "--from", cfg["bridge_address"], "--to", target,
                           "--subject", "[xmpp voice] " + text.splitlines()[0][:70],
                           "--body", framed, "--attach", str(audio)], run).strip()


async def deliver_inbound(cfg: dict, msg, sender: str, local: str, url: str | None) -> None:
    try:
        if url is not None:
            name = await asyncio.to_thread(inbound_voice, cfg, sender, local, url)
        else:
            name = inbound_mail(cfg, sender, local, msg["body"])
    except (BridgeError, OSError) as error:
        diagnostic = " ".join(str(error).split())[:200]
        LOG.error("delivery failed for %s: %s", local, diagnostic)
        prefix = "Voice note could not be transcribed: " if url is not None else "Not delivered: "
        msg.reply(prefix + diagnostic).send()
        return
    LOG.info("delivered %s -> %s as %s", sender, local, name)


def pending_outbound(cfg: dict, run=subprocess.run) -> list[str]:
    rows = mailcortex(["inbox", cfg["bridge_address"]], run).splitlines()
    return [row.split("\t")[1] for row in rows if row.startswith("new\t")]


def render_outbound(cfg: dict, rendered: str) -> tuple[str | None, str, str]:
    """Parse `mailcortex read` output into (seat local part, chat text, Message-ID)."""
    message = Parser(policy=policy.default).parsestr(rendered)
    sender = parseaddr(str(message.get("From", "")))[1].lower()
    local = cfg["reverse"].get(sender.split("@")[0]) if "@" in sender else None
    subject = str(message.get("Subject", "")).strip()
    body = (message.get_payload() or "").strip()
    if subject and not subject.lower().startswith(("re: [xmpp]", "[xmpp]")):
        text = f"{subject}\n\n{body}" if body else subject
    else:
        text = body or subject
    return local, text[:MAX_BODY], str(message.get("Message-ID", "")).strip()


def run_bridge(cfg: dict) -> int:
    try:
        import asyncio
        import slixmpp
    except ImportError:
        raise BridgeError("python3-slixmpp is not installed (mailcortex-xmpp-package)")

    secret = read_secret(cfg["component_secret_file"])
    gate = Gate(cfg["owner_jids"], cfg["rate_per_minute"])
    seen = Seen(state_root() / "seen.json")

    class Component(slixmpp.ComponentXMPP):
        def __init__(self) -> None:
            super().__init__(cfg["component_jid"], secret, cfg["server"], cfg["port"])
            self.register_plugin("xep_0030")
            self.register_plugin("xep_0199")
            self.add_event_handler("session_start", self.on_start)
            self.add_event_handler("message", self.on_message)
            self.add_event_handler("presence_subscribe", self.on_subscribe)
            self.add_event_handler("presence_probe", self.on_probe)
            self.poller = None
            self.voice_jobs = 0

        def seat_jid(self, local: str) -> str:
            return f"{local}@{cfg['component_jid']}"

        async def on_start(self, _event) -> None:
            LOG.info("component online: %s (%d seats)", cfg["component_jid"], len(cfg["seats"]))
            for local in cfg["seats"]:
                for owner in cfg["owner_jids"]:
                    self.send_presence(pfrom=self.seat_jid(local), pto=owner)
            if self.poller is None:
                self.poller = asyncio.ensure_future(self.poll_outbound())

        def on_subscribe(self, presence) -> None:
            local = presence["to"].user
            if bare(presence["from"]) in gate.owners and local in cfg["seats"]:
                self.send_presence(pfrom=presence["to"].bare, pto=presence["from"].bare, ptype="subscribed")
                self.send_presence(pfrom=presence["to"].bare, pto=presence["from"].bare)
            else:
                self.send_presence(pfrom=presence["to"].bare, pto=presence["from"].bare, ptype="unsubscribed")

        def on_probe(self, presence) -> None:
            if bare(presence["from"]) in gate.owners and presence["to"].user in cfg["seats"]:
                self.send_presence(pfrom=presence["to"].bare, pto=presence["from"].bare)

        async def on_message(self, msg) -> None:
            if msg["type"] not in ("chat", "normal"):
                return
            url = voice_url(cfg, msg)
            if not msg["body"] and url is None:
                return
            sender = bare(msg["from"])
            local = msg["to"].user
            refusal = gate.admit(sender, time.monotonic())
            if refusal:
                LOG.warning("refused %s from %s to %s", refusal, sender, local)
                if refusal == "rate_limited":
                    msg.reply("Rate limited; message not delivered.").send()
                return
            if local not in cfg["seats"]:
                LOG.warning("unknown seat %s from %s", local, sender)
                msg.reply("No such seat.").send()
                return
            key = f"{sender}|{local}|{msg['id']}" if msg["id"] else None
            if not seen.check_and_add(key):
                LOG.info("duplicate stanza %s ignored", key)
                return
            if url is not None and self.voice_jobs >= VOICE_JOBS:
                LOG.warning("voice capacity reached for %s", local)
                msg.reply("Voice note not delivered: transcription capacity reached; resend later.").send()
                return
            if url is not None:
                self.voice_jobs += 1
            try:
                await deliver_inbound(cfg, msg, sender, local, url)
            finally:
                if url is not None:
                    self.voice_jobs -= 1

        async def poll_outbound(self) -> None:
            while True:
                try:
                    self.relay_outbound()
                except BridgeError as error:
                    LOG.error("outbound poll failed: %s", error)
                await asyncio.sleep(cfg["poll_seconds"])

        def relay_outbound(self) -> None:
            for name in pending_outbound(cfg):
                rendered = mailcortex(["read", cfg["bridge_address"], name])
                local, text, message_id = render_outbound(cfg, rendered)
                if local is None:
                    LOG.warning("rejected outbound mail %s from an unmapped sender", name)
                    if message_id:
                        mailcortex(["receipt", cfg["bridge_seat"], message_id, "handling_rejected"])
                    continue
                for owner in cfg["owner_jids"]:
                    self.send_message(mto=owner, mfrom=self.seat_jid(local), mbody=text, mtype="chat")
                if message_id:
                    mailcortex(["receipt", cfg["bridge_seat"], message_id, "handling_completed"])
                LOG.info("relayed %s from %s", name, local)

    component = Component()
    component.connect()
    asyncio.get_event_loop().run_until_complete(component.disconnected)
    return 1


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(
        prog="mailcortex-xmpp-bridge",
        description="Bridge MailCortex seats to XMPP through a Prosody component.")
    parser.add_argument("--check", action="store_true",
                        help="validate the private config and secret, then exit")
    parser.add_argument("--config", type=Path, default=None,
                        help="bridge.json path (default ~/.config/mailcortex/xmpp-private/bridge.json)")

* Service owner

=mailcortex-xmpp-service= owns both processes on the serving host: Prosody (user instance, this module's configuration) and the bridge. =ensure= is idempotent and is what the boot and self-heal cron lines call; it starts only what is not running and refuses to start anything until the private site files exist. Processes are identified by pidfile plus a command-line check, never by name alone. =renew-cert= reads the client domain from the private =cert-domain= file, refreshes the Tailscale certificate (Tailscale reissues only inside its renewal window) and sends Prosody =SIGHUP= when the certificate changed, so it reloads without dropping clients. =install-cron= adds the tagged =@reboot=, five-minute self-heal and weekly renewal lines to the user crontab once; =remove-cron= deletes only those tagged lines.

set -euo pipefail

usage() {

Own the user Prosody instance and mailcortex-xmpp-bridge on this host.
ensure starts whatever is not running (boot and self-heal entrypoint).

Nothing starts until ~/.config/mailcortex/xmpp-private/{local.cfg.lua,bridge.json} exist.

base="$HOME/.config/mailcortex/xmpp"
site="$HOME/.config/mailcortex/xmpp-private"
data="$HOME/.local/share/mailcortex/xmpp"
state="$HOME/.local/state/mailcortex/xmpp"
config="$base/prosody.cfg.lua"
prosody_pid="$data/prosody.pid"

tag="# dotcortex:mailcortex-xmpp"

ready() {
  [ -r "$config" ] && [ -r "$site/local.cfg.lua" ] && [ -r "$site/bridge.json" ] || {
    echo "mailcortex-xmpp-service: not ready (private site files missing in $site)" >&2
    return 1
  }
}

alive() { # pidfile pattern
  local pid
  [ -r "$1" ] || return 1
  pid="$(cat "$1" 2>/dev/null)"
  case "$pid" in ''|*[!0-9]*) return 1 ;; esac
  [ -r "/proc/$pid/cmdline" ] && tr '\0' ' ' < "/proc/$pid/cmdline" | grep -q -- "$2"
}

start_prosody() {
  alive "$prosody_pid" "$config" && return 0
  install -d -m 700 "$data" "$data/data"
  nohup prosody --config "$config" >>"$data/prosody.stdout" 2>&1 &
  for _ in $(seq 1 20); do alive "$prosody_pid" "$config" && return 0; sleep 0.5; done
  echo "mailcortex-xmpp-service: prosody did not come up (see $data/prosody.err)" >&2
  return 1
}

start_bridge() {
  alive "$bridge_pid" mailcortex-xmpp-bridge && return 0
  install -d -m 700 "$state"
  mailcortex-xmpp-bridge --check >/dev/null
  nohup mailcortex-xmpp-bridge >>"$state/bridge.log" 2>&1 &
  echo $! > "$bridge_pid"
  sleep 1
  alive "$bridge_pid" mailcortex-xmpp-bridge || {
    echo "mailcortex-xmpp-service: bridge exited (see $state/bridge.log)" >&2
    return 1
  }
}

stop_one() { # pidfile pattern
  if alive "$1" "$2"; then kill "$(cat "$1")"; fi
  rm -f "$1"
}

status() {
  local rc=0
  if alive "$prosody_pid" "$config"; then echo "prosody: running ($(cat "$prosody_pid"))"; else echo "prosody: stopped"; rc=1; fi
  if alive "$bridge_pid" mailcortex-xmpp-bridge; then echo "bridge: running ($(cat "$bridge_pid"))"; else echo "bridge: stopped"; rc=1; fi
  return $rc
}

case "${1:-}" in
  -h|--help) usage ;;
  start|ensure) ready; start_prosody; start_bridge ;;
  stop) stop_one "$bridge_pid" mailcortex-xmpp-bridge; stop_one "$prosody_pid" "$config" ;;
  status) status ;;
  renew-cert)
    [ -r "$site/cert-domain" ] || { echo "mailcortex-xmpp-service: no $site/cert-domain" >&2; exit 1; }
    domain="$(tr -d '[:space:]' < "$site/cert-domain")"
    crt="$site/certs/$domain.crt"
    before="$(sha256sum "$crt" 2>/dev/null | cut -d' ' -f1 || true)"
    mailcortex-xmpp-cert "$domain"
    after="$(sha256sum "$crt" | cut -d' ' -f1)"
    if [ "$before" != "$after" ] && alive "$prosody_pid" "$config"; then
      kill -HUP "$(cat "$prosody_pid")"; echo "certificate changed; prosody reloaded"
    else
      echo "certificate unchanged"
    fi
    mailcortex-xmpp-cert "$domain" --check ;;
  install-cron)
    ready
    self="$HOME/.local/bin/mailcortex-xmpp-service"
    env="HOME=$HOME PATH=$HOME/.local/bin:/usr/local/bin:/usr/bin:/bin"
    current="$(crontab -l 2>/dev/null || true)"
    if printf '%s\n' "$current" | grep -qF "$tag"; then echo "cron already installed"; exit 0; fi
    { printf '%s\n' "$current" | sed '/^$/d'
      echo "@reboot $env $self ensure >>$state/cron.log 2>&1 $tag"
      echo "*/5 * * * * $env $self ensure >>$state/cron.log 2>&1 $tag"
      echo "23 4 * * 1 $env $self renew-cert >>$state/cron.log 2>&1 $tag"
    } | crontab -
    echo "cron installed" ;;
  remove-cron)
    (crontab -l 2>/dev/null || true) | grep -vF "$tag" | crontab -
    echo "cron removed" ;;
  *) usage >&2; exit 2 ;;
esac

    def test_failure_replies_once_and_worker_leaves_loop_responsive(self):
        msg = FakeMessage(self.url)
        async def failure():
            with patch.object(bridge, "inbound_voice", side_effect=bridge.BridgeError("whisper failed\nretry")):
                with self.assertLogs(bridge.LOG, level="ERROR"):
                    await bridge.deliver_inbound(self.cfg, msg, "owner@example.test", "fable", self.url)
        asyncio.run(failure())
        self.assertEqual(msg.replies, ["Voice note could not be transcribed: whisper failed retry"])
        started, release = threading.Event(), threading.Event()
        def slow(*args):
            started.set()
            if not release.wait(2):
                raise bridge.BridgeError("test worker was not released")
            return "delivered.msg"
        async def responsive():
            with patch.object(bridge, "inbound_voice", side_effect=slow):
                job = asyncio.create_task(bridge.deliver_inbound(self.cfg, FakeMessage(self.url),
                                          "owner@example.test", "fable", self.url))
                try:
                    for _ in range(100):
                        if started.is_set():
                            break
                        await asyncio.sleep(0.005)
                    self.assertTrue(started.is_set())
                    self.assertFalse(job.done())
                finally:
                    release.set()
                    await job
        asyncio.run(responsive())
