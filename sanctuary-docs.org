* The Fleet Library

Zeal is the Help engine of the Virtual Habitat: every sanctuary with a Zeal gets a shelf of docsets describing the world it actually lives in. The supersystem owns one generic generator; discovery is per-machine and automatic, so nothing here names a host or hardcodes a corpus. Each machine builds its own truth from what is present, exactly like tangle→stow: the generator syncs via git, the artefacts never do.

Discovery lanes (all automatic, all conditional on presence):

- *Host manuals* — =manpath= on the machine, docset named after the short hostname. The T480s docset reflects Devuan; the X230's reflects its own world.
- *Sanctuary manuals* — every guest under =$XDG_DATA_HOME/dotcortex/guests/*/home= with Guix profiles gets its own docset from its *current* profile generations only (stale-generation man pages are a trap: a naive find over =.guix-extra-profiles= returns pages for software no longer installed).
- Later phases add authored layers (Redstone 9X Help, Sanctuary Help), org-export manuals (DotCortex, HelmCortex — the latter only where =~/HelmCortex= resolves, which is the entire secrecy gate), and Texinfo manuals (Emacs, Doom, Spacemacs).

Generated docsets land in =$XDG_DATA_HOME/dotcortex/docsets/= — never committed, never inside =$HOME= config paths — and are symlinked into every guest home that has a Zeal docsets directory. Section→type mapping: 1,8→Command; 2,3,9→Function; 4,5→File; 6→Game; 7→Guide.

The renderer is =mandoc= (declared in the core Guix manifest; the driver self-wraps in =guix shell mandoc= when the profile has not been applied yet, so a fresh machine can build docs before its first =guix:apply=). Pages whose body is a single =.so= redirect are resolved to their target. Incremental rebuilds track source path+mtime+size in a build manifest inside the docset, so an unchanged corpus is a no-op.

* Docset generator

One docset per invocation. Mode =man= takes any number of man roots; later modes (=org=, =info=) join the same CLI. Python for the index/plist/manifest bookkeeping; =mandoc= does all rendering.

"""Generate a Dash/Zeal docset. Mode `man`: render man roots via mandoc.
Modes `org` and `md`: render authored documents (Emacs ox-html / Python-Markdown).

Usage:
  dotcortex-docset-gen man --name "T480s Manuals" --keyword t480s \
      --out /path/Name.docset ROOT [ROOT ...]
  dotcortex-docset-gen org --name "DotCortex Docs" --keyword dotcortex \
      --out /path/Name.docset --base ~/DotCortex [--exclude GLOB ...] ROOT [ROOT ...]
  dotcortex-docset-gen md  --name "HelmCortex Docs" --keyword helmcortex \
      --out /path/Name.docset --base ~/HelmCortex [--exclude GLOB ...] ROOT [ROOT ...]

Rules honoured here:
  - English pages only (locale subdirs like man/fr/man1 are skipped).
  - First root wins on (name, section) collisions.
  - `.so` redirect pages resolve to their target's HTML.
  - Incremental: unchanged sources (mtime+size) are not re-rendered.
  - org/md: one page per file, named by its path relative to --base; every
    heading becomes a <section class="Sh|Ss"> so dotcortex-help-corpus-build
    chunks per heading exactly as it does for man pages. Symlinks are never
    followed, hidden directories are skipped, and oversize files are reported.
"""

MANDIR_RE = re.compile(r"^man([0-9])$")
PAGE_RE = re.compile(r"^(?P<name>.+)\.(?P<sec>[0-9][a-zA-Z0-9]*)(?P<comp>\.(?:gz|zst|bz2|xz))?$")
SO_RE = re.compile(rb"^\.so\s+(?:.*/)?(?P<target>\S+)\s*$")


def read_source(path: Path) -> bytes:
    """Decompress via stdin pipes: Guix profiles are symlink farms, and zstd
    REFUSES symlink arguments by default (silently: warning + empty output)."""
    if path.suffix == ".gz":
        with gzip.open(path, "rb") as f:
            return f.read()
    tool = {".zst": ["zstd", "-dc"], ".bz2": ["bzip2", "-dc"],
            ".xz": ["xz", "-dc"]}.get(path.suffix)
    if tool:
        with path.open("rb") as f:
            return subprocess.run(tool, stdin=f, check=True,
                                  capture_output=True).stdout
    return path.read_bytes()


def discover(roots):
    """Yield (name, sec, digit, path) for English pages, first root wins."""
    seen = {}
    for root in roots:
        root = Path(root)
        if not root.is_dir():
            continue
        for mandir in sorted(root.iterdir()):
            m = MANDIR_RE.match(mandir.name)
            if not m or not mandir.is_dir():
                continue
            digit = m.group(1)
            for page in sorted(mandir.iterdir()):
                if not page.is_file():
                    continue
                pm = PAGE_RE.match(page.name)
                if not pm:
                    continue
                key = (pm.group("name"), pm.group("sec"))
                if key not in seen:
                    seen[key] = (digit, page)
    for (name, sec), (digit, page) in seen.items():
        yield name, sec, digit, page


DOC_RENDERER = "docs-2"
DOC_SKIP_DIRS = {"node_modules", "__pycache__", "__pycache", ".git"}
DOC_SUFFIX = {"org": ".org", "md": ".md"}

HEADING_RE = re.compile(r"<h([1-6])\b[^>]*>(.*?)</h\1>", re.S)
TAG_RE = re.compile(r"<[^>]+>")
HREF_ATTR_RE = re.compile(r'(\bhref=")([^"]+)(")')

def slugify(text, seen):
    base = re.sub(r"[^a-z0-9]+", "-", htmllib.unescape(text).lower()).strip("-") or "section"
    slug, n = base, 0
    while slug in seen:
        n += 1
        slug = f"{base}-{n}"
    seen.add(slug)
    return slug


def section_open(level, slug, heading_html):
    cls, tag = ("Sh", "h1") if level == 1 else ("Ss", "h2")
    return (f'<section class="{cls}" id="{slug}" data-level="{level}">'
            f'<{tag} class="{cls}" id="{slug}">{heading_html}</{tag}>')


def sectionize_flat(body, title):
    """Wrap flat HTML (Markdown output) into nested Sh/Ss sections by heading level."""
    out, stack, pos, seen = [], [], 0, set()
    first = HEADING_RE.search(body)
    lead = body[:first.start()] if first else body
    if lead.strip():
        slug = slugify(title, seen)
        out.append(section_open(1, slug, htmllib.escape(title)))
        out.append(lead)
        out.append("</section>")
    for m in HEADING_RE.finditer(body):
        level = int(m.group(1))
        if m.start() > pos and pos:
            out.append(body[pos:m.start()])
        while stack and stack[-1] >= level:
            stack.pop()
            out.append("</section>")
        slug = slugify(TAG_RE.sub("", m.group(2)), seen)
        out.append(section_open(level, slug, m.group(2)))
        stack.append(level)
        pos = m.end()
    if first:
        out.append(body[pos:])
    out.extend("</section>" for _ in stack)
    return "".join(out)


class OrgRewriter(HTMLParser):
    """Rewrite ox-html's outline containers (section/div id=outline-container-X) into
    the Sh/Ss contract with stable text-derived anchors; keep everything else verbatim."""

    def __init__(self, idmap, title):
        super().__init__(convert_charrefs=False)
        self.idmap, self.title = idmap, title
        self.out, self.stack, self.in_heading, self.heading_level = [], [], None, 2

    def handle_starttag(self, tag, attrs):
        d = dict(attrs)
        if tag in ("div", "section"):
            m = OUTLINE_RE.match(d.get("id", ""))
            if m and m.group(1) in self.idmap:
                level, slug = self.idmap[m.group(1)]
                cls = "Sh" if level == 1 else "Ss"
                self.out.append(f'<section class="{cls}" id="{slug}" data-level="{level}">')
                self.stack.append("section")
                return
            self.stack.append(tag)
        if tag in ("h1", "h2", "h3", "h4", "h5", "h6") and d.get("id") in self.idmap:
            level, slug = self.idmap[d["id"]]
            cls, htag = ("Sh", "h1") if level == 1 else ("Ss", "h2")
            self.out.append(f'<{htag} class="{cls}" id="{slug}">')
            self.in_heading, self.heading_level = tag, level
            return
        text = self.get_starttag_text()
        for k, v in attrs:
            if k == "href" and v and v.startswith("#") and v[1:] in self.idmap:
                text = text.replace(f'"{v}"', f'"#{self.idmap[v[1:]][1]}"')
        self.out.append(text)

    def handle_startendtag(self, tag, attrs):
        self.out.append(self.get_starttag_text())

    def handle_endtag(self, tag):
        if self.in_heading == tag:
            self.out.append("</h1>" if self.heading_level == 1 else "</h2>")
            self.in_heading = None
            return
        if tag in ("div", "section") and self.stack:
            self.out.append(f"</{self.stack.pop()}>")
            return
        self.out.append(f"</{tag}>")

    def handle_data(self, data):
        self.out.append(data)

    def handle_entityref(self, name):
        self.out.append(f"&{name};")

    def handle_charref(self, name):
        self.out.append(f"&#{name};")


def sectionize_org(body, title):
    """Turn ox-html body output into the Sh/Ss contract."""
    seen, idmap = set(), {}
    levels = {}
    for m in re.finditer(r'<(?:div|section) id="outline-container-([^"]+)" class="outline-(\d+)"', body):
        levels[m.group(1)] = int(m.group(2)) - 1      # outline-2 is org level 1
    for m in re.finditer(r'<h([1-6]) id="([^"]+)">(.*?)</h\1>', body, re.S):
        if m.group(2) in levels:
            idmap[m.group(2)] = (levels[m.group(2)], slugify(TAG_RE.sub("", m.group(3)), seen))
    first = re.search(r'<(?:div|section) id="outline-container-', body)
    lead = body[:first.start()] if first else body
    rest = body[first.start():] if first else ""
    out = []
    if lead.strip():
        slug = slugify(title, seen)
        out.append(section_open(1, slug, htmllib.escape(title)) + lead + "</section>")
    rw = OrgRewriter(idmap, title)
    rw.feed(rest)
    rw.close()
    out.append("".join(rw.out))
    return "".join(out)


def discover_docs(mode, roots, base, excludes, max_bytes):
    """Return (pages, skipped) where pages is [(rel, path)] sorted by rel and skipped
    maps reason -> list of rel paths. Never follows symlinks."""
    suffix, pages, skipped, seen = DOC_SUFFIX[mode], [], {"symlink": [], "oversize": [], "excluded": []}, set()
    base = os.path.abspath(base)

    def relpath(path):
        return Path(os.path.relpath(os.path.abspath(path), base)).as_posix()

    def excluded(rel):
        parts = rel.split("/")
        return any(fnmatch.fnmatch(rel, g) or any(fnmatch.fnmatch(x, g) for x in parts) for g in excludes)

    def consider(path):
        rel = relpath(path)
        if path.is_symlink():
            skipped["symlink"].append(rel)
        elif excluded(rel):
            skipped["excluded"].append(rel)
        elif path.stat().st_size > max_bytes:
            skipped["oversize"].append(rel)
        elif rel not in seen:
            seen.add(rel)
            pages.append((rel, path))

    for root in roots:
        root = Path(root)
        if root.is_file() and not root.is_symlink():
            if root.name.endswith(suffix):
                consider(root)
            continue
        for dirpath, dirnames, filenames in os.walk(root, followlinks=False):
            keep = []
            for name in sorted(dirnames):
                full = Path(dirpath) / name
                if name.startswith(".") or name in DOC_SKIP_DIRS:
                    continue
                if full.is_symlink():
                    skipped["symlink"].append(relpath(full))
                    continue
                if excluded(relpath(full)):
                    skipped["excluded"].append(relpath(full) + "/")
                    continue
                keep.append(name)
            dirnames[:] = keep
            for name in sorted(filenames):
                if name.endswith(suffix) and not name.startswith("."):
                    consider(Path(dirpath) / name)
    return sorted(pages), skipped


def find_emacs():

    if found:

    guix = Path.home() / ".guix-extra-profiles/core/core/bin/emacs"
    return str(guix) if guix.exists() else None


def doc_title(mode, src_text, rel):
    if mode == "org":
        m = re.search(r"^#\+TITLE:\s*(.+)$", src_text, re.M | re.I)
        if m:
            return m.group(1).strip()
    return rel


def build_link_rewriter(pages):
    """Build a function(src_rel, html_body) that rewrites relative inter-document links
    (e.g. `./docs/pvox.md#usage` in `FORGE/README.md`, or ox-html's `CODE_OF_SOVEREIGNTY.html`
    in `README.org`) to the flat docset HTML filenames (`FORGE__docs__pvox.md.html#usage`),
    leaving external URLs, same-page `#anchor` links, and non-docset targets unchanged."""
    html_by_rel = {rel: rel.replace("/", "__") + ".html" for rel, _ in pages}
    stem_to_rel = {os.path.splitext(rel)[0] + ".html": rel for rel, _ in pages}

    def resolve_href(src_rel, raw_href):
        href = htmllib.unescape(raw_href).strip()
        if not href or href.startswith("#"):
            return raw_href
        try:
            parts = urlsplit(href)
        except ValueError:
            return raw_href
        if parts.scheme or parts.netloc or parts.query or not parts.path:
            return raw_href
        joined = os.path.normpath(os.path.join(os.path.dirname(src_rel), unquote(parts.path))).replace(os.sep, "/")
        if joined.startswith("..") or joined.startswith("/"):
            return raw_href
        target_rel = joined if joined in html_by_rel else stem_to_rel.get(joined)
        if not target_rel:
            return raw_href
        out = html_by_rel[target_rel]
        if parts.fragment:
            out += "#" + parts.fragment
        return htmllib.escape(out, quote=True)

    def rewrite(src_rel, body):
        return HREF_ATTR_RE.sub(lambda m: m.group(1) + resolve_href(src_rel, m.group(2)) + m.group(3), body)

    return rewrite


def render_docs(args):
    mode = args.mode
    roots = [Path(r) for r in args.roots]
    if args.base:
        base = Path(args.base)
    elif len(roots) == 1 and roots[0].is_dir():
        base = roots[0]
    else:
        sys.exit("dotcortex-docset-gen: --base is required with several roots or a file root")
    for r in roots:
        try:
            r.resolve().relative_to(base.resolve())
        except ValueError:
            sys.exit(f"dotcortex-docset-gen: root {r} is outside --base {base}")
    pages, skipped = discover_docs(mode, roots, base, args.exclude, args.max_bytes)
    names = {}
    for rel, _ in pages:
        html = rel.replace("/", "__") + ".html"
        if html in names:
            sys.exit(f"dotcortex-docset-gen: page name collision: {rel} and {names[html]}")
        names[html] = rel
    rewrite_links = build_link_rewriter(pages)
    membership = hashlib.sha256("\n".join(rel for rel, _ in pages).encode("utf-8")).hexdigest()[:16]

    out = Path(args.out)
    docs = out / "Contents/Resources/Documents"
    docs.mkdir(parents=True, exist_ok=True)
    manifest_path = out / "Contents/.build-manifest.json"
    manifest = {}
    if manifest_path.is_file():
        try:
            manifest = json.loads(manifest_path.read_text())
        except (json.JSONDecodeError, OSError):
            manifest = {}
    if manifest.get("__renderer__") != DOC_RENDERER or manifest.get("__pages__") != membership:
        manifest = {}
    ident = re.sub(r"[^a-z0-9]+", "-", args.name.lower()).strip("-")
    (out / "Contents/Info.plist").write_text(PLIST.format(ident=ident, name=args.name, keyword=args.keyword))
    (docs / "style.css").write_text(CSS)

    new_manifest = {"__renderer__": DOC_RENDERER, "__pages__": membership}
    stale, entries, skipped_n, failed = [], [], 0, []
    for rel, path in pages:
        html = rel.replace("/", "__") + ".html"
        st = path.stat()
        stamp = [st.st_mtime, st.st_size]
        new_manifest[rel] = stamp
        if manifest.get(rel) == stamp and (docs / html).is_file():
            skipped_n += 1
            entries.append((rel, "Guide", html))
        else:
            stale.append((rel, path, html))

    rendered = 0
    if stale and mode == "org":
        emacs = find_emacs()
        if not emacs:
            sys.exit("dotcortex-docset-gen: emacs not found (Guix core profile provides it)")
        with tempfile.TemporaryDirectory(prefix="dotcortex-docs-") as tmp:
            tmp = Path(tmp)
            jobs = tmp / "jobs.tsv"
            jobs.write_text("".join(f"{path}\t{tmp / (html + '.body')}\n" for _, path, html in stale))
            env = dict(os.environ, DOTCORTEX_DOCS_JOBS=str(jobs))
            proc = subprocess.run([emacs, "--batch", "-Q", "--eval", ORG_JOB_ELISP],
                                  env=env, capture_output=True, text=True, timeout=args.timeout)
            for line in proc.stdout.splitlines():
                if line.startswith("FAIL\t"):
                    print(line, file=sys.stderr)
            for rel, path, html in stale:
                body_file = tmp / (html + ".body")
                if not body_file.is_file():
                    failed.append(rel)
                    new_manifest.pop(rel, None)
                    continue
                title = doc_title(mode, path.read_text(errors="replace"), rel)
                sectioned = rewrite_links(rel, sectionize_org(body_file.read_text(), title))
                (docs / html).write_text(wrap_page(title, sectioned))
                entries.append((rel, "Guide", html))
                rendered += 1
    elif stale and mode == "md":
        try:
            import markdown
        except ImportError:
            sys.exit("dotcortex-docset-gen: python 'markdown' module not importable "
                     "(HelmCortex hosts: run with the helmcortex conda python)")
        for rel, path, html in stale:
            text = path.read_text(errors="replace")
            body = markdown.markdown(text, extensions=["extra", "sane_lists"])
            title = doc_title(mode, text, rel)
            sectioned = rewrite_links(rel, sectionize_flat(body, title))
            (docs / html).write_text(wrap_page(title, sectioned))
            entries.append((rel, "Guide", html))
            rendered += 1

    valid = {html for _, _, html in entries}
    for f in docs.glob("*.html"):
        if f.name not in valid and f.name != "index.html":
            f.unlink()
    db = out / "Contents/Resources/docSet.dsidx"
    db.unlink(missing_ok=True)
    con = sqlite3.connect(db)
    con.execute("CREATE TABLE searchIndex(id INTEGER PRIMARY KEY, name TEXT, type TEXT, path TEXT)")
    con.execute("CREATE UNIQUE INDEX anchor ON searchIndex (name, type, path)")
    con.executemany("INSERT OR IGNORE INTO searchIndex(name, type, path) VALUES (?, ?, ?)", entries)
    con.commit()
    con.close()
    (docs / "index.html").write_text(f"""<!DOCTYPE html><html><head><meta charset="utf-8">
<title>{htmllib.escape(args.name)}</title><link rel="stylesheet" href="style.css"></head><body>
<h1>{htmllib.escape(args.name)}</h1>
<p>{len(entries)} documents, generated {datetime.now():%Y-%m-%d %H:%M} by dotcortex-docset-gen ({mode}).</p>
</body></html>""")
    manifest_path.write_text(json.dumps(new_manifest))
    note = "".join(f", {len(v)} {k}" for k, v in skipped.items() if v)
    print(f"{args.name}: {len(entries)} entries ({rendered} rendered, {skipped_n} cached, {len(failed)} failed{note})")
    if skipped["oversize"]:
        print("oversize: " + ", ".join(skipped["oversize"]), file=sys.stderr)
    if failed:
        print("failed: " + ", ".join(failed), file=sys.stderr)
        sys.exit(1)


def wrap_page(title, body):
    return (f'<!DOCTYPE html><html><head><meta charset="utf-8"><title>{htmllib.escape(title)}</title>'
            f'<link rel="stylesheet" href="style.css"></head><body>{body}</body></html>')


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("mode", choices=["man", "org", "md"])
    ap.add_argument("--name", required=True)
    ap.add_argument("--keyword", required=True)
    ap.add_argument("--out", required=True)
    ap.add_argument("--icon-dir", default=str(Path.home() / ".local/share/icons/Chicago95/apps"))
    ap.add_argument("--base", help="org/md: directory page names are relative to")
    ap.add_argument("--exclude", action="append", default=[],
                    help="org/md: fnmatch glob on a relative path or any path component (repeatable)")
    ap.add_argument("--max-bytes", type=int, default=2_000_000, help="org/md: skip larger files (reported)")
    ap.add_argument("--timeout", type=int, default=1800, help="org: emacs batch deadline in seconds")
    ap.add_argument("roots", nargs="+")
    args = ap.parse_args()

    if args.mode in DOC_SUFFIX:
        return render_docs(args)
    if shutil.which("mandoc") is None:
        sys.exit("dotcortex-docset-gen: mandoc not on PATH (run via dotcortex-docs-build, which wraps guix shell)")

    out = Path(args.out)
    docs = out / "Contents/Resources/Documents"
    docs.mkdir(parents=True, exist_ok=True)
    manifest_path = out / "Contents/.build-manifest.json"
    manifest = {}
    if manifest_path.is_file():
        try:
            manifest = json.loads(manifest_path.read_text())
        except (json.JSONDecodeError, OSError):
            manifest = {}

    ident = re.sub(r"[^a-z0-9]+", "-", args.name.lower()).strip("-")
    (out / "Contents/Info.plist").write_text(
        PLIST.format(ident=ident, name=args.name, keyword=args.keyword))
    (docs / "style.css").write_text(CSS)
    for size, dest in (("16", "icon.png"), ("32", "icon@2x.png")):
        src = Path(args.icon_dir) / size / "help-browser.png"
        if src.is_file():
            shutil.copy(src, out / dest)

    pages = list(discover(args.roots))
    entries = []          # (display_name, type, html)
    redirects = []        # (name, sec, digit, target_basename)
    new_manifest = {}
    rendered = skipped = failed = 0

    for name, sec, digit, path in pages:
        html = f"{name}.{sec}.html"
        st = path.stat()
        stamp = [st.st_mtime, st.st_size]
        key = str(path)
        try:
            src = read_source(path)
        except (OSError, subprocess.CalledProcessError):
            failed += 1
            continue
        so = SO_RE.match(src.splitlines()[0]) if src else None
        if so:
            redirects.append((name, sec, digit, so.group("target").decode(errors="replace")))
            new_manifest[key] = stamp
            continue
        if manifest.get(key) == stamp and (docs / html).is_file():
            skipped += 1
        else:
            proc = subprocess.run(
                ["mandoc", "-Thtml", "-O", "style=style.css,man=%N.%S.html"],
                input=src, capture_output=True)
            if proc.returncode != 0 and not proc.stdout:
                failed += 1
                continue
            (docs / html).write_bytes(proc.stdout)
            rendered += 1
        new_manifest[key] = stamp
        entries.append((f"{name}({sec})", TYPE_MAP.get(digit, "Guide"), html))

    have = {Path(h).name for _, _, h in entries}
    for name, sec, digit, target in redirects:
        target_html = f"{target}.html"
        if target_html in have:
            entries.append((f"{name}({sec})", TYPE_MAP.get(digit, "Guide"), target_html))

    # Drop HTML for sources that vanished from the corpus.
    valid = {f"{n}.{s}.html" for (n, s) in
             {(e[0].rsplit("(", 1)[0], e[0].rsplit("(", 1)[1].rstrip(")")) for e in entries}}
    for f in docs.glob("*.html"):
        if f.name not in valid and f.name != "index.html":
            f.unlink()

    db = out / "Contents/Resources/docSet.dsidx"
    db.unlink(missing_ok=True)
    con = sqlite3.connect(db)
    con.execute("CREATE TABLE searchIndex(id INTEGER PRIMARY KEY, name TEXT, type TEXT, path TEXT)")
    con.execute("CREATE UNIQUE INDEX anchor ON searchIndex (name, type, path)")
    con.executemany("INSERT OR IGNORE INTO searchIndex(name, type, path) VALUES (?, ?, ?)", entries)
    con.commit()
    con.close()

    by_sec = {}
    for disp, _, _ in entries:
        sec = disp.rsplit("(", 1)[1].rstrip(")")
        by_sec[sec] = by_sec.get(sec, 0) + 1
    rows = "".join(f"<tr><td>Section {s}</td><td>{c}</td></tr>"
                   for s, c in sorted(by_sec.items()))
    (docs / "index.html").write_text(f"""<!DOCTYPE html><html><head><meta charset="utf-8">
<title>{args.name}</title><link rel="stylesheet" href="style.css"></head><body>
<h1>{args.name}</h1>
<p>{len(entries)} manual pages, generated {datetime.now():%Y-%m-%d %H:%M} by dotcortex-docset-gen.</p>
<p>Search this docset alone by prefixing queries with <code>{args.keyword}:</code></p>
<table><tr><th align="left">Section</th><th align="left">Pages</th></tr>{rows}</table>
</body></html>""")

    manifest_path.write_text(json.dumps(new_manifest))
    print(f"{args.name}: {len(entries)} entries ({rendered} rendered, {skipped} cached, {failed} failed)")


if __name__ == "__main__":
    main()

* Help corpus

Zeal's =docSet.dsidx= is deliberately thin — =name=, =type=, =path=, nothing
else — which is perfect for Zeal navigation but useless for "what does this
page actually say". Clippy needs a full-text companion index, generated from
the docsets =dotcortex-docset-gen= already rendered — never independently
from the man sources — so Zeal and Clippy always inhabit exactly the same
library. SQLite FTS5, no embeddings: this corpus is highly lexical (command
names, option flags, error strings), and FTS gives deterministic, fast
retrieval for free.

Chunk boundary is the mandoc section, not the whole page: mandoc's HTML
output wraps every =.Sh=/=.Ss= in =<section class="Sh|Ss">= around an
=<h1|h2 id="ANCHOR">= heading (verified live against a rendered page, not
assumed from the CSS rule alone). A leaf-scoped stack parser gives one chunk
per leaf section — a page with subsections yields one chunk per subsection
plus one for the parent section's own lead-in text — so citations in Pass 2
can point at the actual subsection, not just the page.

The corpus lives at =$XDG_DATA_HOME/dotcortex/help/help-corpus.sqlite= —
same non-committed, host-local footing as the docsets shelf. Incremental via
content hash stored per =(docset, path)= in the =documents= table itself, no
separate manifest file: unchanged pages are skipped on rebuild, changed
pages have their chunks and FTS rows replaced, and documents whose docset or
dsidx entry vanished are pruned. A first cold build over the full fleet
shelf (tens of thousands of pages) runs a few minutes; every rebuild after
that only pays for what actually changed.

#+BEGIN_SRC python :tangle all/.local/bin/dotcortex-help-corpus-build :shebang "#!/usr/bin/env python3" :tangle-mode (identity #o755)
"""Build the Help Corpus (FTS5) from already-rendered Zeal docsets.

Consumes docSet.dsidx + Documents/*.html from every *.docset under
--docsets-dir (the exact artefacts dotcortex-docset-gen already produced),
never the original man sources -- Zeal and Clippy inhabit the same library.

Usage:
  dotcortex-help-corpus-build --docsets-dir DIR --out help-corpus.sqlite
"""
import argparse, hashlib, sqlite3, sys
from html.parser import HTMLParser
from pathlib import Path


class SectionChunker(HTMLParser):
    """Splits mandoc's <section class="Sh|Ss"><h1|h2 id=...>...</section>
    tree into one chunk per leaf section. Text seen while a child section
    is open never reaches the parent's buffer (stack scoping), so a
    section with subsections yields one chunk per subsection plus one
    chunk for the parent's own lead-in text."""

    def __init__(self):
        super().__init__(convert_charrefs=True)
        self.stack = []          # list of dict(anchor, heading, buf=[])
        self.chunks = []         # finished chunks
        self.heading_depth = None  # tag name ('h1'/'h2') currently capturing heading text

    def handle_starttag(self, tag, attrs):
        d = dict(attrs)
        cls = d.get("class", "")
        if tag == "section" and cls in ("Sh", "Ss"):
            self.stack.append({"anchor": d.get("id", ""), "heading": "", "buf": []})
        elif tag in ("h1", "h2") and cls in ("Sh", "Ss") and self.stack:
            self.heading_depth = tag
            # mandoc puts the id on the heading, not the section; without this every man-page
            # chunk has an empty anchor and a source chip cannot open the exact section.
            if not self.stack[-1]["anchor"] and d.get("id"):
                self.stack[-1]["anchor"] = d["id"]

    def handle_endtag(self, tag):
        if tag in ("h1", "h2") and self.heading_depth == tag:
            self.heading_depth = None
        elif tag == "section" and self.stack:
            top = self.stack.pop()
            body = "".join(top["buf"]).strip()
            if body:
                self.chunks.append((top["anchor"], top["heading"].strip(), body))

    def handle_data(self, data):
        if not self.stack:
            return
        if self.heading_depth:
            self.stack[-1]["heading"] += data
        else:
            self.stack[-1]["buf"].append(data)


def chunk_html(html: str):
    p = SectionChunker()
    p.feed(html)
    if p.chunks:
        return p.chunks
    # Fallback: no Sh/Ss sections found (unusual/degenerate page) -- one
    # whole-page chunk so nothing silently vanishes from the corpus.
    text = HTMLTextDump()
    text.feed(html)
    body = text.get_text().strip()
    return [("", "", body)] if body else []


class HTMLTextDump(HTMLParser):
    def __init__(self):
        super().__init__(convert_charrefs=True)
        self._parts = []

    def handle_data(self, data):
        self._parts.append(data)

    def get_text(self):
        return "".join(self._parts)


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--docsets-dir", required=True)
    ap.add_argument("--out", required=True)
    args = ap.parse_args()

    docsets_dir = Path(args.docsets_dir)
    out = Path(args.out)
    out.parent.mkdir(parents=True, exist_ok=True)

    con = sqlite3.connect(out)
    # Derived/rebuildable index: trade durability for build speed. A crash
    # mid-build just means the next `loom docs:build` rebuilds it.
    con.executescript("PRAGMA synchronous=OFF; PRAGMA journal_mode=MEMORY;")
    con.executescript("""
    CREATE TABLE IF NOT EXISTS documents(
      id INTEGER PRIMARY KEY,
      docset TEXT NOT NULL,
      name TEXT NOT NULL,
      type TEXT NOT NULL,
      path TEXT NOT NULL,
      source_hash TEXT NOT NULL,
      UNIQUE(docset, path)
    );
    CREATE TABLE IF NOT EXISTS chunks(
      id INTEGER PRIMARY KEY,
      document_id INTEGER NOT NULL REFERENCES documents(id) ON DELETE CASCADE,
      anchor TEXT NOT NULL,
      heading TEXT NOT NULL,
      body TEXT NOT NULL
    );
    CREATE VIRTUAL TABLE IF NOT EXISTS chunks_fts USING fts5(
      title, heading, body, chunk_id UNINDEXED, tokenize='porter unicode61'
    );
    """)

    seen_docsets = set()
    live_keys = set()
    docs_seen = chunks_seen = rendered = skipped = 0

    for docset_dir in sorted(docsets_dir.glob("*.docset")):
        dsidx = docset_dir / "Contents/Resources/docSet.dsidx"
        docs_root = docset_dir / "Contents/Resources/Documents"
        if not dsidx.is_file():
            continue
        docset_name = docset_dir.stem
        seen_docsets.add(docset_name)
        idx = sqlite3.connect(f"file:{dsidx}?mode=ro", uri=True)
        for name, typ, path in idx.execute("SELECT name, type, path FROM searchIndex"):
            live_keys.add((docset_name, path))
            html_path = docs_root / path
            if not html_path.is_file():
                continue
            raw = html_path.read_bytes()
            digest = hashlib.sha1(raw).hexdigest()
            row = con.execute(
                "SELECT id, source_hash FROM documents WHERE docset=? AND path=?",
                (docset_name, path)).fetchone()
            docs_seen += 1
            if row and row[1] == digest:
                skipped += 1
                continue
            html = raw.decode("utf-8", errors="replace")
            chunks = chunk_html(html)
            if row:
                doc_id = row[0]
                con.execute("DELETE FROM chunks WHERE document_id=?", (doc_id,))
                con.execute("DELETE FROM chunks_fts WHERE chunk_id IN "
                            "(SELECT id FROM chunks WHERE document_id=?)", (doc_id,))
                con.execute("UPDATE documents SET name=?, type=?, source_hash=? WHERE id=?",
                            (name, typ, digest, doc_id))
            else:
                cur = con.execute(
                    "INSERT INTO documents(docset,name,type,path,source_hash) VALUES (?,?,?,?,?)",
                    (docset_name, name, typ, path, digest))
                doc_id = cur.lastrowid
            for anchor, heading, body in chunks:
                cur = con.execute(
                    "INSERT INTO chunks(document_id,anchor,heading,body) VALUES (?,?,?,?)",
                    (doc_id, anchor, heading, body))
                con.execute(
                    "INSERT INTO chunks_fts(title,heading,body,chunk_id) VALUES (?,?,?,?)",
                    (name, heading, body, cur.lastrowid))
                chunks_seen += 1
            rendered += 1

    # Prune documents (and their chunks/fts rows, via ON DELETE CASCADE +
    # explicit fts cleanup) for docsets that vanished or pages no longer
    # present in their dsidx.
    stale = []
    for doc_id, docset, path in con.execute("SELECT id, docset, path FROM documents"):
        if docset not in seen_docsets or (docset, path) not in live_keys:
            stale.append(doc_id)
    for doc_id in stale:
        con.execute("DELETE FROM chunks_fts WHERE chunk_id IN "
                    "(SELECT id FROM chunks WHERE document_id=?)", (doc_id,))
        con.execute("DELETE FROM chunks WHERE document_id=?", (doc_id,))
        con.execute("DELETE FROM documents WHERE id=?", (doc_id,))

    con.commit()
    con.close()
    print(f"help-corpus: {docs_seen} pages scanned ({rendered} (re)chunked, "
          f"{skipped} cached, {len(stale)} pruned), {chunks_seen} chunks written -> {out}")


if __name__ == "__main__":
    main()

Read-only query interface. This is the one seam Clippy is allowed to touch —
spawned per query as a child process from Electron's main process (never an
in-process sqlite reader in the fork itself, which would blur the "Clippy
owns no documentation" ownership split), reading the corpus with
=mode=ro= so a query can never mutate the library.

#+BEGIN_SRC python :tangle all/.local/bin/dotcortex-help-query :shebang "#!/usr/bin/env python3" :tangle-mode (identity #o755)
"""Read-only query interface over the Help Corpus (help-corpus.sqlite).

Never opens the corpus for write -- Clippy consumes the Fleet Library
read-only. Designed to be spawned per-query from Electron's main process
and parsed as JSON on stdout (never in-process sqlite in the renderer/main).

Usage:
  dotcortex-help-query search "<query>" [--docset NAME] [--limit N] [--corpus PATH]
  dotcortex-help-query read <chunk-id> [--corpus PATH]
"""
import argparse, json, re, sqlite3, sys
from pathlib import Path

DEFAULT_CORPUS = Path.home() / ".local/share/dotcortex/help/help-corpus.sqlite"
STOPWORDS = frozenset("""a an and are as at be by can do does for from how i if in is it of on or
should the this to use used using was what when where which who why will with you your""".split())


def open_ro(path: Path) -> sqlite3.Connection:
    if not path.is_file():
        print(json.dumps({"error": f"corpus not found: {path}"}), file=sys.stdout)
        sys.exit(1)
    return sqlite3.connect(f"file:{path}?mode=ro", uri=True)


# FTS5 operators are upper case; a lower-case "and" is a word. Any of these means the caller
# wrote a boolean query and gets exactly what it says.
EXPLICIT_FTS = re.compile(r'\b(?:AND|OR|NOT|NEAR)\b|["():*^]')


def rows_to_dicts(rows):
    return [
        {"docset": r[0], "name": r[1], "type": r[2], "path": r[3],
         "chunk_id": r[4], "anchor": r[5], "heading": r[6], "snippet": r[7]}
        for r in rows
    ]


def cmd_search(con, query, docset, limit):
    sql = """
    SELECT d.docset, d.name, d.type, d.path, c.id, c.anchor, c.heading,
           snippet(chunks_fts, 2, '[', ']', '...', 24) AS snip,
           bm25(chunks_fts) AS score
    FROM chunks_fts
    JOIN chunks c ON c.id = chunks_fts.chunk_id
    JOIN documents d ON d.id = c.document_id
    WHERE chunks_fts MATCH ?
    """
    tail, tail_params = "", []
    if docset:
        tail += " AND d.docset = ?"
        tail_params.append(docset)
    tail += " ORDER BY score LIMIT ?"
    tail_params.append(limit)
    relax = not EXPLICIT_FTS.search(query)
    try:
        rows = con.execute(sql + tail, [query] + tail_params).fetchall()
        # Plain words are an implicit AND, so one word the corpus lacks empties the answer
        # ("chmod setgid numeric mode 2755"). Only a query with no FTS operators is relaxed;
        # an explicit AND/OR/NOT, phrase or column filter means exactly what it says.
        if rows or not relax:
            return rows_to_dicts(rows)
        raise sqlite3.OperationalError("empty implicit-AND result, relax")
    except sqlite3.OperationalError:
        # Not valid FTS5 syntax (or an empty plain-word result): a hyphenated command name parses
        # as a column filter ("no such column: help") and "why use chmod 2755?" is a syntax
        # error. Retry the same words as quoted tokens, question words dropped, requiring every
        # token first and falling back to any token; bm25 still ranks rare terms first.
        words = list(dict.fromkeys(re.findall(r"[A-Za-z0-9_]+", query)))
        tokens = [w for w in words if w.lower() not in STOPWORDS][:12] or words[:12]
        if not tokens:
            return []
        rows = []
        for joiner in (" AND ", " OR "):
            fallback = joiner.join(f'"{t}"' for t in tokens)
            rows = con.execute(sql + tail, [fallback] + tail_params).fetchall()
            if rows or len(tokens) == 1:
                break
    return rows_to_dicts(rows)


def cmd_read(con, chunk_id):
    row = con.execute("""
        SELECT d.docset, d.name, d.type, d.path, c.anchor, c.heading, c.body
        FROM chunks c JOIN documents d ON d.id = c.document_id
        WHERE c.id = ?
    """, (chunk_id,)).fetchone()
    if not row:
        return None
    return {"docset": row[0], "name": row[1], "type": row[2], "path": row[3],
            "anchor": row[4], "heading": row[5], "body": row[6]}


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--corpus", default=str(DEFAULT_CORPUS))
    sub = ap.add_subparsers(dest="verb", required=True)

    sp = sub.add_parser("search")
    sp.add_argument("query")
    sp.add_argument("--docset")
    sp.add_argument("--limit", type=int, default=8)

    rp = sub.add_parser("read")
    rp.add_argument("chunk_id", type=int)

    args = ap.parse_args()
    con = open_ro(Path(args.corpus))

    if args.verb == "search":
        result = cmd_search(con, args.query, args.docset, args.limit)
    else:
        result = cmd_read(con, args.chunk_id)
        if result is None:
            print(json.dumps({"error": f"no such chunk: {args.chunk_id}"}))
            sys.exit(1)

    print(json.dumps(result))


if __name__ == "__main__":
    main()

* Discovery driver

Walks the machine and builds every docset that applies, then links the shelf into every guest that has a Zeal. Idempotent; run any time via =loom docs:build=.

#+BEGIN_SRC bash :tangle all/.local/bin/dotcortex-docs-build :shebang "#!/usr/bin/env bash" :tangle-mode (identity #o755)
#!/usr/bin/env bash
# Build the fleet documentation library for THIS machine and link it into guests.
set -euo pipefail

DATA="${XDG_DATA_HOME:-$HOME/.local/share}"
OUT="$DATA/dotcortex/docsets"
GUESTS="$DATA/dotcortex/guests"
GEN="$HOME/.local/bin/dotcortex-docset-gen"
mkdir -p "$OUT"

# mandoc comes from the core Guix manifest; wrap ephemerally if not yet applied.
if ! command -v mandoc >/dev/null 2>&1; then
  if [ -z "${DOTCORTEX_DOCS_WRAPPED:-}" ] && command -v guix >/dev/null 2>&1; then
    exec env DOTCORTEX_DOCS_WRAPPED=1 guix shell mandoc -- "$0" "$@"
  fi
  echo "dotcortex-docs-build: mandoc unavailable and no guix to wrap with" >&2
  exit 1
fi

titleize() {  # sanctuary-redstone-9x -> Redstone 9X
  sed -e 's/^sanctuary-//' -e 's/-/ /g' -e 's/\b\(.\)/\u\1/g' -e 's/\b\([0-9][0-9]*\)x\b/\1X/g' <<<"$1"
}

# --- Lane 1: host manuals ---------------------------------------------------
host_short=$(hostname -s | sed 's/^[Tt]hink[Pp]ad-//')
host_title="$(titleize "$host_short") Manuals"
host_kw=$(tr '[:upper:]' '[:lower:]' <<<"$host_short")
# A MANPATH exported by the shell (Guix profiles) hides the system pages: `manpath` then lists only
# the profile, and the library silently lacks chmod(1) and every other /usr/share/man page. Take
# the machine's own default roots as well, and keep only directories that exist.
mapfile -t host_roots < <({ env -u MANPATH manpath -q; manpath -q; } 2>/dev/null | tr ':' '\n' \
  | awk 'NF && !seen[$0]++' | while IFS= read -r root; do [ -d "$root" ] && printf '%s\n' "$root"; done)
if [ "${#host_roots[@]}" -gt 0 ]; then
  "$GEN" man --name "$host_title" --keyword "$host_kw" \
    --out "$OUT/${host_title// /-}.docset" "${host_roots[@]}"
fi

# --- Lane 2: sanctuary manuals (declared profiles, current generations) -----
# Guest homes all symlink the shared Package Commons, so each guest's profile
# set comes from the guest-profiles map (fallback: core, desktop-common, and
# the guest's same-named profile).
PROFMAP="$DATA/dotcortex/manifests/docsets/guest-profiles.ssv"
if [ -d "$GUESTS" ]; then
  for home in "$GUESTS"/*/home; do
    [ -d "$home" ] || continue
    gid=$(basename "$(dirname "$home")")
    declared=""
    title_over=""
    if [ -f "$PROFMAP" ]; then
      declared=$(awk -v g="$gid" '$1==g {print $2}' "$PROFMAP")
      title_over=$(awk -v g="$gid" '$1==g {$1=""; $2=""; sub(/^[ \t]+/, ""); print}' "$PROFMAP")
    fi
    [ "$declared" = '""' ] && declared=""
    [ -n "$declared" ] || declared="core,desktop-common,$gid"
    roots=()
    for n in ${declared//,/ }; do
      m="$home/.guix-extra-profiles/$n/$n/share/man"   # profile/profile = CURRENT generation
      [ -d "$m" ] && roots+=("$m")
    done
    [ "${#roots[@]}" -gt 0 ] || continue
    gtitle="${title_over:-$(titleize "$gid")} Manuals"
    gkw=$(sed 's/^sanctuary-//' <<<"$gid")
    "$GEN" man --name "$gtitle" --keyword "$gkw" \
      --out "$OUT/${gtitle// /-}.docset" "${roots[@]}"
  done
fi

# --- Lane 2b: DotCortex Org documentation (present on every DotCortex host) -
if [ -d "$HOME/DotCortex" ]; then
  "$GEN" org --name "DotCortex Docs" --keyword dotcortex \
    --out "$OUT/DotCortex-Docs.docset" --base "$HOME/DotCortex" "$HOME/DotCortex"
fi

# --- Link the shelf into every guest that has a Zeal ------------------------
# Also link the global HelmCortex docset (built on X230 local disk) into guest
# Zeal shelves when ~/HelmCortex is available; it stays out of $OUT so the
# per-machine FTS5 corpus and the global HelmCortex corpus never blend.
HC_DOCSET="$HOME/HelmCortex/ROOTS/HelmRoot/help-corpus/build/shelf/HelmCortex-Docs.docset"
if [ -d "$GUESTS" ]; then
  for zdir in "$GUESTS"/*/home/.local/share/Zeal/Zeal/docsets; do
    [ -d "$zdir" ] || continue
    for ds in "$OUT"/*.docset; do
      [ -d "$ds" ] && ln -sfn "$ds" "$zdir/$(basename "$ds")"
    done
    if [ -d "$HC_DOCSET" ]; then
      ln -sfn "$HC_DOCSET" "$zdir/$(basename "$HC_DOCSET")"
    fi
    # prune dangling symlinks from renamed/removed docsets
    find "$zdir" -maxdepth 1 -xtype l -delete
  done
fi

# --- Lane 3: help corpus (FTS5, consumes the shelf just rendered above) -----
# Host-local: Clippy runs as a host-side Electron process (redstone-9x-clippy
# bridges it in via redstone-9x-host-gtk), so it reads this file directly --
# no /run/host bridging needed, unlike the binary launch path itself.
CORPUS_GEN="$HOME/.local/bin/dotcortex-help-corpus-build"
if [ -x "$CORPUS_GEN" ]; then
  "$CORPUS_GEN" --docsets-dir "$OUT" --out "$DATA/dotcortex/help/help-corpus.sqlite"
fi

echo "docs-build: shelf at $OUT"
