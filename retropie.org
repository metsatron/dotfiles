* Purpose

X230 already runs RetroPie bare-metal against =~/RetroPie= (ROMs, BIOS, and Lutris/EmulationStation
state) — that directory is already declared a shared host resource. =vm-homes-init= provides the
generic guest-home projection; the Redstone and RetroPie launchers replace that guest link with a
direct container bind of the resolved NFS subtree so it remains valid across autofs restarts. This file adds
=sanctuary-retropie=: a portable Distrobox sanctuary so the same ROM/BIOS library and
EmulationStation/RetroArch stack can run from any machine, not just X230's bare-metal install,
without duplicating a single ROM or BIOS file.

Ruled 2026-07-03: the emulation substrate goes through Guix, not a Debian-family distrobox
base — the same one-store-many-rooms substrate every other sanctuary in =distrobox.org= uses.
=sanctuary-retropie= is a sixth Guix-shared-store sanctuary, not a bespoke apt rootfs. RetroPie-Setup
is no longer a binary source at all; its role shrinks to nothing this file needs — the profile in
=guix.org= (=room-retropie=) *is* the manifest. This file's job is the sanctuary itself: profile
apply, ES config/theme projection, health, and treating X230's existing native install as a managed,
read-only-observed endpoint rather than something reinstalled here.

* Ports launch lane

The product surface here is the existing =~/RetroPie/roms/ports/*.sh= launcher set. The scripts
remain byte-untouched. The runcommand shim below reproduces the X230 runcommand signature while
resolving only engines declared in the Guix rooms; an unprovisioned engine fails loudly with its
X230 command instead of trying =/opt/retropie= or pretending that a launch succeeded.

The menu generator reads only =*.sh= matches at depth one and depth two below the ports root. It
does not index game content, inspect assets, hash files, or walk any other path. It classifies each
launcher once, caches the rendered menu under the guest's XDG cache directory, and uses only the
ports root plus its immediate directory mtimes for cheap staleness detection. IceWM calls it on
menu expansion; FVWM95 reads its generated menu definitions at startup.

** The collection's own law: links stay INSIDE the tree (sealed 2026-07-14)

Mètsàtron's =~/RetroPie= collection is a symlink farm, and it is a good design: one physical copy
of each asset, fanned out by relative links so a mod is selected by *which directory the IWAD sits
in*.  53 Doom collections and 17 distinct MP3 soundtracks fit in 11G because of it — a WOLF variant
costs ~100K.

But two link styles coexisted, and only one survived a machine migration:

: WOLF/adrian.mp3       -> ../addons/tc/wolfendoom/music/adrian.mp3   RELATIVE, in-tree   SURVIVED
: DOOM-BRUTAL/e2m3.mp3  -> /home/metsatron/Music/doom_playlist/...    ABSOLUTE, out-of-tree  DIED

=~/Music/doom_playlist= moved to a ZFS pool that later went offline, and 157 links died with it —
including his own darksynth arrangements.  Nothing was actually lost: a second copy of the tracks
was already inside the tree at =ports/doom/addons/bgm/doom_playlist/=, because *that* path travelled
with the collection and got backed up with it.  Only the link path pointed at a ghost.

**Any asset a collection depends on must live inside the RetroPie tree and be referenced by a
RELATIVE link.**  An absolute path outside the tree is a time bomb: it breaks on any move, any
unmounted pool, any new machine — and it breaks silently, because a dangling symlink still lists
fine.  When adding music, mods or BIOS to a collection, put the file under =ports/<game>/addons/=
and link to it with =realpath --relative-to=.

Related trap: the tracks were also *renamed* (yt-dlp suffixes like =(128kbit_AAC)= stripped, artist
prefixes added), so an exact-basename search reported them missing when they were sitting right
there.  Fuzzy-match on a normalised name before concluding an asset is gone — but read the matches,
because a naive containment rule will happily match a track to =d.mp3=.

* Prerequisites

1. =loom guix:sanctuary-apply= (or =make guix-room-retropie= directly) — builds the
   =room-retropie= Guix profile declared in =guix.org=.
2. =sanctuary-retropie= uncommented in =linux/.config/virtualisation/guests.conf= (done).
3. =vm-homes-init= (guests.org) — creates the guest home and projects the shared profiles/resources.
4. =distrobox-sanctuaries-create sanctuary-retropie= (distrobox.org) — creates only the missing
   =sanctuary-retropie= container; existing containers are always skipped.

* Health

Checks the Guix profile is built, its binaries resolve, the =~/RetroPie= data mount (BIOS/ROMs/
theme — always a mounted directory, never packaged, never in git) is present, and reports the
X230 native install's own state as a read-only observed endpoint rather than something this
script installs or touches.

#+BEGIN_SRC bash :tangle linux/.local/bin/retropie-health :shebang "#!/usr/bin/env bash"
set -euo pipefail

PROFILE="${HOME}/.guix-extra-profiles/room-retropie/room-retropie"

echo "== room-retropie Guix profile =="
if [[ -d "${PROFILE}" ]]; then
  echo "profile = built (${PROFILE})"
  for bin in retroarch mame mednafen emulationstation px68k_libretro.so; do
    if [[ -e "${PROFILE}/bin/${bin}" || -e "${PROFILE}/lib/libretro/${bin}" ]]; then
      echo "  ${bin} = present"
    else
      echo "  ${bin} = MISSING"
    fi
  done
else
  echo "profile = MISSING — run: make guix-room-retropie"
fi

echo ""
echo "== RetroPie data mount =="
if [[ -d "${HOME}/RetroPie" ]]; then
  echo "~/RetroPie = present"
else
  echo "~/RetroPie = MISSING"
fi

echo ""
echo "== sanctuary-retropie container =="
if command -v distrobox >/dev/null 2>&1 && distrobox list --no-color 2>/dev/null \
  | awk -F '|' '{gsub(/^[ \t]+|[ \t]+$/, "", $2); print $2}' | grep -qx "sanctuary-retropie"; then
  echo "sanctuary-retropie = created"
else
  echo "sanctuary-retropie = not created — run distrobox-sanctuaries-create"
fi

echo ""
echo "== X230 native RetroPie install (read-only observed endpoint) =="
if [[ -x "${HOME}/RetroPie-Setup/retropie_packages.sh" ]]; then
  echo "RetroPie-Setup = present"
  ( cd "${HOME}/RetroPie-Setup" && git log -1 --format='  version: %h %cd' --date=short 2>/dev/null ) || true
else
  echo "RetroPie-Setup = not present on this machine (expected everywhere except X230)"
fi
#+END_SRC

* Sanctuary launcher

Plugs into the existing =sanctuary-enter= fzf picker in =distrobox.org= the same way every
other sanctuary does — =sanctuary-retropie= is already in its =SANCTUARY_DESKTOPS= map.
Projects the =es-theme-metsatron= submodule's =built/= variant into the sanctuary's
EmulationStation config at launch time, the same copy-not-symlink pattern
=sanctuary-redstone-9x-launch= uses for its desktop config (the host repo path isn't visible
inside the container).

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-retropie-launch :shebang "#!/usr/bin/env bash"
# Launch sanctuary-retropie: Xephyr :94 + EmulationStation inside the Guix-store sanctuary.
# Prerequisites:
#   make guix-room-retropie
#   distrobox-sanctuaries-create
#   vm-homes-init
set -euo pipefail

DISPLAY_NUM=":94"
SANCTUARY="sanctuary-retropie"
GUESTS_DIR="${XDG_DATA_HOME:-$HOME/.local/share}/dotcortex/guests"
GUEST_HOME="${GUESTS_DIR}/${SANCTUARY}/home"
GUIX_PROFILES="${HOME}/.guix-extra-profiles"
THEME_SRC="${HOME}/DotCortex/linux/.emulationstation-themes/metsatron/built"
CFG_SRC="${HOME}/DotCortex/linux/.emulationstation-config/es_systems.cfg"
RETROPIE_HOST_ROOT="${HOME}/RetroPie"
RETROPIE_CONTAINER_ROOT="/run/dotcortex/retropie"

# Preflight: verify the room-retropie profile is built before launching.
if [[ ! -f "${GUIX_PROFILES}/room-retropie/room-retropie/etc/profile" ]]; then
  echo "${SANCTUARY}: ERROR — room-retropie Guix profile not built"
  echo "  Build it with: make guix-room-retropie"
  exit 1
fi

# Follow the host ~/RetroPie link before Podman starts. This stat triggers the
# direct autofs mount and fails before Xephyr opens if the NFS-backed library is
# unavailable. The container declaration binds the resolved subtree directly
# at RETROPIE_CONTAINER_ROOT; no nested-mount propagation is required.
HOST_PORTS_DIR="${RETROPIE_HOST_ROOT}/roms/ports"
if ! stat -L -- "${HOST_PORTS_DIR}" >/dev/null 2>&1; then
  echo "${SANCTUARY}: ERROR — RetroPie tree unavailable on the host" >&2
  echo "  Expected a readable ports directory at: ${HOST_PORTS_DIR}" >&2
  echo "  The automount did not become available; container start was not attempted." >&2
  exit 1
fi

if ! distrobox list --no-color 2>/dev/null | awk -F '|' '{gsub(/^[ \t]+|[ \t]+$/, "", $2); print $2}' | grep -qx "${SANCTUARY}"; then
  echo "${SANCTUARY}: not created — run distrobox-sanctuaries-create first" >&2
  exit 1
fi

# Ensure the guest home and Guix profile projection exist. vm-homes-init may
# restore its generic ~/RetroPie host link, so install the sanctuary-specific
# link to the direct container bind immediately afterwards on every launch.
if [[ ! -d "${GUEST_HOME}" || ! -e "${GUEST_HOME}/.guix-extra-profiles" ]]; then
  if ! vm-homes-init >/dev/null; then
    echo "${SANCTUARY}: ERROR — vm-homes-init failed" >&2
    exit 1
  fi
fi
if [[ ! -e "${GUEST_HOME}/.guix-extra-profiles" ]]; then
  echo "${SANCTUARY}: ERROR — Guix profile projection missing from guest home" >&2
  exit 1
fi
if [[ -e "${GUEST_HOME}/RetroPie" && ! -L "${GUEST_HOME}/RetroPie" ]]; then
  echo "${SANCTUARY}: ERROR — refusing to replace non-symlink guest path: ${GUEST_HOME}/RetroPie" >&2
  exit 1
fi
ln -sfnT "${RETROPIE_CONTAINER_ROOT}" "${GUEST_HOME}/RetroPie"

sanctuary-retropie-bind-ensure "${SANCTUARY}" "${RETROPIE_CONTAINER_ROOT}"

# Project the theme (copy, not symlink: the host repo path isn't visible inside the container).
if [[ -d "${THEME_SRC}" ]]; then
  mkdir -p "${GUEST_HOME}/.emulationstation/themes"
  rm -rf "${GUEST_HOME}/.emulationstation/themes/metsatron"
  cp -a "${THEME_SRC}" "${GUEST_HOME}/.emulationstation/themes/metsatron"
fi

# Project the EmulationStation systems config. Copied, not symlinked: the
# DotCortex repo path isn't visible inside the container, and ES writes sibling
# files (es_settings.cfg, gamelists) next to it. Refreshed every launch so a
# re-tangle of retropie.org lands without manual steps. Paths inside follow the
# RetroPie convention (~/RetroPie/roms/<system>) and resolve via the projected
# ~/RetroPie link above.
if [[ -f "${CFG_SRC}" ]]; then
  mkdir -p "${GUEST_HOME}/.emulationstation"
  cp "${CFG_SRC}" "${GUEST_HOME}/.emulationstation/es_systems.cfg"
fi

# Seed a minimal RetroArch config pointing the system (BIOS) directory at the
# RetroPie-convention ~/RetroPie/BIOS so BIOS-dependent cores (PSX, X68000,
# Dreamcast, FDS) find firmware the RetroPie way. Inside the container the
# guest-home RetroPie link resolves to the dedicated direct bind. Seeded only
# when absent, so RetroArch's own written-back settings survive across runs.
RA_CFG="${GUEST_HOME}/.config/retroarch/retroarch.cfg"
if [[ ! -f "${RA_CFG}" ]]; then
  mkdir -p "${GUEST_HOME}/.config/retroarch"
  printf 'system_directory = "%s/RetroPie/BIOS"\n' "${GUEST_HOME}" > "${RA_CFG}"
fi

Xephyr "${DISPLAY_NUM}" -fullscreen -br -ac -no-host-grab &
XEPHYR_PID=$!
trap 'kill "${XEPHYR_PID}" 2>/dev/null || true' EXIT

for _ in $(seq 1 50); do
  [[ -e "/tmp/.X11-unix/X${DISPLAY_NUM#:}" ]] && break
  sleep 0.1
done

DISPLAY="${DISPLAY_NUM}" sanctuary-exec "${SANCTUARY}" sh -c "
  GUIX_PROFILE=${GUIX_PROFILES}/desktop-common/desktop-common
  . \${GUIX_PROFILE}/etc/profile
  GUIX_PROFILE=${GUIX_PROFILES}/room-retropie/room-retropie
  . \${GUIX_PROFILE}/etc/profile
  exec emulationstation
"

wait "${XEPHYR_PID}" 2>/dev/null || true
#+END_SRC

* EmulationStation systems (libretro first cut)

The systems configuration EmulationStation loads to know what consoles exist,
where their ROMs live, and how to launch them.  Authored here rather than
generated by RetroPie-Setup (which we don't run — the =room-retropie= Guix
profile *is* the emulator inventory, ruled 2026-07-03).

Fully RetroPie-convention: every =<path>= is =~/RetroPie/roms/<system>= and
BIOS resolves from =~/RetroPie/BIOS=, exactly as X230's bare-metal RetroPie
reads this same shared library. Inside the sanctuary =~= expands to the guest
home, where the launcher points =~/RetroPie= at the direct container bind and
=vm-homes-init= projects =~/.guix-extra-profiles= from the host; so both the ROM
paths and the =~=-relative core paths resolve with zero machine-specific
absolute paths baked into this file.

This is the *libretro first cut*: the systems that have both a core in
=room-retropie= and populated ROMs.  Launch is =retroarch -L <core> %ROM%=
against the profile's cores.  Deferred to a later pass (each needs work of its
own): systems with ROMs but no core yet (Game Boy/GBC, NDS, PC Engine, Atari
2600 — need cores added to =guix.org=), and the standalone emulators
(=mame=, =np2kai=, =Tsugaru_CUI= — each with its own CLI to wire).

Data-tree note: the shared library's Dreamcast ROMs live under a legacy
=roms/Reicast/= directory; the RetroPie-standard path is =roms/dreamcast/=.
This file uses the standard path — reconcile the shared tree (move or symlink
=Reicast= → =dreamcast=) to surface those 81 titles.

# Replace host-side RetroPie roots only when the original path is unavailable
# and the same relative path exists below the sanctuary bind. The token walk
# also handles launcher strings such as -j/path and --data=/path without
# changing the caller's argument boundaries.
translate_argument() {
  local value="$1"
  local host_root prefix remainder before after path_tail candidate translated

  for host_root in "${RETROPIE_HOST_ROOT}" "${RETROPIE_HOST_RESOLVED_ROOT}"; do
    [[ -n "${host_root}" ]] || continue

    # Preserve paths containing whitespace when the complete argument itself
    # is the path (the normal ROM case).
    if [[ "${value}" == "${host_root}" || "${value}" == "${host_root}/"* ]]; then
      path_tail="${value#"${host_root}"}"
      translated="${RETROPIE_CONTAINER_ROOT}${path_tail}"
      if [[ ! -e "${value}" ]]; then
        TRANSLATED_PATH_CANDIDATE="${translated}"
      fi
      if [[ ! -e "${value}" && -e "${translated}" ]]; then
        value="${translated}"
      fi
      continue
    fi

    prefix=''
    remainder="${value}"
    while [[ "${remainder}" == *"${host_root}"* ]]; do
      before="${remainder%%"${host_root}"*}"
      after="${remainder#*"${host_root}"}"
      case "${after}" in
        ''|[[:space:]]*|/*)
          ;;
        *)
          prefix+="${before}${host_root}"
          remainder="${after}"
          continue
          ;;
      esac

      path_tail="${after%%[[:space:]]*}"
      candidate="${host_root}${path_tail}"
      translated="${RETROPIE_CONTAINER_ROOT}${path_tail}"
      prefix+="${before}"
      if [[ ! -e "${candidate}" && -e "${translated}" ]]; then
        prefix+="${translated}"
      else
        prefix+="${host_root}${path_tail}"
      fi
      remainder="${after#"${path_tail}"}"
    done
    value="${prefix}${remainder}"
  done

  TRANSLATED_ARGUMENT="${value}"
}

guard_rom_path() {
  # duke3d and ionfury use ROM as a whitespace-separated option string, so
  # only guard a non-empty absolute path. Unsupported engines still reach
  # not_provisioned before this check, preserving that intentional behaviour.
  [[ -n "${ROM}" && "${ROM}" == /* && "${ROM}" != *[[:space:]]* ]] || return 0
  if [[ ! -e "${ROM}" ]]; then
    printf 'runcommand-shim: refusing to invoke engine: ROM does not exist\n' >&2
    printf '  requested: %s\n' "${REQUESTED_ROM}" >&2
    printf '  translated: %s\n' "${TRANSLATED_ROM_PATH:-${ROM}}" >&2
    exit 1
  fi
}

# --- dsda-doom: MIDI soundfont -------------------------------------------------
# dsda links fluidsynth but ships no soundfont.  Seed its config ONCE with
# FluidR3 from the room profile.  Idempotent, and never overwrites a value the
# user has already set — dsda reads its config at startup and does not hot-reload,
# so a rewrite would silently clobber tuning done in the in-game menu.
# Mètsàtron keeps a CURATED soundfont collection in ~/RetroPie/BIOS — 26 of them,
# including a purpose-built Doom.sf2 and several Roland SC-55 recreations (the SC-55
# is the hardware Bobby Prince actually composed the Doom MIDIs on, so it is the
# authentic voice).  Use HIS collection.  The Guix fluid-3 package is only a fallback
# for a machine that has no BIOS dir — never prefer it over what he curated.
#
# Selection, in order:
#   1. $DSDA_SOUNDFONT — an absolute path, or a bare filename inside the BIOS dir
#   2. ~/.config/dotcortex/dsda-soundfont — one line, same forms (set by `doom-soundfont`)
#   3. the preference list below, first that exists
#   4. Guix fluid-3, if nothing else is present
resolve_soundfont() {
  local bios pick line
  bios="${RETROPIE_BIOS_DIR:-${HOME}/RetroPie/BIOS}"

  _sf_try() {  # absolute path, or a name inside BIOS
    local c="$1"
    [[ -n "${c}" ]] || return 1
    if [[ "${c}" == /* && -r "${c}" ]]; then printf '%s' "${c}"; return 0; fi
    if [[ -r "${bios}/${c}" ]]; then printf '%s' "${bios}/${c}"; return 0; fi
    return 1
  }

  if pick="$(_sf_try "${DSDA_SOUNDFONT:-}")"; then printf '%s' "${pick}"; return 0; fi

  # A global choice pinned with `doom-soundfont set` overrides everything below.
  line="$(head -n1 "${XDG_CONFIG_HOME:-${HOME}/.config}/dotcortex/dsda-soundfont" 2>/dev/null || true)"
  if pick="$(_sf_try "${line}")"; then printf '%s' "${pick}"; return 0; fi

  # --- otherwise, pick by what is being played --------------------------------
  # Mètsàtron's ruling, after A/B-ing them against lr-prboom (which has no soundfont
  # at all — the difference is not subtle):
  #
  #   CANON  (id's own IWADs: Doom, Doom II, TNT, Plutonia)  -> Roland SC-55.
  #          The SC-55 is the hardware Bobby Prince composed these MIDIs ON, so it
  #          is not nostalgia — it is the intended voice.
  #   CUSTOM (megawads, TCs, mods — everything in a mod dir) -> Arachno.
  #          "Gives them a bit of extra oomph." Fuller, more modern; suits music
  #          that was never written for an SC-55 in the first place.
  #
  # Each side is overridable: `doom-soundfont canon <name>` / `doom-soundfont custom <name>`.
  local canon_default='SC-55 Trevor James.sf2'
  local custom_default='Arachno SoundFont - Version 1.0.sf2'
  local cfgdir="${XDG_CONFIG_HOME:-${HOME}/.config}/dotcortex"
  local c
  c="$(head -n1 "${cfgdir}/dsda-soundfont-canon" 2>/dev/null || true)";  [[ -n "${c}" ]] && canon_default="${c}"
  c="$(head -n1 "${cfgdir}/dsda-soundfont-custom" 2>/dev/null || true)"; [[ -n "${c}" ]] && custom_default="${c}"

  # Canon iff the IWAD sits in a BASE dir (ports/doom, ports/doom2) — the same depth
  # rule add_mod_files uses.  A mod dir means a custom collection.
  local is_canon=1 iwad_dir ports_root
  if [[ -n "${ROM:-}" ]]; then
    iwad_dir="$(cd -- "$(dirname -- "${ROM}")" 2>/dev/null && pwd -P)" || iwad_dir=''
    ports_root="$(cd -- "${RETROPIE_PORTS_DIR:-${HOME}/RetroPie/roms/ports}" 2>/dev/null && pwd -P)" || ports_root=''
    if [[ -n "${iwad_dir}" && -n "${ports_root}" ]]; then
      [[ "$(dirname -- "${iwad_dir}")" == "${ports_root}" ]] || is_canon=0
    fi
  fi

  local candidate
  local -a order
  if (( is_canon )); then
    order=("${canon_default}" 'SC-55 Trevor James.sf2' 'SC-55 Patch93.sf2' 'Roland_SC-88.sf2' 'Doom.sf2' "${custom_default}" 'FluidR3_GM.sf2')
  else
    order=("${custom_default}" 'Arachno SoundFont - Version 1.0.sf2' 'Doom.sf2' "${canon_default}" 'FluidR3_GM.sf2')
  fi
  for candidate in "${order[@]}"; do
    if pick="$(_sf_try "${candidate}")"; then printf '%s' "${pick}"; return 0; fi
  done

  # Last resort: whatever the room profile ships (Guix fluid-3).
  if [[ -r "${ROOM_PROFILE}/share/soundfonts/FluidR3Mono_GM.sf3" ]]; then
    printf '%s' "${ROOM_PROFILE}/share/soundfonts/FluidR3Mono_GM.sf3"
    return 0
  fi
  return 1
}

ensure_dsda_soundfont() {
  local sf cfg dir tmp
  sf="$(resolve_soundfont)" || return 0   # none available — leave dsda alone
  [[ -r "${sf}" ]] || return 0
  dir="${XDG_DATA_HOME:-${HOME}/.local/share}/dsda-doom"
  cfg="${dir}/dsda-doom.cfg"
  mkdir -p "${dir}" || return 0

  # dsda REWRITES its entire config on exit, so an appended line does not survive a
  # single run — it comes back as `snd_soundfont ""`, dsda's own empty default, and
  # the music is silent.  A "set it only if absent" guard is therefore useless: the
  # key is always present, always empty.
  #
  # So the SHIM owns these two keys and rewrites them on every launch.  That is
  # deliberate: `doom-soundfont` is how the soundfont is chosen (dsda reads the
  # config at startup and does not hot-reload), and A/B testing has to actually take
  # effect.  Every other key in the file is left exactly as dsda wrote it.
  if [[ ! -f "${cfg}" ]]; then
    printf 'snd_midiplayer                "fluidsynth"\nsnd_soundfont                 "%s"\n' "${sf}" > "${cfg}"
    return 0
  fi
  tmp="${cfg}.tmp.$$"
  awk -v sf="${sf}" '
    /^snd_soundfont/  { printf "snd_soundfont                 \"%s\"\n", sf; seen_sf=1; next }
    /^snd_midiplayer/ { print  "snd_midiplayer                \"fluidsynth\"";  seen_mp=1; next }
    { print }
    END {
      if (!seen_sf) printf "snd_soundfont                 \"%s\"\n", sf
      if (!seen_mp) print  "snd_midiplayer                \"fluidsynth\""
    }
  ' "${cfg}" > "${tmp}" 2>/dev/null && mv -f "${tmp}" "${cfg}" || rm -f "${tmp}"
  return 0
}

# --- crispy-doom: loose-file music packs ---------------------------------------
# Crispy (via chocolate's lineage) is the ONLY maintained port that keeps
# lr-prboom's loose-file music substitution — the reason 17 of the collections
# exist at all.  It reads music_pack_path from its own config; there is no CLI
# flag.  Seed it, once, at the collection's own music directory.
#
# HONEST LIMIT: chocolate/crispy upstream document MP3 as UNSUPPORTED for music
# packs ("Unrecognized audio format") even when libmpg123 is linked — OGG/FLAC are
# the supported formats.  The collection's tracks are MP3.  So this key gives a
# maintained Doom engine with correct sprites and vanilla-accurate play, but the
# custom soundtracks may NOT substitute until the tracks are transcoded to OGG.
# That is why the legacy `doom` (lr-prboom) lane stays: it is the only thing that
# plays these MP3s as they stand.  Do not claim crispy plays them until it is
# heard doing so.
# Crispy substitutes music ONLY from its own music-packs directory.
#
# `music_pack_path` pointing at the collection is IGNORED — the wiki says otherwise and
# the wiki is wrong.  Proven 2026-07-14: with the pack under the collection and
# music_pack_path set, crispy never opened a single .ogg (a deliberately corrupted one
# drew no complaint at all).  Move the very same files into
# ~/.local/share/crispy-doom/music-packs/ and it immediately opens D_E1M5.ogg.
#
# So point crispy's own dir at the collection's pack, by symlink — the RetroPie tree is
# a read-only bind in the sanctuary, and copying 69MB per launch would be absurd.
# Only OUR symlinks are cleared; a real file a human dropped in there is left alone.
ensure_crispy_music_pack() {
  local pack dir f
  pack="$1"
  [[ -d "${pack}" ]] || return 0
  dir="${XDG_DATA_HOME:-${HOME}/.local/share}/crispy-doom/music-packs"
  mkdir -p "${dir}" || return 0

  # Clear the previous collection's links (symlinks only — never a real file).
  for f in "${dir}"/*.ogg "${dir}"/*.flac "${dir}"/*.cfg; do
    [[ -L "${f}" ]] && rm -f "${f}"
  done

  # Link this collection's pack in.  The .cfg is the SHA1 substitution manifest that
  # doom-musicpack generates with crispy's own -dumpsubstconfig; without it crispy has
  # nothing to match the MIDI lumps against and silently plays the WAD's own music.
  for f in "${pack}"/*.ogg "${pack}"/*.flac "${pack}"/*.cfg; do
    [[ -e "${f}" ]] && ln -sfn "${f}" "${dir}/$(basename -- "${f}")"
  done
  return 0
}

# --- shared: replicate the collection's prboom convention explicitly ------------
# Every mod dir is a symlink farm: the shared IWAD (DOOM.WAD/DOOM2.WAD -> ../), the
# mod's own wads, and prboom.wad, all beside each other.  lr-prboom auto-loads
# whatever sits next to the IWAD — that is how the mod is chosen, BY DIRECTORY.
# dsda and crispy do NOT: given only -iwad they play the base game and ignore the
# mod IN SILENCE (verified: -iwad EVITERNITY/DOOM2.WAD prints "Playing: DOOM 2:
# Hell on Earth" and never touches eviternity.wad).  So discover the siblings.
#
# Scoped by DIRECTORY DEPTH, not by WAD magic.  Base dirs (ports/doom, ports/doom2)
# hold SEVERAL IWADs side by side, so blind discovery there would stack Freedoom on
# top of Doom; mod dirs are one level deeper.  Magic filtering looks principled and
# is WRONG — HacX ships HACX.WAD with IWAD magic yet loads fine via -file, and
# filtering it silently dropped the whole conversion.
#
# -file and -deh take LISTS.  Repeating either flag RESETS it, keeping only the last
# entry — `-file CHEX.WAD -file CQHDMUS.WAD` loaded the music and silently dropped
# Chex Quest's conversion.  Emit each flag once, with every path.
#
# STILL NOT SAFE TO TRUST BLINDLY: load order matters for some mods, others want an
# explicit -complevel.  Promotion of a collection to a new lane is MANUAL.
# `dsda-wad-report` prints what the engine actually loaded, so a silent misload
# cannot hide behind a clean exit.
add_mod_files() {
  local _iwad_dir _ports_root _parent _iwad_base _pwad _deh
  local -a _pwads=() _dehs=()
  [[ -n "${ROM}" ]] || return 0
  _iwad_dir="$(cd -- "$(dirname -- "${ROM}")" 2>/dev/null && pwd -P)" || return 0
  _ports_root="$(cd -- "${RETROPIE_PORTS_DIR:-${HOME}/RetroPie/roms/ports}" 2>/dev/null && pwd -P)" || return 0
  _parent="$(dirname -- "${_iwad_dir}")"
  # A base dir is a DIRECT child of the ports root; a mod dir is deeper.
  if [[ "${_parent}" == "${_ports_root}" ]]; then
    return 0
  fi

  _iwad_base="$(basename -- "${ROM}")"
  while IFS= read -r _pwad; do
    [[ -n "${_pwad}" ]] && _pwads+=("${_pwad}")
  done < <(
    find "${_iwad_dir}" -maxdepth 1 \( -type f -o -type l \) 2>/dev/null \
      | grep -iE '\.wad$' \
      | grep -viF "/${_iwad_base}" \
      | grep -viE '/prboom\.wad$' \
      | sort
  )
  if (( ${#_pwads[@]} )); then
    command+=(-file "${_pwads[@]}")
  fi

  # DeHackEd patches.  lr-prboom picks a .deh up implicitly from the IWAD's dir;
  # dsda and crispy need -deh.  Without it a collection loads its maps and silently
  # keeps vanilla monster/weapon behaviour — PSX Doom ships PSXDoom.deh precisely to
  # change those.
  while IFS= read -r _deh; do
    [[ -n "${_deh}" ]] && _dehs+=("${_deh}")
  done < <(
    find "${_iwad_dir}" -maxdepth 1 \( -type f -o -type l \) 2>/dev/null \
      | grep -iE '\.(deh|bex)$' \
      | sort
  )
  if (( ${#_dehs[@]} )); then
    command+=(-deh "${_dehs[@]}")
  fi

  # MUST end 0.  Under `set -e`, a trailing `(( ... )) && cmd` returns 1 when the
  # array is empty, the function returns 1, and the CALL then aborts the whole shim
  # — silently, with no output at all.  EVITERNITY has no .deh, and that one line
  # killed every mod launch on both new lanes.  Never end this function on a test.
  return 0
}

command=()
case "${SYSTEM}" in
  doom)
    # LEGACY LANE — pinned lr-prboom, deliberately unchanged.  Stock RetroPie on a
    # Pi/Wii/handheld only knows the `doom` key, so scripts that call it stay
    # portable to those builds.  The core is discontinued upstream (PrBoom 2.5,
    # dead since ~2024) and drops the weapon sprite intermittently — that is why
    # doom-dsda exists.  Do not "fix" this branch by pointing it at dsda-doom:
    # its whole job is to keep old collections and old savegames working.
    CORE="${ROOM_PROFILE}/lib/libretro/prboom_libretro.so"
    [[ -x "${ROOM_PROFILE}/bin/retroarch" && -f "${CORE}" ]] || \
      [[ "${RUNCOMMAND_SHIM_DRYRUN:-0}" == 1 ]] || not_provisioned "${SYSTEM}"
    command=("${ROOM_PROFILE}/bin/retroarch" -L "${CORE}" --config "${RETROARCH_CONFIG}" "${ROM}")
    ;;
  doom-dsda)
    # MAINTAINED LANE — dsda-doom (Guix main, rung 1), the active prboom+ successor.
    # Not a libretro core: it runs standalone, so no RetroArch wrapper.  WAD and
    # savegame compatibility is NOT guaranteed against the legacy lane — promotion
    # of a collection from `doom` to `doom-dsda` is a manual, per-collection call.
    ENGINE="${ROOM_PROFILE}/bin/dsda-doom"
    [[ -x "${ENGINE}" ]] || \
      [[ "${RUNCOMMAND_SHIM_DRYRUN:-0}" == 1 ]] || not_provisioned "${SYSTEM}"
    # dsda-doom resolves config and savegames relative to its working directory.
    # The RetroPie tree is a read-only bind in the sanctuary, so run from the
    # guest home instead of next to the IWAD.
    cd -- "${HOME}"
    # MIDI: dsda links fluidsynth but ships NO soundfont, so out of the box its
    # music is silent or awful.  Point it at FluidR3 from the profile (fluid-3 in
    # room-retropie).  Use the PROFILE path — a /gnu/store path changes on every
    # rebuild.  Written into dsda's own config once; it is read at startup and does
    # not hot-reload, so we never rewrite a config the user may have tuned.
    ensure_dsda_soundfont
    command=("${ENGINE}" -iwad "${ROM}")
    #
    # Replicate the collection's prboom convention EXPLICITLY.  Every mod dir is a
    # symlink farm: the shared IWAD (DOOM.WAD/DOOM2.WAD -> ../), the mod's PWADs,
    # and prboom.wad, all beside each other.  lr-prboom auto-loads whatever sits
    # next to the IWAD, which is how the mod gets selected — by directory.
    # dsda-doom does NOT do this: given only -iwad it loads the base game and
    # SILENTLY ignores the mod (verified 2026-07-14: -iwad EVITERNITY/DOOM2.WAD
    # prints "Playing: DOOM 2: Hell on Earth" and never touches eviternity.wad).
    # So discover the siblings and pass them with -file.
    #
    # Excluded: prboom.wad (that engine's own resource file, meaningless to dsda)
    # and the IWAD itself.  Sorted for a deterministic, reproducible load order.
    #
    # Discovery is scoped by DIRECTORY DEPTH, and the distinction is load-bearing.
    #
    #   BASE dirs — ports/doom, ports/doom2 — hold several IWADs side by side
    #   (doom1.wad, DOOM.WAD, freedoom1.wad, freedoom2.wad).  A plain Doom.sh
    #   launch points at one of them, and its siblings are OTHER GAMES.  Never
    #   auto-load there: it would stack Freedoom on top of Doom.
    #
    #   MOD dirs — ports/doom2/EVITERNITY, ports/doom/CHEX, ... — are the
    #   prboom-shaped symlink farms: the shared IWAD symlinked in from ../, the
    #   mod's own wads, and prboom.wad.  lr-prboom auto-loads whatever sits beside
    #   the IWAD, which is how the mod is selected — by directory.  dsda does NOT:
    #   given only -iwad it plays the base game and ignores the mod in silence
    #   (verified: -iwad EVITERNITY/DOOM2.WAD prints "Playing: DOOM 2: Hell on
    #   Earth" and never touches eviternity.wad).  So discover the siblings here.
    #
    # Do NOT filter by WAD magic.  It looks principled and it is wrong: HacX ships
    # HACX.WAD with IWAD magic, yet dsda loads it happily via -file.  Magic
    # filtering silently dropped that entire total conversion.  Depth is the
    # honest signal; magic is not.
    #
    # -file takes a LIST.  Repeating the flag RESETS it, keeping only the last wad
    # — verified: `-file CHEX.WAD -file CQHDMUS.WAD` loaded only the music and
    # dropped the Chex Quest conversion, while `-file CHEX.WAD CQHDMUS.WAD` loads
    # both.  Emit ONE -file with every wad.
    #
    # STILL NOT SAFE TO TRUST BLINDLY.  Load order matters for some mods; others
    # want -deh or an explicit -complevel.  Every collection promoted to this lane
    # must be launched and LOOKED AT.  dsda-wad-report prints what dsda actually
    # loaded, so a silent misload cannot hide behind a clean exit.
    add_mod_files
    ;;
  doom-crispy)
    # MAINTAINED LANE, LOOSE-MUSIC.  crispy-doom (Guix main) is the only maintained
    # port that keeps lr-prboom's loose-file music substitution — 17 collections
    # depend on it.  Vanilla-accurate, actively developed, correct sprites.
    # See ensure_crispy_music_pack() above for the honest limit on MP3.
    ENGINE="${ROOM_PROFILE}/bin/crispy-doom"
    [[ -x "${ENGINE}" ]] || \
      [[ "${RUNCOMMAND_SHIM_DRYRUN:-0}" == 1 ]] || not_provisioned "${SYSTEM}"
    cd -- "${HOME}"
    # Crispy renders MIDI through SDL_mixer, which needs a MIDI backend.  With none it
    # dies on "Couldn't open timidity.cfg" and there is NO MUSIC AT ALL — which is
    # exactly what Mètsàtron heard when he first tried this lane.  SDL2_mixer here links
    # fluidsynth, so it only wants a soundfont: hand it the same curated one dsda uses.
    _sf="$(resolve_soundfont)" && [[ -r "${_sf}" ]] && export SDL_SOUNDFONTS="${_sf}"
    # Point crispy's music pack at the collection's own directory — the loose
    # tracks sit beside the IWAD, exactly as lr-prboom expects them.
    # Prefer a built OGG pack (doom-musicpack) over the collection dir itself.  The
    # loose .mp3 tracks lr-prboom plays are USELESS to crispy — chocolate/crispy
    # reject MP3 for music packs ("Unrecognized audio format"), which is why crispy
    # came up silent.  doom-musicpack transcodes them to OGG under <collection>/
    # musicpack, named after the MIDI lumps (D_E1M1.ogg …), which crispy auto-detects.
    if [[ -n "${ROM}" ]]; then
      _coll="$(dirname -- "${ROM}")"
      if [[ -d "${_coll}/musicpack" ]]; then
        ensure_crispy_music_pack "${_coll}/musicpack"
      else
        ensure_crispy_music_pack "${_coll}"
      fi
    fi
    command=("${ENGINE}" -iwad "${ROM}")
    add_mod_files
    ;;

  # --- Heretic / Hexen / Strife ------------------------------------------------
  # The other id-tech-1 games.  Their IWADs live in gzdoom-games/base alongside a
  # large standalone-GZDoom library; GZDoom already launches them its own way, these
  # keys add the VANILLA-ACCURATE ports.
  #
  #   dsda-doom   plays Doom, Heretic and Hexen (verified: "Playing: Heretic: Shadow
  #               of the Serpent Riders", "Playing: Hexen").  It does NOT do Strife.
  #   crispy      ships a dedicated binary per game — crispy-heretic / crispy-hexen /
  #               crispy-strife — all three verified starting clean.
  #
  # Both get the soundfont (SDL_mixer has no MIDI backend without one — see the crispy
  # branch above) and both get sibling PWAD/DEH discovery via add_mod_files, so an
  # expansion sitting beside the IWAD (Hexen: Deathkings) is picked up.
  heretic-dsda|hexen-dsda)
    ENGINE="${ROOM_PROFILE}/bin/dsda-doom"
    [[ -x "${ENGINE}" ]] || \
      [[ "${RUNCOMMAND_SHIM_DRYRUN:-0}" == 1 ]] || not_provisioned "${SYSTEM}"
    cd -- "${HOME}"
    ensure_dsda_soundfont
    command=("${ENGINE}" -iwad "${ROM}")
    add_mod_files
    ;;
  heretic-crispy|hexen-crispy|strife-crispy)
    case "${SYSTEM}" in
      heretic-crispy) ENGINE="${ROOM_PROFILE}/bin/crispy-heretic" ;;
      hexen-crispy)   ENGINE="${ROOM_PROFILE}/bin/crispy-hexen"   ;;
      strife-crispy)  ENGINE="${ROOM_PROFILE}/bin/crispy-strife"  ;;
    esac
    [[ -x "${ENGINE}" ]] || \
      [[ "${RUNCOMMAND_SHIM_DRYRUN:-0}" == 1 ]] || not_provisioned "${SYSTEM}"
    cd -- "${HOME}"
    _sf="$(resolve_soundfont)" && [[ -r "${_sf}" ]] && export SDL_SOUNDFONTS="${_sf}"
    command=("${ENGINE}" -iwad "${ROM}")
    add_mod_files
    ;;

  quake)
    CORE="${ROOM_PROFILE}/lib/libretro/tyrquake_libretro.so"
    [[ -x "${ROOM_PROFILE}/bin/retroarch" && -f "${CORE}" ]] || \
      [[ "${RUNCOMMAND_SHIM_DRYRUN:-0}" == 1 ]] || not_provisioned "${SYSTEM}"
    command=("${ROOM_PROFILE}/bin/retroarch" -L "${CORE}" --config "${RETROARCH_CONFIG}" "${ROM}")
    ;;
  quake2)
    ENGINE="${ROOM_PROFILE}/bin/yamagi-quake2"
    [[ -x "${ENGINE}" ]] || \
      [[ "${RUNCOMMAND_SHIM_DRYRUN:-0}" == 1 ]] || not_provisioned "${SYSTEM}"
    command=("${ENGINE}" -datadir "${HOME}/RetroPie/roms/ports/quake2" \
      +set vid_renderer gl1 +set game "${ROM}")
    ;;
  quake3)
    ENGINE="${ROOM_PROFILE}/bin/ioquake3.x86_64"
    [[ -x "${ENGINE}" ]] || \
      [[ "${RUNCOMMAND_SHIM_DRYRUN:-0}" == 1 ]] || not_provisioned "${SYSTEM}"
    command=("${ENGINE}")
    [[ -n "${ROM}" ]] && command+=("${ROM}")
    ;;
  duke3d)
    PORT_DIR="${HOME}/RetroPie/roms/ports/duke3d"
    [[ -d "${PORT_DIR}" ]] || not_provisioned "${SYSTEM}"
    ENGINE="${ROOM_PROFILE}/bin/eduke32"
    [[ -x "${ENGINE}" ]] || \
      [[ "${RUNCOMMAND_SHIM_DRYRUN:-0}" == 1 ]] || not_provisioned "${SYSTEM}"
    cd -- "${PORT_DIR}"
    command=("${ENGINE}")
    if [[ -n "${ROM}" ]]; then
      read -r -a ROM_ARGS <<< "${ROM}"

    ;;
  ionfury)
    PORT_DIR="${HOME}/RetroPie/roms/ports/ionfury"
    [[ -d "${PORT_DIR}" ]] || not_provisioned "${SYSTEM}"
    ENGINE="${ROOM_PROFILE}/bin/fury"
    [[ -x "${ENGINE}" ]] || \
      [[ "${RUNCOMMAND_SHIM_DRYRUN:-0}" == 1 ]] || not_provisioned "${SYSTEM}"
    cd -- "${PORT_DIR}"
    command=("${ENGINE}")
    if [[ -n "${ROM}" ]]; then
      read -r -a ROM_ARGS <<< "${ROM}"
      command+=("${ROM_ARGS[@]}")
    fi
    ;;
  supertux)
    ENGINE="${ROOM_PROFILE}/bin/supertux2"
    [[ -x "${ENGINE}" ]] || \

** doom-musicpack — transcode a collection's loose MP3s into a crispy OGG music pack

Seventeen collections carry custom soundtracks as loose =.mp3= files beside the IWAD.
lr-prboom plays them directly — that is the whole reason the prboom lane survives.
**crispy cannot**: chocolate/crispy reject MP3 for digital music packs
("Unrecognized audio format") even when =libmpg123= is linked, which is why crispy came
up silent when Mètsàtron tested it.  OGG and FLAC are the supported formats.

So transcode.  Crispy auto-detects a pack when the files are named after the MIDI lump
they replace (=D_E1M1.ogg=, =D_INTER.ogg=, …) and =music_pack_path= points at the dir;
no manifest is needed for a single game.  The mapping is mechanical — his tracks are
already named after the lump (=e1m1.mp3=, =inter.mp3=, =bunny.mp3=) — so the rule is
just: uppercase, prefix =D_=, encode to OGG.

Writes to =<collection>/musicpack/=, NOT into the collection dir: the loose MP3s must
stay exactly where they are or the prboom lane loses its music.  Nothing is overwritten
and nothing is deleted.

#+BEGIN_SRC bash :tangle linux/.local/bin/doom-musicpack :tangle-mode (identity #o755) :shebang "#!/bin/bash"
# Build a crispy-doom OGG music pack from a collection's loose MP3 tracks.
set -euo pipefail

PORTS="${RETROPIE_PORTS_DIR:-${HOME}/RetroPie/roms/ports}"
QUALITY="${DOOM_MUSICPACK_QUALITY:-5}"   # oggenc-style quality, 0-10; 5 ~ 160kbps VBR

usage() {
  cat <<'EOF'
doom-musicpack - transcode a collection's loose MP3s into a crispy-doom OGG pack

Usage:
  doom-musicpack <collection>     e.g. doom/DOOM-MP3   (or an absolute path)
  doom-musicpack --list           collections that carry loose MP3s
  doom-musicpack --dry <coll>     show the mapping, encode nothing

Why: lr-prboom plays loose .mp3 directly; crispy-doom CANNOT (MP3 is unsupported for
music packs — it comes up silent). This writes <collection>/musicpack/D_<LUMP>.ogg,
which crispy auto-detects. The original MP3s are never touched — the prboom lane still
needs them.

Env: DOOM_MUSICPACK_QUALITY (0-10, default 5)
EOF
}

# e1m1.mp3 -> D_E1M1 ; inter.mp3 -> D_INTER ; bunny.mp3 -> D_BUNNY
lump_of() {
  local b="${1##*/}"
  b="${b%.*}"
  b="${b^^}"
  b="${b// /_}"
  printf 'D_%s' "${b}"
}

list_collections() {
  local d n
  for d in "${PORTS}"/doom/*/ "${PORTS}"/doom2/*/; do
    [[ -d "${d}" ]] || continue
    n=$(find "${d}" -maxdepth 1 -iname '*.mp3' 2>/dev/null | wc -l)
    (( n )) || continue
    printf '  %-28s %3d tracks%s\n' "${d#"${PORTS}"/}" "${n}" \
      "$( [[ -d "${d}musicpack" ]] && printf '   [pack built: %d]' "$(find "${d}musicpack" -iname '*.ogg' 2>/dev/null | wc -l)" )"
  done
}

case "${1:-}" in
  -h|--help|'') usage; exit 0 ;;
  --list) list_collections; exit 0 ;;
esac

DRY=0
if [[ "${1}" == "--dry" ]]; then DRY=1; shift; fi
[[ -n "${1:-}" ]] || { usage >&2; exit 2; }

COLL="$1"
[[ "${COLL}" == /* ]] || COLL="${PORTS}/${COLL}"
COLL="${COLL%/}"
[[ -d "${COLL}" ]] || { echo "doom-musicpack: no such collection: ${COLL}" >&2; exit 1; }

mapfile -t TRACKS < <(find "${COLL}" -maxdepth 1 -iname '*.mp3' 2>/dev/null | sort)
(( ${#TRACKS[@]} )) || { echo "doom-musicpack: no .mp3 tracks in ${COLL}" >&2; exit 1; }

command -v ffmpeg >/dev/null 2>&1 || { echo "doom-musicpack: ffmpeg not found" >&2; exit 1; }

PACK="${COLL}/musicpack"
printf 'collection : %s\n' "${COLL#"${PORTS}"/}"
printf 'tracks     : %d\n' "${#TRACKS[@]}"
printf 'pack       : %s\n' "${PACK#"${PORTS}"/}"
printf 'quality    : %s\n\n' "${QUALITY}"

(( DRY )) || mkdir -p "${PACK}"

made=0 skipped=0 failed=0
for t in "${TRACKS[@]}"; do
  lump="$(lump_of "${t}")"
  out="${PACK}/${lump}.ogg"
  if (( DRY )); then
    printf '  %-34s -> %s.ogg\n' "$(basename -- "${t}")" "${lump}"
    continue
  fi
  # Never redo work, and never overwrite: an existing pack file is left alone.
  if [[ -s "${out}" ]]; then skipped=$(( skipped + 1 )); continue; fi
  if ffmpeg -nostdin -loglevel error -y -i "${t}" -vn -c:a libvorbis -qscale:a "${QUALITY}" "${out}" 2>/dev/null; then
    made=$(( made + 1 ))
    printf '  %-34s -> %s.ogg\n' "$(basename -- "${t}")" "${lump}"
  else
    failed=$(( failed + 1 ))
    rm -f "${out}"
    printf '  FAILED: %s\n' "$(basename -- "${t}")" >&2
  fi
done

(( DRY )) && exit 0

# --- the SHA1 substitution manifest -------------------------------------------
# Crispy matches a replacement track by the SHA1 of the MIDI lump it replaces, NOT by
# filename.  Without this manifest it finds the pack, matches nothing, and silently
# plays the WAD's own music — no error, no clue.  crispy-doom generates it itself.
CRISPY="${ROOM_PROFILE:-${HOME}/.guix-extra-profiles/room-retropie/room-retropie}/bin/crispy-doom"
IWAD="$(find "${COLL}" -maxdepth 1 \( -iname 'DOOM.WAD' -o -iname 'DOOM2.WAD' \) 2>/dev/null | head -1)"
if [[ -x "${CRISPY}" && -n "${IWAD}" ]]; then
  tmpcfg="$(mktemp)"
  if SDL_VIDEODRIVER=dummy SDL_AUDIODRIVER=dummy timeout 30 \
       "${CRISPY}" -iwad "${IWAD}" -dumpsubstconfig "${tmpcfg}" >/dev/null 2>&1 \
     && [[ -s "${tmpcfg}" ]]
  then
    mv -f "${tmpcfg}" "${PACK}/musicpack.cfg"
    printf '\nmanifest : %d lump->track mappings (SHA1, generated by crispy itself)\n' \
      "$(grep -c '= D_' "${PACK}/musicpack.cfg" 2>/dev/null || echo 0)"
  else
    rm -f "${tmpcfg}"
    printf '\nWARNING: could not generate the SHA1 manifest — crispy will find the pack but\n' >&2
    printf 'match nothing, and play the WAD music instead. Generate it by hand:\n' >&2
    printf '  crispy-doom -iwad %s -dumpsubstconfig %s/musicpack.cfg\n' "${IWAD}" "${PACK}" >&2
  fi
else
  printf '\nNOTE: no crispy-doom or no IWAD here — skipped the SHA1 manifest.\n'
fi

printf '\nencoded %d, already present %d, failed %d\n' "${made}" "${skipped}" "${failed}"
printf 'pack size: %s\n' "$(du -sh "${PACK}" 2>/dev/null | cut -f1)"
printf '\nLaunch the (crispy) variant — the shim links this pack into crispy music-packs dir.\n'
(( failed == 0 ))
#+END_SRC

** doom-soundfont — pick which of the curated soundfonts dsda-doom renders MIDI with

Mètsàtron keeps a curated soundfont collection in =~/RetroPie/BIOS= (26 of them: a
purpose-built =Doom.sf2=, several Roland SC-55 recreations — the hardware the Doom
MIDIs were actually composed on — Arachno, FluidR3, and a pile of console fonts).

dsda-doom renders MIDI through fluidsynth and reads =snd_soundfont= from its config
**at startup only** — it does not hot-reload.  This picks the font; =runcommand-shim=
applies it on the next launch.

#+BEGIN_SRC bash :tangle linux/.local/bin/doom-soundfont :tangle-mode (identity #o755) :shebang "#!/bin/bash"
# Choose the soundfont dsda-doom renders MIDI with.
set -euo pipefail

BIOS="${RETROPIE_BIOS_DIR:-${HOME}/RetroPie/BIOS}"
CFGDIR="${XDG_CONFIG_HOME:-${HOME}/.config}/dotcortex"
STATE="${CFGDIR}/dsda-soundfont"                 # pin ONE font for everything
CANON="${CFGDIR}/dsda-soundfont-canon"           # id's own IWADs
CUSTOM="${CFGDIR}/dsda-soundfont-custom"         # megawads, TCs, mods
DSDA_CFG="${XDG_DATA_HOME:-${HOME}/.local/share}/dsda-doom/dsda-doom.cfg"

usage() {
  cat <<'EOF'
doom-soundfont - choose the soundfont dsda-doom renders MIDI with

By default the font is chosen by WHAT IS PLAYING:
  canon  (Doom, Doom II, TNT, Plutonia)  -> Roland SC-55  — the hardware these
                                            MIDIs were composed on
  custom (megawads, TCs, mods)           -> Arachno       — more oomph for music
                                            never written for an SC-55

Usage:
  doom-soundfont                  show what is chosen and what is in use
  doom-soundfont list             the curated soundfonts in ~/RetroPie/BIOS
  doom-soundfont canon <name>     set the font for id's own IWADs
  doom-soundfont custom <name>    set the font for megawads/TCs/mods
  doom-soundfont set <name>       PIN one font for everything (overrides both)
  doom-soundfont reset            clear the pin; canon/custom defaults apply again

<name> may be a bare filename or a fuzzy fragment — one unambiguous hit required.

Takes effect on the NEXT launch: dsda reads its config at startup and does not
hot-reload, so quit the game before switching.

_show1() {
  local f="$1" label="$2" dflt="$3" v=''
  [[ -r "${f}" ]] && v="$(head -n1 "${f}" 2>/dev/null || true)"
  printf '  %-8s %s\n' "${label}" "${v:-${dflt} (default)}"
}

current() {
  local pinned=''
  [[ -r "${STATE}" ]] && pinned="$(head -n1 "${STATE}" 2>/dev/null || true)"
  if [[ -n "${pinned}" ]]; then
    printf 'PINNED for everything: %s\n' "${pinned}"
    printf '  (doom-soundfont reset  -> back to canon/custom selection)\n'
  else
    printf 'chosen by what is playing:\n'
    _show1 "${CANON}"  'canon'  'SC-55 Trevor James.sf2'
    _show1 "${CUSTOM}" 'custom' 'Arachno SoundFont - Version 1.0.sf2'
  fi
  if [[ -r "${DSDA_CFG}" ]]; then
    printf 'last used: %s\n' "$(grep -m1 '^snd_soundfont' "${DSDA_CFG}" 2>/dev/null | sed 's/.*"\(.*\)"/\1/' | sed 's|.*/||')"
  fi
}

# Resolve a fuzzy fragment to exactly one soundfont filename in BIOS.
resolve_name() {
  local want="$1" hit
  if [[ -r "${BIOS}/${want}" ]]; then printf '%s' "${want}"; return 0; fi
  local -a hits
  mapfile -t hits < <(find "${BIOS}" -maxdepth 1 \( -iname '*.sf2' -o -iname '*.sf3' \) -printf '%f\n' 2>/dev/null \
                        | grep -i -- "${want}" || true)
  if (( ${#hits[@]} == 0 )); then
    echo "doom-soundfont: no soundfont matching '${want}' in ${BIOS}" >&2
    echo "  try: doom-soundfont list" >&2
    return 1
  elif (( ${#hits[@]} > 1 )); then
    echo "doom-soundfont: '${want}' is ambiguous:" >&2
    printf '  %s\n' "${hits[@]}" >&2
    return 1
  fi
  printf '%s' "${hits[0]}"
}

case "${1:-show}" in
  -h|--help) usage; exit 0 ;;
  show) current ;;
  list)
    [[ -d "${BIOS}" ]] || { echo "doom-soundfont: no BIOS dir: ${BIOS}" >&2; exit 1; }
    find "${BIOS}" -maxdepth 1 \( -iname '*.sf2' -o -iname '*.sf3' \) -printf '%s\t%f\n' 2>/dev/null \
      | sort -t"$(printf '\t')" -k2 \
      | awk -F'\t' '{ printf "  %7.1f MB  %s\n", $1/1048576, $2 }'
    ;;
  set)
    hit="$(resolve_name "${2:-}")" || exit 1
    mkdir -p "${CFGDIR}"
    printf '%s\n' "${hit}" > "${STATE}"
    printf 'PINNED for everything: %s\n' "${hit}"
    printf 'takes effect on the next launch of a (dsda) port.\n'
    ;;
  canon)
    hit="$(resolve_name "${2:-}")" || exit 1
    mkdir -p "${CFGDIR}"
    printf '%s\n' "${hit}" > "${CANON}"
    printf 'canon  (Doom / Doom II / TNT / Plutonia): %s\n' "${hit}"
    [[ -r "${STATE}" ]] && printf 'NOTE: a global pin is set and overrides this — doom-soundfont reset\n'
    ;;
  custom)
    hit="$(resolve_name "${2:-}")" || exit 1
    mkdir -p "${CFGDIR}"
    printf '%s\n' "${hit}" > "${CUSTOM}"
    printf 'custom (megawads / TCs / mods): %s\n' "${hit}"
    [[ -r "${STATE}" ]] && printf 'NOTE: a global pin is set and overrides this — doom-soundfont reset\n'
    ;;
  reset)
    rm -f "${STATE}"
    echo "pin cleared — canon/custom selection applies again."
    ;;
  *) usage >&2; exit 2 ;;
esac

** dsda-wad-report — see what dsda-doom ACTUALLY loaded

Promoting a Doom collection from the legacy =doom= key (lr-prboom) to =doom-dsda=
cannot be done mechanically, and the failure mode is silence, not a crash.

The collection's mod dirs are prboom-shaped symlink farms: the shared IWAD, the
mod's PWADs, and =prboom.wad=, all sitting beside each other, with lr-prboom
auto-loading whatever it finds next to the IWAD.  dsda-doom does not do that.
Given only =-iwad=, it loads the base game and ignores the mod without a word.
The shim now discovers the siblings and passes them with =-file=, which fixes the
common megawad case — but not every case:

- dsda *rejects an IWAD passed via =-file= and drops it without error*.  Chex
  Quest's =CHEX.WAD= is itself an IWAD, so that collection silently loses its
  total conversion and plays as Ultimate Doom with different music.
- Load order matters for some mods; some need =-deh= or an explicit =-complevel=.

So every collection must be looked at before it is trusted on the new lane.  This
tool makes that cheap: it runs dsda-doom's startup, prints the wads it *actually*
loaded, and flags any that discovery offered but dsda silently ignored.

#+BEGIN_SRC bash :tangle linux/.local/bin/dsda-wad-report :tangle-mode (identity #o755) :shebang "#!/bin/bash"
# Report what dsda-doom actually loads for a given IWAD — and what it silently drops.
set -euo pipefail

usage() {
  cat <<'EOF'
dsda-wad-report - show which WADs dsda-doom actually loads for a RetroPie doom dir

Usage:
  dsda-wad-report <path-to-IWAD>          e.g. ~/RetroPie/roms/ports/doom2/EVITERNITY/DOOM2.WAD
  dsda-wad-report --all                   report on every doom/doom2 mod dir
  dsda-wad-report -h | --help

Exit status is 0 even when a WAD is dropped — the DROPPED lines are the finding.
A dropped WAD means that collection is NOT safe on the doom-dsda lane yet.
EOF
}

[[ "${1:-}" == "-h" || "${1:-}" == "--help" ]] && { usage; exit 0; }
(( $# == 1 )) || { usage >&2; exit 2; }

ROOM_PROFILE="${ROOM_PROFILE:-${HOME}/.guix-extra-profiles/room-retropie/room-retropie}"
DSDA="${ROOM_PROFILE}/bin/dsda-doom"
PORTS_ROOT="${RETROPIE_PORTS_DIR:-${HOME}/RetroPie/roms/ports}"

[[ -x "${DSDA}" ]] || { echo "dsda-wad-report: dsda-doom not built: ${DSDA}" >&2; exit 1; }

report_one() {
  local iwad="$1"
  local dir base offered=() added=() dropped=() w
  [[ -f "${iwad}" || -L "${iwad}" ]] || { echo "  MISSING IWAD: ${iwad}" >&2; return 0; }
  dir="$(dirname -- "${iwad}")"
  base="$(basename -- "${iwad}")"

  while IFS= read -r w; do
    [[ -n "${w}" ]] && offered+=("${w}")
  done < <(
    find "${dir}" -maxdepth 1 \( -type f -o -type l \) 2>/dev/null \
      | grep -iE '\.wad$' | grep -viF "/${base}" | grep -viE '/prboom\.wad$' | sort
  )

  local dehs=()
  while IFS= read -r w; do
    [[ -n "${w}" ]] && dehs+=("${w}")
  done < <(
    find "${dir}" -maxdepth 1 \( -type f -o -type l \) 2>/dev/null \
      | grep -iE '\.(deh|bex)$' | sort
  )

  # -file and -deh are LISTS, not repeatable flags: repeating one resets it and
  # only the last entry survives.  Emit each once, with every path.
  local args=("-iwad" "${iwad}")
  (( ${#offered[@]} )) && args+=(-file "${offered[@]}")
  (( ${#dehs[@]} )) && args+=(-deh "${dehs[@]}")

  # Run only far enough to print the load list, then stop.
  local out
  # HEADLESS, ALWAYS.  This tool inspects; it must never take over the screen.
  # Run over --all and, without this, dsda opens a real window and grabs audio for
  # every one of the 53 collections in turn — which is exactly what happened to
  # Mètsàtron: his desktop cycled through the entire library, game after game.
  # A dummy video/audio driver keeps it a pure metadata probe.  Never remove these.
  #
  # Do NOT truncate the output either.  A short head() cut dsda's load list and
  # reported WADs as DROPPED that it had actually loaded — a false positive in the
  # very tool whose job is to catch silent misloads.
  out="$(
    cd -- "${HOME}" \
      && SDL_VIDEODRIVER=dummy SDL_AUDIODRIVER=dummy \
         timeout 12 "${DSDA}" "${args[@]}" -nodraw -nosound -nomusic 2>&1 \
      || true
  )"

  local playing
  playing="$(printf '%s' "${out}" | grep -m1 -i '^Playing:' | sed 's/^[Pp]laying: *//')"

  for w in "${offered[@]:-}"; do
    [[ -n "${w}" ]] || continue
    if printf '%s' "${out}" | grep -qiF -- "${w}"; then added+=("$(basename -- "${w}")")
    else dropped+=("$(basename -- "${w}")"); fi
  done

  printf '%s\n' "${dir#"${PORTS_ROOT}"/}"
  printf '  playing: %s\n' "${playing:-<unknown>}"
  printf '  loaded : %s\n' "${added[*]:-<none>}"
  if (( ${#dehs[@]} )); then
    local dn=()
    for w in "${dehs[@]}"; do dn+=("$(basename -- "${w}")"); done
    printf '  deh    : %s\n' "${dn[*]}"
  fi
  if (( ${#dropped[@]} )); then
    printf '  DROPPED: %s   <-- dsda ignored these; collection NOT safe on doom-dsda\n' "${dropped[*]}"
  fi
  # No wads to load at all: the mod is not wad-shaped.  DOOM-MP3 is the case in
  # point — loose .mp3 tracks that only lr-prboom's music support understands.
  # Such a collection belongs on the legacy lane permanently.
  if (( ${#offered[@]} == 0 )); then
    printf '  NOTE   : no PWADs here — nothing for dsda to load. If this dir has\n'
    printf '           loose media (mp3 etc), it depends on lr-prboom. Keep it on `doom`.\n'
  fi
}

if [[ "$1" == "--all" ]]; then
  for d in "${PORTS_ROOT}"/doom/*/ "${PORTS_ROOT}"/doom2/*/; do
    [[ -d "${d}" ]] || continue
    iwad="$(find "${d}" -maxdepth 1 \( -type f -o -type l \) -iname 'DOOM.WAD' -o -maxdepth 1 \( -type f -o -type l \) -iname 'DOOM2.WAD' 2>/dev/null | head -1)"
    [[ -n "${iwad}" ]] || continue
    report_one "${iwad}"
  done
else
  report_one "$1"
fi

# Ordered first-match classification table. Patterns match the launcher path
# relative to ROOT, in lowercase. Keep engine-specific paths before the broad
# name rules so a future launcher can be retuned in this one place.
GROUP_RULES=(
  '+*.sh|Utilities'
  'buildgdx/*.sh|Build Engine'
  'eduke32/*.sh|Build Engine'
  'nblood/*.sh|Build Engine'
  'raze/*.sh|Build Engine'
  'duke nukem 3d*.sh|Build Engine'
  'ion fury*.sh|Build Engine'
  'blood.sh|Build Engine'
  'nblood*.sh|Build Engine'
  'powerslave exhumed*.sh|Build Engine'
  'shadow warrior*.sh|Build Engine'
  'redneck rampage*.sh|Build Engine'
  'buildgdx*.sh|Build Engine'
  'quake/*.sh|Quake family'
  'quake2/*.sh|Quake family'
  'quake3/*.sh|Quake family'
  '*quake*.sh|Quake family'
  # --- Doom, split BY ENGINE ---------------------------------------------------
  # 600+ entries in one "Doom" folder is unnavigable, and the three lanes were
  # interleaved.  Split by source port instead.  The engine is read from the
  # FILENAME suffix, not the script body: the variants are named "(dsda)"/"(crispy)"
  # by construction, so classification costs no file reads — this menu is a
  # menuprog on a ~1s timeout and must stay cheap.
  #
  # ORDER IS LOAD-BEARING: the (dsda)/(crispy) patterns must precede the generic
  # doom/*.sh rules, or every variant falls into the legacy folder.
  #
  # ESCAPE THE PARENS.  `*(dsda)*.sh` is EXTGLOB — `*(...)` means "zero or more of",
  # so it matches EVERYTHING: it swallowed all 522 Doom entries into the DSDA folder
  # on the first try.  `\(` and `\)` force a literal match.
  '*\(dsda\)*.sh|DSDA'
  '*\(crispy\)*.sh|Crispy'
  # DIFFERENT ENGINES — not Doom ports, and not GZDoom.  Both were wrongly filed under
  # GZDoom on the first cut.
  #
  # ECWolf is the Wolfenstein 3D engine and carries a real spread of games (Wolf3D,
  # Spear of Destiny, the Astrostein set — 27 launchers), so it earns a folder.
  # RBDOOM-3-BFG (id Tech 4) is a ONE-OFF: four launchers for a single game. A folder
  # per lonely engine is how a menu becomes unnavigable again — it goes in Standalone,
  # which is exactly what Standalone is for.  Build Engine, by contrast, is NOT
  # standalone: it is a family (Duke 3D, Ion Fury, Blood, PowerSlave, Shadow Warrior),
  # and keeps its own folder.
  #
  # Note the WOLF-* mapsets under doom2/ are a different thing entirely — WolfenDOOM
  # is a Wolfenstein-THEMED total conversion running on a DOOM engine, so it stays in
  # the Doom lanes.  The axis is the engine, not the theme.
  'ecwolf/*.sh|Wolfenstein'
  'rbdoom-3-bfg/*.sh|Standalone'
  # Doom ports that launch their OWN binaries rather than going through the shim.
  'gzdoom/*.sh|GZDoom'
  'gzdoom-games/*.sh|GZDoom'
  'gzdoom-tc/*.sh|GZDoom'
  'zandronum/*.sh|GZDoom'
  'edge/*.sh|GZDoom'
  '*zandronum*.sh|GZDoom'
  # Everything else on the legacy `doom` key: lr-prboom.  Keeps the loose-MP3
  # soundtracks, and is the only lane portable to a stock RetroPie on a Pi/Wii.
  'prboom*.sh|PrBoom (legacy)'
  '*prboom*.sh|PrBoom (legacy)'
  'doom/*.sh|PrBoom (legacy)'
  'doom2/*.sh|PrBoom (legacy)'
  '*freedoom*.sh|PrBoom (legacy)'
  '*doom*.sh|PrBoom (legacy)'
)

# The menu's set of reachable launchers changes when a top-level launcher or
# immediate child directory changes. A single stat invocation covers the root
# and every immediate child directory; it does not stat the 498 launcher files.
root_signature() {
  local root="$1"
  LC_ALL=C stat -c '%n:%Y' "${root}" "${root}"/*/ 2>/dev/null || true
}

# Select a mounted root without doing a full inventory on the cache-hit path.
# The first regular glob match is enough to distinguish the real tree from an
# empty/unmounted directory; the complete bounded glob happens only on build.
resolve_root() {
  local candidate resolved script
  local -a probes
  if [[ -v RETROPIE_PORTS_DIR ]]; then
    candidate_roots=("${RETROPIE_PORTS_DIR}")
  else
    candidate_roots=(
      "${HOME}/RetroPie/roms/ports"
      "/home/metsatron/RetroPie/roms/ports"
    )
  fi

  ROOT=''
  for candidate in "${candidate_roots[@]}"; do
    [[ -n "${candidate}" && -d "${candidate}" ]] || continue
    resolved="$(readlink -f -- "${candidate}" 2>/dev/null)" || continue
    [[ -d "${resolved}" ]] || continue
    probes=("${resolved}"/*.sh "${resolved}"/*/*.sh)
    for script in "${probes[@]}"; do
      if [[ -f "${script}" ]]; then
        ROOT="${resolved}"
        return 0
      fi
    done
  done
  return 1
}

menu_quote() {
  local value="$1"
  value="${value//\\/\\\\}"
  value="${value//\"/\\\"}"
  QUOTED="\"${value}\""
}

shell_quote() {
  printf -v SHELL_QUOTED '%q' "$1"
}

launch_command() {
  local script="$1"
  shell_quote "${script}"
  printf -v LAUNCH_COMMAND \
    "sh -c 'cd -- \"\$(dirname \"\$1\")\" && exec \"\$1\"' ports-menu-entry %s" \
    "${SHELL_QUOTED}"
}

classify_script() {
  local script="$1"
  local relative="${script#"${ROOT}"/}"
  local lower="${relative,,}"
  local rule pattern

  for rule in "${GROUP_RULES[@]}"; do
    pattern="${rule%%|*}"
    CLASSIFIED_GROUP="${rule#*|}"
    if [[ "${lower}" == ${pattern} ]]; then
      return 0
    fi
  done

  # Never drop a launcher that has not been added to the table yet.
  CLASSIFIED_GROUP='Standalone'
}

declare -a top_scripts=() nested_level=() all_scripts=() nested_dirs=() sorted_nested_dirs=()
declare -A GROUP_COUNTS=() GROUP_TOP_SCRIPTS=() GROUP_DIR_SCRIPTS=() SEEN_DIRS=()

generate_menu() {
  local script dir group count
  top_scripts=("${ROOT}"/*.sh)
  nested_level=("${ROOT}"/*/*.sh)
  all_scripts=()
  nested_dirs=()
  sorted_nested_dirs=()
  GROUP_COUNTS=()
  GROUP_TOP_SCRIPTS=()
  GROUP_DIR_SCRIPTS=()
  SEEN_DIRS=()

  for script in "${top_scripts[@]}"; do
    [[ -f "${script}" ]] && all_scripts+=("${script}")
  done
  for script in "${nested_level[@]}"; do
    [[ -f "${script}" ]] || continue
    all_scripts+=("${script}")
    dir="${script%/*}"
    if [[ -z "${SEEN_DIRS[${dir}]+present}" ]]; then
      SEEN_DIRS["${dir}"]=1
      nested_dirs+=("${dir}")
    fi
  done

  if (( ${#all_scripts[@]} == 0 )); then
    emit_unavailable
    return 0
  fi

  for script in "${all_scripts[@]}"; do
    classify_script "${script}"
    group="${CLASSIFIED_GROUP}"
    count="${GROUP_COUNTS[${group}]:-0}"
    GROUP_COUNTS["${group}"]=$((count + 1))
    if [[ "${script}" == "${ROOT}"/*/* ]]; then
      dir="${script%/*}"
      GROUP_DIR_SCRIPTS["${dir}"$'\x1f'"${group}"]+="${script}"$'\n'
    else
      GROUP_TOP_SCRIPTS["${group}"]+="${script}"$'\n'
    fi
  done

  if (( ${#nested_dirs[@]} > 0 )); then
    mapfile -t sorted_nested_dirs < <(printf '%s\n' "${nested_dirs[@]}" | LC_ALL=C sort)
  fi

  if [[ "${MODE}" == 'icewm' ]]; then
    emit_icewm
  else
    emit_fvwm
  fi
}

group_has_scripts() {
  local group="$1"
  (( ${GROUP_COUNTS[${group}]:-0} > 0 ))
}

group_dir_has_scripts() {
  local key="${1}"$'\x1f'"${2}"
  [[ -n "${GROUP_DIR_SCRIPTS[${key}]+present}" ]]
}

icewm_entry() {
  local script="$1"
  local label="${script##*/}"
  label="${label%.sh}"
  menu_quote "${label}"
  local quoted_label="${QUOTED}"
  launch_command "${script}"
  printf '  prog %s application-x-executable %s\n' \
    "${quoted_label}" "${LAUNCH_COMMAND}"
}

fvwm_entry() {
  local script="$1"
  local label="${script##*/}"
  label="${label%.sh}"
  menu_quote "${label}"
  local quoted_label="${QUOTED}"
  launch_command "${script}"
  printf '+ %s Exec %s &\n' "${quoted_label}" "${LAUNCH_COMMAND}"
}

emit_icewm() {
  local group script dir label quoted_group key scripts
  for group in "${GROUP_ORDER[@]}"; do
    group_has_scripts "${group}" || continue
    [[ "${group}" == 'Utilities' ]] && printf '  separator\n'
    menu_quote "${GROUP_LABELS[${group}]}"
    quoted_group="${QUOTED}"
    printf '  menu %s %s {\n' "${quoted_group}" "${GROUP_ICONS[${group}]}"
    scripts="${GROUP_TOP_SCRIPTS[${group}]-}"
    while IFS= read -r script; do
      [[ -n "${script}" ]] || continue
      icewm_entry "${script}"
    done <<< "${scripts}"
    for dir in "${sorted_nested_dirs[@]}"; do
      group_dir_has_scripts "${dir}" "${group}" || continue
      label="${dir##*/}"
      menu_quote "${label}"
      printf '    menu %s folder {\n' "${QUOTED}"
      key="${dir}"$'\x1f'"${group}"
      scripts="${GROUP_DIR_SCRIPTS[${key}]-}"
      while IFS= read -r script; do
        [[ -n "${script}" ]] || continue
        icewm_entry "${script}"
      done <<< "${scripts}"
      printf '    }\n'
    done
    printf '  }\n'
  done
}

emit_fvwm() {
  local group script dir label group_id menu_id index=0 quoted_group key scripts
  printf 'DestroyMenu "Ports"\nAddToMenu "Ports" "Ports" Title\n'
  for group in "${GROUP_ORDER[@]}"; do
    group_has_scripts "${group}" || continue
    group_id="${GROUP_MENU_IDS[${group}]}"
    menu_quote "${GROUP_LABELS[${group}]}"
    printf '+ %s Popup %s\n' "${QUOTED}" "${group_id}"
  done
  for group in "${GROUP_ORDER[@]}"; do
    group_has_scripts "${group}" || continue
    group_id="${GROUP_MENU_IDS[${group}]}"
    menu_quote "${GROUP_LABELS[${group}]}"
    quoted_group="${QUOTED}"
    printf 'DestroyMenu "%s"\nAddToMenu "%s" %s Title\n' \
      "${group_id}" "${group_id}" "${quoted_group}"
    scripts="${GROUP_TOP_SCRIPTS[${group}]-}"
    while IFS= read -r script; do
      [[ -n "${script}" ]] || continue
      fvwm_entry "${script}"
    done <<< "${scripts}"
    index=0
    for dir in "${sorted_nested_dirs[@]}"; do
      group_dir_has_scripts "${dir}" "${group}" || continue
      index=$((index + 1))
      label="${dir##*/}"
      menu_id="${group_id}Dir${index}"
      menu_quote "${label}"
      printf '+ %s Popup %s\n' "${QUOTED}" "${menu_id}"
      printf 'DestroyMenu "%s"\nAddToMenu "%s" %s Title\n' \
        "${menu_id}" "${menu_id}" "${QUOTED}"
      key="${dir}"$'\x1f'"${group}"
      scripts="${GROUP_DIR_SCRIPTS[${key}]-}"
      while IFS= read -r script; do
        [[ -n "${script}" ]] || continue
        fvwm_entry "${script}"
      done <<< "${scripts}"
    done
  done
}

cleanup_build() {
  rm -f -- "${BUILD_TMP_MENU}" "${BUILD_TMP_STAMP}"
  if (( LOCK_HELD )); then
    rmdir -- "${LOCK_DIR}" 2>/dev/null || true
  fi
}

cache_problem() {
  if (( ! CACHE_PROBLEM_REPORTED )); then
    printf 'ports-menu-gen: cache unusable or invalid; generating menu directly\n' >&2
    CACHE_PROBLEM_REPORTED=1
  fi
}

cache_path_is_usable() {
  local probe
  if [[ ! -d "${CACHE_DIR}" ]]; then
    mkdir -p -- "${CACHE_DIR}" 2>/dev/null || return 1
  fi
  [[ -r "${CACHE_DIR}" && -x "${CACHE_DIR}" && -w "${CACHE_DIR}" ]] || return 1
  if [[ -e "${CACHE_FILE}" && ! -r "${CACHE_FILE}" ]]; then
    return 1
  fi
  if [[ -e "${STAMP_FILE}" && ! -r "${STAMP_FILE}" ]]; then
    return 1
  fi
  probe="$(mktemp "${CACHE_DIR}/.probe.XXXXXX" 2>/dev/null)" || return 1
  rm -f -- "${probe}" || return 1
}

menu_digest() {
  local hash_line
  [[ -n "${HASH_BIN}" ]] || return 1
  hash_line="$("${HASH_BIN}" -- "$1")" || return 1
  printf '%s\n' "${hash_line%% *}"
}

cache_content_is_valid() {
  local stamp_digest actual_digest
  [[ -s "${CACHE_FILE}" && -r "${CACHE_FILE}" \
    && -s "${STAMP_FILE}" && -r "${STAMP_FILE}" ]] || return 1
  stamp_digest="$(head -n 1 -- "${STAMP_FILE}")" || return 1
  [[ "${stamp_digest}" =~ ^[[:xdigit:]]{64}$ ]] || return 1
  actual_digest="$(menu_digest "${CACHE_FILE}")" || return 1
  [[ "${actual_digest}" == "${stamp_digest}" ]]
}

build_cache() {
  local signature menu_hash
  mkdir -p -- "${CACHE_DIR}" || return 1
  if ! mkdir -- "${LOCK_DIR}" 2>/dev/null; then
    return 0
  fi
  LOCK_HELD=1
  trap cleanup_build EXIT

  resolve_root || return 1
  signature="$(root_signature "${ROOT}")"
  [[ -n "${signature}" ]] || return 1
  BUILD_TMP_MENU="$(mktemp "${CACHE_DIR}/.${MODE}.menu.XXXXXX")"
  BUILD_TMP_STAMP="$(mktemp "${CACHE_DIR}/.${MODE}.stamp.XXXXXX")"
  generate_menu > "${BUILD_TMP_MENU}"
  if grep -qF 'Ports unavailable — RetroPie tree not mounted' "${BUILD_TMP_MENU}"; then
    return 1
  fi
  menu_hash="$(menu_digest "${BUILD_TMP_MENU}")" || return 1
  # Put the digest first; the remaining lines are the existing multi-line
  # root signature. This makes a truncated or corrupt menu a cache miss.
  printf '%s\n%s\n' "${menu_hash}" "${signature}" > "${BUILD_TMP_STAMP}"
  # Publish the complete menu before its matching stamp. A crash between the
  # two leaves the old stamp, so the next call rebuilds instead of trusting a
  # half-published pair.
  mv -f -- "${BUILD_TMP_MENU}" "${CACHE_FILE}"
  BUILD_TMP_MENU=''
  mv -f -- "${BUILD_TMP_STAMP}" "${STAMP_FILE}"
  BUILD_TMP_STAMP=''
}

if (( BUILD_ONLY )); then
  build_cache
  exit $?
fi

runtime_cleanup() {
  local status=$?
  trap - EXIT
  if (( status != 0 )); then
    printf 'ports-menu-gen: runtime failure; emitting unavailable menu\n' >&2
    emit_unavailable || true
  fi
  exit 0
}
trap runtime_cleanup EXIT

cache_is_current() {
  local stamp_digest stamped_signature actual_digest
  [[ -s "${CACHE_FILE}" && -r "${CACHE_FILE}" \
    && -f "${STAMP_FILE}" && -r "${STAMP_FILE}" ]] || return 1
  stamp_digest="$(head -n 1 -- "${STAMP_FILE}")" || return 1
  [[ "${stamp_digest}" =~ ^[[:xdigit:]]{64}$ ]] || return 1
  stamped_signature="$(tail -n +2 -- "${STAMP_FILE}")" || return 1
  [[ "${stamped_signature}" == "${CURRENT_SIGNATURE}" ]] || return 1
  actual_digest="$(menu_digest "${CACHE_FILE}")" || return 1
  [[ "${actual_digest}" == "${stamp_digest}" ]]
}

refresh_background() {
  local worker_pid
  cache_path_is_usable || return 1
  if [[ -x /usr/bin/setsid && -x /usr/bin/nohup ]]; then
    /usr/bin/nohup /usr/bin/setsid "${SELF}" --build "${MODE}" \
      >/dev/null 2>&1 </dev/null &
  elif [[ -x /usr/bin/nohup ]]; then
    /usr/bin/nohup "${SELF}" --build "${MODE}" \
      >/dev/null 2>&1 </dev/null &
  else
    "${SELF}" --build "${MODE}" >/dev/null 2>&1 </dev/null &
  fi
  worker_pid=$!
  kill -0 "${worker_pid}" 2>/dev/null
}

    printf 'ports-menu-gen: no .sh launchers found at depth 1 or 2 below explicit root: %s\n' \
      "${RETROPIE_PORTS_DIR:-<empty>}" >&2
  else
    printf 'ports-menu-gen: no .sh launchers found in guest or host RetroPie roots\n' >&2
  fi
  emit_unavailable
  exit 0
fi

CURRENT_SIGNATURE="$(root_signature "${ROOT}")"
if ! cache_path_is_usable; then
  cache_problem
  generate_menu
  exit 0
fi

if cache_is_current; then
  cat -- "${CACHE_FILE}"
  exit 0
fi

# An existing file without a matching digest is not menu content. Generate
# directly rather than showing it, or replacing it with a transient notice.
if [[ -e "${CACHE_FILE}" || -L "${CACHE_FILE}" ]] && ! cache_content_is_valid; then
  cache_problem
  generate_menu
  # The direct menu is already on stdout. Repair a writable cache in the
  # background for the next open, but never substitute that worker for it.
  refresh_background || true
  exit 0
fi

# Give a cold or stale cache a bounded fast path. If a slow NFS cold start
# exceeds the budget, a detached worker refreshes it for the next menu open.
if [[ -n "${TIMEOUT_BIN}" && -x "${TIMEOUT_BIN}" ]]; then
  REFRESH_BUDGET='0.65s'
  [[ "${MODE}" == 'fvwm' ]] && REFRESH_BUDGET='1.20s'
  "${TIMEOUT_BIN}" --signal=TERM --kill-after=0.1s "${REFRESH_BUDGET}" \
    "${SELF}" --build "${MODE}" >/dev/null 2>&1 || true
fi

if cache_is_current; then
  cat -- "${CACHE_FILE}"
elif refresh_background; then
  emit_refreshing
else
  cache_problem
  generate_menu
fi
exit 0
