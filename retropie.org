* Purpose

X230 already runs RetroPie bare-metal against =~/RetroPie= (ROMs, BIOS, and Lutris/EmulationStation
state) — that directory is already declared a shared host resource and projected into every
Distrobox sanctuary's guest home by =guests.org='s =vm-homes-init=. This file adds
=sanctuary-retropie=: a portable Distrobox sanctuary so the same ROM/BIOS library and
EmulationStation/RetroArch stack can run from any machine, not just X230's bare-metal install,
without duplicating a single ROM or BIOS file.

Ruled 2026-07-03: the emulation substrate goes through Guix, not a Debian-family distrobox
base — the same one-store-many-rooms substrate every other sanctuary in =distrobox.org= uses.
=sanctuary-retropie= is a sixth Guix-shared-store sanctuary, not a bespoke apt rootfs. RetroPie-Setup
is no longer a binary source at all; its role shrinks to nothing this file needs — the profile in
=guix.org= (=room-retropie=) *is* the manifest. This file's job is the sanctuary itself: profile
apply, ES config/theme projection, health, and treating X230's existing native install as a managed,
read-only-observed endpoint rather than something reinstalled here.

* Design

#+BEGIN_SRC text :tangle no
guix.org: room-retropie.scm (retroarch, mame, mednafen, RetroPie's own ES fork, curated
libretro cores, + the X68000/PC-98/FM-TOWNS marrow — see guix.org for the full audit)
  ↓
make guix-room-retropie   → ~/.guix-extra-profiles/room-retropie/room-retropie
  ↓
distrobox-sanctuaries-create (distrobox.org) — sanctuary-retropie joins the other five,
same sanctuary-base:guix image, same /gnu/store + GUIX_PROFILES read-only bind mounts
  ↓
sanctuary-retropie-launch (plugs into sanctuary-enter, same fzf picker as every other sanctuary):
  project the es-theme-metsatron submodule's built/ into the guest's EmulationStation config
  Xephyr :94 -fullscreen
  distrobox enter sanctuary-retropie --
    . ~/.guix-extra-profiles/desktop-common/desktop-common/etc/profile
    . ~/.guix-extra-profiles/room-retropie/room-retropie/etc/profile
    exec emulationstation
#+END_SRC

* Prerequisites

1. =loom guix:sanctuary-apply= (or =make guix-room-retropie= directly) — builds the
   =room-retropie= Guix profile declared in =guix.org=.
2. =sanctuary-retropie= uncommented in =linux/.config/virtualisation/guests.conf= (done).
3. =vm-homes-init= (guests.org) — projects =~/RetroPie=, =~/DotCortex=, etc. into the guest home.
4. =distrobox-sanctuaries-create= (distrobox.org) — creates the =sanctuary-retropie= container
   alongside the other five.

* Health

Checks the Guix profile is built, its binaries resolve, the =~/RetroPie= data mount (BIOS/ROMs/
theme — always a mounted directory, never packaged, never in git) is present, and reports the
X230 native install's own state as a read-only observed endpoint rather than something this
script installs or touches.

#+BEGIN_SRC bash :tangle linux/.local/bin/retropie-health :shebang "#!/usr/bin/env bash"
set -euo pipefail

PROFILE="${HOME}/.guix-extra-profiles/room-retropie/room-retropie"

echo "== room-retropie Guix profile =="
if [[ -d "${PROFILE}" ]]; then
  echo "profile = built (${PROFILE})"
  for bin in retroarch mame mednafen emulationstation px68k_libretro.so; do
    if [[ -e "${PROFILE}/bin/${bin}" || -e "${PROFILE}/lib/retroarch/cores/${bin}" ]]; then
      echo "  ${bin} = present"
    else
      echo "  ${bin} = MISSING"
    fi
  done
else
  echo "profile = MISSING — run: make guix-room-retropie"
fi

echo ""
echo "== RetroPie data mount =="
if [[ -d "${HOME}/RetroPie" ]]; then
  echo "~/RetroPie = present"
else
  echo "~/RetroPie = MISSING"
fi

echo ""
echo "== sanctuary-retropie container =="
if command -v distrobox >/dev/null 2>&1 && distrobox list --no-color 2>/dev/null \
  | awk -F '|' '{gsub(/^[ \t]+|[ \t]+$/, "", $2); print $2}' | grep -qx "sanctuary-retropie"; then
  echo "sanctuary-retropie = created"
else
  echo "sanctuary-retropie = not created — run distrobox-sanctuaries-create"
fi

echo ""
echo "== X230 native RetroPie install (read-only observed endpoint) =="
if [[ -x "${HOME}/RetroPie-Setup/retropie_packages.sh" ]]; then
  echo "RetroPie-Setup = present"
  ( cd "${HOME}/RetroPie-Setup" && git log -1 --format='  version: %h %cd' --date=short 2>/dev/null ) || true
else
  echo "RetroPie-Setup = not present on this machine (expected everywhere except X230)"
fi
#+END_SRC

* Sanctuary launcher

Plugs into the existing =sanctuary-enter= fzf picker in =distrobox.org= the same way every
other sanctuary does — =sanctuary-retropie= is already in its =SANCTUARY_DESKTOPS= map.
Projects the =es-theme-metsatron= submodule's =built/= variant into the sanctuary's
EmulationStation config at launch time, the same copy-not-symlink pattern
=sanctuary-redstone-9x-launch= uses for its desktop config (the host repo path isn't visible
inside the container).

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-retropie-launch :shebang "#!/usr/bin/env bash"
# Launch sanctuary-retropie: Xephyr :94 + EmulationStation inside the Guix-store sanctuary.
# Prerequisites:
#   make guix-room-retropie
#   distrobox-sanctuaries-create
#   vm-homes-init
set -euo pipefail

DISPLAY_NUM=":94"
SANCTUARY="sanctuary-retropie"
GUESTS_DIR="${XDG_DATA_HOME:-$HOME/.local/share}/dotcortex/guests"
GUEST_HOME="${GUESTS_DIR}/${SANCTUARY}/home"
GUIX_PROFILES="${HOME}/.guix-extra-profiles"
THEME_SRC="${HOME}/DotCortex/linux/.emulationstation-themes/metsatron/built"
CFG_SRC="${HOME}/DotCortex/linux/.emulationstation-config/es_systems.cfg"

# Preflight: verify the room-retropie profile is built before launching.
if [[ ! -f "${GUIX_PROFILES}/room-retropie/room-retropie/etc/profile" ]]; then
  echo "${SANCTUARY}: ERROR — room-retropie Guix profile not built"
  echo "  Build it with: make guix-room-retropie"
  exit 1
fi

if ! distrobox list --no-color 2>/dev/null | awk -F '|' '{gsub(/^[ \t]+|[ \t]+$/, "", $2); print $2}' | grep -qx "${SANCTUARY}"; then
  echo "${SANCTUARY}: not created — run distrobox-sanctuaries-create first" >&2
  exit 1
fi

# Ensure the guest home has the RetroPie library and Guix profiles projected.
# vm-homes-init is idempotent (ln -sfnT); it links ~/RetroPie -> the shared
# host library and ~/.guix-extra-profiles -> the host Guix profiles. Without
# these the RetroPie-convention paths inside es_systems.cfg (~/RetroPie/roms/*,
# ~-relative cores) resolve to nothing inside the container.
if [[ ! -e "${GUEST_HOME}/RetroPie" || ! -e "${GUEST_HOME}/.guix-extra-profiles" ]]; then
  vm-homes-init >/dev/null 2>&1 || true
fi

# Project the theme (copy, not symlink: the host repo path isn't visible inside the container).
if [[ -d "${THEME_SRC}" ]]; then
  mkdir -p "${GUEST_HOME}/.emulationstation/themes"
  rm -rf "${GUEST_HOME}/.emulationstation/themes/metsatron"
  cp -a "${THEME_SRC}" "${GUEST_HOME}/.emulationstation/themes/metsatron"
fi

# Project the EmulationStation systems config. Copied, not symlinked: the
# DotCortex repo path isn't visible inside the container, and ES writes sibling
# files (es_settings.cfg, gamelists) next to it. Refreshed every launch so a
# re-tangle of retropie.org lands without manual steps. Paths inside follow the
# RetroPie convention (~/RetroPie/roms/<system>) and resolve via the projected
# ~/RetroPie link above.
if [[ -f "${CFG_SRC}" ]]; then
  mkdir -p "${GUEST_HOME}/.emulationstation"
  cp "${CFG_SRC}" "${GUEST_HOME}/.emulationstation/es_systems.cfg"
fi

# Seed a minimal RetroArch config pointing the system (BIOS) directory at the
# RetroPie-convention ~/RetroPie/BIOS so BIOS-dependent cores (PSX, X68000,
# Dreamcast, FDS) find firmware the RetroPie way. The guest-home absolute path
# is identical inside and outside the container, so it resolves in both. Seeded
# only when absent, so RetroArch's own written-back settings survive across runs.
RA_CFG="${GUEST_HOME}/.config/retroarch/retroarch.cfg"
if [[ ! -f "${RA_CFG}" ]]; then
  mkdir -p "${GUEST_HOME}/.config/retroarch"
  printf 'system_directory = "%s/RetroPie/BIOS"\n' "${GUEST_HOME}" > "${RA_CFG}"
fi

Xephyr "${DISPLAY_NUM}" -fullscreen -br -ac -no-host-grab &
XEPHYR_PID=$!
trap 'kill "${XEPHYR_PID}" 2>/dev/null || true' EXIT

for _ in $(seq 1 50); do
  [[ -e "/tmp/.X11-unix/X${DISPLAY_NUM#:}" ]] && break
  sleep 0.1
done

DISPLAY="${DISPLAY_NUM}" sanctuary-exec "${SANCTUARY}" sh -c "
  GUIX_PROFILE=${GUIX_PROFILES}/desktop-common/desktop-common
  . \${GUIX_PROFILE}/etc/profile
  GUIX_PROFILE=${GUIX_PROFILES}/room-retropie/room-retropie
  . \${GUIX_PROFILE}/etc/profile
  exec emulationstation
"

wait "${XEPHYR_PID}" 2>/dev/null || true
#+END_SRC

* EmulationStation systems (libretro first cut)

The systems configuration EmulationStation loads to know what consoles exist,
where their ROMs live, and how to launch them.  Authored here rather than
generated by RetroPie-Setup (which we don't run — the =room-retropie= Guix
profile *is* the emulator inventory, ruled 2026-07-03).

Fully RetroPie-convention: every =<path>= is =~/RetroPie/roms/<system>= and
BIOS resolves from =~/RetroPie/BIOS=, exactly as X230's bare-metal RetroPie
reads this same shared library.  Inside the sanctuary =~= expands to the guest
home, where =vm-homes-init= projects =~/RetroPie= → the shared host library and
=~/.guix-extra-profiles= → the host Guix profiles; so both the ROM paths and
the =~=-relative core paths resolve with zero machine-specific absolute paths
baked into this file.

This is the *libretro first cut*: the systems that have both a core in
=room-retropie= and populated ROMs.  Launch is =retroarch -L <core> %ROM%=
against the profile's cores.  Deferred to a later pass (each needs work of its
own): systems with ROMs but no core yet (Game Boy/GBC, NDS, PC Engine, Atari
2600 — need cores added to =guix.org=), and the standalone emulators
(=mame=, =np2kai=, =Tsugaru_CUI= — each with its own CLI to wire).

Data-tree note: the shared library's Dreamcast ROMs live under a legacy
=roms/Reicast/= directory; the RetroPie-standard path is =roms/dreamcast/=.
This file uses the standard path — reconcile the shared tree (move or symlink
=Reicast= → =dreamcast=) to surface those 81 titles.
