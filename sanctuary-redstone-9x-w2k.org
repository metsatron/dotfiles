* What this is

Solitaire, FreeCell and Minesweeper as shipped in Windows 2000 — the final classic builds before XP restyled them — installed into the Redstone 9X Wine prefix and wired into the Start menu's Wine → Games branch.

Companion to =sanctuary-redstone-9x-wep.org=, which does the same for the 1994 16-bit Entertainment Pack. The two exist separately because they are genuinely different: the WEP binaries are NE (Win16) hosted by =winevdm= and need Wine's 16-bit subsystem, while these are *PE32 i386* — ordinary Win32 that runs through Wine's normal 32-bit path with no VDM involved. Verified by reading the PE header: signature =PE\0\0=, machine =0x14c=.

Together they mean the room covers Win16 and Win32 natively, alongside the DOS lane (DOSEMU2, DOSBox-X), PowerShell, cmd, and the Proton/Lutris modern stack.

** Verified state (2026-07-27, host T480s, isolated =Xvfb :97=)

All three launch and render correctly — window titles and pixels both checked, through a real Wine session, never the live =:93= room.

| Game        | Binary       | Window title | Notes |
|-------------+--------------+--------------+-------|
| Solitaire   | sol.exe      | Solitário    | Deals a full board; =cards.dll= art correct |
| FreeCell    | freecell.exe | FreeCell     | Empty table until Game→New, which is correct behaviour |
| Minesweeper | winmine.exe  | Minesweeper  | Smiley and both LED counters render |

=cards.dll= (153 KB) is required by Solitaire and FreeCell and is installed alongside them.

** Language: this is the Brazilian Portuguese build

The Internet Archive item is a pt-BR rip — the menus read =Jogo= / =Ajuda=, Solitaire's status bar reads =Pontuação: 0 Tempo: 0=, and FreeCell's reads =Cartas restantes=. Minesweeper's UI is almost entirely iconic so it barely shows.

This is a property of the source archive, not of the packaging: swapping in an English =sol.exe= / =freecell.exe= / =winmine.exe= is a drop-in replacement, since the provisioner installs whatever binaries the archive contains under fixed names. Nothing here needs to change to switch language.

** Provenance

Internet Archive item =windows-32bit-classic-games= (=open_source_software= / =community=), uploaded 2022-09-30 and malware-checked by the IA curator, containing =Windows 2000 Classic Games.rar=. As with the Entertainment Pack, the archive is *not* vendored into DotCortex — these are copyrighted Microsoft binaries and this repo is public. Provisioning reads an operator-supplied archive.

* Provisioner — redstone-9x-w2k-provision

Runs on the *host*: every path is a host path, and the guest's =python3= is a broken shim. Idempotent via a completion marker; =--force= redoes everything.

Simpler than the WEP provisioner — no FAT12 image and no SZDD, just a RAR. The extractor is probed rather than assumed, because DotCortex declares none of =unrar=/=unar=/=7z= as a dependency and which one exists varies by machine.

Icons come out of the PE resources with =wrestool=/=icotool= and are written to *both* places the room resolves them, exactly as documented in =sanctuary-redstone-9x-wep.org=: IceWM's flat =~/.icewm/icons/NAME_WxH.png=, and the XDG =hicolor= tree for the GTK/PCManFM Program Manager entries. Icons are optional — if the tooling is missing the games still install.

#+BEGIN_SRC bash :tangle linux/.local/bin/redstone-9x-w2k-provision :shebang "#!/bin/bash" :tangle-mode (identity #o755)
set -euo pipefail

SANCTUARY="sanctuary-redstone-9x"
GUESTS_DIR="${XDG_DATA_HOME:-$HOME/.local/share}/dotcortex/guests"
GUEST_HOME="${GUESTS_DIR}/${SANCTUARY}/home"
WINEPREFIX="${WINEPREFIX:-${GUEST_HOME}/.wine-redstone}"
STAGE="${GUESTS_DIR}/${SANCTUARY}/w2k"
DEST="${WINEPREFIX}/drive_c/W2KGAMES"
ICONDIR="${GUEST_HOME}/.local/share/icons"
ICEWM_ICONS="${GUEST_HOME}/.icewm/icons"
HICOLOR="${ICONDIR}/hicolor"
ICON_SIZES="16 22 24 32 48"
MARKER="${DEST}/.dotcortex-w2k-complete"
WINE_PROFILE="${HOME}/.guix-extra-profiles/room-windows-compat/room-windows-compat"

# Operator-supplied; never vendored (copyrighted Microsoft binaries, public repo).
ARCHIVE="${W2K_RAR:-${HOME}/HelmCortex/NEXUS/sanctuaries/sanctuary-redstone-9x/media/windows-32bit-classic-games/Windows 2000 Classic Games.rar}"

FORCE=0
[[ "${1:-}" == "--force" ]] && FORCE=1

if [[ -f "${MARKER}" && "${FORCE}" -eq 0 ]]; then
  echo "redstone-9x-w2k: already provisioned (${DEST}) — use --force to redo"
  exit 0
fi

if [[ ! -f "${ARCHIVE}" ]]; then
  echo "redstone-9x-w2k: archive not found: ${ARCHIVE}"
  echo "  Supply one with W2K_RAR=/path/to/archive.rar, or fetch the Internet"
  echo "  Archive item 'windows-32bit-classic-games'. Skipping."
  exit 0
fi

if [[ ! -d "${WINEPREFIX}" ]]; then
  echo "redstone-9x-w2k: Wine prefix missing: ${WINEPREFIX}" >&2
  echo "  Launch the sanctuary once so the prefix initialiser runs." >&2
  exit 1
fi

rm -rf "${STAGE}"
mkdir -p "${STAGE}" "${DEST}" "${ICONDIR}" "${ICEWM_ICONS}"

# RAR extractor: none of these is a declared DotCortex dependency, so probe.
extract() {
  local u
  if u="$(command -v unrar)"; then
    "${u}" x -o+ -idq "${ARCHIVE}" "${STAGE}/" >/dev/null 2>&1 && return 0
  fi
  if u="$(command -v unar)"; then
    "${u}" -force-overwrite -quiet -output-directory "${STAGE}" "${ARCHIVE}" >/dev/null 2>&1 && return 0
  fi
  if u="$(command -v 7z)"; then
    "${u}" x -y -o"${STAGE}" "${ARCHIVE}" >/dev/null 2>&1 && return 0
  fi
  if u="$(command -v bsdtar)"; then
    "${u}" -xf "${ARCHIVE}" -C "${STAGE}" >/dev/null 2>&1 && return 0
  fi
  return 1
}

echo "redstone-9x-w2k: extracting ${ARCHIVE}…"
extract || { echo "redstone-9x-w2k: no working RAR extractor (tried unrar, unar, 7z, bsdtar)" >&2; exit 1; }

# The archive may or may not nest a directory; find the payload wherever it is.
find_one() { find "${STAGE}" -type f -iname "$1" | head -1; }

MISSING=0
for f in sol.exe freecell.exe winmine.exe cards.dll; do
  src="$(find_one "${f}")"
  if [[ -z "${src}" ]]; then
    echo "redstone-9x-w2k: MISSING from archive: ${f}" >&2
    MISSING=1
    continue
  fi
  cp -f "${src}" "${DEST}/${f}"
done
[[ "${MISSING}" -eq 0 ]] || { echo "redstone-9x-w2k: archive incomplete — aborting" >&2; exit 1; }

# Gate on real PE32 i386 before declaring success. A truncated or wrong-arch
# download would otherwise only surface as a mystery failure at play time.
PY=""
for c in python3 "${HOME}/.guix-extra-profiles/desktop-common/desktop-common/bin/python3"; do
  "${c}" -c 'import struct' >/dev/null 2>&1 && { PY="${c}"; break; }
done
if [[ -n "${PY}" ]]; then
  "${PY}" - "${DEST}" <<'PYCHECK'
import struct
import sys

dest = sys.argv[1]
bad = []
for name in ("sol.exe", "freecell.exe", "winmine.exe", "cards.dll"):
    try:
        d = open(f"{dest}/{name}", "rb").read()
        pe = struct.unpack_from("<I", d, 0x3C)[0]
        if d[pe:pe + 4] != b"PE\0\0":
            bad.append(f"{name}: not a PE binary")
        elif struct.unpack_from("<H", d, pe + 4)[0] != 0x14C:
            bad.append(f"{name}: not i386")
    except Exception as exc:
        bad.append(f"{name}: {exc}")
if bad:
    sys.exit("redstone-9x-w2k: FAILED integrity check\n  " + "\n  ".join(bad))
print("redstone-9x-w2k: 4 PE32 i386 binaries verified")
PYCHECK
fi

# Pillow probed separately — only the icon fan-out needs it, and a missing
# Pillow must cost icons, never the games.
PY_PIL=""
for c in python3 "${HOME}/.guix-extra-profiles/desktop-common/desktop-common/bin/python3"; do
  "${c}" -c 'from PIL import Image' >/dev/null 2>&1 && { PY_PIL="${c}"; break; }
done

WRESTOOL="${WINE_PROFILE}/bin/wrestool"
ICOTOOL="${WINE_PROFILE}/bin/icotool"
if [[ -x "${WRESTOOL}" && -x "${ICOTOOL}" && -n "${PY_PIL}" ]]; then
  echo "redstone-9x-w2k: extracting icons…"
  TMPICO="$(mktemp -d)"
  trap 'rm -rf "${TMPICO}"' EXIT
  export LC_ALL=C          # icoutils has no locale data in the Guix profile
  n=0
  for entry in "sol:sol" "freecell:freecell" "winmine:winmine"; do
    slug="${entry%%:*}"; exe="${entry##*:}"
    # Scratch is a SEPARATE subdir from staged/ — wiping the whole tmpdir per
    # game also deletes the staging area and leaves exactly one icon.
    rm -rf "${TMPICO:?}/work"
    mkdir -p "${TMPICO}/work/out" "${TMPICO}/staged"
    "${WRESTOOL}" -x -t 14 -o "${TMPICO}/work" "${DEST}/${exe}.exe" 2>/dev/null || true
    ico="$(find "${TMPICO}/work" -maxdepth 1 -type f -name '*.ico' | sort | head -1)"
    [[ -n "${ico}" ]] || continue
    "${ICOTOOL}" -x -o "${TMPICO}/work/out" "${ico}" 2>/dev/null || true
    # icotool writes <base>_<idx>_<W>x<H>x<depth>.png. Unlike the WEP groups,
    # these mix SIZES as well as depths (32x32 and 16x16 in one group), so sort
    # by width first and depth second — sorting on depth alone can pick the
    # 16x16 and hand a blurry upscale to every larger size.
    png="$(find "${TMPICO}/work/out" -type f -name '*.png' \
             | sed 's/.*_\([0-9]\+\)x[0-9]\+x\([0-9]\+\)\.png$/\1 \2 &/' \
             | sort -k1,1nr -k2,2nr | head -1 | cut -d' ' -f3-)"
    if [[ -n "${png}" ]]; then
      cp -f "${png}" "${TMPICO}/staged/w2k-${slug}.png"
      n=$((n + 1))
    fi
  done

  "${PY_PIL}" - "${TMPICO}/staged" "${ICEWM_ICONS}" "${HICOLOR}" ${ICON_SIZES} <<'PYICON'
import os
import sys

from PIL import Image

staged, icewm_dir, hicolor = sys.argv[1], sys.argv[2], sys.argv[3]
sizes = [int(s) for s in sys.argv[4:]]

os.makedirs(icewm_dir, exist_ok=True)
written = 0
for name in sorted(os.listdir(staged)):
    if not name.endswith(".png"):
        continue
    stem = name[:-4]
    src = Image.open(os.path.join(staged, name)).convert("RGBA")
    for size in sizes:
        img = src if src.size == (size, size) else src.resize((size, size), Image.NEAREST)
        # IceWM: flat dir, name_WxH.png — the ONLY layout it resolves by name.
        img.save(os.path.join(icewm_dir, f"{stem}_{size}x{size}.png"))
        # GTK/pcmanfm (Program Manager .desktop Icon=): real XDG hicolor layout.
        apps = os.path.join(hicolor, f"{size}x{size}", "apps")
        os.makedirs(apps, exist_ok=True)
        img.save(os.path.join(apps, f"{stem}.png"))
        written += 1
print(f"redstone-9x-w2k: {written} icon files across {len(sizes)} sizes")
PYICON
  echo "redstone-9x-w2k: ${n} icons -> ${ICEWM_ICONS} and ${HICOLOR}"
else
  echo "redstone-9x-w2k: icon tooling unavailable — menu will use the generic Wine icon"
fi

touch "${MARKER}"
echo "redstone-9x-w2k: ready — 3 games in ${DEST}"
echo "  Launch one with: redstone-9x-w2k sol"
#+END_SRC

* Launcher — redstone-9x-w2k

Same contract as =redstone-9x-wep=: slug in, game out, run from the install directory.

*The shebang must be =#!/bin/bash=.* The sanctuary guest has no =/usr/bin/env= — it is a Guix-populated container where the =/usr/bin= coreutils shims were never created — so an =env= shebang runs fine on the host and fails at =exec= in the room, which IceWM reports as *"Failed to execute …: No such file or directory"* naming the launcher rather than the interpreter.

#+BEGIN_SRC bash :tangle linux/.local/bin/redstone-9x-w2k :shebang "#!/bin/bash" :tangle-mode (identity #o755)
set -euo pipefail

SANCTUARY="sanctuary-redstone-9x"
GUESTS_DIR="${XDG_DATA_HOME:-$HOME/.local/share}/dotcortex/guests"
GUEST_HOME="${GUESTS_DIR}/${SANCTUARY}/home"
GUIX_PROFILES="${HOME}/.guix-extra-profiles"

export WINEPREFIX="${WINEPREFIX:-${GUEST_HOME}/.wine-redstone}"
W2K="${WINEPREFIX}/drive_c/W2KGAMES"

source_guix_profile() {
  local profile="$1" status=0 had_nounset=0
  case $- in *u*) had_nounset=1; set +u ;; esac
  GUIX_PROFILE="$profile"; export GUIX_PROFILE
  . "$profile/etc/profile" || status=$?
  (( had_nounset )) && set -u
  return "$status"
}

for _prof in desktop-common room-gaming room-windows-compat; do
  source_guix_profile "${GUIX_PROFILES}/${_prof}/${_prof}"
done

export DISPLAY="${DISPLAY:-:93}"
export XDG_RUNTIME_DIR="${XDG_RUNTIME_DIR:-/run/user/$(id -u)}"
export WINEDEBUG="${WINEDEBUG:--all}"

case "${1:-}" in
  sol|solitaire) EXE=sol.exe ;;
  freecell)      EXE=freecell.exe ;;
  winmine|mine|minesweeper) EXE=winmine.exe ;;
  ""|-h|--help)
    echo "usage: redstone-9x-w2k <game>"
    echo "  sol freecell winmine"
    exit 0 ;;
  *)
    echo "redstone-9x-w2k: unknown game '${1}'" >&2
    exit 1 ;;
esac

if [[ ! -f "${W2K}/${EXE}" ]]; then
  echo "redstone-9x-w2k: ${EXE} not installed — run redstone-9x-w2k-provision" >&2
  exit 1
fi

cd "${W2K}"
exec wine "${EXE}"
#+END_SRC
