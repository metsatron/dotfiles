* Fleet map

| Role          | Machine | OS               | Overlay      |
|---------------+---------+------------------+--------------|
| Server+Client | X230    | Ubuntu/systemd   | x230         |
| Server+Client | T480s   | Devuan/sysv-init | t480s        |
| Server+Client | T480    | Vendefoul Wolf (Devuan/sysv-init) | t480 |

Transport: NFSv4 over Tailscale (WireGuard). Tailscale IPs used throughout —
stable =100.x.x.x= addresses that work at home (direct LAN path) and remotely
(DERP relay). Hostnames pinned via =/etc/hosts= so MagicDNS is not required.

** When the server relocates
1. Update the relevant =_TS_IP= in =~/.local/share/dotcortex/nfs/nfs.env= on each client
2. =tangle-one nfs.org=
3. =loom stow:<machine>= (or whichever clients need updating)
4. Re-run =nfs-client-setup= on each client — updates =/etc/hosts=, reloads autofs

** Adding a new client node
1. Add the new client's Tailscale IP to =nfs.env= on each server and update the exports fragment
2. Copy the relevant client section, adjust overlay prefix and mount paths
3. =tangle-one nfs.org && loom stow:<server> && loom stow:<newmachine>=
4. Re-run =nfs-server-setup= on each server — idempotent, picks up new entries
5. Run =nfs-client-setup= on the new machine

** Replacing the storage server
Full mesh: every machine exports to every other machine.
To move the X230 server role to a new machine:
1. Deploy =nfs-server-setup= on the new machine (tangle its overlay section first)
2. Update =X230_TS_IP= → new Tailscale IP in each client's =nfs.env=
3. Retire the old server section or keep it as a template

* Network config (machine-local)
IP addresses and network topology are machine-local and never stored in DotCortex.
Each machine keeps an =nfs.env= file at =~/.local/share/dotcortex/nfs/nfs.env=
(not tracked in git) with its real IP values. Setup scripts source it at runtime.

To bootstrap: copy the template, fill in values, then run the setup script.

* Fleet resilience — firewall + self-heal

This section exists because of a real incident: the X230 was rebooted ungracefully and its =nfs-server= failed to start. The =rpc.nfsd= had been bound to the Tailscale IP out-of-band via =RPCNFSDOPTS="--host <TS_IP>"= in =/etc/default/nfs-kernel-server= — a setting *never authored here*. At boot =nfs-server= started before =tailscaled= brought that IP up, so the bind failed with =errno 99 (Cannot assign requested address)= and systemd never retried. For ~10h there was no NFS server. Every client shell, =ls=, tab-completion, and PATH walk that touched =~/HelmCortex= (an NFS mount) blocked in uninterruptible I/O — the terminal "locked up". =tmux-continuum='s timer kept firing saves into the dead mount, piling up D-state processes and degrading the box for hours.

The durable, declarative answer has three parts, all authored below:

1. *Bind all interfaces* (no =--host=) so =nfsd= can always start regardless of boot order. The =nfs-server-setup= scripts strip any stray =--host= from =/etc/default/nfs-kernel-server=, eliminating the undeclared drift that caused the incident.
2. *Restrict NFS to =tailscale0= + =lo=* with a dedicated nftables table — this provides the access control that =--host= used to, without coupling startup to interface availability. The ruleset is interface+port only (no IPs), so it is repo-safe and committed.
3. *Self-heal* via =nfs-doctor=, a role-aware, idempotent watchdog scheduled on every machine (systemd timer where available, =/etc/cron.d= on sysvinit). It brings =nfsd= up once the Tailscale IP appears, re-asserts the firewall, and detects + clears stale client mounts (lazy unmount + autofs reload + remount), converging the fleet to healthy no matter how a node came up.

Client mount options were also tightened to =timeo=10,retrans=1= (a dead server now errors in seconds, not ~60s), and NFS-backed =$PATH= probes in =shell.org= / =agents.org= are =timeout=-bounded so a wedged mount can never hang shell startup.

Dependency: =nftables= is declared in =debian/.nala/manifest/packages.ssv=. Install with =loom nala:apply= before running the setup scripts on a node.

** Firewall ruleset (IP-free, committed)
Interface names and a port number are not network topology — no IPs here, so this is safe in a public repo. =policy accept= with a dedicated table means only the NFS ports are dropped off-Tailscale; it cannot lock out SSH or anything else. =tailscale0= is matched by name, so the ruleset loads cleanly at boot even before the interface exists.

#+BEGIN_SRC conf :tangle all/.config/dotcortex/nfs/dotcortex-nfs.nft :padline no :comments none
# DotCortex NFS access control — restrict NFS to tailscale0 + loopback.
# Managed by nfs.org; installed to /etc/nftables.d/ by nfs-firewall. No IPs here.
table inet dotcortex_nfs {
  chain input {
    type filter hook input priority -10; policy accept;
    iif "lo" accept
    iifname "tailscale0" accept
    tcp dport { 111, 2049 } drop
    udp dport { 111, 2049 } drop
  }
}
#+END_SRC

** nfs-firewall — install + apply the ruleset
Stow-global. Installs the ruleset as an nftables drop-in, ensures it is included by =/etc/nftables.conf= so it survives reboot, applies it now, and enables the =nftables= service. Idempotent.

#+BEGIN_SRC bash :tangle all/.local/bin/nfs-firewall :shebang "#!/usr/bin/env bash"
set -euo pipefail

TAG="nfs-firewall"
RULES_SRC="${HOME}/.config/dotcortex/nfs/dotcortex-nfs.nft"
NFT_DROPIN_DIR="/etc/nftables.d"
NFT_DROPIN="${NFT_DROPIN_DIR}/dotcortex-nfs.nft"
NFT_MAIN="/etc/nftables.conf"

run_priv() { if [ "$(id -u)" = 0 ]; then "$@"; else sudo -n "$@"; fi; }
is_systemd() { [ -d /run/systemd/system ]; }

command -v nft >/dev/null 2>&1 || {
  echo "$TAG: nft not installed — run 'loom nala:apply' (nftables)" >&2; exit 1; }
[ -f "$RULES_SRC" ] || {
  echo "$TAG: missing $RULES_SRC — run 'tangle-one nfs.org' && stow" >&2; exit 1; }

# 1. Install the ruleset drop-in
run_priv install -d -m 755 "$NFT_DROPIN_DIR"
run_priv install -m 644 "$RULES_SRC" "$NFT_DROPIN"

# 2. Ensure the main config includes the drop-in dir (loads at boot)
INCLUDE_LINE='include "/etc/nftables.d/*.nft"'
if [ ! -f "$NFT_MAIN" ]; then
  # Self-contained table (priority -10, policy accept) — no flush needed.
  printf '#!/usr/sbin/nft -f\n%s\n' "$INCLUDE_LINE" | run_priv tee "$NFT_MAIN" >/dev/null
elif ! grep -qF '/etc/nftables.d/*.nft' "$NFT_MAIN"; then
  printf '%s\n' "$INCLUDE_LINE" | run_priv tee -a "$NFT_MAIN" >/dev/null
fi

# 3. Apply now (idempotent: drop existing table, then reload)
run_priv nft delete table inet dotcortex_nfs 2>/dev/null || true
run_priv nft -f "$NFT_DROPIN"

# 4. Enable at boot
if is_systemd; then
  run_priv systemctl enable nftables >/dev/null 2>&1 || true
else
  command -v update-rc.d >/dev/null 2>&1 && \
    run_priv update-rc.d nftables enable >/dev/null 2>&1 || true
fi

echo "$TAG: applied — NFS (111/2049) restricted to tailscale0 + lo"
run_priv nft list table inet dotcortex_nfs
#+END_SRC

** nfs-doctor — role-aware self-heal watchdog
Stow-global. Idempotent and safe to run repeatedly. Scheduled as root (systemd
timer or =/etc/cron.d=); also runnable by hand (escalates via =sudo -n=). Uses
=NFS_DOCTOR_HOME= (set by the scheduler) so it targets the human's mounts even
when run as root.

#+BEGIN_SRC bash :tangle all/.local/bin/nfs-doctor :shebang "#!/usr/bin/env bash"
# Heal logic must continue past individual failures — no set -e.
set -uo pipefail

TAG="nfs-doctor"
HOME_DIR="${NFS_DOCTOR_HOME:-${HOME:-/home/metsatron}}"
MNT_BASE="${HOME_DIR}/mnt"

log() { logger -t "$TAG" -- "$*" 2>/dev/null || true; printf '%s: %s\n' "$TAG" "$*"; }
run_priv() { if [ "$(id -u)" = 0 ]; then "$@"; else sudo -n "$@"; fi; }
have() { command -v "$1" >/dev/null 2>&1; }
is_systemd() { [ -d /run/systemd/system ]; }

ts_ip() { ip -4 -o addr show tailscale0 2>/dev/null | awk '{print $4}' | cut -d/ -f1 | head -1; }
nfsd_answering() {
  # nfsd may bind only a specific address, so a loopback rpcinfo can falsely
  # report "down". Authoritative check: is anything listening on 2049 on ANY
  # interface? Fall back to rpcinfo if ss is unavailable.
  if command -v ss >/dev/null 2>&1; then
    ss -H -tln 'sport = :2049' 2>/dev/null | grep -q . && return 0
    return 1
  fi
  timeout 5 rpcinfo -t 127.0.0.1 nfs >/dev/null 2>&1
}
is_nfs_server() { have exportfs && grep -q "DOTCORTEX-NFS" /etc/exports 2>/dev/null; }

heal_firewall() {
  have nft || return 0
  if run_priv nft list table inet dotcortex_nfs >/dev/null 2>&1; then return 0; fi
  log "firewall: dotcortex_nfs table missing — re-applying"
  [ -x "${HOME_DIR}/.local/bin/nfs-firewall" ] && \
    "${HOME_DIR}/.local/bin/nfs-firewall" >/dev/null 2>&1 || true
}

heal_server() {
  is_nfs_server || return 0
  local ip; ip="$(ts_ip)"
  if [ -z "$ip" ]; then
    log "server: tailscale0 has no IP yet — deferring nfsd start"
    return 0
  fi
  nfsd_answering && return 0
  log "server: nfsd down but tailscale0 up ($ip) — restarting nfs-kernel-server"
  if is_systemd; then
    run_priv systemctl restart nfs-kernel-server 2>/dev/null \
      || run_priv systemctl restart nfs-server 2>/dev/null || true
  else
    run_priv service nfs-kernel-server restart 2>/dev/null || true
  fi
  run_priv exportfs -ra 2>/dev/null || true
  if nfsd_answering; then log "server: nfsd restored"; else log "server: WARN nfsd still down"; fi
}

reload_autofs() {
  if is_systemd; then
    run_priv systemctl reload autofs 2>/dev/null \
      || run_priv systemctl restart autofs 2>/dev/null || true
  else
    run_priv service autofs reload 2>/dev/null \
      || run_priv service autofs restart 2>/dev/null || true
  fi
}

mount_is_stale() {
  local mp="$1"
  grep -q " $mp " /proc/mounts 2>/dev/null || return 1   # not mounted -> not stale
  timeout 5 stat "$mp" >/dev/null 2>&1 && return 1
  return 0
}

heal_client() {
  [ -d "$MNT_BASE" ] || return 0
  local mp host
  for mp in "$MNT_BASE"/*; do
    [ -d "$mp" ] || continue
    host="$(basename "$mp")"
    if mount_is_stale "$mp"; then
      log "client: $mp is stale — force/lazy unmount + autofs reload"
      run_priv umount -f "$mp" 2>/dev/null || run_priv umount -l "$mp" 2>/dev/null || true
      reload_autofs
    fi
    # If the server is reachable but the share is not mounted, trigger automount.
    if ! grep -q " $mp " /proc/mounts 2>/dev/null; then
      if timeout 5 rpcinfo -t "$host" nfs >/dev/null 2>&1; then
        timeout 8 ls "$mp" >/dev/null 2>&1 || true
      fi
    fi
  done
}

log "run start (uid=$(id -u) home=$HOME_DIR)"
heal_firewall
heal_server
heal_client
log "run done"
#+END_SRC

** nfs-watchdog-setup — install firewall + doctor schedule
Stow-global, init-aware, idempotent. Called at the end of every =nfs-server-setup=
and =nfs-client-setup=, or run standalone. Bakes the human's HOME into the schedule
so the root-run doctor targets the right mounts.

#+BEGIN_SRC bash :tangle all/.local/bin/nfs-watchdog-setup :shebang "#!/usr/bin/env bash"
set -euo pipefail

TAG="nfs-watchdog-setup"
TARGET_HOME="$HOME"
DOCTOR="${TARGET_HOME}/.local/bin/nfs-doctor"
FIREWALL="${TARGET_HOME}/.local/bin/nfs-firewall"

run_priv() { if [ "$(id -u)" = 0 ]; then "$@"; else sudo -n "$@"; fi; }
is_systemd() { [ -d /run/systemd/system ]; }

[ -x "$DOCTOR" ] || {
  echo "$TAG: missing $DOCTOR — run 'tangle-one nfs.org' && stow" >&2; exit 1; }

echo "[1/2] firewall..."
if [ -x "$FIREWALL" ]; then
  "$FIREWALL" || echo "$TAG: WARN firewall step failed (continuing)"
fi

echo "[2/2] nfs-doctor schedule..."
if is_systemd; then
  TMP="$(mktemp)"
  cat >"$TMP" <<EOF
[Unit]
Description=DotCortex NFS fleet self-heal (nfs-doctor)
After=network.target

[Service]
Type=oneshot
Environment=NFS_DOCTOR_HOME=${TARGET_HOME}
ExecStart=${DOCTOR}
EOF
  run_priv install -m 644 "$TMP" /etc/systemd/system/nfs-doctor.service
  cat >"$TMP" <<EOF
[Unit]
Description=Run nfs-doctor periodically

[Timer]
OnBootSec=1min
OnUnitActiveSec=2min
Unit=nfs-doctor.service

[Install]
WantedBy=timers.target
EOF
  run_priv install -m 644 "$TMP" /etc/systemd/system/nfs-doctor.timer
  rm -f "$TMP"
  run_priv systemctl daemon-reload
  run_priv systemctl enable --now nfs-doctor.timer
  echo "$TAG: systemd timer nfs-doctor.timer enabled"
else
  TMP="$(mktemp)"
  cat >"$TMP" <<EOF
# DotCortex NFS fleet self-heal — managed by nfs-watchdog-setup, do not edit.
NFS_DOCTOR_HOME=${TARGET_HOME}
HOME=${TARGET_HOME}
*/2 * * * * root ${DOCTOR} >/dev/null 2>&1
@reboot root ${DOCTOR} >/dev/null 2>&1
EOF
  run_priv install -m 644 "$TMP" /etc/cron.d/dotcortex-nfs-doctor
  rm -f "$TMP"
  echo "$TAG: cron /etc/cron.d/dotcortex-nfs-doctor installed"
fi

echo "$TAG: done"
#+END_SRC

* X230 — NFS Server

** Static IP: enp0s25
X230 serves NFS over its wired interface (=enp0s25=, MAC =3c:97:0e:ac:98:af=).
It must have a stable IP — dynamic DHCP lease renewal causes a brief =no lease= state
that drops NFS4 sessions on connected clients (seen as timeout storms + lost locks).

Static values:
| Key         | Value          |
|-------------+----------------|
| Interface   | enp0s25        |
| Address     | see nfs.env    |
| Gateway     | see nfs.env    |
| DNS         | see nfs.env    |

Ubuntu uses Netplan + NM. The =nmcli connection modify= in =nfs-server-setup= writes
back into =/etc/netplan/= via NM's Netplan renderer, so the change survives reboots.
The step is idempotent: it skips if the interface is already on =manual=.

** Host entries: X230 knows its clients
Generated at runtime by =nfs-server-setup= from =nfs.env= (IPs are machine-local, not in repo).

** Exports: X230 serves registered clients
Injected into =/etc/exports= by =nfs-server-setup=.

Options:
- =rw= — read/write
- =sync= — writes committed to disk before ACK (safe)
- =no_subtree_check= — skip subtree verification (stable handles on rename)
- =no_root_squash= — UID 0 maps to UID 0; same user both sides, trusted Tailscale only

#+BEGIN_SRC text :tangle x230/.local/share/dotcortex/nfs/exports.conf :padline no :comments none
# Star Fleet exports — add one line per client
/home/metsatron   t480s(rw,sync,no_subtree_check,no_root_squash)
/home/metsatron   t480(rw,sync,no_subtree_check,no_root_squash)
#+END_SRC

X230 also mounts from T480s and T480. See =* X230 — NFS Client= section below.

** Setup script: nfs-server-setup
Run on X230 after =tangle-one nfs.org && loom stow:x230=.
Safe to re-run whenever the fleet changes.

#+BEGIN_SRC bash :tangle x230/.local/bin/nfs-server-setup :shebang "#!/usr/bin/env bash"
set -euo pipefail

CONF="${HOME}/.local/share/dotcortex/nfs"
NFS_ENV="${CONF}/nfs.env"
HOSTS_FRAG="${CONF}/hosts-nfs.conf"
EXPORTS_FRAG="${CONF}/exports.conf"
MARKER_START="# BEGIN DOTCORTEX-NFS"
MARKER_END="# END DOTCORTEX-NFS"

die() { printf 'nfs-server-setup: %s\n' "$*" >&2; exit 1; }

[ -f "$NFS_ENV" ] || die "missing $NFS_ENV — copy: cp ${CONF}/nfs.env.template $NFS_ENV and fill in IPs"
# shellcheck source=/dev/null
source "$NFS_ENV"

[ -f "$EXPORTS_FRAG" ] || die "missing $EXPORTS_FRAG — run: tangle-one nfs.org && loom stow:x230"

# Generate hosts fragment from env — IPs are never stored in the repo
cat > "$HOSTS_FRAG" <<EOF
# Star Fleet NFS clients — generated from nfs.env, do not edit manually
${T480S_TS_IP}   t480s
${T480_TS_IP}   t480
EOF

# Idempotent block injection: strips existing DOTCORTEX-NFS block then appends.
inject_block() {
  local target="$1" src="$2"
  local tmp
  tmp="$(mktemp)"
  if grep -qF "$MARKER_START" "$target" 2>/dev/null; then
    awk "/^${MARKER_START}$/{skip=1} !skip{print} /^${MARKER_END}$/{skip=0}" \
      "$target" > "$tmp"
  else
    cat "$target" > "$tmp" 2>/dev/null || true
  fi
  { printf '\n%s\n' "$MARKER_START"; cat "$src"; printf '%s\n' "$MARKER_END"; } >> "$tmp"
  sudo cp "$tmp" "$target"
  rm -f "$tmp"
}

echo "[1/6] Static IP: enp0s25..."
NM_CON=$(nmcli -t -f GENERAL.CONNECTION device show enp0s25 2>/dev/null | cut -d: -f2 || echo "")
if [ -n "$NM_CON" ]; then
  NM_METHOD=$(nmcli -g ipv4.method connection show "$NM_CON" 2>/dev/null || echo "")
  if [ "$NM_METHOD" != "manual" ]; then
    sudo nmcli connection modify "$NM_CON" \
      ipv4.method manual \
      ipv4.addresses "${X230_LAN_IP}/${X230_LAN_PREFIX}" \
      ipv4.gateway  "${X230_GATEWAY_IP}" \
      ipv4.dns      "${X230_DNS_IP}"
    sudo nmcli connection up "$NM_CON"
    echo "    enp0s25 set to static ${X230_LAN_IP}/${X230_LAN_PREFIX}"
  else
    echo "    already static — ok"
  fi
else
  echo "    WARNING: could not find NM connection for enp0s25 — set static IP manually"
fi

echo "[2/6] nfs-kernel-server..."
dpkg -s nfs-kernel-server &>/dev/null || sudo apt-get install -y nfs-kernel-server

# Bind-all: neutralize any out-of-band host binding so nfsd binds every
# interface. Binding the Tailscale IP made nfsd fail at boot (errno 99) before
# tailscaled brought the IP up; access control is the dotcortex_nfs firewall.
# Drift can live in /etc/default, /etc/nfs.conf, OR a /etc/nfs.conf.d/ drop-in
# (the actual culprit on X230 was /etc/nfs.conf.d/tailscale-bind.conf) — clear
# all three.
if [ -f /etc/default/nfs-kernel-server ]; then
  sudo sed -i -E 's/--host[[:space:]]+[^"[:space:]]+//g; s/[[:space:]]+"/"/g' \
    /etc/default/nfs-kernel-server
fi
if [ -f /etc/nfs.conf ]; then
  sudo sed -i -E 's/^[[:space:]]*host[[:space:]]*=.*/# host= (bind-all; DotCortex nfs.org)/' /etc/nfs.conf
fi
if [ -d /etc/nfs.conf.d ]; then
  for _f in /etc/nfs.conf.d/*.conf; do
    [ -f "$_f" ] || continue
    grep -qiE '^[[:space:]]*host[[:space:]]*=[[:space:]]*[^[:space:]]' "$_f" || continue
    echo "    bind-all: neutralizing host= in $_f"
    sudo sed -i -E 's/^[[:space:]]*host[[:space:]]*=.*/# host= removed by DotCortex (bind-all + firewall)/' "$_f"
  done
fi

echo "[3/6] /etc/hosts (client aliases)..."
inject_block /etc/hosts "$HOSTS_FRAG"

echo "[4/6] /etc/exports..."
sudo touch /etc/exports
inject_block /etc/exports "$EXPORTS_FRAG"

echo "[5/6] exportfs -ra..."
sudo exportfs -ra
sudo exportfs -v

echo "[6/6] nfs-kernel-server service..."
sudo systemctl enable nfs-kernel-server
sudo systemctl restart nfs-kernel-server   # restart so stripped /etc/default applies

echo "[+] NFS watchdog (firewall + nfs-doctor self-heal)..."
nfs-watchdog-setup || echo "WARNING: nfs-watchdog-setup failed — run it manually"

echo
echo "=== X230 NFS server ready ==="
echo "Active exports:"
sudo exportfs -v
#+END_SRC

* T480s — NFS Server+Client

T480s mounts from X230 and also serves its home to T480.

** T480s as client: host entries
Generated at runtime by =nfs-client-setup= from =nfs.env= (IPs are machine-local, not in repo).
When X230 relocates: update =X230_TS_IP= in =nfs.env= and re-run =nfs-client-setup=.
Pinning via =/etc/hosts= isolates from router DNS — mounts survive ISP or router disruption.

** T480s as client: autofs master entry
Dropped into =/etc/auto.master.d/= — does not modify =/etc/auto.master= directly.
=/- = means direct map (absolute mount paths, not relative to a parent directory).
=--ghost= keeps mount point directories visible even when unmounted.
=--timeout=0= disables auto-unmount — the share stays mounted indefinitely once
established. This prevents Thunar from showing a blank directory: with a finite
timeout, autofs unmounts after idle but keeps the ghost stub; Thunar then races
the remount and reads the directory as empty. With =timeout=0= the mount is never
released so the directory always has content after first access.

#+BEGIN_SRC text :tangle t480s/.local/share/dotcortex/nfs/nfs-direct.autofs :padline no :comments none
/- /etc/auto.direct --timeout=0 --ghost
#+END_SRC

** T480s as client: setup script
Run on T480s after =tangle-one nfs.org && loom stow:t480s=.
Safe to re-run when the server relocates or fleet changes.

#+BEGIN_SRC bash :tangle t480s/.local/bin/nfs-client-setup :shebang "#!/usr/bin/env bash"
set -euo pipefail

CONF="${HOME}/.local/share/dotcortex/nfs"
NFS_ENV="${CONF}/nfs.env"
HOSTS_FRAG="${CONF}/hosts-nfs.conf"
AUTOFS_MASTER="${CONF}/nfs-direct.autofs"
AUTOFS_DIRECT="${CONF}/auto.direct"
