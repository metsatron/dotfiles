* Purpose

Declares the three Phase 1 Distrobox sanctuaries. Each sanctuary gets its own Xephyr
display, KWin virtual desktop, DotCortex-tangled home, and a read-only bind-mount
of the host =/gnu/store=.

Sanctuaries are created with =distrobox-sanctuaries-create= (tangled below). This is a
one-shot declarative script — to recreate a sanctuary:
=distrobox rm <name> && distrobox-sanctuaries-create=.

* Phase 1A: sanctuary-qtile — Emacs Sanctuary

Stack: Guix-backed Distrobox + Qtile (Python WM) + multi-process Emacs.
Base image: TBD — candidate is a minimal Debian/Ubuntu base with Guix store projected in.
See =Guix-Package-Commons.md= for the profile composability design.

* Phase 1A: sanctuary-gnustep — GNU/NeXT Lineage Sanctuary

Stack: Window Maker + GNUstep.
Base image: TBD — candidate is Debian stable (apt-installable: =windowmaker=,
=gnustep-make=, =gnustep-base=, =gnustep-gui=).

* Phase 1B: sanctuary-cde — Motif/Sun Sanctuary

Stack: Open CDE compiled from source, pinned as git input.
Base image: TBD — needs build toolchain + Motif/X11 deps. Candidate: Debian stable.
Source: =github.com/arcfide/CDesktopEnv= or =cdesktopenv.sourceforge.io=.

* Common Infrastructure Helper

#+BEGIN_SRC bash :tangle linux/.local/bin/distrobox-room :shebang "#!/usr/bin/env bash"
# Wrapper for common distrobox room operations.
# Usage: distrobox-room <verb> [room-name]
#   verbs: list, enter, stop, create
set -euo pipefail

VERB="${1:-list}"
ROOM="${2:-}"

case "$VERB" in
  list)
    distrobox list
    ;;
  enter)
    [[ -z "$ROOM" ]] && { echo "Usage: distrobox-room enter <room-name>"; exit 1; }
    distrobox enter "$ROOM"
    ;;
  stop)
    [[ -z "$ROOM" ]] && { echo "Usage: distrobox-room stop <room-name>"; exit 1; }
    distrobox stop "$ROOM"
    ;;
  create)
    distrobox-sanctuaries-create
    ;;
  *)
    echo "Unknown verb: $VERB"
    echo "Valid verbs: list, enter, stop, create"
    exit 1
    ;;
esac
#+END_SRC
