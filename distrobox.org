* Purpose

Declares the three Phase 1 Distrobox sanctuaries. Each sanctuary gets its own Xephyr
display and dedicated host virtual desktop (Super+2/3/4). Desktop 1 is the normal host desktop.

The container distro is *Guix*. Packages come from the host =/gnu/store= bind-mounted
read-only — nothing is bundled in the container image except the Distrobox compatibility
layer. The sanctuary-specific profile (qtile, emacs, zsh, etc.) is sourced inside the
container from =~/.guix-extra-profiles/=.

Sanctuaries are created with =distrobox-sanctuaries-create= (tangled below). One-shot
declarative — to recreate: =distrobox rm <name> && distrobox-sanctuaries-create=.

* Design

#+BEGIN_SRC text :tangle no
guix pack -f docker -m sanctuary-base.scm   → tiny Guix rootfs (~50MB, compat layer only)
  ↓
podman load → sanctuary-base:guix

distrobox create --image sanctuary-base:guix
  --volume /gnu/store:/gnu/store:ro               ← host store, already built
  --volume ~/.guix-extra-profiles:ro              ← profile symlinks into host store
  ↓
launcher (host-side):
  Xephyr :90 -fullscreen
  distrobox enter sanctuary-qtile --
    . ~/.guix-extra-profiles/desktop-common/desktop-common/etc/profile
    . ~/.guix-extra-profiles/sanctuary-qtile/sanctuary-qtile/etc/profile
    exec qtile start
#+END_SRC

Packages are deduplicated by the host store — three sanctuaries sharing the same emacs
closure cost nothing extra after the first.

* Prerequisites

Before running =distrobox-sanctuaries-create=:

1. *Build Guix profiles on host*: =loom guix:sanctuary-apply= (builds desktop-common,
   sanctuary-qtile, sanctuary-gnustep, sanctuary-cde profiles)
2. *Build and load the base image*: =sanctuary-base-build=
3. *Ensure guest home dirs exist*: =vm-homes-init=

* Base Image Build

=guix pack -f docker= with only =sanctuary-base.scm= — the Distrobox compat layer.
No package content: packages come from the host store bind-mount.

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-base-build :shebang "#!/usr/bin/env bash"
# Build and load the Guix-based Distrobox base image.
# Uses sanctuary-base.scm — minimal Guix rootfs for Distrobox compatibility only.
# Actual packages (qtile, emacs, etc.) come from host /gnu/store bind-mount.
#
# guix pack produces a functional environment image with no /etc/passwd.
# This script injects a second OCI layer adding the system files that
# the OCI runtime (crun) and Distrobox need before they can start a container.
#
# Run once, and re-run if sanctuary-base.scm changes.
# Requires: guix (channel-pinned), podman, python3
set -euo pipefail

GUIX="${HOME}/.config/guix/current/bin/guix"
BASE_MANIFEST="${HOME}/.config/guix/manifests/sanctuaries/sanctuary-base.scm"

if [[ ! -f "${BASE_MANIFEST}" ]]; then
  echo "sanctuary-base-build: manifest not found at ${BASE_MANIFEST}" >&2
  exit 1
fi

echo "==> Packing Guix base image from ${BASE_MANIFEST}…"
tarball="$( "${GUIX}" pack -f docker \
  --entry-point=/bin/sh \
  -S /bin=bin \
  -m "${BASE_MANIFEST}" 2>&1 | tail -1 )"

echo "    tarball: ${tarball}"

# ---- Inject system files layer ----
# guix pack creates a functional environment with no /etc/passwd.
# crun (OCI runtime) and Distrobox both require it before the container can start.
# We add a second OCI layer with the minimal system files.

echo "==> Injecting system files layer (/etc/passwd, /etc/shadow, /etc/group, /root, /tmp)…"
WORK_DIR="$(mktemp -d)"
trap "rm -rf '${WORK_DIR}'" EXIT

tar xzf "${tarball}" -C "${WORK_DIR}"

LAYER_STAGE="${WORK_DIR}/etc-layer-stage"
mkdir -p "${LAYER_STAGE}/etc" "${LAYER_STAGE}/root" "${LAYER_STAGE}/tmp" "${LAYER_STAGE}/var/tmp"

cat > "${LAYER_STAGE}/etc/passwd" <<'PASSWDEOF'
root:x:0:0:root:/root:/bin/sh
nobody:x:65534:65534:nobody:/nonexistent:/bin/false
PASSWDEOF

cat > "${LAYER_STAGE}/etc/group" <<'GROUPEOF'
root:x:0:
nogroup:x:65534:
GROUPEOF

printf 'root:!:19000:0:99999:7:::\n' > "${LAYER_STAGE}/etc/shadow"
chmod 640 "${LAYER_STAGE}/etc/shadow"
chmod 1777 "${LAYER_STAGE}/tmp"
chmod 1777 "${LAYER_STAGE}/var/tmp"

# Distrobox-init calls `command -v <shell>` (from $SHELL on the host) before the
# guix profile bind-mounts are added to PATH.  /bin is symlinked to the guix
# profile/bin, but zsh is not in sanctuary-base.scm.  /usr/bin IS in the default
# PATH, so we add a symlink there pointing into the desktop-common profile
# (which is bind-mounted before any process runs in the container).
mkdir -p "${LAYER_STAGE}/usr/bin" "${LAYER_STAGE}/usr/sbin"
ln -s /home/metsatron/.guix-extra-profiles/desktop-common/desktop-common/bin/zsh \
  "${LAYER_STAGE}/usr/bin/zsh"

# Pre-seed /.containersetupdone so Distrobox skips the package manager block.
# Without a supported pkg manager (apt/pacman/dnf/etc), Distrobox's init exits 127.
# Guix containers get packages via /gnu/store bind-mount, not a pkg manager.
touch "${LAYER_STAGE}/.containersetupdone"

LAYER_TAR_RAW="${WORK_DIR}/sys-layer.tar"
tar -C "${LAYER_STAGE}" -cf "${LAYER_TAR_RAW}" .

DIFF_ID="sha256:$(sha256sum < "${LAYER_TAR_RAW}" | cut -d' ' -f1)"
LAYER_DIR_NAME="${DIFF_ID#sha256:}"
mkdir -p "${WORK_DIR}/${LAYER_DIR_NAME}"
cp "${LAYER_TAR_RAW}" "${WORK_DIR}/${LAYER_DIR_NAME}/layer.tar"
echo "1.0" > "${WORK_DIR}/${LAYER_DIR_NAME}/VERSION"

python3 - <<PYEOF
import json, os
d = '${WORK_DIR}'
with open(os.path.join(d, 'manifest.json')) as f:
    m = json.load(f)
m[0]['Layers'].append('${LAYER_DIR_NAME}/layer.tar')
with open(os.path.join(d, 'manifest.json'), 'w') as f:
    json.dump(m, f)
with open(os.path.join(d, 'config.json')) as f:
    c = json.load(f)
c['rootfs']['diff_ids'].append('${DIFF_ID}')
c['history'].append({
    'created': '1970-01-01T00:00:01Z',
    'created_by': 'sanctuary-base-build: inject system files',
    'comment': '/etc/passwd /etc/group /etc/shadow /root /tmp'
})
with open(os.path.join(d, 'config.json'), 'w') as f:
    json.dump(c, f)
PYEOF

echo "    diff_id: ${DIFF_ID}"

echo "==> Loading patched image into Podman as sanctuary-base:guix…"
# Capture the loaded image reference from `podman load` output (e.g. "Loaded image: repo:tag")
loaded_ref="$( tar -C "${WORK_DIR}" --exclude='etc-layer-stage' --exclude='sys-layer.tar' -cf - . \
  | podman load 2>&1 | grep 'Loaded image' | sed 's/Loaded image: //' )"
echo "    loaded: ${loaded_ref}"
image_id="$( podman images --format '{{.ID}}' --filter "reference=${loaded_ref}" | head -1 )"
[[ -z "${image_id}" ]] && image_id="$( podman images --format '{{.ID}}' | head -1 )"
podman tag "${image_id}" "sanctuary-base:guix"
echo "    tagged: sanctuary-base:guix"
echo "Done. Run distrobox-sanctuaries-create to create the sanctuaries."
#+END_SRC

* Sanctuary Create Script

#+BEGIN_SRC bash :tangle linux/.local/bin/distrobox-sanctuaries-create :shebang "#!/usr/bin/env bash"
# Create the three Phase 1 Distrobox sanctuaries.
# Run once per machine, or after `distrobox rm <name>` to recreate.
#
# Prerequisites:
#   sanctuary-base-build        ← build + load the Guix base image
#   loom guix:sanctuary-apply   ← build desktop-common + sanctuary profiles on host
#   vm-homes-init               ← ensure guest home dirs exist
set -euo pipefail

GUESTS_DIR="${XDG_DATA_HOME:-$HOME/.local/share}/dotcortex/guests"
BASE_IMAGE="sanctuary-base:guix"
GUIX_PROFILES="${HOME}/.guix-extra-profiles"

if ! podman image exists "${BASE_IMAGE}" 2>/dev/null; then
  echo "Base image ${BASE_IMAGE} not found — run sanctuary-base-build first" >&2
  exit 1
fi

# --- sanctuary-qtile: Emacs Sanctuary (Phase 1A) ---
distrobox create \
  --name sanctuary-qtile \
  --image "${BASE_IMAGE}" \
  --home "${GUESTS_DIR}/sanctuary-qtile/home" \
  --volume /gnu/store:/gnu/store:ro \
  --volume "${GUIX_PROFILES}:${GUIX_PROFILES}:ro" \
  --no-entry

#   --volume /gnu/store:/gnu/store:ro \
#   --volume "${GUIX_PROFILES}:${GUIX_PROFILES}:ro" \
#   --no-entry

# --- sanctuary-cde: Motif/Sun Sanctuary (Phase 1B) ---

#   --volume "${GUIX_PROFILES}:${GUIX_PROFILES}:ro" \
#   --no-entry

echo "distrobox-sanctuaries-create: sanctuary-qtile created"
echo "Next: sanctuary-qtile-launch (switch to Desktop 2 first, Super+2)"
#+END_SRC

* Sanctuary Launcher Scripts

Each launcher: starts Xephyr full-screen on the current host desktop, waits for the
display, then sources the Guix profiles inside the container and starts the WM.
Switch to the correct virtual desktop (Super+N) before running.

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-qtile-launch :shebang "#!/usr/bin/env bash"
# Launch sanctuary-qtile: Xephyr :90 + Qtile inside the Guix container.
# Switch to Desktop 2 (Super+2) first.
set -euo pipefail

DISPLAY_NUM=":90"
SANCTUARY="sanctuary-qtile"
GUIX_PROFILES="${HOME}/.guix-extra-profiles"

Xephyr "${DISPLAY_NUM}" -fullscreen -br -ac &
XEPHYR_PID=$!

timeout 10 sh -c "until DISPLAY=${DISPLAY_NUM} xdpyinfo >/dev/null 2>&1; do sleep 0.1; done" \
  || { echo "Xephyr ${DISPLAY_NUM} did not become ready"; kill "${XEPHYR_PID}"; exit 1; }

echo "${SANCTUARY}: Xephyr ${DISPLAY_NUM} ready — sourcing Guix profiles and starting Qtile…"
DISPLAY="${DISPLAY_NUM}" distrobox enter "${SANCTUARY}" -- sh -c "
  GUIX_PROFILE=${GUIX_PROFILES}/desktop-common/desktop-common
  . \${GUIX_PROFILE}/etc/profile
  GUIX_PROFILE=${GUIX_PROFILES}/sanctuary-qtile/sanctuary-qtile
  . \${GUIX_PROFILE}/etc/profile
  exec qtile start
"

kill "${XEPHYR_PID}" 2>/dev/null || true
#+END_SRC

* Common Infrastructure Helper

#+BEGIN_SRC bash :tangle linux/.local/bin/distrobox-room :shebang "#!/usr/bin/env bash"
# Wrapper for common distrobox sanctuary operations.
# Usage: distrobox-room <verb> [sanctuary-name]
#   verbs: list, enter, stop, create, build
set -euo pipefail

VERB="${1:-list}"
ROOM="${2:-}"

case "$VERB" in
  list)
    distrobox list
    ;;
  enter)
    [[ -z "$ROOM" ]] && { echo "Usage: distrobox-room enter <sanctuary-name>"; exit 1; }
    distrobox enter "$ROOM"
    ;;
  stop)
    [[ -z "$ROOM" ]] && { echo "Usage: distrobox-room stop <sanctuary-name>"; exit 1; }
    distrobox stop "$ROOM"
    ;;
  create)
    distrobox-sanctuaries-create
    ;;
  build)
    sanctuary-base-build
    ;;
  *)
    echo "Unknown verb: $VERB"
    echo "Valid verbs: list, enter, stop, create, build"
    exit 1
    ;;
esac
#+END_SRC
