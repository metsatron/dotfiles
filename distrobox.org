* Purpose

Declares the six Phase 1 Distrobox sanctuaries. Each sanctuary gets its own Xephyr
display and dedicated host virtual desktop (Ctrl+F2/F3/F4). Desktop 1 is the normal host desktop.

The container distro is *Guix*. Packages come from the host =/gnu/store= bind-mounted
read-only — nothing is bundled in the container image except the Distrobox compatibility
layer. The sanctuary-specific profile (qtile, emacs, zsh, etc.) is sourced inside the
container from =~/.guix-extra-profiles/=.

Sanctuaries are created with =distrobox-sanctuaries-create= (tangled below). With no
arguments it creates every missing sanctuary and skips every existing one. Pass one or
more exact sanctuary names to create only those missing containers. Removal remains a
separate, human-gated operation; this helper never removes or replaces a container.

* Design

#+BEGIN_SRC text :tangle no
guix pack -f docker -m sanctuary-base.scm   → tiny Guix rootfs (~50MB, compat layer only)
  ↓
podman load → sanctuary-base:guix

distrobox create --image sanctuary-base:guix
  --volume /gnu/store:/gnu/store:ro               ← host store, already built
  --volume ~/.guix-extra-profiles:ro              ← profile symlinks into host store
  ↓
launcher (host-side):
  Xephyr :90 -fullscreen
  distrobox enter sanctuary-qtile --
    . ~/.guix-extra-profiles/desktop-common/desktop-common/etc/profile
    . ~/.guix-extra-profiles/sanctuary-qtile/sanctuary-qtile/etc/profile
    exec qtile start
#+END_SRC

Packages are deduplicated by the host store — three sanctuaries sharing the same emacs
closure cost nothing extra after the first.

* Base Image Build

=guix pack -f docker= with only =sanctuary-base.scm= — the Distrobox compat layer.
No package content: packages come from the host store bind-mount.

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-base-build :shebang "#!/usr/bin/env bash"
# Build and load the Guix-based Distrobox base image.
# Uses sanctuary-base.scm — minimal Guix rootfs for Distrobox compatibility only.
# Actual packages (qtile, emacs, etc.) come from host /gnu/store bind-mount.
#
# guix pack produces a functional environment image with no /etc/passwd.
# This script injects a second OCI layer adding the system files and completion
# markers that the OCI runtime (crun) and Distrobox need before they can start a
# container.
#
# Run once, and re-run if sanctuary-base.scm changes.
# Requires: guix (channel-pinned), podman, python3
set -euo pipefail

usage() {
  cat <<EOF
sanctuary-base-build - build and load the Guix-based Distrobox base image

Usage: sanctuary-base-build
       sanctuary-base-build -h | --help

No arguments. Requires the channel-pinned Guix profile, Podman, and Python 3.
Builds sanctuary-base:guix, including the minimal OCI system-files layer.
EOF
}

if [[ "${1:-}" == "-h" || "${1:-}" == "--help" ]]; then
  usage
  exit 0
fi

if (( $# > 0 )); then
  usage >&2
  exit 1
fi

GUIX="${HOME}/.config/guix/current/bin/guix"
BASE_MANIFEST="${HOME}/.config/guix/manifests/sanctuaries/sanctuary-base.scm"

if [[ ! -f "${BASE_MANIFEST}" ]]; then
  echo "sanctuary-base-build: manifest not found at ${BASE_MANIFEST}" >&2
  exit 1
fi

echo "==> Packing Guix base image from ${BASE_MANIFEST}…"
tarball="$( "${GUIX}" pack -f docker \
  --entry-point=/bin/sh \
  -S /bin=bin \
  -m "${BASE_MANIFEST}" 2>&1 | tail -1 )"

echo "    tarball: ${tarball}"

# ---- Inject system files layer ----
# guix pack creates a functional environment with no /etc/passwd.
# crun (OCI runtime) and Distrobox both require it before the container can start.
# We add a second OCI layer with the minimal system files.

echo "==> Injecting system files layer (/etc/passwd, /etc/shadow, /etc/group, /etc/passwd.done, /root, /tmp)…"
WORK_DIR="$(mktemp -d)"
trap "rm -rf '${WORK_DIR}'" EXIT

tar xzf "${tarball}" -C "${WORK_DIR}"

LAYER_STAGE="${WORK_DIR}/etc-layer-stage"
mkdir -p "${LAYER_STAGE}/etc" "${LAYER_STAGE}/root" "${LAYER_STAGE}/tmp" "${LAYER_STAGE}/var/tmp"

cat > "${LAYER_STAGE}/etc/passwd" <<'PASSWDEOF'
root:x:0:0:root:/root:/bin/sh
nobody:x:65534:65534:nobody:/nonexistent:/bin/false
PASSWDEOF

cat > "${LAYER_STAGE}/etc/group" <<'GROUPEOF'
root:x:0:
nogroup:x:65534:
GROUPEOF

printf 'root:!:19000:0:99999:7:::\n' > "${LAYER_STAGE}/etc/shadow"
chmod 640 "${LAYER_STAGE}/etc/shadow"
chmod 1777 "${LAYER_STAGE}/tmp"
chmod 1777 "${LAYER_STAGE}/var/tmp"

# Distrobox-init calls `command -v <shell>` (from $SHELL on the host) before the
# guix profile bind-mounts are added to PATH.  /bin is symlinked to the guix
# profile/bin, but zsh is not in sanctuary-base.scm.  /usr/bin IS in the default
# PATH, so we add a symlink there pointing into the desktop-common profile
# (which is bind-mounted before any process runs in the container).
mkdir -p "${LAYER_STAGE}/usr/bin" "${LAYER_STAGE}/usr/sbin"
ln -s /home/metsatron/.guix-extra-profiles/desktop-common/desktop-common/bin/zsh \
  "${LAYER_STAGE}/usr/bin/zsh"

# Pre-seed /.containersetupdone so Distrobox skips the package manager block.
# Without a supported pkg manager (apt/pacman/dnf/etc), Distrobox's init exits 127.
# Guix containers get packages via /gnu/store bind-mount, not a pkg manager.
touch "${LAYER_STAGE}/.containersetupdone"

# Pre-seed /etc/passwd.done so upstream distrobox-init skips its one-time
# passwd/chpasswd normalization block.  Podman's keep-id setup has already
# injected the current user with the requested UID, GID, home and shell before
# the entrypoint runs.  The Guix shadow tools cannot complete that block as the
# unprivileged keep-id user: passwd is PAM-linked while this minimal image has no
# passwd PAM service, and chpasswd -e cannot open the account databases.  The
# marker is distrobox-init's own guard for an already-provisioned account; group
# setup, home validation, sudo setup and the rest of init still run normally.
touch "${LAYER_STAGE}/etc/passwd.done"

LAYER_TAR_RAW="${WORK_DIR}/sys-layer.tar"
tar -C "${LAYER_STAGE}" -cf "${LAYER_TAR_RAW}" .

DIFF_ID="sha256:$(sha256sum < "${LAYER_TAR_RAW}" | cut -d' ' -f1)"
LAYER_DIR_NAME="${DIFF_ID#sha256:}"
mkdir -p "${WORK_DIR}/${LAYER_DIR_NAME}"
cp "${LAYER_TAR_RAW}" "${WORK_DIR}/${LAYER_DIR_NAME}/layer.tar"
echo "1.0" > "${WORK_DIR}/${LAYER_DIR_NAME}/VERSION"

python3 - <<PYEOF
import json, os
d = '${WORK_DIR}'
with open(os.path.join(d, 'manifest.json')) as f:
    m = json.load(f)
m[0]['Layers'].append('${LAYER_DIR_NAME}/layer.tar')
with open(os.path.join(d, 'manifest.json'), 'w') as f:
    json.dump(m, f)
with open(os.path.join(d, 'config.json')) as f:
    c = json.load(f)
c['rootfs']['diff_ids'].append('${DIFF_ID}')
c['history'].append({
    'created': '1970-01-01T00:00:01Z',
    'created_by': 'sanctuary-base-build: inject system files',
    'comment': '/etc/passwd /etc/group /etc/shadow /etc/passwd.done /.containersetupdone /root /tmp'
})
with open(os.path.join(d, 'config.json'), 'w') as f:
    json.dump(c, f)
PYEOF

echo "    diff_id: ${DIFF_ID}"

echo "==> Loading patched image into Podman as sanctuary-base:guix…"
# Capture the loaded image reference from `podman load` output (e.g. "Loaded image: repo:tag")
loaded_ref="$( tar -C "${WORK_DIR}" --exclude='etc-layer-stage' --exclude='sys-layer.tar' -cf - . \
  | podman load 2>&1 | grep 'Loaded image' | sed 's/Loaded image: //' )"
echo "    loaded: ${loaded_ref}"
# Tag the exact reference returned by `podman load`.  Podman 5.4's default
# `images --format {{.ID}}` output is truncated and is not accepted by `tag`.
podman tag "${loaded_ref}" "sanctuary-base:guix"
echo "    tagged: sanctuary-base:guix"
echo "Done. Run distrobox-sanctuaries-create to create the sanctuaries."
#+END_SRC

* Sanctuary Create Script

#+BEGIN_SRC bash :tangle linux/.local/bin/distrobox-sanctuaries-create :shebang "#!/usr/bin/env bash"
# Create missing Phase 1 Distrobox sanctuaries, optionally by exact name.
# This helper NEVER removes or replaces an existing container.
#
# Prerequisites:
#   sanctuary-base-build        ← build + load the Guix base image
#   loom guix:sanctuary-apply   ← build desktop-common + sanctuary profiles on host
#   vm-homes-init               ← ensure guest home dirs exist
set -euo pipefail

usage() {
  cat <<EOF
distrobox-sanctuaries-create - create the six Phase 1 Distrobox sanctuaries

Usage: distrobox-sanctuaries-create [SANCTUARY...]
       distrobox-sanctuaries-create -h | --help

With no names, creates all missing sanctuaries. With names, creates only those
missing sanctuaries. Existing containers are always skipped and are never
removed or replaced.

Known names:
  sanctuary-qtile
  sanctuary-gnustep
  sanctuary-cde
  sanctuary-redstone-9x
  sanctuary-sx
  sanctuary-retropie

Requires sanctuary-base:guix, the relevant Guix profiles, and guest homes to
have been prepared first.
EOF
}

if [[ "${1:-}" == "-h" || "${1:-}" == "--help" ]]; then
  usage
  exit 0
fi

GUESTS_DIR="${XDG_DATA_HOME:-$HOME/.local/share}/dotcortex/guests"
BASE_IMAGE="sanctuary-base:guix"
GUIX_PROFILES="${HOME}/.guix-extra-profiles"
CDE_PROFILE="${GUIX_PROFILES}/sanctuary-cde/sanctuary-cde"
CDE_RUNTIME="${HOME}/.config/virtualisation/sanctuary-cde"
DISTROBOX_BIN="/usr/bin/distrobox"
RETROPIE_CONTAINER_ROOT="/run/dotcortex/retropie"
RETROPIE_SOURCE=""

ALL_SANCTUARIES=(
  sanctuary-qtile
  sanctuary-gnustep
  sanctuary-cde
  sanctuary-redstone-9x
  sanctuary-sx
  sanctuary-retropie
)

# NOTE 2026-07-08: the GVFS host-trash leak (R9X-URGENT) is now fixed at
# LAUNCH by sanctuary-trash-shield, not at create time. The former
# create-time FLEET_TRASH_SHADOW flags were both mis-targeted (they shadowed
# each mount's .local/share/Trash, but gvfs reads a foreign mount's topdir
# trash $topdir/.Trash-$uid — a different path it never touched) and
# structurally too weak (you cannot pre-shadow a child of an autofs mount
# that is not mounted yet, and the flags only take effect on a full
# container recreate). sanctuary-trash-shield instead runs inside the
# already-running container's isolated mount namespace at each launch:
# make-rprivate the passthrough parents, then tmpfs-mask the whole ~/mnt
# tree via both reachable paths. It needs no recreation, is re-trigger-proof
# against autofs, and covers new fleet machines automatically. See the
# sanctuary-trash-shield block above and redstone-9x-state-digest.md.

for helper in \
  "${DISTROBOX_BIN}" \
  /usr/bin/distrobox-create \
  /usr/bin/distrobox-init \
  /usr/bin/distrobox-export \
  /usr/bin/distrobox-host-exec
do
  if [[ ! -x "${helper}" ]]; then
    echo "Required system Distrobox helper missing: ${helper}" >&2
    exit 1
  fi
done

if ! podman image exists "${BASE_IMAGE}" 2>/dev/null; then
  echo "Base image ${BASE_IMAGE} not found — run sanctuary-base-build first" >&2
  exit 1
fi

EXISTING_CONTAINERS="$(podman ps -a --format '{{.Names}}')" || {
  echo "Could not list existing Podman containers; refusing to create anything" >&2
  exit 1
}

container_exists() {
  grep -Fxq -- "$1" <<<"${EXISTING_CONTAINERS}"
}

validate_name() {
  case "$1" in
    sanctuary-qtile|sanctuary-gnustep|sanctuary-cde|sanctuary-redstone-9x|sanctuary-sx|sanctuary-retropie)
      return 0 ;;
    *)
      echo "Unknown sanctuary name: $1" >&2
      usage >&2
      return 2 ;;
  esac
}

resolve_retropie_source() {
  [[ -n "${RETROPIE_SOURCE}" ]] && return 0

  local logical_root="${HOME}/RetroPie"
  local ports_dir="${logical_root}/roms/ports"

  # stat -L both follows ~/RetroPie and triggers the direct autofs mount before
  # readlink resolves it. The active NFS and autofs mounts are private on this
  # host, so rslave/rshared cannot propagate a later submount into a container.
  # Binding the resolved, already-mounted NFS subtree directly avoids depending
  # on propagation and pins that mounted subtree for the container lifetime.
  if ! stat -L -- "${ports_dir}" >/dev/null 2>&1; then
    echo "RetroPie tree unavailable: ${ports_dir}" >&2
    echo "The automount did not produce a readable ports directory; refusing to create a gaming sanctuary" >&2
    exit 1
  fi

  RETROPIE_SOURCE="$(readlink -f -- "${logical_root}")" || {
    echo "Could not resolve RetroPie source: ${logical_root}" >&2
    exit 1
  }
  if [[ ! -d "${RETROPIE_SOURCE}/roms/ports" ]]; then
    echo "Resolved RetroPie source has no ports directory: ${RETROPIE_SOURCE}" >&2
    exit 1
  fi
  echo "RetroPie bind source: ${RETROPIE_SOURCE} -> ${RETROPIE_CONTAINER_ROOT} (read-only)"
}

check_cde_resources() {
  local resource
  for resource in \
    "${CDE_PROFILE}/etc/netconfig" \
    "${CDE_PROFILE}/etc/rpc" \
    "${CDE_PROFILE}/etc/services" \
    "${CDE_PROFILE}/bin/hostname" \
    "${CDE_PROFILE}/bin/awk" \
    "${CDE_RUNTIME}/nawk" \
    "${CDE_PROFILE}/bin/xset" \
    "${CDE_RUNTIME}/nsswitch.conf"
  do
    if [[ ! -e "${resource}" ]]; then
      echo "sanctuary-cde runtime resource missing: ${resource}" >&2
      echo "Run 'loom guix:sanctuary-apply' and 'loom stow:t480s' first" >&2
      exit 1
    fi
  done
}

create_common() {
  local name="$1"
  shift
  "${DISTROBOX_BIN}" create \
    --name "${name}" \
    --image "${BASE_IMAGE}" \
    --home "${GUESTS_DIR}/${name}/home" \
    --volume /gnu/store:/gnu/store:ro \
    --volume "${GUIX_PROFILES}:${GUIX_PROFILES}:ro" \
    "$@" \
    --no-entry
}

preflight_one() {
  case "$1" in
    sanctuary-cde)
      check_cde_resources
      ;;
    sanctuary-redstone-9x|sanctuary-retropie)
      resolve_retropie_source
      ;;
  esac
}

create_one() {
  local name="$1"

  case "${name}" in
    sanctuary-qtile|sanctuary-gnustep|sanctuary-sx)
      create_common "${name}"
      ;;
    sanctuary-cde)
      create_common "${name}" \
        --volume "${CDE_PROFILE}/etc/netconfig:/etc/netconfig:ro" \
        --volume "${CDE_PROFILE}/etc/rpc:/etc/rpc:ro" \
        --volume "${CDE_PROFILE}/etc/services:/etc/services:ro" \
        --volume "${CDE_RUNTIME}/nsswitch.conf:/etc/nsswitch.conf:ro" \
        --volume "${CDE_PROFILE}/bin/hostname:/usr/bin/hostname:ro" \
        --volume "${CDE_PROFILE}/bin/awk:/usr/bin/awk:ro" \
        --volume "${CDE_RUNTIME}/nawk:/usr/bin/nawk:ro" \
        --volume "${CDE_PROFILE}/bin/xset:/usr/bin/xset:ro"
      ;;
    sanctuary-redstone-9x)
      create_common "${name}" \
        --volume "${RETROPIE_SOURCE}:${RETROPIE_CONTAINER_ROOT}:ro" \
        --init-hooks 'mkdir -p /opt/retropie/supplementary/runcommand && ln -sfn /home/metsatron/.local/bin/runcommand-shim /opt/retropie/supplementary/runcommand/runcommand.sh'
      ;;
    sanctuary-retropie)
      create_common "${name}" \
        --volume "${RETROPIE_SOURCE}:${RETROPIE_CONTAINER_ROOT}:ro"
      ;;
  esac
}

if (( $# == 0 )); then
  REQUESTED=("${ALL_SANCTUARIES[@]}")
else
  REQUESTED=("$@")
fi

declare -A SEEN=()
TO_CREATE=()
for sanctuary in "${REQUESTED[@]}"; do
  validate_name "${sanctuary}" || exit $?
  if [[ -n "${SEEN[${sanctuary}]+present}" ]]; then
    continue
  fi
  SEEN["${sanctuary}"]=1

  if container_exists "${sanctuary}"; then
    echo "distrobox-sanctuaries-create: ${sanctuary} already exists — skipping"
    continue
  fi

  TO_CREATE+=("${sanctuary}")
done

for sanctuary in "${TO_CREATE[@]}"; do
  preflight_one "${sanctuary}"
done

CREATED=()
for sanctuary in "${TO_CREATE[@]}"; do
  echo "distrobox-sanctuaries-create: creating ${sanctuary}"
  create_one "${sanctuary}"
  CREATED+=("${sanctuary}")
done

if (( ${#CREATED[@]} == 0 )); then
  echo "distrobox-sanctuaries-create: nothing created"
else
  printf 'distrobox-sanctuaries-create: created %s\n' "${CREATED[*]}"
fi
#+END_SRC

* Sanctuary Launcher Scripts

Each launcher starts Xephyr full-screen on the current host desktop, waits for
the display, then sources the Guix profiles inside the container and starts the
selected WM/session.

All entries go through =sanctuary-enter=. Distrobox 1.8.2.4 copies almost every host
environment variable into =podman exec --env= arguments; the helper starts Distrobox
under =env -i= and restores only the variables required for identity, locale, display,
session D-Bus, and audio. API keys and agent sockets must never cross this boundary.

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-enter :shebang "#!/usr/bin/env bash"
# Select and launch a tested graphical habitat profile.
# Usage: sanctuary-enter [profile-id]
#
# Desktop skews: each sanctuary may declare multiple desktop options.
# Add entries below as new desktops are validated.
# Key: sanctuary-name (as it appears in distrobox list)
# Value: space-separated list of desktop identifiers for that sanctuary.
# The first deskop listed is the default (used when no :desktop suffix is given).
declare -A SANCTUARY_DESKTOPS=(
  ["sanctuary-redstone-9x"]="icewm fvwm95"
  ["sanctuary-cde"]="cde"
  ["sanctuary-sx"]="xfce4"
  ["sanctuary-gnustep"]="wmaker"
  ["sanctuary-qtile"]="qtile"
  ["sanctuary-retropie"]="emulationstation"
)

usage() {
  cat <<EOF
sanctuary-enter - select and launch a tested graphical habitat profile

Usage:
  sanctuary-enter                       Interactive fzf picker over available sanctuaries
  sanctuary-enter <sanctuary-name>[:desktop]
  sanctuary-enter -h | --help

With no argument, discovers sanctuaries via 'distrobox list', cross-references
the desktop skews declared below, and offers an fzf menu
(Alt-e down, Alt-i up, Alt-o enter, Alt-n cancel). A bare sanctuary name
launches its first/default desktop; append ':desktop' to pick another.

Known sanctuaries and their desktop skews:
$(for _s in "${!SANCTUARY_DESKTOPS[@]}"; do printf '  %-22s %s\n' "${_s}" "${SANCTUARY_DESKTOPS[${_s}]}"; done | sort)

For a plain shell instead of a graphical session: distrobox-room enter <sanctuary-name>
EOF
}

if [[ "${1:-}" == "-h" || "${1:-}" == "--help" ]]; then
  usage
  exit 0
fi

set -euo pipefail

if (( $# > 1 )); then
  echo "Usage: sanctuary-enter [sanctuary-name[:desktop]]" >&2
  echo "For a shell: distrobox-room enter <sanctuary-name>" >&2
  exit 2
fi

if (( $# == 1 )); then
  PROFILE="$1"
else
  DISTROBOX_BIN="$(command -v distrobox)" \
    || { echo "sanctuary-enter: distrobox not found" >&2; exit 127; }
  FZF_BIN="$(command -v fzf)" \
    || { echo "sanctuary-enter: fzf not found" >&2; exit 127; }

  # Discover sanctuaries from distrobox list.
  AVAILABLE_SANCTUARIES="$(
    "${DISTROBOX_BIN}" list --no-color | awk -F '|' '
      NR > 1 {
        name = $2
        gsub(/^[[:space:]]+|[[:space:]]+$/, "", name)
        print name
      }
    '
  )"

  # Build fzf menu: for each discovered sanctuary that has a declared desktop
  # skew and a matching launcher script, emit one menu line per desktop.
  PROFILES=""
  while IFS= read -r SANCTUARY; do
    DESKTOPS="${SANCTUARY_DESKTOPS[${SANCTUARY}]:-}"
    if [[ -z "${DESKTOPS}" ]]; then
      continue
    fi
    # Verify launcher script exists.
    LAUNCHER_NAME="${SANCTUARY}-launch"
    if ! command -v "${LAUNCHER_NAME}" >/dev/null 2>&1; then
      continue
    fi
    for DESKTOP in ${DESKTOPS}; do
      PROFILES="${PROFILES}${SANCTUARY}:${DESKTOP}"$'\n'
    done
  done <<< "${AVAILABLE_SANCTUARIES}"

  if [[ -z "${PROFILES}" ]]; then
    echo "sanctuary-enter: no available sanctuaries" >&2
    exit 1
  fi

  PROFILE="$(
    printf '%s\n' "${PROFILES}" \
      | "${FZF_BIN}" \
          --prompt='habitat> ' \
          --height=40% \
          --layout=reverse \
          --border \
          --header='Alt-e down · Alt-i up · Alt-o enter · Alt-n cancel' \
          --bind='alt-e:down,alt-i:up,alt-o:accept,alt-n:abort'
  )" || exit 130
fi

# Resolve PROFILE (sanctuary-name:desktop) into a launcher script.
# A bare sanctuary-name (no colon) uses the first/only declared desktop.
SANCTUARY_NAME="${PROFILE%%:*}"

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-teardown-stale-session :shebang "#!/usr/bin/env bash" :tangle-mode (identity #o755)
# Kill any surviving session from a prior launch of a sanctuary before
# starting a fresh one. `podman kill`/`podman restart` on the container
# alone is NOT sufficient — confirmed 2026-07-07: a full prior XFCE desktop
# session (distrobox enter, podman exec, thunar, xfdesktop, gvfsd-trash,
# xfce4-session) survived a full container restart and kept running
# alongside a freshly launched session, invisibly, until killed by exact
# PID. Distrobox's `podman exec` desktop sessions are apparently not torn
# down by cycling the container's own main process. This also matters for
# correctness beyond hygiene: two live sessions can share D-Bus/gvfs state
# in ways that make later diagnosis (or even normal use) unreliable.
# Usage: sanctuary-teardown-stale-session <sanctuary-name> <display-num>
set -uo pipefail

SANCTUARY="${1:?sanctuary name required}"
DISPLAY_NUM="${2:?display num required, e.g. :93}"

# Kill any leftover distrobox-enter wrapper and podman-exec session tied to
# this sanctuary from a prior launch. pgrep/pkill exclude their own PID by
# default, so this is safe to run even though the pattern text below also
# appears later in this same script's own distrobox/podman invocations.
pkill -f "distrobox enter ${SANCTUARY} --" 2>/dev/null || true
pkill -f "podman exec .*${SANCTUARY} sh -c" 2>/dev/null || true

# Kill any stale Xephyr still bound to this display from a prior launch.
stale_xephyr="$(pgrep -f "^Xephyr ${DISPLAY_NUM} " | head -1 || true)"
if [[ -n "${stale_xephyr}" ]]; then
  echo "${SANCTUARY}: killing stale Xephyr ${DISPLAY_NUM} (pid ${stale_xephyr})"
  kill "${stale_xephyr}" 2>/dev/null || true
fi

sleep 1
rm -f "/tmp/.X${DISPLAY_NUM#:}-lock"
exit 0

# sanctuary-trash-shield helper.
# Isolate a sanctuary's =trash:///= from the host's fleet NFS mounts.

Root cause (confirmed live 2026-07-08): Distrobox bind-mounts the host home at
=/home/<user>= *and* passes the host root recursively at =/run/host=, so the
host's autofs fleet NFS mounts (=~/mnt/x230=, =~/mnt/t480=, …) surface *inside*
the container's own mount namespace as real mount points — via *both* paths.
GVFS's trash aggregator (=gvfsd-trash=) walks every visible mount point looking
for =$topdir/.Trash-$uid=, so it merged those remote machines' trash into the
sandboxed room's =trash:///= (measured historically: 392 entries = 68 local +
324 leaked from the host's real =~/mnt/x230/.Trash-1000=).

The fix runs at launch *inside* the container's mount namespace, which is
isolated from the host — verified live: every op below leaves the host mount
table untouched. It makes the two passthrough parents =rprivate= (a
propagation-*type* change, which by Linux mount semantics sends no events to
peers, so it cannot affect the host) then tmpfs-masks the whole =~/mnt= tree via
both reachable paths. A tmpfs over =~/mnt= makes every fleet mount underneath
unreachable (=ENOENT= on path resolution), so =gvfsd-trash= finds only the
guest-home trash — exactly what a sandbox should have. It is *re-trigger-proof*
against autofs (masks *over* the mounts rather than unmounting them, which a
live desktop session instantly re-triggers) and *future-proof* (masks the
parent, so a new fleet machine is covered with no code change). The rooms do not
need =~/mnt= — the only reader is the GE-Proton font fallback, which degrades
gracefully when the NFS is absent (see =redstone-9x-font-provision=).

This never removes or recreates the container; it only adds mounts inside the
running container's namespace, and it is idempotent (re-masking an already-masked
path is skipped).

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-trash-shield :shebang "#!/usr/bin/env bash" :tangle-mode (identity #o755)
# Shield a sanctuary's trash:/// from the host fleet NFS mounts. See the org
# prose above for the full mechanism.
#
# IMPORTANT — why podman exec and NOT distrobox enter / sanctuary-exec:
# both join the SAME container mount namespace (verified), so masks applied
# by either are seen by the desktop session a later distrobox enter starts.
# BUT distrobox enter drops ALL effective capabilities (it runs as the plain
# login user: CapEff=0), so mount(2) fails with EPERM. podman exec keeps the
# container's CAP_SYS_ADMIN (CapEff=all), so it can mount. We therefore apply
# the shield via podman exec, and it still persists for the enter-started
# session because the namespace is shared.
#
# Usage: sanctuary-trash-shield <sanctuary-name> <host-home-dir>
#   <host-home-dir> is the LAUNCHER's $HOME (the host home path at which
#   distrobox bind-mounts the real home inside the container, e.g. /home/user).
set -uo pipefail

SANCTUARY="${1:?sanctuary name required}"
HOST_HOME="${2:?host home dir required (the launcher HOME dir)}"

PODMAN_BIN="$(command -v podman 2>/dev/null || true)"
if [[ -z "${PODMAN_BIN}" ]]; then
  echo "sanctuary-trash-shield: podman not found — cannot shield ${SANCTUARY}" >&2
  exit 0
fi

# The container's home bind and /run/host passthrough (and the fleet mounts
# propagated through them) exist only once it is running. Ensure it is up;
# idempotent no-op if already running.
"${PODMAN_BIN}" start "${SANCTUARY}" >/dev/null 2>&1 || true

# The inner script receives HOST_HOME as $1 (avoids quoting it into the body).
"${PODMAN_BIN}" exec "${SANCTUARY}" sh -c '
  set -u
  host_home="$1"
  # 1. Detach the two passthrough parents from the host peer group so no mask
  #    below can propagate back to the host. Type change only — non-propagating.
  mount --make-rprivate "$host_home"  2>/dev/null || true
  mount --make-rprivate /run/host     2>/dev/null || true
  # 2. tmpfs-mask the fleet mount tree via both reachable paths. Every fleet
  #    mount underneath becomes unreachable, so gvfsd-trash sees no foreign
  #    trash — only the guest home trash ($XDG_DATA_HOME/Trash).
  for d in "$host_home/mnt" "/run/host$host_home/mnt"; do
    [ -d "$d" ] || continue
    # Idempotent: skip if already masked with a tmpfs.
    [ "$(stat -f -c %T "$d" 2>/dev/null)" = tmpfs ] && continue
    if mount -t tmpfs tmpfs "$d" 2>/dev/null; then
      echo "sanctuary-trash-shield: masked $d"
    else
      echo "sanctuary-trash-shield: WARNING could not mask $d (continuing)" >&2
    fi
  done
' sanctuary-trash-shield "${HOST_HOME}" 2>&1 || true
exit 0
#+END_SRC

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-clip-bridge :shebang "#!/usr/bin/env bash"
# Bidirectional CLIPBOARD bridge between host and a Xephyr guest display.
# Usage: sanctuary-clip-bridge <host-display> <guest-display>
# Polls every 300 ms; exits cleanly when the guest display becomes unavailable.
set -euo pipefail
HOST_DISPLAY="${1:-:0}"
GUEST_DISPLAY="${2:-:94}"
last_synced=""
while DISPLAY="${GUEST_DISPLAY}" xdpyinfo >/dev/null 2>&1; do
  guest=$(timeout 1 xclip -display "${GUEST_DISPLAY}" -selection clipboard -o 2>/dev/null || true)
  host=$(timeout 1 xclip -display "${HOST_DISPLAY}" -selection clipboard -o 2>/dev/null || true)
  guest_hash=$(printf '%s' "${guest}" | md5sum | cut -d' ' -f1)
  host_hash=$(printf '%s' "${host}" | md5sum | cut -d' ' -f1)
  if [[ -n "${guest}" && "${guest_hash}" != "${last_synced}" && "${guest_hash}" != "${host_hash}" ]]; then
    printf '%s' "${guest}" | timeout 1 xclip -display "${HOST_DISPLAY}" -selection clipboard -i 2>/dev/null || true
    last_synced="${guest_hash}"
  elif [[ -n "${host}" && "${host_hash}" != "${last_synced}" && "${host_hash}" != "${guest_hash}" ]]; then
    printf '%s' "${host}" | timeout 1 xclip -display "${GUEST_DISPLAY}" -selection clipboard -i 2>/dev/null || true
    last_synced="${host_hash}"
  fi
  sleep 0.3
done
#+END_SRC

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-cde-stop :shebang "#!/usr/bin/env bash"
# Terminate the running sanctuary-cde Xephyr session from any host terminal.
# Reads PID from $XDG_RUNTIME_DIR/dotcortex/sanctuary-cde.pid written by
# sanctuary-cde-launch. Validates ownership and process identity before
# sending SIGTERM. Never uses pkill or broad process-name matching.

STATE_FILE="${DOTCORTEX_RUN}/sanctuary-cde.pid"

  echo "sanctuary-cde-stop: no active session (${STATE_FILE} not found)" >&2
  exit 1
fi

PID="$(grep '^PID=' "${STATE_FILE}" | cut -d= -f2)"
DISP="$(grep '^DISPLAY=' "${STATE_FILE}" | cut -d= -f2)"

if [[ -z "${PID}" ]]; then
  echo "sanctuary-cde-stop: malformed state file — no PID entry" >&2
  exit 1

PROC_UID="$(ps -p "${PID}" -o uid= 2>/dev/null | tr -d ' ' || true)"
PROC_COMM="$(ps -p "${PID}" -o comm= 2>/dev/null | tr -d ' ' || true)"

if [[ -z "${PROC_UID}" ]]; then
  echo "sanctuary-cde-stop: PID ${PID} not found — session already gone"
  rm -f "${STATE_FILE}"
  exit 0
fi

if [[ "${PROC_UID}" != "$(id -u)" ]]; then
  echo "sanctuary-cde-stop: PID ${PID} is owned by UID ${PROC_UID}, not $(id -u) — refusing" >&2
  exit 1

#+BEGIN_SRC python :tangle linux/.local/bin/sanctuary-cde-extension-import :shebang "#!/usr/bin/env python3" :tangle-mode (identity #o755)
import os
import re
import shutil
import struct
import sys
import tempfile
import zipfile
from pathlib import Path


def die(message: str, code: int = 1) -> None:
    print(f"sanctuary-cde-extension-import: {message}", file=sys.stderr)
    raise SystemExit(code)


def safe_name(value: str) -> str:
    name = re.sub(r"[^A-Za-z0-9._-]+", "-", value).strip(".-")
    return name or "extension"


def zip_start(path: Path) -> int:
    with path.open("rb") as fh:
        header = fh.read(16)
    if header.startswith(b"PK\x03\x04"):
        return 0
    if not header.startswith(b"Cr24") or len(header) < 12:
        die("input is neither ZIP nor CRX")
    version = struct.unpack("<I", header[4:8])[0]
    if version == 2:
        pub_len, sig_len = struct.unpack("<II", header[8:16])
        return 16 + pub_len + sig_len
    if version == 3:
        header_len = struct.unpack("<I", header[8:12])[0]
        return 12 + header_len
    die(f"unsupported CRX version: {version}")


def extract_zip_payload(path: Path, destination: Path) -> None:
    start = zip_start(path)
    with path.open("rb") as fh:
        fh.seek(start)
        payload = fh.read()
    tmp_zip = destination / ".payload.zip"
    tmp_zip.write_bytes(payload)
    with zipfile.ZipFile(tmp_zip) as archive:
        for member in archive.infolist():
            target = (destination / member.filename).resolve()
            if destination.resolve() not in [target, *target.parents]:
                die(f"archive path traversal rejected: {member.filename}")
        archive.extractall(destination)
    tmp_zip.unlink()


def find_unpacked_root(path: Path) -> Path:
    root_manifest = path / "manifest.json"
    if root_manifest.is_file():
        return path
    manifests = [p for p in path.rglob("manifest.json") if p.is_file()]
    if len(manifests) == 1:
        return manifests[0].parent
    if not manifests:
        die("no manifest.json found")
    die("multiple manifest.json files found; pass the intended unpacked directory")


def copy_tree(src: Path, dst: Path) -> None:
    if dst.exists():
        shutil.rmtree(dst)
    ignore = shutil.ignore_patterns(
        "Cookies*",
        "Login Data*",
        "History*",
        "Preferences",
        "Secure Preferences",
        "Local State",
        "Cache",
        "Code Cache",
        "Session Storage",
        "Local Storage",
        "IndexedDB",
    )
    shutil.copytree(src, dst, symlinks=False, ignore=ignore)


def main() -> None:
    if len(sys.argv) not in (2, 3):
        die("usage: sanctuary-cde-extension-import <unpacked-dir|extension.crx|extension.zip> [shelf-name]", 2)

    source = Path(sys.argv[1]).expanduser().resolve()
    if not source.exists():
        die(f"source not found: {source}")

    guest_home = Path(os.environ.get("HOME", "")).expanduser()
    if not guest_home or not guest_home.is_dir():
        die("HOME is not a directory")
    shelf = guest_home / ".local/share/cde/extensions/chromium"
    shelf.mkdir(parents=True, exist_ok=True)

    explicit_name = sys.argv[2] if len(sys.argv) == 3 else None
    if source.is_dir():
        unpacked = find_unpacked_root(source)
        name = safe_name(explicit_name or f"{source.parent.name}-{source.name}")
        target = shelf / name
        copy_tree(unpacked, target)
    else:
        with tempfile.TemporaryDirectory(prefix="sanctuary-cde-extension-") as tmp:
            tmp_path = Path(tmp)
            extract_zip_payload(source, tmp_path)
            unpacked = find_unpacked_root(tmp_path)
            name = safe_name(explicit_name or source.stem)
            target = shelf / name
            copy_tree(unpacked, target)

    if not (target / "manifest.json").is_file():
        die("import failed: target has no manifest.json")
    print(target)


if __name__ == "__main__":
    main()
#+END_SRC

** Xclass + Explorer + Desktop build

Builds the rn10950 [[https://github.com/rn10950/FVWM95-Updated][FVWM95-Updated]] xclass library, the =Explorer= file
manager, and the =Desktop= manager, inside the sanctuary using the
=room-fvwm95= Guix profile. All source patches are applied reproducibly via
python3 string replacement (never hand-edited under =$HOME=), so this script is
the single source of truth for the xclass toolchain.

Patches applied:

1. *GCC 16 =min=/=max= templates* (utils.h): replace the broken two-argument
   =auto ... decltype= template with single-argument =template<T> T max(T,T)=
   plus mixed-type overloads (int/unsigned/short pairs) and =abs(unsigned)=
   overloads. The two-arg =max(0,1)= silently returned 0 on GCC 16, breaking
   xclass =max(w,1)= window-dimension clamps (all X window creation failed
   with =BadValue=).
2. *ORectangle.h*: remove the duplicate =#define min/max= macros (collide
   with the utils.h templates); =#include "utils.h"= instead.
3. *OXMainFrame =SetMWMHints=*: write the Motif hints via a =long[4]= array
   (not the =MWMHintsProperty= struct) — =XChangeProperty= format=32 expects
   =long=-sized elements on 64-bit, and the struct's =CARD32= packing produced
   garbage in the decorations/inputMode fields.
4. *Explorer =SetMWMHints= removal* (OXExplorer.cc:443): delete the
   =SetMWMHints(MWM_DECOR_ALL, MWM_FUNC_ALL, MWM_INPUT_MODELESS)= call so the
   Explorer top-level window has *no* =_MOTIF_WM_HINTS= property — exactly like
   PCManFM. fvwm95's MWM-hint path leaves Explorer with no min/max/close caption
   buttons even when =MWM_DECOR_ALL= is requested; removing the redundant hint
   makes Explorer inherit the WM's native caption-button layout under both
   fvwm95 and IceWM.
5. *Desktop cursor* (OXDesktopContainer.cc): =XDefineCursor(XC_top_left_arrow)=
   on the desktop container window.
6. *Desktop =Line up Icons=* (OXDesktopContainer::LineUpIcons): snap every icon's
   current position to an 80x80 grid and persist via =Save()=. Wired to
   =M_VIEW_LINEUP= in main.cc.
7. *Desktop =Properties=* (main.cc): wire =M_ROOT_PROPS= to open the xclass-native
   =OXPropertiesDialog= on the desktop directory.
8. *Explorer =Copy/Cut/Paste=* (OXExplorer.cc): real copy buffer
   (=g_copyBuffer= + =g_cutMode=) with fork+exec =cp -r= / =mv=. Wired to
   =M_EDIT_COPY/CUT/PASTE=; refreshes the file view after paste.

def rd(p):
    with open(p,'rb') as f: return f.read()

        b'inline int max(unsigned short a, int b) { return (int)a > b ? (int)a : b; }\n'
        b'inline int min(int a, unsigned int b) { return (unsigned)a < b ? a : (int)b; }\n'
        b'inline int min(unsigned int a, int b) { return a < (unsigned)b ? (int)a : b; }\n'

** dsdmine launcher wrapper

Small host-side helper used by the Redstone 9X launcher to turn existing
canonical PNG icon assets (Chicago95 / BeOS) into 32×32 XPMs that the xclass
icon pool (=libXpm=) can load. Transparency becomes the XPM =None= colour so
xclass renders a proper shape mask. The PNG sources remain canonical; the XPMs
are generated reproducibly at launch time.

#+BEGIN_SRC python :tangle linux/.local/bin/png2xpm.py :shebang "#!/usr/bin/env python3" :tangle-mode (identity #o755)
"""Convert a PNG to XPM (with transparency mask) for xclass/libXpm.
Usage: png2xpm.py input.png output.xpm [name]
Builds a palette; cpp=1 if <=94 colours else cpp=2. Transparent pixels -> None.
"""
import sys, os
from PIL import Image

def png_to_xpm(src, dst, name=None):
    im = Image.open(src)
    if im.mode not in ("RGBA", "RGB"):
        im = im.convert("RGBA")
    w, h = im.size
    px = im.load()
    palette = []
    palidx = {}
    rows = []
    for y in range(h):
        row = []
        for x in range(w):
            r, g, b, a = px[x, y]
            key = None if a < 128 else (r, g, b)
            if key not in palidx:
                palidx[key] = len(palette)
                palette.append(key)
            row.append(palidx[key])
        rows.append(row)
    ncol = len(palette)
    # Safe single-char alphabet: printable ASCII 33..126 EXCLUDING the XPM
    # string delimiter (0x22) and backslash (0x5c). Using the quote char as a
    # pixel corrupts the XPM; XpmReadFileToPixmap then fails -> generic icons.
    _SAFE1 = [chr(c) for c in range(33, 127) if c not in (0x22, 0x5c)]
    if ncol <= len(_SAFE1):
        cpp = 1
        chars = _SAFE1[:ncol]
    else:
        cpp = 2
        chars = []
        for c1 in range(33, 127):
            if c1 in (0x22, 0x5c): continue
            for c2 in range(33, 127):
                if c2 in (0x22, 0x5c): continue
                chars.append(chr(c1) + chr(c2))
                if len(chars) >= ncol: break
            if len(chars) >= ncol: break
    if not name:
        name = os.path.splitext(os.path.basename(dst))[0]
        name = "".join(c if c.isalnum() else "_" for c in name)
    lines = ["/* XPM */",
             "static char * %s[] = {" % name,
             '"%d %d %d %d",' % (w, h, ncol, cpp)]
    for i, key in enumerate(palette):
        if key is None:
            lines.append('"%s c None",' % chars[i])
        else:
            lines.append('"%s c #%02X%02X%02X",' % (chars[i], key[0], key[1], key[2]))
    for y in range(h):
        s = "".join(chars[rows[y][x]] for x in range(w))
        sep = "}" if y == h - 1 else ","
        lines.append('"%s"%s' % (s, sep))
    lines.append("};")
    with open(dst, "w") as f:
        f.write("\n".join(lines) + "\n")
    return (w, h, ncol)

if __name__ == "__main__":
    if len(sys.argv) < 3:
        sys.exit("usage: png2xpm.py input.png output.xpm [name]")
    w, h, n = png_to_xpm(sys.argv[1], sys.argv[2], sys.argv[3] if len(sys.argv) > 3 else None)
    print("%s -> %s (%dx%d, %d colours)" % (sys.argv[1], sys.argv[2], w, h, n))

#------------------------------------------------------------------------------
# First, for the mouse in the root window (Context=R)
# Button 1 gives the Start menu
# Button 2 gives the Window Ops menu
# Button 3 gives the WindowList
#------------------------------------------------------------------------------


#     Button	Context Modifi 	Function

Mouse 1		R   	A       Menu "StartMenu" Nop
Mouse 2		R    	A       Menu "Window" Nop
# Root button3 is intentionally NOT bound: the xclass desktop manager
# installs its own XGrabButton(AnyButton) on the root to show its native
# context menu (New / Arrange Icons By / Line Up Icons / Auto Arrange /
# Properties). A fvwm95 root button3 binding would conflict (BadAccess) and
# prevent the xclass menu — and thus Arrange Icons By / Auto Arrange —
# from ever working.
#Mouse 3         R       A       Menu "DeskCtx" Nop
#Mouse 3	R    	A      	Module "winlist" FvwmWinList transient


#------------------------------------------------------------------------------
# Now the title bar buttons
# Any button in the left title-bar button gives the window ops menu
# Any button in the first right title-bar button Iconifies the window
# Any button in the second title-bar button full-maximizes
# Any button in the third (rightmost) title-bar button closes
# Note the use of "Mouse 0" for AnyButton.
#------------------------------------------------------------------------------


#     Button	Context Modif 	Function
Mouse 0		1    	A      	Function "window_ops_func"
Mouse 1         2       A       Delete
Mouse 0		4    	A     	Maximize 100 96
Mouse 0		6    	A     	Iconify


#------------------------------------------------------------------------------
# Now the rest of the frame
# Here I invoke my complex functions for Move-or-lower, Move-or-raise,
# and Resize-or-Raise.
#------------------------------------------------------------------------------

# Button 1 in the corners or sides, with any modifiers, gives resize or raise
Mouse 1		FS	A	Function "Resize-or-Raise"

# Button 1 in the title, sides, or icon, w/ any modifiers, gives move or raise
Mouse 1		T	A	Function "Move-or-Raise"

# Button 1 in an icons gives move for a drag, de-iconify for a double-click,
# nothing for a single click
Mouse 1		I	A	Function "Move-or-Iconify"

# Button 2 in an icon, w/ any modifiers, gives de-iconify
Mouse 2		I	A	Iconify

# Button 2 in the corners, sides, or title-bar gives the window ops menu
Mouse 2		FST	A	Function "window_ops_func"

# Button 3 anywhere in the decoration (except the title-bar buttons)
# does a raise-lower
Mouse 3		TSIF	A	RaiseLower

# Button 3 in the window, with the Modifier-1 key (usually alt or diamond)
# gives Raise-Lower. Used to use control here, but that interferes with xterm
Mouse 3         W       M       RaiseLower

Recycle Bin icon-state watcher.  PCManFM's own native trash desktop object
would track full/empty state for free, but room-gaming deliberately has no
=gvfs= (it crashes =pcmanfm --desktop= — see the running registry). This
polls the plain on-disk Trash folder instead — no GVFS, no new package,
just =ls=/=sed= against a path that already exists — and rewrites the
static launcher's =Icon== key directly. =pcmanfm --desktop= already
monitors =~/Desktop/= for content changes (that's how manual icon
repositioning/renaming persists), so an in-place edit to the =.desktop=
file's icon is picked up the same way.

#+BEGIN_SRC bash :tangle linux/.local/bin/redstone-9x-recycle-bin-watch :shebang "#!/bin/bash" :tangle-mode (identity #o755)
# Redstone 9X — Recycle Bin icon state watcher.
# Toggles ~/Desktop/recycle-bin.desktop's Icon= between user-trash and
# user-trash-full to match the real on-disk Trash folder, since the static
# launcher has no dynamic state of its own (no gvfs in this room — see
# redstone-9x-state-digest.md). Plain poll loop; no inotify dependency.
set -euo pipefail

TRASH_FILES="${XDG_DATA_HOME:-${HOME}/.local/share}/Trash/files"
DESKTOP_ICON="${HOME}/Desktop/recycle-bin.desktop"

while true; do
  if [[ -d "${TRASH_FILES}" ]] && [[ -n "$(ls -A "${TRASH_FILES}" 2>/dev/null)" ]]; then
    icon="user-trash-full"
  else
    icon="user-trash"
  fi
  # Compare against the file's ACTUAL current Icon= line, not a remembered
  # in-process variable — a relaunch reprojects a fresh copy of this file
  # over top of a still-running watcher, and an in-memory "last state" would
  # never notice the reset, silently going stale (found 2026-07-07).
  if [[ -f "${DESKTOP_ICON}" ]] && ! grep -qx "Icon=${icon}" "${DESKTOP_ICON}"; then
    sed -i "s/^Icon=.*/Icon=${icon}/" "${DESKTOP_ICON}"
  fi
  sleep 3
done
#+END_SRC

** Redstone PowerShell launcher

PowerShell interactive redraw is sensitive to the terminal line editor and
terminal identity.  Keep this isolated from Bash/CMD launchers.

#+BEGIN_SRC bash :tangle linux/.local/bin/redstone-9x-pwsh :shebang "#!/bin/bash" :tangle-mode (identity #o755)
set -euo pipefail

export TERM="${TERM:-xterm-256color}"
export POWERSHELL_UPDATECHECK=Off
export DOTNET_CLI_TELEMETRY_OPTOUT=1

# .NET 8 System.Console locates the terminfo database via $TERMINFO, ~/.terminfo,
# then fixed roots (/usr/share/terminfo, ...) -- it NEVER consults $TERMINFO_DIRS.
# Inside this rootless Distrobox container /usr/share/terminfo has no 'xterm'
# entry (only /run/host/usr/share/terminfo/x/xterm does), so .NET loads no
# terminfo, CursorAddress (cup) is null, Console.SetCursorPosition silently
# emits nothing while still caching the move, and PSReadLine's full-buffer
# redraw never repositions to the prompt origin -> the interactive "smear".
# CPR (ESC[6n) is unaffected because .NET hard-codes it.  Point .NET at the
# host terminfo tree so cup is emitted and the redraw is correct.  (Root cause
# confirmed 2026-07-06 via strace: openat of the host xterm entry + 26 CUP
# writes appear, smear gone.)
if [ -d /run/host/usr/share/terminfo ]; then
  export TERMINFO=/run/host/usr/share/terminfo
fi

# Let pwsh handle the TTY directly.  PSReadLine (PowerShell 7's readline
# engine) sets raw terminal mode itself and handles all echoing; running
# stty -echo before launch creates a double-echo conflict with PSReadLine.
pwsh -NoLogo -NoProfile
#+END_SRC

#+BEGIN_SRC powershell :tangle linux/.config/redstone-9x/powershell/basic-repl.ps1 :mkdirp yes

* Sanctuary: sanctuary-sx — SX-Window XLibre/X11 Habitat

An XFCE-based XLibre/X11 habitat for a living continuation of Sharp X68000 SX-Window and Ko-Window visual culture. It uses XFCE as a flexible, manually tuneable chassis, beginning from a Windows-3.1-adjacent visual baseline and evolving toward a bespoke Japanese early-1990s workstation grammar. It is intended to host native Linux applications alongside future machine-islands for X68000, PC-98, FM Towns, DOSBox-X, Wine, ScummVM, and related God-PC-era environments.

Stack: Guix base + XFCE desktop stack (no source build required; packages come from host =/gnu/store=).
Guix profiles sourced: =desktop-common= + =sanctuary-sx= (xfce4-session, xfwm4, xfconf, panel, settings, desktop, appfinder, thunar, xfce4-terminal).

Host virtual desktop: current host desktop. Xephyr display: =:94=.
Agent doorway: =distrobox enter sanctuary-sx -- <cmd>=
Launch: =sanctuary-sx-launch=
Capture: =sanctuary-sx-capture= (dry-run by default; =--apply= to write to DotCortex source)

Guest home: =$XDG_DATA_HOME/dotcortex/guests/sanctuary-sx/home/=

** Visual Grammar and Baseline

The initial payload is stock XFCE, started cleanly inside the Xephyr display. The intended visual grammar — woven cross-hatched grey root-desktop texture, narrow black keylines, restrained bevels, horizontal segmented titlebars, compact controls, a fixed vertical left device/tool rail, grayscale bitmap-style icons with selective Sharp/X68000 green accents, and Japanese and English labels living together — is built by the user manually through XFCE's own configuration tools. The sanctuary is designed for manual exploration and iteration, not automated theming.

The initial XFCE session starts from its own defaults. A Windows-3.1-adjacent XFWM4 theme provides the starting geometry; the user tunes from there toward the SX/Ko grammar.

** Configuration Projection (post-capture)

After a manual shaping pass, use =sanctuary-sx-capture= to inventory changed XFCE config and copy selected files into DotCortex source at =linux/.config/sanctuary-sx/=. The launch script will then project those captured files back into the guest home via symlinks on subsequent launches. Only curated, intentional files enter DotCortex; caches, session state, and machine-specific display layout are excluded.

- =.config/xfce4/xfconf/xfce-perchannel-xml/= (xfwm4, xfce4-panel, xfce4-desktop, xfce4-keyboard-shortcuts, xsettings, thunar)

  prefix="$1"
  winver="$2"
  shift 2
  prefix_dir="${data_home}/wine/${prefix}"
  marker="${prefix_dir}/.godzilla-xs-initialized"
  mkdir -p "${prefix_dir}"
  if [ -f "${marker}" ]; then
    echo "godzilla-xs: prefix already initialized: ${prefix}"
    return 0

  for verb in "$@"; do
    godzilla-xs-winetricks "${prefix}" "${verb}" "baseline ${prefix} compatibility"
  done
  date -Iseconds > "${marker}"
}

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-sx-capture :shebang "#!/usr/bin/env bash"
# Inventory and copy manually curated XFCE config from the sanctuary-sx guest
# home into DotCortex declarative source at linux/.config/sanctuary-sx/.

#   XFCE channel XML: xfwm4, xfce4-panel, xfce4-desktop,

# What is excluded:
#   xfce4-session.xml     — session state (window positions, open apps)
#   xfce4-notifyd.xml     — notification daemon ephemeral state
#   displays.xml          — monitor layout (machine-specific)
#   xfce4-power-manager.xml — power/hardware settings (machine-specific)
#   *.db, *.sqlite, thumbnails/, recently-used.xbel, .cache/
set -euo pipefail

if [[ "${1:-}" == "--apply" ]]; then
  APPLY=1

GUESTS_DIR="${XDG_DATA_HOME:-$HOME/.local/share}/dotcortex/guests"

_report() {
  local action="$1"
  local path="$2"

}

_copy() {
  local src="$1"
  local dst_dir="$2"
  if [[ "${APPLY}" -eq 1 ]]; then
    mkdir -p "${dst_dir}"
    cp -a "${src}" "${dst_dir}/"
    _report "COPY" "${src#${GUEST_HOME}/} → linux/.config/sanctuary-sx/$(basename "${dst_dir}")/$(basename "${src}")"
  else
    _report "would copy" "${src#${GUEST_HOME}/} → linux/.config/sanctuary-sx/$(basename "${dst_dir}")/"
  fi
  (( _captured++ )) || true
}

  local src="$1"
  local dst="$2"
  if [[ "${APPLY}" -eq 1 ]]; then
    mkdir -p "$(dirname "${dst}")"
    rsync -a --delete "${src}/" "${dst}/"
    _report "SYNC" "${src#${GUEST_HOME}/} → linux/.config/sanctuary-sx/$(basename "${dst}")/"
  else
    _report "would sync" "${src#${GUEST_HOME}/} → linux/.config/sanctuary-sx/$(basename "${dst}")/"
  fi
  (( _captured++ )) || true
}

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-sx-wallpaper :shebang "#!/usr/bin/env bash" :mkdirp yes
# Apply the given PNG as sanctuary-sx (:94) desktop wallpaper.
# Usage: sanctuary-sx-wallpaper /absolute/or/relative/path.png
set -euo pipefail

usage() {
  echo "Usage: sanctuary-sx-wallpaper <image-path>" >&2
  echo "  Applies the wallpaper through xfconf on the running sanctuary-sx XFCE session." >&2
  echo "  Image must be a PNG readable inside the guest container namespace." >&2
  exit 1
}

(( $# == 1 )) || usage

wallpaper="$(readlink -f "$1")"
[[ -f "${wallpaper}" ]] || { echo "ERROR: not a file: ${wallpaper}" >&2; exit 1; }
[[ -r "${wallpaper}" ]] || { echo "ERROR: not readable: ${wallpaper}" >&2; exit 1; }

# --- locate the running session's D-Bus address ---
dbus_addr=""
for _pid in $(pgrep -f 'xfce4-session' 2>/dev/null || true); do
  _env=$(cat "/proc/${_pid}/environ" 2>/dev/null | tr '\0' '\n' || true)
  _dis=$(echo "${_env}" | grep '^DISPLAY=' | head -1 | cut -d= -f2)
  [[ "${_dis}" == ":94" ]] || continue
  _bus=$(echo "${_env}" | grep '^DBUS_SESSION_BUS_ADDRESS=' | head -1 | cut -d= -f2-)
  [[ -n "${_bus}" ]] && { dbus_addr="${_bus}"; break; }

[[ -n "${dbus_addr}" ]] || { echo "ERROR: sanctuary-sx XFCE session not found on :94" >&2; exit 1; }

  echo "ERROR: xfconf-query cannot reach xfconfd on session D-Bus" >&2
  exit 1

[[ -n "${output}" ]] || { echo "ERROR: no connected xrandr output on :94" >&2; exit 1; }

style_prop="/backdrop/screen0/monitor${output}/workspace0/image-style"

xfdesk_pid=""
for _pid in $(pgrep xfdesktop 2>/dev/null || true); do
  _env_dis=$(cat "/proc/${_pid}/environ" 2>/dev/null | tr '\0' '\n' | grep '^DISPLAY=' | head -1 | cut -d= -f2)
  [[ "${_env_dis}" == ":94" ]] && { xfdesk_pid="${_pid}"; break; }
done

  DISPLAY="${DISPLAY}" "${PROFILE_BIN}/xfdesktop" --quit 2>/dev/null || true
  # Wait for it to actually die
  for _i in $(seq 1 10); do
    kill -0 "${xfdesk_pid}" 2>/dev/null || break
    sleep 0.3
  done
fi

nohup env \
  DBUS_SESSION_BUS_ADDRESS="${dbus_addr}" \
  DISPLAY="${DISPLAY}" \
  XDG_CONFIG_HOME="${GUEST_HOME}/.config" \
  XDG_DATA_HOME="${GUEST_HOME}/.local/share" \
  HOME="${GUEST_HOME}" \
  XDG_CACHE_HOME="${GUEST_HOME}/.cache" \

  >/dev/null 2>&1 &

sleep 2
# Verify xfdesktop is alive by scanning /proc (DISPLAY=:94 is in environ, not cmdline)
new_pid=""
for _pid in $(pgrep xfdesktop 2>/dev/null || true); do
  _env_dis=$(cat "/proc/${_pid}/environ" 2>/dev/null | tr '\0' '\n' | grep '^DISPLAY=' | head -1 | cut -d= -f2)
  [[ "${_env_dis}" == ":94" ]] && { new_pid="${_pid}"; break; }

if [[ -n "${new_pid}" ]]; then
  echo "Wallpaper applied: ${wallpaper}"
  echo "  xrandr output: ${output}"
  echo "  xfconf property: ${prop}"
  echo "  image-style: 2 (tiled)"
else
  echo "WARNING: wallpaper property set but xfdesktop did not start." >&2
  exit 2
fi

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-sx-fastfetch-grid :shebang "#!/bin/bash" :mkdirp yes
# Output the Human68k-style two-column SYSINFO grid for fastfetch Command module.
# Runs inside the sanctuary container — values reflect the container's view.
# Uses /proc and /sys directly; no external tools needed beyond coreutils (grep, awk, etc.).
set -euo pipefail

_col() { printf '%-49s' "$1"; }

# --- Habitat class detection (Virtual Habitat taxonomy) ---
if [[ -f /run/.containerenv ]] || [[ "${container:-}" != "" ]]; then
  _habitat="Sanctuary (Distrobox)"
elif [[ "$(cat /sys/class/dmi/id/product_name 2>/dev/null || true)" == *KVM* ]]; then
  _habitat="Enclave (KVM)"
elif [[ -d /sys/hypervisor ]] && grep -q . /sys/hypervisor/type 2>/dev/null; then
  _habitat="Enclave ($(head -1 /sys/hypervisor/type 2>/dev/null))"
else
  _habitat="Baremetal"
fi

# --- Substrate (package manager) ---
if [[ -d /gnu/store ]]; then
  _pkg="Guix"
elif [[ -f /etc/debian_version ]]; then
  _pkg="Apt/Debian"
else
  _pkg="Unknown"
fi

# --- Display layer ---
_res="${DISPLAY:-:0}"
if grep -qi xephyr /proc/*/cmdline 2>/dev/null; then
  _dis="Xephyr ${_res}"
else
  _dis="X11 ${_res}"
fi

# --- System basics ---
_host="$(cat /proc/sys/kernel/hostname 2>/dev/null || uname -n)"
_kernel="$(uname -r)"
_cpu="$(grep -m1 'model name' /proc/cpuinfo 2>/dev/null | cut -d: -f2 | xargs)"
[[ -z "${_cpu}" ]] && _cpu="Unknown"

# Memory from /proc/meminfo
_mem_kb="$(awk '/^MemTotal:/{print $2}' /proc/meminfo 2>/dev/null)"
if [[ -n "${_mem_kb}" ]]; then
  if (( _mem_kb >= 1048576 )); then
    _mem="$(awk "BEGIN {printf \"%.0fG\", ${_mem_kb}/1048576}")"
  else
    _mem="$(awk "BEGIN {printf \"%.0fM\", ${_mem_kb}/1024}")"
  fi
else
  _mem="Unknown"
fi

# Uptime from /proc/uptime
_uptime_sec="$(awk -F. '{print $1}' /proc/uptime 2>/dev/null)"
if [[ -n "${_uptime_sec}" ]]; then
  _days=$((_uptime_sec / 86400))
  _hours=$(((_uptime_sec % 86400) / 3600))
  _mins=$(((_uptime_sec % 3600) / 60))
  if (( _days > 0 )); then
    _uptime="${_days}d ${_hours}h ${_mins}m"
  elif (( _hours > 0 )); then
    _uptime="${_hours}h ${_mins}m"
  else
    _uptime="${_mins}m"
  fi
else
  _uptime="Unknown"
fi

_shell="$(basename "${SHELL:-/bin/sh}")"
_shell_ver=""

# GPU from /sys
_gpu="Unknown"
for p in /sys/class/drm/card*/device/vendor; do
  [[ -f "$p" ]] || continue
  _dev="$(dirname "$p")"
  _vendor="$(cat "$p" 2>/dev/null)"
  [[ "$_vendor" != "0x10de" ]] || _gpu="NVIDIA"
  break
done

# Screen from /sys
_res_str="?x?"
for fb in /sys/class/graphics/fb*/modes; do
  [[ -f "$fb" ]] || continue
  _res_str="$(head -1 "$fb" 2>/dev/null)"
  break
done

# DE/WM/theme — static for sanctuary-sx
_de="XFCE"
_wm="xfwm4"
_wm_theme="Default"
_gtk="Default"
_icons="Default"
_font="Monospace"

# --- Output the grid ---
printf '%s\n%s\n\n' \
  "$(_col " Host        ${_host}")" \
  "$(_col " Display     ${_res_str}")"

** RetroPie bind lifecycle helper

The RetroPie tree is a direct Podman bind whose source can be an autofs-backed
NFS path. Podman resolves that bind when the container starts; an already-running
container therefore needs a stop/start cycle when its bind was captured empty.
This helper is shared by both launchers so a stale bind never gets misdiagnosed
as a reason to remove or recreate a sanctuary.

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-retropie-bind-ensure :shebang "#!/usr/bin/env bash" :tangle-mode (identity #o755)
set -euo pipefail

SANCTUARY="${1:?sanctuary name required}"
RETROPIE_CONTAINER_ROOT="${2:?RetroPie container root required}"
BIND_PATH="${RETROPIE_CONTAINER_ROOT}/roms/ports"
WAIT_SECONDS="${SANCTUARY_PODMAN_WAIT_SECONDS:-8}"
WAIT_LOOPS=$((WAIT_SECONDS * 10))

container_state() {
  podman inspect --format '{{.State.Status}}' "${SANCTUARY}" 2>/dev/null || printf '%s\n' unknown
}

is_startable() {
  case "$1" in
    created|exited|stopped) return 0 ;;
    *) return 1 ;;
  esac
}

wait_for_state() {
  local wanted="$1" i state
  for ((i = 0; i < WAIT_LOOPS; i++)); do
    state="$(container_state)"
    [[ "${state}" == "${wanted}" ]] && return 0
    sleep 0.1
  done
  return 1
}

wait_for_startable() {
  local i state
  for ((i = 0; i < WAIT_LOOPS; i++)); do
    state="$(container_state)"
    is_startable "${state}" && return 0
    sleep 0.1
  done
  return 1
}

recover_container() {
  local state after stop_rc
  state="$(container_state)"
  case "${state}" in
    running|stopping)
      echo "${SANCTUARY}: requesting a bounded clean stop (state: ${state})"
      if timeout --kill-after=2s "${WAIT_SECONDS}s" podman stop -t 5 "${SANCTUARY}" >/dev/null 2>&1; then
        :
      else
        stop_rc=$?
        echo "${SANCTUARY}: podman stop did not complete cleanly (exit ${stop_rc}); waiting before escalation"
      fi
      ;;
    created|exited|stopped)
      return 0
      ;;
    *)
      echo "${SANCTUARY}: ERROR — cannot recover container from state: ${state}" >&2
      return 1
      ;;
  esac

  if wait_for_startable; then
    after="$(container_state)"
    echo "${SANCTUARY}: clean stop reached startable state: ${after}"
    return 0
  fi

  after="$(container_state)"
  echo "${SANCTUARY}: container remained in state ${after}; escalating to podman kill"
  podman kill "${SANCTUARY}" >/dev/null 2>&1 || true
  if wait_for_state exited; then
    echo "${SANCTUARY}: podman kill confirmed container reached Exited"
    return 0
  fi

  after="$(container_state)"
  if is_startable "${after}"; then
    echo "${SANCTUARY}: podman kill reached startable state: ${after}"
    return 0
  fi
  echo "${SANCTUARY}: ERROR — container did not reach Exited or another startable state after podman kill (state: ${after})" >&2
  return 1
}

start_container() {
  local start_rc state
  if podman start "${SANCTUARY}" >/dev/null 2>&1; then
    if wait_for_state running; then
      return 0
    fi
    state="$(container_state)"
    echo "${SANCTUARY}: ERROR — podman start returned success but state is ${state}" >&2
    return 1
  fi

  start_rc=$?
  state="$(container_state)"
  if [[ "${state}" == "stopping" ]]; then
    echo "${SANCTUARY}: start refused while container is Stopping; recovering it"
    recover_container || return 1
    if podman start "${SANCTUARY}" >/dev/null 2>&1 && wait_for_state running; then
      return 0
    fi
    state="$(container_state)"
    echo "${SANCTUARY}: ERROR — container still failed to start after Stopping recovery (state: ${state})" >&2
    return 1
  fi

  echo "${SANCTUARY}: ERROR — container failed to start (exit ${start_rc}, state: ${state})" >&2
  return 1
}

bind_present() {
  podman exec "${SANCTUARY}" test -d "${BIND_PATH}" >/dev/null 2>&1
}

restart_for_bind() {
  echo "${SANCTUARY}: RetroPie bind is stale — restarting the container to re-establish it"
  recover_container || return 1
  start_container
}

state="$(container_state)"
case "${state}" in
  running)
    if ! bind_present; then
      restart_for_bind || exit 1
    fi
    ;;
  stopping)
    echo "${SANCTUARY}: container is wedged in Stopping; recovering it before start"
    recover_container || exit 1
    start_container || exit 1
    ;;
  created|exited|stopped)
    start_container || exit 1
    ;;
  *)
    echo "${SANCTUARY}: ERROR — container is not startable (state: ${state})" >&2
    exit 1
    ;;
esac

# A bind absent immediately after a normal start is also given one explicit
# stop/start repair attempt. If it remains absent, report the real state without
# prescribing container recreation for a mount-lifecycle problem.
if ! bind_present; then
  echo "${SANCTUARY}: RetroPie bind is absent after start — restarting once to re-establish it"
  restart_for_bind || exit 1
fi

if ! bind_present; then
  echo "${SANCTUARY}: ERROR — RetroPie bind remains absent after restart" >&2
  echo "  Expected: ${BIND_PATH}" >&2
  echo "  The container was not removed or recreated; inspect the declaration and Podman mount state." >&2
  exit 1
fi

echo "${SANCTUARY}: RetroPie bind present inside the running container: ${BIND_PATH}"
#+END_SRC

* Host-facing sanctuary menu launchers

Freedesktop =.desktop= entries that surface each sanctuary — and each spin — in the host application menu, so a sanctuary can be started from the launcher instead of a terminal. They live in the =linux/= overlay (sanctuaries are Guix/Distrobox/Xephyr, i.e. Linux-only) and stow to =~/.local/share/applications/=. Each =Exec= is an absolute path to the sanctuary's launch script; each =Icon= is an absolute path into the themed icon pack that matches that sanctuary's own identity — Chicago95 (Windows 9x) for Redstone 9X, Irixium for Godzilla XS-86000, and the SGI-family Iris / indigo-reality packs for the CDE (Motif/Sun) and GNUstep (NeXT) workstations — so each tile reads correctly regardless of the host icon theme. Only =sanctuary-redstone-9x= has multiple spins (IceWM by default, FVWM95), selected through the =SANCTUARY_DESKTOP= environment variable the launcher already reads; every other sanctuary is single-desktop. The RetroPie launcher and its host entry live in =retropie.org= alongside that sanctuary's own launch script.

Every entry's =Exec= goes through the shim =sanctuary-menu-launch= rather than calling the launch script directly. A desktop-menu launch inherits the graphical session's environment, which lacks both the Guix core profile (where =distrobox= lives) and =~/.local/bin= (the =sanctuary-*= helpers); the launch scripts run =set -e= and call those bare, so the first one hits command-not-found and the launch dies silently (=Terminal=false= means no visible error). The shim rebuilds a login-like environment — sourcing the Guix profiles exactly as =.zshenv= does for a terminal, then prepending =~/.local/bin= — before exec'ing the real launcher. It is invoked by absolute path so it resolves without any pre-existing =PATH=.

** sanctuary-menu-launch shim

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-menu-launch :shebang "#!/usr/bin/env bash" :tangle-mode (identity #o755)
# sanctuary-menu-launch — host-menu shim for the sanctuary .desktop launchers.
# Rebuild the login-like environment a terminal would have (Guix profiles +
# ~/.local/bin) so the launch scripts' bare host commands (distrobox,
# sanctuary-exec, sanctuary-teardown-stale-session, …) resolve, then exec the
# real launcher. See the org prose above for why this indirection is needed.
set -eo pipefail

if [[ "${1:-}" == "-h" || "${1:-}" == "--help" ]]; then
  cat <<EOF
sanctuary-menu-launch - host-menu shim for the sanctuary .desktop launchers

Usage: sanctuary-menu-launch <qtile|gnustep|cde|redstone-9x|sx|retropie> [spin]
  spin is only meaningful for redstone-9x: icewm (default) or fvwm95

Rebuilds a login-like environment (Guix profiles + ~/.local/bin) so the bare
launch scripts' host commands resolve, then execs the real sanctuary-*-launch.
Called by the .desktop entries in linux/.local/share/applications/ — not
normally invoked by hand.
EOF
  exit 0
fi

for _prof in "${HOME}/.config/guix/current" "${HOME}/.guix-extra-profiles/core/core"; do
  [ -r "${_prof}/etc/profile" ] && . "${_prof}/etc/profile"
done
export PATH="${HOME}/.local/bin:${PATH}"

sanctuary="${1:?usage: sanctuary-menu-launch <qtile|gnustep|cde|redstone-9x|sx|retropie> [spin]}"
case "${sanctuary}" in
  qtile|gnustep|cde|sx|retropie)
    exec "sanctuary-${sanctuary}-launch" ;;
  redstone-9x)
    export SANCTUARY_DESKTOP="${2:-icewm}"
    exec sanctuary-redstone-9x-launch ;;
  *)
    echo "sanctuary-menu-launch: unknown sanctuary '${sanctuary}'" >&2
    exit 2 ;;
esac
#+END_SRC
