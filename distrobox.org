* Purpose

Declares the three Phase 1 Distrobox sanctuaries. Each sanctuary gets its own Xephyr
display and dedicated host virtual desktop (Super+2/3/4). Desktop 1 is the normal host desktop.

The container distro is *Guix*. Packages come from the host =/gnu/store= bind-mounted
read-only — nothing is bundled in the container image except the Distrobox compatibility
layer. The sanctuary-specific profile (qtile, emacs, zsh, etc.) is sourced inside the
container from =~/.guix-extra-profiles/=.

Sanctuaries are created with =distrobox-sanctuaries-create= (tangled below). One-shot
declarative — to recreate: =distrobox rm <name> && distrobox-sanctuaries-create=.

* Design

#+BEGIN_SRC text :tangle no
guix pack -f docker -m sanctuary-base.scm   → tiny Guix rootfs (~50MB, compat layer only)
  ↓
podman load → sanctuary-base:guix

distrobox create --image sanctuary-base:guix
  --volume /gnu/store:/gnu/store:ro               ← host store, already built
  --volume ~/.guix-extra-profiles:ro              ← profile symlinks into host store
  ↓
launcher (host-side):
  Xephyr :90 -fullscreen
  distrobox enter sanctuary-qtile --
    . ~/.guix-extra-profiles/desktop-common/desktop-common/etc/profile
    . ~/.guix-extra-profiles/sanctuary-qtile/sanctuary-qtile/etc/profile
    exec qtile start
#+END_SRC

Packages are deduplicated by the host store — three sanctuaries sharing the same emacs
closure cost nothing extra after the first.

* Prerequisites

Before running =distrobox-sanctuaries-create=:

1. *Build Guix profiles on host*: =loom guix:sanctuary-apply= (builds desktop-common,
   sanctuary-qtile, sanctuary-gnustep, sanctuary-cde profiles)
2. *Build and load the base image*: =sanctuary-base-build=
3. *Ensure guest home dirs exist*: =vm-homes-init=

* Base Image Build

=guix pack -f docker= with only =sanctuary-base.scm= — the Distrobox compat layer.
No package content: packages come from the host store bind-mount.

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-base-build :shebang "#!/usr/bin/env bash"
# Build and load the Guix-based Distrobox base image.
# Uses sanctuary-base.scm — minimal Guix rootfs for Distrobox compatibility only.
# Actual packages (qtile, emacs, etc.) come from host /gnu/store bind-mount.
#
# guix pack produces a functional environment image with no /etc/passwd.
# This script injects a second OCI layer adding the system files that
# the OCI runtime (crun) and Distrobox need before they can start a container.
#
# Run once, and re-run if sanctuary-base.scm changes.
# Requires: guix (channel-pinned), podman, python3
set -euo pipefail

GUIX="${HOME}/.config/guix/current/bin/guix"
BASE_MANIFEST="${HOME}/.config/guix/manifests/sanctuaries/sanctuary-base.scm"

if [[ ! -f "${BASE_MANIFEST}" ]]; then
  echo "sanctuary-base-build: manifest not found at ${BASE_MANIFEST}" >&2
  exit 1
fi

echo "==> Packing Guix base image from ${BASE_MANIFEST}…"
tarball="$( "${GUIX}" pack -f docker \
  --entry-point=/bin/sh \
  -S /bin=bin \
  -m "${BASE_MANIFEST}" 2>&1 | tail -1 )"

echo "    tarball: ${tarball}"

# ---- Inject system files layer ----
# guix pack creates a functional environment with no /etc/passwd.
# crun (OCI runtime) and Distrobox both require it before the container can start.
# We add a second OCI layer with the minimal system files.

echo "==> Injecting system files layer (/etc/passwd, /etc/shadow, /etc/group, /root, /tmp)…"
WORK_DIR="$(mktemp -d)"
trap "rm -rf '${WORK_DIR}'" EXIT

tar xzf "${tarball}" -C "${WORK_DIR}"

LAYER_STAGE="${WORK_DIR}/etc-layer-stage"
mkdir -p "${LAYER_STAGE}/etc" "${LAYER_STAGE}/root" "${LAYER_STAGE}/tmp" "${LAYER_STAGE}/var/tmp"

cat > "${LAYER_STAGE}/etc/passwd" <<'PASSWDEOF'
root:x:0:0:root:/root:/bin/sh
nobody:x:65534:65534:nobody:/nonexistent:/bin/false
PASSWDEOF

cat > "${LAYER_STAGE}/etc/group" <<'GROUPEOF'
root:x:0:
nogroup:x:65534:
GROUPEOF

printf 'root:!:19000:0:99999:7:::\n' > "${LAYER_STAGE}/etc/shadow"
chmod 640 "${LAYER_STAGE}/etc/shadow"
chmod 1777 "${LAYER_STAGE}/tmp"
chmod 1777 "${LAYER_STAGE}/var/tmp"

# Distrobox-init calls `command -v <shell>` (from $SHELL on the host) before the
# guix profile bind-mounts are added to PATH.  /bin is symlinked to the guix
# profile/bin, but zsh is not in sanctuary-base.scm.  /usr/bin IS in the default
# PATH, so we add a symlink there pointing into the desktop-common profile
# (which is bind-mounted before any process runs in the container).
mkdir -p "${LAYER_STAGE}/usr/bin" "${LAYER_STAGE}/usr/sbin"
ln -s /home/metsatron/.guix-extra-profiles/desktop-common/desktop-common/bin/zsh \
  "${LAYER_STAGE}/usr/bin/zsh"

# Pre-seed /.containersetupdone so Distrobox skips the package manager block.
# Without a supported pkg manager (apt/pacman/dnf/etc), Distrobox's init exits 127.
# Guix containers get packages via /gnu/store bind-mount, not a pkg manager.
touch "${LAYER_STAGE}/.containersetupdone"

LAYER_TAR_RAW="${WORK_DIR}/sys-layer.tar"
tar -C "${LAYER_STAGE}" -cf "${LAYER_TAR_RAW}" .

DIFF_ID="sha256:$(sha256sum < "${LAYER_TAR_RAW}" | cut -d' ' -f1)"
LAYER_DIR_NAME="${DIFF_ID#sha256:}"
mkdir -p "${WORK_DIR}/${LAYER_DIR_NAME}"
cp "${LAYER_TAR_RAW}" "${WORK_DIR}/${LAYER_DIR_NAME}/layer.tar"
echo "1.0" > "${WORK_DIR}/${LAYER_DIR_NAME}/VERSION"

python3 - <<PYEOF
import json, os
d = '${WORK_DIR}'
with open(os.path.join(d, 'manifest.json')) as f:
    m = json.load(f)
m[0]['Layers'].append('${LAYER_DIR_NAME}/layer.tar')
with open(os.path.join(d, 'manifest.json'), 'w') as f:
    json.dump(m, f)
with open(os.path.join(d, 'config.json')) as f:
    c = json.load(f)
c['rootfs']['diff_ids'].append('${DIFF_ID}')
c['history'].append({
    'created': '1970-01-01T00:00:01Z',
    'created_by': 'sanctuary-base-build: inject system files',
    'comment': '/etc/passwd /etc/group /etc/shadow /root /tmp'
})
with open(os.path.join(d, 'config.json'), 'w') as f:
    json.dump(c, f)
PYEOF

echo "    diff_id: ${DIFF_ID}"

echo "==> Loading patched image into Podman as sanctuary-base:guix…"
# Capture the loaded image reference from `podman load` output (e.g. "Loaded image: repo:tag")
loaded_ref="$( tar -C "${WORK_DIR}" --exclude='etc-layer-stage' --exclude='sys-layer.tar' -cf - . \
  | podman load 2>&1 | grep 'Loaded image' | sed 's/Loaded image: //' )"
echo "    loaded: ${loaded_ref}"
image_id="$( podman images --format '{{.ID}}' --filter "reference=${loaded_ref}" | head -1 )"
[[ -z "${image_id}" ]] && image_id="$( podman images --format '{{.ID}}' | head -1 )"
podman tag "${image_id}" "sanctuary-base:guix"
echo "    tagged: sanctuary-base:guix"
echo "Done. Run distrobox-sanctuaries-create to create the sanctuaries."
#+END_SRC

* Sanctuary Create Script

#+BEGIN_SRC bash :tangle linux/.local/bin/distrobox-sanctuaries-create :shebang "#!/usr/bin/env bash"
# Create the three Phase 1 Distrobox sanctuaries.
# Run once per machine, or after `distrobox rm <name>` to recreate.
#
# Prerequisites:
#   sanctuary-base-build        ← build + load the Guix base image
#   loom guix:sanctuary-apply   ← build desktop-common + sanctuary profiles on host
#   vm-homes-init               ← ensure guest home dirs exist
set -euo pipefail

GUESTS_DIR="${XDG_DATA_HOME:-$HOME/.local/share}/dotcortex/guests"
BASE_IMAGE="sanctuary-base:guix"
GUIX_PROFILES="${HOME}/.guix-extra-profiles"
CDE_PROFILE="${GUIX_PROFILES}/sanctuary-cde/sanctuary-cde"
CDE_RUNTIME="${HOME}/.config/virtualisation/sanctuary-cde"

if ! podman image exists "${BASE_IMAGE}" 2>/dev/null; then
  echo "Base image ${BASE_IMAGE} not found — run sanctuary-base-build first" >&2
  exit 1
fi

# --- sanctuary-qtile: Emacs Sanctuary (Phase 1A) ---
distrobox create \
  --name sanctuary-qtile \
  --image "${BASE_IMAGE}" \
  --home "${GUESTS_DIR}/sanctuary-qtile/home" \
  --volume /gnu/store:/gnu/store:ro \
  --volume "${GUIX_PROFILES}:${GUIX_PROFILES}:ro" \
  --no-entry

# --- sanctuary-gnustep: GNU/NeXT Lineage Sanctuary (Phase 1A) ---
distrobox create \
  --name sanctuary-gnustep \
  --image "${BASE_IMAGE}" \
  --home "${GUESTS_DIR}/sanctuary-gnustep/home" \
  --volume /gnu/store:/gnu/store:ro \
  --volume "${GUIX_PROFILES}:${GUIX_PROFILES}:ro" \
  --no-entry

# --- sanctuary-cde: Motif/Sun Sanctuary (Phase 1B) ---
for resource in \
  "${CDE_PROFILE}/etc/netconfig" \
  "${CDE_PROFILE}/etc/rpc" \
  "${CDE_PROFILE}/etc/services" \
  "${CDE_PROFILE}/bin/hostname" \
  "${CDE_PROFILE}/bin/awk" \
  "${CDE_RUNTIME}/nawk" \
  "${CDE_PROFILE}/bin/xset" \
  "${CDE_RUNTIME}/nsswitch.conf"
do
  if [[ ! -e "${resource}" ]]; then
    echo "sanctuary-cde runtime resource missing: ${resource}" >&2
    echo "Run 'loom guix:sanctuary-apply' and 'loom stow:t480s' first" >&2
    exit 1
  fi
done

distrobox create \
  --name sanctuary-cde \
  --image "${BASE_IMAGE}" \
  --home "${GUESTS_DIR}/sanctuary-cde/home" \
  --volume /gnu/store:/gnu/store:ro \
  --volume "${GUIX_PROFILES}:${GUIX_PROFILES}:ro" \
  --volume "${CDE_PROFILE}/etc/netconfig:/etc/netconfig:ro" \
  --volume "${CDE_PROFILE}/etc/rpc:/etc/rpc:ro" \
  --volume "${CDE_PROFILE}/etc/services:/etc/services:ro" \
  --volume "${CDE_RUNTIME}/nsswitch.conf:/etc/nsswitch.conf:ro" \
  --volume "${CDE_PROFILE}/bin/hostname:/usr/bin/hostname:ro" \
  --volume "${CDE_PROFILE}/bin/awk:/usr/bin/awk:ro" \
  --volume "${CDE_RUNTIME}/nawk:/usr/bin/nawk:ro" \
  --volume "${CDE_PROFILE}/bin/xset:/usr/bin/xset:ro" \
  --no-entry

# --- sanctuary-redstone-9x: Redstone 9X IceWM (gaming wing, first slice) ---
# Theme and icon assets are projected from DotCortex by the launcher.  Do not
# bind host /usr/share theme/icon trees into the public Redstone contract.
distrobox create \
  --name sanctuary-redstone-9x \
  --image "${BASE_IMAGE}" \
  --home "${GUESTS_DIR}/sanctuary-redstone-9x/home" \
  --volume /gnu/store:/gnu/store:ro \
  --volume "${GUIX_PROFILES}:${GUIX_PROFILES}:ro" \
  --no-entry

# --- sanctuary-sx: SX-Window XLibre/X11 XFCE Habitat ---
distrobox create \
  --name sanctuary-sx \
  --image "${BASE_IMAGE}" \
  --home "${GUESTS_DIR}/sanctuary-sx/home" \
  --volume /gnu/store:/gnu/store:ro \
  --volume "${GUIX_PROFILES}:${GUIX_PROFILES}:ro" \
  --no-entry

echo "distrobox-sanctuaries-create: all five sanctuaries created"
echo "Next: run 'sanctuary-cde-build' to compile CDE 2.5.3 inside the sanctuary"
echo "Then: sanctuary-cde-launch"
echo "      sanctuary-redstone-9x-launch"
echo "      sanctuary-sx-launch"
#+END_SRC

* Sanctuary Launcher Scripts

Each launcher starts Xephyr full-screen on the current host desktop, waits for
the display, then sources the Guix profiles inside the container and starts the
selected WM/session.

All entries go through =sanctuary-enter=. Distrobox 1.8.2.4 copies almost every host
environment variable into =podman exec --env= arguments; the helper starts Distrobox
under =env -i= and restores only the variables required for identity, locale, display,
session D-Bus, and audio. API keys and agent sockets must never cross this boundary.

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-enter :shebang "#!/usr/bin/env bash"
# Select and launch a tested graphical habitat profile.
# Usage: sanctuary-enter [profile-id]
set -euo pipefail

if (( $# > 1 )); then
  echo "Usage: sanctuary-enter [sanctuary-name]" >&2
  echo "For a shell: distrobox-room enter <sanctuary-name>" >&2
  exit 2
fi

if (( $# == 1 )); then
  PROFILE="$1"
else
  DISTROBOX_BIN="$(command -v distrobox)" \
    || { echo "sanctuary-enter: distrobox not found" >&2; exit 127; }
  FZF_BIN="$(command -v fzf)" \
    || { echo "sanctuary-enter: fzf not found" >&2; exit 127; }

  AVAILABLE_SANCTUARIES="$(
    "${DISTROBOX_BIN}" list --no-color | awk -F '|' '
      NR > 1 {
        name = $2
        gsub(/^[[:space:]]+|[[:space:]]+$/, "", name)
        print name
      }
    '
  )"

  PROFILES=""
  case "${AVAILABLE_SANCTUARIES}" in
    *sanctuary-redstone-9x*) PROFILES="${PROFILES}"$'\n'"redstone-9x:icewm" ;;
  esac
  case "${AVAILABLE_SANCTUARIES}" in
    *sanctuary-cde*) PROFILES="${PROFILES}"$'\n'"sanctuary-cde:cde" ;;
  esac
  case "${AVAILABLE_SANCTUARIES}" in
    *sanctuary-sx*) PROFILES="${PROFILES}"$'\n'"sx-window:xfce4" ;;
  esac
  PROFILES="$(printf '%s\n' "${PROFILES}" | sed '/^$/d')"

  if [[ -z "${PROFILES}" ]]; then
    echo "sanctuary-enter: no available sanctuaries" >&2
    exit 1
  fi

  PROFILE="$(
    printf '%s\n' "${PROFILES}" \
      | "${FZF_BIN}" \
          --prompt='habitat> ' \
          --height=40% \
          --layout=reverse \
          --border \
          --header='Alt-e down · Alt-i up · Alt-o enter · Alt-n cancel' \
          --bind='alt-e:down,alt-i:up,alt-o:accept,alt-n:abort'
  )" || exit 130
fi

case "${PROFILE}" in
  redstone-9x:icewm|sanctuary-redstone-9x)
    LAUNCHER="sanctuary-redstone-9x-launch"
    ;;
  sanctuary-cde:cde|sanctuary-cde)
    LAUNCHER="sanctuary-cde-launch"
    ;;
  sx-window:xfce4|sanctuary-sx)
    LAUNCHER="sanctuary-sx-launch"
    ;;
  *)
    echo "sanctuary-enter: unsupported or untested profile: ${PROFILE}" >&2
    exit 2
    ;;
esac

LAUNCHER_BIN="$(command -v "${LAUNCHER}")" \
  || { echo "sanctuary-enter: launcher not found: ${LAUNCHER}" >&2; exit 127; }
exec "${LAUNCHER_BIN}"
#+END_SRC

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-exec :shebang "#!/usr/bin/env bash"
# Guarded command and shell doorway for sanctuary launchers and agents.
# Usage: sanctuary-exec <sanctuary-name> [command [args...]]
set -euo pipefail

if (( $# < 1 )); then
  echo "Usage: sanctuary-exec <sanctuary-name> [command [args...]]" >&2
  exit 2
fi

DISTROBOX_BIN="$(command -v distrobox 2>/dev/null)" \
  || DISTROBOX_BIN="${HOME}/.guix-extra-profiles/core/core/bin/distrobox"
[[ -x "${DISTROBOX_BIN}" ]] \
  || { echo "sanctuary-exec: distrobox not found (not in PATH or core profile)" >&2; exit 127; }
SANCTUARY="$1"
shift

# Variables required by distrobox-enter itself.
clean_env=(
  "HOME=${HOME}"
  "USER=${USER:-$(id -un)}"
  "LOGNAME=${LOGNAME:-${USER:-$(id -un)}}"
  "PATH=${PATH}"
  "PWD=${PWD}"
  "SHELL=${SHELL:-/bin/sh}"
)

# Optional terminal, locale, X11, session-bus, and audio integration.
allow_if_set=(
  TERM COLORTERM
  LANG LANGUAGE LC_ALL LC_CTYPE LC_COLLATE LC_MESSAGES LC_MONETARY LC_NUMERIC LC_TIME
  DISPLAY XAUTHORITY
  XDG_RUNTIME_DIR DBUS_SESSION_BUS_ADDRESS
  PULSE_SERVER PIPEWIRE_REMOTE
)

for variable in "${allow_if_set[@]}"; do
  if [[ -v "${variable}" ]]; then
    clean_env+=("${variable}=${!variable}")
  fi
done

if (( $# > 0 )); then
  exec env -i "${clean_env[@]}" "${DISTROBOX_BIN}" enter "${SANCTUARY}" -- "$@"
else
  exec env -i "${clean_env[@]}" "${DISTROBOX_BIN}" enter "${SANCTUARY}"
fi
#+END_SRC

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-clip-bridge :shebang "#!/usr/bin/env bash"
# Bidirectional CLIPBOARD bridge between host and a Xephyr guest display.
# Usage: sanctuary-clip-bridge <host-display> <guest-display>
# Polls every 300 ms; exits cleanly when the guest display becomes unavailable.
set -euo pipefail
HOST_DISPLAY="${1:-:0}"
GUEST_DISPLAY="${2:-:94}"
last_synced=""
while DISPLAY="${GUEST_DISPLAY}" xdpyinfo >/dev/null 2>&1; do
  guest=$(timeout 1 xclip -display "${GUEST_DISPLAY}" -selection clipboard -o 2>/dev/null || true)
  host=$(timeout 1 xclip -display "${HOST_DISPLAY}" -selection clipboard -o 2>/dev/null || true)
  guest_hash=$(printf '%s' "${guest}" | md5sum | cut -d' ' -f1)
  host_hash=$(printf '%s' "${host}" | md5sum | cut -d' ' -f1)
  if [[ -n "${guest}" && "${guest_hash}" != "${last_synced}" && "${guest_hash}" != "${host_hash}" ]]; then
    printf '%s' "${guest}" | timeout 1 xclip -display "${HOST_DISPLAY}" -selection clipboard -i 2>/dev/null || true
    last_synced="${guest_hash}"
  elif [[ -n "${host}" && "${host_hash}" != "${last_synced}" && "${host_hash}" != "${guest_hash}" ]]; then
    printf '%s' "${host}" | timeout 1 xclip -display "${GUEST_DISPLAY}" -selection clipboard -i 2>/dev/null || true
    last_synced="${host_hash}"
  fi
  sleep 0.3
done
#+END_SRC

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-qtile-launch :shebang "#!/usr/bin/env bash"

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-cde-launch :shebang "#!/usr/bin/env bash"
# Launch sanctuary-cde: Xephyr :92 + CDE inside the Guix container.
# Launch from the host desktop; Xephyr does not need a workspace hop.
# Escape: Super+1 / Ctrl+F1 works while Xephyr has focus (-no-host-grab).
# Host-side exit: sanctuary-cde-stop (from any terminal, tmux, or SSH).
# Clipboard: cde-copy-to-host exports CDE selection to host; bridge auto-runs.

    [[ "${XEPHYR_PID}" -gt 0 ]] && kill "${XEPHYR_PID}" 2>/dev/null || true
    [[ "${BRIDGE_PID}" -gt 0 ]]  && kill "${BRIDGE_PID}"  2>/dev/null || true

XEPHYR_PID=$!
printf 'PID=%s\nDISPLAY=%s\n' "${XEPHYR_PID}" "${DISPLAY_NUM}" > "${STATE_FILE}"

DISPLAY="${DISPLAY_NUM}" sanctuary-exec "${SANCTUARY}" sh -c "

#+BEGIN_SRC bash :tangle linux/.local/bin/cde-clipboard-bridge :shebang "#!/usr/bin/env bash"
# Forward CDE Xephyr PRIMARY selection → host CLIPBOARD and PRIMARY (one-way).
# Polls every 300 ms; exits cleanly when the CDE display becomes unavailable.
# Usage (called by sanctuary-cde-launch):
#   cde-clipboard-bridge <host-display> <cde-display>
# Requires: xclip in the host-side desktop-common Guix profile.
set -euo pipefail
HOST_DISPLAY="${1:-:0}"
CDE_DISPLAY="${2:-:92}"
prev_hash=""
while DISPLAY="${CDE_DISPLAY}" xdpyinfo >/dev/null 2>&1; do
    content=$(DISPLAY="${CDE_DISPLAY}" xclip -selection primary -o 2>/dev/null) || true
    if [[ -n "${content}" ]]; then
        curr_hash=$(printf '%s' "${content}" | md5sum | cut -d' ' -f1)
        if [[ "${curr_hash}" != "${prev_hash}" ]]; then
            printf '%s' "${content}" | DISPLAY="${HOST_DISPLAY}" xclip -selection clipboard -i 2>/dev/null || true
            printf '%s' "${content}" | DISPLAY="${HOST_DISPLAY}" xclip -selection primary   -i 2>/dev/null || true
            prev_hash="${curr_hash}"
        fi
    fi
    sleep 0.3
done
#+END_SRC

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-cde-stop :shebang "#!/usr/bin/env bash"
# Terminate the running sanctuary-cde Xephyr session from any host terminal.
# Reads PID from $XDG_RUNTIME_DIR/dotcortex/sanctuary-cde.pid written by
# sanctuary-cde-launch. Validates ownership and process identity before
# sending SIGTERM. Never uses pkill or broad process-name matching.
set -euo pipefail

DOTCORTEX_RUN="${XDG_RUNTIME_DIR:-/run/user/$(id -u)}/dotcortex"
STATE_FILE="${DOTCORTEX_RUN}/sanctuary-cde.pid"

if [[ ! -f "${STATE_FILE}" ]]; then
  echo "sanctuary-cde-stop: no active session (${STATE_FILE} not found)" >&2
  exit 1
fi

PID="$(grep '^PID=' "${STATE_FILE}" | cut -d= -f2)"
DISP="$(grep '^DISPLAY=' "${STATE_FILE}" | cut -d= -f2)"

if [[ -z "${PID}" ]]; then
  echo "sanctuary-cde-stop: malformed state file — no PID entry" >&2
  exit 1
fi

PROC_UID="$(ps -p "${PID}" -o uid= 2>/dev/null | tr -d ' ' || true)"
PROC_COMM="$(ps -p "${PID}" -o comm= 2>/dev/null | tr -d ' ' || true)"

if [[ -z "${PROC_UID}" ]]; then
  echo "sanctuary-cde-stop: PID ${PID} not found — session already gone"
  rm -f "${STATE_FILE}"
  exit 0
fi

if [[ "${PROC_UID}" != "$(id -u)" ]]; then
  echo "sanctuary-cde-stop: PID ${PID} is owned by UID ${PROC_UID}, not $(id -u) — refusing" >&2
  exit 1
fi

if [[ "${PROC_COMM}" != "Xephyr" ]]; then
  echo "sanctuary-cde-stop: PID ${PID} is '${PROC_COMM}', not Xephyr — refusing" >&2
  exit 1
fi

echo "Stopping sanctuary-cde (Xephyr ${DISP:-:92}, PID ${PID})…"
kill -TERM "${PID}"
rm -f "${STATE_FILE}"
echo "Done."
#+END_SRC

#+BEGIN_SRC python :tangle linux/.local/bin/sanctuary-cde-extension-import :shebang "#!/usr/bin/env python3" :tangle-mode (identity #o755)
import os
import re
import shutil
import struct
import sys
import tempfile
import zipfile
from pathlib import Path


def die(message: str, code: int = 1) -> None:
    print(f"sanctuary-cde-extension-import: {message}", file=sys.stderr)
    raise SystemExit(code)


def safe_name(value: str) -> str:
    name = re.sub(r"[^A-Za-z0-9._-]+", "-", value).strip(".-")
    return name or "extension"


def zip_start(path: Path) -> int:
    with path.open("rb") as fh:
        header = fh.read(16)
    if header.startswith(b"PK\x03\x04"):
        return 0
    if not header.startswith(b"Cr24") or len(header) < 12:
        die("input is neither ZIP nor CRX")
    version = struct.unpack("<I", header[4:8])[0]
    if version == 2:
        pub_len, sig_len = struct.unpack("<II", header[8:16])
        return 16 + pub_len + sig_len
    if version == 3:
        header_len = struct.unpack("<I", header[8:12])[0]
        return 12 + header_len
    die(f"unsupported CRX version: {version}")


def extract_zip_payload(path: Path, destination: Path) -> None:
    start = zip_start(path)
    with path.open("rb") as fh:
        fh.seek(start)
        payload = fh.read()
    tmp_zip = destination / ".payload.zip"
    tmp_zip.write_bytes(payload)
    with zipfile.ZipFile(tmp_zip) as archive:
        for member in archive.infolist():
            target = (destination / member.filename).resolve()
            if destination.resolve() not in [target, *target.parents]:
                die(f"archive path traversal rejected: {member.filename}")
        archive.extractall(destination)
    tmp_zip.unlink()


def find_unpacked_root(path: Path) -> Path:
    root_manifest = path / "manifest.json"
    if root_manifest.is_file():
        return path
    manifests = [p for p in path.rglob("manifest.json") if p.is_file()]
    if len(manifests) == 1:
        return manifests[0].parent
    if not manifests:
        die("no manifest.json found")
    die("multiple manifest.json files found; pass the intended unpacked directory")


def copy_tree(src: Path, dst: Path) -> None:
    if dst.exists():
        shutil.rmtree(dst)
    ignore = shutil.ignore_patterns(
        "Cookies*",
        "Login Data*",
        "History*",
        "Preferences",
        "Secure Preferences",
        "Local State",
        "Cache",
        "Code Cache",
        "Session Storage",
        "Local Storage",
        "IndexedDB",
    )
    shutil.copytree(src, dst, symlinks=False, ignore=ignore)


def main() -> None:
    if len(sys.argv) not in (2, 3):
        die("usage: sanctuary-cde-extension-import <unpacked-dir|extension.crx|extension.zip> [shelf-name]", 2)

    source = Path(sys.argv[1]).expanduser().resolve()
    if not source.exists():
        die(f"source not found: {source}")

    guest_home = Path(os.environ.get("HOME", "")).expanduser()
    if not guest_home or not guest_home.is_dir():
        die("HOME is not a directory")
    shelf = guest_home / ".local/share/cde/extensions/chromium"
    shelf.mkdir(parents=True, exist_ok=True)

    explicit_name = sys.argv[2] if len(sys.argv) == 3 else None
    if source.is_dir():
        unpacked = find_unpacked_root(source)
        name = safe_name(explicit_name or f"{source.parent.name}-{source.name}")
        target = shelf / name
        copy_tree(unpacked, target)
    else:
        with tempfile.TemporaryDirectory(prefix="sanctuary-cde-extension-") as tmp:
            tmp_path = Path(tmp)
            extract_zip_payload(source, tmp_path)
            unpacked = find_unpacked_root(tmp_path)
            name = safe_name(explicit_name or source.stem)
            target = shelf / name
            copy_tree(unpacked, target)

    if not (target / "manifest.json").is_file():
        die("import failed: target has no manifest.json")
    print(target)


if __name__ == "__main__":
    main()
#+END_SRC

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-cde-build :shebang "#!/usr/bin/env bash"
# Build CDE 2.5.3 from source inside the sanctuary-cde container.
# Run once from the host: sanctuary-cde-build
# Uses the official CDE 2.5.3 release (SourceForge, 2025-11-25).
# NOT the 2012 arcfide/CDesktopEnv clone.
set -euo pipefail

CDE_VERSION="2.5.3"
SANCTUARY="sanctuary-cde"
GUIX_PROFILES="${HOME}/.guix-extra-profiles"

# body are just text (no quoting-state effects on the outer shell).
# Outer-shell vars (CDE_VERSION, GUIX_PROFILES) expand at heredoc time;
# inner-shell vars (HOME, CDE_PREFIX, etc.) are deferred via backslash-$.

CDE_PREFIX=\${HOME}/.local/share/cde
CDE_SRC=\${HOME}/.local/share/cde-src
CDE_TARBALL=cde-${CDE_VERSION}.tar.gz
CDE_URL=https://downloads.sourceforge.net/project/cdesktopenv/src/\${CDE_TARBALL}

. \${GUIX_PROFILE}/etc/profile
export CURL_CA_BUNDLE=\${GIT_SSL_CAINFO}

# Idempotent post-install fixups — run on every invocation (before early-exit).
if [ -d "\${CDE_PREFIX}/bin" ]; then
  # CDE ksh scripts hardcode /usr/bin/tr; Guix puts it at /bin/tr only.
  ln -sf /bin/tr /usr/bin/tr 2>/dev/null || true
  # Create fonts.dir so xset fp+ accepts the fontaliases directory.
  printf '0\n' > "\${CDE_PREFIX}/etc/cde/fontaliases/fonts.dir"
  # Fix hardcoded /usr/dt/bin/ paths in installed CDE action database.
  if ls "\${CDE_PREFIX}/appconfig/types/C/"*.dt >/dev/null 2>&1; then

      "\${CDE_PREFIX}"/appconfig/types/C/*.dt 2>/dev/null || true

  if [ -f "\${CDE_PREFIX}/appconfig/types/C/uxstd.dt" ]; then

  if [ -d "\${PTYPE_DIR}" ]; then
    sed -i "s|/usr/dt/infolib/|\${CDE_PREFIX}/infolib/|g" \
      "\${PTYPE_DIR}/dtinfo.ptype" "\${PTYPE_DIR}/dtinfo_start.ptype" 2>/dev/null || true
    sed -i "s|/usr/dt/bin/dtinfo|\${CDE_PREFIX}/bin/dtinfo|g" \
      "\${PTYPE_DIR}/dtinfo.ptype" 2>/dev/null || true
    _TTBUILD=\$(mktemp -d)
    (cd "\${PTYPE_DIR}"
     for _ptype in dtfile dticon dtpad dtcm dtmail dtdbcache dtterm dtinfo_start dtinfo; do
       [ -f "\${_ptype}.ptype" ] || continue
       TTPATH="\${_TTBUILD}" "\${CDE_PREFIX}/bin/tt_type_comp" -sd user -m "\${_ptype}.ptype" \
         2>/dev/null || true
     done)
    [ -f "\${_TTBUILD}/types.xdr" ] && \
      cp "\${_TTBUILD}/types.xdr" "\${CDE_PREFIX}/appconfig/tttypes/types.xdr"
    rm -rf "\${_TTBUILD}"
  fi

  #    container. saverTimeout (screen blank) is kept; lockTimeout=0 ensures
  #    the password prompt never appears.
  sed -i 's/^dtsession\*lockTimeout:.*$/dtsession*lockTimeout:   0/' \
      "\${CDE_PREFIX}/config/C/sys.resources" 2>/dev/null || true

  #    The FrontPanel Lock button calls dtlock via dtsession; this wrapper
  #    activates X11 blanking instead of demanding a password.
  if [ -f "\${CDE_PREFIX}/bin/dtlock" ] && \
     ! grep -q 'DotCortex dtlock wrapper' "\${CDE_PREFIX}/bin/dtlock" 2>/dev/null; then
    mv "\${CDE_PREFIX}/bin/dtlock" "\${CDE_PREFIX}/bin/dtlock.real"

  chmod +x "\${CDE_PREFIX}/bin/dtlock"
  # 3. Guard starship init in guest ~/.bashrc (Bash is the default dtterm shell).
  if ! grep -q 'command -v starship' "\${HOME}/.bashrc" 2>/dev/null; then

  #    chromium.dt calls chromium-browser; ungoogled-chromium (Guix) provides chromium.

  #    supertux.dt calls supertux; the Guix supertux package provides supertux2.

shelf="\${HOME}/.local/share/cde/extensions/chromium"
extensions=""

    extensions="\$(find "\${shelf}" -mindepth 2 -maxdepth 2 -name manifest.json -printf '%h\n' 2>/dev/null | sort | paste -sd, -)"
fi

    exec chromium --load-extension="\${extensions}" "\$@"
fi
exec chromium "\$@"
CHROMIUM_BROWSER_WRAPPER
    chmod +x "\${CDE_PREFIX}/bin/chromium-browser"
  fi
  if command -v icedove >/dev/null 2>&1; then
    printf '#!/bin/sh\nexec icedove "\$@"\n' > "\${CDE_PREFIX}/bin/thunderbird"
    chmod +x "\${CDE_PREFIX}/bin/thunderbird"
  fi
  if command -v supertux2 >/dev/null 2>&1; then
    printf '#!/bin/sh\nexec supertux2 "\$@"\n' > "\${CDE_PREFIX}/bin/supertux"
    chmod +x "\${CDE_PREFIX}/bin/supertux"
  fi
  # 5. Write sanctuary.dt — DotCortex CDE action additions (idempotent rewrite).

** Font provision script

Stages Microsoft and period-appropriate fonts into the room's private font directory
at =~/.local/share/dotcortex/guests/sanctuary-redstone-9x/fonts/=.  This path is
outside DotCortex git (mutable guest state).  The launch script symlinks this dir
into the guest home's =.local/share/fonts/redstone-9x= for fontconfig.

Provenance table:

|---------------|------------------------------|------------------|------------------|
| Arial         | Winetricks =corefonts=       | Microsoft EULA   | Auto-install into Redstone prefix |
| Tahoma        | Winetricks =tahoma=          | Microsoft EULA   | Auto-install into Redstone prefix |
| Times New Roman | Winetricks =corefonts=     | Microsoft EULA   | Auto-install into Redstone prefix |
| Courier New   | Winetricks =corefonts=       | Microsoft EULA   | Auto-install into Redstone prefix |
| Cascadia Mono | github.com/microsoft/cascadia-code | MIT       | Auto-download    |
| Lucida Console | Winetricks =lucida=          | Microsoft EULA   | Auto-install into Redstone prefix |
| Consolas      | Winetricks =consolas=        | Microsoft EULA   | Auto-install into Redstone prefix |
| Verdana       | Winetricks =corefonts=       | Microsoft EULA   | Auto-install into Redstone prefix |
| Webdings      | Winetricks =webdings=        | Microsoft EULA   | Auto-install into Redstone prefix |

Run: =redstone-9x-font-provision= (once; idempotent).

#+BEGIN_SRC bash :tangle linux/.local/bin/redstone-9x-font-provision :shebang "#!/usr/bin/env bash" :tangle-mode (identity #o755)
set -euo pipefail

SANCTUARY="sanctuary-redstone-9x"
GUESTS_DIR="${XDG_DATA_HOME:-$HOME/.local/share}/dotcortex/guests"
FONT_STAGE="${GUESTS_DIR}/${SANCTUARY}/fonts"
FONT_WINEPREFIX="${GUESTS_DIR}/${SANCTUARY}/font-provision-prefix"
mkdir -p "${FONT_STAGE}"

STAGED=0

# Source 1: Winetricks Microsoft font verbs.
# Use a managed font-provisioning prefix so active Redstone Wine sessions do not
# block font installation. Never use the default ~/.wine.
WINE_PROFILE="${HOME}/.guix-extra-profiles/room-windows-compat/room-windows-compat"
if [[ -x "${WINE_PROFILE}/bin/winetricks" ]]; then
  echo "redstone-9x-fonts: installing Microsoft fonts via Winetricks…"
  WINEPREFIX="${FONT_WINEPREFIX}" \
  WINEARCH=win32 \
  WINEDEBUG=-all \
  PATH="${WINE_PROFILE}/bin:${PATH}" \
    "${WINE_PROFILE}/bin/winetricks" -q corefonts tahoma webdings lucida consolas

  PREFIX_FONTS="${FONT_WINEPREFIX}/drive_c/windows/Fonts"
  if [[ -d "${PREFIX_FONTS}" ]]; then
    for font in \
      andale32.exe arial.ttf arialbd.ttf arialbi.ttf ariali.ttf ariblk.ttf \
      comic.ttf comicbd.ttf cour.ttf courbd.ttf courbi.ttf couri.ttf \
      georgia.ttf georgiab.ttf georgiai.ttf georgiaz.ttf impact.ttf \
      lucon.ttf consola.ttf consolab.ttf consolai.ttf consolaz.ttf \
      tahoma.ttf tahomabd.ttf times.ttf timesbd.ttf timesbi.ttf timesi.ttf \
      trebuc.ttf trebucbd.ttf trebucbi.ttf trebucit.ttf verdana.ttf \
      verdanab.ttf verdanai.ttf verdanaz.ttf webdings.ttf; do
      [[ -f "${PREFIX_FONTS}/${font}" ]] && cp -n "${PREFIX_FONTS}/${font}" "${FONT_STAGE}/"
    done
    find "${FONT_STAGE}" -maxdepth 1 -type f \( -iname "lucon.ttf" -o -iname "consola.ttf" -o -iname "cour.ttf" \) | grep -q . && STAGED=1
  fi
else
  echo "redstone-9x-fonts: winetricks not available — build room-windows-compat first"
fi

# Source 2: GE-Proton Wine fonts from X230 NFS (fallback/cache when mounted)
GEPROTON_FONTS="/home/metsatron/mnt/x230/.steam/compatibilitytools.d/GE-Proton7-45/files/share/wine/fonts"
if [[ -d "${GEPROTON_FONTS}" ]]; then
  echo "redstone-9x-fonts: copying from GE-Proton7 (X230 NFS)…"
  cp -n "${GEPROTON_FONTS}"/*.ttf "${FONT_STAGE}/" 2>/dev/null || true
  STAGED=1
else
  echo "redstone-9x-fonts: X230 NFS not mounted — skipping GE-Proton fonts"
fi

# Source 3: Guix wine64 profile fonts (fallback; available once room-windows-compat is built)
GUIX_WINE_FONTS="${WINE_PROFILE}/share/wine/fonts"

  echo "redstone-9x-fonts: copying from Guix wine64 profile…"
  cp -n "${GUIX_WINE_FONTS}"/*.ttf "${FONT_STAGE}/" 2>/dev/null || true
  STAGED=1
fi

# Source 4: Cascadia Mono (MIT licence — auto-download)
CASCADIA_TTF="${FONT_STAGE}/CascadiaMono.ttf"
if [[ ! -f "${CASCADIA_TTF}" ]]; then
  echo "redstone-9x-fonts: downloading Cascadia Mono (MIT)…"
  CASCADIA_URL="https://github.com/microsoft/cascadia-code/releases/download/v2404.23/CascadiaCode-2404.23.zip"
  CASCADIA_TMP="$(mktemp -d)"
  trap "rm -rf '${CASCADIA_TMP}'" EXIT
  curl -L --fail -o "${CASCADIA_TMP}/cascadia.zip" "${CASCADIA_URL}"
  unzip -q "${CASCADIA_TMP}/cascadia.zip" "ttf/CascadiaMono.ttf" -d "${CASCADIA_TMP}" 2>/dev/null \
    || unzip -q "${CASCADIA_TMP}/cascadia.zip" "*CascadiaMono.ttf" -d "${CASCADIA_TMP}" 2>/dev/null
  find "${CASCADIA_TMP}" -name "CascadiaMono*.ttf" -exec cp -n {} "${FONT_STAGE}/" \;
  STAGED=1
fi

echo ""
echo "Font staging complete: ${FONT_STAGE}"
ls "${FONT_STAGE}/"
if [[ "${STAGED}" -eq 0 ]]; then

echo "Fonts requiring manual provisioning (proprietary):"
echo "  MS Sans Serif   — extract from Windows install if exact bitmap UI fallback is needed"

    if ($null -eq $line) { break }
    if ($line.Trim() -eq "exit") { break }
    if ($line.Trim().Length -eq 0) { continue }

    try {
        Invoke-Expression $line
    }
    catch {
        Write-Error $_
    }

* Sanctuary: sanctuary-sx — SX-Window XLibre/X11 Habitat

An XFCE-based XLibre/X11 habitat for a living continuation of Sharp X68000 SX-Window and Ko-Window visual culture. It uses XFCE as a flexible, manually tuneable chassis, beginning from a Windows-3.1-adjacent visual baseline and evolving toward a bespoke Japanese early-1990s workstation grammar. It is intended to host native Linux applications alongside future machine-islands for X68000, PC-98, FM Towns, DOSBox-X, Wine, ScummVM, and related God-PC-era environments.

Stack: Guix base + XFCE desktop stack (no source build required; packages come from host =/gnu/store=).
Guix profiles sourced: =desktop-common= + =sanctuary-sx= (xfce4-session, xfwm4, xfconf, panel, settings, desktop, appfinder, thunar, xfce4-terminal).

Host virtual desktop: current host desktop. Xephyr display: =:94=.
Agent doorway: =distrobox enter sanctuary-sx -- <cmd>=
Launch: =sanctuary-sx-launch=
Capture: =sanctuary-sx-capture= (dry-run by default; =--apply= to write to DotCortex source)

Guest home: =$XDG_DATA_HOME/dotcortex/guests/sanctuary-sx/home/=

** Visual Grammar and Baseline

The initial payload is stock XFCE, started cleanly inside the Xephyr display. The intended visual grammar — woven cross-hatched grey root-desktop texture, narrow black keylines, restrained bevels, horizontal segmented titlebars, compact controls, a fixed vertical left device/tool rail, grayscale bitmap-style icons with selective Sharp/X68000 green accents, and Japanese and English labels living together — is built by the user manually through XFCE's own configuration tools. The sanctuary is designed for manual exploration and iteration, not automated theming.

The initial XFCE session starts from its own defaults. A Windows-3.1-adjacent XFWM4 theme provides the starting geometry; the user tunes from there toward the SX/Ko grammar.

** Configuration Projection (post-capture)

After a manual shaping pass, use =sanctuary-sx-capture= to inventory changed XFCE config and copy selected files into DotCortex source at =linux/.config/sanctuary-sx/=. The launch script will then project those captured files back into the guest home via symlinks on subsequent launches. Only curated, intentional files enter DotCortex; caches, session state, and machine-specific display layout are excluded.

Capture candidates:

- =.config/xfce4/xfconf/xfce-perchannel-xml/= (xfwm4, xfce4-panel, xfce4-desktop, xfce4-keyboard-shortcuts, xsettings, thunar)
- =.config/xfce4/panel/=
- =.themes/= (custom XFWM4 theme and GTK theme directories)
- =.icons/= (custom icon themes and cursor themes)
- =.local/share/applications/= (custom launchers)
- Selected =.local/share/xfce4/= content

Run =sanctuary-sx-capture= (dry-run) first to review the inventory. Pass =--apply= to write the selected files. Commit the DotCortex source changes with =/commit= after review.

** Future Habitat Content

Once the visual grammar is stable, sanctuary-sx is intended to host machine-islands for:

- X68000 (Sharp MZ/X68k emulation)
- PC-98 (Neko Project II / np21w)
- FM Towns (Tsugaru)
- DOSBox-X (MS-DOS / Windows 3.x / 9x)
- Wine (Windows compatibility)
- ScummVM (adventure game engine)
- Native Linux applications in the SX visual frame

These are future content, not a requirement for the initial declaration.

** Godzilla XS-86000 library, state, and menu foundation

Godzilla XS-86000 is the visible identity of =sanctuary-sx=.  The technical
identifier remains =sanctuary-sx= for containers, guest homes, manifests,
helpers, and Xephyr display wiring.

Shared media lives in =~/RetroPie= and is treated as a durable media library,
not a RetroPie OS installation.  Emulator configuration, Wine prefixes, saves,
caches, shader cache, Lutris state, and generated thumbnails stay in
=XDG_DATA_HOME/godzilla-xs= and =XDG_CONFIG_HOME/godzilla-xs= inside the
sanctuary guest home.

Bus policy:
- X68 BUS: XEiJ primary; XM6 under Wine fallback only.
- DRIVE A: PC-98: NP2Kai primary; T98-Next under Wine fallback only.
- DRIVE B: PC-88: QUASI88 primary; MAME fallback only, not the front end.
- FM TOWNS: Tsugaru primary; ScummVM supplement; UNZ under Wine fallback only.
- ARCADE BUS: MAME only.  Neo Geo is SNK Neo Geo MVS arcade hardware.
- PC COMPATIBILITY BOARD: Wine/Lutris Japanese and period PC software.

No Saturn bus, no Nintendo/Super Famicom bus, no FBNeo/FinalBurn Alpha arcade
runtime, and no private/adult quarantine category.

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-sx-capture :shebang "#!/usr/bin/env bash"
# Inventory and copy manually curated XFCE config from the sanctuary-sx guest
# home into DotCortex declarative source at linux/.config/sanctuary-sx/.
#
# Usage: sanctuary-sx-capture [--apply]
#
# Default (no flags): dry-run — print capture inventory and stop.
# --apply: write selected files to DotCortex source.
#
# After the user has manually shaped the habitat, run this script (dry-run),
# review the inventory, then pass --apply to commit the curated selection.
# Then commit the DotCortex source changes with /commit.
#
# What is captured:
#   XFCE channel XML: xfwm4, xfce4-panel, xfce4-desktop,
#                     xfce4-keyboard-shortcuts, xsettings, thunar
#   Panel config:     .config/xfce4/panel/
#   Themes:           .themes/ (user-local, excluding system-managed)
#   Icons:            .icons/ (user-local icon/cursor themes)
#   Launchers:        .local/share/applications/ (custom .desktop files)
#
# What is excluded:
#   xfce4-session.xml     — session state (window positions, open apps)
#   xfce4-notifyd.xml     — notification daemon ephemeral state
#   displays.xml          — monitor layout (machine-specific)
#   xfce4-power-manager.xml — power/hardware settings (machine-specific)
#   *.db, *.sqlite, thumbnails/, recently-used.xbel, .cache/
set -euo pipefail

APPLY=0
if [[ "${1:-}" == "--apply" ]]; then
  APPLY=1
fi

GUESTS_DIR="${XDG_DATA_HOME:-$HOME/.local/share}/dotcortex/guests"
GUEST_HOME="${GUESTS_DIR}/sanctuary-sx/home"
DOTCORTEX_SX="${HOME}/DotCortex/linux/.config/sanctuary-sx"

if [[ ! -d "${GUEST_HOME}" ]]; then
  echo "sanctuary-sx-capture: guest home not found at ${GUEST_HOME}" >&2
  echo "  Run vm-homes-init and distrobox-sanctuaries-create first" >&2
  exit 1
fi

_captured=0
_skipped=0

_report() {
  local action="$1"
  local path="$2"
  printf '  [%s] %s\n' "${action}" "${path}"
}

_copy() {
  local src="$1"
  local dst_dir="$2"
  if [[ "${APPLY}" -eq 1 ]]; then
    mkdir -p "${dst_dir}"
    cp -a "${src}" "${dst_dir}/"
    _report "COPY" "${src#${GUEST_HOME}/} → linux/.config/sanctuary-sx/$(basename "${dst_dir}")/$(basename "${src}")"
  else
    _report "would copy" "${src#${GUEST_HOME}/} → linux/.config/sanctuary-sx/$(basename "${dst_dir}")/"
  fi
  (( _captured++ )) || true
}

_copy_dir() {
  local src="$1"
  local dst="$2"
  if [[ "${APPLY}" -eq 1 ]]; then
    mkdir -p "$(dirname "${dst}")"
    rsync -a --delete "${src}/" "${dst}/"
    _report "SYNC" "${src#${GUEST_HOME}/} → linux/.config/sanctuary-sx/$(basename "${dst}")/"
  else
    _report "would sync" "${src#${GUEST_HOME}/} → linux/.config/sanctuary-sx/$(basename "${dst}")/"
  fi
  (( _captured++ )) || true
}

echo "sanctuary-sx-capture: scanning ${GUEST_HOME}"
echo ""

# ---- XFCE channel XML (curated subset only) ----
XFCONF_SRC="${GUEST_HOME}/.config/xfce4/xfconf/xfce-perchannel-xml"
XFCONF_DST="${DOTCORTEX_SX}/xfconf"

CAPTURE_CHANNELS=(
  xfwm4
  xfce4-panel
  xfce4-desktop
  xfce4-keyboard-shortcuts
  keyboard-layout
  xsettings
  thunar

SKIP_CHANNELS=(

  xfce4-notifyd
  displays
  xfce4-power-manager

  else

      f="${XFCONF_SRC}/${channel}.xml"
      if [[ -f "${f}" ]]; then
        _copy "${f}" "${XFCONF_DST}"
      fi
    done
    for channel in "${SKIP_CHANNELS[@]}"; do
      f="${XFCONF_SRC}/${channel}.xml"
      [[ -f "${f}" ]] && { _report "skip (ephemeral)" "${channel}.xml"; (( _skipped++ )) || true; }
    done
  fi
  echo ""
fi

  echo ""
fi

echo "---"
if [[ "${APPLY}" -eq 0 ]]; then
  printf 'Dry-run complete: %d items would be captured, %d skipped.\n' "${_captured}" "${_skipped}"

else

  echo "Review with: git diff linux/.config/sanctuary-sx/"
  echo "Then commit with: /commit"
fi

** sanctuary-sx wallpaper

Set the sanctuary-sx XFCE wallpaper directly via xfconf, bypassing the broken
XFCE 4.20 folder-picker UI (\"Unable to load images from folder '(null)' — Operation was cancelled\").

Usage: =sanctuary-sx-wallpaper /path/to/image.png=

Requirements: sanctuary-sx container must be running with an XFCE session;
Xephyr display =:94= must be up; xfconf-query in PATH.

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-sx-wallpaper :shebang "#!/usr/bin/env bash" :mkdirp yes
# Apply the given PNG as sanctuary-sx (:94) desktop wallpaper.
# Usage: sanctuary-sx-wallpaper /absolute/or/relative/path.png
set -euo pipefail

DISPLAY=":94"
GUESTS_DIR="${XDG_DATA_HOME:-$HOME/.local/share}/dotcortex/guests"
GUEST_HOME="${GUESTS_DIR}/sanctuary-sx/home"
PROFILE_BIN="${HOME}/.guix-extra-profiles/sanctuary-sx/sanctuary-sx/bin"
XFCONF="${PROFILE_BIN}/xfconf-query"

usage() {
  echo "Usage: sanctuary-sx-wallpaper <image-path>" >&2
  echo "  Applies the wallpaper through xfconf on the running sanctuary-sx XFCE session." >&2
  echo "  Image must be a PNG readable inside the guest container namespace." >&2
  exit 1
}

(( $# == 1 )) || usage

wallpaper="$(readlink -f "$1")"
[[ -f "${wallpaper}" ]] || { echo "ERROR: not a file: ${wallpaper}" >&2; exit 1; }
[[ -r "${wallpaper}" ]] || { echo "ERROR: not readable: ${wallpaper}" >&2; exit 1; }

# --- locate the running session's D-Bus address ---
dbus_addr=""
for _pid in $(pgrep -f 'xfce4-session' 2>/dev/null || true); do
  _env=$(cat "/proc/${_pid}/environ" 2>/dev/null | tr '\0' '\n' || true)
  _dis=$(echo "${_env}" | grep '^DISPLAY=' | head -1 | cut -d= -f2)
  [[ "${_dis}" == ":94" ]] || continue
  _bus=$(echo "${_env}" | grep '^DBUS_SESSION_BUS_ADDRESS=' | head -1 | cut -d= -f2-)
  [[ -n "${_bus}" ]] && { dbus_addr="${_bus}"; break; }
done

[[ -n "${dbus_addr}" ]] || { echo "ERROR: sanctuary-sx XFCE session not found on :94" >&2; exit 1; }
export DBUS_SESSION_BUS_ADDRESS="${dbus_addr}"

# --- verify xfconf-query works ---
if ! "${XFCONF}" -c xfce4-desktop -lv >/dev/null 2>&1; then
  echo "ERROR: xfconf-query cannot reach xfconfd on session D-Bus" >&2
  exit 1
fi

# --- get the xrandr output name ---
output="$(DISPLAY="${DISPLAY}" xrandr --query 2>/dev/null | awk '/ connected/{print $1; exit}')"
[[ -n "${output}" ]] || { echo "ERROR: no connected xrandr output on :94" >&2; exit 1; }

# --- apply the wallpaper ---
prop="/backdrop/screen0/monitor${output}/workspace0/last-image"
style_prop="/backdrop/screen0/monitor${output}/workspace0/image-style"

"${XFCONF}" -c xfce4-desktop -p "${prop}" -t string -s "${wallpaper}" --create
"${XFCONF}" -c xfce4-desktop -p "${style_prop}" -t int -s 2 --create  # 2 = tiled

# --- restart xfdesktop if it's running on :94 ---
xfdesk_pid=""
for _pid in $(pgrep xfdesktop 2>/dev/null || true); do

#+BEGIN_SRC bash :tangle linux/.local/bin/distrobox-room :shebang "#!/usr/bin/env bash"
# Wrapper for common distrobox sanctuary operations.
# Usage: distrobox-room <verb> [sanctuary-name]
#   verbs: list, enter, stop, create, build
set -euo pipefail

VERB="${1:-list}"
ROOM="${2:-}"

case "$VERB" in
  list)
    distrobox list
    ;;
  enter)
    [[ -z "$ROOM" ]] && { echo "Usage: distrobox-room enter <sanctuary-name>"; exit 1; }
    sanctuary-exec "$ROOM"
    ;;
  stop)
    [[ -z "$ROOM" ]] && { echo "Usage: distrobox-room stop <sanctuary-name>"; exit 1; }
    distrobox stop "$ROOM"
    ;;
  create)
    distrobox-sanctuaries-create
    ;;
  build)
    sanctuary-base-build
    ;;
  *)
    echo "Unknown verb: $VERB"
    echo "Valid verbs: list, enter, stop, create, build"
    exit 1
    ;;
esac
