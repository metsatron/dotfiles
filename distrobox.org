* Purpose

Declares the three Phase 1 Distrobox desktop rooms using =distrobox assemble=.
Each room gets its own Xephyr display, KWin virtual desktop, DotCortex-tangled home,
and a read-only bind-mount of the host =/gnu/store=.

Apply with:
#+BEGIN_SRC bash :tangle no
distrobox assemble create --file ~/.config/virtualisation/distrobox-rooms.ini
#+END_SRC

* Phase 1A: room-qtile — Emacs Sanctuary

Stack: Guix-backed Distrobox + Qtile (Python WM) + multi-process Emacs.
Base image: TBD — candidate is a minimal Debian/Ubuntu base with Guix store projected in.
See =Guix-Package-Commons.md= for the profile composability design.

* Common Infrastructure Helper

#+BEGIN_SRC bash :tangle linux/.local/bin/distrobox-room :shebang "#!/usr/bin/env bash"
# Wrapper for common distrobox room operations.
# Usage: distrobox-room <verb> [room-name]
#   verbs: list, enter, stop, assemble
set -euo pipefail

ROOMS_INI="${XDG_CONFIG_HOME:-$HOME/.config}/virtualisation/distrobox-rooms.ini"
VERB="${1:-list}"
ROOM="${2:-}"

case "$VERB" in
  list)
    distrobox list
    ;;
  enter)
    [[ -z "$ROOM" ]] && { echo "Usage: distrobox-room enter <room-name>"; exit 1; }
    distrobox enter "$ROOM"
    ;;
  stop)
    [[ -z "$ROOM" ]] && { echo "Usage: distrobox-room stop <room-name>"; exit 1; }
    distrobox stop "$ROOM"
    ;;
  assemble)
    distrobox assemble create --file "$ROOMS_INI"
    ;;
  *)
    echo "Unknown verb: $VERB"
    echo "Valid verbs: list, enter, stop, assemble"
    exit 1
    ;;
esac
#+END_SRC
