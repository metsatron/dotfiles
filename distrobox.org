* Purpose

Declares the three Phase 1 Distrobox sanctuaries. Each sanctuary gets its own Xephyr
display, dedicated host virtual desktop (Super+1/2/3), and a Guix-packed base image.

Sanctuaries are created with =distrobox-sanctuaries-create= (tangled below). This is a
one-shot declarative script — to recreate a sanctuary:
=distrobox rm <name> && distrobox-sanctuaries-create=.

* Base Image Strategy — Guix Pack

Each sanctuary base image is built via =guix pack -f docker= from a combined manifest.
The packed image contains the Guix store closure baked in — no host store bind-mount
needed. The container is self-contained and reproducible.

Build flow (run on host before =distrobox-sanctuaries-create=):

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-base-build :shebang "#!/usr/bin/env bash"
# Build Distrobox base images for all three sanctuaries using guix pack.
# Produces Docker-format tarballs loaded into Podman.
# Run once before distrobox-sanctuaries-create, and re-run when manifests change.
#
# Requires: guix (channel-pinned), podman
set -euo pipefail

GUIX="${HOME}/.config/guix/current/bin/guix"
MANIFESTS="${HOME}/.config/guix/manifests"

build_and_load() {
  local name="$1"
  local manifest="$2"
  echo "==> Building guix pack for ${name}…"
  tarball="$( "$GUIX" pack -f docker \
    --entry-point=/bin/sh \
    -S /bin=bin -S /lib=lib \
    -m "${MANIFESTS}/sanctuaries/${manifest}" 2>&1 | tail -1 )"
  echo "    tarball: ${tarball}"
  echo "==> Loading into Podman as sanctuary-${name}:latest…"
  podman load < "${tarball}"
  # Tag the most-recent untagged image produced by this load
  image_id="$( podman images --format '{{.ID}}' | head -1 )"
  podman tag "${image_id}" "sanctuary-${name}:latest"
  echo "    tagged: sanctuary-${name}:latest"
}

* Phase 1A: sanctuary-qtile — Emacs Sanctuary

Stack: Guix-packed base + Qtile (Python WM) + multi-process Emacs.
Base image built from =all/.config/guix/manifests/sanctuaries/sanctuary-qtile.scm= once
the manifest stub has real content (=guix search python-qtile= to validate).

Host virtual desktop: *Desktop 1*, accessed via =Super+1=.
Xephyr display: =:90=.
Agent doorway: =distrobox exec --name sanctuary-qtile -- <cmd>=.

* Phase 1A: sanctuary-gnustep — GNU/NeXT Lineage Sanctuary

Stack: Window Maker + GNUstep.
Window Maker and GNUstep come from apt inside the container (=windowmaker=,
=gnustep-make=, =gnustep-base=, =gnustep-gui=). The Guix manifest provides
editor/shell layer from =desktop-common.scm=.
Base image: Debian bookworm slim + apt packages injected on first entry.

Host virtual desktop: *Desktop 2*, accessed via =Super+2=.
Xephyr display: =:91=.

* Phase 1B: sanctuary-cde — Motif/Sun Sanctuary

Stack: Open CDE compiled from source, pinned as git input.
Source: =github.com/arcfide/CDesktopEnv= or =cdesktopenv.sourceforge.io=.
Needs build toolchain + Motif/X11 deps.

Host virtual desktop: *Desktop 3*, accessed via =Super+3=.
Xephyr display: =:92=.

* Sanctuary Launcher Scripts

One launcher per sanctuary. Each launches Xephyr on the host, waits for the display,
then starts the WM inside the Distrobox container. Run from the host desktop.
Switch to the correct virtual desktop first (Super+N), then run the launcher.

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-qtile-launch :shebang "#!/usr/bin/env bash"
# Launch sanctuary-qtile on Xephyr :90 (full-screen on current host desktop).
# Bind: host Super+1 → switch to Desktop 1, then run this.
set -euo pipefail

DISPLAY_NUM=":90"
SANCTUARY="sanctuary-qtile"

# Start Xephyr full-screen (matches host resolution)
Xephyr "${DISPLAY_NUM}" -fullscreen -br -ac &
XEPHYR_PID=$!

# Wait for the Xephyr display to be ready
timeout 10 sh -c "until DISPLAY=${DISPLAY_NUM} xdpyinfo >/dev/null 2>&1; do sleep 0.1; done" \
  || { echo "Xephyr ${DISPLAY_NUM} did not become ready"; kill ${XEPHYR_PID}; exit 1; }

echo "Xephyr ${DISPLAY_NUM} ready — starting ${SANCTUARY}…"
# Launch Qtile inside the sanctuary container
DISPLAY="${DISPLAY_NUM}" distrobox exec --name "${SANCTUARY}" -- qtile start

# Clean up Xephyr when WM exits
kill "${XEPHYR_PID}" 2>/dev/null || true
#+END_SRC

* Common Infrastructure Helper

#+BEGIN_SRC bash :tangle linux/.local/bin/distrobox-room :shebang "#!/usr/bin/env bash"
# Wrapper for common distrobox sanctuary operations.
# Usage: distrobox-room <verb> [sanctuary-name]
#   verbs: list, enter, stop, create, build
set -euo pipefail

VERB="${1:-list}"
ROOM="${2:-}"

case "$VERB" in
  list)
    distrobox list
    ;;
  enter)
    [[ -z "$ROOM" ]] && { echo "Usage: distrobox-room enter <sanctuary-name>"; exit 1; }
    distrobox enter "$ROOM"
    ;;
  stop)
    [[ -z "$ROOM" ]] && { echo "Usage: distrobox-room stop <sanctuary-name>"; exit 1; }
    distrobox stop "$ROOM"
    ;;
  create)
    distrobox-sanctuaries-create
    ;;
  build)
    sanctuary-base-build
    ;;
  *)
    echo "Unknown verb: $VERB"
    echo "Valid verbs: list, enter, stop, create, build"
    exit 1
    ;;
esac
#+END_SRC
