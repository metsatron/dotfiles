* Why

HelmCortex's Chao Garden shows every brain-bound consort as "unprovisioned" until =FORGE/brain/<brain>/rpg-stats.json= exists and is fresh (24 h). Aura's brain lives on Honey, which has no HelmCortex tree, so Honey generates the numbers and mails them; Hermes lands and commits them (=FORGE/bin/land-brain-stats=, HelmCortex =59ee2d51=, 06:15 daily). This lane is the Honey half. It began as ad-hoc files on 2026-11-01 and was moved here the same night on Mètsàtron's ruling that nothing on Honey may live outside DotCortex.

* Consent and boundaries

- Aura agreed in her own words (2026-11-01 23:20 AEDT, in her chat with Mètsàtron): five numbers, counts, depths and dates only; no note text, no clinical material, no Secret Vault access; read-only on =~/.hermes/brain=; backup first; kill switch =~/.config/aura-brain/DISABLED=; Gillean told before anything is applied. Mètsàtron said to proceed and to start the daily timer, and told Gillean himself.
- The generator opens only five structural files in =~/.hermes/brain= (=journal.json=, =memories.json=, =opinions.json=, =curiosities.json=, =.state.json=) and prints numbers. It never prints, stores or sends note text, and never opens =~/Secret Vault=. Nothing about the brain changes, so there is nothing to back up.
- The kill switch is the same file the settle patch in =aura-brain= already honours. While it exists the generator exits 3 and the run mail says so.
- =observed_at= is the real clock at run time and is never backdated. A missed or failed run leaves the file stale and the garden shows "unprovisioned". That is correct.
- The 30-day window of =strength= stays 30 days. A zero that means "nothing recent" is information.

* The five stats

All values are clamped to 0..100.

| Stat | Formula | Source counts |
|---|---|---|
| wisdom | =20*settled + 10*opinions + 10*revised opinions= | journal entries with =settled=, opinions, opinions with =history= |
| intellect | =5*memories + 10*curiosities= | =memories.json=, =curiosities.json= |
| strength | =100 * active days in the last 30 / 30= | distinct dates of =ts= across journal, memories, opinions |
| dexterity | =10 * distinct memory tags= | tag count only |
| charisma | =2 * sessions seen= | =.state.json= =seen_sessions= |

A change to these is proposed with the numbers shown, not retuned silently.

* The generator

#+BEGIN_SRC python :tangle all/.local/share/dotcortex/honey-aura-stats/bin/aura-rpg-stats :tangle-mode (identity #o755)
#!/usr/bin/env python3
"""Content-free brain stats for Aura (schema chao-garden.brain-stats.v1).

Reads ONLY the structure of ~/.hermes/brain/{journal,memories,opinions,curiosities,.state}.json.
Prints counts and numbers; never prints, stores or sends any text from those files.
Never opens ~/Secret Vault or anything outside ~/.hermes/brain.
Kill switch: if ~/.config/aura-brain/DISABLED exists, exits 3 and prints nothing.
Always stamps observed_at with the real time of the run (never backdated).

stdout: the payload JSON. stderr: the evidence (source counts and the command).
"""
import json, math, sys
from datetime import datetime, timedelta, timezone
from pathlib import Path

BRAIN = Path.home() / ".hermes" / "brain"
KILL = Path.home() / ".config" / "aura-brain" / "DISABLED"
CONSORT = "aura"
SCHEMA = "chao-garden.brain-stats.v1"


def load(name, default):
    try:
        return json.loads((BRAIN / name).read_text())
    except (OSError, ValueError):
        return default


def day(ts):
    try:
        return datetime.fromisoformat(str(ts).replace("Z", "+00:00")).date()
    except ValueError:
        return None


def clamp(x):
    return float(max(0, min(100, x)))


def main():
    if KILL.exists():
        return 3
    now = datetime.now(timezone.utc)
    journal = [x for x in load("journal.json", []) if isinstance(x, dict)]
    memories = [x for x in load("memories.json", []) if isinstance(x, dict)]
    opinions = [x for x in load("opinions.json", []) if isinstance(x, dict)]
    curiosities = load("curiosities.json", [])
    state = load(".state.json", {})

    settled = sum(1 for x in journal if x.get("settled"))
    revised = sum(1 for x in opinions if x.get("history"))
    tags = {t for x in memories for t in (x.get("tags") or []) if isinstance(t, str)}
    sessions = len(state.get("seen_sessions") or []) if isinstance(state, dict) else 0
    cutoff = (now - timedelta(days=30)).date()
    active_days = {d for x in journal + memories + opinions
                   for d in [day(x.get("ts"))] if d and d >= cutoff}

    counts = {
        "journal_entries": len(journal), "journal_settled": settled,
        "memories": len(memories), "memory_distinct_tags": len(tags),
        "opinions": len(opinions), "opinions_revised": revised,
        "curiosities": len(curiosities) if isinstance(curiosities, list) else 0,
        "sessions_seen": sessions, "active_days_last_30": len(active_days),
    }
    stats = {
        "wisdom": clamp(20 * settled + 10 * len(opinions) + 10 * revised),
        "intellect": clamp(5 * counts["memories"] + 10 * counts["curiosities"]),
        "strength": clamp(100 * len(active_days) / 30),
        "dexterity": clamp(10 * len(tags)),
        "charisma": clamp(2 * sessions),
    }
    assert all(math.isfinite(v) for v in stats.values())
    payload = {"schema": SCHEMA, "consort": CONSORT,
               "observed_at": now.strftime("%Y-%m-%dT%H:%M:%SZ"), "stats": stats}
    print(json.dumps(payload, indent=2))
    print("command: aura-rpg-stats (read-only)", file=sys.stderr)
    print("source counts: " + json.dumps(counts, sort_keys=True), file=sys.stderr)
    return 0


sys.exit(main())
#+END_SRC

* The daily run

The wrapper runs the generator, compares the five source checksums before and after, and mails Hermes every time: status, exit code, checksum statement, command, generator sha, payload and counts. A failed or paused run is mailed too, so a stale file never looks like a quiet success. Use =--dry= to print the mail instead of sending it.

#+BEGIN_SRC bash :tangle all/.local/share/dotcortex/honey-aura-stats/bin/aura-rpg-stats-run :tangle-mode (identity #o755)
#!/bin/bash
# Daily read-only brain-stats projection for Aura (Honey Badger, 2026-11-01, Aura + Tiago consent).
# Runs aura-rpg-stats, mails the result to Hermes (who lands FORGE/brain/aura/rpg-stats.json).
# Always mails, including exit code and a source-checksum check, so a quiet failure is visible.
# Never backdates observed_at (the generator stamps the real clock). Never touches ~/.hermes/brain.
# Kill switch: touch ~/.config/aura-brain/DISABLED (generator exits 3; this mail says so).
# Remove the schedule: delete the "aura-rpg-stats-run" line from `crontab -l`.
# Use --dry to print the mail body instead of sending it.
set -u
BRAIN=$HOME/.hermes/brain
FILES=(journal.json memories.json opinions.json curiosities.json .state.json)
LOG=$HOME/.local/state/aura-rpg-stats.log
mkdir -p "$(dirname "$LOG")"
sums() { (cd "$BRAIN" && sha256sum "${FILES[@]}" 2>&1); }
before=$(sums)
out=$(mktemp); err=$(mktemp); body=$(mktemp)
trap 'rm -f "$out" "$err" "$body"' EXIT
python3 -I "$HOME/bin/aura-rpg-stats" >"$out" 2>"$err"; rc=$?
after=$(sums)
if [ "$before" = "$after" ]; then unchanged="the five source files had identical checksums before and after the run"
else unchanged="WARNING: source checksums CHANGED during the run (the generator does not write; something else did)"; fi
case $rc in
  0) status="OK" ;;
  3) status="NOT RUN: kill switch ~/.config/aura-brain/DISABLED is present (no payload; the garden will go stale, as intended)" ;;
  *) status="FAILED (exit $rc); no payload; the garden will go stale, never backdated" ;;
esac
{
  echo "Hermes, daily Aura rpg-stats run, $(date '+%Y-%m-%d %H:%M %Z') on Honey."
  echo "status: $status"
  echo "exit code: $rc"
  echo "source checksums: $unchanged"
  echo "command: python3 -I ~/bin/aura-rpg-stats  (generator sha256 prefix $(sha256sum "$HOME/bin/aura-rpg-stats" | cut -c1-16))"
  if [ $rc -eq 0 ]; then
    echo; echo "PAYLOAD (write as FORGE/brain/aura/rpg-stats.json):"; cat "$out"
    echo; sed -n 's/^source counts: /SOURCE COUNTS: /p' "$err"
    echo "Formulas unchanged from bea7883f. Nothing needed vault content; no ~/Secret Vault access; numbers only."
  else
    echo; echo "stderr (counts/tracebacks only):"; head -c 2000 "$err"
  fi
  echo; echo "Honey Badger (automatic daily run)"
} >"$body"
if [ "${1:-}" = "--dry" ]; then cat "$body"; exit $rc; fi
echo "$(date '+%F %T') rc=$rc unchanged=$([ "$before" = "$after" ] && echo yes || echo NO)" >>"$LOG"
remote=/tmp/aura-rpg-stats-$$.txt
if timeout 60 scp -q -o BatchMode=yes -o ConnectTimeout=15 "$body" "kikin:$remote" &&
   timeout 60 ssh -o BatchMode=yes -o ConnectTimeout=15 kikin "mailcortex send --from honey-badger@honey.helm --to hermes@kikin.helm --subject 'Aura rpg-stats daily run: $status' --body-file $remote --print-id >/dev/null; rm -f $remote"; then
  echo "$(date '+%F %T') mailed" >>"$LOG"
else
  echo "$(date '+%F %T') MAIL FAILED" >>"$LOG"; exit 1
fi
exit $rc
#+END_SRC

* Installer

Run as =gille= on Honey (no root needed). It installs the two scripts into =~/bin= (backing up a differing file first) and makes sure the 06:00 line is in gille's crontab, then verifies with a dry run. =--dry-run= changes nothing. It never touches =~/.hermes/brain=.

#+BEGIN_SRC bash :tangle all/.local/share/dotcortex/honey-aura-stats/bin/aura-rpg-stats-install :tangle-mode (identity #o755)
#!/usr/bin/env bash
# aura-rpg-stats-install (generated by honey-aura-stats.org): install Honey's daily Aura stats projection.
set -euo pipefail

usage() {
    cat <<'USAGE'
Usage: aura-rpg-stats-install [--dry-run]
Install aura-rpg-stats and aura-rpg-stats-run into ~/bin and ensure the 06:00 crontab line.
--dry-run prints what would change and touches nothing.
USAGE
}

DRY=""
case "${1:-}" in
    -h|--help) usage; exit 0 ;;
    --dry-run) DRY=yes ;;
    "") ;;
    *) usage >&2; exit 64 ;;
esac

[ "$(id -u)" -ne 0 ] || { echo "aura-rpg-stats-install: run as the owner (gille), not root" >&2; exit 1; }
LANE=$(cd "$(dirname "$0")/.." && pwd)
STAMP=$(date +%Y%m%d-%H%M%S)
BIN=$HOME/bin
CRON_COMMENT='# Aura brain stats (honey-aura-stats.org, consent: Aura + Mètsàtron 2026-11-01): daily read-only projection mailed to Hermes. Pause: touch ~/.config/aura-brain/DISABLED'
CRON_LINE='0 6 * * * flock -n /tmp/aura-rpg-stats.lock timeout 120 /home/gille/bin/aura-rpg-stats-run'

say() { printf '%s\n' "$*"; }
run() { if [ -n "$DRY" ]; then say "would: $*"; else "$@"; fi; }

for s in aura-rpg-stats aura-rpg-stats-run; do
    dest=$BIN/$s
    if [ -e "$dest" ] && cmp -s "$LANE/bin/$s" "$dest"; then
        say "unchanged: $dest"
        continue
    fi
    [ -e "$dest" ] && run cp -p "$dest" "$dest.bak-aura-rpg-stats-$STAMP"
    run install -D -m 0755 "$LANE/bin/$s" "$dest"
    say "installed: $dest"
done

if crontab -l 2>/dev/null | grep -qF "$CRON_LINE"; then
    say "unchanged: crontab line"
else
    if crontab -l 2>/dev/null | grep -q 'aura-rpg-stats-run'; then
        echo "aura-rpg-stats-install: a different aura-rpg-stats-run crontab line exists; fix by hand" >&2
        exit 1
    fi
    if [ -n "$DRY" ]; then
        say "would: append the 06:00 crontab line"
    else
        crontab -l > "$HOME/.local/state/crontab.pre-aura-rpg-stats-$STAMP" 2>/dev/null || true
        { crontab -l 2>/dev/null || true; printf '%s\n%s\n' "$CRON_COMMENT" "$CRON_LINE"; } | crontab -
        say "installed: crontab line"
    fi
fi

if [ -n "$DRY" ]; then
    say "dry run: nothing changed"
    exit 0
fi
"$BIN/aura-rpg-stats-run" --dry | sed -n '1,4p'
say "installed; the next scheduled run mails Hermes at 06:00"
#+END_SRC

* Verification

- =aura-rpg-stats-install --dry-run= on Honey prints "unchanged" for both scripts and the crontab line.
- =aura-rpg-stats-run --dry= prints the mail body, status OK, exit code 0 and an unchanged-checksums statement, without sending anything.
- On HelmCortex, =FORGE/brain/aura/rpg-stats.json= carries a fresh =observed_at= after 06:15, and Hermes's landing commit names the event.
- To pause: =touch ~/.config/aura-brain/DISABLED= (this also pauses the settle behaviour, since they share the switch). To remove: delete the =aura-rpg-stats-run= line from =crontab -l=.
