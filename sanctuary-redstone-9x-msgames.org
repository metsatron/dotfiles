* What this is

NtGm's collected pack of Microsoft games shipped with Windows, 3.x through 7, installed into the Redstone 9X Wine prefix and wired into the Start menu under Wine → Games → Microsoft Games, split by era.

This *replaces* the earlier =sanctuary-redstone-9x-w2k.org= three-game module, whose Internet Archive source turned out to be the Portuguese (=LANGID 2070=, pt-PT) build. The 9x + 2000 binaries here are English.

It does *not* replace =sanctuary-redstone-9x-wep.org=. That module installs the 1994 "Best of" Entertainment Pack from the original single-floppy disc image and keeps its own provenance; the Windows 3.x menu here lists only the Entertainment Pack titles that floppy did *not* carry, so nothing appears twice.

** Coverage

| Era | Titles |
|-----+--------|
| Windows 3.x | Reversi, plus 16 Entertainment Pack titles beyond the Best-of floppy (Chess, Cruel, Fuji Golf, Go Figure, IdleWild, JigSawed, Klotski, Life Genesis, Maxwell's Maniac, Pegged, Rattler Race, Stones, TicTactics, Tic Tac Drop, Minesweeper, WordZap) |
| Windows 9x + 2000 | Solitaire, FreeCell, Minesweeper, Hover!, 3D Pinball Space Cadet |
| Windows XP | Solitaire, FreeCell, Minesweeper, Spider Solitaire, Hearts, 3D Pinball, MSN Gaming Zone clients |
| Windows Vista + 7 | Chess Titans, FreeCell, Hearts, Hold'Em, InkBall, Mahjong Titans, Minesweeper, Purble Place, Solitaire, Spider Solitaire, Tinker, Multiplayer (Backgammon/Checkers/Spades) |

Binary classes differ by era and that is the whole reason the room can host all of them: the 3.x titles are NE Win16 through =winevdm=, 9x/2000/XP are PE32 i386 through Wine's ordinary 32-bit path, and Vista/7 are PE32 with heavier runtime demands.

** Verified state

See the sweep table in =Verification= below — every executable was launched headlessly on an isolated =Xvfb :97= and recorded as rendering a window or not. Titles that do not run are still installed but are kept out of the menu, so nothing in the Start menu is a dead entry.

** Provenance

Internet Archive item =ntgm-except-in-nebraska= ("Microsoft's Windows Games"), uploaded 2023-07-12, assembled by the uploader from archive.org and win7games.com sources. Copyrighted Microsoft binaries: the archive is operator-supplied and never vendored into this public repo.

* Provisioner — redstone-9x-msgames-provision

Host-side, idempotent. Extracts the pack once into the guest media area, then installs each era into its own directory under =C:\MSGAMES=, and pulls an icon out of every executable.

#+BEGIN_SRC bash :tangle linux/.local/bin/redstone-9x-msgames-provision :shebang "#!/bin/bash" :tangle-mode (identity #o755)
set -euo pipefail

SANCTUARY="sanctuary-redstone-9x"
GUESTS_DIR="${XDG_DATA_HOME:-$HOME/.local/share}/dotcortex/guests"
GUEST_HOME="${GUESTS_DIR}/${SANCTUARY}/home"
WINEPREFIX="${WINEPREFIX:-${GUEST_HOME}/.wine-redstone}"
MEDIA="${GUESTS_DIR}/${SANCTUARY}/media/msgames"
DEST="${WINEPREFIX}/drive_c/MSGAMES"
ICONDIR="${GUEST_HOME}/.local/share/icons"
ICEWM_ICONS="${GUEST_HOME}/.icewm/icons"
HICOLOR="${ICONDIR}/hicolor"
ICON_SIZES="16 22 24 32 48"
MARKER="${DEST}/.dotcortex-msgames-complete"
WINE_PROFILE="${HOME}/.guix-extra-profiles/room-windows-compat/room-windows-compat"

# The archive filename contains an apostrophe ("NtGm's Pack of ..."). Do NOT
# inline it as a ${VAR:-default} fallback: inside the expansion bash treats that
# apostrophe as an opening quote, silently swallows the rest of the script, and
# the first thing that fails to parse is a heredoc eighty lines later. Assign
# the default on its own line, where plain double quotes handle it correctly.
DEFAULT_ZIP="${HOME}/HelmCortex/NEXUS/sanctuaries/sanctuary-redstone-9x/media/ntgm-except-in-nebraska/NtGm's Pack of Microsoft Games.zip"
ARCHIVE="${MSGAMES_ZIP:-${DEFAULT_ZIP}}"

FORCE=0; RESTAGE=0
for a in "$@"; do
  case "${a}" in
    --force)   FORCE=1 ;;
    --restage) FORCE=1; RESTAGE=1 ;;
  esac
done

if [[ -f "${MARKER}" && "${FORCE}" -eq 0 ]]; then
  echo "redstone-9x-msgames: already provisioned (${DEST}) — use --force to redo"
  exit 0
fi

if [[ ! -d "${WINEPREFIX}" ]]; then
  echo "redstone-9x-msgames: Wine prefix missing: ${WINEPREFIX}" >&2
  exit 1
fi

# ------------------------------------------------------------------ stage
if [[ "${RESTAGE}" -eq 1 || ! -d "${MEDIA}/Windows 3.x" ]]; then
  if [[ ! -f "${ARCHIVE}" ]]; then
    echo "redstone-9x-msgames: archive not found: ${ARCHIVE}"
    echo "  Supply one with MSGAMES_ZIP=/path/to.zip, or fetch the Internet"
    echo "  Archive item 'ntgm-except-in-nebraska'. Skipping."
    exit 0
  fi
  command -v unzip >/dev/null 2>&1 || { echo "redstone-9x-msgames: unzip not found" >&2; exit 1; }
  echo "redstone-9x-msgames: staging pack…"
  rm -rf "${MEDIA}"; mkdir -p "${MEDIA}"
  # One entry has a mojibake filename that trips unzip's local/central header
  # check; it is a .lnk we do not need, so a warning there is not fatal.
  unzip -q -o "${ARCHIVE}" -d "${MEDIA}" || true
else
  echo "redstone-9x-msgames: pack already staged at ${MEDIA} (--restage to redo)"
fi

[[ -d "${MEDIA}/Windows 3.x" ]] || { echo "redstone-9x-msgames: staging failed" >&2; exit 1; }

# ---------------------------------------------------------------- install
# One directory per era. Names are slugs so DOS-era code never meets a space.
declare -A ERAS=(
  [win3x]="Windows 3.x"
  [win9x]="Windows 9x + 2000"
  [winxp]="Windows XP"
  [win7]="Windows Vista + 7"
)

mkdir -p "${DEST}"
for slug in "${!ERAS[@]}"; do
  src="${MEDIA}/${ERAS[$slug]}"
  [[ -d "${src}" ]] || { echo "redstone-9x-msgames: WARN missing era ${ERAS[$slug]}" >&2; continue; }
  rm -rf "${DEST:?}/${slug}"
  mkdir -p "${DEST}/${slug}"
  cp -a "${src}/." "${DEST}/${slug}/"
  n="$(find "${DEST}/${slug}" -type f -iname '*.exe' | wc -l)"
  echo "redstone-9x-msgames: ${slug} — ${n} executables"
done

# cards.dll is needed beside the card games; the pack ships one per era already.
# Nothing else to place: these titles are self-contained directories.

# ------------------------------------------------------------------ icons
PY_PIL=""
for c in python3 "${HOME}/.guix-extra-profiles/desktop-common/desktop-common/bin/python3"; do
  "${c}" -c 'from PIL import Image' >/dev/null 2>&1 && { PY_PIL="${c}"; break; }
done
WRESTOOL="${WINE_PROFILE}/bin/wrestool"
ICOTOOL="${WINE_PROFILE}/bin/icotool"

if [[ -x "${WRESTOOL}" && -x "${ICOTOOL}" && -n "${PY_PIL}" ]]; then
  echo "redstone-9x-msgames: extracting icons…"
  TMPICO="$(mktemp -d)"
  trap 'rm -rf "${TMPICO}"' EXIT
  export LC_ALL=C
  mkdir -p "${TMPICO}/staged"
  n=0
  while IFS= read -r exe; do
    rel="${exe#${DEST}/}"
    slug="msg-$(echo "${rel}" | tr 'A-Z' 'a-z' | sed 's/\.exe$//' | tr -c 'a-z0-9\n' '-' | tr -s '-' | sed 's/^-//; s/-$//')"
    rm -rf "${TMPICO:?}/work"; mkdir -p "${TMPICO}/work/out"
    "${WRESTOOL}" -x -t 14 -o "${TMPICO}/work" "${exe}" 2>/dev/null || true
    ico="$(find "${TMPICO}/work" -maxdepth 1 -type f -name '*.ico' | sort | head -1)"
    [[ -n "${ico}" ]] || continue
    "${ICOTOOL}" -x -o "${TMPICO}/work/out" "${ico}" 2>/dev/null || true
    # Width first, then depth: these groups mix sizes and a depth-only sort can
    # pick a 16x16 and upscale it into every larger slot.
    png="$(find "${TMPICO}/work/out" -type f -name '*.png' \
             | sed 's/.*_\([0-9]\+\)x[0-9]\+x\([0-9]\+\)\.png$/\1 \2 &/' \
             | sort -k1,1nr -k2,2nr | head -1 | cut -d' ' -f3-)"
    [[ -n "${png}" ]] || continue
    cp -f "${png}" "${TMPICO}/staged/${slug}.png"
    n=$((n + 1))
  done < <(find "${DEST}" -type f -iname '*.exe')

  "${PY_PIL}" - "${TMPICO}/staged" "${ICEWM_ICONS}" "${HICOLOR}" ${ICON_SIZES} <<'PYICON'
import os
import sys

from PIL import Image

staged, icewm_dir, hicolor = sys.argv[1], sys.argv[2], sys.argv[3]
sizes = [int(s) for s in sys.argv[4:]]
os.makedirs(icewm_dir, exist_ok=True)
written = 0
for name in sorted(os.listdir(staged)):
    if not name.endswith(".png"):
        continue
    stem = name[:-4]
    try:
        src = Image.open(os.path.join(staged, name)).convert("RGBA")
    except Exception:
        continue
    for size in sizes:
        img = src if src.size == (size, size) else src.resize((size, size), Image.NEAREST)
        img.save(os.path.join(icewm_dir, f"{stem}_{size}x{size}.png"))
        apps = os.path.join(hicolor, f"{size}x{size}", "apps")
        os.makedirs(apps, exist_ok=True)
        img.save(os.path.join(apps, f"{stem}.png"))
        written += 1
print(f"redstone-9x-msgames: {written} icon files from {written // len(sizes)} sources")
PYICON
  echo "redstone-9x-msgames: ${n} icons extracted"
else
  echo "redstone-9x-msgames: icon tooling unavailable — menu will use generic icons"
fi

touch "${MARKER}"
echo "redstone-9x-msgames: ready — ${DEST}"
echo "  Launch with: redstone-9x-msgames win3x REVERSI.EXE"
#+END_SRC

* Launcher — redstone-9x-msgames

Generic by design: era slug plus the executable's path relative to that era's directory. With sixty-odd titles a slug table would be pure maintenance burden, and the menu already knows the exact paths.

=#!/bin/bash= — the guest has no =/usr/bin/env=.

#+BEGIN_SRC bash :tangle linux/.local/bin/redstone-9x-msgames :shebang "#!/bin/bash" :tangle-mode (identity #o755)
set -euo pipefail

SANCTUARY="sanctuary-redstone-9x"
GUESTS_DIR="${XDG_DATA_HOME:-$HOME/.local/share}/dotcortex/guests"
GUEST_HOME="${GUESTS_DIR}/${SANCTUARY}/home"
GUIX_PROFILES="${HOME}/.guix-extra-profiles"

export WINEPREFIX="${WINEPREFIX:-${GUEST_HOME}/.wine-redstone}"
BASE="${WINEPREFIX}/drive_c/MSGAMES"

source_guix_profile() {
  local profile="$1" status=0 had_nounset=0
  case $- in *u*) had_nounset=1; set +u ;; esac
  GUIX_PROFILE="$profile"; export GUIX_PROFILE
  . "$profile/etc/profile" || status=$?
  (( had_nounset )) && set -u
  return "$status"
}

for _prof in desktop-common room-gaming room-windows-compat; do
  source_guix_profile "${GUIX_PROFILES}/${_prof}/${_prof}"
done

export DISPLAY="${DISPLAY:-:93}"
export XDG_RUNTIME_DIR="${XDG_RUNTIME_DIR:-/run/user/$(id -u)}"
export WINEDEBUG="${WINEDEBUG:--all}"

ERA="${1:-}"
REL="${2:-}"

if [[ -z "${ERA}" || -z "${REL}" ]]; then
  echo "usage: redstone-9x-msgames <win3x|win9x|winxp|win7> <relative/path.exe>"
  echo "example: redstone-9x-msgames win3x REVERSI.EXE"
  exit 0
fi

case "${ERA}" in
  win3x|win9x|winxp|win7) ;;
  *) echo "redstone-9x-msgames: unknown era '${ERA}'" >&2; exit 1 ;;
esac

TARGET="${BASE}/${ERA}/${REL}"
if [[ ! -f "${TARGET}" ]]; then
  echo "redstone-9x-msgames: not installed: ${ERA}/${REL}" >&2
  echo "  run redstone-9x-msgames-provision" >&2
  exit 1
fi

cd "$(dirname "${TARGET}")"
exec wine "$(basename "${TARGET}")"
#+END_SRC
