* Sanctuary: sanctuary-redstone-9x — Redstone 9X IceWM

First gaming-wing sanctuary.  IceWM with the Windows NT theme.
Launch from the current host desktop. Xephyr display: =:93=.
Guix profiles: =desktop-common= + =room-gaming= (icewm, pcmanfm, xterm) + =room-windows-compat= (wine64, winetricks, fontconfig, powershell, DOS emulation tooling).

Current DOS direction (2026-07-07): =DOSEMU2= is the terminal-clean DOS lane.
=DOSBox-X= remains packaged in =room-windows-compat= as an integrated
compatibility lane for mouse-heavy DOS software, Windows 3.x, and booted
Win9x machine profiles. New Redstone DOS work uses the host-visible =.compat/=
runtime spine and =.dosemu/= bridge declared below.

The launcher projects =DotCortex/linux/.icewm/= directly into the isolated guest
home before launching Xephyr — IceWM reads config, theme, and menu from org-managed
source. =pcmanfm --desktop= (via =~/.icewm/startup=) manages Win95-style desktop
icons (My Computer, My Documents, Recycle Bin) from =linux/.icewm/desktop/=.
Recycle Bin opens the real on-disk Trash folder directly (no GVFS =trash://=
URI — room-gaming deliberately has no =gvfs=; a 2026-07-07 retry leaked the
HOST's real Trash contents into the sandboxed room via distrobox's /run/host
bind mount, on top of the earlier libfm crash risk — see
redstone-9x-state-digest.md) and a small poller (=redstone-9x-recycle-bin-watch=,
launched from =~/.icewm/startup=) keeps its icon in sync with full/empty state.

The Redstone create stanza uses Distrobox's existing =--init-hooks= mechanism to create
=/opt/retropie/supplementary/runcommand/= and symlink =runcommand.sh= to the projected guest-home
=~/.local/bin/runcommand-shim=. The target is projected by the launcher before either WM starts;
the hook is scoped to =sanctuary-redstone-9x=, whose IceWM and FVWM95 menus expose the ports lane.

prepare_retropie_tree() {
  local host_ports="${RETROPIE_HOST_ROOT}/roms/ports"
  local guest_link="${GUEST_HOME}/RetroPie"

  # Follow the host ~/RetroPie link before Podman starts. This access triggers
  # the direct autofs mount; if it cannot produce the NFS-backed ports tree,
  # stop before opening Xephyr or presenting an empty desktop menu.
  if ! stat -L -- "${host_ports}" >/dev/null 2>&1; then
    echo "${SANCTUARY}: ERROR — RetroPie tree unavailable on the host" >&2
    echo "  Expected a readable ports directory at: ${host_ports}" >&2
    echo "  The automount did not become available; container start was not attempted." >&2
    exit 1
  fi

  if [[ ! -d "${GUEST_HOME}" ]]; then
    echo "${SANCTUARY}: ERROR — guest home missing: ${GUEST_HOME}" >&2
    echo "  Run vm-homes-init first." >&2
    exit 1
  fi
  if [[ -e "${guest_link}" && ! -L "${guest_link}" ]]; then
    echo "${SANCTUARY}: ERROR — refusing to replace non-symlink guest path: ${guest_link}" >&2
    exit 1
  fi
  ln -sfnT "${RETROPIE_CONTAINER_ROOT}" "${guest_link}"

  sanctuary-retropie-bind-ensure "${SANCTUARY}" "${RETROPIE_CONTAINER_ROOT}"
}

# Project DotCortex-managed config into isolated guest home.
# Copy, do not symlink: the host repo path is not visible inside the container.
project_file() {
  local src="$1" dst="$2"
  mkdir -p "$(dirname "${dst}")"
  rm -f "${dst}"
  cp -f "${src}" "${dst}"
}

project_dir() {
  local src="$1" dst="$2" tmp="${2}.tmp"
  mkdir -p "$(dirname "${dst}")"
  rm -rf "${tmp}"
  cp -a "${src}" "${tmp}"
  rm -rf "${dst}"
  mv "${tmp}" "${dst}"
}

# Qt CA store — the sanctuary image ships an EMPTY /etc/ssl/certs, and QSslSocket
# builds its CA store by SCANNING that directory; SSL_CERT_FILE steers only plain
# OpenSSL, which Qt bypasses. Present-but-empty means every Qt TLS chain dies with
# "issuer certificate ... could not be found" (Zeal docset downloads, 2026-07-18).
# Symlink the desktop-common bundle at the Debian-convention path Qt checks first.
# Root-side write to the container layer: idempotent, survives restarts, and is
# re-asserted here every launch so recreation heals itself.
PODMAN_BIN="$(command -v podman 2>/dev/null || true)"
if [[ -n "${PODMAN_BIN}" ]]; then
  "${PODMAN_BIN}" exec --user 0:0 "${SANCTUARY}" sh -c \
    "mkdir -p /etc/ssl/certs && ln -sfn ${GUIX_PROFILES}/desktop-common/desktop-common/etc/ssl/certs/ca-certificates.crt /etc/ssl/certs/ca-certificates.crt" \

# Xfe stat-probes EVERY mtab entry each refresh — in-guest that includes the

# x230, …) raises a modal "Mount point … is not responding" per cycle. Its

# about mounts the sanctuary never uses. mount_warn=0 disables the dialogs.

# IceWM does not resolve icon names out of the Chicago95 XDG theme — pcmanfm (GTK)
# does, which is why the DESKTOP icons render from Chicago95 while the identical name
# in the menu or the quick-launch strip comes up empty.  Worse, IceWM does not draw a
# fallback: a toolbar `prog` whose icon it cannot find is dropped from the strip
# entirely, so the failure looks like a missing BUTTON, not a missing icon, and sends
# you hunting for the wrong bug.  Every icon name that appears to "work" in the menu
# (firefox_2, multimedia, system-file-manager) is one that also exists in a theme IceWM
# does read; nothing that lives only in Chicago95 ever resolves.
#
# IceWM's own icon directory always works, so graft the sanctuary's app icons there,
# size-suffixed the way IceWM expects.  Verified inside the guest: name lookup fails,
# ~/.icewm/icons and absolute paths both succeed.  The graft is scheme-aware

** Flatpak session service

Redstone runs its desktop inside a private =dbus-run-session=.  Flatpak's outer
sandbox needs =flatpak-session-helper= on that same bus so it can publish a
monitored =resolv.conf= under =/run/host/monitor=.  Without it, Flatpak falls
back to rebinding the container-managed =/etc/resolv.conf= and Bubblewrap dies
before Electron or Zypak starts.

#+BEGIN_SRC bash :tangle linux/.local/bin/redstone-9x-flatpak-session :shebang "#!/bin/bash" :tangle-mode (identity #o755)
set -euo pipefail

if [[ "$#" -lt 1 ]]; then
  echo "Usage: redstone-9x-flatpak-session <desktop-command> [args...]" >&2
  exit 2
fi

flatpak_bin="$(command -v flatpak 2>/dev/null || true)"
flatpak_real="$(readlink -f "${flatpak_bin}" 2>/dev/null || true)"
session_helper="${flatpak_real%/bin/flatpak}/libexec/flatpak-session-helper"
session_log="${XDG_RUNTIME_DIR:-/tmp}/redstone-9x-flatpak-session-helper.log"

if [[ -n "${flatpak_real}" && -x "${session_helper}" ]]; then
  "${session_helper}" --replace >"${session_log}" 2>&1 &
  helper_pid=$!
  helper_ready=0

  for _attempt in {1..50}; do
    if dbus-send --session --print-reply \
        --dest=org.freedesktop.Flatpak \
        /org/freedesktop/Flatpak/SessionHelper \
        org.freedesktop.Flatpak.SessionHelper.RequestSession \
        >/dev/null 2>&1; then
      helper_ready=1
      break
    fi
    kill -0 "${helper_pid}" 2>/dev/null || break
    sleep 0.1
  done

  if [[ "${helper_ready}" -ne 1 ]]; then
    echo "redstone-9x-flatpak-session: warning — Flatpak session helper unavailable; see ${session_log}" >&2
  fi
else
  echo "redstone-9x-flatpak-session: warning — flatpak-session-helper not found for ${flatpak_bin:-flatpak}" >&2
fi

exec "$@"
#+END_SRC

** Xclass + Explorer + Desktop build

Builds the rn10950 [[https://github.com/rn10950/FVWM95-Updated][FVWM95-Updated]] xclass library, the =Explorer= file
manager, and the =Desktop= manager, inside the sanctuary using the
=room-fvwm95= Guix profile. All source patches are applied reproducibly via
python3 string replacement (never hand-edited under =$HOME=), so this script is
the single source of truth for the xclass toolchain.

Patches applied:

1. *GCC 16 =min=/=max= templates* (utils.h): replace the broken two-argument
   =auto ... decltype= template with single-argument =template<T> T max(T,T)=
   plus mixed-type overloads (int/unsigned/short pairs) and =abs(unsigned)=
   overloads. The two-arg =max(0,1)= silently returned 0 on GCC 16, breaking
   xclass =max(w,1)= window-dimension clamps (all X window creation failed
   with =BadValue=).
2. *ORectangle.h*: remove the duplicate =#define min/max= macros (collide
   with the utils.h templates); =#include "utils.h"= instead.
3. *OXMainFrame =SetMWMHints=*: write the Motif hints via a =long[4]= array
   (not the =MWMHintsProperty= struct) — =XChangeProperty= format=32 expects
   =long=-sized elements on 64-bit, and the struct's =CARD32= packing produced
   garbage in the decorations/inputMode fields.
4. *Explorer =SetMWMHints= removal* (OXExplorer.cc:443): delete the
   =SetMWMHints(MWM_DECOR_ALL, MWM_FUNC_ALL, MWM_INPUT_MODELESS)= call so the
   Explorer top-level window has *no* =_MOTIF_WM_HINTS= property — exactly like
   PCManFM. fvwm95's MWM-hint path leaves Explorer with no min/max/close caption
   buttons even when =MWM_DECOR_ALL= is requested; removing the redundant hint
   makes Explorer inherit the WM's native caption-button layout under both
   fvwm95 and IceWM.
5. *Desktop cursor* (OXDesktopContainer.cc): =XDefineCursor(XC_top_left_arrow)=
   on the desktop container window.
6. *Desktop =Line up Icons=* (OXDesktopContainer::LineUpIcons): snap every icon's
   current position to an 80x80 grid and persist via =Save()=. Wired to
   =M_VIEW_LINEUP= in main.cc.
7. *Desktop =Properties=* (main.cc): wire =M_ROOT_PROPS= to open the xclass-native
   =OXPropertiesDialog= on the desktop directory.
8. *Explorer =Copy/Cut/Paste=* (OXExplorer.cc): real copy buffer
   (=g_copyBuffer= + =g_cutMode=) with fork+exec =cp -r= / =mv=. Wired to
   =M_EDIT_COPY/CUT/PASTE=; refreshes the file view after paste.

def rd(p):
    with open(p,'rb') as f: return f.read()
def wr(p,b):
    with open(p,'wb') as f: f.write(b)

B = os.environ['BUILD_DIR']

# --- Patch 1: utils.h min/max templates + abs(unsigned) overloads ---

# remove the broken two-arg max/min templates if present

# remove ANY #define min(...) / #define max(...) macros (whatever their format)

        b'template <class T> inline T max(T a, T b) { return a > b ? a : b; }\n'
        b'template <class T> inline T min(T a, T b) { return a < b ? a : b; }\n'
        b'inline int max(int a, unsigned int b) { return (unsigned)a > b ? a : (int)b; }\n'
        b'inline int max(unsigned int a, int b) { return a > (unsigned)b ? (int)a : b; }\n'
        b'inline int max(int a, short b) { return a > (int)b ? a : (int)b; }\n'
        b'inline int max(short a, int b) { return (int)a > b ? (int)a : b; }\n'
        b'inline int max(int a, unsigned short b) { return a > (int)b ? a : (int)b; }\n'
        b'inline int max(unsigned short a, int b) { return (int)a > b ? (int)a : b; }\n'
        b'inline int min(int a, unsigned int b) { return (unsigned)a < b ? a : (int)b; }\n'
        b'inline int min(unsigned int a, int b) { return a < (unsigned)b ? (int)a : b; }\n'
        b'inline int min(int a, short b) { return a < (int)b ? a : (int)b; }\n'
        b'inline int min(short a, int b) { return (int)a < b ? (int)a : b; }\n'
        b'inline int min(int a, unsigned short b) { return a < (int)b ? a : (int)b; }\n'
        b'inline int min(unsigned short a, int b) { return (int)a < b ? (int)a : b; }\n'
        b'inline unsigned int abs(unsigned int v) { return v; }\n'
        b'inline unsigned long abs(unsigned long v) { return v; }\n')
if b'GCC16-safe min/max' not in c:

    c = re.sub(rb'(?m)^(#endif\s*//\s*__UTILS_H\s*)$',
               tmpl + b'\n\\1', c, count=1)
wr(p, c)

# --- Patch 2: ORectangle.h — drop duplicate min/max defines ---
p = B + '/xclass/include/xclass/ORectangle.h'
c = rd(p)
c = re.sub(rb'\s*#define\s+min\b.*\n', b'\n', c)
c = re.sub(rb'\s*#define\s+max\b.*\n', b'\n', c)
if b'utils.h' not in c:
    c = b'#include "utils.h"\n' + c
wr(p, c)

# --- Patch 3: OXMainFrame.cc — SetMWMHints using long[4] array ---
p = B + '/xclass/lib/libxclass/OXMainFrame.cc'
c = rd(p)
old = (b'void OXMainFrame::SetMWMHints(unsigned int value, unsigned int funcs, unsigned int input) {\n'
       b'  MWMHintsProperty prop;\n\n'
       b'  prop.decorations = value;\n'
       b'  prop.functions   = funcs;\n'
       b'  prop.inputMode   = input;\n'
       b'  prop.flags       = MWM_HINTS_DECORATIONS | \n'
       b'                     MWM_HINTS_FUNCTIONS   |\n'
       b'                     MWM_HINTS_INPUT_MODE;\n\n'
       b'  XChangeProperty(GetDisplay(), _id, _MOTIF_WM_HINTS, _MOTIF_WM_HINTS, 32,\n'
       b'                  PropModeReplace, (unsigned char *)&prop, PROP_MWM_HINTS_ELEMENTS);\n'
       b'}')
new = (b'void OXMainFrame::SetMWMHints(unsigned int value, unsigned int funcs, unsigned int input) {\n'
       b'  long hints[4];\n'
       b'  hints[0] = MWM_HINTS_DECORATIONS | MWM_HINTS_FUNCTIONS | MWM_HINTS_INPUT_MODE;\n'
       b'  hints[1] = funcs;\n'
       b'  hints[2] = value;\n'
       b'  hints[3] = input;\n'
       b'  XChangeProperty(GetDisplay(), _id, _MOTIF_WM_HINTS, _MOTIF_WM_HINTS, 32,\n'
       b'                  PropModeReplace, (unsigned char *)hints, PROP_MWM_HINTS_ELEMENTS);\n'
       b'}')

else:

    pass
wr(p, c)

# --- Patch 3b: OXMainFrame.h — MWMHintsProperty fields -> long ---
p = B + '/xclass/include/xclass/OXMainFrame.h'

** dsdmine launcher wrapper

Small host-side helper used by the Redstone 9X launcher to turn existing
canonical PNG icon assets (Chicago95 / BeOS) into 32×32 XPMs that the xclass
icon pool (=libXpm=) can load. Transparency becomes the XPM =None= colour so
xclass renders a proper shape mask. The PNG sources remain canonical; the XPMs
are generated reproducibly at launch time.

#+BEGIN_SRC python :tangle linux/.local/bin/png2xpm.py :shebang "#!/usr/bin/env python3" :tangle-mode (identity #o755)
"""Convert a PNG to XPM (with transparency mask) for xclass/libXpm.
Usage: png2xpm.py input.png output.xpm [name]
Builds a palette; cpp=1 if <=94 colours else cpp=2. Transparent pixels -> None.
"""
import sys, os
from PIL import Image

def png_to_xpm(src, dst, name=None):
    im = Image.open(src)
    if im.mode not in ("RGBA", "RGB"):
        im = im.convert("RGBA")
    w, h = im.size
    px = im.load()
    palette = []
    palidx = {}
    rows = []
    for y in range(h):
        row = []
        for x in range(w):
            r, g, b, a = px[x, y]
            key = None if a < 128 else (r, g, b)
            if key not in palidx:
                palidx[key] = len(palette)
                palette.append(key)
            row.append(palidx[key])
        rows.append(row)
    ncol = len(palette)
    # Safe single-char alphabet: printable ASCII 33..126 EXCLUDING the XPM
    # string delimiter (0x22) and backslash (0x5c). Using the quote char as a
    # pixel corrupts the XPM; XpmReadFileToPixmap then fails -> generic icons.
    _SAFE1 = [chr(c) for c in range(33, 127) if c not in (0x22, 0x5c)]
    if ncol <= len(_SAFE1):
        cpp = 1
        chars = _SAFE1[:ncol]
    else:
        cpp = 2
        chars = []
        for c1 in range(33, 127):
            if c1 in (0x22, 0x5c): continue
            for c2 in range(33, 127):
                if c2 in (0x22, 0x5c): continue
                chars.append(chr(c1) + chr(c2))
                if len(chars) >= ncol: break
            if len(chars) >= ncol: break
    if not name:
        name = os.path.splitext(os.path.basename(dst))[0]
        name = "".join(c if c.isalnum() else "_" for c in name)
    lines = ["/* XPM */",
             "static char * %s[] = {" % name,
             '"%d %d %d %d",' % (w, h, ncol, cpp)]
    for i, key in enumerate(palette):
        if key is None:
            lines.append('"%s c None",' % chars[i])
        else:
            lines.append('"%s c #%02X%02X%02X",' % (chars[i], key[0], key[1], key[2]))
    for y in range(h):
        s = "".join(chars[rows[y][x]] for x in range(w))
        sep = "}" if y == h - 1 else ","
        lines.append('"%s"%s' % (s, sep))
    lines.append("};")
    with open(dst, "w") as f:
        f.write("\n".join(lines) + "\n")
    return (w, h, ncol)

if __name__ == "__main__":
    if len(sys.argv) < 3:
        sys.exit("usage: png2xpm.py input.png output.xpm [name]")
    w, h, n = png_to_xpm(sys.argv[1], sys.argv[2], sys.argv[3] if len(sys.argv) > 3 else None)
    print("%s -> %s (%dx%d, %d colours)" % (sys.argv[1], sys.argv[2], w, h, n))
#+END_SRC
