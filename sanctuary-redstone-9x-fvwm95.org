#------------------------------------------------------------------------------
# This one moves and then raises the window if you drag the mouse,
# only raises the window if you click, or does a vertical maximize if
# you double click (full screen maximize would be 'Maximize 100 100')
#------------------------------------------------------------------------------

DestroyFunc "Move-or-Raise"
AddToFunc "Move-or-Raise" "M" Move
+                         "M" Raise
+                         "C" Raise
+                         "D" Maximize 100 96



#------------------------------------------------------------------------------
# This one moves and then lowers the window if you drag the mouse,
# only lowers the window if you click, or does a RaiseLower if you double
# click
#------------------------------------------------------------------------------

DestroyFunc "Move-or-Lower"
AddToFunc "Move-or-Lower" "M" Move
+                         "M" Lower
+                         "C" Lower
+                         "D" RaiseLower


#------------------------------------------------------------------------------
# This one moves or (de)iconifies:
#------------------------------------------------------------------------------

DestroyFunc "Move-or-Iconify"
AddToFunc "Move-or-Iconify" "M" Move
+                           "D" Iconify

#------------------------------------------------------------------------------
# This one maximizes vertically if you click (leaving room for the taskbar
# at the bottom, or does a full maximization if you double click, or a
# true full vertical maximization if you just hold the mouse button down.
#------------------------------------------------------------------------------


DestroyFunc "Maximize-Func"
AddToFunc "Maximize-Func" "M"	Maximize 0 96
+ 			  "C"	Maximize 0 100
+ 			  "D"	Maximize 100 96

#------------------------------------------------------------------------------
# This one resizes and then raises the window if you drag the mouse,
# only raises the window if you click,  or does a RaiseLower if you double
# click
#------------------------------------------------------------------------------

DestroyFunc "Resize-or-Raise"
AddToFunc "Resize-or-Raise" "M" Resize
+                           "M" Raise
+                           "C" Raise
+                           "D" RaiseLower

Lutris game-library menu generator.

The =Lutris= entry directly under the Wine menu is an IceWM =menuprog= — IceWM runs this generator on every open and consumes its stdout as the submenu body (the same dynamic-menu mechanism the =Ports= entry uses). It reads the *machine-local* Lutris =pga.db= sqlite catalogue **directly** — never spawning the Lutris Flatpak — so it stays far inside the menuprog budget (≈50 ms for a 400-game library; the bash-loop first draft took 1 s, hence the awk emitter). Only =installed=1= and non-hidden games are listed. The library is large, so it is grouped: a *Recently Played* submenu (the ten most-recent by =lastplayed=) followed by =A–Z= letter folders (a =#= folder collects non-alphabetic titles). Every launch goes through the =lutris-play= envelope (lease + hub sync, see =lutris.org=) wrapping =sanctuary-flatpak-run=, via Lutris's own =lutris:rungameid/<id>= URI. Absent DB or sqlite degrades to a single informational entry rather than an error. The =MODE= argument (only =icewm= today) leaves room to add an XFCE emitter when this is ported to Godzilla XS.

#+BEGIN_SRC bash :tangle linux/.local/bin/lutris-menu-gen :shebang "#!/bin/bash" :tangle-mode (identity #o755)
# lutris-menu-gen — emit a Lutris game submenu for a running sanctuary.
# Reads the machine-local Lutris pga.db directly (no flatpak spawn) so it stays
# well within IceWM's menuprog budget. Every launch goes through the
# lutris-play lease/sync envelope wrapping sanctuary-flatpak-run.
#
# Usage: lutris-menu-gen icewm
set -euo pipefail

MODE="${1:-icewm}"
DB="${HOME}/.local/share/lutris/pga.db"
LAUNCHER="${HOME}/.local/bin/lutris-play"
WRAPPER="${HOME}/.local/bin/sanctuary-flatpak-run"
APP="net.lutris.Lutris"
ICON="lutris"
US=$'\x1f'   # unit separator — never appears in a game name

msg() { printf '  prog "%s" dialog-information true\n' "${1//\"/\\\"}"; }

if [[ "${MODE}" != icewm ]]; then echo "lutris-menu-gen: only icewm mode implemented" >&2; exit 2; fi
if [[ ! -f "${DB}" ]] || ! command -v sqlite3 >/dev/null 2>&1; then
  msg "Lutris library unavailable"; exit 0
fi

# awk emitter: FLAT=1 emits a flat list; FLAT=0 groups into A–Z / # folders.
AWK='
BEGIN { FS="\x1f" }
function q(s){ gsub(/\\/,"\\\\",s); gsub(/"/,"\\\"",s); return s }
{
  name=$2; id=$1
  if (!FLAT) {
    L=toupper(substr(name,1,1)); if (L !~ /[A-Z]/) L="#"
    if (L!=cur){ if(cur!="") print "  }"; printf "  menu \"%s\" folder {\n", L; cur=L }
  }
  printf "  prog \"%s\" %s %s -- %s %s -- lutris:rungameid/%s\n", q(name), ICON, LAUNCHER, WRAPPER, APP, id
}
END { if (!FLAT && cur!="") print "  }" }
'

# ---- Open Lutris (the application itself) ----
printf '  prog "Open Lutris" %s %s -- %s %s\n  separator\n' "${ICON}" "${LAUNCHER}" "${WRAPPER}" "${APP}"

# ---- Recently Played (top 10 actually-played) ----
recent="$(sqlite3 -separator "${US}" "${DB}" \
  "SELECT id,name FROM games WHERE installed=1 AND (hidden IS NULL OR hidden=0) AND COALESCE(lastplayed,0)>0 ORDER BY lastplayed DESC LIMIT 10;" 2>/dev/null || true)"
if [[ -n "${recent}" ]]; then
  printf '  menu "Recently Played" %s {\n' "${ICON}"
  printf '%s\n' "${recent}" | awk -v FLAT=1 -v ICON="${ICON}" -v LAUNCHER="${LAUNCHER}" -v WRAPPER="${WRAPPER}" -v APP="${APP}" "${AWK}"
  printf '  }\n  separator\n'
fi

# ---- A–Z letter groups over the whole installed library ----
all="$(sqlite3 -separator "${US}" "${DB}" \
  "SELECT id,name FROM games WHERE installed=1 AND (hidden IS NULL OR hidden=0) ORDER BY name COLLATE NOCASE;" 2>/dev/null || true)"
if [[ -z "${all}" ]]; then msg "No installed Lutris games"; exit 0; fi
printf '%s\n' "${all}" | awk -v FLAT=0 -v ICON="${ICON}" -v LAUNCHER="${LAUNCHER}" -v WRAPPER="${WRAPPER}" -v APP="${APP}" "${AWK}"
#+END_SRC

PCManFM desktop icon grid helper.

PCManFM exposes =Snap to Grid= as an internal desktop-context action, not as
a command-line option.  This helper gives the IceWM menu an equivalent
all-icons action: stop the desktop layer, preserve a timestamped copy of its
position file, snap only desktop-icon coordinates to Redstone's 80-pixel grid,
then start the desktop layer again.  It does not enable auto-arrange, so later
manual movement remains possible.

#+BEGIN_SRC bash :tangle linux/.local/bin/redstone-9x-icons-grid :shebang "#!/usr/bin/env bash" :tangle-mode (identity #o755)
set -euo pipefail

usage() {
  cat <<'EOF'
redstone-9x-icons-grid - snap PCManFM desktop icons to Redstone's grid

Usage: redstone-9x-icons-grid
       redstone-9x-icons-grid -h | --help

Stops the PCManFM desktop layer, backs up desktop-items-0.conf, rounds desktop
icon x/y coordinates to PCManFM's real cell size, and starts the desktop again.
EOF
}

case "${1:-}" in
  -h|--help)
    usage
    exit 0
    ;;
  "")
    ;;
  *)
    usage >&2
    exit 2
    ;;
esac

if (( $# > 1 )); then
  usage >&2
  exit 2
fi

config_home="${XDG_CONFIG_HOME:-${HOME}/.config}"
config="${config_home}/pcmanfm/default/desktop-items-0.conf"
cache_dir="${XDG_CACHE_HOME:-${HOME}/.cache}/redstone-9x"
# PCManFM's desktop cell is NOT square, and it is not 80. From pcmanfm-1.4.0
# src/desktop.c on_size_allocate(): cell_w = MAX(text_w, big_icon_size) + xpad*2
# = (100+4) + 12 = 116, font-independent; cell_h = big_icon_size + spacing +
# (font_h*2 + 4) + ypad*2, which is 76..86 across the GTK fonts the schemes use.
# The old square grid=80 snapped columns to 80px against a real 116px cell, so
# every snap overlapped adjacent columns by 36px. Shares its geometry with
# redstone-9x-desktop-layout so the two writers cannot disagree.
grid_x="${REDSTONE_DESKTOP_CELL_W:-116}"
grid_y="${REDSTONE_DESKTOP_CELL_H:-86}"
margin="${REDSTONE_DESKTOP_MARGIN:-2}"

if [[ ! -f "${config}" ]]; then
  printf 'redstone-9x-icons-grid: PCManFM desktop config not found: %s\n' "${config}" >&2
  exit 1
fi

mkdir -p "${cache_dir}"
backup="${config}.backup-$(date +%Y%m%d-%H%M%S)-$$"
temp="$(mktemp "${config}.tmp.XXXXXX")"
restart_needed=0

cleanup() {
  [[ -z "${temp:-}" ]] || rm -f -- "${temp}"
  if (( restart_needed )); then
    pcmanfm --desktop >"${cache_dir}/pcmanfm-desktop.log" 2>&1 &
  fi
}
trap cleanup EXIT

pcmanfm --desktop-off >/dev/null 2>&1
restart_needed=1
sleep 0.5

cp -p -- "${config}" "${backup}"

awk -v gx="${grid_x}" -v gy="${grid_y}" -v m="${margin}" '
function snap(value, grid) {
  value -= m
  if (value < 0) value = 0
  return m + int((value + grid / 2) / grid) * grid
}

/^\[/ {
  in_desktop_icon = ($0 ~ /^\[[^]]+\.desktop\]$/)
}

in_desktop_icon && /^x=-?[0-9]+$/ {
  sub(/^x=/, "")
  print "x=" snap($0 + 0, gx)
  next
}

in_desktop_icon && /^y=-?[0-9]+$/ {
  sub(/^y=/, "")
  print "y=" snap($0 + 0, gy)
  next
}

{ print }
' "${config}" >"${temp}"

chmod --reference="${config}" "${temp}"
mv -f -- "${temp}" "${config}"
temp=""

pcmanfm --desktop >"${cache_dir}/pcmanfm-desktop.log" 2>&1 &
restart_needed=0
trap - EXIT

printf 'Desktop icons snapped to a %sx%s grid. Backup: %s\n' "${grid_x}" "${grid_y}" "${backup}"
#+END_SRC

The =redstone-9x-desktop-restart= helper backs the *Restart Desktop* menu item
(=Programs ▸ Settings ▸ PCManFM ▸ Restart Desktop=).  PCManFM has no =--restart=
flag, so it drops desktop mode via =--desktop-off=, reaps a renderer that ignored
the message (hung), then relaunches the scoped renderer.  It runs inside the
IceWM session (uid 1000), so the new process inherits the correct =DISPLAY=/D-Bus
and comes up as the user — never container-root (see the podman-exec-as-root
gotcha in the running registry).

#+BEGIN_SRC sh :tangle linux/.local/bin/redstone-9x-desktop-restart :tangle-mode (identity #o755) :mkdirp yes
#!/bin/sh
# redstone-9x-desktop-restart — restart the PCManFM desktop renderer.
# Bound to the "Restart Desktop" menu item. Runs in the IceWM session (uid
# 1000): the new renderer inherits the session DISPLAY/D-Bus and comes up as
# the user, never container-root.
cache="${HOME}/.cache/redstone-9x"
mkdir -p "${cache}"

# Resolve pcmanfm: the menu runs this in-session (room-gaming profile on PATH),
# but fall back to the profile path so a restart also works from a bare shell.
pcmanfm="$(command -v pcmanfm 2>/dev/null || printf '%s' "${HOME}/.guix-extra-profiles/room-gaming/room-gaming/bin/pcmanfm")"

# 1) Ask the live instance to drop desktop mode (clean path).
"${pcmanfm}" --desktop-off >/dev/null 2>&1

# 2) Reap a renderer that ignored the message (hung). The renderer's cmdline is
#    exactly "pcmanfm --desktop"; the trailing anchor avoids matching this script
#    or "pcmanfm --desktop-pref".
for pid in $(pgrep -u "$(id -u)" -f 'pcmanfm --desktop$' 2>/dev/null); do
  kill "${pid}" 2>/dev/null
done

sleep 0.5

# 3) Relaunch the scoped desktop renderer.
"${pcmanfm}" --desktop >>"${cache}/pcmanfm-desktop.log" 2>&1 &

** Dynamic menus — recent Documents + Desktop folder

Win95's Start→Documents was a *recent documents* menu; ours was a folder shortcut. IceWM's =menuprog= regenerates a submenu by running a script on every open (the antiX/BobC pattern from =~/Downloads/icewm-menu-7=, rewritten for Redstone). Icons must be names IceWM can actually resolve — an unresolvable icon silently drops the whole entry — so both scripts pick from the grafted set and fall back to =folder=.

#+BEGIN_SRC bash :tangle linux/.local/bin/redstone-9x-menu-recent :shebang "#!/bin/sh" :tangle-mode (identity #o755)
# Emit IceWM menu entries for recent documents (Win95 Start->Documents).
# Reads recently-used.xbel (GTK apps maintain it); newest first, capped.
XBEL="${XDG_DATA_HOME:-$HOME/.local/share}/recently-used.xbel"
ICONDIR="${HOME}/.icewm/icons"
MAX=15

if [ ! -f "${XBEL}" ]; then
  echo 'prog "(no recent documents)" folder true'
  exit 0
fi

icon_for() {
  case "$(printf %s "$1" | tr "[:upper:]" "[:lower:]")" in
    *.txt|*.md|*.org|*.conf|*.ini|*.log|*.sh) echo text-x-generic ;;
    *.png|*.jpg|*.jpeg|*.gif|*.bmp|*.xpm|*.webp|*.svg) echo image-x-generic ;;
    *.wav|*.mp3|*.ogg|*.flac|*.m4a|*.mod|*.it|*.s3m|*.xm|*.mid) echo audio-x-generic ;;
    *.mp4|*.mkv|*.avi|*.webm|*.mov|*.mpg) echo video-x-generic ;;
    *.pdf) echo application-pdf ;;
    *.zip|*.7z|*.rar|*.tar|*.gz|*.xz|*.zst|*.wsz) echo package-x-generic ;;
    *) echo unknown ;;
  esac
}

count=0
# hrefs appear in chronological order; newest are last — reverse with tail+tac.
grep -oE '<bookmark href="file://[^"]*"' "${XBEL}" \
  | sed -e 's|.*href="file://||' -e 's|"$||' \
  | tail -n "${MAX}" | tac \
  | while IFS= read -r enc; do
      # URL-decode the common cases (printf %b interprets \x escapes)
      path=$(printf '%b' "$(printf %s "${enc}" | sed 's/%\([0-9a-fA-F][0-9a-fA-F]\)/\\x\1/g')")
      [ -e "${path}" ] || continue
      name=$(basename "${path}" | sed 's/"/\\"/g')
      icon=$(icon_for "${path}")
      [ -f "${ICONDIR}/${icon}_16x16.png" ] || icon=folder
      printf 'prog "%s" %s xdg-open "%s"\n' "${name}" "${icon}" "${path}"
      count=$((count+1))
    done
exit 0
#+END_SRC

#+BEGIN_SRC bash :tangle linux/.local/bin/redstone-9x-menu-desktop :shebang "#!/bin/sh" :tangle-mode (identity #o755)
# Emit IceWM menu entries mirroring ~/Desktop (BobC's antiX Desktop-folder
# menu, Redstone-ised). .desktop launchers run their Exec (field codes
# stripped); plain files open via xdg-open.
DESK="${HOME}/Desktop"
ICONDIR="${HOME}/.icewm/icons"
[ -d "${DESK}" ] || exit 0

for f in "${DESK}"/*; do
  [ -e "${f}" ] || continue
  base=$(basename "${f}")
  case "${base}" in
    *.desktop)
      name=$(sed -n 's/^Name=//p' "${f}" | head -1)
      icon=$(sed -n 's/^Icon=//p' "${f}" | head -1)
      cmd=$(sed -n 's/^Exec=//p' "${f}" | head -1 | sed 's/ %[a-zA-Z]//g')
      [ -n "${name}" ] && [ -n "${cmd}" ] || continue
      [ -f "${ICONDIR}/${icon}_16x16.png" ] || icon=folder
      printf 'prog "%s" %s %s\n' "$(printf %s "${name}" | sed 's/"/\\"/g')" "${icon}" "${cmd}"
      ;;
    *)
      icon=folder
      printf 'prog "%s" %s xdg-open "%s"\n' "$(printf %s "${base}" | sed 's/"/\\"/g')" "${icon}" "${f}"
      ;;
  esac
done
exit 0
#+END_SRC

# --- Why -dmenu, not run mode (rofi 2.0.0, verified 2026-07-18) ---------------
# rofi fires a themed button's `action:` on MOUSE CLICK only in -dmenu mode; in
# -modes run / -show run the click is silently swallowed, so the Browse and
# dropdown buttons were dead however they were styled. So the box is driven as
# -dmenu and this wrapper runs the accepted command itself — which also matches
# the real Win95 Run box, that does not autocomplete. The Run history IS the
# -dmenu row list, fed on stdin; it stays hidden (listview enabled:false) until
# the ▼ dropdown reveals it. A trailing blank line is always fed as a guard:
# clicking any button while the dmenu list is EMPTY segfaults rofi, so >=1 row
# must always be present.
#
# Button -> exit code -> handled below (no rofi binary patch):
#   Return / OK  (kb-accept-custom) -> exit 0  -> run the typed/selected command
#   Browse...    (button-browse -> kb-custom-1) -> exit 10 -> drun app launcher
#   ▼ dropdown   (combo-button  -> kb-custom-2) -> exit 11 -> reveal Run history
#   Cancel / Esc (kb-cancel)                    -> exit 1  -> do nothing
#
# Once IceWM maps the Rofi window, retitle it ("Run", not "rofi - Run") and
# centre it — rofi ignores its own theme location under -normal-window, so IceWM
# would otherwise pin it top-left and clip the titlebar. The map + WM handshake
# outruns a fixed delay, so poll (icesh ships with IceWM).
_frame_rofi() {
  local title="$1"
  ( for _i in $(seq 1 50); do
      if icesh -c Rofi list 2>/dev/null | grep -q Rofi; then
        icesh -c Rofi setWindowTitle "${title}" 2>/dev/null
        icesh -c Rofi center 2>/dev/null
        break
      fi
      sleep 0.08
    done ) &
}

# Most-recent-first, de-duplicated, non-blank history rows.
_history_rows() { tac "$histfile" 2>/dev/null | awk 'NF && !seen[$0]++'; }

# Prepend a command to the history (dedup, cap 50). Never fails the script.
_record() {
  local c="$1"
  [ -z "$c" ] && return 0
  { printf '%s\n' "$c"; grep -vxF "$c" "$histfile" 2>/dev/null || true; } \
    | awk 'NF' | head -n 50 >"$histfile.tmp" 2>/dev/null \
    && mv "$histfile.tmp" "$histfile" 2>/dev/null || true
  return 0
}

view="run"
while : ; do
  args=( -dmenu -normal-window -config "$config" -theme "$theme"
         -kb-accept-entry "Control+j,Control+m"
         -kb-accept-custom "Return,KP_Enter,Control+Return"
         -pid "$pidfile" )
  if [ "$view" = history ]; then
    # ▼ dropdown view: reveal the history list, hide the chevron (list is open).
    # Down navigates the list here (rofi default), so no key override.
    args+=( -theme-str 'listview { enabled: true; }'
            -theme-str 'combo-frame { enabled: false; }' )
    _frame_rofi "Run history"
  else
    # Run view: Down / Alt+Down / F4 open the dropdown, exactly like a real Win95
    # combobox. Move row-down off Down first (the list is hidden here, so row
    # navigation is unused) — rofi rejects a key bound to two actions.
    args+=( -kb-row-down "Control+n"
            -kb-custom-2 "Down,Alt+Down,F4" )
    _frame_rofi "Run"
  fi

  rc=0
  cmd="$( { _history_rows; printf '\n'; } | rofi "${args[@]}" )" || rc=$?

  case "$rc" in
    10)
      # Browse... -> the drun application launcher (a normal rofi window so its
      # listview grows without the -normal-window fixed-height oscillation).
      exec rofi -config "$config" -show drun -show-icons -display-drun "Programs"
      ;;
    11)
      view="history"
      continue
      ;;
    0)
      if printf '%s' "$cmd" | grep -q '[^[:space:]]'; then
        _record "$cmd"
        setsid bash -c "$cmd" >/dev/null 2>&1 &
      fi
      break
      ;;
    *)
      break
      ;;
  esac
done

# The guard used to be a bare `! pgrep -x clipmenud`, which is wrong twice over.
# clipmenud polls the X selection forever; when the room's Xephyr goes away its
# clipmenud does NOT exit, it spins on a dead display logging
#     xsel: Can't open display: (null)
# as fast as the loop runs. Found 2026-07-26: an orphan from 18 July, still
# running eight days later, had written a 5.3 GB log at ~974 MB/day. Worse, that
# orphan satisfied the pgrep guard, so every room since started WITHOUT a working
# clipboard daemon — the check proved a process existed, never that it was usable.
#
# Record the display alongside the pid. Reuse the daemon only when it is alive AND
# belongs to the display we are starting now; otherwise retire it and start fresh.
# The pid is killed by exact value, never by name — this PID namespace is shared.
CLIPMENU_STATE="${HOME}/.cache/redstone-9x/clipmenud.state"
if command -v clipmenud >/dev/null 2>&1 && [ -n "${DISPLAY:-}" ]; then
  _clip_reuse=0
  if [ -r "${CLIPMENU_STATE}" ]; then
    read -r _clip_pid _clip_disp < "${CLIPMENU_STATE}" || true
    if [ -n "${_clip_pid:-}" ] && kill -0 "${_clip_pid}" 2>/dev/null; then
      if [ "${_clip_disp:-}" = "${DISPLAY}" ]; then
        _clip_reuse=1
      else
        kill "${_clip_pid}" 2>/dev/null || true
      fi
    fi
  fi
  if [ "${_clip_reuse}" -eq 0 ]; then
    clipmenud >"${HOME}/.cache/redstone-9x/clipmenud.log" 2>&1 &
    printf '%s %s\n' "$!" "${DISPLAY}" > "${CLIPMENU_STATE}"
  fi
fi

# Tray inhabitants: start only when available and not already running.
# PCManFM remains the desktop/background owner; these only occupy IceWM's tray.
if command -v nm-applet >/dev/null 2>&1 \
  && pgrep -x NetworkManager >/dev/null 2>&1 \
  && ! pgrep -xu "$(id -u)" nm-applet >/dev/null 2>&1; then
  nm-applet >"${HOME}/.cache/redstone-9x/nm-applet.log" 2>&1 &
fi

if command -v pnmixer >/dev/null 2>&1 \
  && ! pgrep -xu "$(id -u)" pnmixer >/dev/null 2>&1; then
  pnmixer >"${HOME}/.cache/redstone-9x/pnmixer.log" 2>&1 &
fi

# Recycle Bin icon state watcher: the static ~/Desktop/recycle-bin.desktop
# launcher has no dynamic full/empty state on its own (GVFS's native trash
# object would give us that for free, but room-gaming has no gvfs — a
# 2026-07-07 retry of plain gvfs leaked the HOST's real Trash contents into
# the sandboxed room via distrobox's /run/host bind mount — see
# redstone-9x-state-digest.md). Poll the on-disk Trash folder instead and
# rewrite Icon= directly; no new package required.
if [ -x "${HOME}/.local/bin/redstone-9x-recycle-bin-watch" ] \
  && ! pgrep -fu "$(id -u)" "redstone-9x-recycle-bin-watch" >/dev/null 2>&1; then
  "${HOME}/.local/bin/redstone-9x-recycle-bin-watch" \
    >"${HOME}/.cache/redstone-9x/recycle-bin-watch.log" 2>&1 &
fi
#+END_SRC

Recycle Bin icon-state watcher.  PCManFM's own native trash desktop object
would track full/empty state for free, but room-gaming deliberately has no
=gvfs= (it crashes =pcmanfm --desktop= — see the running registry). This
polls the plain on-disk Trash folder instead — no GVFS, no new package,
just =ls=/=sed= against a path that already exists — and rewrites the
static launcher's =Icon== key directly. =pcmanfm --desktop= already
monitors =~/Desktop/= for content changes (that's how manual icon
repositioning/renaming persists), so an in-place edit to the =.desktop=
file's icon is picked up the same way.

#+BEGIN_SRC bash :tangle linux/.local/bin/redstone-9x-recycle-bin-watch :shebang "#!/bin/bash" :tangle-mode (identity #o755)
# Redstone 9X — Recycle Bin icon state watcher.
# Toggles ~/Desktop/recycle-bin.desktop's Icon= between user-trash and
# user-trash-full to match the real on-disk Trash folder, since the static
# launcher has no dynamic state of its own (no gvfs in this room — see
# redstone-9x-state-digest.md). Plain poll loop; no inotify dependency.
set -euo pipefail

TRASH_FILES="${XDG_DATA_HOME:-${HOME}/.local/share}/Trash/files"
DESKTOP_ICON="${HOME}/Desktop/recycle-bin.desktop"

while true; do
  if [[ -d "${TRASH_FILES}" ]] && [[ -n "$(ls -A "${TRASH_FILES}" 2>/dev/null)" ]]; then
    icon="user-trash-full"
  else
    icon="user-trash"
  fi
  # Compare against the file's ACTUAL current Icon= line, not a remembered
  # in-process variable — a relaunch reprojects a fresh copy of this file
  # over top of a still-running watcher, and an in-memory "last state" would
  # never notice the reset, silently going stale (found 2026-07-07).
  if [[ -f "${DESKTOP_ICON}" ]] && ! grep -qx "Icon=${icon}" "${DESKTOP_ICON}"; then
    sed -i "s/^Icon=.*/Icon=${icon}/" "${DESKTOP_ICON}"
  fi
  sleep 3
done
#+END_SRC

=My Documents= points at =$HOME/Documents=, not =$HOME=.  Home is the Windows XP =Users\{user}= concept and has no Windows 9x analogue, so it gets no desktop shortcut here — reach it by drilling down from My Computer or up from Documents.  Uses the =sh -c= + =$HOME= form for the same reason Program Manager and Recycle Bin do: inside the room =HOME= is the guest home, and a =.desktop= =Exec=  line does not expand =~=.

Icon naming is unresolved across schemes and neither obvious candidate is correct everywhere.  Measured at 32px (=big_icon_size=32=, the size the desktop actually renders), 2026-07-26:

| theme         | =user-home=        | =folder-documents=       |
|---------------+--------------------+--------------------------|
| Chicago95     | folder + papers    | briefcase (wrong)        |
| Win98SE       | folder + papers    | folder + sheets          |
| SE98          | folder + papers    | folder + sheets          |
| LinXP         | house (wrong)      | open folder + blue sheet |
| BeOS-r5-Icons | folder + house tag | folder + note            |
| Irixium       | folder + pencil    | folder + document        |

=folder-documents= is the name, because it is the semantically correct one and is right in LinXP, Win98SE, SE98, BeOS-r5-Icons and Irixium; Serenity95 resolves it through =Inherits=Chicago95=.  =user-home= means the home directory and is a literal house in LinXP — never a My Documents icon.

Chicago95 is the single outlier and that is a defect in Chicago95, not a reason to pick a worse name globally.  Its =folder-documents= is inconsistent within the pristine upstream pack itself — briefcase at 16 and 32, plain folder at 22 and 24, and the correct documents folder only at 48 — so the 32px desktop slot shows a briefcase while the right art sits one size up.  Fix belongs in the pack (regenerate 16 and 32 from its own 48px art), not in this launcher.  There is no per-scheme icon override: a scheme sets =ICON_THEME= and nothing else, and the applier never rewrites =Icon== lines.
