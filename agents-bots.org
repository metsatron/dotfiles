*** Token Conflict / Workaround

The Claude Code plugin currently shares =@dotcortex_opencode_bot='s token with the OpenCode
bot. Telegram enforces one polling consumer per token — the OpenCode bot (running since Apr 30)
holds the slot, causing 409 Conflict for the Claude plugin.

*Workaround (active):* =claude-auryn --telegram= sends SIGSTOP to the opencode-telegram process
before launching Claude, freeing the token. On session exit the wrapper sends SIGCONT to resume it.

*Proper fix (pending):* Create a dedicated bot for Auryn via @BotFather, update
=~/.claude/channels/telegram/.env= and =NEXUS/stow/linux/.claude/channels/telegram/.env=,
run =helmstow=. Then remove the SIGSTOP workaround from =claude-auryn=.

** Codex

Codex still has no native Telegram channel, but HelmCortex now supplies a
private Codex app-server adapter for HelmAstra.

- Wrapper: =codex-helmastra --telegram= ensures the adapter, then continues
  into interactive Codex when attached to a terminal; the host manager uses
  the same flag non-interactively to establish only the background adapter
- Backend: Codex =app-server= JSON-RPC, with persistent Telegram-to-thread mapping
- Startup contract: the wrapper returns success only after bot identity and the
  Codex app-server are verified and the adapter publishes its PID-owned ready marker
- Approval policy: =never= inside the workspace-write sandbox
- Compaction: native =thread/compact/start= plus the 27-minute / 70,000-token
  idle governor inherited from =codex-luna= / =codex-warm=
- Runtime credentials: private =~/.config/codex-telegram-helmastra/.env= only
- Identity safety: the expected bot ID and username are pinned in the private
  env; a token for OpenCode, Claude, Hermes, or any other bot fails closed

The adapter is deliberately separate from Ductor: Ductor keeps its own bot
identity and remains the fleet coordinator, while HelmAstra owns this bot.

** DeepSeek Harness

DeepSeek Harness Telegram is staged as a separate =deepseek-harness= agent. It
is not Ductor, not OpenCode, and not enabled in the live Kikin host row until
private credentials and a deny-all canary have been provisioned.

- CLI: =@deepseek-ai/dsh= pinned in the npm manifest
- Bridge: =xqicxx/dsh-telegram=, built from the pinned sovereign checkout at
  =~/HelmCortex/NEXUS/git/dsh-telegram=
- Runtime env: private =~/.config/deepseek-harness-telegram/env= only
- Provider: custom OpenAI-compatible =neuralwatt= route, never the native
  =deepseek= route; the only declared model is =deepseek-v4-flash=
- Credential: =NEURALWATT_API_KEY= is populated at runtime from the private,
  mode-0600 HelmCortex NeuralWatt key file; no credential is stored here
- Provider boundary rule: model authorship does not identify the API provider.
  Name routes and credential variables after the actual gateway, scrub unrelated
  inherited provider credentials before preflight and launch, then verify both
  the live endpoint and the child process's credential-variable names before a
  production claim.
- Workspace config: private =~/.local/share/deepseek-harness-telegram/workspace/.pi/telegram.json=
- DSH profile/home: dedicated =helmcortex-telegram= profile under the private
  DSH home declared by the env file
- Access control: =security.allowedChatIds=[]= in the template means deny all;
  =telegram-agent-host start deepseek-harness= refuses to start until the
  private workspace config contains an explicit non-empty allowlist
- Availability: startup performs an authenticated =GET /v1/models= before
  poller ownership and refuses to start unless the exact V4 Flash model is
  visible; the Flex alias and undeclared models are never fallback candidates
- Ownership: one long-polling process, owned by the PID file under
  =~/.local/state/telegram-agents=, verified by exact DSH profile cmdline before
  status or stop; no broad process kill is used

* OpenCode ownership helper

#+BEGIN_SRC python :tangle all/.local/bin/opencode-owner :shebang "#!/usr/bin/env python3"
"""Fail-closed lifecycle owner for the isolated Kikin OpenCode pair.

This helper deliberately discovers nothing by process-name search.  The state
file is an ownership claim, and every operation revalidates PID, Linux start
ticks, cwd, and argv against that claim before declaring or stopping a process.
"""

from __future__ import annotations

import argparse
import json
import os
import signal
import subprocess
import sys
import time
from pathlib import Path


OWNER = "telegram-agent-host:opencode"
BOT = "opencode"
DEFAULT_PROJECT = "/home/metsatron/HelmCortex"
DEFAULT_HOST = "127.0.0.1"
DEFAULT_PORT = 4096
PACKAGE_NAME = "@grinev/opencode-telegram-bot"
PACKAGE_VERSION = "0.22.5"


def json_out(value: object) -> None:
    print(json.dumps(value, sort_keys=True))


def read_json(path: Path) -> dict | None:
    try:
        value = json.loads(path.read_text(encoding="utf-8"))
    except (OSError, ValueError):
        return None
    return value if isinstance(value, dict) else None


def pid_info(pid: int) -> dict | None:
    proc = Path("/proc") / str(pid)
    try:
        stat = (proc / "stat").read_text(encoding="utf-8")
        after_comm = stat[stat.rfind(")") + 2 :].split()
        start_ticks = int(after_comm[19])
        argv = [part.decode(errors="replace") for part in (proc / "cmdline").read_bytes().split(b"\0") if part]
        cwd = os.path.realpath(proc / "cwd")
    except (OSError, ValueError, IndexError, UnicodeError):
        return None
    if not argv:
        return None
    return {"pid": pid, "start_ticks": start_ticks, "cwd": cwd, "argv": argv}


def state_path(value: str | None) -> Path:
    return Path(value or os.environ.get("OPENCODE_STATE_FILE", str(Path.home() / ".local/state/telegram-agents/opencode.json")))


def project_path(value: str | None) -> str:
    return os.path.realpath(value or os.environ.get("OPENCODE_PROJECT_ROOT", DEFAULT_PROJECT))


def port_value(value: str | None) -> int:
    return int(value or os.environ.get("OPENCODE_PORT", str(DEFAULT_PORT)))


def expected_backend_argv(host: str, port: int) -> list[str]:
    return ["opencode", "serve", "--hostname", host, "--port", str(port)]


def argv_has_backend_contract(argv: list[str], host: str, port: int) -> bool:
    if len(argv) < 6:
        return False
    # The executable may be absolute after a launcher resolves it.  Everything
    # after it must be the exact serve contract, with no broad substring match.
    return os.path.basename(argv[0]) == "opencode" and argv[1:] == expected_backend_argv(host, port)[1:]


def argv_has_poller_contract(argv: list[str], entrypoint: str | None) -> bool:
    if not argv or not entrypoint:
        return False
    expected = os.path.realpath(entrypoint)
    for index, item in enumerate(argv):
        if os.path.realpath(item) == expected:
            return argv[index + 1 :] == ["start", "--mode", "installed"]
    return False


def check_record(state: dict, role: str, expected_project: str, host: str, port: int) -> tuple[dict | None, list[str]]:
    pid_key = f"{role}_pid"
    ticks_key = f"{role}_start_ticks"
    argv_key = f"{role}_argv"
    cwd_key = f"{role}_cwd"
    reasons: list[str] = []
    try:
        pid = int(state.get(pid_key))
    except (TypeError, ValueError):
        return None, [f"{role}-pid-missing"]
    current = pid_info(pid)
    if current is None:
        return None, [f"{role}-down"]
    if str(state.get(ticks_key)) != str(current["start_ticks"]):
        reasons.append(f"{role}-start-ticks-mismatch")
    if os.path.realpath(str(state.get(cwd_key) or "")) != expected_project or current["cwd"] != expected_project:
        reasons.append(f"{role}-wrong-cwd")
    recorded_argv = state.get(argv_key)
    if not isinstance(recorded_argv, list) or [str(x) for x in recorded_argv] != current["argv"]:
        reasons.append(f"{role}-argv-mismatch")
    if role == "backend" and not argv_has_backend_contract(current["argv"], host, port):
        reasons.append("backend-argv-contract-mismatch")
    if role == "poller" and not argv_has_poller_contract(current["argv"], state.get("poller_entrypoint")):
        reasons.append("poller-identity-mismatch")
    return current, reasons


def native_poller_status(entrypoint: str | None) -> dict:
    if not entrypoint:
        return {"status": "unavailable", "reason": "poller-entrypoint-unknown"}
    try:
        result = subprocess.run(
            [entrypoint, "status"], capture_output=True, text=True, timeout=5, check=False
        )
    except (OSError, subprocess.TimeoutExpired) as exc:
        return {"status": "unavailable", "reason": type(exc).__name__}
    text = (result.stdout + result.stderr).strip()
    status = "running" if "Service status: running" in text else "stopped" if "Service status: stopped" in text else "unknown"
    return {"status": status, "exit": result.returncode, "output": text[-500:]}


def native_service_state() -> dict | None:
    home = Path(os.environ.get("OPENCODE_TELEGRAM_HOME", str(Path.home() / ".config/opencode-telegram-bot")))
    return read_json(home / "run/bot-service.json")


def settings_binding(project: str) -> dict:
    home = Path(os.environ.get("OPENCODE_TELEGRAM_HOME", str(Path.home() / ".config/opencode-telegram-bot")))
    settings_file = home / "settings.json"
    settings = read_json(settings_file)
    if not settings:
        return {"status": "session-unbound", "source": str(settings_file), "reason": "settings-missing"}
    current_project = settings.get("currentProject")
    current_session = settings.get("currentSession")
    worktree = current_project.get("worktree") if isinstance(current_project, dict) else None
    session_id = current_session.get("id") if isinstance(current_session, dict) else None
    directory = current_session.get("directory") if isinstance(current_session, dict) else None
    if worktree != project or directory != project or not session_id:
        return {
            "status": "session-unbound",
            "source": str(settings_file),
            "project_worktree": worktree,
            "session_directory": directory,
            "reason": "missing-or-project-mismatch",
        }
    return {
        "status": "bound",
        "source": str(settings_file),
        "project_worktree": worktree,
        "session_directory": directory,
        "session_id": session_id,
        "session_title": current_session.get("title"),
    }


def inspect(args: argparse.Namespace) -> int:
    state = read_json(state_path(args.state))
    result = {"status": "stopped", "backend": None, "poller": None, "reasons": []}
    if not state:
        result["reasons"] = ["owner-state-missing"]
        json_out(result)
        return 1
    project = project_path(args.project or state.get("project"))
    host = args.host or str(state.get("host") or DEFAULT_HOST)
    port = port_value(args.port or str(state.get("port") or DEFAULT_PORT))
    backend, backend_reasons = check_record(state, "backend", project, host, port)
    poller, poller_reasons = check_record(state, "poller", project, host, port)
    if backend is not None:
        backend["valid"] = not backend_reasons
        backend["reasons"] = backend_reasons
    if poller is not None:
        poller["valid"] = not poller_reasons
        poller["reasons"] = poller_reasons
    result["backend"] = backend
    result["poller"] = poller
    result["reasons"] = backend_reasons + poller_reasons
    if state.get("owner") != OWNER:
        result["reasons"].append("foreign-owner")
    if state.get("bot") != BOT:
        result["reasons"].append("bot-identity-mismatch")
    if project != os.path.realpath(DEFAULT_PROJECT):
        result["reasons"].append("wrong-project")
    if host != DEFAULT_HOST or port != DEFAULT_PORT:
        result["reasons"].append("wrong-listen-boundary")
    result["native_poller"] = native_poller_status(state.get("poller_entrypoint"))
    binding = settings_binding(project)
    result["session"] = binding
    if state.get("session_binding") != binding:
        # Session/project metadata is safe to refresh.  Credentials and package
        # settings remain outside this owner file.
        state["session_binding"] = binding
        path = state_path(args.state)
        temp = path.with_name(f"{path.name}.{os.getpid()}.tmp")
        temp.write_text(json.dumps(state, indent=2) + "\n", encoding="utf-8")
        os.replace(temp, path)
    result["project"] = project
    result["host"] = host
    result["port"] = port
    result["status"] = "running" if not result["reasons"] else "degraded"
    json_out(result)
    return 0 if result["status"] == "running" else 1


def capture(args: argparse.Namespace) -> int:
    project = project_path(args.project)
    host = args.host or DEFAULT_HOST
    port = port_value(args.port)
    backend = pid_info(int(args.backend_pid))
    poller = pid_info(int(args.poller_pid))
    if not backend or not poller:
        print("cannot capture missing backend/poller", file=sys.stderr)
        return 1
    if backend["cwd"] != project or not argv_has_backend_contract(backend["argv"], host, port):
        print("backend does not satisfy exact owner contract", file=sys.stderr)
        return 1
    if poller["cwd"] != project or not argv_has_poller_contract(poller["argv"], args.poller_entrypoint):
        print("poller does not satisfy exact owner contract", file=sys.stderr)
        return 1
    service_state = read_json(Path(args.poller_service_state)) if args.poller_service_state else None
    if args.poller_service_state and (not service_state or int(service_state.get("pid", -1)) != poller["pid"]):

def stop(args: argparse.Namespace) -> int:
    state = read_json(state_path(args.state))
    if not state:
        print("opencode: STOPPED (owner state absent)")
        return 0
    project = project_path(args.project or state.get("project"))
    host = args.host or str(state.get("host") or DEFAULT_HOST)
    port = port_value(args.port or str(state.get("port") or DEFAULT_PORT))
    boundary_reasons: list[str] = []
    if state.get("schema") != "helmcortex.opencode-owner.v2":
        boundary_reasons.append("schema-mismatch")
    if state.get("owner") != OWNER:
        boundary_reasons.append("foreign-owner")
    if state.get("bot") != BOT:
        boundary_reasons.append("bot-identity-mismatch")
    if project != os.path.realpath(DEFAULT_PROJECT):
        boundary_reasons.append("wrong-project")
    if host != DEFAULT_HOST or port != DEFAULT_PORT:
        boundary_reasons.append("wrong-listen-boundary")
    if boundary_reasons:
        print(f"refusing stale-state cleanup: {','.join(boundary_reasons)}", file=sys.stderr)
        return 1
    owned: list[int] = []
    refused = 0
    stale = 0
    for role in ("poller", "backend"):
        current, reasons = check_record(state, role, project, host, port)
        if current is None and reasons == [f"{role}-down"]:
            stale += 1
            continue
        if reasons:
            refused += 1
            print(f"refusing to stop {role}: {','.join(reasons)}", file=sys.stderr)
            continue
        if current:
            owned.append(current["pid"])
    for pid in owned:
        try:
            os.kill(pid, signal.SIGTERM)
        except ProcessLookupError:
            pass
    deadline = time.monotonic() + 5
    while owned and time.monotonic() < deadline:
        if all(pid_info(pid) is None for pid in owned):
            break
        time.sleep(0.1)
    remaining = [pid for pid in owned if pid_info(pid) is not None]
    if remaining:
        for pid in remaining:
            try:
                os.kill(pid, signal.SIGKILL)
            except ProcessLookupError:
                pass
    if not remaining and refused == 0:
        try:
            state_path(args.state).unlink()
        except FileNotFoundError:
            pass
    print(f"opencode: stopped_owned={len(owned)} stale={stale} refused={refused}")
    return 0 if not remaining and refused == 0 else 1

* OpenCode survival watchdog

The OpenCode pair is a host-managed headless service on Kikin. This watchdog is
scheduled outside OpenCode and therefore must never be launched as a synchronous
child of the session it may need to restart. It checks the versioned owner claim,
the exact backend and poller identities, and a bounded loopback API probe. It
only heals an existing owner state whose failure is limited to a missing backend,
missing poller, or unreachable local API; missing owner state and identity
mismatches remain operator-visible skips, so an intentional stop is not undone.
The first observation is persisted and must survive the confirmation interval.
Recovery is dispatched with a new session and recorded under the private XDG
state directory. The cron installer is explicit and dry-run capable; tangling
does not install a privileged schedule.

"""Guard the Kikin OpenCode pair from outside the OpenCode process tree."""

from __future__ import annotations

import argparse
import fcntl
import json
import os
import pathlib
import subprocess
import sys
import tempfile
import time
from urllib.error import HTTPError, URLError
from urllib.request import Request, urlopen


SCHEMA = "dotcortex.opencode-watchdog.v1"
SAFE_REASONS = frozenset({"backend-down", "poller-down", "api-unreachable"})
DEFAULT_COOLDOWN = 15 * 60
DEFAULT_CONFIRM_SECONDS = 120.0
DEFAULT_ALERT_COOLDOWN = 6 * 60 * 60
DEFAULT_MAX_FAILURES = 3


def read_json(path: pathlib.Path) -> dict | None:
    try:
        value = json.loads(path.read_text(encoding="utf-8"))
    except (OSError, ValueError):
        return None
    return value if isinstance(value, dict) else None


def atomic_json(path: pathlib.Path, value: dict) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    fd, temporary = tempfile.mkstemp(prefix=f".{path.name}.", dir=path.parent)
    try:
        with os.fdopen(fd, "w", encoding="utf-8") as stream:
            json.dump(value, stream, sort_keys=True, separators=(",", ":"))
            stream.write("\n")
            stream.flush()
            os.fsync(stream.fileno())
        os.chmod(temporary, 0o600)
        os.replace(temporary, path)
    finally:
        try:
            os.unlink(temporary)
        except FileNotFoundError:
            pass


def log_event(path: pathlib.Path, **fields: object) -> None:
    try:
        path.parent.mkdir(parents=True, exist_ok=True)
        with path.open("a", encoding="utf-8") as stream:
            stream.write(json.dumps({"timestamp": time.time(), **fields}, sort_keys=True) + "\n")
        os.chmod(path, 0o600)
    except OSError:
        pass


def emit(value: dict, json_output: bool) -> None:
    if json_output:
        print(json.dumps(value, sort_keys=True, separators=(",", ":")))
    else:
        print(f"OpenCode watchdog: {value.get('status')} ({value.get('reason')})")


def host_matches(expected: str) -> bool:
    try:
        return pathlib.Path("/etc/hostname").read_text(encoding="utf-8").strip() == expected
    except OSError:
        return False


def owner_inspect(args: argparse.Namespace) -> tuple[dict | None, int, str]:
    command = [
        str(pathlib.Path(args.owner).expanduser()),
        "inspect",
        "--state", str(pathlib.Path(args.owner_state).expanduser()),
        "--project", str(pathlib.Path(args.project).expanduser()),
        "--host", "127.0.0.1",
        "--port", str(args.port),
    ]
    try:
        completed = subprocess.run(command, capture_output=True, text=True, timeout=args.command_timeout)
    except (OSError, subprocess.TimeoutExpired) as error:
        return None, 124, type(error).__name__
    try:
        payload = json.loads(completed.stdout)
    except (TypeError, ValueError):
        return None, completed.returncode, "owner-invalid-json"
    if not isinstance(payload, dict):
        return None, completed.returncode, "owner-invalid-document"
    return payload, completed.returncode, completed.stderr.strip()


def api_probe(port: int, timeout: float) -> dict:
    request = Request(f"http://127.0.0.1:{port}/", headers={"Accept": "application/json"})
    try:
        with urlopen(request, timeout=timeout) as response:
            return {"status": "healthy" if response.status == 200 else "unhealthy", "http_status": response.status}
    except HTTPError as error:
        return {"status": "unhealthy", "http_status": error.code, "reason": "api-unreachable"}
    except (OSError, URLError, TimeoutError) as error:
        return {"status": "unhealthy", "reason": "api-unreachable", "error": type(error).__name__}


def fingerprint(payload: dict, probe: dict) -> str:
    material = {
        "reasons": payload.get("reasons", []),
        "backend": (payload.get("backend") or {}).get("pid"),
        "poller": (payload.get("poller") or {}).get("pid"),
        "api": probe.get("reason") or probe.get("http_status"),
    }
    return json.dumps(material, sort_keys=True, separators=(",", ":"))


def runtime_environment() -> dict[str, str]:
    environment = dict(os.environ)
    home = pathlib.Path.home()
    environment["HOME"] = str(home)
    environment["PATH"] = ":".join(filter(None, [
        str(home / ".local/bin"),
        str(home / ".npm-global/bin"),
        environment.get("PATH", ""),
    ]))
    return environment


def run_command(command: list[str], args: argparse.Namespace, stream) -> subprocess.CompletedProcess:
    stream.write(f"command={json.dumps(command)}\n")
    stream.flush()
    try:
        completed = subprocess.run(
            command,
            stdin=subprocess.DEVNULL,
            stdout=stream,
            stderr=subprocess.STDOUT,
            text=True,
            timeout=args.command_timeout,
            env=args.environment,
        )
    except (OSError, subprocess.TimeoutExpired) as error:
        stream.write(f"error={type(error).__name__}\n")
        stream.flush()
        return subprocess.CompletedProcess(command, 124)
    stream.write(f"returncode={completed.returncode}\n")
    stream.flush()
    return completed


def worker(args: argparse.Namespace) -> int:
    state_path = pathlib.Path(args.watchdog_state).expanduser()
    event_path = state_path.with_name("events.jsonl")
    log_path = state_path.with_name("recovery.log")
    manager = str(pathlib.Path(args.manager).expanduser())
    with log_path.open("a", encoding="utf-8") as stream:
        stream.write(f"worker-start={time.time()}\n")
        stop = run_command([manager, "stop", "opencode"], args, stream)
        start = run_command([manager, "start", "opencode"], args, stream)
        payload, inspect_code, detail = owner_inspect(args)
        probe = api_probe(args.port, args.api_timeout) if payload and payload.get("status") == "running" else {"status": "not-probed"}
        healthy = inspect_code == 0 and payload is not None and payload.get("status") == "running" and probe.get("status") == "healthy"
        stream.write(f"worker-result={'success' if healthy else 'failed'}\n")
    state = read_json(state_path) or {"schema": SCHEMA, "failures": 0}
    state.update({"last_worker": time.time(), "last_result": "recovered" if healthy else "failed"})
    state["failures"] = 0 if healthy else int(state.get("failures", 0)) + 1
    if healthy:
        state.pop("degraded_since", None)
        state.pop("degraded_fingerprint", None)
        state.pop("last_alert", None)
    atomic_json(state_path, state)
    log_event(event_path, action="recovery", result=state["last_result"], stop=stop.returncode, start=start.returncode, inspect=detail)
    return 0 if healthy else 1


def assess_and_dispatch(args: argparse.Namespace, state_path: pathlib.Path) -> int:
    event_path = state_path.with_name("events.jsonl")
    state = read_json(state_path) or {"schema": SCHEMA, "failures": 0}
    payload, inspect_code, detail = owner_inspect(args)
    if payload is None:
        value = {"schema": SCHEMA, "status": "skip", "reason": detail, "inspect_code": inspect_code}
        emit(value, args.json)
        return 0

    probe = api_probe(args.port, args.api_timeout) if payload.get("status") == "running" else {"status": "not-probed"}
    reasons = set(str(reason) for reason in payload.get("reasons", []))
    if probe.get("reason") == "api-unreachable":
        reasons.add("api-unreachable")
    if not reasons:
        state.update({"last_healthy": time.time(), "failures": 0})
        state.pop("degraded_since", None)
        state.pop("degraded_fingerprint", None)
        state.pop("last_alert", None)
        if not args.dry_run:
            atomic_json(state_path, state)
        emit({"schema": SCHEMA, "status": "healthy", "reason": "owner-and-api-healthy", "probe": probe}, args.json)
        return 0

    if not reasons.issubset(SAFE_REASONS) or payload.get("status") == "stopped":
        emit({"schema": SCHEMA, "status": "skip", "reason": "owner-not-safe-to-restart", "owner_reasons": sorted(reasons), "probe": probe}, args.json)
        return 0

    now = time.time()
    current_fingerprint = fingerprint(payload, probe)
    if state.get("degraded_fingerprint") != current_fingerprint:
        state.update({"degraded_since": now, "degraded_fingerprint": current_fingerprint})
        if not args.dry_run:
            atomic_json(state_path, state)
        emit({"schema": SCHEMA, "status": "suspect", "reason": "confirmation-pending", "owner_reasons": sorted(reasons), "probe": probe}, args.json)
        return 0
    if now - float(state.get("degraded_since", now)) < args.confirm_seconds:
        emit({"schema": SCHEMA, "status": "suspect", "reason": "confirmation-pending", "owner_reasons": sorted(reasons), "probe": probe}, args.json)
        return 0
    if now - float(state.get("last_attempt", 0)) < args.cooldown:
        emit({"schema": SCHEMA, "status": "skip", "reason": "cooldown", "owner_reasons": sorted(reasons), "probe": probe}, args.json)
        return 0
    if int(state.get("failures", 0)) >= args.max_failures:
        if now - float(state.get("last_alert", 0)) < args.alert_cooldown:
            emit({"schema": SCHEMA, "status": "alert", "reason": "failure-alert-cooldown", "failures": state.get("failures", 0)}, args.json)
            return 0
        state["last_alert"] = now
        if not args.dry_run:
            atomic_json(state_path, state)
        emit({"schema": SCHEMA, "status": "alert", "reason": "recovery-failure-threshold", "failures": state.get("failures", 0)}, args.json)
        return 0
    if args.dry_run:
        emit({"schema": SCHEMA, "status": "dry-run", "reason": "would-dispatch-recovery", "owner_reasons": sorted(reasons), "probe": probe}, args.json)
        return 0

    state.update({"last_attempt": now, "last_reason": sorted(reasons)})
    atomic_json(state_path, state)
    command = [
        sys.executable, str(pathlib.Path(__file__).resolve()),
        "--worker", "--expected-host", args.expected_host,
        "--owner", args.owner, "--owner-state", args.owner_state,
        "--manager", args.manager, "--project", args.project,
        "--port", str(args.port), "--watchdog-state", args.watchdog_state,
        "--api-timeout", str(args.api_timeout),
        "--command-timeout", str(args.command_timeout),
    ]
    log_path = state_path.with_name("recovery.log")
    with log_path.open("a", encoding="utf-8") as stream:
        subprocess.Popen(
            command,
            stdin=subprocess.DEVNULL,
            stdout=stream,
            stderr=subprocess.STDOUT,
            start_new_session=True,
            close_fds=True,
            env=args.environment,
        )
    log_event(event_path, action="dispatch", result="dispatched", reasons=sorted(reasons), fingerprint=current_fingerprint)
    emit({"schema": SCHEMA, "status": "dispatched", "reason": "detached-recovery", "owner_reasons": sorted(reasons), "probe": probe}, args.json)
    return 0


def run(args: argparse.Namespace) -> int:
    if not host_matches(args.expected_host):
        value = {"schema": SCHEMA, "status": "skip", "reason": "wrong-host", "expected_host": args.expected_host}
        emit(value, args.json)
        return 0
    args.environment = runtime_environment()
    if args.worker:
        return worker(args)

    state_path = pathlib.Path(args.watchdog_state).expanduser()
    if args.dry_run:
        return assess_and_dispatch(args, state_path)
    state_path.parent.mkdir(parents=True, exist_ok=True)
    lock_path = state_path.with_name("watchdog.lock")
    with lock_path.open("a+", encoding="utf-8") as lock:
        try:
            fcntl.flock(lock.fileno(), fcntl.LOCK_EX | fcntl.LOCK_NB)
        except BlockingIOError:
            emit({"schema": SCHEMA, "status": "skip", "reason": "watchdog-already-running"}, args.json)
            return 0
        return assess_and_dispatch(args, state_path)


def parser() -> argparse.ArgumentParser:
    home = pathlib.Path.home()
    state_home = pathlib.Path(os.environ.get("XDG_STATE_HOME", str(home / ".local/state")))
    p = argparse.ArgumentParser(description=__doc__)

    p.add_argument("--manager", default=str(home / ".local/bin/telegram-agent-host"))

    p.add_argument("--command-timeout", type=float, default=120.0)
    p.add_argument("--confirm-seconds", type=float, default=DEFAULT_CONFIRM_SECONDS)
    p.add_argument("--cooldown", type=float, default=DEFAULT_COOLDOWN)

TAG="opencode-watchdog-cron-apply"
TARGET="/etc/cron.d/dotcortex-opencode-watchdog"
REMOVE=0
DRY=0
EXPECTED_HOST=""

while [ "$#" -gt 0 ]; do
  case "$1" in
    --remove) REMOVE=1 ;;
    --dry-run) DRY=1 ;;
    --host)
      [ "$#" -ge 2 ] || { echo "$TAG: --host requires a value" >&2; exit 2; }
      EXPECTED_HOST="$2"
      shift ;;
    -h|--help|help)
      echo "Usage: $TAG --host EXACT_HOST [--dry-run] [--remove]"
      exit 0 ;;
    *) echo "$TAG: unknown argument: $1" >&2; exit 2 ;;
  esac
  shift
done

run_priv() { if [ "$(id -u)" = 0 ]; then "$@"; else sudo -n "$@"; fi; }

if [ "$REMOVE" = 1 ]; then
  if [ "$DRY" = 1 ]; then
    echo "remove $TARGET"
  else
    run_priv rm -f "$TARGET"
    echo "$TAG: removed $TARGET"
  fi
  exit 0
fi

[ -n "$EXPECTED_HOST" ] || { echo "$TAG: --host EXACT_HOST is required" >&2; exit 2; }
CURRENT_HOST="$(hostname)"
[ "$CURRENT_HOST" = "$EXPECTED_HOST" ] || {
  echo "$TAG: refusing installation on $CURRENT_HOST; expected $EXPECTED_HOST" >&2
  exit 1
}

USER_NAME="$(id -un)"
USER_ID="$(id -u)"
TARGET_HOME="$HOME"
WATCHDOG="$TARGET_HOME/.local/bin/opencode-watchdog"

* Telegram agent boot owner

The host manager already owns exact enabled-agent selection and readiness.  This
boot wrapper adds only bounded initial launch, per-agent retry, locking, receipts,
and log retention; one failed agent cannot suppress the other enabled agents.
The installed cron owner supplies the Guix core profile explicitly, while the
manager binds Ductor to its canonical supervisor path and OpenCode to the core
Node runtime.  Cold boot therefore does not depend on an interactive shell's
ambient =PATH= and never duplicates agent-specific process ownership.

#+BEGIN_SRC bash :tangle all/.local/bin/telegram-agent-boot :shebang "#!/usr/bin/env bash" :comments no
set -u

EXPECTED_HOST=""
DELAY=15
ATTEMPTS=4
RETRY_SECONDS=15
MANAGER="${TELEGRAM_AGENT_MANAGER:-$HOME/.local/bin/telegram-agent-host}"
STATE_DIR="${XDG_STATE_HOME:-$HOME/.local/state}/telegram-agent-boot"
NO_LOG="${TELEGRAM_AGENT_BOOT_NO_LOG:-0}"

usage() {
  echo "Usage: telegram-agent-boot --expected-host HOST [--delay SECONDS] [--attempts COUNT] [--retry-seconds SECONDS] [--manager PATH] [--state-dir PATH]"
}

while [ "$#" -gt 0 ]; do
  case "$1" in
    --expected-host) [ "$#" -ge 2 ] || { usage >&2; exit 2; }; EXPECTED_HOST="$2"; shift ;;
    --delay) [ "$#" -ge 2 ] || { usage >&2; exit 2; }; DELAY="$2"; shift ;;
    --attempts) [ "$#" -ge 2 ] || { usage >&2; exit 2; }; ATTEMPTS="$2"; shift ;;
    --retry-seconds) [ "$#" -ge 2 ] || { usage >&2; exit 2; }; RETRY_SECONDS="$2"; shift ;;
    --manager) [ "$#" -ge 2 ] || { usage >&2; exit 2; }; MANAGER="$2"; shift ;;
    --state-dir) [ "$#" -ge 2 ] || { usage >&2; exit 2; }; STATE_DIR="$2"; shift ;;
    -h|--help|help) usage; exit 0 ;;
    *) echo "telegram-agent-boot: unknown argument: $1" >&2; usage >&2; exit 2 ;;
  esac
  shift
done

[ -n "$EXPECTED_HOST" ] || { echo "telegram-agent-boot: --expected-host is required" >&2; exit 2; }
case "$DELAY:$ATTEMPTS:$RETRY_SECONDS" in
  *[!0-9:]*|:*|*::*|*:) echo "telegram-agent-boot: delay, attempts and retry seconds must be non-negative integers" >&2; exit 2 ;;
esac
[ "$ATTEMPTS" -gt 0 ] || { echo "telegram-agent-boot: attempts must be positive" >&2; exit 2; }

CURRENT_HOST="$(hostname | tr '[:upper:]' '[:lower:]')"
EXPECTED_HOST="$(printf '%s' "$EXPECTED_HOST" | tr '[:upper:]' '[:lower:]')"
[ "$CURRENT_HOST" = "$EXPECTED_HOST" ] || {
  echo "telegram-agent-boot: refusing host $CURRENT_HOST; expected $EXPECTED_HOST" >&2
  exit 64
}
[ -x "$MANAGER" ] || { echo "telegram-agent-boot: manager is not executable: $MANAGER" >&2; exit 69; }

umask 077
mkdir -p "$STATE_DIR"
if [ "$NO_LOG" != 1 ]; then
  LOG="$STATE_DIR/boot.log"
  if [ -f "$LOG" ] && [ "$(wc -c <"$LOG")" -ge 10485760 ]; then
    mv -f "$LOG" "$LOG.1"
  fi
  exec >>"$LOG" 2>&1
fi

exec 9>"$STATE_DIR/boot.lock"
if ! flock -n 9; then
  echo "telegram-agent-boot: another boot attempt owns the lock"
  exit 0
fi

write_receipt() {
  status="$1"
  attempt="$2"
  outcomes="$3"
  RECEIPT_TMP="$STATE_DIR/receipt.json.tmp.$$"
  python3 - "$RECEIPT_TMP" "$STATE_DIR/receipt.json" "$CURRENT_HOST" "$status" "$attempt" "$outcomes" <<'PY'
import json, os, pathlib, sys, time
tmp, dest, host, status, attempt, outcome_text = sys.argv[1:]
agents = {}
for row in outcome_text.split():
    name, value = row.split("=", 1)
    agents[name] = value
path = pathlib.Path(tmp)
path.write_text(json.dumps({"agents": agents, "attempt": int(attempt), "host": host, "schema": "dotcortex.telegram-agent-boot.v2", "status": status, "timestamp": int(time.time())}, sort_keys=True, separators=(",", ":")) + "\n", encoding="utf-8")
os.chmod(path, 0o600)
os.replace(path, dest)
PY
}

[ "$DELAY" -eq 0 ] || sleep "$DELAY"
enabled="$($MANAGER enabled)" || {
  write_receipt failed 0 ""
  echo "telegram-agent-boot: cannot enumerate enabled agents" >&2
  exit 1
}
[ -n "$enabled" ] || {
  write_receipt failed 0 ""
  echo "telegram-agent-boot: no enabled agents" >&2
  exit 1
}
unresolved="$enabled"
attempt=1
while [ "$attempt" -le "$ATTEMPTS" ]; do
  echo "telegram-agent-boot: attempt $attempt/$ATTEMPTS"
  next_unresolved=""
  outcomes=""
  for agent in $enabled; do
    case " $unresolved " in
      *" $agent "*)
        if "$MANAGER" start "$agent"; then
          outcomes="$outcomes $agent=ready"
        else
          outcomes="$outcomes $agent=failed"
          next_unresolved="$next_unresolved $agent"
        fi ;;
      *) outcomes="$outcomes $agent=ready" ;;
    esac
  done
  unresolved="$next_unresolved"
  if [ -z "$unresolved" ]; then
    write_receipt ready "$attempt" "$outcomes"
    echo "telegram-agent-boot: ready"
    exit 0
  fi
  write_receipt retry "$attempt" "$outcomes"
  [ "$attempt" -ge "$ATTEMPTS" ] || sleep "$RETRY_SECONDS"
  attempt=$((attempt + 1))
done

write_receipt failed "$ATTEMPTS" "$outcomes"
echo "telegram-agent-boot: failed after $ATTEMPTS attempts" >&2
exit 1

pid_file_has_command() {

    [ -r "$pid_file" ] || return 1
    IFS= read -r pid < "$pid_file" || return 1
    case "$pid" in ''|*[!0-9]*) return 1 ;; esac

    done < "/proc/$pid/cmdline"
    return 1
}

deepseek_harness_rotate_log() {
    local log="$DSH_TELEGRAM_LOG_FILE" max="$DSH_TELEGRAM_LOG_MAX_BYTES" keep="$DSH_TELEGRAM_LOG_KEEP"
    case "$max" in ''|*[!0-9]*) max=10485760 ;; esac
    case "$keep" in ''|*[!0-9]*) keep=5 ;; esac
    [ -f "$log" ] || return 0
    local size
    size=$(wc -c < "$log" 2>/dev/null || printf '0')
    [ "$size" -le "$max" ] && return 0
    local i prev
    i="$keep"
    while [ "$i" -gt 1 ]; do
        prev=$((i - 1))
        [ -f "$log.$prev" ] && mv "$log.$prev" "$log.$i"
        i="$prev"
    done
    mv "$log" "$log.1"
}

        case "$key" in ''|\#*) continue ;; esac
        case "$key" in
            TELEGRAM_BOT_TOKEN|TELEGRAM_BOT_TOKEN_FILE|NEURALWATT_API_KEY|NEURALWATT_API_KEY_FILE|\
            DSH_HOME|DSH_TELEGRAM_PROFILE|DSH_TELEGRAM_WORKSPACE|DSH_TELEGRAM_PLUGIN_ROOT|\
            DSH_TELEGRAM_MODEL_PROVIDER|DSH_TELEGRAM_MODEL|DSH_TELEGRAM_PROVIDER_BASE_URL)
                value="${value%\"}"
                value="${value#\"}"
                value="${value%\'}"
                value="${value#\'}"
                export "$key=$value"
                ;;
        esac
    done < "$env_file"
}

deepseek_harness_validate_private_config() {
    local token_file key_file config settings profile_patch
    deepseek_harness_load_env || return 1

    if [ -z "${TELEGRAM_BOT_TOKEN:-}" ]; then
        token_file="${TELEGRAM_BOT_TOKEN_FILE:-}"
        if [ -z "$token_file" ]; then
            echo "DeepSeek Harness Telegram token is missing; set TELEGRAM_BOT_TOKEN or TELEGRAM_BOT_TOKEN_FILE" >&2
            return 1
        fi
        if [ ! -r "$token_file" ]; then
            echo "DeepSeek Harness token file is not readable: $token_file" >&2
            return 1
        fi
        if [ "$(stat -c '%a' "$token_file" 2>/dev/null || printf '000')" != "600" ]; then
            echo "DeepSeek Harness token file must be mode 0600: $token_file" >&2
            return 1
        fi
    fi

    key_file="${NEURALWATT_API_KEY_FILE:-}"
    if [ -z "$key_file" ] || [ "$key_file" = "YOUR_HELMCORTEX_NEURALWATT_KEY_FILE" ]; then
        echo "DeepSeek Harness requires NEURALWATT_API_KEY_FILE pointing to the private HelmCortex NeuralWatt key" >&2
        return 1
    fi
    if [ ! -r "$key_file" ]; then
        echo "HelmCortex NeuralWatt key file is not readable: $key_file" >&2
        return 1
    fi
    if [ "$(stat -c '%a' "$key_file" 2>/dev/null || printf '000')" != "600" ]; then
        echo "HelmCortex NeuralWatt key file must be mode 0600: $key_file" >&2
        return 1
    fi
    IFS= read -r NEURALWATT_API_KEY < "$key_file" || true
    NEURALWATT_API_KEY="${NEURALWATT_API_KEY%$'\r'}"
    export NEURALWATT_API_KEY
    if [ -z "$NEURALWATT_API_KEY" ]; then
        echo "HelmCortex NeuralWatt key file is empty: $key_file" >&2
        return 1
    fi

    if [ "$DSH_TELEGRAM_MODEL_PROVIDER" != "neuralwatt" ] || \
       [ "$DSH_TELEGRAM_MODEL" != "deepseek-v4-flash" ] || \
       [ "$DSH_TELEGRAM_PROVIDER_BASE_URL" != "https://api.neuralwatt.com/v1" ]; then
        echo "DeepSeek Harness must target neuralwatt/deepseek-v4-flash at https://api.neuralwatt.com/v1; no fallback is permitted" >&2
        return 1
    fi

    settings="$DSH_HOME/settings.yaml"
    if [ ! -r "$DSH_TELEGRAM_SETTINGS_TEMPLATE" ]; then
        echo "DeepSeek Harness NeuralWatt settings template is missing: $DSH_TELEGRAM_SETTINGS_TEMPLATE" >&2
        return 1
    fi
    if [ ! -r "$settings" ]; then
        echo "DeepSeek Harness settings are missing: $settings (copy the NeuralWatt template exactly)" >&2
        return 1
    fi
    if ! cmp -s "$settings" "$DSH_TELEGRAM_SETTINGS_TEMPLATE"; then
        echo "DeepSeek Harness settings differ from the single-model NeuralWatt V4 Flash template; refusing possible fallback" >&2
        return 1
    fi

    profile_patch="$DSH_HOME/profiles/$DSH_TELEGRAM_PROFILE/cordis.patch.yml"
    if [ ! -r "$DSH_TELEGRAM_PROFILE_PATCH_TEMPLATE" ]; then
        echo "DeepSeek Harness credential-containment patch template is missing: $DSH_TELEGRAM_PROFILE_PATCH_TEMPLATE" >&2
        return 1
    fi
    if [ ! -r "$profile_patch" ]; then
        echo "DeepSeek Harness profile patch is missing: $profile_patch (copy the credential-containment template exactly)" >&2
        return 1
    fi
    if ! cmp -s "$profile_patch" "$DSH_TELEGRAM_PROFILE_PATCH_TEMPLATE"; then
        echo "DeepSeek Harness profile patch does not disable native DeepSeek chat/search routes; refusing credential egress" >&2
        return 1
    fi

    config="$(deepseek_harness_config_file)"
    if [ ! -r "$config" ]; then
        echo "DeepSeek Harness Telegram config is missing: $config" >&2
        return 1
    fi
    python3 - "$config" "$DSH_TELEGRAM_MODEL_PROVIDER" "$DSH_TELEGRAM_MODEL" <<'PY'
import json
import sys
from pathlib import Path

path = Path(sys.argv[1])
expected_provider, expected_model = sys.argv[2], sys.argv[3]
try:
    data = json.loads(path.read_text(encoding="utf-8"))
except Exception as exc:
    print(f"DeepSeek Harness Telegram config is invalid JSON: {exc}", file=sys.stderr)
    raise SystemExit(1)
allowed = (((data.get("security") or {}).get("allowedChatIds")) or [])
if not isinstance(allowed, list):
    print("DeepSeek Harness security.allowedChatIds must be a list", file=sys.stderr)
    raise SystemExit(1)
if not allowed:
    print("DeepSeek Harness security.allowedChatIds is empty; startup remains deny-all", file=sys.stderr)
    raise SystemExit(1)
if not all(isinstance(item, int) for item in allowed):
    print("DeepSeek Harness security.allowedChatIds must contain numeric chat IDs only", file=sys.stderr)
    raise SystemExit(1)
model = data.get("model") or {}
if model.get("provider") != expected_provider or model.get("model") != expected_model:
    print(
        f"DeepSeek Harness Telegram model must be {expected_provider}/{expected_model}; no fallback is permitted",
        file=sys.stderr,
    )
    raise SystemExit(1)
PY
}

deepseek_harness_preflight_model() {
    env -u DEEPSEEK_API_KEY -u DEEPSEEK_API_KEY_FILE \
        NEURALWATT_API_KEY="$NEURALWATT_API_KEY" \
        DSH_TELEGRAM_PROVIDER_BASE_URL="$DSH_TELEGRAM_PROVIDER_BASE_URL" \
        DSH_TELEGRAM_MODEL="$DSH_TELEGRAM_MODEL" \
        python3 - <<'PY'
import json
import os
import sys
from urllib.error import HTTPError, URLError
from urllib.request import Request, urlopen

base_url = os.environ["DSH_TELEGRAM_PROVIDER_BASE_URL"].rstrip("/")
model = os.environ["DSH_TELEGRAM_MODEL"]
request = Request(
    f"{base_url}/models",
    headers={"Authorization": f"Bearer {os.environ['NEURALWATT_API_KEY']}"},
)
try:
    with urlopen(request, timeout=15) as response:
        payload = json.load(response)
except HTTPError as exc:
    print(f"NeuralWatt model visibility preflight failed: HTTP {exc.code}", file=sys.stderr)
    raise SystemExit(1)
except (URLError, TimeoutError, OSError, ValueError) as exc:
    print(f"NeuralWatt model visibility preflight failed: {exc}", file=sys.stderr)
    raise SystemExit(1)

visible = set()
data = payload.get("data") if isinstance(payload, dict) else None
if isinstance(data, list):
    visible.update(item.get("id") for item in data if isinstance(item, dict) and isinstance(item.get("id"), str))
models = payload.get("models") if isinstance(payload, dict) else None
if isinstance(models, dict):
    visible.update(key for key in models if isinstance(key, str))
if model not in visible:
    print(
        f"NeuralWatt does not expose required model {model}; refusing undeclared fallback and poller start",
        file=sys.stderr,
    )
    raise SystemExit(1)
print(f"NeuralWatt model visibility preflight passed: {model}")
PY
}

stop_pi_agent() {
    if ! gemma_telegram_running; then
        echo "pi-agent: not running"
        return 0
    fi
    local pid pgid
    pid="$(cat "$GEMMA_TELEGRAM_PID_FILE" 2>/dev/null)"
    pgid=$(ps -o pgid= -p "$pid" 2>/dev/null | tr -d ' ' || true)
    if [ "$pgid" = "$pid" ]; then
        kill -TERM -- "-$pgid" 2>/dev/null || true
    else
        kill -TERM "$pid" 2>/dev/null || true
    fi
    for _ in {1..20}; do
        gemma_telegram_running || break
        sleep 0.25
    done
    if gemma_telegram_running; then
        echo "Gemma Telegram did not stop gracefully; forcing verified process group" >&2
        if [ "$pgid" = "$pid" ]; then
            kill -KILL -- "-$pgid" 2>/dev/null || true
        else
            kill -KILL "$pid" 2>/dev/null || true
        fi
    fi
    gemma_telegram_running && return 1
    rm -f "$GEMMA_TELEGRAM_PID_FILE"
}

enable_agent() {
    local agent="$1"
    validate_agent "$agent"
    local host
    host=$(get_hostname)

    if [ ! -f "$HOSTS_FILE" ]; then
        echo "Error: hosts.conf not found at $HOSTS_FILE"
        exit 1
    fi

    local line
    line=$(grep -i "^${host}|" "$HOSTS_FILE" 2>/dev/null || true)
    if [ -z "$line" ]; then
        echo "Error: host '$host' not found in hosts.conf"
        exit 1
    fi

    local current_agents
    current_agents=$(echo "$line" | cut -d'|' -f2)

    if echo "$current_agents" | grep -qw "$agent"; then
        echo "$agent is already enabled on $host"
        return
    fi

    local new_agents
    if [ -z "$current_agents" ]; then
        new_agents="$agent"
    else
        new_agents="$current_agents,$agent"
    fi

    local tmp_hosts
    tmp_hosts="${HOSTS_FILE}.tmp.$$"
    awk -F'|' -v host="$host" -v agents="$new_agents" '
        BEGIN { OFS = FS }
        tolower($1) == tolower(host) { $2 = agents }
        { print }
    ' "$HOSTS_FILE" > "$tmp_hosts"
    mv "$tmp_hosts" "$HOSTS_FILE"
    echo "Enabled $agent on $host"
    echo "Run 'telegram-agent-host sync' to apply, then 'telegram-agent-host start'"
}

disable_agent() {
    local agent="$1"
    validate_agent "$agent"
    local host
    host=$(get_hostname)

    if [ ! -f "$HOSTS_FILE" ]; then
        echo "Error: hosts.conf not found at $HOSTS_FILE"
        exit 1
    fi

    local line
    line=$(grep -i "^${host}|" "$HOSTS_FILE" 2>/dev/null || true)
    if [ -z "$line" ]; then
        echo "Error: host '$host' not found in hosts.conf"
        exit 1
    fi

    local current_agents
    current_agents=$(echo "$line" | cut -d'|' -f2)

    if ! echo "$current_agents" | grep -qw "$agent"; then
        echo "$agent is not enabled on $host"
        return
    fi

    local new_agents
    new_agents=$(echo "$current_agents" | tr ',' '\n' | grep -v "^${agent}$" | tr '\n' ',' | sed 's/,$//' | sed 's/^,//')

    local tmp_hosts
    tmp_hosts="${HOSTS_FILE}.tmp.$$"
    awk -F'|' -v host="$host" -v agents="$new_agents" '
        BEGIN { OFS = FS }
        tolower($1) == tolower(host) { $2 = agents }
        { print }
    ' "$HOSTS_FILE" > "$tmp_hosts"
    mv "$tmp_hosts" "$HOSTS_FILE"
    echo "Disabled $agent on $host"
    echo "Run 'telegram-agent-host stop $agent' to stop it"
}

start_agent() {
    local agent="$1"
    validate_agent "$agent"
    case "$agent" in
        opencode)
            load_opencode_continuity_policy
            if [ ! -d "$OPENCODE_PROJECT_ROOT" ]; then
                echo "OpenCode project root not found: $OPENCODE_PROJECT_ROOT" >&2
                return 1
            fi
            if [ ! -x "$OPENCODE_PATCH_APPLIER" ]; then
                echo "OpenCode Telegram patch applier not found: $OPENCODE_PATCH_APPLIER" >&2
                return 1
            fi
            if [ ! -x "$CORE_PROFILE_BIN/node" ]; then
                echo "Intended OpenCode Node runtime not found: $CORE_PROFILE_BIN/node" >&2
                return 1
            fi
            if ! env PATH="$AGENT_RUNTIME_PATH" "$OPENCODE_PATCH_APPLIER"; then
                echo "OpenCode Telegram package seam is not ready; refusing start" >&2
                return 1
            fi
            if [ -r "$OPENCODE_STATE_FILE" ]; then
                if check_opencode >/dev/null 2>&1; then
                    echo "opencode is already running"
                    return 0
                fi
                echo "Existing OpenCode owner state is not healthy; validating and stopping only its owned processes..."
                "$OPENCODE_OWNER_HELPER" stop --state "$OPENCODE_STATE_FILE" --project "$OPENCODE_PROJECT_ROOT" --host 127.0.0.1 --port "$OPENCODE_PORT" || true
            fi
            if command -v ss >/dev/null 2>&1 && ss -Hln "sport = :$OPENCODE_PORT" 2>/dev/null | grep -q .; then
                echo "Refusing OpenCode start: port $OPENCODE_PORT is already occupied by an unowned listener" >&2
                return 1
            fi
            echo "Starting opencode serve in $OPENCODE_PROJECT_ROOT..."
            (
                cd "$OPENCODE_PROJECT_ROOT"
                exec nohup env PATH="$AGENT_RUNTIME_PATH" opencode serve --hostname 127.0.0.1 --port "$OPENCODE_PORT"
            ) > "$STATE_DIR/opencode-serve.log" 2>&1 </dev/null &
            printf '%s\n' "$!" > "$OPENCODE_BACKEND_PID_FILE"
            sleep 2
            if [ ! -s "$OPENCODE_BACKEND_PID_FILE" ]; then
                echo "OpenCode backend did not publish an owned PID" >&2
                return 1
            fi
            echo "Starting opencode-telegram in $OPENCODE_PROJECT_ROOT..."
            if ! (umask 077; cd "$OPENCODE_PROJECT_ROOT" && env PATH="$AGENT_RUNTIME_PATH" NODE_OPTIONS="$OPENCODE_NODE_OPTIONS" "$OPENCODE_POLLER_BIN" start --daemon --mode installed > "$STATE_DIR/opencode-telegram.log" 2>&1 </dev/null); then
                backend_pid=$(cat "$OPENCODE_BACKEND_PID_FILE")
                kill -TERM "$backend_pid" 2>/dev/null || true
                rm -f "$OPENCODE_BACKEND_PID_FILE"
                echo "OpenCode Telegram daemon failed to start; rolled back owned backend" >&2
                return 1
            fi
            for _ in {1..15}; do
                [ -s "$OPENCODE_TELEGRAM_HOME/run/bot-service.json" ] && break
                sleep 1
            done
            write_opencode_state || {
                env PATH="$AGENT_RUNTIME_PATH" "$OPENCODE_POLLER_BIN" stop >/dev/null 2>&1 || true
                backend_pid=$(cat "$OPENCODE_BACKEND_PID_FILE")
                kill -TERM "$backend_pid" 2>/dev/null || true
                rm -f "$OPENCODE_BACKEND_PID_FILE" "$OPENCODE_POLLER_PID_FILE"
                echo "OpenCode backend/poller did not produce a complete owner state" >&2
                return 1
            }
            python3 -c 'import json,sys; print(json.load(open(sys.argv[1]))["pid"])' "$OPENCODE_TELEGRAM_HOME/run/bot-service.json" > "$OPENCODE_POLLER_PID_FILE"
            ;;
        ductor)
            if command -v ductor >/dev/null 2>&1 && [ -x "$DUCTOR_SUPERVISOR" ]; then
                if ductor_ready; then
                    echo "ductor is already running"
                elif ductor_running; then
                    echo "ductor supervisor is running; waiting for cold-start readiness..."
                    if ! wait_ductor_ready; then
                        echo "ductor supervisor remained degraded after ${DUCTOR_READY_TIMEOUT:-90}s" >&2
                        return 1
                    fi
                    echo "ductor started"
                else
                    echo "Starting ductor (supervised)..."
                    rm -f "$STATE_DIR/ductor-supervise.pid" "$STATE_DIR/ductor-child.pid"
                    nohup setsid env PATH="$AGENT_RUNTIME_PATH" DUCTOR_HOME="$DUCTOR_HOME_DIR" "$DUCTOR_SUPERVISOR" > "$STATE_DIR/ductor-supervise.log" 2>&1 </dev/null &
                    if ! wait_ductor_ready; then
                        echo "ductor failed supervised readiness" >&2
                        return 1
                    fi
                    echo "ductor started"
                fi
            else
                echo "ductor or its canonical supervisor is unavailable"
                return 1
            fi
            ;;
        claudecode)
            echo "claudecode Telegram runs inline via the PTY-supervised claude-auryn launcher."
            echo "Launch Claude with: claude-auryn --telegram"
            echo "Access control: ~/.claude/channels/telegram/access.json"
            ;;
        hermes)
            start_hermes
            ;;
        codex)
            local wrapper="${CODEX_HELMASTRA_WRAPPER:-$HOME/HelmCortex/FORGE/bin/codex-helmastra}"
            if [ ! -x "$wrapper" ]; then
                echo "codex-helmastra wrapper not found at $wrapper"
                return 1
            fi
            if codex_telegram_running; then
                echo "HelmAstra Telegram is already running"
            else
                echo "Starting HelmAstra Codex Telegram adapter..."
                if ! "$wrapper" --telegram \
                    >> "$STATE_DIR/codex-helmastra-telegram.log" 2>&1 </dev/null; then
                    echo "HelmAstra Telegram adapter failed readiness; inspect $STATE_DIR/codex-helmastra-telegram.log"
                    return 1
                fi
                if ! codex_telegram_running; then
                    echo "HelmAstra Telegram adapter reported ready but is not running"
                    return 1
                fi
            fi
            ;;
        deepseek-harness)
            mkdir -p "$STATE_DIR"
            deepseek_harness_validate_private_config || return 1
            deepseek_harness_validate_install || return 1
            if deepseek_harness_running; then
                echo "deepseek-harness already has an owned poller"
                return 1
            fi
            if [ -r "$DSH_TELEGRAM_PID_FILE" ]; then
                echo "DeepSeek Harness owner state is stale or invalid; run telegram-agent-host stop deepseek-harness first" >&2
                return 1
            fi
            local other_pid
            other_pid="$(deepseek_harness_find_unowned 2>/dev/null || true)"
            if [ -n "$other_pid" ]; then
                echo "Refusing DeepSeek Harness start: another dsh poller already uses profile $DSH_TELEGRAM_PROFILE (pid $other_pid)" >&2
                return 1
            fi
            deepseek_harness_preflight_model || return 1
            deepseek_harness_rotate_log
            printf '\n=== deepseek-harness launch %s ===\n' "$(date -u +%Y-%m-%dT%H:%M:%SZ)" >> "$DSH_TELEGRAM_LOG_FILE"
            echo "Starting DeepSeek Harness Telegram profile $DSH_TELEGRAM_PROFILE..."
            (
                cd "$DSH_TELEGRAM_WORKSPACE"
                exec nohup setsid env -u DEEPSEEK_API_KEY -u DEEPSEEK_API_KEY_FILE \
                    PATH="$AGENT_RUNTIME_PATH" \
                    NODE_OPTIONS="$DSH_TELEGRAM_NODE_OPTIONS" \
                    DSH_HOME="$DSH_HOME" \
                    DSH_TELEGRAM_PROFILE="$DSH_TELEGRAM_PROFILE" \
                    DSH_TELEGRAM_LOG_FILE="$DSH_TELEGRAM_LOG_FILE" \
                    TELEGRAM_BOT_TOKEN="${TELEGRAM_BOT_TOKEN:-}" \
                    TELEGRAM_BOT_TOKEN_FILE="${TELEGRAM_BOT_TOKEN_FILE:-}" \
                    NEURALWATT_API_KEY="$NEURALWATT_API_KEY" \
                    bash -c '
                        exec dsh --profile "$DSH_TELEGRAM_PROFILE" > >(
                            sed -u -E \
                                -e '\''s#bot[0-9]{8,}:[A-Za-z0-9_-]{30,}#bot[REDACTED]#g'\'' \
                                -e '\''s#chatId=-?[0-9]+#chatId=[REDACTED]#g'\'' \
                                -e '\''s#bar-sync\(-?[0-9]+\)#bar-sync([REDACTED])#g'\'' \
                                -e '\''s#([?&]token=)[A-Za-z0-9_-]+#\1[REDACTED]#g'\'' \
                                >> "$DSH_TELEGRAM_LOG_FILE"
                        ) 2>&1 </dev/null
                    '
            ) &
            printf '%s\n' "$!" > "$DSH_TELEGRAM_PID_FILE"
            sleep 2
            if ! deepseek_harness_running; then
                rm -f "$DSH_TELEGRAM_PID_FILE"
                echo "DeepSeek Harness Telegram failed to publish an owned poller; inspect $DSH_TELEGRAM_LOG_FILE" >&2
                return 1
            fi
            ;;
        pi-agent)
            start_pi_agent
            ;;
        *)
            echo "Unknown agent: $agent"
            exit 1
            ;;
    esac
    echo "$agent started"
}

stop_agent() {
    local agent="$1"
    validate_agent "$agent"
    case "$agent" in
        opencode)
            if [ -x "$OPENCODE_OWNER_HELPER" ]; then
                "$OPENCODE_OWNER_HELPER" stop \
                    --state "$OPENCODE_STATE_FILE" \
                    --project "$OPENCODE_PROJECT_ROOT" \
                    --host 127.0.0.1 --port "$OPENCODE_PORT"
            else
                echo "OpenCode owner helper unavailable; refusing unscoped stop" >&2
                return 1
            fi
            ;;
        ductor)
            stop_ductor_owned
            ;;
        claudecode)
            pkill -f "claude.*channels.*telegram" 2>/dev/null || true
            ;;
        hermes)
            stop_hermes
            ;;
        codex)
            local codex_pid codex_pgid
            if codex_telegram_running; then
                codex_pid=$(cat "$STATE_DIR/codex-helmastra-telegram.pid")
                codex_pgid=$(ps -o pgid= -p "$codex_pid" 2>/dev/null | tr -d ' ' || true)
                if [ "$codex_pgid" = "$codex_pid" ]; then
                    kill -TERM -- "-$codex_pgid" 2>/dev/null || true
                else
                    kill -TERM "$codex_pid" 2>/dev/null || true
                fi
                for _ in {1..20}; do
                    codex_telegram_running || break
                    sleep 0.25
                done
                if codex_telegram_running; then
                    echo "HelmAstra Telegram did not stop gracefully; forcing its verified process group" >&2
                    if [ "$codex_pgid" = "$codex_pid" ]; then
                        kill -KILL -- "-$codex_pgid" 2>/dev/null || true
                    else
                        kill -KILL "$codex_pid" 2>/dev/null || true
                    fi
                    for _ in {1..20}; do
                        codex_telegram_running || break
                        sleep 0.25
                    done
                fi
            fi
            if codex_telegram_running; then
                echo "HelmAstra Telegram failed to stop" >&2
                return 1
            fi
            ;;
        deepseek-harness)
            local dsh_pid dsh_pgid
            if deepseek_harness_running; then
                dsh_pid=$(cat "$DSH_TELEGRAM_PID_FILE")
                dsh_pgid=$(ps -o pgid= -p "$dsh_pid" 2>/dev/null | tr -d ' ' || true)
                if [ "$dsh_pgid" = "$dsh_pid" ]; then
                    kill -TERM -- "-$dsh_pgid" 2>/dev/null || true
                else
                    kill -TERM "$dsh_pid" 2>/dev/null || true
                fi
                for _ in {1..20}; do
                    deepseek_harness_running || break
                    sleep 0.25
                done
                if deepseek_harness_running; then
                    echo "DeepSeek Harness Telegram did not stop gracefully; forcing its verified process group" >&2
                    if [ "$dsh_pgid" = "$dsh_pid" ]; then
                        kill -KILL -- "-$dsh_pgid" 2>/dev/null || true
                    else
                        kill -KILL "$dsh_pid" 2>/dev/null || true
                    fi
                fi
            fi
            if deepseek_harness_running; then
                echo "DeepSeek Harness Telegram failed to stop" >&2
                return 1
            fi
            rm -f "$DSH_TELEGRAM_PID_FILE"
            ;;
        pi-agent)
            stop_pi_agent
            ;;
        *)
            echo "Unknown agent: $agent"
            exit 1
            ;;
    esac
    echo "$agent stopped"
}

start_all() {
    local host
    host=$(get_hostname)
    local agents
    agents=$(get_enabled_agents "$host")

    if [ -z "$agents" ]; then
        echo "No agents enabled for $host. Run 'telegram-agent-host enable <agent>' first."
        exit 1
    fi

    echo "Starting enabled agents for $host: $agents"
    local failed=0
    for agent in $agents; do
        if ! start_agent "$agent"; then
            echo "Failed to start enabled agent: $agent" >&2
            failed=1
        fi
    done
    return "$failed"
}

stop_all() {
    for agent in opencode ductor claudecode hermes codex deepseek-harness pi-agent; do
        stop_agent "$agent" 2>/dev/null || true
    done
    echo "All agents stopped"
}

switch_to_machine() {
    local target="$1"
    local current_host
    current_host=$(get_hostname)

    if [ "$current_host" = "$target" ]; then
        echo "Already on $target"
        return
    fi

    local target_agents
    target_agents=$(get_enabled_agents "$target")

    if [ -z "$target_agents" ]; then
        echo "No agents configured for $target"
        exit 1
    fi

    local target_ssh
    target_ssh=$(grep -i "^${target}|" "$HOSTS_FILE" 2>/dev/null | cut -d'|' -f3)

    echo "Switching from $current_host to $target"

    echo "Stopping all agents on $current_host..."
    stop_all

    echo "Stopping agents on $target before restart..."
    if [ -n "$target_ssh" ]; then
        ssh "$target_ssh" "systemctl --user stop hermes-gateway.service 2>/dev/null || pkill -x hermes 2>/dev/null || true; pkill -f 'ductor' 2>/dev/null || true" 2>/dev/null || true
        sleep 1
    fi

    echo "Starting agents on $target via SSH..."
    if [ -n "$target_ssh" ]; then
        ssh "$target_ssh" "\$HOME/.local/bin/telegram-agent-remote-start $target_agents"
        echo "Switched to $target"
    else
        echo "No SSH config for $target. Manually start on target machine:"
        echo " ssh $target"
        echo " telegram-agent-host start"
    fi
    echo ""
    echo "Enabled on $target: $target_agents"
}

bring_here() {
    local current_host
    current_host=$(get_hostname)
    local agents
    agents=$(get_enabled_agents "$current_host")

    if [ -z "$agents" ]; then
        echo "No agents configured for $current_host"
        exit 1
    fi

    echo "Bringing agents to $current_host..."

    for host_line in $(grep -v '^#' "$HOSTS_FILE" | grep -v '^$'); do
        local other_host
        other_host=$(echo "$host_line" | cut -d'|' -f1)
        if [ "$other_host" != "$current_host" ]; then
            local other_ssh
            other_ssh=$(echo "$host_line" | cut -d'|' -f3)
            if [ -n "$other_ssh" ]; then
                echo "Stopping agents on $other_host..."
                ssh "$other_ssh" "systemctl --user stop hermes-gateway.service 2>/dev/null || pkill -x hermes 2>/dev/null || true; pkill -f 'ductor' 2>/dev/null || true" 2>/dev/null || true
            fi
        fi
    done

    sleep 1
    echo "Starting agents locally..."
    start_all
}

* Remote Start Helper

This script runs on the target machine via SSH. It kills existing processes,
starts new ones, waits for confirmation, then exits cleanly.

#+BEGIN_SRC bash :tangle all/.local/bin/telegram-agent-remote-start :shebang "#!/usr/bin/env bash"
# ~/DotCortex/all/.local/bin/telegram-agent-remote-start
# Run on target machine via SSH to start agents.
# Usage: telegram-agent-remote-start <agent> [agent ...]

set -euo pipefail

STATE_DIR="${XDG_STATE_HOME:-$HOME/.local/state}/telegram-agents"
KNOWN_AGENTS="ductor hermes"
DUCTOR_HOME_DIR="${DUCTOR_HOME_DIR:-$HOME/HelmCortex/FORGE/brain/ductor}"
mkdir -p "$STATE_DIR"

validate_agent() {
    local agent="${1:-}"
    case " $KNOWN_AGENTS " in
        *" $agent "*) ;;
        *)
            echo "Agent $agent not yet supported for remote start"
            return 1
            ;;
    esac
}

pid_file_has_command() {
    local pid_file="$1" expected="$2" pid argument
    [ -r "$pid_file" ] || return 1
    IFS= read -r pid < "$pid_file" || return 1
    case "$pid" in ''|*[!0-9]*) return 1 ;; esac
    [ -r "/proc/$pid/cmdline" ] || return 1
    while IFS= read -r -d '' argument; do
        [ "${argument##*/}" = "$expected" ] && return 0
    done < "/proc/$pid/cmdline"
    return 1
}

ductor_running() {
    pid_file_has_command "$STATE_DIR/ductor-supervise.pid" ductor-supervise
}

ductor_ready() {
    ductor_running && pid_file_has_command "$STATE_DIR/ductor-child.pid" ductor
}

stop_ductor_owned() {
    local supervisor_pid child_pid
    if ductor_running; then
        IFS= read -r supervisor_pid < "$STATE_DIR/ductor-supervise.pid"
        kill -TERM "$supervisor_pid"
        for _ in {1..15}; do
            [ ! -r "/proc/$supervisor_pid/cmdline" ] && break
            sleep 1
        done
        [ ! -r "/proc/$supervisor_pid/cmdline" ] || return 1
    elif pid_file_has_command "$STATE_DIR/ductor-child.pid" ductor; then
        IFS= read -r child_pid < "$STATE_DIR/ductor-child.pid"
        kill -TERM "$child_pid"
    fi
    rm -f "$STATE_DIR/ductor-supervise.pid" "$STATE_DIR/ductor-child.pid"
}

hermes_service_unit() {
    printf '%s\n' "${XDG_CONFIG_HOME:-$HOME/.config}/systemd/user/hermes-gateway.service"
}

hermes_service_installed() {
    command -v systemctl >/dev/null 2>&1 && [ -f "$(hermes_service_unit)" ]
}

hermes_running() {
    if hermes_service_installed && systemctl --user is-active --quiet hermes-gateway.service; then
        return 0
    fi
    pgrep -x hermes >/dev/null 2>&1
}

for agent in "$@"; do
    validate_agent "$agent" || continue
    case "$agent" in
    ductor)
        echo "Stopping existing ductor process..."
        if ! stop_ductor_owned; then
            echo "ductor: FAILED TO STOP OWNED PROCESS"
            continue
        fi
        rm -f "$STATE_DIR/ductor-supervise.pid" "$STATE_DIR/ductor-child.pid"
        echo "Starting ductor (supervised)..."
        nohup setsid env DUCTOR_HOME="$DUCTOR_HOME_DIR" ductor-supervise > "$STATE_DIR/ductor-supervise.log" 2>&1 </dev/null &
        for _ in {1..15}; do
            ductor_ready && break
            sleep 1
        done
        if ductor_ready; then
            echo "ductor: STARTED OK"
        else
            echo "ductor: FAILED TO START"
        fi
        ;;
    hermes)
        if ! command -v hermes >/dev/null 2>&1; then
            echo "hermes not found in PATH"
            continue
        fi
        if hermes_service_installed; then
            echo "Restarting supervised Hermes gateway..."
            systemctl --user restart hermes-gateway.service
            systemctl --user enable hermes-gateway.service >/dev/null
        elif command -v systemctl >/dev/null 2>&1 && systemctl --user show-environment >/dev/null 2>&1; then
            echo "Installing supervised Hermes gateway service..."
            hermes gateway install --start-now --start-on-login
        else
            echo "No user service manager available; restarting Hermes gateway with nohup..."
            pkill -x hermes 2>/dev/null || true
            sleep 1
            nohup hermes gateway run > "$STATE_DIR/hermes.log" 2>&1 </dev/null &
            disown
        fi
        sleep 3
        if hermes_running; then
            echo "hermes gateway: STARTED OK"
        else
            echo "hermes gateway: FAILED TO START"
        fi
        ;;
    *)
        echo "Agent $agent not yet supported for remote start"
        ;;
    esac
done
