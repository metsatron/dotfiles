#+TITLE: XFCE Desktop Menu — global-menu fallback + maximized caption
#+AUTHOR: Mètsàtron
#+PROPERTY: header-args :mkdirp yes

This is the XFCE reproduction of the SonicDE (KDE Plasma 6) top-panel shape owned by =plasma.org=: a macOS-style global menu with a *fallback menu bar* that appears only when the focused window exports no application menu, window *title + control buttons* carried in the panel, and *titleless maximized windows* so the panel carries the chrome. On XFCE this is a native build, not a QML port — the appmenu bridge already lives in =x11.org=; this file adds the fallback bar, the panel placement, and the titleless-maximize toggle.

Design lives in MetaCortex =Projects/XFCE-Desktop-Menu.md= (research R1/R2/R3 resolved). Component map:

| SonicDE / KDE                        | XFCE reproduction                                   |
|--------------------------------------+-----------------------------------------------------|
| Global Menu applet                   | =xfce4-appmenu-plugin= (=appmenu=), placed in panel |
| =org.dotcortex.desktopmenu= plasmoid | native =xfce-desktop-menubar= libxfce4panel plugin  |
| =org.kde.windowtitle=                | =windowck-plugin= (Window Header - Title)           |
| application-title-bar buttons        | =wckbuttons= (Window Buttons)                       |
| =kwin-borderless-maximized=          | =xfwm-titleless-maximized= (two xfwm4 xfconf keys)  |

*Compiled-artifact pattern (new for DotCortex).* Unlike the interpreted QML plasmoid, the fallback bar is a compiled =libxfce4panel-2.0= plugin. Source is stowed to =~/.local/src/xfce-desktop-menubar/=; a loom verb builds it with Meson and installs it. *Scope:* xfce4-panel 4.20 scans =~/.local/share= for plugin =.desktop= files but loads the module =.so= only from the *system* panel libdir — a user-scope =.so= in =~/.local/lib= is silently ignored (verified live on Devuan / xfce4-panel 4.20.4). So the build helper defaults to =SCOPE=system= (one =sudo= install to =/usr/lib/<multiarch>/xfce4/panel/plugins/= + =/usr/share/xfce4/panel/plugins/=); =SCOPE=user= is kept only for any future panel that scans user lib dirs. Debian/Devuan ship no usable Vala binding for =libxfce4panel-2.0= (and =vapigen= cannot parse the shipped GIR), so a small hand-written =libxfce4panel-2.0.vapi= is shipped alongside the source.

* Native fallback menu bar — meson.build
Out-of-tree Meson build. The plugin =.so= gets a =lib= prefix so the panel resolves =X-XFCE-Module=xfce-desktop-menubar= to =libxfce-desktop-menubar.so=. Debian/Devuan ship no =.vapi= for =libxfce4panel-2.0=, and =vapigen= cannot parse the shipped GIR (its =remote-event= signal reads as an incompatible override of the =PanelPluginProvider= interface method — a hard parse error =skip= metadata cannot rescue). So we ship a small hand-written =libxfce4panel-2.0.vapi= (next block) covering only the tiny =PanelPlugin= surface the plugin uses, and point valac at it with =--vapidir=.

* Native fallback menu bar — Vala source
A =GtkMenuBar= rendered in the panel process. Structure mirrors the plasmoid (=brand | File | Edit | Go | Recent | Windows | Help=) with XFCE/Thunar-native actions and =zenity= dialogs. The *interlock* (R3) hides the bar whenever the active window already exports a global menu — resolved on each =active-window-changed= via the AppMenu Registrar first, then GTK GMenuModel window props, with one short delayed recheck to catch apps that export just after focus.

#+BEGIN_SRC vala :tangle linux/.local/src/xfce-desktop-menubar/src/menubar-plugin.vala :comments no
/*
 * xfce-desktop-menubar — DotCortex native libxfce4panel plugin.
 *
 * Fallback global-menu bar for XFCE. Renders File/Edit/Go/Recent/Windows/Help
 * and hides itself whenever the active window already exports an application
 * menu, interlocking with xfce4-appmenu-plugin exactly as
 * org.dotcortex.desktopmenu interlocks with the KDE Global Menu on SonicDE.
 *
 * Tangled from xfce-desktopmenu.org — never edit under the overlay.
 */

namespace DesktopMenubar {

    public class Plugin : Xfce.PanelPlugin {

        Gtk.MenuBar menubar;
        unowned Wnck.Screen screen;
        string brand;
        uint recheck_id = 0;

        construct {
            brand = load_brand ();

            menubar = new Gtk.MenuBar ();
            menubar.set_pack_direction (Gtk.PackDirection.LTR);

            build_menus ();
            apply_style ();

            add (menubar);
            menubar.show_all ();

            orientation_changed.connect ((o) => {
                menubar.set_pack_direction (o == Gtk.Orientation.HORIZONTAL
                    ? Gtk.PackDirection.LTR : Gtk.PackDirection.TTB);
            });

            screen = Wnck.Screen.get_default ();
            screen.force_update ();
            screen.active_window_changed.connect (on_active_window_changed);

            update_visibility ();
        }

        /* ---- brand string (configurable, neutral default — never "SonicDE") ---- */
        string load_brand () {
            var path = Path.build_filename (Environment.get_user_config_dir (),
                                            "xfce-desktop-menubar", "brand");
            if (FileUtils.test (path, FileTest.EXISTS)) {
                try {
                    string c;
                    FileUtils.get_contents (path, out c);
                    c = c.strip ();
                    if (c != "")
                        return c;
                } catch (Error e) { /* fall through */ }
            }
            return Environment.get_host_name ();
        }

        // Let the panel background show through, and keep only the brand bold
        // (the brand label carries its own Pango bold markup, which wins over
        // this normal-weight rule). Scoped to this plugin's own wrapper process.
        void apply_style () {
            var css = new Gtk.CssProvider ();
            try {
                css.load_from_data (
                    "menubar, menubar > menuitem { background-color: transparent; background-image: none; box-shadow: none; border-width: 0; }\n" +
                    "menubar > menuitem > label { font-weight: normal; }");
            } catch (Error e) {
                warning ("xfce-desktop-menubar: css load failed: %s", e.message);
                return;
            }
            Gtk.StyleContext.add_provider_for_screen (
                Gdk.Screen.get_default (), css,
                Gtk.STYLE_PROVIDER_PRIORITY_APPLICATION);
        }

        void launch (string cmdline) {
            try {
                Process.spawn_command_line_async (cmdline);
            } catch (Error e) {
                warning ("xfce-desktop-menubar: spawn failed: %s", e.message);
            }
        }

        void add_action (Gtk.Menu menu, string label, owned string cmd) {
            var it = new Gtk.MenuItem.with_label (label);
            it.activate.connect (() => launch (cmd));
            menu.append (it);
        }

        void add_sep (Gtk.Menu menu) {
            menu.append (new Gtk.SeparatorMenuItem ());
        }

        Gtk.MenuItem top_item (string label, Gtk.Menu submenu) {
            var it = new Gtk.MenuItem.with_label (label);
            it.set_submenu (submenu);
            return it;
        }

        /* ------------------------------ menus ------------------------------ */
        void build_menus () {
            // Brand (Apple-style) menu.
            var brand_menu = new Gtk.Menu ();
            add_action (brand_menu, "About This Computer",
                "sh -c " + Shell.quote ("zenity --info --no-wrap --title='About This Computer' --text=\"$(. /etc/os-release 2>/dev/null; echo \"$PRETTY_NAME\"; uname -sr; echo \"Host: $(uname -n)\"; echo \"Memory: $(free -h | awk '/^Mem:/{print $2}')\")\""));
            add_action (brand_menu, "Settings Manager…", "xfce4-settings-manager");
            add_sep (brand_menu);
            add_action (brand_menu, "Lock Screen", "xflock4");
            add_action (brand_menu, "Log Out…", "xfce4-session-logout");
            var brand_item = new Gtk.MenuItem ();
            var brand_lbl = new Gtk.Label (null);
            brand_lbl.set_markup ("<b>" + Markup.escape_text (brand) + "</b>");
            brand_item.add (brand_lbl);
            brand_item.set_submenu (brand_menu);

            // File.
            var file_menu = new Gtk.Menu ();
            add_action (file_menu, "New File Manager Window", "thunar");
            add_action (file_menu, "New Folder on Desktop…",
                "sh -c " + Shell.quote ("d=\"$(xdg-user-dir DESKTOP 2>/dev/null || echo \"$HOME/Desktop\")\"; n=$(zenity --entry --title='New Folder' --text='Folder name:' --entry-text='New Folder') && [ -n \"$n\" ] && mkdir -p \"$d/$n\""));
            add_action (file_menu, "Open Desktop Folder",
                "sh -c " + Shell.quote ("xdg-open \"$(xdg-user-dir DESKTOP 2>/dev/null || echo \"$HOME/Desktop\")\""));
            add_sep (file_menu);
            add_action (file_menu, "Open Terminal Here", "xfce4-terminal");
            add_sep (file_menu);
            add_action (file_menu, "Open Trash", "thunar trash:///");

            // Edit (settings-oriented, XFCE-native).
            var edit_menu = new Gtk.Menu ();
            add_action (edit_menu, "Desktop & Wallpaper", "xfdesktop-settings");
            add_action (edit_menu, "Appearance", "xfce4-appearance-settings");
            add_action (edit_menu, "Display", "xfce4-display-settings");
            add_sep (edit_menu);
            add_action (edit_menu, "Panel Preferences", "xfce4-panel --preferences");

            // Go (dynamic: XDG dirs + gtk bookmarks).
            var go_menu = new Gtk.Menu ();
            go_menu.show.connect (() => populate_go (go_menu));

            // Recent (self-populating).
            var recent = new Gtk.RecentChooserMenu ();
            recent.set_local_only (false);
            recent.set_show_tips (true);
            recent.set_sort_type (Gtk.RecentSortType.MRU);
            recent.set_limit (15);
            recent.item_activated.connect (() => {
                var uri = recent.get_current_uri ();
                if (uri != null)
                    launch ("xdg-open " + Shell.quote (uri));
            });

            // Windows (dynamic: Wnck task list).
            var windows_menu = new Gtk.Menu ();
            windows_menu.show.connect (() => populate_windows (windows_menu));

            // Help.
            var help_menu = new Gtk.Menu ();
            add_action (help_menu, "About This System",
                "sh -c " + Shell.quote ("zenity --info --no-wrap --title='About This System' --text=\"$(. /etc/os-release 2>/dev/null; echo \"$PRETTY_NAME\"; echo \"$HOME_URL\")\""));
            add_sep (help_menu);
            add_action (help_menu, "XFCE Documentation", "xdg-open https://docs.xfce.org/");
            add_action (help_menu, "About Desktop Menubar",
                "zenity --info --no-wrap --title=Desktop Menubar --text=" + Shell.quote ("DotCortex XFCE Desktop Menubar 0.1.0 — global-menu fallback for XFCE. Tangled from xfce-desktopmenu.org."));

            menubar.append (brand_item);
            menubar.append (top_item ("File", file_menu));
            menubar.append (top_item ("Edit", edit_menu));
            menubar.append (top_item ("Go", go_menu));
            menubar.append (top_item ("Recent", recent));
            menubar.append (top_item ("Windows", windows_menu));
            menubar.append (top_item ("Help", help_menu));
        }

        void populate_go (Gtk.Menu menu) {
            foreach (var c in menu.get_children ())
                menu.remove (c);

            add_go_dir (menu, "Home", Environment.get_home_dir ());
            add_go_special (menu, "Desktop", UserDirectory.DESKTOP);
            add_go_special (menu, "Documents", UserDirectory.DOCUMENTS);
            add_go_special (menu, "Downloads", UserDirectory.DOWNLOAD);
            add_go_special (menu, "Music", UserDirectory.MUSIC);
            add_go_special (menu, "Pictures", UserDirectory.PICTURES);
            add_go_special (menu, "Videos", UserDirectory.VIDEOS);

            var bm = Path.build_filename (Environment.get_user_config_dir (), "gtk-3.0", "bookmarks");
            if (FileUtils.test (bm, FileTest.EXISTS)) {
                try {
                    string content;
                    FileUtils.get_contents (bm, out content);
                    bool sep_added = false;
                    foreach (var raw in content.split ("\n")) {
                        var line = raw.strip ();
                        if (line == "")
                            continue;
                        var parts = line.split (" ", 2);
                        var uri = parts[0];
                        string label = parts.length > 1
                            ? parts[1]
                            : Path.get_basename (uri.replace ("file://", ""));
                        if (!sep_added) { add_sep (menu); sep_added = true; }
                        add_go_uri (menu, label, uri);
                    }
                } catch (Error e) { /* ignore */ }
            }

            add_sep (menu);
            add_action (menu, "Go to Folder…",
                "sh -c " + Shell.quote ("d=$(zenity --file-selection --directory --title='Go to Folder') && [ -n \"$d\" ] && thunar \"$d\""));
        }

        void add_go_dir (Gtk.Menu menu, string label, string? path) {
            if (path == null || !FileUtils.test (path, FileTest.IS_DIR))
                return;
            add_go_uri (menu, label, Filename.to_uri (path, null));
        }

        void add_go_special (Gtk.Menu menu, string label, UserDirectory dir) {
            add_go_dir (menu, label, Environment.get_user_special_dir (dir));
        }

        void add_go_uri (Gtk.Menu menu, string label, string uri) {
            var it = new Gtk.MenuItem.with_label (label);
            it.activate.connect (() => launch ("xdg-open " + Shell.quote (uri)));
            menu.append (it);
            it.show ();
        }

        void populate_windows (Gtk.Menu menu) {
            foreach (var c in menu.get_children ())
                menu.remove (c);
            screen.force_update ();
            bool any = false;
            unowned Wnck.Window active = screen.get_active_window ();
            foreach (unowned Wnck.Window w in screen.get_windows ()) {
                if (w.is_skip_tasklist ())
                    continue;
                any = true;
                var it = new Gtk.CheckMenuItem.with_label (w.get_name ());
                it.draw_as_radio = true;
                it.set_active (w == active);
                unowned Wnck.Window win = w;
                it.activate.connect (() => win.activate (Gtk.get_current_event_time ()));
                menu.append (it);
                it.show ();
            }
            if (!any) {
                var none = new Gtk.MenuItem.with_label ("(no windows)");
                none.sensitive = false;
                menu.append (none);
                none.show ();
            }
        }

        /* ------------------------- interlock (R3) ------------------------- */
        void on_active_window_changed (Wnck.Window? previous) {
            update_visibility ();
            if (recheck_id != 0)
                Source.remove (recheck_id);
            recheck_id = Timeout.add (180, () => {
                recheck_id = 0;
                update_visibility ();
                return Source.REMOVE;
            });
        }

        void update_visibility () {
            unowned Wnck.Window? win = screen.get_active_window ();
            bool available = (win != null) && global_menu_available (win.get_xid ());
            menubar.set_visible (!available);
        }

        bool global_menu_available (ulong xid) {
            if (registrar_has_menu (xid))
                return true;
            if (has_prop (xid, "_GTK_UNIQUE_BUS_NAME")
                && (has_prop (xid, "_GTK_MENUBAR_OBJECT_PATH")
                    || has_prop (xid, "_GTK_APP_MENU_OBJECT_PATH")))
                return true;
            return false;
        }

        bool registrar_has_menu (ulong xid) {
            try {
                var conn = Bus.get_sync (BusType.SESSION);
                var reply = conn.call_sync (
                    "com.canonical.AppMenu.Registrar",
                    "/com/canonical/AppMenu/Registrar",
                    "com.canonical.AppMenu.Registrar",
                    "GetMenuForWindow",
                    new Variant ("(u)", (uint32) xid),
                    new VariantType ("(so)"),
                    DBusCallFlags.NO_AUTO_START, 400, null);
                string service;
                string object_path;
                reply.get ("(so)", out service, out object_path);
                return service != "" && object_path != "" && object_path != "/";
            } catch (Error e) {
                return false;
            }
        }

        // Event-driven read (not a poll): one xprop per active-window transition.
        bool has_prop (ulong xid, string name) {
            string outp;
            int status;
            try {
                Process.spawn_command_line_sync (
                    "xprop -id %lu %s".printf (xid, name), out outp, null, out status);
            } catch (Error e) {
                return false;
            }
            return status == 0 && !outp.contains ("not found") && !outp.contains ("no such");
        }
    }

    // The panel dlopens the .so and calls exactly "xfce_panel_module_init";
    // force the C name so the namespace prefix is not applied.
    [ModuleInit]
    [CCode (cname = "xfce_panel_module_init")]
    public Type xfce_panel_module_init (GLib.TypeModule module) {
        return typeof (DesktopMenubar.Plugin);
    }
}

* Build + install helper
Out-of-tree Meson build, installed user-scope by default (no sudo). =SCOPE=system= installs to the panel's own multiarch plugin dir with sudo, as a fallback if a given xfce4-panel build does not scan =~/.local/lib=. =FORCE=1= wipes the build dir first.

#+BEGIN_SRC bash :tangle linux/.local/bin/xfce-desktop-menubar-build :shebang "#!/usr/bin/env bash" :tangle-mode (identity #o755)
set -euo pipefail

SRC="${SRC_DIR:-$HOME/.local/src/xfce-desktop-menubar}"
# Build OUT of the source tree — the source is stow-managed, so an in-tree
# build dir would write artifacts back into the DotCortex overlay.
BUILD="${BUILD_DIR:-${XDG_CACHE_HOME:-$HOME/.cache}/xfce-desktop-menubar/build}"
# xfce4-panel 4.20 scans ~/.local/share for plugin .desktop files but loads the
# module .so ONLY from the system panel libdir — a user-scope .so is silently
# ignored (verified on Devuan/xfce4-panel 4.20.4). So the default is 'system'
# (one sudo install). SCOPE=user remains for any future panel that scans it.
SCOPE="${SCOPE:-system}"

[ -f "$SRC/meson.build" ] || { echo "source not stowed at $SRC (run loom stow first)" >&2; exit 1; }
command -v meson >/dev/null 2>&1 || { echo "meson missing — install build deps (nala:apply)" >&2; exit 1; }
command -v valac >/dev/null 2>&1 || { echo "valac missing — install build deps (nala:apply)" >&2; exit 1; }

case "$SCOPE" in
  user)
    PREFIX="$HOME/.local"; LIBDIR="lib"; SUDO=()
    ;;
  system)
    PREFIX="/usr"
    LIBDIR="$(pkg-config --variable=libdir libxfce4panel-2.0)"
    SUDO=(sudo)
    ;;
  *)
    echo "SCOPE must be 'user' or 'system'" >&2; exit 1
    ;;
esac

[ "${FORCE:-0}" = "1" ] && rm -rf "$BUILD"
if [ -d "$BUILD" ]; then
  meson setup --reconfigure "$BUILD" "$SRC" --prefix="$PREFIX" --libdir="$LIBDIR"
else
  meson setup "$BUILD" "$SRC" --prefix="$PREFIX" --libdir="$LIBDIR"
fi
meson compile -C "$BUILD"
"${SUDO[@]}" meson install -C "$BUILD"

case "$LIBDIR" in /*) PLUGROOT="$LIBDIR" ;; *) PLUGROOT="$PREFIX/$LIBDIR" ;; esac
echo "installed xfce-desktop-menubar ($SCOPE) -> $PLUGROOT/xfce4/panel/plugins/libxfce-desktop-menubar.so"
echo "restart the panel to load it:  xfce4-panel -r"
#+END_SRC

* Panel placement helper (additive, idempotent)
Adds the four plugins (=appmenu=, =windowck-plugin=, =wckbuttons=, =xfce-desktop-menubar=) to a top panel via =xfconf-query=, matching how =xfce-appmenu-configure= is additive. It never rewrites =xfce4-panel.xml= wholesale: it backs the channel XML up, skips any plugin already present, allocates fresh plugin ids, and appends to the chosen panel's =plugin-ids=. Requires a live XFCE session (xfconf daemon). =--dry-run= prints the plan only; =PANEL=N= targets a specific panel (default: the panel already holding =appmenu=, else the lowest-numbered panel).

#+BEGIN_SRC bash :tangle linux/.local/bin/xfce-desktopmenu-configure :shebang "#!/usr/bin/env bash" :tangle-mode (identity #o755)
set -euo pipefail

CH=xfce4-panel
DRY=0
[ "${1:-}" = "--dry-run" ] && { DRY=1; shift; }

# Plugins to ensure, in panel order (name = .desktop stem = xfconf plugin value).
# windowck-plugin (the standalone window-title applet) is intentionally NOT here
# — the appmenu/menubar already carry identity, and the title is redundant beside
# them. Add "windowck-plugin" to WANT (or WANT_EXTRA) if you want it back.
WANT=(appmenu wckbuttons xfce-desktop-menubar)
[ -n "${WANT_EXTRA:-}" ] && WANT+=($WANT_EXTRA)

# Bold, always-visible caption-button theme for windowck (see the caption-button
# theme section in xfce-desktopmenu.org). Overridable with WCK_THEME=…; set it to
# the empty string to leave the windowck rc untouched.
WCK_THEME="${WCK_THEME-BigSur-Bold-Dark}"

command -v xfconf-query >/dev/null 2>&1 || { echo "xfconf-query not found" >&2; exit 1; }
xfconf-query -c "$CH" -l >/dev/null 2>&1 || {
  echo "no xfce4-panel xfconf channel (run inside a live XFCE session)" >&2; exit 1; }

backup() {
  local xml="$HOME/.config/xfce4/xfconf/xfce-perchannel-xml/xfce4-panel.xml"
  [ -f "$xml" ] || return 0
  cp "$xml" "$xml.backup-$(date +%Y%m%d-%H%M%S)"
  echo "backed up $xml"
}

# All currently-configured plugin names.
existing_names() {
  xfconf-query -c "$CH" -l 2>/dev/null | grep -E '^/plugins/plugin-[0-9]+$' \
    | while read -r p; do xfconf-query -c "$CH" -p "$p" 2>/dev/null; done
}

plugin_present() { existing_names | grep -qx "$1"; }

next_id() {
  local max=0 n
  for p in $(xfconf-query -c "$CH" -l 2>/dev/null | grep -oE '/plugins/plugin-[0-9]+' | sort -u); do
    n=${p##*plugin-}
    [ "$n" -gt "$max" ] && max="$n"
  done
  echo $((max + 1))
}

list_panels() {
  xfconf-query -c "$CH" -l 2>/dev/null | grep -oE '/panels/panel-[0-9]+' \
    | sort -u | sed 's#.*panel-##' | sort -n
}

panel_ids() {
  xfconf-query -c "$CH" -p "/panels/panel-$1/plugin-ids" 2>/dev/null \
    | grep -E '^[0-9]+$'
}

target_panel() {
  [ -n "${PANEL:-}" ] && { echo "$PANEL"; return; }
  # Prefer the panel already holding appmenu.
  local p appid
  for p in $(list_panels); do
    for appid in $(panel_ids "$p"); do
      [ "$(xfconf-query -c "$CH" -p "/plugins/plugin-$appid" 2>/dev/null)" = appmenu ] \
        && { echo "$p"; return; }
    done
  done
  list_panels | head -1
}

# Recover the live session bus from the running panel — a detached tmux/ssh
# shell may carry a stale DBUS_SESSION_BUS_ADDRESS.
panel_dbus() {
  local pid; pid=$(pgrep -x xfce4-panel | head -1 || true)
  [ -n "$pid" ] && grep -z DBUS_SESSION_BUS_ADDRESS "/proc/$pid/environ" 2>/dev/null | tr '\0' '\n'
}

# Update-or-append a key in an xfce_rc file.
set_rc_key() {
  local file="$1" key="$2" val="$3"
  if grep -q "^${key}=" "$file" 2>/dev/null; then
    sed -i "s|^${key}=.*|${key}=${val}|" "$file"
  else
    printf '%s=%s\n' "$key" "$val" >> "$file"
  fi
}

# Pin the windowck caption-button theme. windowck re-saves its in-memory config
# on panel teardown, so editing the rc under a live panel gets clobbered by the
# next restart — the only reliable path is quit → write rc → relaunch. The rc is
# created only once the panel has instantiated the wckbuttons plugin, so this
# runs AFTER the first restart below.
apply_wck_theme() {
  local theme="$1"
  [ -n "$theme" ] || { echo "WCK_THEME empty — leaving windowck rc untouched"; return 0; }
  # libwckbuttons scans /usr/share/themes ONLY (confirmed against the .so strings,
  # 2026-07-10) — a theme living solely under ~/.themes is invisible to the plugin,
  # which then silently falls back AND REWRITES its rc to the xfwm4 theme name.
  # So system-side visibility is mandatory: plant a symlink into the home theme.
  if [ ! -e "/usr/share/themes/$theme" ]; then
    local src=""
    [ -d "$HOME/.themes/$theme" ] && src="$HOME/.themes/$theme"
    [ -z "$src" ] && [ -d "$HOME/.local/share/themes/$theme" ] && src="$HOME/.local/share/themes/$theme"
    if [ -z "$src" ]; then
      echo "warn: windowck theme '$theme' not found anywhere (run loom stow first) — skipping" >&2
      return 0
    fi
    src=$(readlink -f "$src")
    if sudo -n ln -sfn "$src" "/usr/share/themes/$theme" 2>/dev/null; then
      echo "planted /usr/share/themes/$theme -> $src (plugin only scans system themes)"
    else
      echo "warn: cannot plant /usr/share/themes/$theme (sudo -n unavailable) — plugin will NOT see '$theme'; run: sudo ln -sfn '$src' '/usr/share/themes/$theme'" >&2
      return 0
    fi
  fi
  local rc="" i
  for i in $(seq 1 15); do
    rc=$(ls "$HOME"/.config/xfce4/panel/wckbuttons-*.rc 2>/dev/null | head -1 || true)
    [ -n "$rc" ] && break
    sleep 0.2
  done
  [ -n "$rc" ] || { echo "warn: no wckbuttons rc yet — is wckbuttons on the panel? skipping" >&2; return 0; }

  local dbus; dbus=$(panel_dbus)
  [ -n "$dbus" ] && export "$dbus"
  xfce4-panel -q >/dev/null 2>&1 || true
  for i in $(seq 1 20); do pgrep -x xfce4-panel >/dev/null || break; sleep 0.2; done
  for rc in "$HOME"/.config/xfce4/panel/wckbuttons-*.rc; do
    [ -f "$rc" ] || continue
    set_rc_key "$rc" sync_wm_theme false
    set_rc_key "$rc" theme "$theme"
    echo "wck theme -> $theme  ($rc)"
  done
  setsid xfce4-panel >/dev/null 2>&1 < /dev/null &
  disown 2>/dev/null || true
  echo "panel relaunched with the '$theme' caption buttons"
}

P="$(target_panel)"
[ -n "$P" ] || { echo "no panel found" >&2; exit 1; }
echo "target panel: panel-$P"

[ "$DRY" = "1" ] || backup

base="$(next_id)"
offset=0
for name in "${WANT[@]}"; do
  if plugin_present "$name"; then
    echo "present : $name"
    continue
  fi
  id=$((base + offset))
  offset=$((offset + 1))
  if [ "$DRY" = "1" ]; then
    echo "would add: $name  (plugin-$id -> panel-$P)"
    continue
  fi
  xfconf-query -c "$CH" -p "/plugins/plugin-$id" -n -t string -s "$name"
  # Rebuild the panel's plugin-ids array with the new id appended.
  args=()
  for v in $(panel_ids "$P"); do args+=(-t int -s "$v"); done
  args+=(-t int -s "$id")
  xfconf-query -c "$CH" -p "/panels/panel-$P/plugin-ids" "${args[@]}"
  echo "added   : $name  (plugin-$id -> panel-$P)"
done

if [ "$DRY" = "1" ]; then
  [ -n "$WCK_THEME" ] && echo "would set windowck theme -> $WCK_THEME (sync_wm_theme=false)"
  exit 0
fi
echo "restarting panel to instantiate plugins…"
xfce4-panel -r >/dev/null 2>&1 || { echo "run 'xfce4-panel -r' to apply"; exit 0; }

# Pin the bold caption-button theme once the panel has created the wckbuttons rc.
apply_wck_theme "$WCK_THEME"

* Caption button theme (windowck bold-glyph set)
=wckbuttons= renders the maximized window's min/max/close buttons in the panel, either syncing the xfwm4 theme (=sync_wm_theme=true=) or loading a standalone windowck theme (=sync_wm_theme=false=, =theme==). The macOS =BigSur-Dark= buttons are near-black filled circles — invisible on a dark panel — and the shipped =Windowck-dark= set only reveals its glyphs on hover. So we ship our own: *bold, always-visible white =✕ ─ ☐= glyphs* that turn red (close) / brighten (min·max) on hover and dim to gray when the window is unfocused. The =xfce-desktopmenu-configure= helper pins them (=sync_wm_theme=false=, =theme=BigSur-Bold-Dark=), overridable via =WCK_THEME=.

The deployed asset is *committed PNGs plus an xfwm4 half* under =linux/.themes/BigSur-Bold-Dark/{unity,xfwm4}/= (stowed to =~/.themes/=, exactly like the other tracked =linux/.themes/= packs) — so the target needs no build-time image library. Both reference sets (=/usr/share/themes/Windowck/= and =Windowck-dark/=) carry an =xfwm4/= subfolder with a =themerc= alongside their =unity/= PNGs; =wckbuttons='s theme-validity scan (confirmed via =strings= on =libwckbuttons.so=: it keys on =themerc=/=xfwm4= alongside =unity=) silently rejects a theme that has only =unity/=, falling back to its near-black stock glyphs. So the generator emits both halves from the same glyph geometry: PNGs into =unity/= for the plugin's own rendering, and the identical strokes quantised into hard-edged =.xpm= text (transparent background plus one solid colour per glyph, same 18×14 canvas the reference button xpms use) into =xfwm4/= — sized to the five caption buttons only (close/hide/maximize/maximize-toggled/menu), not the full xfwm4 border-decoration set (title tiles, corners, shade, stick), which =wckbuttons= never reads. The =themerc= is copied verbatim from the reference (identical between =Windowck= and =Windowck-dark=: layout offsets only, no colour keys — the colour lives in the pixmaps). Tweak a glyph, regenerate with =xfce-wck-theme-gen ~/DotCortex/linux/.themes/BigSur-Bold-Dark/unity= (the argument is still the =unity/= path; the script derives the theme root and writes the sibling =xfwm4/= itself), and commit both subfolders alongside this file. With no argument it writes a live copy to =~/.themes/BigSur-Bold-Dark/=. Requires =python3-pil=; no imagemagick or other image-conversion tool needed — the xpm text is written directly.

#+BEGIN_SRC python :tangle linux/.local/bin/xfce-wck-theme-gen :shebang "#!/usr/bin/env python3" :tangle-mode (identity #o755) :comments no
# xfce-wck-theme-gen — generate the windowck caption-button set for XFCE: bold,
# always-visible white glyphs on a transparent background; close turns red on
# hover, min/max brighten, all dim to gray when the window is unfocused. Built
# for dark panels, where windowck's shipped themes render near-invisible
# (BigSur-Dark synced) or hover-only (Windowck-dark) glyphs.
#
# Emits BOTH halves a theme needs: unity/*.png for wckbuttons' own rendering,
# and xfwm4/{themerc,*.xpm} so wckbuttons' theme-validity scan (it keys on
# themerc/xfwm4 alongside unity — confirmed via strings on libwckbuttons.so)
# accepts the theme instead of silently falling back to stock glyphs. Only the
# five caption buttons get xpm siblings (close/hide/maximize/maximize-toggled/
# menu) — wckbuttons never reads the border-decoration files (title tiles,
# corners, shade, stick) that a full xfwm4 window-manager theme also carries.
#
# The committed asset lives in linux/.themes/BigSur-Bold-Dark/{unity,xfwm4}/
# (stowed to ~/.themes) — this script is its canonical source. Tangled from
# xfce-desktopmenu.org; never edit under the overlay. Requires python3-pil; no
# imagemagick or other image-conversion tool — xpm text is written directly.
import os, sys
from PIL import Image, ImageDraw

THEME = "BigSur-Bold-Dark"
OUT_UNITY = sys.argv[1] if len(sys.argv) > 1 else \
    os.path.expanduser("~/.themes/%s/unity" % THEME)
THEME_ROOT = os.path.dirname(os.path.normpath(OUT_UNITY))
OUT_XFWM4 = os.path.join(THEME_ROOT, "xfwm4")
os.makedirs(OUT_UNITY, exist_ok=True)
os.makedirs(OUT_XFWM4, exist_ok=True)

# Minimal valid xfwm4 themerc — verbatim from /usr/share/themes/Windowck{,-dark}
# /xfwm4/themerc, byte-identical between the light and dark reference themes.
# Layout offsets only; colour lives in the pixmaps, not here.
THEMERC = """button_offset=0
button_spacing=0
show_app_icon=false
maximized_offset=0
title_vertical_offset_active=1
title_vertical_offset_inactive=1
"""

W, H = 18, 14                    # final size (matches the shipped unity set)
S = 8                            # supersample factor for smooth downscaling
BW, BH = W * S, H * S
L, R, T, B = 5, 12, 3, 10        # glyph bounding box (final coords)
LW = 1.7                         # stroke width (final px)

WHITE  = (242, 242, 242, 255)    # focused normal
GRAY   = (140, 140, 140, 255)    # unfocused
RED    = (255, 95, 87, 255)      # close hover
REDDIM = (224, 70, 63, 255)      # close pressed
BRIGHT = (255, 255, 255, 255)    # min/max hover
PRESSD = (210, 210, 210, 255)    # min/max pressed

def canvas():
    return Image.new("RGBA", (BW, BH), (0, 0, 0, 0))

def down(im):
    return im.resize((W, H), Image.LANCZOS)

def line(d, p0, p1, col, w):
    d.line([(p0[0] * S, p0[1] * S), (p1[0] * S, p1[1] * S)], fill=col, width=int(round(w * S)))

def rect(d, x0, y0, x1, y1, col, w):
    d.rectangle([x0 * S, y0 * S, x1 * S, y1 * S], outline=col, width=int(round(w * S)))

def g_close(col):
    im = canvas(); d = ImageDraw.Draw(im)
    line(d, (L, T), (R, B), col, LW); line(d, (R, T), (L, B), col, LW)
    return down(im)

def g_min(col):
    im = canvas(); d = ImageDraw.Draw(im)
    y = (T + B) // 2 + 1
    line(d, (L, y), (R, y), col, LW)
    return down(im)

def g_max(col):
    im = canvas(); d = ImageDraw.Draw(im)
    rect(d, L, T, R, B, col, LW)
    return down(im)

def g_unmax(col):
    im = canvas(); d = ImageDraw.Draw(im)
    rect(d, L + 2, T, R, B - 2, col, LW - 0.2)   # back square (upper-right)
    front = canvas(); d2 = ImageDraw.Draw(front)
    rect(d2, L, T + 2, R - 2, B, col, LW)         # front square (lower-left)
    im.alpha_composite(front)
    return down(im)

def g_menu(col):
    im = canvas(); d = ImageDraw.Draw(im)
    for y in (T + 1, (T + B) // 2 + 1, B - 1):
        line(d, (L, y), (R, y), col, LW - 0.3)
    return down(im)

GLYPH = {"close": g_close, "minimize": g_min, "maximize": g_max,
         "unmaximize": g_unmax, "menu": g_menu}

# per-button state colours: (normal, prelight, pressed, unfocused)
STATES = {
    "close":      (WHITE, RED,    REDDIM, GRAY),
    "minimize":   (WHITE, BRIGHT, PRESSD, GRAY),
    "maximize":   (WHITE, BRIGHT, PRESSD, GRAY),
    "unmaximize": (WHITE, BRIGHT, PRESSD, GRAY),
    "menu":       (WHITE, BRIGHT, PRESSD, GRAY),
}

for btn, fn in GLYPH.items():
    normal, prelight, pressed, unfoc = STATES[btn]
    variants = {
        "%s.png" % btn:                  fn(normal),
        "%s_focused_normal.png" % btn:   fn(normal),
        "%s_focused_prelight.png" % btn: fn(prelight),
        "%s_focused_pressed.png" % btn:  fn(pressed),
        "%s_unfocused.png" % btn:        fn(unfoc),
    }
    for name, im in variants.items():
        im.save(os.path.join(OUT_UNITY, name))

# --- xfwm4 half: same glyph geometry, quantised into hard-edged XPM text ---
# XPM has no alpha channel (only a fully-transparent "None" colour), and the
# LANCZOS downscale blends both alpha *and* RGB toward the transparent
# canvas's (0,0,0,0) at every anti-aliased edge — sampling the blended RGB
# back out would explode into dozens of near-black off-shades. So each pixel
# is thresholded against the *known* nominal glyph colour (the col the glyph
# function was actually asked to draw in), not the blended pixel value:
# alpha >= 128 -> col, else "None". Exactly two colours per file, same
# simplicity as the reference button xpms (which use 2-4).
def to_xpm(im, col, name):
    w, h = im.size
    a_ch = im.getchannel("A")
    lines_px = []
    for y in range(h):
        row = []
        for x in range(w):
            row.append("+" if a_ch.getpixel((x, y)) >= 128 else ".")
        lines_px.append("".join(row))
    lines = ["/* XPM */", "static char * %s = {" % name.replace("-", "_"),
             '"%d %d 2 1",' % (w, h),
             '".\tc None",',
             '"+\tc #%02X%02X%02X",' % col[:3]]
    lines.extend('"%s",' % row for row in lines_px)
    lines.append("};")
    return "\n".join(lines) + "\n"

# unity glyph name -> xfwm4 button name (xfwm4 calls minimize "hide" and the
# restore-from-maximized icon "maximize-toggled")
XFWM4_NAME = {"close": "close", "minimize": "hide", "maximize": "maximize",
              "unmaximize": "maximize-toggled", "menu": "menu"}
# xfwm4 state suffix -> which of (normal, prelight, pressed, unfocused) to use
XFWM4_STATE = {"active": 0, "prelight": 1, "pressed": 2, "inactive": 3}

for btn, fn in GLYPH.items():
    colours_by_state = STATES[btn]
    xname = XFWM4_NAME[btn]
    for suffix, idx in XFWM4_STATE.items():
        stem = "%s-%s" % (xname, suffix)
        col = colours_by_state[idx]
        with open(os.path.join(OUT_XFWM4, stem + ".xpm"), "w") as f:
            f.write(to_xpm(fn(col), col, stem))

with open(os.path.join(OUT_XFWM4, "themerc"), "w") as f:
    f.write(THEMERC)

print("wrote %d files to %s" % (len(os.listdir(OUT_UNITY)), OUT_UNITY))
print("wrote %d files to %s" % (len(os.listdir(OUT_XFWM4)), OUT_XFWM4))
#+END_SRC

* Titleless / borderless maximize toggle (R1)
The xfwm4 equivalent of KWin =BorderlessMaximizedWindows= — two native xfconf booleans, no watcher or theme hack. =enable= sets both true (maximized windows drop titlebar + borders, so =windowck-plugin= / =wckbuttons= carry the chrome in the panel); =disable= sets both false. Client-side-decorated apps draw their own titlebar and are the documented exception.

#+BEGIN_SRC bash :tangle linux/.local/bin/xfwm-titleless-maximized :shebang "#!/usr/bin/env bash" :tangle-mode (identity #o755)
set -euo pipefail

CH=xfwm4
KEYS=(/general/borderless_maximize /general/titleless_maximize)

usage() {
  cat <<'EOF'
usage: xfwm-titleless-maximized {status|enable|disable}

Controls xfwm4 /general/borderless_maximize and /general/titleless_maximize.
enable  = maximized windows lose titlebar/borders (panel carries the chrome)
disable = normal decorations everywhere
EOF
  exit "${1:-0}"
}

command -v xfconf-query >/dev/null 2>&1 || { echo "xfconf-query not found" >&2; exit 1; }
xfconf-query -c "$CH" -l >/dev/null 2>&1 || {
  echo "no xfwm4 xfconf channel (run inside a live XFCE session)" >&2; exit 1; }

get() { xfconf-query -c "$CH" -p "$1" 2>/dev/null || echo "unset (default: false)"; }

setval() {
  local val="$1" key
  for key in "${KEYS[@]}"; do
    if xfconf-query -c "$CH" -p "$key" >/dev/null 2>&1; then
      xfconf-query -c "$CH" -p "$key" -s "$val"
    else
      xfconf-query -c "$CH" -p "$key" -n -t bool -s "$val"
    fi
    echo "${key##*/}=$val"
  done
}

case "${1:-status}" in
  status)
    for key in "${KEYS[@]}"; do echo "${key##*/}: $(get "$key")"; done
    ;;
  enable)  setval true ;;
  disable) setval false ;;
  -h|--help) usage ;;
  *) usage 1 ;;
esac
#+END_SRC

* Deployment
1. =tangle-one xfce-desktopmenu.org= then =loom stow:x230= / =loom stow:t480s= — places source + helpers under =$HOME=.
2. Install the declared toolchain (=valac meson ninja-build libxfce4panel-2.0-dev libxfce4ui-2-dev libwnck-3-dev libx11-dev= + =xfce4-windowck-plugin wmctrl zenity=). A machine-wide =loom nala:apply= converges the whole manifest; install just these if the manifest has drifted.
3. =loom desktop:xfce-menu= — builds the plugin and installs it *system-scope* (=sudo=; see scope note above), then adds the plugins to the top panel additively and pins the bold =BigSur-Bold-Dark= caption-button theme (stowed in step 1; regenerate its PNGs with =xfce-wck-theme-gen= after a glyph tweak).
4. =loom xfwm:titleless-on= — enable titleless maximize. (=xfwm:titleless-status= / =xfwm:titleless-off= to inspect/revert.)
5. Reload the panel: =xfce4-panel -r= (run inside the live XFCE session; a stale =DBUS_SESSION_BUS_ADDRESS= in a detached tmux/ssh shell will fail — source it from the running =xfce4-panel= process env if so).
6. CSD suppression (=GTK_CSD=0=, =gtk3-nocsd=) is already set for the XFCE machines in =x11.org= (=x230/.xsessionrc=, =devuan/.xsessionrc=).
