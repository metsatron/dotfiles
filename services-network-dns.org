* Contract

On a Linux host using a regular =/etc/resolv.conf=, NetworkManager and
Tailscale can both write that file. A connection or DHCP event can replace
Tailscale's resolver with the LAN resolver and break MagicDNS while the
WireGuard transport remains healthy.

This module gives Tailscale exclusive ownership on those direct-file hosts:
NetworkManager gets =dns=none= and =rc-manager=unmanaged=. Addresses, domains,
credentials, connection profiles, and router configuration are not encoded.
Tailscale continues to obtain its DNS settings from the existing control plane.
The installed NetworkManager drop-in persists across DHCP changes and reboot.

An ifupdown/dhclient host has the same competing-writer risk without
NetworkManager. After inspecting its actual running dhclient and packaged
=dhclient-script=, use =--dhclient= with the same plan/apply/check command.
This installs a late enter-hook overriding only =make_resolv_conf=; leases,
routes, and interface configuration remain dhclient-owned. The hook mechanism
matches Debian's existing =resolved-enter= integration. It requires the verified
packaged hook contract and refuses a host with a NetworkManager config surface.

Hosts already using systemd-resolved or resolvconf symlinks retain their
existing integration. Unknown resolver owners, symlinks, caching plugins,
unprovisioned Tailscale DNS, and unexpected drop-in contents fail before writes.
This is a setup command, not another daemon, watchdog, or init-system wrapper.

* Build, apply, and verify

The explicit overlay path is supported before stow, avoiding a broad restow of
unrelated live configurations. Normal =loom stow:<machine>= also deploys the
Linux command. It resolves its template from the owning overlay, not an
arbitrary current working directory.

When repository push/pull is not authorized, transfer this reviewed source and
its generated files as a checksum-verified, repo-layout deployment
artifact in a fresh target-local =/var/tmp/= directory. Run its tests and plan
before apply. Keep the source with the artifact as provenance; do not copy into,
commit on, pull, or restow the remote checkout to force deployment. The live
change remains the same canonical module's root-owned DNS ownership declaration.
Normal repository synchronization is a separate, explicitly authorized step.

Apply checkpoints the resolver and any existing managed drop-in under
=/var/lib/dotcortex/network-dns/checkpoints/= before mutation, installs only its
own drop-in, and uses synchronous =nmcli general reload conf=. If the resolver
was overwritten, it briefly toggles only Tailscale's accept-DNS preference to
reapply DNS; it never downs the interface or restarts either network daemon.
Failures leave the checkpoint and installed state intact and report their
location; there is no automatic destructive rollback.

The final check asks NetworkManager to refresh DNS via =reload dns-rc= and
asserts that the resolver bytes remain identical. This exercises the offending
writer without reconnecting networking or risking the active SSH transport.
Check a private tailnet HTTPS service from the client afterward, with normal
DNS and certificate validation; do not substitute an address override.
A physical router replacement/reboot is a separate acceptance event, not
something this non-disruptive check claims to have performed.

For dhclient, validation checks the installed hook is selected last by
=run-parts= and sources it in an isolated shell whose original resolver writer
would fail. Its replacement must succeed without touching the live resolver.
It never runs the full dhclient-script or requests a new lease as a test.

Intentional removal or disabling of Tailscale DNS requires reconsidering this
exclusive ownership policy. Rollback is operator-controlled: inspect the
checkpoint, remove the managed drop-in, reload NM configuration, and restore
the desired resolver policy. Do not blindly restore an old resolver file.

The CLI prepends the standard administrative executable directories to its
search path. If the caller supplies no =PATH= or an empty one, it also restores
standard user executable directories; a stripped agent subprocess environment
must not make installed host tools appear absent. Deterministic tests cover
both missing and empty inherited paths.

from __future__ import annotations

import argparse
import configparser
import datetime
import hashlib
import json
import os
from pathlib import Path
import shutil
import subprocess
import sys
import time

EXPECTED = "# Managed by DotCortex services-network-dns.org\n[main]\ndns=none\nrc-manager=unmanaged\n"
TS_HEADER = "# resolv.conf(5) file generated by tailscale"
NM_HEADER = "# Generated by NetworkManager"
DHCLIENT_EXPECTED = "#!/bin/sh\n# Managed by DotCortex services-network-dns.org\nmake_resolv_conf() { :; }\n"


class ContractError(RuntimeError):
    pass


def run(argv: list[str], privileged: bool = False) -> str:
    if privileged and os.geteuid() != 0:
        argv = ["sudo", "-n", *argv]
    result = subprocess.run(argv, text=True, capture_output=True, timeout=30)
    if result.returncode:
        raise ContractError(f"{' '.join(argv)}: {result.stderr.strip() or result.stdout.strip()}")
    return result.stdout


class Setup:
    def __init__(self, root: Path = Path("/"), runner=run, template: Path | None = None, owner: str = "networkmanager"):
        if owner not in ("networkmanager", "dhclient"):
            raise ContractError("Unknown DNS writer substrate")
        self.root = root
        self.run = runner
        self.owner = owner
        self.expected = DHCLIENT_EXPECTED if owner == "dhclient" else EXPECTED
        self.resolver = root / "etc/resolv.conf"
        relative = "etc/dhcp/dhclient-enter-hooks.d/zz-dotcortex-tailscale-dns" if owner == "dhclient" else "etc/NetworkManager/conf.d/90-dotcortex-tailscale-dns.conf"
        self.target = root / relative
        self.template = template or Path(__file__).resolve().parents[2] / ".config/dotcortex/network-dns" / self.target.name
        self.checkpoint: Path | None = None

    def status(self) -> dict:
        data = json.loads(self.run(["tailscale", "status", "--json"]))
        if data.get("BackendState") != "Running":
            raise ContractError("Tailscale is not Running")
        dns = json.loads(self.run(["tailscale", "dns", "status", "--json"], privileged=True))
        if dns.get("TailscaleDNS") is not True:
            raise ContractError("Tailscale accept-DNS is not enabled; refusing to change operator preference")
        if dns.get("CurrentTailnet", {}).get("MagicDNSEnabled") is not True:
            raise ContractError("MagicDNS is not enabled in the existing control-plane policy")
        return data

    def config(self) -> configparser.ConfigParser:
        config = configparser.ConfigParser(interpolation=None, strict=False)
        config.read_string(self.run(["NetworkManager", "--print-config"]))
        return config

    def preflight(self) -> str:
        self.status()
        if self.resolver.is_symlink():
            destination = self.resolver.resolve(strict=True)
            integrated = (self.root / "run/systemd/resolve", self.root / "run/resolvconf")
            if any(destination.is_relative_to(directory) for directory in integrated):
                return "integrated"
            raise ContractError(f"Unknown resolver symlink: {destination}")
        if not self.resolver.is_file():
            raise ContractError("Missing or non-regular resolver")
        content = self.resolver.read_text()
        if not content.startswith((TS_HEADER, NM_HEADER)):
            raise ContractError("Unknown direct-file resolver owner")
        if self.owner == "networkmanager":
            config = self.config()
            if config.get("main", "dns", fallback="default") not in ("default", "none"):
                raise ContractError("Existing DNS plugin requires its own integration; refusing to disable it")
            if config.get("main", "rc-manager", fallback="auto") not in ("auto", "symlink", "file", "unmanaged"):
                raise ContractError("Existing resolver manager requires its own integration")
        else:
            if (self.root / "etc/NetworkManager").exists():
                raise ContractError("NetworkManager config surface exists; reconcile substrate before choosing dhclient")
            script = (self.root / "sbin/dhclient-script").read_text()
            definition = script.find("make_resolv_conf() {")
            hooks = script.find("run_hookdir /etc/dhcp/dhclient-enter-hooks.d")
            if not 0 <= definition < hooks:
                raise ContractError("Packaged dhclient-script does not expose the verified enter-hook contract")
            selected = self.run(["run-parts", "--list", str(self.target.parent)]).splitlines()
            if any(Path(item).name > self.target.name for item in selected):
                raise ContractError("A later dhclient hook would run after the DNS ownership declaration")
        if self.template.is_symlink() or self.template.read_text() != self.expected:
            raise ContractError("Canonical template is missing, linked, or differs from the declared contract")
        if self.target.is_symlink() or (self.target.exists() and self.target.read_text() != self.expected):
            raise ContractError("Managed drop-in path contains unexpected content; preserve and reconcile first")
        return "direct"

    def verify_declaration(self) -> None:
        if self.owner == "networkmanager":
            config = self.config()
            if config.get("main", "dns", fallback="") != "none" or config.get("main", "rc-manager", fallback="") != "unmanaged":
                raise ContractError("Effective NetworkManager configuration does not match; DNS preference left untouched")
        else:
            selected = self.run(["run-parts", "--list", str(self.target.parent)]).splitlines()
            if not selected or Path(selected[-1]) != self.target or not os.access(self.target, os.X_OK):
                raise ContractError("dhclient ownership hook is not selected last and executable")

    def verify(self, exercise_writer: bool = False) -> None:
        if self.preflight() == "integrated":
            print("integrated resolver preserved; verify client DNS/HTTPS separately")
            return
        if not self.target.is_file() or self.target.read_text() != self.expected:
            raise ContractError("DNS ownership drop-in is not installed")
        self.verify_declaration()
        if not self.resolver.read_text().startswith(TS_HEADER):
            raise ContractError("Resolver is not Tailscale-owned")
        if exercise_writer:
            before = hashlib.sha256(self.resolver.read_bytes()).digest()
            if self.owner == "networkmanager":
                self.run(["nmcli", "general", "reload", "dns-rc"], privileged=True)
            else:
                self.run(["sh", "-c", 'make_resolv_conf() { return 71; }; . "$1"; make_resolv_conf', "dns-hook-check", str(self.target)])
            if hashlib.sha256(self.resolver.read_bytes()).digest() != before:
                raise ContractError("NetworkManager DNS refresh still changed the resolver")
        health = self.status().get("Health") or []
        if any("resolv.conf overwritten" in item for item in health):
            raise ContractError("Tailscale still reports an overwritten resolver")
        print(f"direct resolver: Tailscale owns DNS; {self.owner} leaves resolver unchanged")

    def apply(self) -> None:
        if self.preflight() == "integrated":
            self.verify()
            return
        needs_install = not self.target.exists()
        needs_repair = not self.resolver.read_text().startswith(TS_HEADER)
        if needs_install or needs_repair:
            stamp = datetime.datetime.now(datetime.timezone.utc).strftime("%Y%m%dT%H%M%S.%fZ")
            self.checkpoint = self.root / "var/lib/dotcortex/network-dns/checkpoints" / stamp
            self.run(["install", "-d", "-m", "0700", str(self.checkpoint)], privileged=True)
            self.run(["cp", "-a", str(self.resolver), str(self.checkpoint / "resolv.conf")], privileged=True)
            if self.target.exists():
                self.run(["cp", "-a", str(self.target), str(self.checkpoint / self.target.name)], privileged=True)
            print(f"checkpoint: {self.checkpoint}", flush=True)
        if needs_install:
            if self.template.read_text() != self.expected:
                raise ContractError("Template changed after preflight")
            self.run(["install", "-d", "-m", "0755", str(self.target.parent)], privileged=True)
            mode = "0755" if self.owner == "dhclient" else "0644"
            self.run(["install", "-m", mode, str(self.template), str(self.target)], privileged=True)
        if self.owner == "networkmanager":
            self.run(["nmcli", "general", "reload", "conf"], privileged=True)
        self.verify_declaration()
        if needs_repair:
            disable_error = None
            try:
                self.run(["tailscale", "set", "--accept-dns=false"], privileged=True)
            except Exception as exc:
                disable_error = exc
            try:
                self.run(["tailscale", "set", "--accept-dns=true"], privileged=True)
            except Exception as exc:
                raise ContractError(f"DNS re-enable failed; accept-DNS may be off. Checkpoint: {self.checkpoint}. {exc}") from exc
            if disable_error:
                raise ContractError(f"DNS disable failed; re-enable command succeeded, verification still required: {disable_error}") from disable_error
            for _ in range(30):
                health = self.status().get("Health") or []
                if self.resolver.read_text().startswith(TS_HEADER) and not any("resolv.conf overwritten" in item for item in health):
                    break
                time.sleep(0.5)
            else:
                raise ContractError("Tailscale DNS did not converge after re-enable")
        self.verify(exercise_writer=True)


def main() -> int:
    parser = argparse.ArgumentParser(description="Declare exclusive Tailscale DNS ownership on verified direct-file Linux hosts")
    parser.add_argument("--dhclient", action="store_true", help="select inspected ifupdown/dhclient substrate instead of NetworkManager")
    modes = parser.add_mutually_exclusive_group(required=True)
    modes.add_argument("--plan", action="store_true", help="read-only preflight")
    modes.add_argument("--apply", action="store_true", help="checkpoint and apply without restarting networking")
    modes.add_argument("--check", action="store_true", help="read-only ownership check; no reload")
    args = parser.parse_args()
    os.environ["PATH"] = "/usr/sbin:/sbin:" + (os.environ.get("PATH") or "/usr/local/bin:/usr/bin:/bin")
    tools = ("tailscale", "dhclient", "run-parts", "sh") if args.dhclient else ("tailscale", "NetworkManager", "nmcli")
    for tool in tools:
        if not shutil.which(tool):
            parser.error(f"{tool} is unavailable on this execution surface; run on the actual host")
    setup = Setup(owner="dhclient" if args.dhclient else "networkmanager")
    try:
        if args.plan:
            print(f"resolver mode: {setup.preflight()}")
        elif args.apply:
            setup.apply()
        else:
            setup.verify()
    except (ContractError, OSError, ValueError, subprocess.TimeoutExpired) as exc:
        print(f"tailscale-dns-setup: {exc}", file=sys.stderr)
        if setup.checkpoint:
            print(f"checkpoint preserved: {setup.checkpoint}", file=sys.stderr)
        return 1
    return 0


if __name__ == "__main__":
    raise SystemExit(main())

from __future__ import annotations

import contextlib
import io
import json
from pathlib import Path
import runpy

import unittest
from unittest import mock

REPO = Path(__file__).resolve().parents[5]
SCRIPT = REPO / "linux/.local/bin/tailscale-dns-setup"
MODULE = runpy.run_path(str(SCRIPT), run_name="dns_test_module")
Setup, ContractError = MODULE["Setup"], MODULE["ContractError"]
EXPECTED, TS_HEADER, NM_HEADER = (MODULE[key] for key in ("EXPECTED", "TS_HEADER", "NM_HEADER"))


class FakeHost:
    def __init__(self, root):
        self.root = root
        self.calls = []
        self.accept = True
        self.running = True
        self.magic = True
        self.plugin = "default"
        self.override = False
        self.reenabled_fails = False
        self.disable_fails = False
        self.rewrite = False
        self.health = []
        self.target = root / "etc/NetworkManager/conf.d/90-dotcortex-tailscale-dns.conf"
        self.resolver = root / "etc/resolv.conf"
        self.resolver.parent.mkdir(parents=True)
        self.resolver.write_text(NM_HEADER + "\n")
        self.template = root / "template.conf"
        self.template.write_text(EXPECTED)

    def __call__(self, argv, privileged=False):
        self.calls.append((argv, privileged))
        if argv == ["tailscale", "status", "--json"]:
            return json.dumps({"BackendState": "Running" if self.running else "Stopped", "Health": self.health})
        if argv == ["tailscale", "dns", "status", "--json"]:
            return json.dumps({"TailscaleDNS": self.accept, "CurrentTailnet": {"MagicDNSEnabled": self.magic}})
        if argv == ["NetworkManager", "--print-config"]:
            if self.target.exists() and not self.override:
                return EXPECTED
            return f"[main]\ndns={self.plugin}\nrc-manager=auto\n"
        if argv[:2] == ["install", "-d"]:
            Path(argv[-1]).mkdir(parents=True, exist_ok=True)
        elif argv[:2] == ["install", "-m"] or argv[:2] == ["cp", "-a"]:
            shutil.copyfile(argv[-2], argv[-1])
            if argv[0] == "install":
                Path(argv[-1]).chmod(int(argv[2], 8))
        elif argv[0] in ("run-parts", "sh"):
            return subprocess.run(argv, text=True, capture_output=True, check=True).stdout
        elif argv == ["nmcli", "general", "reload", "dns-rc"]:
            if self.rewrite:
                self.resolver.write_text(NM_HEADER + "\nchanged\n")
        elif argv == ["nmcli", "general", "reload", "conf"]:
            pass
        elif argv == ["tailscale", "set", "--accept-dns=false"]:
            self.accept = False
            if self.disable_fails:
                raise ContractError("fixture failure after disabling DNS")
        elif argv == ["tailscale", "set", "--accept-dns=true"]:
            if self.reenabled_fails:
                raise ContractError("fixture re-enable failure")
            self.accept = True
            self.health = []
            self.resolver.write_text(TS_HEADER + "\n")
        else:
            raise AssertionError(f"Unexpected command: {argv}")
        return ""


class DnsOwnershipTests(unittest.TestCase):
    def setUp(self):
        self.tmp = tempfile.TemporaryDirectory()
        self.addCleanup(self.tmp.cleanup)
        self.root = Path(self.tmp.name)
        self.host = FakeHost(self.root)
        self.setup = Setup(self.root, self.host, self.host.template)
        self.output = contextlib.redirect_stdout(io.StringIO())
        self.output.__enter__()
        self.addCleanup(self.output.__exit__, None, None, None)

    def mutation_calls(self):
        return [argv for argv, _ in self.host.calls if argv[0] in ("install", "cp", "nmcli") or argv[:2] == ["tailscale", "set"]]

    def test_plan_is_read_only(self):
        self.assertEqual(self.setup.preflight(), "direct")
        self.assertEqual(self.mutation_calls(), [])

    def test_repair_checkpoints_before_mutation_and_reloads_without_restart(self):
        before = self.host.resolver.read_bytes()
        self.setup.apply()
        self.assertEqual((self.setup.checkpoint / "resolv.conf").read_bytes(), before)
        self.assertEqual(self.host.target.read_text(), EXPECTED)
        self.assertTrue(self.host.accept)
        calls = self.mutation_calls()
        self.assertLess(next(i for i, cmd in enumerate(calls) if cmd[:2] == ["cp", "-a"]), next(i for i, cmd in enumerate(calls) if cmd[:2] == ["install", "-m"]))
        self.assertIn(["nmcli", "general", "reload", "conf"], calls)
        self.assertIn(["nmcli", "general", "reload", "dns-rc"], calls)
        self.assertLess(calls.index(["nmcli", "general", "reload", "conf"]), calls.index(["tailscale", "set", "--accept-dns=false"]))
        self.assertFalse(any("restart" in cmd or "down" in cmd for cmd in calls))

    def test_healthy_direct_host_is_protected_without_dns_toggle(self):
        self.host.resolver.write_text(TS_HEADER + "\n")
        self.setup.apply()
        self.assertFalse(any(cmd[:2] == ["tailscale", "set"] for cmd in self.mutation_calls()))
        self.assertEqual(self.host.target.read_text(), EXPECTED)

    def test_repeat_apply_does_not_rewrite_files_or_create_checkpoint(self):
        self.setup.apply()
        checkpoint_dirs = list((self.root / "var/lib/dotcortex/network-dns/checkpoints").iterdir())
        self.host.calls.clear()
        self.setup.apply()
        self.assertFalse(any(cmd[0] in ("install", "cp") or cmd[:2] == ["tailscale", "set"] for cmd in self.mutation_calls()))
        self.assertEqual(list((self.root / "var/lib/dotcortex/network-dns/checkpoints").iterdir()), checkpoint_dirs)

    def test_check_is_read_only(self):
        self.setup.apply()
        self.host.calls.clear()
        self.setup.verify()
        self.assertEqual(self.mutation_calls(), [])

    def test_uninstalled_check_fails(self):
        with self.assertRaisesRegex(ContractError, "not installed"):
            self.setup.verify()

    def test_integrated_resolvers_are_preserved(self):
        for name in ("systemd/resolve", "resolvconf"):
            with self.subTest(name=name):
                self.host.resolver.unlink()
                target = self.root / "run" / name / "resolv.conf"
                target.parent.mkdir(parents=True, exist_ok=True)
                target.write_text("integration fixture\n")
                self.host.resolver.symlink_to(target)
                self.host.calls.clear()
                self.setup.apply()
                self.assertEqual(self.mutation_calls(), [])
                self.assertFalse(self.host.target.exists())
                self.assertTrue(self.host.resolver.is_symlink())

    def test_unknown_symlink_fails_before_mutation(self):
        self.host.resolver.unlink()
        self.host.resolver.symlink_to(self.host.template)
        with self.assertRaisesRegex(ContractError, "Unknown resolver symlink"):
            self.setup.apply()
        self.assertEqual(self.mutation_calls(), [])

    def test_unknown_file_owner_fails_before_mutation(self):
        self.host.resolver.write_text("operator-owned fixture\n")
        with self.assertRaisesRegex(ContractError, "Unknown direct-file"):
            self.setup.apply()
        self.assertEqual(self.mutation_calls(), [])

    def test_disabled_dns_and_magicdns_are_not_overridden(self):
        for field in ("accept", "magic", "running"):
            with self.subTest(field=field):
                setattr(self.host, field, False)
                with self.assertRaises(ContractError):
                    self.setup.apply()
                setattr(self.host, field, True)
        self.assertEqual(self.mutation_calls(), [])

    def test_existing_caching_plugin_is_preserved(self):
        self.host.plugin = "dnsmasq"
        with self.assertRaisesRegex(ContractError, "DNS plugin"):
            self.setup.apply()
        self.assertEqual(self.mutation_calls(), [])

    def test_unexpected_dropin_is_preserved(self):
        self.host.target.parent.mkdir(parents=True)
        self.host.target.write_text("operator-owned drop-in\n")
        with self.assertRaisesRegex(ContractError, "unexpected content"):
            self.setup.apply()
        self.assertEqual(self.mutation_calls(), [])
        self.assertEqual(self.host.target.read_text(), "operator-owned drop-in\n")

    def test_bad_template_fails_before_mutation(self):
        self.host.template.write_text(EXPECTED + "extra=bad\n")
        with self.assertRaisesRegex(ContractError, "Canonical template"):
            self.setup.apply()
        self.assertEqual(self.mutation_calls(), [])

    def test_overriding_config_aborts_before_dns_toggle(self):
        self.host.override = True
        with self.assertRaisesRegex(ContractError, "Effective NetworkManager"):
            self.setup.apply()
        self.assertFalse(any(cmd[:2] == ["tailscale", "set"] for cmd in self.mutation_calls()))
        self.assertTrue((self.setup.checkpoint / "resolv.conf").exists())

    def test_writer_challenge_detects_resolver_overwrite(self):
        self.host.rewrite = True
        with self.assertRaisesRegex(ContractError, "still changed"):
            self.setup.apply()

    def test_failed_reenable_is_reported_without_automatic_restore(self):
        self.host.reenabled_fails = True
        with self.assertRaisesRegex(ContractError, "accept-DNS may be off"):
            self.setup.apply()
        self.assertFalse(self.host.accept)
        self.assertTrue((self.setup.checkpoint / "resolv.conf").exists())
        self.assertEqual(self.host.target.read_text(), EXPECTED)

    def test_disable_failure_still_reenables_dns_and_fails_loud(self):
        self.host.disable_fails = True
        with self.assertRaisesRegex(ContractError, "disable failed; re-enable command succeeded"):
            self.setup.apply()
        self.assertTrue(self.host.accept)
        self.assertTrue((self.setup.checkpoint / "resolv.conf").exists())

class DhclientOwnershipTests(unittest.TestCase):
    def setUp(self):
        self.tmp = tempfile.TemporaryDirectory()
        self.addCleanup(self.tmp.cleanup)
        self.root = Path(self.tmp.name)
        self.host = FakeHost(self.root)
        self.host.target = self.root / "etc/dhcp/dhclient-enter-hooks.d/zz-dotcortex-tailscale-dns"
        self.host.target.parent.mkdir(parents=True)
        self.host.template.write_text(MODULE["DHCLIENT_EXPECTED"])
        self.host.resolver.write_text(TS_HEADER + "\n")
        script = self.root / "sbin/dhclient-script"
        script.parent.mkdir()
        script.write_text("make_resolv_conf() { :; }\nrun_hookdir /etc/dhcp/dhclient-enter-hooks.d\n")
        self.setup = Setup(self.root, self.host, self.host.template, owner="dhclient")
        self.output = contextlib.redirect_stdout(io.StringIO())
        self.output.__enter__()
        self.addCleanup(self.output.__exit__, None, None, None)

    def test_dhclient_hook_installed_without_nm_or_dns_toggle(self):
        before = self.host.resolver.read_bytes()
        self.setup.apply()
        self.assertEqual(self.host.target.read_text(), MODULE["DHCLIENT_EXPECTED"])
        self.assertEqual(self.host.resolver.read_bytes(), before)
        self.assertFalse(any(cmd[0] == "nmcli" or cmd[:2] == ["tailscale", "set"] for cmd, _ in self.host.calls))
        self.assertTrue(any(cmd[0] == "sh" for cmd, _ in self.host.calls))
        self.assertEqual((self.setup.checkpoint / "resolv.conf").read_bytes(), before)

    def test_dhclient_hook_overrides_a_failing_writer(self):
        code = 'make_resolv_conf() { return 71; }; make_resolv_conf'
        baseline = subprocess.run(["sh", "-c", code], capture_output=True)
        self.assertEqual(baseline.returncode, 71)
        self.setup.apply()
        subprocess.run(["sh", "-c", 'make_resolv_conf() { return 71; }; . "$1"; make_resolv_conf', "check", str(self.host.target)], check=True)

    def test_dhclient_repeat_apply_has_no_mutations(self):
        self.setup.apply()
        self.host.calls.clear()
        self.setup.apply()
        self.assertFalse(any(cmd[0] in ("install", "cp", "nmcli") or cmd[:2] == ["tailscale", "set"] for cmd, _ in self.host.calls))

    def test_nm_surface_prevents_dhclient_selection(self):
        (self.root / "etc/NetworkManager").mkdir()
        with self.assertRaisesRegex(ContractError, "reconcile substrate"):
            self.setup.apply()
        self.assertFalse(self.host.target.exists())

    def test_incompatible_packaged_script_is_not_modified(self):
        (self.root / "sbin/dhclient-script").write_text("unknown contract\n")
        with self.assertRaisesRegex(ContractError, "verified enter-hook contract"):
            self.setup.apply()
        self.assertFalse(self.host.target.exists())

    def test_later_hook_is_a_blocker_before_mutation(self):
        (self.host.target.parent / "zzz-other-owner").write_text("competing owner\n")
        with self.assertRaisesRegex(ContractError, "later dhclient hook"):
            self.setup.apply()
        self.assertFalse(self.host.target.exists())
