* Intent
A minimal, sovereign Guix install on a Debian-family host, managed from this repo.
We keep privileged steps explicit, package state declarative, and paths inside overlays.
Nothing in here overwrites your shell files directly, it only adds small blocks that tangle into your existing exports files.

* Layout
- Guix channels, profiles, manifests under =all/.config/guix/=
- Helper scripts under =all/.local/bin/=
- Shell exports for PATH added in tiny, self-contained blocks that tangle into =all/.bash_exports= and =all/.zsh_exports=
- No files removed, only appended sections with clear sentinels

* Virtual Habitat — Sanctuary Guix profiles

Phase 0B stub. Manifests are declared here; apply them in Phase 1A once the
Guix store read-only bind-mount is validated inside a throwaway Distrobox.

Profile composition model:
- =desktop-common= is built on the host and mounted read-only into sanctuaries
- Sanctuary launcher scripts source =desktop-common/etc/profile= first, then
  the sanctuary-specific profile (e.g. =sanctuary-qtile/etc/profile=)
- No package is duplicated: the host store is shared, not copied

See =Guix-Package-Commons.md= in MetaCortex for the full design.

** sanctuary-base

gets packed into a Docker image via =guix pack=. It contains nothing sanctuary-specific —
just the system utilities Distrobox needs to function inside a Guix rootfs.

Actual packages (qtile, emacs, zsh, etc.) are NOT bundled here. They come from
the host =/gnu/store= bind-mounted read-only into the container, accessed via
=~/.guix-extra-profiles/= profile symlinks.

** PowerShell 7.x (binary)

Official Microsoft Linux x86_64 release, pinned and hashed.  Uses the nonguix
=binary-build-system= (already a configured channel) for ELF interpreter and
rpath patching.  The =pwsh= binary is wrapped so =PATH= finds it normally.

SHA256 base32: =0nh53w3v9584q98rljjabqpvbkn3mn6ylw8483dg5nd0nwkpkmfg= (v7.4.7)
Upstream: =https://github.com/PowerShell/PowerShell/releases=

#+BEGIN_SRC scheme :tangle all/.config/guix/local-packages/local/packages/powershell.scm :mkdirp yes
;;; Local Guix package — PowerShell 7.x binary
;;; Pinned: v7.4.7 linux-x64 official Microsoft release
;;; License: MIT (Expat)
;;; Provenance: https://github.com/PowerShell/PowerShell/releases/tag/v7.4.7
;;; Hash verified: 2026-06-25 on T480s with `guix hash`

(define-module (local packages powershell)
  #:use-module (guix packages)
  #:use-module (guix download)
  #:use-module (nonguix build-system binary)
  #:use-module ((guix licenses) #:prefix license:)
  #:use-module (gnu packages compression)
  #:use-module (gnu packages gcc)
  #:use-module (gnu packages icu4c)
  #:use-module (gnu packages instrumentation)
  #:use-module (gnu packages tls)
  #:use-module (gnu packages base))

(define-public powershell
  (package
    (name "powershell")
    (version "7.4.7")
    (source
     (origin
       (method url-fetch)
       (uri (string-append
             "https://github.com/PowerShell/PowerShell/releases/download/"
             "v" version "/powershell-" version "-linux-x64.tar.gz"))
       (sha256
        (base32 "0nh53w3v9584q98rljjabqpvbkn3mn6ylw8483dg5nd0nwkpkmfg"))))
    (build-system binary-build-system)
    (arguments
     `(#:install-plan
       '(("." "lib/powershell" #:include-regexp (".*")))
       #:patchelf-plan
       '(("pwsh" ("glibc" "gcc:lib")))
       #:phases
       (modify-phases %standard-phases
         (add-after 'unpack 'enter-archive-root
           (lambda _
             ;; The upstream tarball has several top-level directories. Guix's
             ;; unpack phase can leave cwd in Modules/, which drops pwsh from
             ;; the later install-plan.
             (when (and (string=? (basename (getcwd)) "Modules")
                        (file-exists? "../pwsh"))
               (chdir ".."))))
         (add-after 'enter-archive-root 'make-payload-writable
           (lambda* (#:key outputs #:allow-other-keys)
             (for-each make-file-writable (find-files "." "\\.so$"))
             (make-file-writable "pwsh")
             (chmod "pwsh" #o755)))
         (add-after 'install 'patch-native-runpaths
           (lambda* (#:key inputs outputs #:allow-other-keys)
             (let* ((out (assoc-ref outputs "out"))
                    (lib (string-append out "/lib/powershell"))
                    (rpath (string-append
                            lib ":"
                            (assoc-ref inputs "gcc:lib") "/lib:"
                            (assoc-ref inputs "glibc") "/lib:"
                            (assoc-ref inputs "icu4c") "/lib:"
                            (assoc-ref inputs "openssl") "/lib:"
                            (assoc-ref inputs "zlib") "/lib:"
                            (assoc-ref inputs "lttng-ust") "/lib")))
               (for-each
                (lambda (file)
                  (make-file-writable file)
                  (invoke "patchelf" "--set-rpath" rpath file))
                (append (find-files lib "\\.so$")
                        (find-files lib "createdump$")))
               ;; The .NET tracepoint provider depends on liblttng-ust.so.0,
               ;; but current Guix ships liblttng-ust.so.1. PowerShell runs
               ;; without this optional tracing provider.
               (let ((trace-provider
                      (string-append lib "/libcoreclrtraceptprovider.so")))
                 (when (file-exists? trace-provider)
                   (delete-file trace-provider))))))
         (add-after 'install 'create-launcher
           (lambda* (#:key outputs #:allow-other-keys)
             (let* ((out (assoc-ref outputs "out"))
                    (lib (string-append out "/lib/powershell"))
                    (bin (string-append out "/bin")))
               (mkdir-p bin)
               (call-with-output-file (string-append bin "/pwsh")
                 (lambda (port)
                   (format port "#!/bin/sh\nexec ~a/pwsh \"$@\"\n" lib)))
               (chmod (string-append bin "/pwsh") #o755)))))))
    (inputs
     `(("glibc" ,glibc)
       ("gcc:lib" ,gcc "lib")
       ("icu4c" ,icu4c)
       ("lttng-ust" ,lttng-ust)
       ("openssl" ,openssl)
       ("zlib" ,zlib)))
    (supported-systems '("x86_64-linux"))
    (synopsis "PowerShell — cross-platform shell and scripting language")
    (description
     "PowerShell Core is a cross-platform automation and configuration
tool/framework from Microsoft.  This package bundles the official prebuilt
Linux x86_64 release (a .NET 8 self-contained application).")
    (home-page "https://github.com/PowerShell/PowerShell")
    (license license:expat)))
#+END_SRC

** Apply script

#+BEGIN_SRC bash :tangle all/.local/bin/agent-guix-apply :shebang "#!/usr/bin/env bash"
# ~/DotCortex/all/.local/bin/agent-guix-apply
# Builds per-agent Guix profiles from all/.config/guix/manifests/agents/*.scm.
# DRY-RUN unless --apply. Run as the human operator (uses sudo per agent).
# The manifest is copied into the agent home first so no DotCortex read
# permission is assumed; the guix binary is the human's channel-pinned one
# resolved to its store path (world-executable), never the fossil.
set -euo pipefail

MANIFEST_DIR="$HOME/DotCortex/all/.config/guix/manifests/agents"
APPLY=0
ONLY=""

while [ $# -gt 0 ]; do
  case "$1" in
    --apply) APPLY=1 ;;
    --only) shift; ONLY="$1" ;;
    *) echo "usage: agent-guix-apply [--apply] [--only TOOL]"; exit 1 ;;
  esac
  shift
done

run() {
  if [ "$APPLY" -eq 1 ]; then
    echo "+ $*"
    "$@"
  else
    echo "DRY-RUN: $*"
  fi
}

GUIX_CURRENT="$(readlink -f "$HOME/.config/guix/current" 2>/dev/null || true)"
GUIX_BIN="$GUIX_CURRENT/bin/guix"
if [ ! -x "$GUIX_BIN" ]; then
  echo "FATAL: no pulled guix at ~/.config/guix/current — run loom guix:pull first." >&2
  echo "Refusing to fall back to the /usr/local/bin/guix fossil." >&2
  exit 1
fi
echo "guix (channel-pinned store path): $GUIX_BIN"

found=0
for manifest in "$MANIFEST_DIR"/*.scm; do
  [ -e "$manifest" ] || continue
  tool="$(basename "$manifest" .scm)"
  [ -n "$ONLY" ] && [ "$tool" != "$ONLY" ] && continue
  found=1
  user="agent-$tool"
  if ! id "$user" >/dev/null 2>&1; then
    echo "no user: $user (run agent-users-bootstrap first; skip)"
    continue
  fi
  home="$(getent passwd "$user" | cut -d: -f6)"
  profile_dir="$home/.guix-extra-profiles/agent"
  profile="$profile_dir/agent"
  agent_manifest="$home/.config/guix/agent-manifest.scm"

  run sudo -u "$user" -H mkdir -p "$profile_dir" "$home/.config/guix"
  if [ "$APPLY" -eq 1 ]; then
    sudo -u "$user" -H tee "$agent_manifest" >/dev/null < "$manifest"
    echo "+ manifest copied to $agent_manifest"
  else
    echo "DRY-RUN: copy $manifest -> $agent_manifest"
  fi
  run sudo -u "$user" -H "$GUIX_BIN" package -m "$agent_manifest" -p "$profile"
  run sudo -u "$user" -H sh -c "grep -q guix-extra-profiles/agent '$home/.profile' 2>/dev/null || printf 'GUIX_PROFILE=\"\$HOME/.guix-extra-profiles/agent/agent\"\n[ -f \"\$GUIX_PROFILE/etc/profile\" ] && . \"\$GUIX_PROFILE/etc/profile\"\n' >> '$home/.profile'"
done

[ "$found" -eq 0 ] && echo "no agent manifests matched in $MANIFEST_DIR"
[ "$APPLY" -eq 0 ] && echo "(dry-run complete — re-run with --apply after approval)"
exit 0
#+END_SRC

# all/.mk/guix.mk
ifndef GUIX_MK_INCLUDED
GUIX_MK_INCLUDED := 1

.RECIPEPREFIX := |
SHELL := /bin/bash
.ONESHELL:

GUIX ?= guix
GUIX_HOME := $(HOME)/.config/guix
EXTRA := $(HOME)/.guix-extra-profiles
LOCAL_PKGS := $(HOME)/.config/guix/local-packages
BENCH_DIR := $(GUIX_HOME)/.bench
PULL_CACHE := $(BENCH_DIR)/pull-url
FALLBACK_PULL_URLS ?= https://git.cbaines.net/guix/guix https://codeberg.org/guix/guix.git https://git.savannah.gnu.org/git/guix.git

.PHONY: guix-dirs guix-pull-bench guix-pull guix-core guix-dev guix-gc guix-nonguix guix-desktop-common guix-sanctuary-qtile guix-sanctuary-gnustep guix-sanctuary-cde guix-sanctuary-sx guix-room-gaming guix-room-windows-compat

guix-dirs:
| @chmod +x $(HOME)/.local/bin/guix-mkdirs 2>/dev/null || true
| @$(HOME)/.local/bin/guix-mkdirs
| @mkdir -p $(BENCH_DIR)
# 1) BENCH → writes cache, prints URL (LOUD)
guix-pull-bench: guix-dirs
| set -Eeuo pipefail; \
| BENCH="$(HOME)/DotCortex/all/.local/bin/guix-bench-pull"; \
| [ -x "$$BENCH" ] || { echo "guix-bench-pull not found/executable" >&2; exit 1; }; \
| URL="$$( "$$BENCH" )" || URL=""; \
| if [ -z "$$URL" ]; then echo "No URL found by bench" >&2; exit 1; fi; \
| echo "$$URL" >"$(PULL_CACHE)"; \
| echo "cached: $(PULL_CACHE) → $$URL"; \
| echo "$$URL"

# 2) PULL → uses cached URL if present; NEVER re-bench
guix-pull: guix-dirs
| set -Eeuo pipefail; \
| URL=""; [ -r "$(PULL_CACHE)" ] && URL="$$(tr -d '\r\n' <"$(PULL_CACHE)")"; \
| tried=0; \
| success=0; \
| choose_and_pull() { \
|   u="$$1"; \
|   [ -z "$$u" ] && return 1; \
|   tried=1; \
|   echo "guix pull --url=$$u (cached/fallback)"; \
|   if $(GUIX) pull --url="$$u"; then \
|     success=1; \
|     printf '%s\n' "$$u" >"$(PULL_CACHE)";  # <-- promote last success to cache
|     return 0; \
|   else \
|     return 1; \
|   fi; \
| }; \
| # 1) try cached (if present)
| if [ -n "$$URL" ]; then \
|   choose_and_pull "$$URL" || echo "cached URL failed → trying fallbacks…"; \
| fi; \
| # 2) try fallbacks (skip if equal to cached)
| if [ "$$success" -eq 0 ]; then \
|   for fb in $(FALLBACK_PULL_URLS); do \
|     [ "$$fb" = "$$URL" ] && continue; \
|     if choose_and_pull "$$fb"; then break; fi; \
|   done; \
| fi; \
| # 3) final fallback: plain `guix pull` (no mirror override)
| if [ "$$success" -eq 0 ]; then \
|   if [ "$$tried" -eq 1 ]; then echo "all mirrors failed → falling back to plain 'guix pull'"; else echo "guix pull (no cache present)"; fi; \
|   $(GUIX) pull; \
| fi

** Bench fastest Guix channel mirror
#+BEGIN_SRC bash :tangle all/.local/bin/guix-bench-pull :shebang "#!/usr/bin/env bash" :tangle-mode (identity #o755) :mkdirp yes
#!/usr/bin/env bash
# all/.local/bin/guix-bench-pull
set -Eeuo pipefail

BENCH_DIR="${XDG_CONFIG_HOME:-$HOME/.config}/guix/.bench"
CACHE="${BENCH_DIR}/pull-url"
BL="${BENCH_DIR}/pull-blacklist"
SSV="${XDG_CONFIG_HOME:-$HOME/.config}/guix/pull-candidates.ssv"

mkdir -p "$BENCH_DIR"; touch "$BL"

urls_from_ssv() {
  [[ -r "$SSV" ]] || return 1
  awk '
    BEGIN{IGNORECASE=1}
    /^[[:space:]]*#/ {next}           # comments
    NF==0 {next}                      # blank lines
    NR==1 && $1 ~ /^url$/ {next}      # optional header row
    {print $1}                        # first column is the URL
  ' "$SSV"
}

declare -a CANDS=()
if [[ -n "${GUIX_PULL_CANDIDATES:-}" ]]; then
  # space-separated URLs override SSV
  read -r -a CANDS <<< "$GUIX_PULL_CANDIDATES"
else
  mapfile -t CANDS < <(urls_from_ssv || true)
  # final fallback if SSV missing/empty
  if [[ ${#CANDS[@]} -eq 0 ]]; then
    CANDS=( "https://codeberg.org/guix/guix.git"
            "https://git.cbaines.net/guix/guix"
            "https://git.savannah.gnu.org/git/guix.git"
            "https://mirror.git.savannah.gnu.org/r/guix.git" )
  fi
fi

have_git=0; command -v git >/dev/null 2>&1 && have_git=1

probe_git() { # url -> seconds
  local u="$1"
  local t
  t="$( TIMEFORMAT=%R; { time git ls-remote --heads --tags --refs --timeout=12 "$u" >/dev/null 2>&1; } 2>&1 )" || return 1
  printf '%s\n' "$t"
}
probe_tcp() { # host:443 reachable?
  timeout 4 bash -lc "exec 3<>/dev/tcp/$1/443" 2>/dev/null
}

rows=()
for u in "${CANDS[@]}"; do
  grep -qxF "$u" "$BL" && continue
  host="$(sed -n 's#https\?://\([^/]*\).*#\1#p' <<<"$u")"
  probe_tcp "$host" || continue
  t=""
  if [[ $have_git -eq 1 ]]; then
    t="$(probe_git "$u" || true)"
  fi
  [[ -z "$t" ]] && continue
  rows+=("$t $u")
done

# choose the fastest
best="$(printf '%s\n' "${rows[@]}" | sort -n | awk 'NR==1{print $2}')"

if [[ -z "${best:-}" ]]; then
  echo "no-viable-mirror" >&2
  exit 2
fi

printf '%s\n' "$best"
#+END_SRC

** System Python override — Guix python3 must not shadow the distro
On Debian-family machines the Guix core profile ships =python3=, and the profile
bin dir sits in PATH ahead of =/usr/bin=. Every =#!/usr/bin/env python3= shebang
in distro tooling (e.g. Vendefoul Wolf's =gksu= at =/usr/local/bin/gksu=) then
resolves to Guix Python — which lacks =_tkinter= and whose =GUIX_PYTHONPATH=
site-packages routinely drift out of sync with the interpreter version. Result:
distro GUI tools crash with =ModuleNotFoundError=.

=~/.local/bin= is ordered ahead of the Guix profile bin in PATH (see
=shell.org=), so this wrapper makes =python3= resolve to the distro interpreter
for shells, =env=-shebangs, and GUI-launched subprocesses alike. Guix-built
applications are unaffected — they reference their interpreter by absolute
=/gnu/store/...= path, never through PATH. Guix Python stays reachable
explicitly at =~/.guix-extra-profiles/core/core/bin/python3=.

Scoped to =debian/= because it assumes =/usr/bin/python3= exists.

#+BEGIN_SRC sh :tangle debian/.local/bin/python3 :shebang "#!/bin/sh" :mkdirp yes
exec /usr/bin/python3 "$@"
#+END_SRC

* Notes
- Guix Home is intentionally not enabled here, since you use literate dotfiles as the source of truth. We keep Guix focused on packages and profiles.
- If you ever add =nonguix=, you must explicitly authorize its substitute key. Keep that ritual documented alongside the channels pin.
- Guix can install many tools that overlap with apt, snaps, or flatpaks. Prefer one source per tool to reduce path ambiguity.
