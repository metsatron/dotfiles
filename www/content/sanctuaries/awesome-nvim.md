The mirror image of [the Emacs sanctuary](/sanctuaries/emacs/): where that space is Lisp all the way down, this one is Lua. AwesomeWM as the window manager — configured in Lua, with its own widget system — and Neovim as the central IDE surface, with Telescope for navigation, a proper git porcelain, and file browsing that lives in the terminal where it belongs.

The law that keeps it honest: Guix owns the binaries — Neovim, the terminal, every language server — and DotCortex tangles the configuration. No Mason pulling binaries from the network, no config islands outside the tangle. The same declared-and-reproducible doctrine as everything else in the habitat, expressed in a different tongue.

Two editors, two sanctuaries, deliberately not merged. Emacs and Neovim are both right, about different things, and each deserves a space built around its own grain rather than a compromise desktop that serves neither. Screenshots when it breathes.
