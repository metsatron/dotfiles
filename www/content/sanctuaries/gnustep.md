Window Maker and GNUstep: the NeXT lineage as a living free-software environment rather than an archaeology project. Black title bars, tiles and dockapps, Objective-C where Objective-C belongs — with modern package management underneath, because the whole sanctuary is declared in Guix and tangled from DotCortex like everything else.

Window Maker proves the grammar; GWorkspace speaks the sentence — the Workspace Manager built from source inside the room, since Guix carries the frameworks' toolchain but not the frameworks themselves. [NEXTSPACE](https://github.com/trunkmaster/nextspace) remains on the horizon as a bounded experiment (ruled 2026-07-31): its Workspace application turns out to *be* a window manager — a modified Window Maker beats inside it — so if it ever arrives here it arrives as a whole alternative session, not a layer on this one. And the icon layer is non-negotiable: the original NeXTSTEP isometric icons, the ones that taught a generation what depth on a screen could mean.

This sanctuary earns its keep as the pathfinder: once it proves the pattern, the real artefacts arrive as historical enclaves — NeXTSTEP 3.3 and OPENSTEP 4.2, the actual operating systems on virtual hardware. The sanctuary is where the NeXT grammar gets lived in daily; the enclaves are where the originals get preserved.

It breathes:

![GNUstep Sanctuary — Window Maker + GNUstep, the NeXTSTEP grammar on a modern GNU system](/img/sanctuaries/gnustep/nextstep-grammar.png)

Black focused titlebars, the `#555577` workspace, the right-edge dock with the Guix dockapp roster running, and GWorkspace holding the desktop. Window Maker's compiled `next` caption style — the geometry and glyphs that match the NeXT-era reference. The icon layer is the original NeXTSTEP isometric set: period-correct substitutions, not approximations. The whole room rebuilds from DotCortex source, no hand-installed steps.
