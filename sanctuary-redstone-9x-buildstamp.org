* Desktop build stamp

Redstone's lower-right development-build watermark has two deliberately separate
state layers:

- =~/.local/share/redstone-9x/build.ini= is the persistent deployed identity.  It
  records =Mineshaft Redstone 9X=, the committing date of the deployed DotCortex
  revision, its seven-character commit, and the resulting =YYMMDD.COMMIT=
  identifier.  Login never changes it merely because the wall clock advanced.
- =$XDG_RUNTIME_DIR/dotcortex/redstone-9x/buildstamp.{txt,pid,state,command}=
  belongs only to the running renderer.  The PID file records the product and
  details renderers separately; each is paired with its process start time and
  executable so stop/refresh cannot signal a reused or unrelated PID.

=redstone-buildstamp-generate= refreshes the persistent metadata from a real
DotCortex checkout.  If the checkout is unavailable it preserves an existing
deployed file, so the guest does not need =.git= at display time.  The launcher
and live refresh helper invoke it at deployment boundaries; =osd_cat= never runs
Git commands.

The renderer remains XOSD.  Two coordinated one-line =osd_cat= processes are
used because XOSD cannot mix bold and normal faces inside one OSD.  Both use the
same right margin: the bold product line sits immediately above the normal
=Build IDENTIFIER  SCHEME= line, while =buildstamp.txt= remains the exact
two-line logical stamp shown by the command surface.  Redstone's room-local
=xosd-redstone= Guix variant
keeps XOSD's override-redirect shaped root child, removes its always-on-top call,
maps without raising, then locates PCManFM through =_NET_CLIENT_LIST_STACKING= and
=_NET_WM_WINDOW_TYPE_DESKTOP=.  It ascends that managed client to its root-level
IceWM frame and stacks the stamp immediately above that sibling.  Root property
and structure events re-resolve this relation after window restacks or PCManFM
replacement.  IceWM does not manage the stamp; its diagnostic WM_CLASS is not a
winoptions contract.  The empty input shape makes every glyph click-through.

The rejected initial experiment made the shaped XOSD client managed and assigned
it IceWM's Below layer.  The client bitmap remained valid, but IceWM's reparented
frame did not expose the shaped pixels even at AboveAll.  Supporting that route
would require XOSD to synchronize MapRequest, reparent and frame-shape state, so
the smaller root-sibling implementation is the supported initial renderer.  The
stable wrapper surface still permits a future renderer replacement without
changing startup or Desktop Scheme integration.

** Persistent build metadata generator

#+BEGIN_SRC bash :tangle linux/.local/bin/redstone-buildstamp-generate :shebang "#!/bin/bash" :tangle-mode (identity #o755)
set -euo pipefail

repo="${DOTCORTEX_ROOT:-${HOME}/DotCortex}"
output="${XDG_DATA_HOME:-${HOME}/.local/share}/redstone-9x/build.ini"

usage() {
  cat <<'EOF'
redstone-buildstamp-generate - generate persistent Redstone build identity

Usage: redstone-buildstamp-generate [--repo PATH] [--output FILE]

The date is the deployed DotCortex commit date (YYMMDD), not login time. The
commit is abbreviated to seven characters. Tracked development dirt appends
+dirty; clean generated builds carry no suffix.
EOF
}

while (( $# )); do
  case "$1" in
    --repo)
      [[ $# -ge 2 ]] || { echo "redstone-buildstamp-generate: --repo needs a path" >&2; exit 2; }
      repo="$2"; shift 2
      ;;
    --output)
      [[ $# -ge 2 ]] || { echo "redstone-buildstamp-generate: --output needs a file" >&2; exit 2; }
      output="$2"; shift 2
      ;;
    -h|--help) usage; exit 0 ;;
    *) echo "redstone-buildstamp-generate: unknown option: $1" >&2; usage >&2; exit 2 ;;
  esac
done

if [[ ! -d "${repo}/.git" ]] || ! command -v git >/dev/null 2>&1; then
  if [[ -s "${output}" ]]; then
    printf 'redstone-buildstamp-generate: preserving deployed metadata: %s\n' "${output}"
    exit 0
  fi
  echo "redstone-buildstamp-generate: DotCortex Git checkout unavailable: ${repo}" >&2
  exit 1
fi

commit="$(git -C "${repo}" rev-parse --short=7 HEAD)"
build_date="$(git -C "${repo}" show -s --format=%cd --date=format:%y%m%d HEAD)"
dirty=""
if ! git -C "${repo}" diff --quiet --ignore-submodules -- \
   || ! git -C "${repo}" diff --cached --quiet --ignore-submodules --; then
  dirty="+dirty"
fi
identifier="${build_date}.${commit}${dirty}"

mkdir -p "$(dirname "${output}")"
tmp="$(mktemp "${output}.tmp.XXXXXX")"
trap 'rm -f -- "${tmp}"' EXIT
cat >"${tmp}" <<EOF
[Build]
product=Mineshaft Redstone 9X
date=${build_date}
commit=${commit}
identifier=${identifier}
EOF
chmod 0644 "${tmp}"
mv -f -- "${tmp}" "${output}"
trap - EXIT
printf 'redstone-buildstamp-generate: %s -> %s\n' "${identifier}" "${output}"
#+END_SRC

** Stable renderer wrapper

#+BEGIN_SRC bash :tangle linux/.local/bin/redstone-buildstamp :shebang "#!/bin/bash" :tangle-mode (identity #o755)
set -euo pipefail

product_default="Mineshaft Redstone 9X"
config_home="${XDG_CONFIG_HOME:-${HOME}/.config}"
data_home="${XDG_DATA_HOME:-${HOME}/.local/share}"
cache_home="${XDG_CACHE_HOME:-${HOME}/.cache}"
runtime_root="${XDG_RUNTIME_DIR:-${TMPDIR:-/tmp}}/dotcortex/redstone-9x"
metadata_file="${data_home}/redstone-9x/build.ini"
defaults_file="${config_home}/redstone-9x/buildstamp.conf"
local_file="${config_home}/redstone-9x/buildstamp.local"
scheme_state="${config_home}/redstone-9x/scheme"
scheme_dir="${config_home}/redstone-9x/schemes"
text_file="${runtime_root}/buildstamp.txt"
product_text_file="${runtime_root}/buildstamp.product.txt"
detail_text_file="${runtime_root}/buildstamp.details.txt"
pid_file="${runtime_root}/buildstamp.pid"
state_file="${runtime_root}/buildstamp.state"
command_file="${runtime_root}/buildstamp.command"
log_file="${cache_home}/redstone-9x/buildstamp.log"

usage() {
  cat <<'EOF'
Usage: redstone-buildstamp {start|refresh|stop|show|status}

  start    generate two-line runtime text and start both renderers if needed
  refresh  reread identity/theme/style and restart both recorded renderers
  stop     stop only the two validated recorded renderers and remove runtime state
  show     print the exact two-line product/build+theme text without launching XOSD
  status   report both processes, theme, build, display, files, and commands
EOF
}

warn() {
  mkdir -p "$(dirname "${log_file}")"
  printf 'redstone-buildstamp: %s\n' "$*" | tee -a "${log_file}" >&2
}

ini_value() {
  local key="$1"
  [[ -f "${metadata_file}" ]] || return 0
  awk -F= -v wanted="${key}" '
    /^\[Build\]$/ { in_build=1; next }
    /^\[/ { in_build=0 }
    in_build && $1 == wanted { sub(/^[^=]*=/, ""); print; exit }
  ' "${metadata_file}"
}

load_identity() {
  PRODUCT="$(ini_value product)"
  BUILD_ID="$(ini_value identifier)"
  BUILD_COMMIT="$(ini_value commit)"
  [[ -n "${PRODUCT}" ]] || PRODUCT="${product_default}"
  [[ -n "${BUILD_ID}" ]] || BUILD_ID="${BUILD_COMMIT:-unknown}"

  SCHEME_ID="$(cat "${scheme_state}" 2>/dev/null || printf 'windows-95')"
  SCHEME_FILE="${scheme_dir}/${SCHEME_ID}.scheme"
  SCHEME_TITLE=""

  BUILDSTAMP_ENABLED=1
  BUILDSTAMP_PRODUCT_FONT="-misc-fixed-bold-r-normal--12-*-*-*-c-*-iso10646-1"
  BUILDSTAMP_PRODUCT_FONT_SIZE=12
  BUILDSTAMP_DETAIL_FONT="-misc-fixed-medium-r-normal--12-*-*-*-c-*-iso10646-1"
  BUILDSTAMP_DETAIL_FONT_SIZE=12
  BUILDSTAMP_LINE_GAP=2
  BUILDSTAMP_FOREGROUND="#ffffff"
  BUILDSTAMP_SHADOW="#000000"
  BUILDSTAMP_SHADOW_OFFSET=1
  BUILDSTAMP_RIGHT_MARGIN=14
  BUILDSTAMP_BOTTOM_MARGIN=12

  # shellcheck disable=SC1090
  [[ -r "${defaults_file}" ]] && . "${defaults_file}"
  # Existing Desktop Scheme declarations are trusted shell assignments.
  # shellcheck disable=SC1090
  [[ -r "${SCHEME_FILE}" ]] && . "${SCHEME_FILE}"
  # Private user override is sourced last and never belongs to DotCortex.
  # shellcheck disable=SC1090
  [[ -r "${local_file}" ]] && . "${local_file}"

  [[ -n "${SCHEME_TITLE}" ]] || SCHEME_TITLE="${SCHEME_ID:-Unknown Theme}"
  [[ -n "${SCHEME_TITLE}" ]] || SCHEME_TITLE="Unknown Theme"
}

compose_text() {
  printf '%s\nBuild %s  %s\n' "${PRODUCT}" "${BUILD_ID}" "${SCHEME_TITLE}"
}

resolve_display() {
  REDSTONE_DISPLAY="${DISPLAY:-:93}"
  case "${REDSTONE_DISPLAY}" in
    :93|:93.0) ;;
    *) warn "refusing non-Redstone display ${REDSTONE_DISPLAY}"; return 1 ;;
  esac
  export DISPLAY="${REDSTONE_DISPLAY}"
}

render_text() {
  mkdir -p "${runtime_root}"
  local tmp product_tmp detail_tmp
  tmp="$(mktemp "${text_file}.tmp.XXXXXX")"
  product_tmp="$(mktemp "${product_text_file}.tmp.XXXXXX")"
  detail_tmp="$(mktemp "${detail_text_file}.tmp.XXXXXX")"
  compose_text >"${tmp}"
  sed -n '1p' "${tmp}" >"${product_tmp}"
  sed -n '2p' "${tmp}" >"${detail_tmp}"
  if [[ "$(wc -l <"${tmp}")" -ne 2 || "$(wc -l <"${product_tmp}")" -ne 1 \
        || "$(wc -l <"${detail_tmp}")" -ne 1 ]]; then
    rm -f -- "${tmp}" "${product_tmp}" "${detail_tmp}"
    warn "internal error: build stamp must contain exactly two physical lines"
    return 1
  fi
  chmod 0600 "${tmp}" "${product_tmp}" "${detail_tmp}"
  mv -f -- "${tmp}" "${text_file}"
  mv -f -- "${product_tmp}" "${product_text_file}"
  mv -f -- "${detail_tmp}" "${detail_text_file}"
}

renderer_path() {
  command -v osd_cat 2>/dev/null || true
}

font_for_xosd() {
  local role="$1" candidate size weight fallback
  if [[ "${role}" == product ]]; then
    candidate="${BUILDSTAMP_PRODUCT_FONT}"
    size="${BUILDSTAMP_PRODUCT_FONT_SIZE}"
    weight="bold"
    fallback="-misc-fixed-bold-r-normal--12-*-*-*-c-*-iso10646-1"
  else
    candidate="${BUILDSTAMP_DETAIL_FONT}"
    size="${BUILDSTAMP_DETAIL_FONT_SIZE}"
    weight="medium"
    fallback="-misc-fixed-medium-r-normal--12-*-*-*-c-*-iso10646-1"
  fi
  if [[ "${candidate}" != -* ]]; then
    candidate="-*-${candidate// /-}-${weight}-r-normal--${size}-*-*-*-*-*-iso10646-1"
  fi
  if command -v xlsfonts >/dev/null 2>&1 \
     && ! xlsfonts "${candidate}" 2>/dev/null | grep -q .; then
    candidate="${fallback}"
  fi
  printf '%s\n' "${candidate}"
}

bottom_offset() {
  local offset="${BUILDSTAMP_BOTTOM_MARGIN}" dims height workarea wy wh reserved
  if command -v xdpyinfo >/dev/null 2>&1 && command -v xprop >/dev/null 2>&1; then
    dims="$(xdpyinfo 2>/dev/null | awk '/dimensions:/ { print $2; exit }')"
    height="${dims#*x}"
    workarea="$(xprop -root _NET_WORKAREA 2>/dev/null | sed 's/^[^=]*= *//' | cut -d, -f1-4)"
    if [[ "${height}" =~ ^[0-9]+$ && -n "${workarea}" ]]; then
      IFS=, read -r _wx wy _ww wh <<< "${workarea// /}"
      if [[ "${wy}" =~ ^[0-9]+$ && "${wh}" =~ ^[0-9]+$ ]]; then
        reserved=$(( height - wy - wh ))
        (( reserved > 0 )) && offset=$(( reserved + BUILDSTAMP_BOTTOM_MARGIN ))
      fi
    fi
  fi
  printf '%s\n' "${offset}"
}

process_starttime() {
  awk '{ print $22 }' "/proc/$1/stat" 2>/dev/null
}

read_recorded_state() {
  PRODUCT_PID=""
  PRODUCT_START=""
  PRODUCT_EXE=""
  DETAIL_PID=""
  DETAIL_START=""
  DETAIL_EXE=""
  RECORDED_DISPLAY=""
  LEGACY_PID=""
  LEGACY_START=""
  LEGACY_EXE=""
  if [[ -r "${pid_file}" ]]; then
    if [[ "$(cat "${pid_file}")" =~ ^[0-9]+$ ]]; then
      LEGACY_PID="$(cat "${pid_file}")"
    else
      while IFS='=' read -r key value; do
        case "${key}" in
          product) PRODUCT_PID="${value}" ;;
          details) DETAIL_PID="${value}" ;;
        esac
      done <"${pid_file}"
    fi
  fi
  if [[ -r "${state_file}" ]]; then
    while IFS='=' read -r key value; do
      case "${key}" in
        product_starttime) PRODUCT_START="${value}" ;;
        product_executable) PRODUCT_EXE="${value}" ;;
        details_starttime) DETAIL_START="${value}" ;;
        details_executable) DETAIL_EXE="${value}" ;;
        display) RECORDED_DISPLAY="${value}" ;;
        starttime) LEGACY_START="${value}" ;;
        executable) LEGACY_EXE="${value}" ;;
      esac
    done < "${state_file}"
  fi
}

process_is_ours() {
  local pid="$1" start="$2" executable="$3"
  [[ "${pid}" =~ ^[0-9]+$ ]] || return 1
  kill -0 "${pid}" 2>/dev/null || return 1
  [[ -n "${start}" && "$(process_starttime "${pid}")" == "${start}" ]] || return 1
  [[ -n "${executable}" \
     && "$(readlink -f "/proc/${pid}/exe" 2>/dev/null || true)" == "${executable}" ]] || return 1
  return 0
}

recorded_pair_is_ours() {
  read_recorded_state
  process_is_ours "${PRODUCT_PID}" "${PRODUCT_START}" "${PRODUCT_EXE}" \
    && process_is_ours "${DETAIL_PID}" "${DETAIL_START}" "${DETAIL_EXE}"
}

remove_process_state() {
  rm -f -- "${pid_file}" "${state_file}" "${command_file}"
}

remove_runtime_state() {
  remove_process_state
  rm -f -- "${text_file}" "${product_text_file}" "${detail_text_file}"
}

terminate_pid() {
  local pid="$1"
  [[ "${pid}" =~ ^[0-9]+$ ]] || return 0
  kill "${pid}" 2>/dev/null || true
  for _attempt in {1..20}; do
    kill -0 "${pid}" 2>/dev/null || break
    sleep 0.1
  done
  if kill -0 "${pid}" 2>/dev/null; then
    kill -KILL "${pid}" 2>/dev/null || true
  fi
}

stop_renderer() {
  read_recorded_state
  if process_is_ours "${PRODUCT_PID}" "${PRODUCT_START}" "${PRODUCT_EXE}"; then
    terminate_pid "${PRODUCT_PID}"
  fi
  if process_is_ours "${DETAIL_PID}" "${DETAIL_START}" "${DETAIL_EXE}"; then
    terminate_pid "${DETAIL_PID}"
  fi
  # One-time migration from the original single-process state format.
  if process_is_ours "${LEGACY_PID}" "${LEGACY_START}" "${LEGACY_EXE}"; then
    terminate_pid "${LEGACY_PID}"
  fi
  remove_runtime_state
}

validate_detail_width() {
  local font="$1" dims screen_width resolved average_width char_width estimate available
  dims="$(xdpyinfo 2>/dev/null | awk '/dimensions:/ { print $2; exit }')"
  screen_width="${dims%x*}"
  resolved="$(xlsfonts "${font}" 2>/dev/null | head -n 1 || true)"
  average_width="$(awk -F- '{ print $13 }' <<<"${resolved}")"
  [[ "${screen_width}" =~ ^[0-9]+$ ]] || return 0
  if [[ "${average_width}" =~ ^[0-9]+$ && "${average_width}" -gt 0 ]]; then
    char_width=$(( (average_width + 9) / 10 ))
  else
    char_width=$(( (BUILDSTAMP_DETAIL_FONT_SIZE * 3 + 3) / 5 ))
  fi
  estimate=$(( ${#DETAIL_TEXT} * char_width + BUILDSTAMP_SHADOW_OFFSET + 2 ))
  available=$(( screen_width - BUILDSTAMP_RIGHT_MARGIN ))
  if (( estimate > available )); then
    warn "details line is ${estimate}px wide but only ${available}px is available"
    return 1
  fi
}

start_renderer() {
  load_identity
  if [[ "${BUILDSTAMP_ENABLED}" != 1 ]]; then
    stop_renderer
    return 0
  fi
  resolve_display || return 1
  render_text || return 1
  if recorded_pair_is_ours; then
    printf 'redstone-buildstamp: already running (product=%s details=%s)\n' \
      "${PRODUCT_PID}" "${DETAIL_PID}"
    return 0
  fi
  # If only one half survived, stop that exact validated PID before replacing
  # the pair.  Never allow a half-stamp to survive a recovery or refresh.
  stop_renderer
  render_text || return 1
  # Preserve the freshly rendered text while discarding only stale process
  # ownership records before launching its two readers.
  remove_process_state

  local renderer product_font detail_font detail_offset product_offset
  local product_pid detail_pid product_exe detail_exe
  local -a product_args detail_args
  renderer="$(renderer_path)"
  if [[ -z "${renderer}" ]]; then
    warn "osd_cat is unavailable; desktop startup continues without a stamp"
    return 0
  fi
  if ! command -v xdpyinfo >/dev/null 2>&1 || ! xdpyinfo >/dev/null 2>&1; then
    warn "Redstone display ${DISPLAY} is unavailable"
    return 0
  fi
  product_font="$(font_for_xosd product)"
  detail_font="$(font_for_xosd details)"
  DETAIL_TEXT="$(cat "${detail_text_file}")"
  validate_detail_width "${detail_font}" || {
    remove_runtime_state
    return 0
  }
  detail_offset="$(bottom_offset)"
  # XOSD's shaped window includes one shadow extent on both vertical edges.
  # Add that measured glyph-window height to the configured inter-line gap.
  product_offset=$(( detail_offset + BUILDSTAMP_DETAIL_FONT_SIZE \
                     + (2 * BUILDSTAMP_SHADOW_OFFSET) + BUILDSTAMP_LINE_GAP ))
  detail_args=(
    --pos=bottom
    --align=right
    "--offset=${detail_offset}"
    "--indent=${BUILDSTAMP_RIGHT_MARGIN}"
    "--font=${detail_font}"
    "--colour=${BUILDSTAMP_FOREGROUND}"
    "--shadow=${BUILDSTAMP_SHADOW_OFFSET}"
    "--shadowcolour=${BUILDSTAMP_SHADOW}"
    --lines=1
    --delay=0
  )
  product_args=(
    --pos=bottom
    --align=right
    "--offset=${product_offset}"
    "--indent=${BUILDSTAMP_RIGHT_MARGIN}"
    "--font=${product_font}"
    "--colour=${BUILDSTAMP_FOREGROUND}"
    "--shadow=${BUILDSTAMP_SHADOW_OFFSET}"
    "--shadowcolour=${BUILDSTAMP_SHADOW}"
    --lines=1
    --delay=0
  )
  mkdir -p "$(dirname "${log_file}")"
  "${renderer}" "${detail_args[@]}" <"${detail_text_file}" >>"${log_file}" 2>&1 &
  detail_pid=$!
  "${renderer}" "${product_args[@]}" <"${product_text_file}" >>"${log_file}" 2>&1 &
  product_pid=$!
  sleep 0.1
  if ! kill -0 "${product_pid}" 2>/dev/null || ! kill -0 "${detail_pid}" 2>/dev/null; then
    terminate_pid "${product_pid}"
    terminate_pid "${detail_pid}"
    warn "one renderer exited during startup; no half-stamp was retained"
    remove_runtime_state
    return 0
  fi
  product_exe="$(readlink -f "/proc/${product_pid}/exe")"
  detail_exe="$(readlink -f "/proc/${detail_pid}/exe")"
  {
    printf 'product=%s\n' "${product_pid}"
    printf 'details=%s\n' "${detail_pid}"
  } >"${pid_file}"
  {
    printf 'product_starttime=%s\n' "$(process_starttime "${product_pid}")"
    printf 'product_executable=%s\n' "${product_exe}"
    printf 'details_starttime=%s\n' "$(process_starttime "${detail_pid}")"
    printf 'details_executable=%s\n' "${detail_exe}"
    printf 'display=%s\n' "${DISPLAY}"
  } >"${state_file}"
  {
    printf 'product: DISPLAY=%q ' "${DISPLAY}"
    printf '%q ' "${renderer}" "${product_args[@]}"
    printf '< %q\n' "${product_text_file}"
    printf 'details: DISPLAY=%q ' "${DISPLAY}"
    printf '%q ' "${renderer}" "${detail_args[@]}"
    printf '< %q\n' "${detail_text_file}"
  } >"${command_file}"
  chmod 0600 "${pid_file}" "${state_file}" "${command_file}"
  # Revalidate after recording ownership so a process dying in this narrow
  # interval cannot leave a durable one-sided state.
  if ! recorded_pair_is_ours; then
    stop_renderer
    warn "renderer pair did not survive ownership validation"
    return 0
  fi
  printf 'redstone-buildstamp: started (product=%s details=%s)\n' \
    "${product_pid}" "${detail_pid}"
}

show_status() {
  load_identity
  resolve_display >/dev/null 2>&1 || REDSTONE_DISPLAY="${DISPLAY:-unknown}"
  if recorded_pair_is_ours; then
    running="running"
    product_pid="${PRODUCT_PID}"
    detail_pid="${DETAIL_PID}"
  else
    running="stopped"
    product_pid="-"
    detail_pid="-"
    stop_renderer
  fi
  printf 'State: %s\n' "${running}"
  printf 'Product PID: %s\n' "${product_pid}"
  printf 'Details PID: %s\n' "${detail_pid}"
  printf 'Active theme: %s\n' "${SCHEME_TITLE}"
  printf 'Build identity: %s\n' "${BUILD_ID}"
  printf 'Display: %s\n' "${REDSTONE_DISPLAY}"
  printf 'Metadata: %s\n' "${metadata_file}"
  printf 'Runtime text: %s\n' "${text_file}"
  if [[ -r "${command_file}" ]]; then
    while IFS= read -r renderer_command; do
      printf 'Renderer command: %s\n' "${renderer_command}"
    done <"${command_file}"
  else
    printf 'Renderer command: %s\n' "$(renderer_path)"
  fi
}

case "${1:-}" in
  start) start_renderer ;;
  refresh)
    load_identity
    if [[ "${BUILDSTAMP_ENABLED}" != 1 ]]; then
      stop_renderer
    else
      stop_renderer
      start_renderer
    fi
    ;;
  stop) stop_renderer ;;
  show) load_identity; compose_text ;;
  status) show_status ;;
  -h|--help) usage ;;
  *) usage >&2; exit 2 ;;
esac
#+END_SRC

** Manual verification

After tangling, applying =room-gaming= and relaunching Redstone:

#+BEGIN_EXAMPLE
redstone-buildstamp show
redstone-buildstamp start
redstone-buildstamp start      # same two PIDs; no duplicate
redstone-buildstamp status
redstone-buildstamp refresh    # only the two recorded stamp PIDs change
redstone-buildstamp stop
#+END_EXAMPLE

Inspect the live X11 boundary with =xprop= and =xwininfo -root -tree=.  Both
one-line windows must be direct override-redirect root children named
=Redstone Build Stamp= and classed
=redstone-buildstamp/RedstoneBuildstamp=.  Each root-stack predecessor must be
PCManFM's resolved root-level IceWM frame (or the other stamp window immediately
above that frame), and ordinary application frames must follow both.
=ShapeBounding= must contain the glyphs while =ShapeInput= is empty on each
window; a click on either visible line must therefore reach PCManFM.  Raising,
minimizing and closing normal windows, clicking the desktop, changing screen
geometry, and restarting PCManFM must preserve or safely reconstruct the sibling
relation.  A maximized normal application must cover both lines.  Runtime files
must remain untracked and a normal session must leave the DotCortex tree clean.

Per-theme style keys use the existing shell-sourceable scheme schema:
=BUILDSTAMP_ENABLED=, =BUILDSTAMP_PRODUCT_FONT=,
=BUILDSTAMP_PRODUCT_FONT_SIZE=, =BUILDSTAMP_DETAIL_FONT=,
=BUILDSTAMP_DETAIL_FONT_SIZE=, =BUILDSTAMP_LINE_GAP=,
=BUILDSTAMP_FOREGROUND=, =BUILDSTAMP_SHADOW=,
=BUILDSTAMP_SHADOW_OFFSET=, =BUILDSTAMP_RIGHT_MARGIN=,
=BUILDSTAMP_BOTTOM_MARGIN=.  They alter only style and placement;
product/theme/build content and the two-line structure remain system-owned.
