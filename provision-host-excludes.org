* Why
The nala/flatpak/appimage lanes had no per-machine scoping — a single global manifest applied to every host, so a local uninstall on a headless box was undone by the next apply run. Only guix was natively per-profile. This file adds one small cross-lane exclude gate so a headless box (kikin-kushi) or a storage-squeezed laptop (t480/t480s) can drop GUI apps they don't use while the shared manifests stay intact for machines that do use them. Ordered by Mètsàtron 2026-08-20; reuses the =loom.org:174= hostname-gate shape (=host=$(hostname -s); case "$host" in ...=).

Default behaviour with no rows for a host is unchanged: nothing is excluded, every lane behaves exactly as it did before this file existed.

* Exclude data — SSV manifest
Columns: =HOST LANE ID NOTE=. =HOST= is the =hostname -s= value. =LANE= is one of =nala | flatpak | appimage | guix=. =ID= is the nala package name / flatpak app-id / appimage =APPIMG_NAME= / guix profile name. =NOTE= is a freeform reason and may contain spaces or quotes — it is never parsed, only =$1/$2/$3= matter. Comments (=#=) and blank lines are allowed. Deployed to =~/.provision/host-excludes.ssv=.

* Helper — host-excludes
One shared, lane-agnostic CLI on PATH. Every apply script sources/calls this instead of re-implementing the SSV parse. Reads =${HOST_EXCLUDES:-$HOME/.provision/host-excludes.ssv}= and =${HOST_EXCLUDES_HOSTNAME:-$(hostname -s)}=, both overridable by env for tests and for callers running against a different manifest.

Two forms:
- =host-excludes <lane> <id>= — exit 0 if the current host excludes that id in that lane, else exit 1.
- =host-excludes <lane>= (no id) — print the excluded ids for the current host+lane, one per line, exit 0 always.

A missing manifest file means nothing is excluded: the check form exits 1, the list form prints nothing and exits 0 — this is what keeps every lane byte-identical to pre-gate behaviour on a host with no rows.

#+BEGIN_SRC bash :tangle all/.local/bin/host-excludes :shebang "#!/usr/bin/env bash"
set -euo pipefail

FILE="${HOST_EXCLUDES:-$HOME/.provision/host-excludes.ssv}"
HOST="${HOST_EXCLUDES_HOSTNAME:-$(hostname -s)}"

usage() {
  cat <<EOF
Usage: host-excludes <lane> <id>   exit 0 if this host excludes id in lane, else 1
       host-excludes <lane>        print excluded ids for this host+lane, exit 0
Env:   HOST_EXCLUDES (manifest path, default \$HOME/.provision/host-excludes.ssv)
       HOST_EXCLUDES_HOSTNAME (host, default \$(hostname -s))
EOF
}

case "${1:-}" in
  -h|--help) usage; exit 0 ;;
  "") usage >&2; exit 2 ;;
esac

LANE="$1"
ID="${2:-}"

if [ ! -f "$FILE" ]; then
  if [ -n "$ID" ]; then
    exit 1
  fi
  exit 0
fi

if [ -n "$ID" ]; then
  awk -v host="$HOST" -v lane="$LANE" -v id="$ID" '
    /^[ \t]*#/ || NF==0 { next }
    $1==host && $2==lane && $3==id { found=1; exit }
    END { exit(found?0:1) }
  ' "$FILE"
else
  awk -v host="$HOST" -v lane="$LANE" '
    /^[ \t]*#/ || NF==0 { next }
    $1==host && $2==lane { print $3 }
  ' "$FILE"
fi
#+END_SRC

* Helper fixture tests
#+BEGIN_SRC bash :tangle all/.local/share/dotcortex/tests/host-excludes.sh :shebang "#!/usr/bin/env bash" :comments no
set -euo pipefail

ROOT="$(cd "$(dirname "$0")/../../../../.." && pwd)"
HELPER="$ROOT/all/.local/bin/host-excludes"

tmp="$(mktemp -d)"
trap 'rm -rf "$tmp"' EXIT

# --- Default-empty passthrough: missing manifest excludes nothing ---
missing="$tmp/missing.ssv"
if HOST_EXCLUDES="$missing" HOST_EXCLUDES_HOSTNAME=anyhost "$HELPER" nala gparted; then
  echo "missing-file check-form: expected exit 1 (not excluded), got 0" >&2
  exit 1
fi
out="$(HOST_EXCLUDES="$missing" HOST_EXCLUDES_HOSTNAME=anyhost "$HELPER" nala)"
if [ -n "$out" ]; then
  echo "missing-file list-form: expected empty output, got: $out" >&2
  exit 1
fi

# --- Fixture manifest ---
ssv="$tmp/host-excludes.ssv"
cat >"$ssv" <<'EOF'
# HOST LANE ID NOTE
kikin-kushi nala gparted "headless: no display"
kikin-kushi appimage Azahar "3DS emu won't run meaningfully"
kikin-kushi guix room-gaming "won't run heavy games on kikin"
EOF

# --- Host match + lane match + id match: excluded ---
if ! HOST_EXCLUDES="$ssv" HOST_EXCLUDES_HOSTNAME=kikin-kushi "$HELPER" nala gparted; then
  echo "exact match: expected exit 0 (excluded), got nonzero" >&2
  exit 1
fi
if ! HOST_EXCLUDES="$ssv" HOST_EXCLUDES_HOSTNAME=kikin-kushi "$HELPER" appimage Azahar; then
  echo "appimage match: expected exit 0 (excluded), got nonzero" >&2
  exit 1
fi
if ! HOST_EXCLUDES="$ssv" HOST_EXCLUDES_HOSTNAME=kikin-kushi "$HELPER" guix room-gaming; then
  echo "guix match: expected exit 0 (excluded), got nonzero" >&2
  exit 1
fi

# --- List-form for host+lane ---
out="$(HOST_EXCLUDES="$ssv" HOST_EXCLUDES_HOSTNAME=kikin-kushi "$HELPER" nala)"
[ "$out" = "gparted" ] || { echo "list-form: expected 'gparted', got: $out" >&2; exit 1; }

# --- Non-match: wrong host ---
if HOST_EXCLUDES="$ssv" HOST_EXCLUDES_HOSTNAME=t480 "$HELPER" nala gparted; then
  echo "wrong-host: expected exit 1 (not excluded), got 0" >&2
  exit 1
fi

# --- Non-match: wrong lane ---
if HOST_EXCLUDES="$ssv" HOST_EXCLUDES_HOSTNAME=kikin-kushi "$HELPER" appimage gparted; then
  echo "wrong-lane: expected exit 1 (not excluded), got 0" >&2
  exit 1
fi

# --- Non-match: wrong id ---
if HOST_EXCLUDES="$ssv" HOST_EXCLUDES_HOSTNAME=kikin-kushi "$HELPER" nala audacity; then
  echo "wrong-id: expected exit 1 (not excluded), got 0" >&2
  exit 1
fi

printf '%s\n' 'host-excludes fixtures: ok'
#+END_SRC
