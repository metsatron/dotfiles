* Why

Honey (hostname =beelink=) is Gillean's machine and runs her clinical stack. Mètsàtron wants three Telegram Claude bots there (=@honey_opus_bot=, =@honey_sonnet_bot=, =@honey_haiku_bot=) that work like the kikin ones: one append-only =claude-warm= session each, compacted in idle windows, so the prompt cache survives between turns. His ruling (2026-09-25, "Option A"): they run as the Unix user =metsatron=, not =gille=, so the clinical boundary is real file permissions (=metsatron= cannot enter =/home/gille= or read the Secret Vault), and they log in with Gillean's Claude account.

The kikin launchers (=HelmCortex/FORGE/bin/claude-{fable,opus,haiku}=) are bound to HelmCortex paths =metsatron= on Honey does not have, so this module ports their behaviour into the =honey/= host overlay:

- =honey/.local/bin/honey-{opus,sonnet,haiku}=: the launchers.
- =honey/.local/share/honey-claude/lib/=: the shared launcher library and the Telegram preflight (a port of kikin's =claude-telegram-preflight.bash=).
- =honey/.local/share/honey-claude/openrc/=: the three OpenRC services, *staged in the overlay*. Stow only links them into =$HOME=; installing them into =/etc/init.d= is a separate, reviewed root step (=install -m 755=), never a symlink into a user's home.
- =honey/.local/share/honey-claude/CLAUDE.boundary.md=: the Honey boundary law, copied into each bot's working directory =~/honey-work/<bot>/CLAUDE.md=.

The =honey= row in =hosts.ssv= is =active= for =metsatron= only ([[file:layers.org][layers.org]]); Gillean's row stays =planned=. Node comes from Honey's nala lane ([[file:package-nala-honey.org][package-nala-honey.org]]), =claude= and =bun= from metsatron's own npm lane ([[file:package-npm.org][package-npm.org]], "Account lane: metsatron on Honey").

* What differs from kikin

- *Always the Telegram bot.* The launchers keep kikin's =--telegram= switch, so a plain run is an interactive warm session in the same directory, but the services always pass =--telegram=.
- *No preservation guard bindings.* kikin's =claude-preservation.bash= binds =claude-warm= to the fleet preservation authority on kikin, which accounts for Mètsàtron's shared subscription. These bots use Gillean's account, a different pool, so the launchers leave every =CLAUDE_WARM_PRESERVATION_*= variable unset and =claude-warm= runs without that guard. Wiring Honey into the authority is a separate decision.
- *Herdr agent names are machine-prefixed and distinct from Honey's existing warm consort.* =/etc/init.d/claude-warm= (as =gille=) already registers as =honey-opus=, so the bots register as =honey-opus-bot=, =honey-sonnet-bot= and =honey-haiku-bot=.
- *A pid file.* Three =claude-warm= supervisors run under one account, so the OpenRC service cannot find "its" supervisor by command line. The launcher writes =$XDG_RUNTIME_DIR/<name>.pid= just before it =exec='s =claude-warm= (same pid), and each service owns its own =XDG_RUNTIME_DIR= (=/run/honey-<bot>=).

#+BEGIN_SRC bash :tangle honey/.local/share/honey-claude/lib/telegram-preflight.bash
# honey/.local/share/honey-claude/lib/telegram-preflight.bash (generated by agents-bots-honey.org)
# Port of kikin's FORGE/bin/lib/claude-telegram-preflight.bash for Honey.
#
# The official Telegram integration is not a daemon: the plugin's .mcp.json
# starts server.ts through Claude Code's MCP stdio client. This preflight
# validates that inline server and reserves the per-token state directory;
# it never daemonizes server.ts or starts an unrelated Telegram service.
# The token itself never lands in a path, a log or the environment.

honey_telegram_preflight() {
    local wrapper_name="${1:-}"
    local state_dir="${2:-}"
    local settings="${CLAUDE_SETTINGS_FILE:-$HOME/.claude/settings.json}"
    local plugin_cache="$HOME/.claude/plugins/cache/claude-plugins-official/telegram"
    local plugin_root="" candidate plugin_command pid pid_command pid_state_dir
    local runtime_root lock_path token_fingerprint

    if [[ ! "$wrapper_name" =~ ^honey-(opus|sonnet|haiku)$ ]]; then
        printf '%s\n' "honey Telegram launch refused: invalid wrapper identity" >&2
        return 1
    fi
    if [[ ! "$state_dir" =~ ^$HOME/\.claude/channels/[a-z0-9-]+$ ]]; then
        printf '%s\n' "$wrapper_name: Telegram launch refused: invalid channel state path" >&2
        return 1
    fi
    command -v jq >/dev/null 2>&1 || {
        printf '%s\n' "$wrapper_name: Telegram launch refused: jq is required for plugin preflight" >&2
        return 1
    }
    [[ -f "$settings" ]] || {
        printf '%s\n' "$wrapper_name: Telegram launch refused: settings are missing at $settings" >&2
        return 1
    }
    jq -e '.enabledPlugins["telegram@claude-plugins-official"] == true' "$settings" >/dev/null 2>&1 || {
        printf '%s\n' "$wrapper_name: Telegram launch refused: Telegram plugin is not enabled in $settings" >&2
        return 1
    }
    [[ -d "$plugin_cache" ]] || {
        printf '%s\n' "$wrapper_name: Telegram launch refused: official Telegram plugin cache is missing" >&2
        return 1
    }
    while IFS= read -r candidate; do
        plugin_root="$candidate"
    done < <(find "$plugin_cache" -mindepth 1 -maxdepth 1 -type d -print 2>/dev/null | sort -V)
    [[ -n "$plugin_root" && -f "$plugin_root/.mcp.json" && -f "$plugin_root/server.ts" ]] || {
        printf '%s\n' "$wrapper_name: Telegram launch refused: no complete official plugin server was found" >&2
        return 1
    }
    plugin_command="$(jq -r '.mcpServers.telegram.command // empty' "$plugin_root/.mcp.json" 2>/dev/null || true)"
    # Plugin 0.0.6 declares a bare "bun"; on Honey bun lives in metsatron's npm prefix.
    if [[ "$plugin_command" != /* ]]; then
        plugin_command="$(command -v -- "$plugin_command" 2>/dev/null || true)"
    fi
    [[ "$plugin_command" = /* && -x "$plugin_command" ]] || {
        printf '%s\n' "$wrapper_name: Telegram launch refused: plugin MCP command is unavailable" >&2
        return 1
    }
    [[ -f "$state_dir/.env" ]] && grep -Eq '^TELEGRAM_BOT_TOKEN=[^[:space:]].*$' "$state_dir/.env" || {
        printf '%s\n' "$wrapper_name: Telegram launch refused: bot token state is missing at $state_dir/.env" >&2
        return 1
    }
    command -v sha256sum >/dev/null 2>&1 || {
        printf '%s\n' "$wrapper_name: Telegram launch refused: sha256sum is required for token locking" >&2
        return 1
    }
    token_fingerprint="$(grep '^TELEGRAM_BOT_TOKEN=' "$state_dir/.env" | sha256sum | awk '{print substr($1,1,16)}')"
    if [[ ! "$token_fingerprint" =~ ^[0-9a-f]{16}$ ]]; then
        printf '%s\n' "$wrapper_name: Telegram launch refused: bot token state could not be fingerprinted" >&2
        return 1
    fi

    # One getUpdates consumer per token: hold a per-token lock across the exec.
    runtime_root="${XDG_RUNTIME_DIR:-/run/user/$(id -u)}/claude-idle-compaction"
    mkdir -p "$runtime_root"
    lock_path="$runtime_root/telegram-token-${token_fingerprint}.launch.lock"
    exec 9>"$lock_path"
    if ! flock -n 9; then
        printf '%s\n' "$wrapper_name: Telegram launch refused: another session owns this bot token" >&2
        return 1
    fi

    # Never kill or replace a live plugin server; a stale pid file is the plugin's to recover.
    if [[ -f "$state_dir/bot.pid" ]]; then
        pid="$(tr -d '[:space:]' < "$state_dir/bot.pid" 2>/dev/null || true)"
        if [[ "$pid" =~ ^[1-9][0-9]*$ && -r "/proc/$pid/cmdline" ]]; then
            pid_command="$(tr '\0' ' ' < "/proc/$pid/cmdline" 2>/dev/null || true)"
            pid_state_dir="$(tr '\0' '\n' < "/proc/$pid/environ" 2>/dev/null \
                | sed -n 's/^TELEGRAM_STATE_DIR=//p' | head -1 || true)"
            if [[ "$pid_state_dir" == "$state_dir" && "$pid_command" == *server.ts* ]]; then
                printf '%s\n' "$wrapper_name: Telegram launch refused: an active inline plugin server already owns $state_dir" >&2
                return 1
            fi
        fi
    fi
    return 0
}

# honey/.local/share/honey-claude/lib/launch.bash (generated by agents-bots-honey.org)
# Shared body of honey-opus / honey-sonnet / honey-haiku.

honey_claude_path_append() {
    local dir
    for dir in "$@"; do
        [[ -d "$dir" ]] || continue
        case ":$PATH:" in *":$dir:"*) ;; *) PATH="${PATH:+$PATH:}$dir" ;; esac
    done
    export PATH
}

# honey_claude_launch <bot> <model> [--telegram] [claude args...]
honey_claude_launch() {
    local bot="$1" model="$2"
    shift 2
    local name="honey-$bot"
    local agent="honey-$bot-bot"
    local state_dir="$HOME/.claude/channels/telegram-$bot"
    local work_dir="${HONEY_CLAUDE_WORK_ROOT:-$HOME/honey-work}/$bot"
    local telegram=0 arg
    local passthrough=()

    for arg in "$@"; do
        case "$arg" in
            --telegram) telegram=1 ;;
            *) passthrough+=("$arg") ;;
        esac
    done

    # Metsatron's own npm prefix (claude, bun) and stowed bin; appended, never replacing PATH.
    honey_claude_path_append "$HOME/.local/bin" "${NPM_CONFIG_PREFIX:-$HOME/.npm-global}/bin"

    [[ -d "$work_dir" ]] || {
        printf '%s\n' "$name: refused: working directory $work_dir is missing (see agents-bots-honey.org)" >&2
        return 1
    }
    [[ -f "$work_dir/CLAUDE.md" ]] || {
        printf '%s\n' "$name: refused: $work_dir/CLAUDE.md (the Honey boundary law) is missing" >&2
        return 1
    }
    cd "$work_dir" || return 1

    if [[ "$telegram" -eq 1 ]]; then
        honey_telegram_preflight "$name" "$state_dir" || return 1
    fi
    # The OpenRC service finds this supervisor by pid: exec keeps the pid.
    if [[ -n "${XDG_RUNTIME_DIR:-}" && -d "$XDG_RUNTIME_DIR" ]]; then
        printf '%s\n' "$$" > "$XDG_RUNTIME_DIR/$name.pid"
    fi
    if [[ "$telegram" -eq 1 ]]; then
        # acceptEdits (auto) mode: plan mode blocks unattended bot work (as on kikin).
        exec env CLAUDE_WARM_HERDR_AGENT="$agent" TELEGRAM_STATE_DIR="$state_dir" \
            claude-warm --model "$model" --permission-mode acceptEdits \
            --channels plugin:telegram@claude-plugins-official "${passthrough[@]+"${passthrough[@]}"}"
    fi
    exec env CLAUDE_WARM_HERDR_AGENT="$agent" \
        claude-warm --model "$model" "${passthrough[@]+"${passthrough[@]}"}"
}

* OpenRC services (staged, installed by root)

Modelled on Honey's =/etc/init.d/claude-warm=, with the lessons it already paid for:

- =use net dns= / =after=, never =need net=: Honey has no hard =net= service and =need net= fails dependency resolution.
- A dedicated =XDG_RUNTIME_DIR= under =/run= per bot, created in =start_pre=: =/run/user/<uid>= does not exist at a headless boot.
- =claude-warm= ignores SIGHUP and survives its tmux pane, so =stop= signals the supervisor itself (by the launcher's pid file), then removes the tmux session.
- =PATH= is only ever *appended* to (the login shell's PATH plus metsatron's npm prefix and stowed bin), never overwritten.

One script body serves all three services: the bot comes from =RC_SVCNAME= (=honey-opus= to =opus=). Install as root, for example =install -m 755 ~metsatron/.local/share/honey-claude/openrc/honey-opus /etc/init.d/honey-opus=, then =rc-update add honey-opus default= and check the =/etc/runlevels/default= link.

#+NAME: honey-openrc
#+BEGIN_SRC bash
#!/sbin/openrc-run
# Honey Telegram Claude bot (generated by agents-bots-honey.org; source of truth: DotCortex).
# Runs honey-<bot> --telegram inside its own detached tmux session as metsatron.
# Observe: su -l metsatron -c 'tmux attach -t honey-<bot>' (Ctrl-b d detaches).
# Control: XDG_RUNTIME_DIR=/run/honey-<bot> claude-warmctl list (as metsatron).

bot="${RC_SVCNAME#honey-}"
name="${RC_SVCNAME}"
description="Honey ${bot} Telegram Claude bot (claude-warm as metsatron)"

bot_user="metsatron"
bot_home="/home/metsatron"
bot_session="${RC_SVCNAME}"
bot_cwd="${bot_home}/honey-work/${bot}"
bot_launcher="${bot_home}/.local/bin/${RC_SVCNAME}"
bot_log="/var/log/${RC_SVCNAME}.log"
xdg="/run/${RC_SVCNAME}"
bot_pidfile="${xdg}/${RC_SVCNAME}.pid"
bot_path_add="${bot_home}/.local/bin:${bot_home}/.npm-global/bin"

depend() {
    use net dns
    after net elogind dbus
}

start_pre() {
    case "${bot}" in
        opus|sonnet|haiku) ;;
        *) eerror "unknown Honey bot service name: ${RC_SVCNAME}"; return 1 ;;
    esac
    checkpath -d -m 0700 -o "${bot_user}:${bot_user}" "${xdg}"
    checkpath -f -m 0640 -o "${bot_user}:${bot_user}" "${bot_log}"
}

bot_pid() {
    local pid
    [ -r "${bot_pidfile}" ] || return 1
    pid="$(tr -dc '0-9' < "${bot_pidfile}")"
    [ -n "${pid}" ] || return 1
    [ "$(stat -c %U "/proc/${pid}" 2>/dev/null)" = "${bot_user}" ] || return 1
    tr '\0' ' ' < "/proc/${pid}/cmdline" 2>/dev/null | grep -q 'claude-warm' || return 1
    echo "${pid}"
}

start() {
    ebegin "Starting ${description} (tmux: ${bot_session})"
    su -l "${bot_user}" -c "export XDG_RUNTIME_DIR='${xdg}' PATH=\"\${PATH}:${bot_path_add}\"; \
        tmux new-session -d -s '${bot_session}' -c '${bot_cwd}' \
        -e XDG_RUNTIME_DIR='${xdg}' -e PATH=\"\${PATH}\" \
        'exec ${bot_launcher} --telegram >> ${bot_log} 2>&1'"
    eend $? "Failed to start ${RC_SVCNAME}"
}

stop() {
    local pid i=0
    ebegin "Stopping ${description}"
    pid="$(bot_pid)"
    if [ -n "${pid}" ]; then
        kill -TERM "${pid}" 2>/dev/null
        while kill -0 "${pid}" 2>/dev/null && [ $i -lt 10 ]; do
            sleep 1; i=$((i+1))
        done
        kill -0 "${pid}" 2>/dev/null && kill -KILL "${pid}" 2>/dev/null
    fi
    rm -f "${bot_pidfile}"
    su -l "${bot_user}" -c "tmux kill-session -t '${bot_session}'" 2>/dev/null
    eend 0
}

status() {
    if bot_pid >/dev/null; then
        einfo "${RC_SVCNAME} supervisor is running (pid $(bot_pid))"
        return 0
    fi
    einfo "${RC_SVCNAME} is not running"
    return 3
}

    @staticmethod
    def script(path, body, shebang="#!/bin/sh\n"):
        path.write_text(shebang + body)
        path.chmod(0o755)

    def run(self, bot, *args):
        env = {"HOME": str(self.home), "PATH": f"{self.bin}:/usr/bin:/bin",
               "XDG_RUNTIME_DIR": str(self.xdg)}
        return subprocess.run([str(BIN / f"honey-{bot}"), *args], capture_output=True,
                              text=True, env=env)

    def recorded(self):
        return json.loads(self.record.read_text())

    def close(self):
        self.tmp.cleanup()

    def test_each_bot_launches_its_telegram_warm_session(self):
        box = Home()
        try:
            agents = set()
            for bot, model in BOTS.items():
                result = box.run(bot, "--telegram")
                self.assertEqual(result.returncode, 0, result.stderr)
                rec = box.recorded()
                self.assertEqual(rec["argv"], ["--model", model, "--permission-mode", "acceptEdits",
                                               "--channels", "plugin:telegram@claude-plugins-official"])
                self.assertEqual(rec["cwd"], str(box.home / "honey-work" / bot))
                self.assertEqual(rec["state"], str(box.home / f".claude/channels/telegram-{bot}"))
                self.assertEqual(rec["agent"], f"honey-{bot}-bot")
                self.assertIn(str(box.home / ".npm-global/bin"), rec["path"].split(":"))
                self.assertTrue(rec["path"].startswith(str(box.bin)), "PATH must be appended to")
                pidfile = box.xdg / f"honey-{bot}.pid"
                self.assertEqual(pidfile.read_text().strip(), str(rec["pid"]))
                agents.add(rec["agent"])
            self.assertNotIn("honey-opus", agents, "collides with Honey's existing warm consort")
        finally:
            box.close()

    def test_plain_run_has_no_channel(self):
        box = Home()

            self.assertEqual(result.returncode, 0, result.stderr)
            self.assertEqual(box.recorded()["argv"], ["--model", BOTS["haiku"]])
        finally:
            box.close()

        finally:
            box.close()

class ServiceTests(unittest.TestCase):
    def scripts(self):
        return {bot: (OPENRC / f"honey-{bot}").read_text() for bot in BOTS}

    def test_three_identical_scripts(self):
        texts = set(self.scripts().values())
        self.assertEqual(len(texts), 1)

    def test_script_rules(self):
        text = next(iter(self.scripts().values()))
        self.assertTrue(text.startswith("#!/sbin/openrc-run\n"))
        self.assertNotRegex(text, r"\bneed\s+net\b")
        self.assertIn("use net dns", text)
        self.assertNotRegex(text, r"(^|[\s;'\"])PATH=['\"]?/", "PATH must only be appended to")
        self.assertIn('PATH=\\"\\${PATH}:', text)
        self.assertIn('bot_user="metsatron"', text)
        self.assertNotIn("/home/gille", text)
        result = subprocess.run(["sh", "-n", str(OPENRC / "honey-opus")], capture_output=True, text=True)
        self.assertEqual(result.returncode, 0, result.stderr)

    def test_boundary_law_names_the_vault_and_no_addresses(self):
        text = BOUNDARY.read_text()
        self.assertIn("Secret Vault", text)
        self.assertIsNone(re.search(r"\b\d{1,3}(\.\d{1,3}){3}\b", text))
