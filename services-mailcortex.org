* Boundary

The package manifest is sourced in =package-nala.org=. This module only plans
and applies that small manifest, then owns Syncthing's boot lifecycle on each
configured node. Private device IDs, credentials, peer addresses,
and folder membership stay in a dedicated per-host Syncthing home at
=~/.config/mailcortex/syncthing/=. Configuration isolation prevents MailCortex
settings from rewriting an older general-purpose Syncthing profile. Both
profiles may claim the same network ports, so runtime startup refuses a second
Syncthing owner until the private port plan is reviewed.
Activation requires an explicit local readiness marker at
=~/.config/mailcortex/syncthing-ready=, a complete private identity/config, and
an existing =~/Mail/= directory; these are provisioned only after private
configuration is reviewed. No public source writes them.

** Narrow additive package apply

The default is a read-only apt simulation. =--apply= installs only the single
package in the micro-manifest; no repository setup, upgrade, removal, release
sync, or unrelated Nala manifest action is reachable from this entrypoint.

* Maildir command surface

The public command carries no fleet topology.  It maps a restricted RFC-style
address onto an already-provisioned Maildir below =~/Mail=: a bare local part is
a consort, while =seat+=, =machine+=, and =sanctuary+= select the other three
namespaces.  The domain must end in =.helm=, but remains provenance rather than
a network destination because Syncthing carries the entire tree.

=provision= creates validated Maildirs with private directory permissions;
=send= refuses unknown Maildirs so a typo cannot silently create a new address.
It writes a complete RFC 822 message under =tmp/=, fsyncs it, and atomically
renames it into =new/=. =send --in-reply-to= writes both =In-Reply-To= and
=References=; the opt-in =--print-id= output adds the generated Message-ID
after the filename without changing default output. =inbox= is read-only;
=read= moves a message from =new/= to =cur/= with the standard seen flag
before rendering it, including reply headers. Bodies may
refer to HelmCortex paths. Repeatable =send --attach PATH= adds MIME attachments
with the plain-text body first; missing, symlink and non-regular inputs are
refused before delivery. Total raw attachments are capped at 25 MiB. Types are
guessed from filenames, falling back to =application/octet-stream=. Without
=--attach= the original single-part wire format is unchanged.

** Explicit cross-UID delivery

=send --shared-delivery= is an opt-in for an operator-provisioned receiver Maildir.
Its =tmp/= and =new/= must be sticky setgid directories with the same owner/group
as the Maildir and no other-user access. The staged message becomes =0640= before
publication, allowing the receiver's inherited group to read it even when the
sender runs under a different UID. Ordinary sends remain =0600=. Provision only
named sender ACLs: ancestor traversal, target traversal, and =rwx= on those two
leaves. Sticky directories prevent deletion of another sender's messages. Do not
grant read access to existing messages or the receiver's =cur/= directory. Directory
listing reveals filenames, not message bodies. This is a filesystem communication
permission, not authenticated sender authority; the operator must establish the
sender address separately. No ACL, identity, or registry is created by the CLI.

** Existing OpenCode seats

The CLI delivers to the same provisioned Maildir for every harness. The
OpenCode wake transport and placeholder registry contract live in
[[file:services-mailcortex-watcher.org][the seat watcher module]]. The private seat registry is deliberately not
tangled: host topology, session IDs and exact session directories remain
operator-provisioned. Provision the selected seat with =mailcortex provision=
and confirm the live Telegram session binding before enabling its watcher.

** BBS fleet alerts

=mailcortex bbs alert= extends the existing read-only BBS with a small durable
system-signal lane. Records live below =~/Mail/.bbs/alerts/= as immutable,
content-addressed JSON using =mailcortex.bbs-alert.v1=. Every alert has a
required expiry and one of four levels, in descending display priority:

- =pain=: outage, blocker, or safety condition;
- =adrenaline=: urgent opportunity with a short window, such as quota that
  should be used before a verified reset;
- =notice=: bounded operational information;
- =calm=: recovery or explicit all-clear.

=scope= is either the whole =fleet= or =squadron:NAME=. A later record may
name =supersedes=; readers compute expiry and supersession without editing old
records. =current= returns only active, non-superseded records, highest level
first, while =list= retains the append-only history.

Posting is bound to the existing private seat registry. The operator adds this
top-level fragment to =~/.config/mailcortex/seats.json=; every named value must
also be a canonical key in the registry's existing =seats= object:

#+BEGIN_SRC json :tangle no :comments no
"bbs_alerts": {
  "admiral": "YOUR_ADMIRAL_SEAT",
  "coordinator": "YOUR_COORDINATOR_SEAT",
  "emitters": ["YOUR_NAMED_EMITTER_SEAT"]
}
#+END_SRC

The first deterministic emitter is =mailcortex bbs alert emit-reset=. It reads
the existing local =ai-usage= Codex cache without refreshing it and posts one
idempotent =adrenaline= record only when the native signal is at most five
minutes old, carries an absolute future reset within 90 minutes, and still has
quota to burn. Missing, stale, fallback, malformed, or ambiguous telemetry is a
loud refusal and never creates an alert. No schedule or live post is installed
by this source.

ADDRESS_RE = re.compile(
    r"^(?:(consort|seat|machine|sanctuary)\+)?"
    r"([a-z0-9][a-z0-9._-]*)@"
    r"([a-z0-9][a-z0-9.-]*\.helm)$"
)
MESSAGE_ID_RE = re.compile(r"^<[^<>\s@]+@[^<>\s@]+>$")
PERMISSION_AUTH_RE = re.compile(
    r"^seat=[a-z0-9][a-z0-9._-]{0,63};request_id=[a-km-z]{5};"
    r"behavior=(?:allow|deny);timestamp=[0-9]{1,12};hmac=[0-9a-f]{64}$"
)
COMPONENT_RE = re.compile(r"^[a-z0-9][a-z0-9._-]{0,63}$")
ALERT_ID_RE = re.compile(r"^[0-9a-f]{64}$")
ALERT_SCHEMA = "mailcortex.bbs-alert.v1"
ALERT_LEVELS = ("pain", "adrenaline", "notice", "calm")
ALERT_LEVEL_RANK = {level: rank for rank, level in enumerate(ALERT_LEVELS)}
ALERT_SIGNAL_MAX_AGE_SECONDS = 300
ALERT_RESET_WINDOW_MINUTES = 90

def utc_now() -> datetime:
    return datetime.now(timezone.utc)


def parse_alert_timestamp(value: object, label: str) -> datetime:
    if not isinstance(value, str) or not value or len(value) > 40:
        raise MailCortexError(f"alert {label} must be an RFC 3339 timestamp")
    try:
        parsed = datetime.fromisoformat(value.replace("Z", "+00:00"))
    except ValueError as error:
        raise MailCortexError(f"alert {label} must be an RFC 3339 timestamp") from error
    if parsed.tzinfo is None or parsed.utcoffset() is None:
        raise MailCortexError(f"alert {label} must include a UTC offset")
    return parsed.astimezone(timezone.utc)


def format_alert_timestamp(value: datetime) -> str:
    return value.astimezone(timezone.utc).isoformat(timespec="seconds").replace("+00:00", "Z")


def alert_text(value: object, label: str, limit: int) -> str:
    if not isinstance(value, str):
        raise MailCortexError(f"alert {label} must be text")
    normalized = value.strip()
    if not normalized or len(normalized) > limit or any(ord(char) < 32 for char in normalized):
        raise MailCortexError(f"alert {label} must be one line of 1-{limit} characters")
    return normalized


def parse_alert_scope(value: object) -> dict[str, str]:
    if not isinstance(value, str):
        raise MailCortexError("alert scope must be fleet or squadron:NAME")
    if value == "fleet":
        return {"kind": "fleet"}
    if value.startswith("squadron:") and COMPONENT_RE.fullmatch(value.removeprefix("squadron:")):
        return {"kind": "squadron", "name": value.removeprefix("squadron:")}
    raise MailCortexError("alert scope must be fleet or squadron:NAME")


def validate_alert_scope(value: object) -> dict[str, str]:
    if value == {"kind": "fleet"}:
        return {"kind": "fleet"}
    if (
        isinstance(value, dict)
        and set(value) == {"kind", "name"}
        and value.get("kind") == "squadron"
        and isinstance(value.get("name"), str)
        and COMPONENT_RE.fullmatch(value["name"])
    ):
        return {"kind": "squadron", "name": value["name"]}
    raise MailCortexError("alert scope is invalid")


def alert_identifier(payload: dict[str, object]) -> str:
    encoded = json.dumps(payload, sort_keys=True, separators=(",", ":")).encode("utf-8")
    return hashlib.sha256(encoded).hexdigest()


def validate_alert(value: object, path: Path | None = None) -> dict[str, object]:
    if not isinstance(value, dict):
        raise MailCortexError("alert record is not an object")
    required = {
        "schema", "id", "level", "title", "body", "issued_by", "issued_at",
        "expires_at", "scope",
    }
    optional = {"supersedes"}
    if not required <= set(value) or set(value) - required - optional:
        raise MailCortexError("alert record fields are not exact")
    if value.get("schema") != ALERT_SCHEMA:
        raise MailCortexError("alert schema is invalid")
    alert_id = value.get("id")
    if not isinstance(alert_id, str) or not ALERT_ID_RE.fullmatch(alert_id):
        raise MailCortexError("alert id is invalid")
    if path is not None and path.name != f"{alert_id}.json":
        raise MailCortexError("alert filename does not match its id")
    level = value.get("level")
    if level not in ALERT_LEVELS:
        raise MailCortexError("alert level is invalid")
    title = alert_text(value.get("title"), "title", 120)
    body = alert_text(value.get("body"), "body", 500)
    issued_by = value.get("issued_by")
    if not isinstance(issued_by, str) or not COMPONENT_RE.fullmatch(issued_by):
        raise MailCortexError("alert issued_by is invalid")
    issued = parse_alert_timestamp(value.get("issued_at"), "issued_at")
    expires = parse_alert_timestamp(value.get("expires_at"), "expires_at")
    if expires <= issued:
        raise MailCortexError("alert expires_at must be later than issued_at")
    scope = validate_alert_scope(value.get("scope"))
    supersedes = value.get("supersedes")
    if supersedes is not None:
        if not isinstance(supersedes, str) or not ALERT_ID_RE.fullmatch(supersedes):
            raise MailCortexError("alert supersedes id is invalid")
        if supersedes == alert_id:
            raise MailCortexError("alert cannot supersede itself")
    payload: dict[str, object] = {
        "schema": ALERT_SCHEMA,
        "level": level,
        "title": title,
        "body": body,
        "issued_by": issued_by,
        "issued_at": format_alert_timestamp(issued),
        "expires_at": format_alert_timestamp(expires),
        "scope": scope,
    }
    if supersedes is not None:
        payload["supersedes"] = supersedes
    if alert_identifier(payload) != alert_id:
        raise MailCortexError("alert id does not match immutable content")
    return payload | {"id": alert_id}


def load_alerts() -> list[dict[str, object]]:
    directory = alert_root()
    if not directory.exists():
        return []
    if directory.is_symlink() or not directory.is_dir():
        raise MailCortexError("alert root is not a safe directory")
    alerts = []
    for path in sorted(directory.glob("*.json")):
        if path.is_symlink() or not path.is_file():
            raise MailCortexError("alert record is not a regular file")
        try:
            value = json.loads(path.read_text(encoding="utf-8"))
        except (OSError, json.JSONDecodeError) as error:
            raise MailCortexError(f"alert record is unreadable: {path.name}") from error
        alerts.append(validate_alert(value, path))
    by_id = {str(alert["id"]): alert for alert in alerts}
    if len(by_id) != len(alerts):
        raise MailCortexError("duplicate alert id")
    for alert in alerts:
        target = alert.get("supersedes")
        if target is None:
            continue
        if target not in by_id:
            raise MailCortexError("alert supersedes an unknown id")
        if parse_alert_timestamp(alert["issued_at"], "issued_at") < parse_alert_timestamp(
            by_id[str(target)]["issued_at"], "issued_at"
        ):
            raise MailCortexError("alert supersedes a later record")
        seen = {str(alert["id"])}
        cursor: object = target
        while cursor is not None:
            if cursor in seen:
                raise MailCortexError("alert supersession cycle")
            seen.add(str(cursor))
            cursor = by_id[str(cursor)].get("supersedes")
    return alerts


def alert_authorized(issued_by: str) -> None:
    path = seat_registry_path()
    if path.is_symlink() or not path.is_file() or path.stat().st_mode & 0o077:
        raise MailCortexError("private seat registry is unavailable")
    try:
        registry = json.loads(path.read_text(encoding="utf-8"))
    except (OSError, json.JSONDecodeError) as error:
        raise MailCortexError("private seat registry is unreadable") from error
    if not isinstance(registry, dict) or registry.get("schema") != "mailcortex.seats.v1":
        raise MailCortexError("private seat registry is invalid")
    host = registry.get("host")
    seats = registry.get("seats")
    policy = registry.get("bbs_alerts")
    if not isinstance(host, str) or not host or not isinstance(seats, dict) or not isinstance(policy, dict):
        raise MailCortexError("BBS alert authorization is not provisioned")
    if set(policy) != {"admiral", "coordinator", "emitters"}:
        raise MailCortexError("BBS alert authorization fields are not exact")
    admiral = policy.get("admiral")
    coordinator = policy.get("coordinator")
    emitters = policy.get("emitters")
    if (
        not isinstance(admiral, str)
        or not isinstance(coordinator, str)
        or not isinstance(emitters, list)
        or not all(isinstance(item, str) for item in emitters)
    ):
        raise MailCortexError("BBS alert authorization is invalid")
    identities = [admiral, coordinator, *emitters]
    if len(set(identities)) != len(identities) or not all(COMPONENT_RE.fullmatch(item) for item in identities):
        raise MailCortexError("BBS alert authorization identities are invalid")
    if issued_by not in identities:
        raise MailCortexError(f"seat is not authorised to post BBS alerts: {issued_by}")
    for identity in identities:
        record = seats.get(identity)
        if (
            not isinstance(record, dict)
            or record.get("host") != host
            or record.get("mailbox") not in {f"seats/{identity}", f"consorts/{identity}"}
        ):
            raise MailCortexError("BBS alert authorization is not bound to canonical seats")


def write_alert(payload: dict[str, object]) -> str:
    alert_id = alert_identifier(payload)
    record = payload | {"id": alert_id}
    encoded = (json.dumps(record, sort_keys=True, separators=(",", ":")) + "\n").encode("utf-8")
    directory = alert_root()
    parent = directory.parent
    for component in (parent, directory):
        if component.exists() and component.is_symlink():
            raise MailCortexError(f"refusing symlink in BBS alert path: {component}")
    old_umask = os.umask(0o077)
    try:
        parent.mkdir(mode=0o700, parents=True, exist_ok=True)
        directory.mkdir(mode=0o700, exist_ok=True)
    finally:
        os.umask(old_umask)
    if not parent.is_dir() or not directory.is_dir():
        raise MailCortexError("BBS alert path is unsafe")
    path = directory / f"{alert_id}.json"
    if path.exists():
        if path.is_symlink() or not path.is_file() or path.read_bytes() != encoded:
            raise MailCortexError("BBS alert id collision")
        return alert_id
    temporary = directory / f".{alert_id}.{os.getpid()}.{uuid.uuid4().hex}.tmp"
    try:
        descriptor = os.open(temporary, os.O_WRONLY | os.O_CREAT | os.O_EXCL, 0o600)
        with os.fdopen(descriptor, "wb") as stream:
            stream.write(encoded)
            stream.flush()
            os.fsync(stream.fileno())
        try:
            os.link(temporary, path)
        except FileExistsError:
            if path.is_symlink() or not path.is_file() or path.read_bytes() != encoded:
                raise MailCortexError("BBS alert id collision")
        fsync_directory(directory)
    finally:
        try:
            temporary.unlink()
        except FileNotFoundError:
            pass
    return alert_id


def make_alert(
    *, level: str, title: str, body: str, issued_by: str, issued_at: datetime,
    expires_at: datetime, scope: dict[str, str], supersedes: str | None = None,
) -> dict[str, object]:
    if level not in ALERT_LEVELS:
        raise MailCortexError("alert level is invalid")
    normalized_issued = parse_alert_timestamp(
        format_alert_timestamp(issued_at), "issued_at"
    )
    normalized_expires = parse_alert_timestamp(
        format_alert_timestamp(expires_at), "expires_at"
    )
    if normalized_expires <= normalized_issued:
        raise MailCortexError("alert expires_at must be later than issued_at")
    payload: dict[str, object] = {
        "schema": ALERT_SCHEMA,
        "level": level,
        "title": alert_text(title, "title", 120),
        "body": alert_text(body, "body", 500),
        "issued_by": issued_by,
        "issued_at": format_alert_timestamp(normalized_issued),
        "expires_at": format_alert_timestamp(normalized_expires),
        "scope": scope,
    }
    if supersedes is not None:
        if not ALERT_ID_RE.fullmatch(supersedes):
            raise MailCortexError("alert supersedes id is invalid")
        payload["supersedes"] = supersedes
    return payload


def post_bbs_alert(args: argparse.Namespace) -> int:
    alert_authorized(args.issued_by)
    now = utc_now()
    expires = parse_alert_timestamp(args.expires_at, "expires_at")
    if expires <= now:
        raise MailCortexError("alert expires_at must be in the future")
    alerts = load_alerts()
    by_id = {str(alert["id"]): alert for alert in alerts}
    if args.supersedes:
        if args.supersedes not in by_id:
            raise MailCortexError("alert supersedes an unknown id")
        if now < parse_alert_timestamp(by_id[args.supersedes]["issued_at"], "issued_at"):
            raise MailCortexError("alert cannot supersede a later record")
    alert_id = write_alert(make_alert(
        level=args.level,
        title=args.title,
        body=args.body,
        issued_by=args.issued_by,
        issued_at=now,
        expires_at=expires,
        scope=parse_alert_scope(args.scope),
        supersedes=args.supersedes,
    ))
    print(alert_id)
    return 0


def alert_scope_text(scope: object) -> str:
    validated = validate_alert_scope(scope)
    return "fleet" if validated["kind"] == "fleet" else f"squadron:{validated['name']}"


def output_alerts(alerts: list[dict[str, object]], as_json: bool) -> int:
    if as_json:
        print(json.dumps(alerts, sort_keys=True, separators=(",", ":")))
        return 0
    for alert in alerts:
        print(
            f"{str(alert['level']).upper():<10} "
            f"[{alert_scope_text(alert['scope'])}] {alert['title']} — {alert['body']} "
            f"(until {alert['expires_at']}) [{str(alert['id'])[:12]}]"
        )
    return 0


def list_bbs_alerts(args: argparse.Namespace) -> int:
    alerts = sorted(
        load_alerts(),
        key=lambda alert: (parse_alert_timestamp(alert["issued_at"], "issued_at"), str(alert["id"])),
        reverse=True,
    )
    return output_alerts(alerts, args.json)


def current_alerts(now: datetime | None = None) -> list[dict[str, object]]:
    observed = now or utc_now()
    alerts = load_alerts()
    superseded = {
        str(alert["supersedes"])
        for alert in alerts
        if alert.get("supersedes") is not None
        and parse_alert_timestamp(alert["issued_at"], "issued_at") <= observed
    }
    current = [
        alert for alert in alerts
        if parse_alert_timestamp(alert["issued_at"], "issued_at") <= observed
        < parse_alert_timestamp(alert["expires_at"], "expires_at")
        and str(alert["id"]) not in superseded
    ]
    return sorted(
        current,
        key=lambda alert: (
            ALERT_LEVEL_RANK[str(alert["level"])],
            -parse_alert_timestamp(alert["issued_at"], "issued_at").timestamp(),
            str(alert["id"]),
        ),
    )


def show_current_bbs_alerts(args: argparse.Namespace) -> int:
    return output_alerts(current_alerts(), args.json)


def codex_reset_signal(path: Path, now: datetime) -> tuple[datetime, datetime, int]:
    diagnostic = "trustworthy Codex quota signal unavailable"
    if path.is_symlink() or not path.is_file():
        raise MailCortexError(diagnostic + ": cache is absent or unsafe")
    try:
        document = json.loads(path.read_text(encoding="utf-8"))
    except (OSError, json.JSONDecodeError) as error:
        raise MailCortexError(diagnostic + ": cache is unreadable") from error
    if not isinstance(document, dict) or not isinstance(document.get("ts"), (int, float)):
        raise MailCortexError(diagnostic + ": observation time is absent")
    try:
        observed = datetime.fromtimestamp(float(document["ts"]), tz=timezone.utc)
    except (OSError, OverflowError, ValueError) as error:
        raise MailCortexError(diagnostic + ": observation time is invalid") from error
    age = (now - observed).total_seconds()
    if age < -60 or age > ALERT_SIGNAL_MAX_AGE_SECONDS:
        raise MailCortexError(diagnostic + ": cache is stale")
    result = document.get("result")
    if (
        not isinstance(result, dict)
        or result.get("provider") != "codex"
        or result.get("state") != "ok"
        or result.get("source") != "codex-native"
        or result.get("stale") is True
    ):
        raise MailCortexError(diagnostic + ": provider state is not authoritative")
    raw = result.get("raw")
    if (
        not isinstance(raw, dict)
        or raw.get("provider") != "codex"
        or raw.get("source") != "codex-native"
        or not isinstance(raw.get("usage"), dict)
        or not isinstance(raw["usage"].get("primary"), dict)
    ):
        raise MailCortexError(diagnostic + ": primary window is absent")
    window = raw["usage"]["primary"]
    used = window.get("usedPercent")
    if not isinstance(used, (int, float)) or isinstance(used, bool) or not 0 <= float(used) <= 100:
        raise MailCortexError(diagnostic + ": remaining quota is invalid")
    reset = parse_alert_timestamp(window.get("resetsAt"), "reset signal")
    if reset <= now:
        raise MailCortexError(diagnostic + ": reset is not in the future")
    return observed, reset, max(0, int(round(100.0 - float(used))))


def emit_reset_alert(args: argparse.Namespace) -> int:
    alert_authorized(args.issued_by)
    now = utc_now()
    cache = Path(
        os.environ.get("MAILCORTEX_CODEX_USAGE_CACHE", "~/.cache/ai-usage/codex-v2.json")
    ).expanduser()
    observed, reset, remaining = codex_reset_signal(cache, now)
    seconds_until_reset = (reset - now).total_seconds()
    if seconds_until_reset > args.within_minutes * 60:
        print("no-alert: Codex reset is not imminent")
        return 0
    if remaining <= 0:
        print("no-alert: no remaining Codex quota to burn")
        return 0
    alert_id = write_alert(make_alert(
        level="adrenaline",
        title="Codex quota reset imminent",
        body=(
            f"{remaining}% remains; reset at {format_alert_timestamp(reset)}. "
            "Burn the remaining window."
        ),
        issued_by=args.issued_by,
        issued_at=observed,
        expires_at=reset,
        scope=parse_alert_scope(args.scope),
    ))
    print(alert_id)
    return 0


def atomic_json(path: Path, value: object) -> None:
    path.parent.mkdir(mode=0o700, parents=True, exist_ok=True)
    temporary = path.with_name(f".{path.name}.{os.getpid()}.{uuid.uuid4().hex}.tmp")
    try:
        descriptor = os.open(temporary, os.O_WRONLY | os.O_CREAT | os.O_EXCL, 0o600)
        with os.fdopen(descriptor, "w", encoding="utf-8") as stream:
            json.dump(value, stream, sort_keys=True, separators=(",", ":"))
            stream.write("\n")
            stream.flush()
            os.fsync(stream.fileno())
        os.replace(temporary, path)
        fsync_directory(path.parent)
    except Exception:
        try:
            temporary.unlink()
        except FileNotFoundError:
            pass
        raise


def canonical_message_id(message_id: str) -> str:
    """One message, one key.

    The same id arrives bracketed from a notice, unbracketed from a header, and
    lower-cased from a maildir filename. Hashing the raw string gave one message
    up to three receipt files: a wake receipt could land in a different file from
    the handling receipt, so the watcher's "already handled" skip never fired and
    the mail was re-offered forever.
    """
    return message_id.strip().strip("<>").strip().lower()


def receipt_path(seat: str, message_id: str) -> Path:
    if not MESSAGE_ID_RE.fullmatch(message_id):
        raise MailCortexError("invalid Message-ID")
    key = hashlib.sha256(canonical_message_id(message_id).encode("utf-8")).hexdigest()
    return runtime_root() / "receipts" / seat / f"{key}.json"


def load_receipt(seat: str, message_id: str) -> dict[str, object] | None:
    path = receipt_path(seat, message_id)
    if not path.exists():
        return None
    if path.is_symlink() or not path.is_file():
        raise MailCortexError("receipt is not a regular file")
    try:
        current = json.loads(path.read_text(encoding="utf-8"))
    except (OSError, json.JSONDecodeError) as error:
        raise MailCortexError("receipt is unreadable") from error
    if (
        not isinstance(current, dict)
        or current.get("schema") != "mailcortex.receipt.v2"
        or current.get("seat") != seat
        or current.get("message_id") != message_id
        or current.get("wake_state") not in WAKE_STATES
        or current.get("handling_state") not in HANDLING_STATES | {None}
    ):
        raise MailCortexError("receipt is invalid")
    return current


def write_wake_receipt(seat: str, message_id: str, state: str, **extra: object) -> None:
    if state not in WAKE_STATES - {"manual"}:
        raise MailCortexError(f"unknown wake state: {state}")
    path = receipt_path(seat, message_id)
    current = load_receipt(seat, message_id) or {
        "schema": "mailcortex.receipt.v2", "seat": seat,
        "message_id": message_id, "handling_state": None,
    }
    current.update({"wake_state": state, "wake_updated_at": time.time(), **extra})
    atomic_json(path, current)


def write_handling_receipt(seat: str, message_id: str, state: str) -> None:
    if state not in HANDLING_STATES:
        raise MailCortexError(f"unknown handling state: {state}")
    path = receipt_path(seat, message_id)
    current = load_receipt(seat, message_id) or {
        "schema": "mailcortex.receipt.v2", "seat": seat,
        "message_id": message_id, "wake_state": "manual",
    }
    current.update({"handling_state": state, "handling_updated_at": time.time()})
    atomic_json(path, current)


def receipt(args: argparse.Namespace) -> int:
    # A receipt is evidence, so it must point at mail that exists. Reconstructed
    # or mistyped Message-IDs were accepted silently, producing receipts for
    # messages that were never in the mailbox — the ledger then "proved"
    # handling of mail nobody had read. Refuse instead: name the file the id
    # does match, or say nothing matches.
    mailbox = mail_root() / "consorts" / args.seat
    wanted = args.message_id.strip().strip("<>").lower()
    match = None
    if wanted:
        for sub in ("new", "cur"):
            for candidate in (mailbox / sub).glob("*"):
                try:
                    with candidate.open("r", errors="replace") as handle:
                        for line in handle:
                            if line.lower().startswith("message-id:"):
                                if line.split(":", 1)[1].strip().strip("<>").lower() == wanted:
                                    match = candidate
                                break
                except OSError:
                    continue
                if match:
                    break
            if match:
                break
    if match is None:
        raise MailCortexError(
            f"no mail in {args.seat} with Message-ID {args.message_id!r}; "
            "copy the id from the message header or file name, never rebuild it"
        )
    write_handling_receipt(args.seat, args.message_id, args.state)
    return 0


def address_maildir(address: str) -> Path:
    match = ADDRESS_RE.fullmatch(address.lower())
    if not match:
        raise MailCortexError(
            "invalid address; use name@machine.helm or "
            "seat+name@machine.helm (also machine+ and sanctuary+)"
        )
    kind, name, _domain = match.groups()
    return mail_root() / NAMESPACE[kind] / name


def require_maildir(address: str) -> Path:
    path = address_maildir(address)
    missing = [name for name in ("tmp", "new", "cur") if not (path / name).is_dir()]
    if missing:
        # Name the seats that DO exist: a seat that guesses its own address
        # otherwise just sees "not provisioned" and guesses again.
        consorts = path.parent
        try:
            known = sorted(entry.name for entry in consorts.iterdir()
                           if entry.is_dir() and (entry / "new").is_dir())
        except OSError:
            known = []
        hint = f"; provisioned seats: {', '.join(known)}" if known else ""
        raise MailCortexError(f"maildir is not provisioned for {address}: {path}{hint}")
    return path


def provision(args: argparse.Namespace) -> int:
    # Validate every address before creating any directory.
    paths = list(dict.fromkeys(address_maildir(address) for address in args.addresses))
    root = mail_root()
    for path in paths:
        for component in (root, path.parent, path):
            if component.is_symlink():
                raise MailCortexError(f"refusing symlink in maildir path: {component}")
    old_umask = os.umask(0o077)
    try:
        for path in paths:
            for directory in (root, path.parent, path, *(path / leaf for leaf in ("tmp", "new", "cur"))):
                directory.mkdir(mode=0o700, parents=True, exist_ok=True)
                if directory.is_symlink() or not directory.is_dir():
                    raise MailCortexError(f"unsafe maildir path: {directory}")
                directory.chmod(0o700)
            print(path)
    finally:
        os.umask(old_umask)
    return 0


def safe_name() -> str:
    host = re.sub(r"[^A-Za-z0-9_-]", "_", socket.gethostname())
    return f"{time.time_ns()}.{os.getpid()}_{uuid.uuid4().hex}.{host}"


def fsync_directory(path: Path) -> None:
    descriptor = os.open(path, os.O_RDONLY | os.O_DIRECTORY)
    try:
        os.fsync(descriptor)
    finally:
        os.close(descriptor)


ATTACHMENT_LIMIT = 25 * 1024 * 1024


def attachments(paths: list[str]):
    remaining = ATTACHMENT_LIMIT
    for value in paths:
        path = Path(value).expanduser()
        # O_NONBLOCK avoids hanging on a FIFO; fstat binds validation to the
        # opened inode, and O_NOFOLLOW refuses a raced-in leaf symlink.
        descriptor = os.open(path, os.O_RDONLY | os.O_NOFOLLOW | os.O_NONBLOCK)
        with os.fdopen(descriptor, "rb") as stream:
            info = os.fstat(stream.fileno())
            if not stat.S_ISREG(info.st_mode):
                raise MailCortexError("attachment must be a regular file")
            if info.st_size > remaining:
                raise MailCortexError("attachments exceed 25 MiB")
            data = stream.read(remaining + 1)
        if len(data) > remaining:
            raise MailCortexError("attachments exceed 25 MiB")
        remaining -= len(data)
        mime, encoding = mimetypes.guess_type(path.name)
        yield path.name, mime if mime and not encoding else "application/octet-stream", data


def registered_seats() -> set[str]:
    """Seat names in the watcher registry; the only addresses with a transport."""
    try:
        registry = json.loads(seat_registry_path().read_text(encoding="utf-8"))
        return {str(name).lower() for name in registry.get("seats", {})}
    except (OSError, ValueError):
        return set()


def recipient_has_transport(address: str) -> bool:
    """True when the recipient has a registered seat, else delivery is silent loss.

    `mailcortex send` writes any syntactically valid address into a mailbox, and a
    mailbox without a watcher seat is a dead drop: the mail lands, nothing ever
    reads it, and the sender sees success. A probe to honey-badger@honey.helm did
    exactly that while the real Honey Badger seat is honey-badger on kikin.
    """
    return address.rsplit("@", 1)[0] in registered_seats()


def deliver(args: argparse.Namespace) -> int:
    target = require_maildir(args.to)
    if (not args.recipient_local_only and not recipient_has_transport(args.to)):
        # Name the seats that DO have a transport: the sender can pick the right
        # address instead of discovering the dead drop hours later.
        raise MailCortexError(
            f"recipient {args.to} has no registered seat; mail would never be "
            f"read. Seats with a transport: {', '.join(sorted(registered_seats()))}. "
            "Override only if the mailbox is read by hand (--recipient-local-only)."
        )
    if args.shared_delivery:
        owner = target.lstat()
        for leaf in ("tmp", "new"):
            entry = (target / leaf).lstat()
            if (not stat.S_ISDIR(entry.st_mode)
                    or entry.st_mode & 0o3000 != 0o3000
                    or entry.st_uid != owner.st_uid or entry.st_gid != owner.st_gid
                    or entry.st_mode & 0o007):
                raise MailCortexError("shared delivery requires owner-matched sticky setgid tmp/new directories with no other access")
    if args.body is not None:
        body = args.body
    else:
        body = Path(args.body_file).read_text(encoding="utf-8")

    message = EmailMessage(policy=policy.SMTP)
    message["Date"] = format_datetime(datetime.now().astimezone())
    message["From"] = args.sender
    message["To"] = args.to
    message["Subject"] = args.subject
    message["Message-ID"] = make_msgid(domain=args.sender.rsplit("@", 1)[-1])
    if args.in_reply_to:
        message["In-Reply-To"] = args.in_reply_to
        message["References"] = args.in_reply_to
    if args.permission_auth:
        message["X-MailCortex-Permission"] = args.permission_auth
    message.set_content(body)
    for filename, mime, data in attachments(getattr(args, "attach", [])):
        major, minor = mime.split("/", 1)
        message.add_attachment(data, maintype=major, subtype=minor, filename=filename)

    name = safe_name()
    temporary = target / "tmp" / name
    delivered = target / "new" / name
    try:
        descriptor = os.open(temporary, os.O_WRONLY | os.O_CREAT | os.O_EXCL, 0o600)
        with os.fdopen(descriptor, "wb") as stream:
            stream.write(message.as_bytes())
            stream.flush()
            if args.shared_delivery:
                os.fchmod(stream.fileno(), 0o640)
            os.fsync(stream.fileno())
        os.replace(temporary, delivered)
        _grant_mailbox_read(delivered, target)
        fsync_directory(target / "new")
    except Exception:
        try:
            temporary.unlink()
        except FileNotFoundError:
            pass
        raise
    if args.print_id:
        print(f"{name}\t{message['Message-ID']}")
    else:
        print(name)
    return 0


def _grant_mailbox_read(delivered: Path, mailbox: Path) -> None:
    """Keep a seat's mailbox readable by the seat, not just by its owner.

    Mail landed 0600 and, where an ACL already existed, with mask `---`: the seat
    was granted read and the mask denied it, so eleven messages sat invisible in
    Ecco's mailbox while she honestly reported "no new mail". Repair the mask.
    """
    try:
        owner = mailbox.stat().st_uid
        import pwd
        import subprocess
        seat = pwd.getpwuid(owner).pw_name
        # Repair the mask even when the sender IS the mailbox owner. Returning early
        # there left an inherited ACL mask of `---` in place, so a cross-uid seat's
        # copy of the message stayed unreadable while the delivery looked successful.
        subprocess.run(["setfacl", "-m", f"u:{seat}:rw-,m::rw-", str(delivered)],
                       check=False, capture_output=True)
    except (OSError, KeyError):
        pass


def parse_message(path: Path) -> EmailMessage:
    with path.open("rb") as stream:
        return BytesParser(policy=policy.default).parse(stream)


def messages(maildir: Path):
    for state in ("new", "cur"):
        for path in (maildir / state).iterdir():
            # Dot-prefixed names are in-flight writes (Syncthing's
            # .syncthing.*.tmp), never deliverable messages.
            if path.is_file() and not path.name.startswith("."):
                yield state, path


def show_inbox(args: argparse.Namespace) -> int:
    maildir = require_maildir(args.address)
    rows = sorted(messages(maildir), key=lambda item: (item[1].stat().st_mtime_ns, item[1].name))
    for state, path in rows:
        message = parse_message(path)
        fields = (
            state,
            path.name,
            str(message.get("Date", "")),
            str(message.get("From", "")),
            str(message.get("Subject", "")),
        )
        print("\t".join(value.replace("\t", " ").replace("\n", " ") for value in fields))
    return 0


def locate_message(maildir: Path, name: str) -> tuple[str, Path]:
    if not name or name in {".", ".."} or Path(name).name != name:
        raise MailCortexError("message must be an exact inbox filename")
    for state in ("new", "cur"):
        candidate = maildir / state / name
        if candidate.is_file():
            return state, candidate
    # A delivery notice quotes a Message-ID and a human usually has that, not
    # the Maildir filename ("<stamp.pid_uuid.host>"). Accept a bare Message-ID
    # or a unique filename prefix so seats stop guessing at addresses and
    # filenames when they want to open their mail.
    token = name.strip().strip("<>").strip()
    if not token:
        raise MailCortexError(f"message not found: {name}")
    matches: list[tuple[str, Path]] = []
    for state, path in messages(maildir):
        key = path.name.partition(":2,")[0]
        if key.startswith(token):
            matches.append((state, path))
            continue
        try:
            message_id = str(parse_message(path).get("Message-ID", "")).strip().strip("<>")
        except Exception:
            message_id = ""
        if message_id and message_id == token:
            matches.append((state, path))
    if len(matches) == 1:
        return matches[0]
    if len(matches) > 1:
        listing = ", ".join(path.name for _state, path in matches[:5])
        raise MailCortexError(f"ambiguous message reference ({len(matches)} matches): {listing}")
    raise MailCortexError(f"message not found: {name}")


def close_read_receipt(address: str, message: object) -> None:
    """Mark the message handled for the seat that reads it.

    A mailbox is `consorts/<seat>`; the address local part is the seat name. Failures here
    must never break a read — the mail is already marked seen on disk, which is the real
    state — so every error is swallowed deliberately rather than raised into the reader.
    """
    local = address.split("@", 1)[0]
    message_id = (message.get("Message-ID") or "").strip()
    if not local or not message_id:
        return
    try:
        write_handling_receipt(local, message_id, "handling_completed")
    except (MailCortexError, OSError, ValueError):
        return


def read_message(args: argparse.Namespace) -> int:
    maildir = require_maildir(args.address)
    state, path = locate_message(maildir, args.message)
    message = parse_message(path)
    key, _separator, flags = path.name.partition(":2,")
    seen_name = key + ":2," + "".join(sorted(set(flags) | {"S"}))
    destination = maildir / "cur" / seen_name
    if path != destination:
        if destination.exists():
            raise MailCortexError(f"seen-message destination already exists: {seen_name}")
        os.replace(path, destination)
        fsync_directory(path.parent)
        if path.parent != destination.parent:
            fsync_directory(destination.parent)

    # Reading is handling. Without this the wake receipt stays `queued`/`busy` and the
    # watcher re-offers the same message on every scan, because it can only see spool
    # state and its own wake ledger — never the fact that a human-shaped reader took it.
    close_read_receipt(args.address, message)

    for header in ("Date", "From", "To", "Subject", "Message-ID", "In-Reply-To", "References",
                   "X-MailCortex-Permission"):
        print(f"{header}: {message.get(header, '')}")
    print()
    body = message.get_body(preferencelist=("plain",))
    print(body.get_content() if body is not None else "", end="")
    return 0

    if not COMPONENT_RE.fullmatch(value):

    try:

        raise argparse.ArgumentTypeError("alert window must be an integer") from error
    if not 1 <= minutes <= 1440:
        raise argparse.ArgumentTypeError("alert window must be between 1 and 1440 minutes")
    return minutes


def validate_message_id(value: str) -> str:
    if not MESSAGE_ID_RE.fullmatch(value):
        raise argparse.ArgumentTypeError("invalid Message-ID")

    if not PERMISSION_AUTH_RE.fullmatch(value):
        raise argparse.ArgumentTypeError("invalid permission authentication")

* Aura's MailCortex lane: the forced-command wrapper

Aura reaches her mailbox (=aura@honey.helm=, =consorts/aura=) from Honey through one ssh key whose =authorized_keys= entry forces this script on kikin. It serves four verbs for that one mailbox, the sender is always her, and no shell is involved. Until 2026-11-07 it lived only as a hand-made file in =~/.local/bin=. It is now tracked here.

The short forms exist because her model mis-copies long opaque names. The lane log shows five different wrong spellings of one Maildir filename in two minutes (2026-11-07 01:44, Admiral 11199). The forms are:
- =read next=: the oldest unread message.
- =read N=: the Nth inbox row, counted from 1.
- =last=: the message the lane most recently read. It works with =receipt=, =send --to= and =send --in-reply-to=.

So she never has to retype a filename, a Message-ID or a sender. Every resolved value is still validated against the same patterns as before.

#+BEGIN_SRC python :tangle all/.local/bin/mailcortex-aura-wrapper :shebang "#!/usr/bin/env python3" :tangle-mode (identity #o755)
"""Forced-command wrapper for Aura's MailCortex lane (runs on kikin as metsatron).

Reached only through Aura's dedicated ssh key (authorized_keys: restrict + command=this script).
It serves exactly four verbs for ONE mailbox, aura@honey.helm (consorts/aura), and nothing else:

  inbox
  read FILENAME | read next | read N        (next = oldest unread; N = Nth row of inbox, from 1)
  reply                                      (body on stdin) answer the message last read: recipient, subject,
                                             thread and the handling receipt all come from that read; once per read
  send --to ADDRESS|last --subject SUBJECT [--in-reply-to '<Message-ID>'|last]   (body on stdin, max 8000 bytes)
  receipt '<Message-ID>'|last handling_completed|handling_deferred|handling_failed|handling_rejected

"last" always means the message this lane most recently read: its sender for --to, its Message-ID for
--in-reply-to and receipt. Aura's model mis-copies the long Maildir filenames and Message-IDs (lane log,
2026-11-07 01:44), so she never has to retype one (Admiral 11199).

The sender is always aura@honey.helm and the seat/mailbox is always aura: neither can be chosen by the caller.
No shell is ever involved: arguments are validated and passed as an argument list. Every call is logged
(verb and metadata only, never message bodies) to ~/.local/state/mailcortex/aura-lane.log.
"""
import os
import re
import shlex
import subprocess
import sys
import json
import tempfile
import time

ME = "aura@honey.helm"
SEAT = "aura"
MAILCORTEX = "/home/metsatron/.local/bin/mailcortex"
LOG = os.path.expanduser("~/.local/state/mailcortex/aura-lane.log")
MAX_BODY = 8000
ADDR = re.compile(r"^[a-z0-9][a-z0-9._-]{0,63}@[a-z0-9][a-z0-9.-]{0,63}\.helm$")
FILENAME = re.compile(r"^[A-Za-z0-9][A-Za-z0-9._:,=+-]{0,200}$")
MSGID = re.compile(r"^<[A-Za-z0-9.!#$%&'*+/=?^_`{|}~-]{1,200}@[A-Za-z0-9.-]{1,100}>$")
STATES = {"handling_completed", "handling_deferred", "handling_failed", "handling_rejected"}
LAST = os.path.expanduser("~/.local/state/mailcortex/aura-lane-last.json")
ENV = {"PATH": "/home/metsatron/.local/bin:/usr/local/bin:/usr/bin:/bin", "HOME": "/home/metsatron"}


def inbox_rows():
    out = subprocess.run([MAILCORTEX, "inbox", ME], env=ENV, capture_output=True, text=True)
    if out.returncode != 0:
        refuse("inbox unavailable")
    return [line.split("\t") for line in out.stdout.splitlines() if line.count("\t") >= 1]


def resolve_filename(token):
    rows = inbox_rows()
    if token == "next":
        unread = [r[1] for r in rows if r[0] == "new" and len(r) > 1]
        if not unread:
            refuse("no unread mail")
        return unread[0]
    if token.isdigit():
        n = int(token)
        if not 1 <= n <= len(rows) or len(rows[n - 1]) < 2:
            refuse(f"no row {n}; inbox has {len(rows)}")
        return rows[n - 1][1]
    return token


def remember(stdout, name=""):
    meta = {"filename": name, "replied": False}
    for line in stdout.splitlines():
        if not line.strip():
            break
        key, _, value = line.partition(":")
        if key.lower() in ("from", "message-id", "subject"):
            meta[key.lower()] = value.strip()
    if MSGID.match(meta.get("message-id", "")):
        try:
            with open(LAST, "w") as fh:
                json.dump(meta, fh)
        except OSError:
            pass


def last(field):
    try:
        with open(LAST) as fh:
            value = json.load(fh).get(field, "")
    except (OSError, ValueError):
        refuse("no message read yet; run read next first")
    if field == "from":
        value = value.split("<")[-1].rstrip(">").strip() if "<" in value else value
    return value


def log(verb, detail=""):
    try:
        os.makedirs(os.path.dirname(LOG), exist_ok=True)
        with open(LOG, "a") as fh:
            fh.write(f"{time.strftime('%Y-%m-%dT%H:%M:%S%z')} {verb} {detail}\n")
    except OSError:
        pass


def refuse(why):
    log("REFUSED", why)
    print(f"mailcortex-aura: refused: {why}", file=sys.stderr)
    sys.exit(2)


def run(args):
    env = {"PATH": "/home/metsatron/.local/bin:/usr/local/bin:/usr/bin:/bin", "HOME": "/home/metsatron"}
    sys.exit(subprocess.run([MAILCORTEX, *args], env=env).returncode)


def main():
    raw = os.environ.get("SSH_ORIGINAL_COMMAND", "")
    try:
        argv = shlex.split(raw)
    except ValueError:
        refuse("unparseable command")
    if not argv:
        refuse("no command; verbs are inbox, read, reply, send, receipt")
    verb, rest = argv[0], argv[1:]

    if verb == "inbox":
        if rest:
            refuse("inbox takes no arguments")
        log("inbox")
        print("hint: open mail with `mailcortex-aura read next` or `mailcortex-aura read N`; "
              "never retype a file name. Answer it with `echo TEXT | mailcortex-aura reply` (it fills in everything else).",
              file=sys.stderr)
        run(["inbox", ME])

    if verb == "read":
        if len(rest) != 1 or not FILENAME.match(rest[0]):
            refuse("usage: read FILENAME | read next | read N (no paths)")
        name = resolve_filename(rest[0])
        if not FILENAME.match(name):
            refuse("bad file name")
        if name not in {r[1] for r in inbox_rows() if len(r) > 1}:
            refuse("no message by that name. Do not retype file names: "
                   "use `mailcortex-aura read next` (oldest unread) or `mailcortex-aura read N` (Nth inbox row)")
        log("read", name)
        out = subprocess.run([MAILCORTEX, "read", ME, name], env=ENV, capture_output=True, text=True)
        sys.stdout.write(out.stdout)
        sys.stderr.write(out.stderr)
        if out.returncode == 0:
            remember(out.stdout, name)
        sys.exit(out.returncode)

    if verb == "receipt":
        if len(rest) == 2 and rest[0] == "last":
            rest = [last("message-id"), rest[1]]
        if len(rest) != 2 or not MSGID.match(rest[0]) or rest[1] not in STATES:
            refuse("usage: receipt '<Message-ID>' " + "|".join(sorted(STATES)))
        log("receipt", f"{rest[0]} {rest[1]}")
        run(["receipt", SEAT, rest[0], rest[1]])

    if verb == "send":
        opts, i = {}, 0
        while i < len(rest):
            key = rest[i]
            if key not in ("--to", "--subject", "--in-reply-to") or i + 1 >= len(rest) or key in opts:
                refuse("usage: send --to ADDRESS --subject SUBJECT [--in-reply-to '<Message-ID>'] (body on stdin)")
            opts[key] = rest[i + 1]
            i += 2
        if opts.get("--to") == "last":
            opts["--to"] = last("from")
        if opts.get("--in-reply-to") == "last":
            opts["--in-reply-to"] = last("message-id")
        to, subject = opts.get("--to", ""), opts.get("--subject", "")
        if not ADDR.match(to):
            refuse("recipient must be a fleet address like name@host.helm")
        if not subject or len(subject) > 200 or "\n" in subject or "\r" in subject:
            refuse("subject must be 1-200 characters on one line")
        reply = opts.get("--in-reply-to")
        if reply is not None and not MSGID.match(reply):
            refuse("in-reply-to must be a '<Message-ID>'")
        body = sys.stdin.buffer.read(MAX_BODY + 1)
        if not body.strip():
            refuse("empty body")
        if len(body) > MAX_BODY:
            refuse(f"body over {MAX_BODY} bytes")
        try:
            body.decode("utf-8")
        except UnicodeDecodeError:
            refuse("body must be UTF-8 text")
        log("send", f"to={to} subject_len={len(subject)} body_bytes={len(body)} reply={'yes' if reply else 'no'}")
        with tempfile.TemporaryDirectory(prefix="aura-lane-", dir="/tmp") as tmp:
            path = os.path.join(tmp, "body.txt")
            with open(path, "wb") as fh:
                fh.write(body)
            args = ["send", "--from", ME, "--to", to, "--subject", subject, "--body-file", path, "--print-id"]
            if reply:
                args += ["--in-reply-to", reply]
            env = {"PATH": "/home/metsatron/.local/bin:/usr/local/bin:/usr/bin:/bin", "HOME": "/home/metsatron"}
            sys.exit(subprocess.run([MAILCORTEX, *args], env=env).returncode)

    if verb == "reply":
        if rest:
            refuse("usage: echo TEXT | mailcortex-aura reply   (no arguments; answers the message last read)")
        try:
            with open(LAST) as fh:
                meta = json.load(fh)
        except (OSError, ValueError):
            refuse("no message read yet; run `mailcortex-aura read next` first")
        if meta.get("replied"):
            refuse("already replied to the message last read; run `mailcortex-aura read next` for the next one")
        raw_from, mid = meta.get("from", ""), meta.get("message-id", "")
        to = raw_from.split("<")[-1].rstrip(">").strip() if "<" in raw_from else raw_from.strip()
        if not ADDR.match(to) or to == ME:
            refuse("the message last read has no fleet sender to reply to")
        if not MSGID.match(mid):
            refuse("the message last read has no valid Message-ID")
        subject = meta.get("subject", "").strip() or "(no subject)"
        if not subject.lower().startswith("re:"):
            subject = "Re: " + subject
        subject = subject[:200].replace("\n", " ").replace("\r", " ")
        body = sys.stdin.buffer.read(MAX_BODY + 1)
        if not body.strip():
            refuse("empty body")
        if len(body) > MAX_BODY:
            refuse(f"body over {MAX_BODY} bytes")
        try:
            body.decode("utf-8")
        except UnicodeDecodeError:
            refuse("body must be UTF-8 text")
        # Mark first, so a crash or a retry can never send twice; unmark only on a failed send.
        meta["replied"] = True
        with open(LAST, "w") as fh:
            json.dump(meta, fh)
        log("reply", f"to={to} reply_to={mid} body_bytes={len(body)}")
        with tempfile.TemporaryDirectory(prefix="aura-lane-", dir="/tmp") as tmp:
            path = os.path.join(tmp, "body.txt")
            with open(path, "wb") as fh:
                fh.write(body)
            sent = subprocess.run([MAILCORTEX, "send", "--from", ME, "--to", to, "--subject", subject,
                                   "--body-file", path, "--in-reply-to", mid, "--print-id"], env=ENV)
        if sent.returncode != 0:
            meta["replied"] = False
            with open(LAST, "w") as fh:
                json.dump(meta, fh)
            log("reply-failed", f"rc={sent.returncode}")
            sys.exit(sent.returncode)
        done = subprocess.run([MAILCORTEX, "receipt", SEAT, mid, "handling_completed"], env=ENV)
        log("reply-receipt", f"{mid} rc={done.returncode}")
        print(f"replied to {to} and recorded handling_completed for the message you last read")
        sys.exit(done.returncode)

    refuse("unknown verb; verbs are inbox, read, reply, send, receipt")


if __name__ == "__main__":
    main()

** Tests for the wrapper

These run against a fake =mailcortex= that records its argument lists, so no real mailbox is touched. They cover:
- =read next=;
- the no-identifier =reply=;
- the once-per-read guard;
- the un-marking when a send fails;
- the refusals.

"""Tests for Aura's MailCortex forced-command wrapper (services-mailcortex.org)."""
import importlib.machinery

HERE = pathlib.Path(__file__).resolve()

INBOX = ("seen\t111.1_a.kikin-kushi\tFri\thermes@kikin.helm\tOld\n"
         "new\t222.2_b.kikin-kushi\tSat\thermes@kikin.helm\tWake test ABC\n"

class Fake:
    def __init__(self, send_rc=0):
        self.calls, self.send_rc = [], send_rc

    def __call__(self, argv, env=None, capture_output=False, text=False, **kw):
        args = argv[1:]
        self.calls.append(args)
        out = mock.Mock(returncode=0, stdout="", stderr="")
        if args[0] == "inbox":
            out.stdout = INBOX
        elif args[0] == "read":
            out.stdout = MESSAGE if args[2] == "222.2_b.kikin-kushi" else ""
            out.returncode = 0 if out.stdout else 1
        elif args[0] == "send":
            out.returncode = self.send_rc
        return out


def load(tmp):
    loader = importlib.machinery.SourceFileLoader("aura_wrapper_test", str(WRAPPER))
    spec = importlib.util.spec_from_loader(loader.name, loader)
    mod = importlib.util.module_from_spec(spec)
    loader.exec_module(mod)
    mod.LAST = os.path.join(tmp, "last.json")
    mod.LOG = os.path.join(tmp, "lane.log")
    return mod


def run(mod, fake, command, stdin=b""):
    env = {"SSH_ORIGINAL_COMMAND": command}
    buf = mock.Mock(buffer=io.BytesIO(stdin))
    with mock.patch.dict(os.environ, env), mock.patch.object(mod.subprocess, "run", fake), \
            mock.patch.object(sys, "stdin", buf), mock.patch("sys.stdout", new_callable=io.StringIO), \
            mock.patch("sys.stderr", new_callable=io.StringIO) as err:
        try:
            mod.main()
        except SystemExit as stop:
            return stop.code, err.getvalue()
    return 0, err.getvalue()


class WrapperTests(unittest.TestCase):
    def setUp(self):
        self.tmp = tempfile.mkdtemp(prefix="aura-wrapper-test-")
        self.mod = load(self.tmp)

    def test_read_next_opens_oldest_unread_and_remembers_it(self):
        fake = Fake()
        code, _ = run(self.mod, fake, "read next")
        self.assertEqual(code, 0)
        self.assertIn(["read", "aura@honey.helm", "222.2_b.kikin-kushi"], fake.calls)
        meta = json.load(open(self.mod.LAST))
        self.assertEqual(meta["message-id"], "<222.2.99@kikin.helm>")
        self.assertFalse(meta["replied"])

    def test_mistyped_name_is_refused_with_the_short_form(self):
        code, err = run(self.mod, Fake(), "read 2222.2_b")
        self.assertEqual(code, 2)
        self.assertIn("read next", err)

    def test_reply_derives_recipient_thread_subject_and_receipt(self):
        fake = Fake()
        run(self.mod, fake, "read next")
        code, _ = run(self.mod, fake, "reply", b"received ABC\n")
        self.assertEqual(code, 0)
        send = [c for c in fake.calls if c[0] == "send"][0]
        self.assertEqual(send[send.index("--to") + 1], "hermes@kikin.helm")
        self.assertEqual(send[send.index("--in-reply-to") + 1], "<222.2.99@kikin.helm>")
        self.assertEqual(send[send.index("--subject") + 1], "Re: Wake test ABC")
        self.assertEqual(send[send.index("--from") + 1], "aura@honey.helm")
        self.assertIn(["receipt", "aura", "<222.2.99@kikin.helm>", "handling_completed"], fake.calls)

    def test_reply_sends_only_once_per_read(self):
        fake = Fake()
        run(self.mod, fake, "read next")
        run(self.mod, fake, "reply", b"one\n")
        code, err = run(self.mod, fake, "reply", b"two\n")
        self.assertEqual(code, 2)
        self.assertIn("already replied", err)
        self.assertEqual(len([c for c in fake.calls if c[0] == "send"]), 1)

    def test_failed_send_records_no_receipt_and_allows_a_retry(self):
        fake = Fake(send_rc=1)
        run(self.mod, fake, "read next")
        code, _ = run(self.mod, fake, "reply", b"x\n")
        self.assertEqual(code, 1)
        self.assertFalse([c for c in fake.calls if c[0] == "receipt"])
        self.assertFalse(json.load(open(self.mod.LAST))["replied"])

    def test_reply_without_a_read_or_with_arguments_is_refused(self):
        self.assertEqual(run(self.mod, Fake(), "reply", b"x\n")[0], 2)
        fake = Fake()
        run(self.mod, fake, "read next")
        self.assertEqual(run(self.mod, fake, "reply --to someone@kikin.helm", b"x\n")[0], 2)

    def test_reply_never_answers_her_own_mail(self):
        json.dump({"from": "aura@honey.helm", "message-id": "<1.2@kikin.helm>", "subject": "s", "replied": False},
                  open(self.mod.LAST, "w"))
        self.assertEqual(run(self.mod, Fake(), "reply", b"x\n")[0], 2)


if __name__ == "__main__":
    unittest.main()
