#+AUTHOR: Mètsàtron

* Intent

Music playback as a fleet concern: one daemon (=mpd=), one CLI surface (=mpc=), one library. The library is not a local folder — it is =~/HelmCortex/NADA=, the sacred music archive, NFS-mounted on every machine, so the same songs and the same =.m3u= playlists (=MetsatronLatest=, =Metsatron Top=, per-being folders like =LumenAstra/=, =Eve/=, =Auryn/=) are addressable everywhere without duplication. Agents DJ through =mpc= (see the =dj-mpd= skill in =agents-skills.org=) and humans reach it through the rofi menu on =Super+m= (declared in =menu.org=, which owns all dmenu-family surfaces per the category law).

Packages (=mpd= =mpc=) live in the =package-guix.org= core manifest alongside =vlc= and =rofi= — this file owns the daemon's configuration and startup, per the category-manifest law.

Born 2026-07-12, the quiet evening after the IdeaCentre outage: first spin was LumenAstra's "No Flatten Me (LumenAstra Riddim)", MC'd by Fable through pvox.

* Daemon configuration

Per-user mpd, localhost-only, PulseAudio output. State stays machine-local under =~/.local/state/mpd= (a database over NFS-mounted media is fine; the database itself over NFS is not — each machine indexes its own view). =playlist_directory= points into NADA so the curated =.m3u= playlists appear as native mpd playlists on every machine. =auto_update= keeps the index current when new songs land in the archive.

#+BEGIN_SRC conf :tangle all/.config/mpd/mpd.conf :tangle-mode (identity #o644)
music_directory     "~/HelmCortex/NADA"
playlist_directory  "~/HelmCortex/NADA"
db_file             "~/.local/state/mpd/database"
state_file          "~/.local/state/mpd/state"
sticker_file        "~/.local/state/mpd/sticker.sql"
log_file            "~/.local/state/mpd/mpd.log"
pid_file            "~/.local/state/mpd/pid"

bind_to_address     "127.0.0.1"
port                "6600"
auto_update         "yes"
restore_paused      "yes"
follow_outside_symlinks "yes"
follow_inside_symlinks  "yes"

audio_output {
    type            "pulse"
    name            "PulseAudio"
}
#+END_SRC

* Autostart

mpd self-daemonizes reading the config above; the state directory is created first because mpd will not invent it. Sources the Guix core profile the same way the rofi wrappers in =menu.org= do, so the binary is found regardless of the session's PATH state.

#+BEGIN_SRC bash :tangle linux/.local/bin/mpd-start :shebang "#!/usr/bin/env bash" :tangle-mode (identity #o755)
P="$HOME/.guix-extra-profiles/core/core"; [ -r "$P/etc/profile" ] && . "$P/etc/profile"
set -euo pipefail
mkdir -p "$HOME/.local/state/mpd"
pgrep -u "$USER" -x mpd >/dev/null && exit 0
exec mpd "$HOME/.config/mpd/mpd.conf"
#+END_SRC

#+BEGIN_SRC conf :tangle linux/.config/autostart/mpd.desktop :tangle-mode (identity #o644) :comments no
[Desktop Entry]
Type=Application
Name=mpd
Comment=Music Player Daemon (music.org — library: HelmCortex/NADA)
Exec=/bin/sh -c "$HOME/.local/bin/mpd-start"
X-GNOME-Autostart-enabled=true
#+END_SRC
