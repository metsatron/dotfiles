* Bot Inventory

Stock of all Telegram-connected agents. Only one machine should run a given bot
at a time to avoid duplicate message handling.

| Bot          | Type            | Status   | Transport                    | Port | Machine |
|--------------+-----------------+----------+------------------------------+------+---------|
| Hermes       | gateway (native) | WORKING  | python-telegram-bot webhooks | —    | x230    |
| OpenCode     | wrapper (npm)   | WORKING  | polling / webhook            | 4096 | x230    |
| Ductor       | wrapper (pip)   | PENDING  | Telegram / Matrix            | —    | t480s   |
| Claude Code  | plugin (channel) | PARTIAL  | --channels plugin inline     | —    | any     |
| Codex        | none            | PENDING  | no native bot                | —    | —       |
| Pi Agent     | none            | PENDING  | no native bot (TUI only)     | —    | —       |

** Hermes Agent

Native Telegram gateway via =python-telegram-bot[webhooks]>=22.6=.

- Config: =~/.hermes/config.yaml= under =telegram:= section
- Token + credentials: =~/.hermes/.env= (=TELEGRAM_BOT_TOKEN=)
- Start: =hermes gateway run=
- Toolset: =hermes-telegram= (defined in =platform_toolsets= in config.yaml)
- Platform state: =connected= (last confirmed 2026-04-19)
- Session ID format: =agent:main:telegram:dm:<user_id>=
- Two-way: full conversation agent, tool calls, routines, MCP

** OpenCode Telegram Bot

npm wrapper that sends tasks to a running =opencode serve= backend.

- Package: =@grinev/opencode-telegram-bot= (in npm manifest)
- Config: =~/.config/opencode-telegram-bot/.env=
- Env vars: =TELEGRAM_BOT_TOKEN=, =TELEGRAM_ALLOWED_USER_ID=, =OPENCODE_API_URL=
- Start: =opencode serve &= then =opencode-telegram start=
- Port: 4096 (OpenCode API)
- Env template: =~/.bots/templates/opencode-telegram.env=

** Claude Code (Channel Plugin)

Official Telegram channel plugin =telegram@claude-plugins-official= (bun-based MCP server).
Runs *inline* with the Claude Code session — not a standalone background service.

- Plugin: =~/.claude/plugins/cache/claude-plugins-official/telegram/0.0.6/=
- Activate: launch Claude with =--channels plugin:telegram@claude-plugins-official=
- Token: =~/.claude/channels/telegram/.env= (=TELEGRAM_BOT_TOKEN=)
- Access control: =~/.claude/channels/telegram/access.json= (=dmPolicy=, =allowFrom=)
- Two-way: receives DMs + sends replies; supports inline keyboard, reactions, media
- Skill: =/telegram:configure= to verify token; =/telegram:access= to manage allowlist
- Note: =bun= must be on PATH or use absolute path in plugin =.mcp.json=

** Codex

No native Telegram bot integration. Codex is an interactive terminal TUI.
No =serve= mode, no REST API, no webhook support.

Possible path forward: wrap with a proxy similar to opencode-telegram-bot.
Bot candidates: =codex-telegram= (not yet written), or route through Hermes gateway.

** Pi Agent

No native Telegram bot integration. Pi Agent is a terminal-only interactive TUI
(=@mariozechner/pi-coding-agent=). No =serve= mode, no HTTP API.

Possible path forward: same as Codex — custom wrapper bot, or route through Hermes.

* Agent Control Script

#+BEGIN_SRC bash :tangle all/.local/bin/telegram-agent-host :shebang "#!/usr/bin/env bash"
# ~/DotCortex/all/.local/bin/telegram-agent-host
# Manage which Telegram agents run on this machine

set -euo pipefail

AGENTS_DIR="${DOTCORTEX_AGENTS_DIR:-$HOME/DotCortex/all/.bots}"
CONFIG_DIR="$HOME/.config"
HOSTS_FILE="$AGENTS_DIR/hosts.conf"
STATE_DIR="${XDG_STATE_HOME:-$HOME/.local/state}/telegram-agents"

usage() {
    cat <<EOF
Usage: telegram-agent-host <command> [agent]

Commands:
  list              List all known agents
  status            Show which agents are running
  enable <agent>    Enable agent on this machine
  disable <agent>   Disable agent on this machine
  sync              Sync configs to this machine from DotCortex
  start             Start all enabled agents
  stop              Stop all agents
  switch <machine>  Switch to another machine's agents (disables local, enables remote)
  bring             Bring agents to this machine (stop remote, start local)

Agents: opencode ductor claudecode hermes codex pi-agent

Examples:
  telegram-agent-host list
  telegram-agent-host status
  telegram-agent-host enable opencode
  telegram-agent-host disable opencode
  telegram-agent-host switch x230
EOF
}

mkdir -p "$STATE_DIR"

get_hostname() {
    hostname | tr '[:upper:]' '[:lower:]'
}

get_enabled_agents() {
    local host="$1"
    grep -i "^${host}|" "$HOSTS_FILE" 2>/dev/null | cut -d'|' -f2 | tr ',' ' '
}

is_agent_enabled() {
    local agent="$1"
    local host
    host=$(get_hostname)
    local enabled
    enabled=$(get_enabled_agents "$host")
    echo "$enabled" | grep -qw "$agent"
}

list_agents() {
    echo "Known agents:"
    echo "  opencode    - OpenCode + Telegram bot"
    echo "  ductor      - Ductor + Telegram/Matrix bot"
    echo "  claudecode  - Claude Code (MCP send/receive)"
    echo "  hermes      - Hermes gateway (native Telegram)"
    echo "  codex       - OpenAI Codex (no bot yet)"
    echo "  pi-agent    - Pi Coding Agent (no bot yet)"
    echo ""
    echo "Configured hosts:"
    if [ -f "$HOSTS_FILE" ]; then
        grep -v '^#' "$HOSTS_FILE" | grep -v '^$'
    else
        echo " (no hosts.conf found)"
    fi
}

check_opencode() {
    if pgrep -f "opencode serve" >/dev/null 2>&1; then
        echo "  opencode serve: RUNNING"
    else
        echo "  opencode serve: STOPPED"
    fi
    if pgrep -f "opencode-telegram" >/dev/null 2>&1; then
        echo "  opencode-telegram: RUNNING"
    else
        echo "  opencode-telegram: STOPPED"
    fi
}

check_ductor() {
    if pgrep -f "ductor" >/dev/null 2>&1; then
        echo "  ductor: RUNNING"
    else
        echo "  ductor: STOPPED"
    fi
}

check_claudecode() {
    if pgrep -f "claude.*channels.*telegram" >/dev/null 2>&1; then
        echo "  claudecode (--channels telegram plugin): RUNNING"
    else
        echo "  claudecode (--channels telegram plugin): STOPPED"
    fi
}

check_hermes() {
    if pgrep -f "hermes.*gateway" >/dev/null 2>&1; then
        echo "  hermes gateway run: RUNNING"
    else
        echo "  hermes gateway run: STOPPED"
    fi
}

check_codex() {
    if pgrep -f "codex" >/dev/null 2>&1; then
        echo "  codex: RUNNING"
    else
        echo "  codex: STOPPED"
    fi
}

check_pi_agent() {
    if pgrep -f "pi-agent\|pi-coding-agent" >/dev/null 2>&1; then
        echo "  pi-agent: RUNNING"
    else
        echo "  pi-agent: STOPPED"
    fi
}

status_cmd() {
    local host
    host=$(get_hostname)
    echo "Host: $host"
    echo "Enabled agents: $(get_enabled_agents "$host")"
    echo ""
    echo "Running processes:"
    check_opencode
    check_ductor
    check_claudecode
    check_hermes
    check_codex
    check_pi_agent
}

enable_agent() {
    local agent="$1"
    local host
    host=$(get_hostname)

    if [ ! -f "$HOSTS_FILE" ]; then
        echo "Error: hosts.conf not found at $HOSTS_FILE"
        exit 1
    fi

    local line
    line=$(grep -i "^${host}|" "$HOSTS_FILE" 2>/dev/null || true)
    if [ -z "$line" ]; then
        echo "Error: host '$host' not found in hosts.conf"
        exit 1
    fi

    local current_agents
    current_agents=$(echo "$line" | cut -d'|' -f2)

    if echo "$current_agents" | grep -qw "$agent"; then
        echo "$agent is already enabled on $host"
        return
    fi

    local new_agents
    if [ -z "$current_agents" ]; then
        new_agents="$agent"
    else
        new_agents="$current_agents,$agent"
    fi

    sed -i "s|^${host}|.*|${host}|${new_agents}|I" "$HOSTS_FILE"
    echo "Enabled $agent on $host"
    echo "Run 'telegram-agent-host sync' to apply, then 'telegram-agent-host start'"
}

disable_agent() {
    local agent="$1"
    local host
    host=$(get_hostname)

    if [ ! -f "$HOSTS_FILE" ]; then
        echo "Error: hosts.conf not found at $HOSTS_FILE"
        exit 1
    fi

    local line
    line=$(grep -i "^${host}|" "$HOSTS_FILE" 2>/dev/null || true)
    if [ -z "$line" ]; then
        echo "Error: host '$host' not found in hosts.conf"
        exit 1
    fi

    local current_agents
    current_agents=$(echo "$line" | cut -d'|' -f2)

    if ! echo "$current_agents" | grep -qw "$agent"; then
        echo "$agent is not enabled on $host"
        return
    fi

    local new_agents
    new_agents=$(echo "$current_agents" | tr ',' '\n' | grep -v "^${agent}$" | tr '\n' ',' | sed 's/,$//' | sed 's/^,//')

    sed -i "s|^${host}|.*|${host}|${new_agents}|I" "$HOSTS_FILE"
    echo "Disabled $agent on $host"
    echo "Run 'telegram-agent-host stop $agent' to stop it"
}

sync_configs() {
    echo "Syncing agent configs from DotCortex..."
    local repo="$HOME/DotCortex"

    if [ ! -d "$repo/all/.bots" ]; then
        echo "Error: DotCortex/all/.bots not found"
        exit 1
    fi

    mkdir -p "$HOME/.config/opencode-telegram-bot"
    mkdir -p "$HOME/.config/pi-agent" 2>/dev/null || true
    mkdir -p "$HOME/.config/telegram-agents"

    if [ -f "$repo/all/.bots/hosts.conf" ]; then
        cp "$repo/all/.bots/hosts.conf" "$HOME/.config/telegram-agents/hosts.conf"
    fi

    echo "Config sync complete. Update credentials manually if needed."
}

start_agent() {
    local agent="$1"
    case "$agent" in
        opencode)
            if ! pgrep -f "opencode serve" >/dev/null 2>&1; then
                echo "Starting opencode serve..."
                nohup opencode serve > "$STATE_DIR/opencode-serve.log" 2>&1 </dev/null &
                sleep 2
            fi
            if ! pgrep -f "opencode-telegram" >/dev/null 2>&1; then
                echo "Starting opencode-telegram..."
                nohup ~/.npm-global/bin/opencode-telegram start > "$STATE_DIR/opencode-telegram.log" 2>&1 </dev/null &
                sleep 3
            fi
            ;;
        ductor)
            if command -v ductor >/dev/null 2>&1; then
                echo "Starting ductor..."
                nohup ductor > "$STATE_DIR/ductor.log" 2>&1 </dev/null &
                sleep 3
            else
                echo "ductor not found in PATH"
            fi
            ;;
        claudecode)
            echo "claudecode Telegram runs inline via --channels at session start."
            echo "Launch Claude with: claude --channels plugin:telegram@claude-plugins-official"
            echo "Access control: ~/.claude/channels/telegram/access.json"
            ;;
        hermes)
            if command -v hermes >/dev/null 2>&1; then
                echo "Starting hermes gateway run..."
                nohup hermes gateway run > "$STATE_DIR/hermes.log" 2>&1 &
            else
                echo "hermes not found in PATH"
            fi
            ;;
        codex)
            echo "codex has no Telegram bot — skipping"
            ;;
        pi-agent)
            echo "pi-agent has no Telegram bot — skipping"
            ;;
        *)
            echo "Unknown agent: $agent"
            exit 1
            ;;
    esac
    echo "$agent started"
}

stop_agent() {
    local agent="$1"
    case "$agent" in
        opencode)
            pkill -f "opencode-telegram" 2>/dev/null || true
            pkill -f "opencode serve" 2>/dev/null || true
            ;;
        ductor)
            pkill -f "ductor" 2>/dev/null || true
            ;;
        claudecode)
            pkill -f "claude.*channels.*telegram" 2>/dev/null || true
            ;;
        hermes)
            pkill -f "hermes.*gateway" 2>/dev/null || true
            ;;
        codex)
            pkill -f "codex" 2>/dev/null || true
            ;;
        pi-agent)
            pkill -f "pi-agent\|pi-coding-agent" 2>/dev/null || true
            ;;
        *)
            echo "Unknown agent: $agent"
            exit 1
            ;;
    esac
    echo "$agent stopped"
}

start_all() {
    local host
    host=$(get_hostname)
    local agents
    agents=$(get_enabled_agents "$host")

    if [ -z "$agents" ]; then
        echo "No agents enabled for $host. Run 'telegram-agent-host enable <agent>' first."
        exit 1
    fi

    echo "Starting enabled agents for $host: $agents"
    for agent in $agents; do
        start_agent "$agent"
    done
}

stop_all() {
    for agent in opencode ductor claudecode hermes codex pi-agent; do
        stop_agent "$agent" 2>/dev/null || true
    done
    echo "All agents stopped"
}

switch_to_machine() {
    local target="$1"
    local current_host
    current_host=$(get_hostname)

    if [ "$current_host" = "$target" ]; then
        echo "Already on $target"
        return
    fi

    local target_agents
    target_agents=$(get_enabled_agents "$target")

    if [ -z "$target_agents" ]; then
        echo "No agents configured for $target"
        exit 1
    fi

    local target_ssh
    target_ssh=$(grep -i "^${target}|" "$HOSTS_FILE" 2>/dev/null | cut -d'|' -f3)

    echo "Switching from $current_host to $target"

    echo "Stopping all agents on $current_host..."
    stop_all

    echo "Stopping agents on $target before restart..."
    if [ -n "$target_ssh" ]; then
        ssh "$target_ssh" "pkill -f 'opencode-telegram' 2>/dev/null || true; pkill -f 'opencode serve' 2>/dev/null || true; pkill -f 'ductor' 2>/dev/null || true; pkill -f 'hermes.*gateway' 2>/dev/null || true" 2>/dev/null || true
        sleep 1
    fi

    echo "Starting agents on $target via SSH..."
    if [ -n "$target_ssh" ]; then
        ssh "$target_ssh" "\$HOME/.local/bin/telegram-agent-remote-start $target_agents"
        echo "Switched to $target"
    else
        echo "No SSH config for $target. Manually start on target machine:"
        echo " ssh $target"
        echo " telegram-agent-host start"
    fi
    echo ""
    echo "Enabled on $target: $target_agents"
}

bring_here() {
    local current_host
    current_host=$(get_hostname)
    local agents
    agents=$(get_enabled_agents "$current_host")

    if [ -z "$agents" ]; then
        echo "No agents configured for $current_host"
        exit 1
    fi

    echo "Bringing agents to $current_host..."

    for host_line in $(grep -v '^#' "$HOSTS_FILE" | grep -v '^$'); do
        local other_host
        other_host=$(echo "$host_line" | cut -d'|' -f1)
        if [ "$other_host" != "$current_host" ]; then
            local other_ssh
            other_ssh=$(echo "$host_line" | cut -d'|' -f3)
            if [ -n "$other_ssh" ]; then
                echo "Stopping agents on $other_host..."
                ssh "$other_ssh" "pkill -f 'opencode-telegram' 2>/dev/null || true; pkill -f 'opencode serve' 2>/dev/null || true; pkill -f 'ductor' 2>/dev/null || true; pkill -f 'hermes.*gateway' 2>/dev/null || true" 2>/dev/null || true
            fi
        fi
    done

    sleep 1
    echo "Starting agents locally..."
    start_all
}

COMMAND="${1:-}"
shift || true

case "$COMMAND" in
    list) list_agents ;;
    status) status_cmd ;;
    enable) enable_agent "${1:-}" ;;
    disable) disable_agent "${1:-}" ;;
    sync) sync_configs ;;
    start)
        if [ -n "${1:-}" ]; then
            start_agent "$1"
        else
            start_all
        fi
        ;;
    stop)
        if [ -n "${1:-}" ]; then
            stop_agent "$1"
        else
            stop_all
        fi
        ;;
    switch) switch_to_machine "${1:-}" ;;
    bring) bring_here ;;
    *) usage; exit 1 ;;
esac
#+END_SRC

* Remote Start Helper

This script runs on the target machine via SSH. It kills existing processes,
starts new ones, waits for confirmation, then exits cleanly.

#+BEGIN_SRC bash :tangle all/.local/bin/telegram-agent-remote-start :shebang "#!/usr/bin/env bash"
# ~/DotCortex/all/.local/bin/telegram-agent-remote-start
# Run on target machine via SSH to start agents.
# Usage: telegram-agent-remote-start <agent> [agent ...]

set -euo pipefail

STATE_DIR="${XDG_STATE_HOME:-$HOME/.local/state}/telegram-agents"
mkdir -p "$STATE_DIR"

for agent in "$@"; do
    case "$agent" in
    opencode)
        echo "Stopping existing opencode processes..."
        pkill -f "opencode-telegram" 2>/dev/null || true
        pkill -f "opencode serve" 2>/dev/null || true
        sleep 1
        echo "Starting opencode serve..."
        nohup opencode serve > "$STATE_DIR/opencode-serve.log" 2>&1 </dev/null &
        disown
        sleep 3
        echo "Starting opencode-telegram..."
        nohup ~/.npm-global/bin/opencode-telegram start > "$STATE_DIR/opencode-telegram.log" 2>&1 </dev/null &
        disown
        sleep 3
        if pgrep -f "opencode-telegram" >/dev/null 2>&1; then
            echo "opencode-telegram: STARTED OK"
        else
            echo "opencode-telegram: FAILED TO START"
        fi
        ;;
    ductor)
        echo "Stopping existing ductor process..."
        pkill -f "ductor" 2>/dev/null || true
        sleep 1
        echo "Starting ductor..."
        nohup ductor > "$STATE_DIR/ductor.log" 2>&1 </dev/null &
        disown
        sleep 3
        if pgrep -f "ductor" >/dev/null 2>&1; then
            echo "ductor: STARTED OK"
        else
            echo "ductor: FAILED TO START"
        fi
        ;;
    hermes)
        echo "Stopping existing hermes processes..."
        pkill -f "hermes.*gateway" 2>/dev/null || true
        sleep 1
        echo "Starting hermes gateway run..."
        nohup hermes gateway run > "$STATE_DIR/hermes.log" 2>&1 </dev/null &
        disown
        sleep 3
        if pgrep -f "hermes.*gateway" >/dev/null 2>&1; then
            echo "hermes gateway: STARTED OK"
        else
            echo "hermes gateway: FAILED TO START"
        fi
        ;;
    *)
        echo "Agent $agent not yet supported for remote start"
        ;;
    esac
done
#+END_SRC

* Sync Script for X230

#+BEGIN_SRC bash :tangle all/.local/bin/telegram-agent-sync-x230 :shebang "#!/usr/bin/env bash"
# ~/DotCortex/all/.local/bin/telegram-agent-sync-x230
# Sync telegram-agent config to X230

set -euo pipefail

DOTCORTEX="$HOME/DotCortex"
X230_HOST="x230"
STATE_DIR="${XDG_STATE_HOME:-$HOME/.local/state}/telegram-agents"

echo "== Syncing Telegram Agent configs to X230 =="

# Sync hosts.conf
echo "Syncing hosts.conf..."
rsync -az --rsync-path="mkdir -p ~/.config && rsync" "$DOTCORTEX/all/.bots/hosts.conf" "$X230_HOST:~/.config/telegram-agents/hosts.conf" 2>/dev/null || \
    scp "$DOTCORTEX/all/.bots/hosts.conf" "$X230_HOST:~/.config/telegram-agents/hosts.conf"

# Sync opencode-telegram-bot config if it exists locally
if [ -f "$HOME/.config/opencode-telegram-bot/.env" ]; then
    echo "Syncing opencode-telegram-bot .env..."
    ssh "$X230_HOST" "mkdir -p ~/.config/opencode-telegram-bot"
    rsync -az --rsync-path="mkdir -p ~/.config && rsync" "$HOME/.config/opencode-telegram-bot/.env" "$X230_HOST:~/.config/opencode-telegram-bot/.env" 2>/dev/null || \
        scp "$HOME/.config/opencode-telegram-bot/.env" "$X230_HOST:~/.config/opencode-telegram-bot/.env"
fi

echo "Sync complete."
echo "On X230, run:"
echo "  cd ~/DotCortex && make tangle"
echo "  telegram-agent-host sync"
echo "  telegram-agent-host status"
#+END_SRC
