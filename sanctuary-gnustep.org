* Purpose

=sanctuary-gnustep= is the GNU/NeXT lineage room: Window Maker proves the NeXTSTEP grammar today and GNUstep restores the OpenStep runtime underneath it. This stock GNUstep substrate remains the primary recreation, while compatible NEXTSPACE theme and cursor assets are projected into it as a visual layer. [[https://github.com/trunkmaster/nextspace][NEXTSPACE]]'s alternative Workspace session remains optional and is not a dependency of this room. The icon layer is non-negotiable: NeXTSTEP isometric icons, period-correct substitutions.

Like every sanctuary it rides the one-store-many-rooms Guix substrate from =sanctuary-distrobox.org=: base image =sanctuary-base:guix=, host =/gnu/store= read-only, a dedicated =sanctuary-gnustep= Guix profile (manifest in =package-guix-habitat.org=). Xephyr display is *=:91=*, host Desktop 3 (=Ctrl+F3=) — the full lineage: =:90= qtile, =:91= gnustep, =:92= cde, =:93= redstone-9x, =:94= godzilla-xs and retropie, =:95= mide, =:96= nscde.

The authenticity build-out is phased (plan sealed 2026-07-30):
- *Phase A — NeXT look* (this file, live): tangled Window Maker defaults with black focused titlebars and NeXT grays, =NewStyle = new= caption buttons, solid =#555577= workspace — the room's selected full-color NeXTSTEP/OPENSTEP desktop background — TeX Gyre Heros (Helvetica-metric) titles, a curated root menu, and a declarative right-edge dock carrying the Guix dockapp roster.
- *Phase B — GNUstep runtime*: source build in-guest (=gnustep-base/gui/back= are not in Guix; there is no apt in the sanctuary — ruled 2026-07-30), gnustep-make + libobjc2 from Guix, GWorkspace as the Workspace Manager. Follows the =sanctuary-nscde-build= sentinel pattern. Stage 0 also builds the dockapps Guix lacks (asclock — the canonical NeXT dock clock — wmmon, wmmemload, wmnet, wmmoonclock).
- *Phase C — NEXTSPACE alternative session* (research gate closed 2026-07-30, ruled 2026-07-31, deferred 2026-08-03): NEXTSPACE's Workspace.app *embeds* a modified Window Maker in-process (wmaker's =main()= disabled via =#ifndef NEXTSPACE=, event loop on a libdispatch queue) — it can never run atop the stock wmaker session. If it is ever built, it arrives as an optional second session where Workspace replaces wmaker (Login skipped — launchers exec sessions directly; =libudisks2= linkage satisfied from Guix with mounting degraded). It is non-blocking and may become redundant; GWorkspace stays the primary session's Workspace Manager.
- *Phase D — icon and widget layer*: build the pinned NEXTSPACE GNUstep theme and cursor payload into the existing stock Cairo runtime, enable both, and keep the runtime probe's =no_desktop= safeguard so GWorkspace's managed viewer remains visible. The donor theme's folder artwork and stippled controls render correctly with the current backend. Window Maker's outer frame remains its compiled =next= style because the alternative NEXTSPACE Workspace session embeds its own modified Window Maker and remains out of scope.

* Window Maker defaults — the NeXT look

Curated =~/GNUstep/Defaults/WindowMaker= attribute set, projected into the guest home at every launch (Window Maker fills unlisted keys with its own defaults). Style decisions: focused titlebars are solid black with white text — the NeXTSTEP signature — unfocused are the light widget gray, owner-of-focus the dark gray; =NewStyle = new= selects the new-style caption-button rendering; menus are black-titled over gray bodies; the workspace is solid =#555577=. GWorkspace also paints the desktop, so the launcher projects the same colour into its one =desktopinfo.backcolor= key rather than letting its private persisted default win. Fonts resolve through fontconfig to TeX Gyre Heros (the Helvetica-metric clone, =font-tex-gyre= in the profile) with a =sans= fallback.

The caption geometry and glyphs are Window Maker 0.96.0's compiled =next=
style, which matches its bundled NeXT-style reference but is an approximation
rather than the original NeXTSTEP/OpenStep artwork. Exact period buttons require
rebuilding Window Maker with replacement titlebar bitmaps. NEXTSPACE remains
an optional comparison session, not a prerequisite for the primary room.

* GNUstep zsh identity

GNUstep's Terminal should feel like the room, not inherit the host's modern
Starship prompt. This rc sources the shared DotCortex configuration first so
aliases and functions remain available, removes Starship's prompt hook, and
then applies a restrained NeXTSTEP-style prompt.

#+BEGIN_SRC bash :tangle linux/.config/gnustep-sanctuary/shell/zshrc :comments no :mkdirp yes
# GNUstep sanctuary zsh rc — classic NeXTSTEP-style prompt.
# The launcher symlinks this room rc over the shared ~/.zshrc.
if [[ -f "${HOME}/DotCortex/all/.zshrc" ]]; then
  DOTCORTEX_DISABLE_SSH_AGENT=1 source "${HOME}/DotCortex/all/.zshrc"
  unset SSH_AUTH_SOCK SSH_AGENT_PID
fi

# The shared rc initializes Starship for modern host sessions. Remove its
# precmd hook here so it cannot redraw over the room prompt.
precmd_functions=(${precmd_functions:#prompt_starship_precmd})
PROMPT='%F{7}GNUstep:%F{8}%~%F{7}%#%f '
unset RPROMPT
#+END_SRC

* Dock — declarative WMState template

The dock is declarative: this template is projected at every launch (ruled 2026-07-30 — in-room dock rearrangements are intentionally ephemeral, matching the Redstone scheme philosophy). =@DOCK_X@= is substituted by the launcher with =room width − 64= so the tower hugs the right edge — the NeXT dock convention — at whatever geometry Xephyr got. The first tile is the running GWorkspace bundle, giving the Window Maker dock the NeXT cube icon and its bevel; the remaining tiles carry the Guix dockapp roster, including =wmamixer= as the room's useful audio-control tile. Asclock and the rest of the missing-from-Guix set join in Phase B stage 0. =Name= values are the dockapps' =WM_CLASS= instance.class pairs (verified live 2026-07-30 and for wmamixer in this pass). A small launcher-side shelf helper moves Window Maker's minimized client icons into the empty column directly below these six dock tiles; Window Maker itself only exposes corner-based icon placement, so this preserves the right-edge grammar without hiding them behind the GWorkspace tab shelf.

* Minimized-window shelf

Window Maker supports top/bottom/left/right icon placement, but it does not
provide a declarative starting offset beneath a dock. With =IconPosition = trv=
it correctly keeps miniwindows at the right, but starts them in the adjacent
column so they avoid the dock. This host-side helper watches the adjacent
64×64 miniwindow column and moves only frames that actually contain a client
window below the six-tile dock. It assigns stable slots for the lifetime of
each X window, so opening or closing one icon does not compact the others and
leave jumpy or blank tiles. It is deliberately separate from Window Maker's
state: the window manager remains responsible for iconification, while the
helper supplies the missing visual shelf geometry.

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-gnustep-icon-shelf :shebang "#!/usr/bin/env bash" :mkdirp yes
# Keep Window Maker miniwindows in a visible shelf below the NeXT dock.
set -euo pipefail

DISPLAY_NUM="${1:-:91}"
ROOM_WIDTH="${2:-1920}"
DOCK_TILES="${3:-6}"
ICON_SIZE=64
SOURCE_X=$((ROOM_WIDTH - (ICON_SIZE * 2)))
TARGET_X=$((ROOM_WIDTH - ICON_SIZE))
TARGET_Y=$((DOCK_TILES * ICON_SIZE))

XWININFO="${XWININFO:-/usr/bin/xwininfo}"
XDOTOOL="${XDOTOOL:-/usr/bin/xdotool}"
export DISPLAY="${DISPLAY_NUM}"
export XAUTHORITY="${XAUTHORITY:-${HOME}/.Xauthority}"

[[ -x "${XWININFO}" ]] || exit 0
[[ -x "${XDOTOOL}" ]] || exit 0

declare -A slots=()

while :; do
  # Keep assignments for live frames even after they leave SOURCE_X. A moved
  # frame is no longer a source-column candidate, but it still owns its slot.
  for window_id in "${!slots[@]}"; do
    if ! "${XWININFO}" -id "${window_id}" -tree >/dev/null 2>&1; then
      unset "slots[${window_id}]"
    fi
  done

  mapfile -t miniwindows < <(
    "${XWININFO}" -root -tree 2>/dev/null | awk -v source_x="${SOURCE_X}" '
      /^     0x[0-9a-f]+ / {
        # Window Maker own app icon occupies y=0 in this adjacent column;
        # minimized client icons begin at the next 64px tile.
        if (index($0, "64x64+" source_x "+") &&
            index($0, "64x64+" source_x "+0 ") == 0) print $1
      }
    '
  )

  for window_id in "${miniwindows[@]}"; do
    [[ "${window_id}" =~ ^0x[0-9a-f]+$ ]] || continue
    [[ -n "${slots[${window_id}]+assigned}" ]] && continue

    # Empty Window Maker frames are stale containers, not application icons.
    # Never move them into the dock column: doing so creates the blank tiles
    # seen after a power-loss restart or a client disappearing mid-iconify.
    child_count=$("${XWININFO}" -id "${window_id}" -tree 2>/dev/null |
      awk '/children:/{print $2; exit}')
    [[ "${child_count}" =~ ^[1-9][0-9]*$ ]] || continue

    slot=0
    while :; do
      occupied=0
      for assigned_slot in "${slots[@]}"; do
        if [[ "${assigned_slot}" == "${slot}" ]]; then
          occupied=1
          break
        fi
      done
      ((occupied == 0)) && break
      slot=$((slot + 1))
    done

    slots["${window_id}"]="${slot}"
    "${XDOTOOL}" windowmove "${window_id}" "${TARGET_X}" "$((TARGET_Y + slot * ICON_SIZE))" >/dev/null 2>&1 || true
  done
  sleep 1
done
#+END_SRC

static unsigned long
colour(Display *display, Colormap colormap, const char *spec)
{
  XColor exact;
  if (!XParseColor(display, colormap, spec, &exact) ||
      !XAllocColor(display, colormap, &exact)) {
    return BlackPixel(display, DefaultScreen(display));
  }
  return exact.pixel;
}

static void
draw_tile_background(Display *display, Window window, GC gc, Colormap colormap)
{
  unsigned long light = colour(display, colormap, "#ffffff");
  unsigned long inner_dark = colour(display, colormap, "#23242b");
  unsigned long dark = colour(display, colormap, "#000000");
  unsigned long diagonal[120] = {0};
  unsigned int x;
  unsigned int y;

  /* This is the same 64x64 common_Tile.tiff geometry shipped by the pinned
     NEXTSPACE theme: two white pixels at the upper/left edge, two near-black
     pixels at the lower/right edge, and a cool gray diagonal interpolation
     through the interior. Keep it in the dockapp so the custom tile and WM's
     tpixmap IconBack share one surface instead of drifting by a shade. */
  XSetForeground(display, gc, light);
  XFillRectangle(display, window, gc, 0, 0, 64, 64);
  for (y = 2; y < 62; y++) {
    for (x = 2; x < 62; x++) {
      unsigned int distance = x + y - 4;
      char spec[32];
      int red = 170 - (int) ((distance * 83 + 59) / 118);
      int blue = 183 - (int) ((distance * 80 + 59) / 118);
      if (diagonal[distance] == 0) {
        snprintf(spec, sizeof(spec), "#%02x%02x%02x", red, red, blue);
        diagonal[distance] = colour(display, colormap, spec);
      }
      XSetForeground(display, gc, diagonal[distance]);
      XDrawPoint(display, window, gc, x, y);
    }
  }
  XSetForeground(display, gc, inner_dark);
  XDrawLine(display, window, gc, 62, 2, 62, 61);
  XDrawLine(display, window, gc, 2, 62, 61, 62);
  XSetForeground(display, gc, dark);
  XDrawLine(display, window, gc, 63, 0, 63, 63);
  XDrawLine(display, window, gc, 0, 63, 63, 63);
}

static void
draw_logo(Display *display, Window window, GC gc, Colormap colormap)
{
  unsigned long pixels[256] = {0};
  unsigned int i;
  unsigned int x;
  unsigned int y;

  for (i = 0; i < 8; i++) {
    char symbol;
    char spec[32];
    if (sscanf(nextstep_logo[i + 1], "%c c %31s", &symbol, spec) != 2) {
      continue;
    }
    if (strcmp(spec, "None") != 0) {
      pixels[(unsigned char) symbol] = colour(display, colormap, spec);
    }
  }

  /* Fill the two-pixel bevel's interior directly from the 60px SVG-derived
     XPM. The vector source is rasterized at the display size before build;
     there is no runtime enlargement of a smaller raster. */
  for (y = 0; y < LOGO_DRAW_SIZE; y++) {
    for (x = 0; x < LOGO_DRAW_SIZE; x++) {
      unsigned char symbol =
        (unsigned char) nextstep_logo[y + 9][x];
      /* '+' is transparent; a literal space is the cube's dark fill. */
      if (symbol != '+') {
        XSetForeground(display, gc, pixels[symbol]);
        XDrawPoint(display, window, gc, x + LOGO_OFFSET, y + LOGO_OFFSET);
      }
    }
  }
}

* NeXTSTEP application catalogue

The catalogue separates three truths which are easy to conflate in a
retro-computing room: applications already installed in this guest, official
GNUstep continuations which can be built into the same prefix, and period
applications which are documented by the GNUstep Application Project (GAP)
but still need a source/build recipe. Only the first class is emitted into
Window Maker's menu. A catalogue entry is useful even when it is not runnable:
it gives the next build pass a named, provenance-backed target instead of
turning a remembered NeXTSTEP title into a fake launcher.

The first official wave is deliberately small and well-supported: Gorm is the
GNUstep Interface Builder continuation, ProjectCenter is the IDE,
SystemPreferences supplies the classic Preferences role, and the GNU Emacs
wrapper provides the room's editor entry. The first archive tranche adds
GMines, GShisen, GMastermind, and GSPdf from hash-verified GAP releases. These
ten applications are now installed and menu-linked in the live guest. The
catalogue now also carries the wider period surface from the recovered
Window Maker session: Terminal, TextEdit, Ink, Preview, ImageViewer, GNUMail,
PRICE, PikoPixel, Grr, SimpleAgenda, AddressManager, Zipper, TalkSoup, and
LaternaMagica. The source-pinned build wave covers the recoverable games and
accessories, plus the modern GNUstep StepDown Markdown editor and Billiards
game. Sudoku, LapisPuzzle, and Jigsaw have passed the guest build and
bundle-check gates; NeXTGo and Ladder remain source-pinned but blocked by
legacy source compatibility errors. LaternaMagica is a small period-style
GNUstep image viewer: an image/slide viewer rather than a game, and a good
candidate for testing the room's classic image/document associations.

StepDown and Billiards use exact upstream Git commits. ScoreMaker is recorded
as a source candidate with a custom bundle adapter still required because its
upstream GNUstep makefile produces a standalone binary and links an optional
AVFoundation compatibility library. NetSurf is recorded separately because
its GNUstep port requires the full NetSurf workspace and frontend build rather
than the catalogue helper's self-contained application recipe. These entries
remain honest build or research candidates until each has passed a guest
build, bundle check, and launcher test.

The =source=, =ref=, =source URL=, and =sha256= fields make the provenance
explicit rather than claiming that a package is already installed. =github=
and =tarball= rows are eligible for =sanctuary-gnustep-apps build=;
=gap= rows remain catalogue-only until their upstream source/archive is pinned
and its build path is tested. A source-pinned row is reported separately from
an installed row in the ledger, so a release archive cannot masquerade as a
runnable application. This is the same availability ledger discipline used
by the MiDesktop KDE 1 catalogue. The optional NEXTSPACE session is not a
prerequisite for promoting any catalogue entry.

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-gnustep-apps :shebang "#!/usr/bin/env bash"
# Inventory, build, check, and materialise the GNUstep NeXTSTEP catalogue.
set -euo pipefail

usage() {
  cat <<'EOF'
sanctuary-gnustep-apps - catalogue the NeXTSTEP-era GNUstep application surface

Usage:
  sanctuary-gnustep-apps inventory       print the catalogue as TSV
  sanctuary-gnustep-apps ledger          write the persistent guest-home ledger
  sanctuary-gnustep-apps menu            write the verified Window Maker submenu
  sanctuary-gnustep-apps build <id>      build an explicitly buildable app
  sanctuary-gnustep-apps check <id>      verify an installed app bundle

The menu contains only executable bundles found in the persistent GNUstep
prefix. Source-pinned rows are recorded as build candidates until a live build
and bundle check succeeds; GAP catalogue rows remain research candidates.
EOF
}

MODE="${1:-inventory}"
APP_ID="${2:-}"
case "$MODE" in
  -h|--help)
    usage
    exit 0
    ;;
  inventory|ledger|menu)
    ;;
  build|check)
    [[ -n "$APP_ID" ]] || { usage >&2; exit 2; }
    ;;
  *)
    usage >&2
    exit 2
    ;;
esac

SANCTUARY="sanctuary-gnustep"
GUESTS_DIR="${XDG_DATA_HOME:-$HOME/.local/share}/dotcortex/guests"
GUEST_HOME="${GUESTS_DIR}/${SANCTUARY}/home"
PREFIX="${GNUSTEP_PREFIX:-${GUEST_HOME}/.local/share/gnustep}"
CATALOGUE_FILE="${GNUSTEP_CATALOGUE:-${HOME}/DotCortex/all/.config/gnustep-sanctuary/apps.ssv}"
LEDGER="${GNUSTEP_LEDGER:-${GUEST_HOME}/.local/share/gnustep/catalogue.tsv}"
MENU_FILE="${GNUSTEP_MENU:-${GUEST_HOME}/GNUstep/Defaults/ApplicationsCatalogue}"

[[ -r "$CATALOGUE_FILE" ]] || {
  echo "sanctuary-gnustep-apps: missing catalogue: $CATALOGUE_FILE" >&2
  exit 1
}

app_path() {
  local bundle="$1" binary="$2" result
  [[ -d "$PREFIX" ]] || return 1
  result="$(find "$PREFIX" -type f -path "*/${bundle}/${binary}" -print -quit 2>/dev/null || true)"
  [[ -n "$result" && -x "$result" ]] || return 1
  printf '%s\n' "$result"
}

find_record() {
  local wanted="$1"
  local id category display bundle binary source_kind ref source_url sha256 provenance
  while IFS='|' read -r id category display bundle binary source_kind ref source_url sha256 provenance; do
    [[ -z "$id" || "$id" == \#* ]] && continue
    if [[ "$id" == "$wanted" ]]; then
      APP_CATEGORY="$category"
      APP_DISPLAY="$display"
      APP_BUNDLE="$bundle"
      APP_BINARY="$binary"
      APP_SOURCE_KIND="$source_kind"
      APP_REF="$ref"
      APP_SOURCE_URL="$source_url"
      APP_SHA256="$sha256"
      APP_PROVENANCE="$provenance"
      return 0
    fi
  done < "$CATALOGUE_FILE"
  return 1
}

inventory() {
  local id category display bundle binary source_kind ref source_url sha256 provenance path status launch
  printf 'status\tcategory\tname\tid\tlaunch\tlocation\tprovenance\n'
  while IFS='|' read -r id category display bundle binary source_kind ref source_url sha256 provenance; do
    [[ -z "$id" || "$id" == \#* ]] && continue
    path="$(app_path "$bundle" "$binary" || true)"
    if [[ -n "$path" ]]; then
      launch="openapp $binary"
      if [[ -f "$MENU_FILE" ]] && grep -Fq "openapp $binary" "$MENU_FILE"; then
        status='installed-and-menu-linked'
      else
        status='installed-unlisted'
      fi
    elif [[ ( "$source_kind" == github && -n "$source_url" && -n "$ref" ) || ( "$source_kind" == tarball && -n "$source_url" && -n "$sha256" ) ]]; then
      launch="openapp $binary"
      status='source-pinned'
      path=''
    elif [[ "$source_kind" == gap ]]; then
      launch="openapp $binary"
      status='catalogued-source'
      path=''
    else
      launch=''
      status='missing'
      path=''
    fi
    printf '%s\t%s\t%s\t%s\t%s\t%s\t%s\n' \
      "$status" "$category" "$display" "$id" "$launch" "$path" "$provenance"
  done < "$CATALOGUE_FILE"
}

write_ledger() {
  mkdir -p "$(dirname "$LEDGER")"
  local tmp
  tmp="$(mktemp "${LEDGER}.tmp.XXXXXX")"
  trap 'rm -f "$tmp"' EXIT
  inventory > "$tmp"
  mv -f "$tmp" "$LEDGER"
  trap - EXIT
  printf 'sanctuary-gnustep-apps: wrote %s\n' "$LEDGER"
}

write_menu() {
  mkdir -p "$(dirname "$MENU_FILE")"
  local tmp id category display bundle binary source_kind ref source_url sha256 provenance path entry
  local -a category_order=(Accessories Games Development Graphics Multimedia Networking)
  declare -A rows=()
  while IFS='|' read -r id category display bundle binary source_kind ref source_url sha256 provenance; do
    [[ -z "$id" || "$id" == \#* ]] && continue
    path="$(app_path "$bundle" "$binary" || true)"
    [[ -n "$path" ]] || continue
    entry="    (\"$display\", EXEC, \"openapp $binary\"),"
    if [[ -v "rows[$category]" ]]; then
      rows["$category"]+="${entry}"$'\n'
    else
      rows["$category"]="${entry}"$'\n'
    fi
  done < "$CATALOGUE_FILE"

  tmp="$(mktemp "${MENU_FILE}.tmp.XXXXXX")"
  trap 'rm -f "$tmp"' EXIT
  {
    printf '(\n'
    printf '  "NeXTSTEP Catalogue",\n'
    local wrote=0
    local category
    for category in "${category_order[@]}"; do
      [[ -v "rows[$category]" ]] || continue
      printf '  (\n'
      printf '    %s,\n' "$category"
      printf '%s' "${rows[$category]}"
      printf '  ),\n'
      wrote=1
    done
    if (( wrote == 0 )); then
      printf '  ("No verified applications", SHEXEC, "echo No verified GNUstep applications are installed yet")\n'
    fi
    printf ')\n'
  } > "$tmp"
  mv -f "$tmp" "$MENU_FILE"
  trap - EXIT
  printf 'sanctuary-gnustep-apps: wrote %s\n' "$MENU_FILE"
}

# sanctuary-teardown-stale-session can stop the room wrapper while guest
# children remain alive in the shared PID namespace. GNUstep's port registry
# is likewise shared through /tmp, so a power-loss restart can leave a dead
# GWorkspace name (or a duplicate live Workspace Manager) behind. Remove only
# the exact GWorkspace executable and only port records whose owning PID is no
# longer alive; never sweep another GNUstep application's live registration.
cleanup_gworkspace_runtime() {
  local runtime_root="/tmp/GNUstepSecure${UID}"
  local gws_path="${GUEST_HOME}/.local/share/gnustep/lib/GNUstep/Applications/GWorkspace.app/GWorkspace"
  local fswatcher_path="${GUEST_HOME}/.local/share/gnustep/bin/fswatcher"
  local ddbd_path="${GUEST_HOME}/.local/share/gnustep/bin/ddbd"
  local app_root="${GUEST_HOME}/.local/share/gnustep/lib/GNUstep/Applications/"
  local name_file port_file port_path port_pid pid
  local -a gws_pids fswatcher_pids ddbd_pids app_pids

  mapfile -t gws_pids < <(
    ps -eo pid=,args= | awk -v path="${gws_path}" \
      'index($0, path) { print $1 }'
  )
  for pid in "${gws_pids[@]}"; do
    [[ "${pid}" =~ ^[0-9]+$ ]] || continue
    kill -TERM "${pid}" 2>/dev/null || true
  done
  for _ in {1..20}; do
    mapfile -t gws_pids < <(
      ps -eo pid=,args= | awk -v path="${gws_path}" \
        'index($0, path) { print $1 }'
    )
    ((${#gws_pids[@]} == 0)) && break
    sleep 0.1
  done
  for pid in "${gws_pids[@]}"; do
    [[ "${pid}" =~ ^[0-9]+$ ]] || continue
    kill -KILL "${pid}" 2>/dev/null || true
  done

  # A power-loss restart can leave fswatcher orphaned after GWorkspace dies.
  # It owns a live GNUstep name, so the generic dead-record pass below cannot
  # identify it as stale.  Preserve it whenever another GNUstep application
  # is still using the shared daemon; otherwise remove only this exact binary.
  mapfile -t app_pids < <(
    ps -eo pid=,args= | awk -v path="${app_root}" \
      'index($0, path) { print $1 }'
  )
  if ((${#app_pids[@]} == 0)); then
    mapfile -t fswatcher_pids < <(
      ps -eo pid=,args= | awk -v path="${fswatcher_path}" \
        '$2 == path && $3 == "--daemon" && $4 == "--auto" { print $1 }'
    )
    for pid in "${fswatcher_pids[@]}"; do
      [[ "${pid}" =~ ^[0-9]+$ ]] || continue
      kill -KILL "${pid}" 2>/dev/null || true
    done
    mapfile -t ddbd_pids < <(
      ps -eo pid=,args= | awk -v path="${ddbd_path}" \
        '$2 == path && $3 == "--daemon" && $4 == "--auto" { print $1 }'
    )
    for pid in "${ddbd_pids[@]}"; do
      [[ "${pid}" =~ ^[0-9]+$ ]] || continue
      kill -KILL "${pid}" 2>/dev/null || true
    done
  fi

  [[ -d "${runtime_root}/NSMessagePort" ]] || return 0
  for name_file in "${runtime_root}/NSMessagePort/names/"*; do
    [[ -f "${name_file}" ]] || continue
    port_path="$(sed -n '1p' "${name_file}" 2>/dev/null || true)"
    port_pid="$(sed -n '2p' "${name_file}" 2>/dev/null || true)"
    if [[ "${port_pid}" =~ ^[0-9]+$ ]] && kill -0 "${port_pid}" 2>/dev/null; then
      continue
    fi
    rm -f "${name_file}"
    [[ "${port_path}" == "${runtime_root}/NSMessagePort/ports/"* ]] && \
      rm -f "${port_path}"
  done
  for port_file in "${runtime_root}/NSMessagePort/ports/"*; do
    [[ -S "${port_file}" ]] || continue
    port_pid="${port_file##*/}"
    port_pid="${port_pid%%.*}"
    if [[ ! "${port_pid}" =~ ^[0-9]+$ ]] || ! kill -0 "${port_pid}" 2>/dev/null; then
      rm -f "${port_file}"
    fi
  done

  # GSLaunchedApplications is a session registry, not a durable preference.
  # Drop it only when no other GNUstep application bundle is still running.
  mapfile -t app_pids < <(
    ps -eo pid=,args= | awk -v path="${app_root}" \
      'index($0, path) { print $1 }'
  )
  if ((${#app_pids[@]} == 0)); then
    rm -f "${runtime_root}/GSLaunchedApplications"
  fi
}

project_emacs_icon() {
  local app_dir="${GUEST_HOME}/.local/share/gnustep/lib/GNUstep/Applications/Emacs.app"
  local app_icon="${app_dir}/Resources/emacs.tiff"
  local old_app_icon="${app_dir}.pre-native-emacs-30.2/Resources/emacs.tiff"
  local app_plist="${app_dir}/Resources/Info-gnustep.plist"
  local app_desktop="${app_dir}/Resources/Emacs.desktop"
  [[ -f "${old_app_icon}" && -d "${app_dir}" ]] || return 0

  # Keep the native build's modern icon recoverable, then restore the exact
  # 48x48 GNU artwork from the pre-native bundle. GWorkspace's shelf reads
  # ApplicationIcon/NSIcon from this plist, so this fixes both shelf and
  # miniwindows without raster conversion.
  if [[ -f "${app_icon}" &&
        ! -f "${app_dir}/Resources/emacs-modern.tiff" ]]; then
    cp -p "${app_icon}" "${app_dir}/Resources/emacs-modern.tiff"
  fi
  project_file "${old_app_icon}" "${app_icon}"
  python3 - "${app_plist}" "${app_desktop}" <<'PY'
import os
import re
import sys
import tempfile

plist_path, desktop_path = sys.argv[1:]
if os.path.exists(plist_path):
    with open(plist_path, encoding="utf-8") as stream:
        plist = stream.read()
    plist, application_count = re.subn(
        r"(?m)^    ApplicationIcon\s*=\s*[^;]+;",
        "    ApplicationIcon = emacs.tiff;",
        plist,
        count=1,
    )
    plist, ns_count = re.subn(
        r"(?m)^    NSIcon\s*=\s*[^;]+;",
        "    NSIcon = emacs.tiff;",
        plist,
        count=1,
    )
    if application_count != 1 or ns_count != 1:
        raise SystemExit("unexpected GNUstep Emacs plist icon layout")
    mode = os.stat(plist_path).st_mode & 0o777
    fd, temporary = tempfile.mkstemp(prefix=".emacs-icon.", dir=os.path.dirname(plist_path))
    try:
        with os.fdopen(fd, "w", encoding="utf-8") as stream:
            stream.write(plist)
        os.chmod(temporary, mode)
        os.replace(temporary, plist_path)
    finally:
        if os.path.exists(temporary):
            os.unlink(temporary)
if os.path.exists(desktop_path):
    with open(desktop_path, encoding="utf-8") as stream:
        desktop = stream.read()
    desktop = re.sub(r"(?m)^Icon=emacs\.(?:png|tiff)$", "Icon=emacs.tiff", desktop)
    with open(desktop_path, "w", encoding="utf-8") as stream:
        stream.write(desktop)
PY
}

# Window Maker owns the room desktop and already paints the declarative
# #555577 background. Keep GWorkspace's full-screen desktop surface disabled:
# on this stock Window Maker/GNUstep combination it can sit above client
# bodies while their managed title frames remain visible. Merge only the
# declarative keys into the private plist; preserve every other user/runtime
# preference in that mutable file. plistlib is used instead of replacing the
# whole file with a DotCortex-owned template.
project_gworkspace_background() {
  local plist="$1"
  python3 - "${plist}" "${GWORKSPACE_BACKGROUND}" <<'PY'
import os
import plistlib
import sys
import tempfile

path, colour = sys.argv[1:]
channels = {
    "red": int(colour[1:3], 16) / 255.0,
    "green": int(colour[3:5], 16) / 255.0,
    "blue": int(colour[5:7], 16) / 255.0,
    "alpha": 1.0,
}

if os.path.exists(path):
    with open(path, "rb") as stream:
        defaults = plistlib.load(stream)
    mode = os.stat(path).st_mode & 0o777
else:
    defaults = {}
    mode = 0o600

desktopinfo = defaults.setdefault("desktopinfo", {})
desktopinfo["backcolor"] = channels
# GWorkspace's own dock duplicates Window Maker's app icons and uses a
# different, non-NeXT bevel. Window Maker is the room's single dock surface.
defaults["hidedock"] = True
# The Window Maker desktop is the room background; GWorkspace's desktop
# surface otherwise occludes the body of managed File Viewer windows.
defaults["no_desktop"] = True

directory = os.path.dirname(path)
os.makedirs(directory, exist_ok=True)
fd, temporary = tempfile.mkstemp(prefix=".gworkspace.", dir=directory)
try:
    with os.fdopen(fd, "wb") as stream:
        stream.write(plistlib.dumps(defaults, fmt=plistlib.FMT_XML, sort_keys=False))
    os.chmod(temporary, mode)
    os.replace(temporary, path)
finally:
    if os.path.exists(temporary):
        os.unlink(temporary)
PY
}

# Populate GWorkspace's NeXT-style tabbed shelf from the same verified bundle
# catalogue that feeds Window Maker's Applications menu.  Only installed,
# executable bundles become shelf icons; catalogue-only GAP candidates remain
# visible in the ledger without becoming broken launch targets.  Preserve any
# user-created tabs outside the managed set.
project_gworkspace_tabshelf() {
  local plist="$1"
  local catalogue="${HOME}/DotCortex/all/.config/gnustep-sanctuary/apps.ssv"
  local prefix="${GUEST_HOME}/.local/share/gnustep"
  python3 - "${plist}" "${catalogue}" "${prefix}" <<'PY'
import os
import plistlib
import sys
import tempfile

path, catalogue_path, prefix = sys.argv[1:]
managed_labels = {"Applications", "Accessories", "Development", "Games",
                  "Graphics", "Multimedia", "Networking"}
category_order = ["Accessories", "Games", "Development", "Graphics",
                  "Multimedia", "Networking"]

def installed_bundle(bundle, binary):
    for root, dirs, files in os.walk(prefix):
        if os.path.basename(root) != bundle or binary not in files:
            continue
        candidate = os.path.join(root, binary)
        if os.access(candidate, os.X_OK):
            return root
    return None

installed = []
with open(catalogue_path, encoding="utf-8") as stream:
    for raw in stream:
        raw = raw.rstrip("\n")
        if not raw or raw.startswith("#"):
            continue
        fields = raw.split("|", 8)
        if len(fields) != 9:
            continue
        app_id, category, display, bundle, binary = fields[:5]
        # GWorkspace is the room's Workspace Manager, not a second shelf
        # application. Exposing it here lets one click create a second
        # Workspace Manager (and therefore a second tabbed shelf).
        if app_id == "gworkspace":
            continue
        app_path = installed_bundle(bundle, binary)
        if app_path:
            installed.append((category, display, app_path))

tabs = []

def make_tab(label, rows):
    return {label: {"icons": [
        {"index": index, "paths": [app_path]}
        for index, (_category, _display, app_path) in enumerate(rows)
    ], "iconstype": 0}}

all_rows = sorted(installed, key=lambda row: row[1].casefold())
if all_rows:
    tabs.append(make_tab("Applications", all_rows))
for category in category_order:
    rows = sorted((row for row in installed if row[0] == category),
                  key=lambda row: row[1].casefold())
    if rows:
        tabs.append(make_tab(category, rows))

if os.path.exists(path):
    with open(path, "rb") as stream:
        defaults = plistlib.load(stream)
    mode = os.stat(path).st_mode & 0o777
else:
    defaults = {}
    mode = 0o600

old_shelf = defaults.get("tabshelf", {})
old_tabs = old_shelf.get("tabs", []) if isinstance(old_shelf, dict) else []
for entry in old_tabs:
    if not isinstance(entry, dict) or not entry:
        continue
    label = next(iter(entry))
    if label not in managed_labels and label != "last":
        tabs.append(entry)

# GWorkspace keeps the special `last` tab outside its ordinary tab list.
tabs.append({"last": {"icons": [], "iconstype": 0}})
defaults["tabshelf"] = {"auto_hide": False, "tabs": tabs}
defaults["tshelf"] = bool(all_rows)
# The managed shelf is presented as the room's application launcher. Keep its
# NeXT-style single-click affordance explicit instead of inheriting the
# upstream double-click default, which otherwise looks like a dead shelf.
defaults["singleclicklaunch"] = True

directory = os.path.dirname(path)
os.makedirs(directory, exist_ok=True)
fd, temporary = tempfile.mkstemp(prefix=".gworkspace.", dir=directory)
try:
    with os.fdopen(fd, "wb") as stream:
        stream.write(plistlib.dumps(defaults, fmt=plistlib.FMT_XML,
                                    sort_keys=False))
    os.chmod(temporary, mode)
    os.replace(temporary, path)
finally:
    if os.path.exists(temporary):
        os.unlink(temporary)
PY
}
project_gworkspace_tabshelf "${GUEST_HOME}/GNUstep/Defaults/org.gnustep.GWorkspace.plist"
