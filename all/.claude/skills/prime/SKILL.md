# DotCortex Orientation

Use this to orient yourself in a DotCortex session.

## Steps

1. Read the top-level directory structure.
2. Check recent history and current state.
3. Read the relevant root Org files for the current scope.
4. Report a brief orientation and ask what to work on.

## Rules

- Keep it concise.
- Do not read more than needed for orientation.
- Always edit Org sources, never tangled output.
