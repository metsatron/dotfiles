#+TITLE: Honey UPS lane: NUT shutdown policy, Envy-first ordering, and a watchdog for the watchdog
#+DESCRIPTION: Honey (beelink) owns the CyberPower UPS over USB. NUT runs as primary with a battery-percentage shutdown, the HP Envy is shut down first over a restricted SSH key, and a root cron watchdog restarts NUT, tracks the battery and backstops the shutdown if NUT itself fails.
#+AUTHOR: Claudeificus (Tanuki), for Mètsàtron's DotCortex
#+LANGUAGE: en
#+PROPERTY: header-args :mkdirp yes :results silent
#+PROPERTY: header-args:bash :comments no
#+PROPERTY: header-args:text :comments no :padline no

* Why

On 2026-10-30 a power outage on Gillean's side lasted over half an hour. The UPS drained to empty, and with the network down there was no way to shut Honey down safely. Mètsàtron asked for a watchdog that runs at boot and tracks the UPS live. It must shut down everything it can once the battery falls far enough, and it needs a watchdog of its own in case the first one dies. The HP Envy (Windows 11, Gillean's all-in-one) is on the same UPS but has no USB link to it. Honey therefore shuts the Envy down first, which also stretches Honey's own runtime, and then shuts itself down.

Honey Badger installed NUT 2.8.1 on Honey the same afternoon, in monitor-only mode (=upsmon= as =secondary=, no shutdown command). This lane turns that into the shutdown policy below, and makes DotCortex the source of truth for it.

* The policy

| Stage | Trigger | Action |
|---|---|---|
| On battery | =ONBATT= | Telegram alert with charge and runtime; start the Envy timer |
| Live tracking | every minute while on battery (watchdog) | log charge and runtime; alert every =REPORT_EVERY= seconds (default 5 min) |
| Envy off | =ENVY_AFTER= seconds on battery (default 300) | =shutdown /s /f /t 60= on the Envy through its restricted key |
| Honey off | battery at 40% or about 10 minutes left | NUT raises low battery and =upsmon= runs =honey-ups-shutdown=: Envy (if not already down), alert, then =shutdown -h now= |
| Backstop | battery at 30% or 5 minutes left, still running | the watchdog runs the same shutdown itself, in case =upsmon= failed |
| Blind backstop | UPS unreadable for =COMMLOST_AFTER= (15 min) after going on battery | the watchdog shuts down, since it can no longer see the battery |
| Power back | =ONLINE= | alert; clear the Envy and shutdown state |
| UPS power-off | at the very end of halt | the UPS cuts its output and restores it when mains returns, so a host with "power on after AC loss" set boots by itself |

Why 40%: the CP900EPFCLCD reported about 36 minutes of runtime at 12% load and full charge (2026-10-30). Lead-acid batteries age faster with every deep discharge. Stopping at 40% keeps the battery healthy and leaves several minutes for Honey's services (Docker, llama-swap, Hermes) to stop in order. The 30% backstop sits below NUT's trigger, so normally =upsmon= acts first.

Alerts are best effort. During a real outage the internet is usually down, so every alert has a timeout and never delays a shutdown. The log at =/var/log/honey-ups.log= is the record.

** Dry run first

The first install leaves =/etc/honey-ups/dry-run= in place. While that file exists, every stage runs and alerts, but the Envy is not touched and Honey does not shut down; each alert says "[dry run]". To test, pull the UPS plug for a minute, or run =upsmon -c fsd= to force the low-battery path, then read the log. Removing the file arms the lane. In dry run the shutdown script also deletes the UPS power-off flag that =upsmon= writes, so a later ordinary reboot cannot switch the UPS off.

** The Envy key

Honey shuts the Envy down over SSH with its own key, =/etc/honey-ups/envy_ed25519=, which the installer generates. The key is restricted on the Envy side with a forced command, so it can do nothing but start a shutdown. It has to be added on the Envy once, from Gillean's session (RustDesk or at the keyboard). If =gille= is an administrator there, Windows OpenSSH reads =C:\ProgramData\ssh\administrators_authorized_keys=, not the user's file. The installer prints the exact line.

Caveats:

- *As of 2026-10-30 the modem and router are NOT on a UPS* (they were moved off to make room for Milk-V and Honey; a third UPS for the network is coming). Until then Honey loses the LAN the moment the power cuts and cannot reach the Envy, so the Envy step fails, is logged, and Honey still shuts itself down. Two ways to close the gap: the network UPS, or a direct cable between Honey's spare USB Ethernet adapter and the Envy, which needs no router at all.
- In July 2026 a remote restart of the Envy bluescreened (=DRIVER_POWER_STATE_FAILURE=). A remote shutdown carries the same small risk.

* Settings

The installer writes =/etc/honey-ups/honey-ups.conf= only when it is absent, so host values survive reinstalls. This repo is public: the Envy's addresses are placeholders here and are filled in on Honey.

* NUT configuration

=standalone= keeps =upsd= on loopback: nothing else on the network reads this UPS.

#+BEGIN_SRC text :tangle all/.local/share/dotcortex/honey-ups/etc/nut/nut.conf
# generated by honey-ups.org
MODE=standalone
#+END_SRC

=ignorelb= makes the driver ignore the UPS's own low-battery signal and raise it from the two overrides instead: 40% charge or 600 seconds of runtime, whichever comes first. The UPS's factory thresholds (10% and 300 s) would leave too little battery for a clean stop.

#+BEGIN_SRC text :tangle all/.local/share/dotcortex/honey-ups/etc/nut/ups.conf
# generated by honey-ups.org
maxretry = 3

[cyberpower]
    driver = usbhid-ups
    port = auto
    vendorid = 0764
    productid = 0501
    desc = "CyberPower CP900EPFCLCD on Honey"
    ignorelb
    override.battery.charge.low = 40
    override.battery.runtime.low = 600
#+END_SRC

=upsmon= becomes =primary=: it owns the shutdown decision and writes the power-off flag. The =monitor= password already lives in =upsd.users= on the host; the installer copies it into this file, so it never enters the repo. =SHUTDOWNCMD= runs as root; =NOTIFYCMD= runs as =nut= through =upssched=.

#+BEGIN_SRC text :tangle all/.local/share/dotcortex/honey-ups/etc/nut/upsmon.conf.in
# generated by honey-ups.org; @MONITOR_PASSWORD@ is filled in by honey-ups-install
RUN_AS_USER nut
MONITOR cyberpower@localhost 1 monitor @MONITOR_PASSWORD@ primary
MINSUPPLIES 1
SHUTDOWNCMD "/usr/local/sbin/honey-ups-shutdown upsmon"
NOTIFYCMD /usr/sbin/upssched
POLLFREQ 5
POLLFREQALERT 5
HOSTSYNC 15
DEADTIME 15
FINALDELAY 5
POWERDOWNFLAG /etc/killpower
NOTIFYFLAG ONLINE SYSLOG+EXEC
NOTIFYFLAG ONBATT SYSLOG+EXEC
NOTIFYFLAG LOWBATT SYSLOG+EXEC
NOTIFYFLAG COMMOK SYSLOG+EXEC
NOTIFYFLAG COMMBAD SYSLOG+EXEC
NOTIFYFLAG NOCOMM SYSLOG+EXEC
NOTIFYFLAG FSD SYSLOG
NOTIFYFLAG SHUTDOWN SYSLOG
#+END_SRC

=upssched= turns events into timers and calls. Keep the Envy timer equal to =ENVY_AFTER=; the watchdog enforces the same deadline independently.

#+BEGIN_SRC text :tangle all/.local/share/dotcortex/honey-ups/etc/nut/upssched.conf
# generated by honey-ups.org
CMDSCRIPT /usr/local/sbin/honey-ups-sched
PIPEFN /run/nut/upssched.pipe
LOCKFN /run/nut/upssched.lock

AT ONBATT * EXECUTE onbatt
AT ONBATT * START-TIMER envy-off 300
AT ONLINE * CANCEL-TIMER envy-off
AT ONLINE * EXECUTE online
AT LOWBATT * EXECUTE lowbatt
AT COMMBAD * START-TIMER commbad 120
AT COMMOK * CANCEL-TIMER commbad
AT NOCOMM * EXECUTE nocomm
#+END_SRC

* Scripts

Shared preamble for the root scripts. Cron and =upsmon= give a bare environment, so =PATH= is set explicitly.

#+NAME: honey-ups-common
#+BEGIN_SRC bash
export PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
CONF=/etc/honey-ups/honey-ups.conf
STATE=/run/honey-ups
LOG=/var/log/honey-ups.log
DRYRUN_FLAG=/etc/honey-ups/dry-run
UPS=cyberpower@localhost
ENVY_AFTER=300 REPORT_EVERY=300 FLOOR_CHARGE=30 FLOOR_RUNTIME=300 COMMLOST_AFTER=900
ALERT_USER=gille ALERT_CMD=/home/gille/bin/honey-alert ALERT_TIMEOUT=20
ENVY_HOSTS="" ENVY_USER=gille
ENVY_KEY=/etc/honey-ups/envy_ed25519 ENVY_KNOWN_HOSTS=/etc/honey-ups/envy_known_hosts
# shellcheck source=/dev/null
[ -r "$CONF" ] && . "$CONF"
mkdir -p "$STATE"

log() {
    printf '%s %s[%s] %s\n' "$(date '+%F %T')" "${0##*/}" "$$" "$*" >>"$LOG"
    logger -t honey-ups -- "$*" 2>/dev/null || true
}
# Best effort: the internet is usually down during an outage, so never block long.
alert() {
    local prefix=""
    dry_run && prefix="[dry run] "
    timeout "$ALERT_TIMEOUT" sudo -n -u "$ALERT_USER" -- "$ALERT_CMD" "UPS: ${prefix}$*" \
        >/dev/null 2>&1 || log "alert not delivered: $*"
}
dry_run() { [ -e "$DRYRUN_FLAG" ]; }
ups_var() { timeout 10 upsc "$UPS" "$1" 2>/dev/null | grep -v '^Init SSL'; }
int_or() { case "$1" in ''|*[!0-9]*) echo "$2" ;; *) echo "$1" ;; esac; }
summary() {
    local c r
    c=$(int_or "$(ups_var battery.charge)" "?")
    r=$(int_or "$(ups_var battery.runtime)" "")
    if [ -n "$r" ]; then echo "charge ${c}%, about $((r / 60)) min left"; else echo "charge ${c}%"; fi
}
#+END_SRC

** =honey-ups-sched= (runs as =nut=)

=upssched= calls this with an event or timer name. The =nut= user may run exactly one root command, =honey-ups-event=, with one of these names (see the sudoers rule below).

#+BEGIN_SRC bash :tangle all/.local/share/dotcortex/honey-ups/sbin/honey-ups-sched :tangle-mode (identity #o755)
#!/bin/sh
# honey-ups-sched (generated by honey-ups.org): upssched CMDSCRIPT, runs as nut.
case "${1:-}" in
    onbatt|online|lowbatt|envy-off|commbad|nocomm)
        exec /usr/bin/sudo -n /usr/local/sbin/honey-ups-event "$1" ;;
    *)
        /usr/bin/logger -t honey-ups -- "honey-ups-sched: unknown event '${1:-}'"
        exit 64 ;;
esac
#+END_SRC

** =honey-ups-event= (root)

#+BEGIN_SRC bash :tangle all/.local/share/dotcortex/honey-ups/sbin/honey-ups-event :tangle-mode (identity #o755) :noweb yes
#!/usr/bin/env bash
# honey-ups-event (generated by honey-ups.org): act on one upssched event, as root.
set -u
<<honey-ups-common>>

case "${1:-}" in
    onbatt)
        [ -e "$STATE/ob_since" ] || date +%s >"$STATE/ob_since"
        date +%s >"$STATE/rate-report"
        log "on battery: $(summary)"
        alert "Power is out, Honey is on battery: $(summary). The Envy shuts down after $((ENVY_AFTER / 60)) min; Honey at 40% or 10 min left."
        ;;
    online)
        was_out=""
        [ -e "$STATE/ob_since" ] && was_out=yes
        rm -f "$STATE/ob_since" "$STATE/envy-done" "$STATE/rate-report"
        if dry_run; then
            rmdir "$STATE/shutdown.lock" 2>/dev/null || true
            rm -f /etc/killpower
        fi
        log "power back: $(summary)"
        [ -n "$was_out" ] && alert "Power is back: $(summary)."
        ;;
    envy-off)
        /usr/local/sbin/honey-ups-envy-off "on battery for $((ENVY_AFTER / 60)) min"
        ;;
    lowbatt)
        log "low battery: $(summary)"
        alert "Low battery: $(summary). Honey is shutting down."
        ;;
    commbad)
        log "lost contact with the UPS for 2 minutes"
        alert "Lost contact with the UPS for 2 minutes; the watchdog will try to restart NUT."
        ;;
    nocomm)
        log "UPS not reachable"
        ;;
    *)
        log "unknown event '${1:-}'"
        exit 64
        ;;
esac
#+END_SRC

** =honey-ups-envy-off= (root)

Idempotent per outage: =envy-done= is cleared when power returns. The Envy side forces the command, so the remote command name here is only a label.

#+BEGIN_SRC bash :tangle all/.local/share/dotcortex/honey-ups/sbin/honey-ups-envy-off :tangle-mode (identity #o755) :noweb yes
#!/usr/bin/env bash
# honey-ups-envy-off (generated by honey-ups.org): shut the HP Envy down over its
# restricted key. Exit 0 = requested (or already done), 1 = unreachable, 2 = not configured.
set -u
<<honey-ups-common>>

reason=${1:-unspecified}
if [ -e "$STATE/envy-done" ]; then
    log "envy: already requested this outage"
    exit 0
fi
if [ ! -r "$ENVY_KEY" ] || [ -z "$ENVY_HOSTS" ] || [ ! -s "$ENVY_KNOWN_HOSTS" ]; then
    log "envy: key, host or host key not configured; skipped ($reason)"
    alert "The Envy was NOT shut down: Honey has no working shutdown key for it yet ($reason)."
    exit 2
fi
if dry_run; then
    touch "$STATE/envy-done"
    log "envy: dry run, would shut down now ($reason)"
    alert "Would shut the Envy down now ($reason)."
    exit 0
fi
for host in $ENVY_HOSTS; do
    if timeout 25 ssh -i "$ENVY_KEY" -o BatchMode=yes -o IdentitiesOnly=yes \
        -o PasswordAuthentication=no -o KbdInteractiveAuthentication=no \
        -o PreferredAuthentications=publickey -o ConnectTimeout=8 -o ConnectionAttempts=1 \
        -o UserKnownHostsFile="$ENVY_KNOWN_HOSTS" -o StrictHostKeyChecking=yes \
        "$ENVY_USER@$host" honey-ups-shutdown </dev/null >>"$LOG" 2>&1; then
        touch "$STATE/envy-done"
        log "envy: shutdown requested via $host ($reason)"
        alert "Envy shutdown requested ($reason)."
        exit 0
    fi
    log "envy: $host unreachable or refused"
done
alert "Envy shutdown FAILED: not reachable ($reason)."
exit 1
#+END_SRC

** =honey-ups-shutdown= (root, =upsmon='s =SHUTDOWNCMD= and the watchdog's backstop)

One shutdown per outage: the lock is a directory under =/run=, so it vanishes with the boot. =sync= and =shutdown -h now= run the normal runlevel-0 path, which stops every service in order; the halt script then asks the UPS to cut its output.

#+BEGIN_SRC bash :tangle all/.local/share/dotcortex/honey-ups/sbin/honey-ups-shutdown :tangle-mode (identity #o755) :noweb yes
#!/usr/bin/env bash
# honey-ups-shutdown (generated by honey-ups.org): Envy first, then Honey.
set -u
<<honey-ups-common>>

reason=${1:-unspecified}
if ! mkdir "$STATE/shutdown.lock" 2>/dev/null; then
    log "shutdown already in progress ($reason)"
    exit 0
fi
log "shutdown sequence ($reason): status=$(ups_var ups.status) $(summary)"
/usr/local/sbin/honey-ups-envy-off "Honey shutting down: $reason" || true

if dry_run; then
    # upsmon wrote the UPS power-off flag before calling us; a later ordinary
    # reboot must not switch the UPS off, so remove it in dry run.
    rm -f /etc/killpower
    log "dry run: Honey would shut down now"
    alert "Honey would shut down now ($reason). Nothing was stopped."
    exit 0
fi

ALERT_TIMEOUT=8 alert "Shutting Honey down now ($reason): $(summary)."
sync
exec /sbin/shutdown -h now "UPS: $reason"
#+END_SRC

** =honey-ups-watchdog= (root, every minute from cron)

The watchdog for the watchdog. It runs outside NUT, so a dead =upsd=, driver or =upsmon= cannot silence it:

1. If the UPS does not answer, it restarts =nut-server= (driver and =upsd=).
2. If the root =upsmon= is gone, it restarts =nut-client=.
3. While on battery, it logs charge and runtime every minute and alerts every =REPORT_EVERY= seconds.
4. It shuts the Envy down at =ENVY_AFTER= if the =upssched= timer did not.
5. It shuts Honey down itself at the floor (30% or 5 minutes), or when the UPS has been unreadable for =COMMLOST_AFTER= after going on battery.

Restart alerts are rate-limited to one per 30 minutes each.

#+BEGIN_SRC bash :tangle all/.local/share/dotcortex/honey-ups/sbin/honey-ups-watchdog :tangle-mode (identity #o755) :noweb yes
#!/usr/bin/env bash
# honey-ups-watchdog (generated by honey-ups.org): keep NUT alive, track the battery,
# and backstop the shutdown. Runs every minute from /etc/cron.d/honey-ups-watchdog.
set -u
<<honey-ups-common>>

exec 9>"$STATE/watchdog.lock"
flock -n 9 || exit 0
now=$(date +%s)

# rate KEY SECONDS: succeed (and stamp) at most once per SECONDS.
rate() {
    local f="$STATE/rate-$1" last=0
    [ -r "$f" ] && last=$(int_or "$(cat "$f")" 0)
    [ $((now - last)) -ge "$2" ] || return 1
    echo "$now" >"$f"
}

status=$(ups_var ups.status)
case "$status" in
    ''|*'Data stale'*)
        log "watchdog: UPS not answering (status='${status}'); restarting nut-server"
        /etc/init.d/nut-server restart >>"$LOG" 2>&1
        sleep 5
        status=$(ups_var ups.status)
        rate nut-server 1800 && alert "The UPS monitor was not answering; restarted NUT (now: ${status:-still no data})."
        ;;
esac

if ! pgrep -u root -x upsmon >/dev/null; then
    log "watchdog: upsmon not running; restarting nut-client"
    /etc/init.d/nut-client restart >>"$LOG" 2>&1
    rate nut-client 1800 && alert "upsmon was not running; restarted it."
fi

case " $status " in
    *" OB "*)
        [ -r "$STATE/ob_since" ] || echo "$now" >"$STATE/ob_since"
        since=$(int_or "$(cat "$STATE/ob_since")" "$now")
        elapsed=$((now - since))
        charge=$(int_or "$(ups_var battery.charge)" 100)
        runtime=$(int_or "$(ups_var battery.runtime)" 99999)
        log "on battery ${elapsed}s: charge=${charge}% runtime=${runtime}s status=${status}"
        rate report "$REPORT_EVERY" && alert "On battery for $((elapsed / 60)) min: charge ${charge}%, about $((runtime / 60)) min left."
        if [ "$elapsed" -ge "$ENVY_AFTER" ] && [ ! -e "$STATE/envy-done" ]; then
            /usr/local/sbin/honey-ups-envy-off "watchdog: on battery ${elapsed}s" || true
        fi
        if [ "$charge" -le "$FLOOR_CHARGE" ] || [ "$runtime" -le "$FLOOR_RUNTIME" ]; then
            /usr/local/sbin/honey-ups-shutdown "watchdog backstop: charge ${charge}%, runtime ${runtime}s"
        fi
        ;;
    *" OL "*)
        if [ -e "$STATE/ob_since" ]; then
            rm -f "$STATE/ob_since" "$STATE/envy-done" "$STATE/rate-report"
            log "watchdog: back on mains"
        fi
        ;;
    *)
        if [ -r "$STATE/ob_since" ]; then
            since=$(int_or "$(cat "$STATE/ob_since")" "$now")
            elapsed=$((now - since))
            log "watchdog: UPS unreadable ${elapsed}s after going on battery"
            if [ "$elapsed" -ge "$COMMLOST_AFTER" ]; then
                /usr/local/sbin/honey-ups-shutdown "watchdog: UPS unreadable on battery for $((elapsed / 60)) min"
            fi
        fi
        ;;
esac
#+END_SRC

#+BEGIN_SRC text :tangle all/.local/share/dotcortex/honey-ups/etc/cron.d/honey-ups-watchdog
# generated by honey-ups.org: the UPS watchdog for the watchdog, every minute
SHELL=/bin/sh
PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
* * * * * root /usr/local/sbin/honey-ups-watchdog
#+END_SRC

* Installer

=honey-ups-install [--dry-run]= runs as root on Honey from any copy of this lane (the system checkout or a staged copy). It:

- backs up every file it replaces as =<file>.bak-honey-ups-<stamp>=;
- carries the existing =monitor= password from =upsd.users= into =upsmon.conf=, and refuses if there is none;
- checks the sudoers rule with =visudo -c= before installing it;
- writes =honey-ups.conf= and the =dry-run= flag only when =/etc/honey-ups= is new, so a reinstall never re-arms or disarms the lane;
- generates the Envy key if absent and prints the line to add on the Envy;
- links =/etc/init.d/ups-monitor= to =nut-client=, which is the hook Devuan's =halt= script calls to cut the UPS output at the end of a shutdown;
- restarts =nut-server= and then =nut-client=, and verifies the new thresholds and the root =upsmon= are live.

#+BEGIN_SRC bash :tangle all/.local/share/dotcortex/honey-ups/bin/honey-ups-install :tangle-mode (identity #o755)
#!/usr/bin/env bash
# honey-ups-install (generated by honey-ups.org): install Honey's UPS shutdown lane.
set -euo pipefail
umask 022

usage() {
    cat <<'USAGE'
Usage: honey-ups-install [--dry-run]
Install the NUT shutdown policy, scripts, sudoers rule and watchdog cron from this
lane, then restart NUT. --dry-run prints what would change and touches nothing.
USAGE
}

DRY=""
case "${1:-}" in
    -h|--help) usage; exit 0 ;;
    --dry-run) DRY=yes ;;
    "") ;;
    *) usage >&2; exit 64 ;;
esac

LANE=$(cd "$(dirname "$0")/.." && pwd)
STAMP=$(date +%Y%m%d-%H%M%S)
[ "$(id -u)" -eq 0 ] || [ -n "$DRY" ] || { echo "honey-ups-install: run as root" >&2; exit 1; }

say() { printf '%s\n' "$*"; }
run() { if [ -n "$DRY" ]; then say "would: $*"; else "$@"; fi; }

# put SRC DEST MODE OWNER:GROUP: back up DEST if it differs, then install SRC.
put() {
    local src=$1 dest=$2 mode=$3 owner=$4
    if [ -e "$dest" ] && cmp -s "$src" "$dest"; then
        say "unchanged: $dest"
        return
    fi
    [ -e "$dest" ] && run cp -p "$dest" "$dest.bak-honey-ups-$STAMP"
    run install -D -m "$mode" -o "${owner%%:*}" -g "${owner##*:}" "$src" "$dest"
    say "installed: $dest"
}

pass=$(awk '/^\[monitor\]/{m=1;next} /^\[/{m=0} m && $1=="password" {sub(/^[^=]*=[ \t]*/,""); print; exit}' /etc/nut/upsd.users 2>/dev/null || true)
[ -n "$pass" ] || { echo "honey-ups-install: no [monitor] password in /etc/nut/upsd.users" >&2; exit 1; }

tmp=$(mktemp -d)
trap 'rm -rf "$tmp"' EXIT
sed "s|@MONITOR_PASSWORD@|$pass|" "$LANE/etc/nut/upsmon.conf.in" >"$tmp/upsmon.conf"

visudo -cf "$LANE/etc/sudoers.d/honey-ups" >/dev/null || { echo "honey-ups-install: sudoers rule fails visudo" >&2; exit 1; }

first=""
[ -d /etc/honey-ups ] || first=yes

put "$LANE/etc/nut/nut.conf"       /etc/nut/nut.conf       0640 root:nut
put "$LANE/etc/nut/ups.conf"       /etc/nut/ups.conf       0640 root:nut
put "$tmp/upsmon.conf"             /etc/nut/upsmon.conf    0640 root:nut
put "$LANE/etc/nut/upssched.conf"  /etc/nut/upssched.conf  0640 root:nut
for s in honey-ups-sched honey-ups-event honey-ups-envy-off honey-ups-shutdown honey-ups-watchdog; do
    put "$LANE/sbin/$s" "/usr/local/sbin/$s" 0755 root:root
done
put "$LANE/etc/sudoers.d/honey-ups"       /etc/sudoers.d/honey-ups     0440 root:root
put "$LANE/etc/cron.d/honey-ups-watchdog" /etc/cron.d/honey-ups-watchdog 0644 root:root

if [ -n "$first" ]; then
    run install -d -m 0750 -o root -g root /etc/honey-ups
