Full-layer theme switching for the Redstone 9X sanctuary. Split out of =sanctuary-redstone-9x-desktop.org= on 2026-07-19 (module budget) — the scheme declarations, the apply/graft/host-gtk helpers, and the SerenityOS asset importer live here; the menu entries, IceWM startup hook, and GTK/qt6ct base configs they act on remain in the desktop module.

* Desktop Schemes — full-layer theme switching

A *Desktop Scheme* swaps every appearance layer at once: IceWM theme, GTK2/GTK3 theme, icon theme, cursor theme, fonts, desktop background, selection colours, Qt palette, and sound scheme. Before this existed (2026-07-19 audit) the Windows 95 look was smeared across nine uncoordinated mechanisms — a session-frozen =GTK_THEME= export, five absolute Chicago95 paths in the menu, a launcher-time icon graft, projected GTK/Qt files, and a dead =gtk-cursor-theme-name=Win95= reference. A scheme is one declarative file; =redstone-9x-scheme-apply= is the single mover.

Mechanism per layer:
- *IceWM*: writes =~/.icewm/theme= and restarts the WM. The curated Win2k IceWM themes remain reachable as "window borders only" variants that do not change the rest of the scheme.
- *GTK (new apps)*: rewrites =settings.ini= / =.gtkrc-2.0=. The session-wide =GTK_THEME= export is gone — it overrides both settings.ini and XSETTINGS, which would make switching impossible. Host-spawned browsers get their =GTK_THEME= from =redstone-9x-host-gtk=, which reads the *active* scheme at click time.
- *GTK (running apps)*: =xsettingsd= (desktop-common) is started by the IceWM startup hook; scheme-apply rewrites its config and SIGHUPs it, so already-running GTK3 apps restyle live.
- *Icons*: IceWM does not resolve XDG icon-theme names (a name it can't find silently drops the whole menu button), so the launcher grafts a curated set into =~/.icewm/icons/= — the graft is now scheme-aware via =redstone-9x-icons-graft=, sourcing from the scheme's icon theme with Chicago95 fallback.
- *Sounds*: =~/.local/share/sounds/sanctuary= becomes a symlink to =~/.local/share/sounds/schemes/<scheme>/= (the flat dir from the first sound landing migrates automatically).
- *Persistence*: the choice lands in =~/.config/redstone-9x/scheme=; the launcher re-asserts the active scheme after every projection pass (=--boot= mode, file effects only), so projection no longer resets appearance to Windows 95.

** Icon graft — scheme-aware

Copies a curated name list into IceWM's private =icons/= dir, size-suffixed the way IceWM wants (=<name>_<size>x<size>.png=), sourcing each name from the scheme's icon theme first and Chicago95 second (both use the =<category>/<size>/<name>.png= grammar). Runs host-side from the launcher (guest paths as args) and in-guest from scheme-apply.

#+BEGIN_SRC bash :tangle linux/.local/bin/redstone-9x-icons-graft :shebang "#!/bin/bash" :tangle-mode (identity #o755)
# redstone-9x-icons-graft <icons-root> <dest-dir> <icon-theme>
# Graft the curated Redstone icon set into an IceWM icons dir from the given
# XDG-layout icon theme (Chicago95 directory grammar: <category>/<size>/<name>.png),
# falling back to Chicago95 per name+size. IceWM cannot resolve XDG icon-theme
# names itself — a missing name silently drops the menu button — so this graft
# is the only bridge between icon themes and IceWM-drawn UI.
set -uo pipefail

# Roots may be colon-separated: XDG icon dirs AND legacy ~/.icons both count
# (SE98/LinXP live in ~/.icons — found 2026-07-19).
ICONS_ROOT="${1:?icons roots required (colon-separated)}"
DEST="${2:?dest dir required (e.g. \$HOME/.icewm/icons)}"
THEME="${3:-Chicago95}"

NAMES="winamp ultimate-doom quake diablo hellfire theme-hospital duke-nukem-3d
red-alert command-conquer half-life blue-shift opposing-force zsnes snes9x
mupen64plus ms-dos-prompt retroarch msn inbox help-browser lxfind vlc
seamonkey palemoon redstone-system smplayer redstone-control-panel
system-file-manager emacs obsidian user-home system-run archive-manager
preferences-desktop-theme gnome-applications libreoffice-startcenter gimp
inkscape com.visualstudio.code postscript-viewer audio-card video-display
folder accessories-text-editor firefox_2 utilities-terminal
control-center2 system-shut-down preferences-system preferences-desktop
system-search edit-paste accessories-character-map applications-system
text-editor reload web-browser user-desktop text-x-generic image-x-generic
audio-x-generic video-x-generic application-pdf package-x-generic unknown
applications-utilities applications-development applications-games
applications-graphics applications-internet applications-multimedia
applications-office wine applications-painting eom corsix-th abiword gnumeric
libreoffice-writer libreoffice-calc libreoffice-impress libreoffice-draw
libreoffice-base libreoffice-math"
SIZES="16 22 24 32 48"
CATEGORIES="apps places actions devices mimes mimetypes status categories"

# Per-name theme pins (Mètsàtron's standing picks): VLC always wears his
# BeOS-r5 art — VLC is not Media-Player-Classic-like.
override_theme() {
  case "$1" in
    vlc) echo "BeOS-r5-Icons" ;;
    *) echo "" ;;
  esac
}

mkdir -p "${DEST}"
for name in ${NAMES}; do
  for size in ${SIZES}; do
    src=""
    _pin="$(override_theme "${name}")"
    for theme in ${_pin} "${THEME}" Chicago95; do
      for root in ${ICONS_ROOT//:/ }; do
        for cat in ${CATEGORIES}; do
          cand="${root}/${theme}/${cat}/${size}/${name}.png"
          [ -f "${cand}" ] && { src="${cand}"; break 3; }
        done
      done
    done
    [ -n "${src}" ] && cp -f "${src}" "${DEST}/${name}_${size}x${size}.png"
  done
done
exit 0
#+END_SRC

** Scheme apply

#+BEGIN_SRC bash :tangle linux/.local/bin/redstone-9x-scheme-apply :shebang "#!/bin/bash" :tangle-mode (identity #o755)
# redstone-9x-scheme-apply [--boot] <scheme-id>
# Swap every appearance layer to the named Desktop Scheme.
# --boot: file effects only (no WM restart, no daemon HUPs, no sounds) —
#         called by the launcher after projection, host-side with
#         HOME=<guest-home>, to re-assert the active scheme.
# Full mode (from the Desktop Schemes menu, in-guest): also restarts IceWM,
# HUPs xsettingsd, reconfigures pcmanfm, and plays the notify sound.
set -uo pipefail

BOOT=0
if [[ "${1:-}" == "--boot" ]]; then BOOT=1; shift; fi
SCHEME_ID="${1:?usage: redstone-9x-scheme-apply [--boot] <scheme-id>}"

CFG="${HOME}/.config/redstone-9x"
SCHEME_FILE="${CFG}/schemes/${SCHEME_ID}.scheme"
if [[ ! -f "${SCHEME_FILE}" ]]; then
  echo "scheme not found: ${SCHEME_FILE}" >&2
  ls "${CFG}/schemes/" 2>/dev/null >&2
  exit 1
fi
# shellcheck disable=SC1090
. "${SCHEME_FILE}"

: "${ICEWM_THEME:?}" "${GTK_THEME:?}" "${ICON_THEME:?}" "${CURSOR_THEME:?}"
: "${CURSOR_SIZE:=24}" "${GTK_FONT:=Sans 8}" "${DESKTOP_BG:=#008080}"
: "${SEL_BG:=#000080}" "${SEL_FG:=#ffffff}" "${QT6CT_COLORS:=win95.conf}"
: "${SOUND_SCHEME:=${SCHEME_ID}}"

# --- IceWM theme (the file the curated switcher always used) ---
mkdir -p "${HOME}/.icewm"
printf 'Theme="%s"\n' "${ICEWM_THEME}" > "${HOME}/.icewm/theme"

# --- IceWM taskbar-layout overrides (managed prefoverride block) ---
# Themes can only set colours; show/hide + placement toggles are
# preferences-level, and prefoverride outranks everything. The block is
# marked so the Focus menu's own prefoverride writes are never touched.
PREFO="${HOME}/.icewm/prefoverride"
touch "${PREFO}"
sed -i '/^# BEGIN redstone-scheme/,/^# END redstone-scheme/d' "${PREFO}"
if [[ -n "${ICEWM_PREFS:-}" ]]; then
  {
    echo "# BEGIN redstone-scheme (managed by redstone-9x-scheme-apply — do not edit)"
    IFS=';' read -ra _kvs <<< "${ICEWM_PREFS}"
    for _kv in "${_kvs[@]}"; do [[ -n "${_kv}" ]] && echo "${_kv}"; done
    echo "# END redstone-scheme"
  } >> "${PREFO}"
fi

# --- FOX toolkit registry (every FOX app: xfe, adie, PathFinder, ice2k) ---
if [[ -n "${FOX_BASE:-}" ]]; then
  mkdir -p "${HOME}/.foxrc"
  cat > "${HOME}/.foxrc/Desktop" <<FOXEOF
# Written by redstone-9x-scheme-apply (Desktop Scheme: ${SCHEME_ID}).
[SETTINGS]
basecolor=${FOX_BASE}
forecolor=#000000
backcolor=#ffffff
selbackcolor=${FOX_SEL_BG:-#000080}
selforecolor=${FOX_SEL_FG:-#ffffff}
selmenubackcolor=${FOX_MENU_BG:-${FOX_SEL_BG:-#000080}}
selmenutextcolor=${FOX_MENU_FG:-${FOX_SEL_FG:-#ffffff}}
tipbackcolor=#ffffe1
tipforecolor=#000000
FOXEOF
fi

# --- GTK3 settings.ini + GTK2 rc (newly launched apps) ---
set_ini() { # file key value  (replace or append; tolerate quoted gtk2 style)
  local file="$1" key="$2" val="$3"
  if grep -q "^${key}=" "${file}" 2>/dev/null; then
    sed -i "s|^${key}=.*|${key}=${val}|" "${file}"
  else
    printf '%s=%s\n' "${key}" "${val}" >> "${file}"
  fi
}
GTK3="${HOME}/.config/gtk-3.0/settings.ini"
if [[ -f "${GTK3}" ]]; then
  set_ini "${GTK3}" gtk-theme-name "${GTK_THEME}"
  set_ini "${GTK3}" gtk-icon-theme-name "${ICON_THEME}"
  set_ini "${GTK3}" gtk-font-name "${GTK_FONT}"
  set_ini "${GTK3}" gtk-cursor-theme-name "${CURSOR_THEME}"
  set_ini "${GTK3}" gtk-cursor-theme-size "${CURSOR_SIZE}"
fi
GTK2="${HOME}/.gtkrc-2.0"
if [[ -f "${GTK2}" ]]; then
  set_ini "${GTK2}" gtk-theme-name "\"${GTK_THEME}\""
  set_ini "${GTK2}" gtk-icon-theme-name "\"${ICON_THEME}\""
  set_ini "${GTK2}" gtk-font-name "\"${GTK_FONT}\""
  set_ini "${GTK2}" gtk-cursor-theme-name "\"${CURSOR_THEME}\""
  set_ini "${GTK2}" gtk-cursor-theme-size "${CURSOR_SIZE}"
fi

# --- GTK user CSS from template (selection colours) ---
if [[ -f "${CFG}/gtk-3.0/gtk.css.in" ]]; then
  r=$((16#${SEL_BG:1:2})); g=$((16#${SEL_BG:3:2})); b=$((16#${SEL_BG:5:2}))
  mkdir -p "${HOME}/.config/gtk-3.0"
  sed -e "s|@SEL_BG@|${SEL_BG}|g" \
      -e "s|@SEL_FG@|${SEL_FG}|g" \
      -e "s|@SEL_RGBA@|rgba(${r}, ${g}, ${b}, 0.35)|g" \
      "${CFG}/gtk-3.0/gtk.css.in" > "${HOME}/.config/gtk-3.0/gtk.css"
fi

# --- Qt via qt6ct ---
QT6CT="${HOME}/.config/qt6ct/qt6ct.conf"
if [[ -f "${QT6CT}" ]]; then
  sed -i -e "s|^color_scheme_path=.*|color_scheme_path=${HOME}/.config/qt6ct/colors/${QT6CT_COLORS}|" \
         -e "s|^icon_theme=.*|icon_theme=${ICON_THEME}|" "${QT6CT}"
fi

# --- Cursor fallback (libXcursor default when env is absent; also repairs
#     LXAppearance drive-by overwrites of this file) ---
mkdir -p "${HOME}/.icons/default"
printf '[Icon Theme]\nName=Default\nComment=Redstone scheme cursor fallback\nInherits=%s\n' \
  "${CURSOR_THEME}" > "${HOME}/.icons/default/index.theme"

# --- XSETTINGS (live restyle of running GTK3 apps) ---
mkdir -p "${HOME}/.config/xsettingsd"
cat > "${HOME}/.config/xsettingsd/xsettingsd.conf" <<XSEOF
Net/ThemeName "${GTK_THEME}"
Net/IconThemeName "${ICON_THEME}"
Gtk/FontName "${GTK_FONT}"
Gtk/CursorThemeName "${CURSOR_THEME}"
Gtk/CursorThemeSize ${CURSOR_SIZE}
Net/EnableEventSounds 0
XSEOF

# --- Desktop background (pcmanfm owns the desktop) ---
PCMANFM_CONF="${HOME}/.config/pcmanfm/default/desktop-items-0.conf"
if [[ -f "${PCMANFM_CONF}" ]]; then
  if [[ -n "${WALLPAPER:-}" && -f "${WALLPAPER}" ]]; then
    sed -i -e "s|^wallpaper_mode=.*|wallpaper_mode=stretch|" \
           -e "s|^wallpaper=.*|wallpaper=${WALLPAPER}|" "${PCMANFM_CONF}"
    grep -q '^wallpaper=' "${PCMANFM_CONF}" || sed -i "/^wallpaper_mode=/a wallpaper=${WALLPAPER}" "${PCMANFM_CONF}"
  else
    # pcmanfm's real key is desktop_bg; the launcher's write-once seed used
    # wallpaper_bg_color and pcmanfm rewrote it (found by scratch test
    # 2026-07-19) — handle both so pristine and evolved confs both switch.
    sed -i -e "s|^wallpaper_mode=.*|wallpaper_mode=color|" \
           -e "s|^wallpaper_bg_color=.*|wallpaper_bg_color=${DESKTOP_BG}|" \
           -e "s|^desktop_bg=.*|desktop_bg=${DESKTOP_BG}|" \
           -e "s|^desktop_fg=.*|desktop_fg=${DESKTOP_FG:-#ffffff}|" "${PCMANFM_CONF}"
  fi
fi

# --- IceWM menu/toolbar icons regrafted from this scheme's icon theme ---
if command -v redstone-9x-icons-graft >/dev/null 2>&1; then
  redstone-9x-icons-graft "${HOME}/.local/share/icons:${HOME}/.icons" "${HOME}/.icewm/icons" "${ICON_THEME}"
elif [[ -x "${HOME}/.local/bin/redstone-9x-icons-graft" ]]; then
  "${HOME}/.local/bin/redstone-9x-icons-graft" "${HOME}/.local/share/icons:${HOME}/.icons" "${HOME}/.icewm/icons" "${ICON_THEME}"
fi

# --- Sound scheme (migrate the pre-scheme flat dir once, then symlink) ---
SND="${HOME}/.local/share/sounds"
mkdir -p "${SND}/schemes/${SOUND_SCHEME}"
if [[ -d "${SND}/sanctuary" && ! -L "${SND}/sanctuary" ]]; then
  # One-time migration of the original flat layout into schemes/windows-95
  # (the founding assets were the Win95 set). mv only — guest home is precious.
  mkdir -p "${SND}/schemes/windows-95"
  for f in "${SND}/sanctuary"/*; do
    [[ -e "${f}" ]] && mv -n "${f}" "${SND}/schemes/windows-95/"
  done
  rmdir "${SND}/sanctuary" 2>/dev/null || true
fi
[[ -e "${SND}/sanctuary" && ! -L "${SND}/sanctuary" ]] || ln -sfnT "${SND}/schemes/${SOUND_SCHEME}" "${SND}/sanctuary"

# --- Persist the choice ---
mkdir -p "${CFG}"
printf '%s\n' "${SCHEME_ID}" > "${CFG}/scheme"

if [[ "${BOOT}" -eq 1 ]]; then
  exit 0
fi

# --- Live reloads (full mode only) ---
pkill -HUP -x xsettingsd 2>/dev/null || true
pcmanfm --reconfigure 2>/dev/null || true
# pcmanfm does NOT repaint desktop_bg (or reload the selection gtk.css) on
# --reconfigure — verified live 2026-07-19, desktop stayed teal after a
# serenity switch. Bounce the desktop renderer; it re-reads both on start.
if pgrep -u "$(id -u)" -f "pcmanfm --desktop" >/dev/null 2>&1; then
  pkill -u "$(id -u)" -f "pcmanfm --desktop" 2>/dev/null || true
  ( sleep 1; pcmanfm --desktop >>"${HOME}/.cache/redstone-9x/pcmanfm-desktop.log" 2>&1 & ) &
fi
# icesound samples live under the sanctuary symlink, but icesound scans its
# sample dir at startup — bounce it so the NEW scheme's GUI-event sounds load
# (started fresh only when the new scheme actually ships icewm/*.wav).
pkill -x icesound 2>/dev/null || true

** Smooth title-gradient renderer

IceWM's =Gradients== theme key scales listed pixmaps instead of tiling them — so a rendered 1024px-wide gradient becomes a genuinely SMOOTH titlebar, ending the banded-ramp era. Used by the Serenity importer and the Windows 98 builder.

#+BEGIN_SRC python :tangle linux/.local/bin/redstone-9x-title-gradient :shebang "#!/usr/bin/env python3" :tangle-mode (identity #o755)
"""redstone-9x-title-gradient <theme-dir> <activeDark> <activeLight> <inactiveDark> <inactiveLight> [height]
Render smooth horizontal-gradient titleAT.png/titleIT.png into an IceWM theme
and ensure Gradients= declares them (scaled, not tiled)."""
import sys, os
from PIL import Image

theme, ad, al, idk, il = sys.argv[1:6]
height = int(sys.argv[6]) if len(sys.argv) > 6 else 20

def hx(h):
    h = h.lstrip('#')
    return tuple(int(h[i:i+2], 16) for i in (0, 2, 4))

def render(dark, light, name):
    # 2px colour-stop image in XPM format. IceWM 4.0 registers gradient slots
    # by EXACT filename ("titleAT.xpm" — wpixres.cc GradientResource): a .png
    # can never enter the gradient path and silently tiles instead. XPM stops
    # interpolate smoothly across the full segment width at any window size.
    stem = name.rsplit('.', 1)[0]
    var = stem.replace('-', '_')
    lines = [f'/* XPM */',
             f'static char * {var}_xpm[] = {{',
             f'"2 {height} 2 1",',
             f'"a\tc {dark}",',
             f'"b\tc {light}",']
    lines += [f'"ab",'] * (height - 1) + [f'"ab"}};']
    with open(os.path.join(theme, stem + '.xpm'), 'w') as f:
        f.write('\n'.join(lines) + '\n')
    # remove any stale png twin from earlier eras
    png = os.path.join(theme, stem + '.png')
    if os.path.exists(png):
        os.remove(png)

render(ad, al, 'titleAT.png')
render(idk, il, 'titleIT.png')
render(ad, al, 'titleAB.png')
render(idk, il, 'titleIB.png')

# Caption buttons carry BAKED title-colour margins from the flat-title era.
# The ice2k technique (and the answer to "how does the XP theme do it?"):
# buttons sit at the bar's RIGHT end where the gradient has reached its
# light endpoint — so their margins are painted EXACTLY that end colour and
# blend seamlessly. (Transparency was wrong: IceWM composites buttons on
# their own fill, so cleared pixels rendered garbage.)
AL, IL = hx(al), hx(il)
CLEAR = {(0,0,128), (0,0,130), (0x84,0x35,0x1A)}
for stem in ('close', 'minimize', 'maximize', 'restore', 'hide', 'rollup'):
    for st, endc in (('A', AL), ('I', IL)):
        bp = os.path.join(theme, f'{stem}{st}.png')
        if not os.path.isfile(bp):
            continue
        im = Image.open(bp).convert('RGBA')
        px = im.load(); ch = False
        for y in range(im.height):
            for x in range(im.width):
                r, g, b, a2 = px[x, y]
                if (r, g, b) in CLEAR or a2 == 0:
                    px[x, y] = (*endc, 255); ch = True
        if ch:
            im.save(bp)
th = os.path.join(theme, 'default.theme')
t = open(th, encoding='latin-1').read()
if 'Gradients=' not in t:
    t += '\nGradients="titleAT.xpm titleIT.xpm titleAB.xpm titleIB.xpm"\n'
    open(th, 'w', encoding='latin-1').write(t)
print(f"smooth gradients rendered into {theme} (h={height})")
#+END_SRC

** IceWM theme deriver — minimal-touch, exact-ramp

The first derivations mangled tested themes: a broad "is it bluish?" pixel test chewed antialiased button and bevel pixels, and broken-symlink pruning dropped pixmaps IceWM then faked badly. This tool is the correction: the authoritative gradient ramp is collected from the =title*.xpm= palettes ONLY, and ONLY those exact colours are remapped anywhere else — every other pixel and file stays byte-identical to the source theme the user already approved.

#+BEGIN_SRC bash :tangle linux/.local/bin/redstone-9x-icewm-derive :shebang "#!/bin/bash" :tangle-mode (identity #o755)
# redstone-9x-icewm-derive <src> <out> <dark-hex> <light-hex> [--flat-menusel HEX] [--drop-icons]
# Clone an IceWM theme and remap ONLY its titlebar gradient ramp onto
# dark->light. Nothing else changes: buttons, bevels, taskbar art stay
# byte-identical; valid symlinks are preserved; only BROKEN links are pruned.
set -euo pipefail
SRC="${1:?src theme dir}"; OUT="${2:?out dir}"; DARK="${3:?dark hex}"; LIGHT="${4:?light hex}"
shift 4
FLAT=""; DROP_ICONS=0
while [[ $# -gt 0 ]]; do
  case "$1" in
    --flat-menusel) FLAT="$2"; shift 2 ;;
    --drop-icons) DROP_ICONS=1; shift ;;
    *) echo "unknown arg: $1" >&2; exit 1 ;;
  esac
done
rm -rf "${OUT}"
cp -a "${SRC}" "${OUT}"
find "${OUT}" -xtype l -delete
rm -f "${OUT}/default.theme.custom" "${OUT}"/default.theme.save "${OUT}"/*.save "${OUT}/results.txt" 2>/dev/null || true
[[ "${DROP_ICONS}" -eq 1 ]] && rm -rf "${OUT}/icons"

python3 - "${OUT}" "${DARK}" "${LIGHT}" "${FLAT}" <<'PYINNER'
import sys, os, re
out, dark, light, flat = sys.argv[1], sys.argv[2], sys.argv[3], sys.argv[4]
DARK = tuple(int(dark.lstrip('#')[i:i+2],16) for i in (0,2,4))
LIGHT = tuple(int(light.lstrip('#')[i:i+2],16) for i in (0,2,4))
FLAT = tuple(int(flat.lstrip('#')[i:i+2],16) for i in (0,2,4)) if flat else None
HEXRE = re.compile(r'c #([0-9a-fA-F]{6})')
def lum(c): return 0.299*c[0] + 0.587*c[1] + 0.114*c[2]
def is_blue(c): return c[2] > c[0] + 24 and c[2] > c[1] + 16

# The ramp = blue palette entries of title*.xpm ONLY. Authoritative, narrow.
ramp = set()
for fn in os.listdir(out):
    if fn.startswith('title') and fn.endswith('.xpm'):
        for m in HEXRE.finditer(open(os.path.join(out, fn), encoding='latin-1').read()):
            c = tuple(int(m.group(1)[i:i+2],16) for i in (0,2,4))
            if is_blue(c): ramp.add(c)
if not ramp:
    print("no titlebar ramp found — nothing remapped"); sys.exit(0)
LO, HI = min(map(lum, ramp)), max(map(lum, ramp))
def mapped(c):
    t = 0.0 if HI == LO else (lum(c)-LO)/(HI-LO)
    return tuple(round(d + (l-d)*t) for d, l in zip(DARK, LIGHT))
n = 0
try:
    from PIL import Image
    HAVE_PIL = True
except ImportError:
    HAVE_PIL = False
for dp, _, fs in os.walk(out):
    for fn in fs:
        p = os.path.join(dp, fn)
        if not os.path.isfile(p) or os.path.islink(p):
            continue
        flat_this = FLAT and fn.startswith('menusel')
        if fn.endswith('.xpm'):
            t = open(p, encoding='latin-1').read()
            def sub(m):
                c = tuple(int(m.group(1)[i:i+2],16) for i in (0,2,4))
                if c not in ramp: return m.group(0)
                R,G,B = FLAT if flat_this else mapped(c)
                return f'c #{R:02X}{G:02X}{B:02X}'
            t2 = HEXRE.sub(sub, t)
            if t2 != t: open(p, 'w', encoding='latin-1').write(t2); n += 1
        elif fn.endswith('.png') and HAVE_PIL:
            im = Image.open(p).convert('RGBA'); px = im.load(); ch = False
            for y in range(im.height):
                for x in range(im.width):
                    r,g,b,a = px[x,y]
                    if (r,g,b) in ramp:
                        R,G,B = FLAT if flat_this else mapped((r,g,b))
                        px[x,y] = (R,G,B,a); ch = True
            if ch: im.save(p); n += 1
print(f"exact-ramp remap: {len(ramp)} ramp colours, {n} files touched")
PYINNER
#+END_SRC

def emit(imgs, cat, name):
    # imgs: {16: Image|None, 32: Image|None}; nearest-neighbour resample for
    # the in-between/large sizes IceWM's graft wants (pixel-art rule).
    global count
    base32 = imgs.get(32) or (imgs.get(16).resize((32, 32), Image.NEAREST) if imgs.get(16) else None)
    base16 = imgs.get(16) or (imgs.get(32).resize((16, 16), Image.NEAREST) if imgs.get(32) else None)
    if base32 is None and base16 is None:
        return
    for size in SIZES:
        if size == 16:
            img = base16
        elif size == 32:
            img = base32
        else:
            src = base32 if base32 is not None else base16
            img = src.resize((size, size), Image.NEAREST)
        d = os.path.join(out, cat, str(size))
        os.makedirs(d, exist_ok=True)
        img.save(os.path.join(d, name + ".png"))
        count += 1

import sys, os
from PIL import Image
COLORMAP = {
    (0xC0, 0xC0, 0xC0): (0xD4, 0xD0, 0xC8),
    # Taskbar/toolbar fill: the Windows-95 theme uses a THIRD grey (#c3c3c3,
    # +3 over chrome) in taskbarbg.xpm/toolbuttonbg.xpm — found live 2026-07-19

    (0xDF, 0xDF, 0xDF): (0xE8, 0xE4, 0xDC),
    (0xE0, 0xE0, 0xE0): (0xE8, 0xE4, 0xDC),
    (0x00, 0x00, 0x80): (0x84, 0x35, 0x1A),
    (0x00, 0x80, 0x80): (0x50, 0x50, 0x50),
}
n = 0
for root in sys.argv[1:]:
    for dirpath, _, files in os.walk(root):
        for fn in files:
            if not fn.lower().endswith((".png", ".xpm")):
                continue
            if fn.lower().endswith(".xpm"):
                # xpm is text: colour-table substitution
                p = os.path.join(dirpath, fn)
                t = open(p, encoding="latin-1").read()
                for (r, g, b), (R, G, B) in COLORMAP.items():
                    t = t.replace(f"#{r:02x}{g:02x}{b:02x}", f"#{R:02x}{G:02x}{B:02x}")
                    t = t.replace(f"#{r:02X}{g:02X}{b:02X}", f"#{R:02X}{G:02X}{B:02X}")
                open(p, "w", encoding="latin-1").write(t)
                n += 1
                continue
            p = os.path.join(dirpath, fn)
            img = Image.open(p).convert("RGBA")
            px = img.load()
            changed = False
            for y in range(img.height):
                for x in range(img.width):
                    r, g, b, a = px[x, y]
                    m = COLORMAP.get((r, g, b))
                    if m:
                        px[x, y] = (*m, a)
                        changed = True
            if changed:
                img.save(p)
                n += 1
print(f"recoloured {n} pixmaps")
