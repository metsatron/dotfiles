* Purpose
Brave (flatpak =com.brave.Browser=, declared in =package-flatpak.org=) is used as a Chromium-family agent browser: fleet agents drive it over the Chrome DevTools Protocol (CDP) to work ChatGPT Projects and Perplexity Spaces. A stock Brave profile carries substantial first-party bloat (Rewards, Wallet, VPN upsells, Leo AI, telemetry) that has no place in an agent-driven profile, so this module authors ONE managed-policy JSON that hardens everything else while leaving CDP explicitly open. The same policy is meant to be reused for the daily-driver Brave later — this module does not scope it to the agent profile alone.

** Attribution and scope decision
The hardening set below is modelled on [[https://github.com/ChaoticSi1ence/SlimBrave-Neo][SlimBrave-Neo]] (GPL-3, ChaoticSi1ence), a Python-stdlib tool that assembles the same class of Chromium enterprise policy. This module vendors the *resulting policy artifact* — a single managed-policy JSON — rather than SlimBrave-Neo's Python source tree. Rationale: the apply lane below is a static file install (=install -Dm644=) into =/etc/brave/policies/managed/=; it never executes SlimBrave-Neo's code, so there is nothing here for that source tree to do at apply time. If a byte-for-byte vendored copy of the upstream tool is wanted instead (e.g. to keep its =--export=/=--import= workflow available locally), that is a bigger, separate ask — flagged back to the coordinator rather than assumed.

The policy keys below were cross-checked against SlimBrave-Neo's published documentation, not pulled byte-for-byte from its source (source retrieval here goes through a summarizing fetch, not a verbatim one, and a wrong Chromium policy key is silently ignored by the browser rather than erroring loudly — so favor a smaller, high-confidence key set over a larger guessed one). Verify the full effective set against upstream and against =brave://policy= after a real apply; this module does not claim exact parity with SlimBrave-Neo's own generated JSON.

** The one hard rule: remote debugging stays open
SlimBrave-Neo ships a "Block Remote Debugging" toggle (=RemoteDebuggingAllowed: false=) whose own docs say it breaks Puppeteer/Playwright and =brave://inspect=. That toggle is intentionally OMITTED from "off" and instead pinned explicitly to =true= below — see the =RemoteDebuggingAllowed= key. =DeveloperToolsAvailability= is left unset for the same reason: it is a separate Chromium policy gating the DevTools UI/panel, and pinning it closed risks colliding with the CDP-open requirement for no benefit here. Do not add either restriction without re-confirming it does not close CDP.

* Managed policy JSON
Single file, all Brave channels on Linux read the same managed-policy directory. Tangled into the stowed =$HOME= tree first; =brave-managed-policy-apply= (below) is the only thing that copies it into the live, root-owned =/etc/brave/policies/managed/= — that copy is a system mutation and is NOT run by tangle/stow.

** Violentmonkey carve-out (Mètsàtron's ruling 2026-08-16)
The agent browser carries the FORGE userscripts (=~/HelmCortex/FORGE/userscripts/= — the exporters) through a userscript manager, so Violentmonkey (=jinjaccalgkegednnccohejagnlnfdag=) is the ONE extension allowed through the wildcard blocklist: =ExtensionInstallAllowlist= exempts it and =ExtensionInstallForcelist= auto-installs it from the Web Store on every profile, including agentify's, at next browser start. Userscript *contents* are installed into the manager per the FORGE userscripts README (the installed copy is a deployment artifact; the file in FORGE stays canonical). No other extension gets an exception without a new ruling here.

* Apply lane
Not run this pass — author-and-stage only. =--check= is safe and read-only; the default (no args) writes to =/etc/brave/policies/managed/= and requires root (escalates via =sudo -n=, matching the =run_priv= idiom used elsewhere in DotCortex, e.g. =nfs.org=, =sanctuary-gaming.org=).

#+BEGIN_SRC bash :tangle linux/.local/bin/brave-managed-policy-apply :shebang "#!/usr/bin/env bash"
# ~/DotCortex/linux/.local/bin/brave-managed-policy-apply
set -euo pipefail

TAG="brave-managed-policy-apply"
SRC="${HOME}/.config/dotcortex/brave-policy/slimbrave-managed.json"
DEST_DIR="/etc/brave/policies/managed"
DEST="${DEST_DIR}/dotcortex-slimbrave.json"

usage() {
  cat <<'EOF'
Usage: brave-managed-policy-apply [--check]

Installs the DotCortex-managed Brave hardening policy (CDP left open) to
/etc/brave/policies/managed/dotcortex-slimbrave.json. Flatpak Brave reads
this via its default --filesystem=host-etc grant and brave.sh's symlink of
/run/host/etc/brave/policies/{managed,recommended,enrollment} — no flatpak
override is required. --check reports state without writing anything.
EOF
}

[[ -r "${SRC}" ]] || {
  echo "${TAG}: missing ${SRC} — run 'tangle-one package-flatpak-brave-policy.org' && stow" >&2
  exit 1
}

if ! command -v python3 >/dev/null 2>&1 || ! python3 -c "import json,sys; json.load(open(sys.argv[1]))" "${SRC}" >/dev/null 2>&1; then
  echo "${TAG}: ${SRC} is not valid JSON" >&2
  exit 1
fi

if ! python3 -c "import json,sys; sys.exit(0 if json.load(open(sys.argv[1])).get('RemoteDebuggingAllowed') is True else 1)" "${SRC}"; then
  echo "${TAG}: refusing to apply — RemoteDebuggingAllowed is not explicitly true in ${SRC}" >&2
  exit 1
fi

if [[ "${1:-}" == "--check" ]]; then
  printf 'source     : %s\n' "${SRC}"
  printf 'live       : %s\n' "${DEST}"
  if [[ -r "${DEST}" ]]; then
    printf 'live state : present\n'
    cmp -s "${SRC}" "${DEST}" && printf 'in sync    : yes\n' || printf 'in sync    : NO — stale, run without --check\n'
  else
    printf 'live state : absent — not yet applied\n'
  fi
  exit 0
fi
[[ "${1:-}" == "" ]] || { usage >&2; exit 2; }

if [[ "$(id -u)" -eq 0 ]]; then
  install -D -m 0644 "${SRC}" "${DEST}"
else
  command -v sudo >/dev/null 2>&1 || {
    echo "${TAG}: sudo is required to provision ${DEST}" >&2
    exit 127
  }
  sudo -n install -D -m 0644 "${SRC}" "${DEST}"
fi

printf '%s: installed %s (RemoteDebuggingAllowed=true). Restart Brave and verify at brave://policy.\n' "${TAG}" "${DEST}"
#+END_SRC
