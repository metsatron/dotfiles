#+DESCRIPTION: Local bash shims for HelmCortex FORGE tools, so PATH lookup never touches NFS
#+AUTHOR: Mètsàtron — Sovereign Weaver
#+LANGUAGE: en

* The problem this solves

On every machine except the one that hosts HelmCortex natively, =~/HelmCortex= is a symlink into an NFS mount. Three of its directories — =FORGE/bin=, =FORGE/VoxForge/bin=, =FORGE/PixelForge/bin= — used to sit near the *front* of =PATH=. PATH resolution =stat()=s every directory entry in order, so with those present, **every bare-name command execution on the system reaches across NFS before it can find anything local**. When the mount is healthy that costs a fraction of a millisecond. When the server sleeps, drops off the tailnet, or is simply rebooting, the mounts are =soft,timeo=30,retrans=2= — three seconds per attempt, two retries — and *every command you type* pays it. Not just HelmCortex tools: =ls=, =git=, your rofi launcher, your window-manager keybinds.

=shell.org= already guarded this at shell *startup* with a timeout-bounded =path_dir_healthy=, and that guard is correct as far as it goes. It cannot go far enough: it runs once, when the shell starts. If the mount is healthy at 09:00 and the server goes down at 14:00, the directory is still in =PATH= and every command in every already-running shell hangs. Startup guarding cannot close a hole that opens at runtime.

The fix is to take NFS out of =PATH= entirely and reach it only when someone actually asks for a HelmCortex tool. A shim does exactly that: it is a **local regular file**, so PATH resolution finds it on local disk and never leaves the machine. NFS is touched only on invocation.

This does *not* make the tools work when the mount is down — nothing can, the code lives there. What it does is convert a **system-wide hang into a per-tool one**, and give that one tool a two-second failure with a readable reason instead of a nine-second stall.

* Why a shim and not a symlink

A symlink placed in =PATH= would defeat the entire exercise, because PATH resolution follows symlinks: =stat()= on a link whose target is on NFS is an NFS operation. The shim has to be a real local file whose *body* references the remote path, so that nothing dereferences anything remote until the shim actually runs. This distinction is the difference between a fix and a placebo, and it is easy to get backwards.

* Where the pieces live, and why

The generated shims name every HelmCortex tool. That list is not a neutral inventory — it is a map of a private operation, naming which vendors are pipelined, which client work exists, and which archival and research machinery is running. It does not belong in a public repository, so the private tool manifest remains in HelmCortex. DotCortex carries the generic capture/apply/diff machinery, the public route-class registry, and the router runtime; the registry contains classes and safe argument rules, not a private tool inventory.

| Layer | Location | Tracked? |
|-------+----------+----------|
| Generator | =all/.local/bin/hx-{capture,apply,diff}= (this file) | DotCortex, public |
| Router runtime | =all/.local/libexec/hx-router= (this file) | DotCortex, public |
| Route registry | =all/.config/agent-session/fleet-router.json= (services-fleet-router.org) | DotCortex, public |
| Manifest (authoritative) | =HelmCortex/ROOTS/DotCortex/helmcortex-shims.ssv= | HelmCortex, private |
| Manifest (local cache) | =~/.local/share/dotcortex/hx/manifest.ssv= | untracked |
| Generated shims | =~/.local/hx/bin/= | untracked |

The manifest sits in =ROOTS/= because that is where HelmCortex keeps indexed data — =FORGE/harness/= is the source layer for compiled agent behaviour and emphatically not a datastore. It sits under =ROOTS/DotCortex/= following the compiler's own precedent of filing an index under its consumer's name, exactly as =ROOTS/Hermes/helmcortex-skills.json= does.

The **local cache is the point of the whole arrangement**: it is what lets a machine regenerate its shims with the mount dead. Capture needs the mount; apply does not.

One consequence to state plainly, because it is easy to assume otherwise: **=ROOTS/= is deliberately not tracked by HelmCortex's git**. Its =.gitignore= is deny-all with explicit un-ignores, and it carries the comment "ROOTS: backed up by helmcortex-borg (daily archives), not tracked in git" (the sync-era rsync mirrors were retired 2026-08-27 after the borg rehydrate drill passed). So the manifest is backed up — borg's daily archives even give it point-in-time history — but there is no commit diff to review when the tool list changes. =hx-diff= is the review mechanism instead — and it is the better one for this job, because it compares three things a commit diff cannot: the manifest, the shims actually generated on this machine, and the live contents of HelmCortex. Do not reach for =git log= here expecting history that was never kept.

* The guards, and what each one is for

**Capture refuses a short manifest.** If capture ever runs while the mount is down, half-populated, or pointed somewhere wrong, it would otherwise write an empty list — and apply would faithfully delete all ninety-odd shims. =MIN_TOOLS= is the floor that makes that impossible. This is the same shape as the double-suspend guard in =xfce-host-keys=: the dangerous case is not the operation failing, it is the operation succeeding against an empty input.

**Capture probes before it scans.** A directory that does not answer within the timeout aborts the whole capture rather than contributing zero tools to the total.

**Capture ignores backup and editor artefacts.** Editing a HelmCortex tool in place leaves an executable sibling next to it — =pvox.backup-20260725-181959=, an editor swap file, a =.orig= from a merge. Without a filter those become shims on =PATH=, and removing the backup later leaves an orphan that nothing but =hx-apply= would ever notice. =hx-diff= applies the identical filter to its live scan; if the two ever drift apart, =hx-diff= reports permanent phantom drift for files capture is correctly ignoring.

**Apply prunes only what the manifest disowns**, and prints every addition and removal. Orphan removal is the feature that keeps a renamed or deleted tool from leaving a shim that fails confusingly later.

**Apply prefers the live manifest and falls back to the cache**, announcing which it used. Silent fallback is the failure mode this house names most often; the source of truth for a given run should never be a guess.

** The one assumption the timeout guard rests on

Every probe here is =timeout -k 1 2=, not a bare =timeout 2=, and the reason is worth writing down because it is invisible from the outside.

There are two ways HelmCortex can be gone, and they behave nothing alike. If the path simply does not resolve — the automount failed, the export vanished, the symlink dangles — =test -d= returns =ENOENT= immediately and the guard fires in about ten milliseconds. That is the easy case and it is fully verified. The hard case is a server that is still *reachable at the TCP level* but has stopped answering RPCs: a wedged x230, a suspended host, a tailnet that is up but blackholed. There =stat()= does not return, it blocks in the kernel, and whether the guard can save you depends entirely on how the mount was made.

The mount is =nfs4 … soft,timeo=30,retrans=2=. On a **soft** mount the RPC wait is =TASK_KILLABLE=, so a fatal signal breaks it — but =timeo= is measured in tenths of a second, so 3 s per attempt across 2 retransmits means the kernel may take the better part of ten seconds to give up on its own. The =timeout= is what bounds that. Plain =timeout= sends =SIGTERM=, which does in fact break a killable wait (a default-disposition =SIGTERM= causes a group exit, which posts =SIGKILL= to the thread), but that chain has more links in it than a safety guard should depend on. The =-k 1= appends an unconditional =SIGKILL= one second later, which needs no reasoning at all to be correct.

**On a =hard= mount none of this works.** Hard-mount RPC waits are =TASK_UNINTERRUPTIBLE=; the process sits in =D= state and no signal — not =SIGKILL=, not anything — will move it until the server comes back. Every guard in this file would be decorative, and the shims would hang exactly like the bare =PATH= entries they were built to replace. **The =soft= mount option is therefore a load-bearing part of this design, not an incidental detail of how the share happens to be configured today.** =hx-diff= checks it on every run and says so out loud, because a documented invariant that nothing verifies is an invariant that quietly stops being true.

* Capture — scan HelmCortex and write the manifest

#+BEGIN_SRC bash :tangle all/.local/bin/hx-capture :shebang "#!/usr/bin/env bash" :tangle-mode (identity #o755)
# hx-capture — scan HelmCortex FORGE bin directories and write the shim manifest.
# Requires the mount to be reachable. Writes the authoritative manifest into
# HelmCortex (private) and refreshes the machine-local cache. See helmcortex-shims.org.
set -euo pipefail

HELM="${HELMCORTEX_ROOT:-$HOME/HelmCortex}"
SCAN_DIRS=(FORGE/bin FORGE/VoxForge/bin FORGE/PixelForge/bin)
MANIFEST="${HELM}/ROOTS/DotCortex/helmcortex-shims.ssv"
CACHE_DIR="${XDG_DATA_HOME:-$HOME/.local/share}/dotcortex/hx"
CACHE="${CACHE_DIR}/manifest.ssv"

# Floor guard: a capture that finds fewer than this many tools is assumed broken
# (dead mount, wrong root, partial listing) and must not be allowed to overwrite
# a good manifest with a short one — apply would then delete every real shim.
MIN_TOOLS=20
PROBE_TIMEOUT=5

die() { echo "hx-capture: $*" >&2; exit 1; }

[ -n "${HELM}" ] || die "HELMCORTEX_ROOT is empty"

# Probe every directory first. A dir that does not answer aborts the run rather
# than silently contributing zero entries to the total.
for d in "${SCAN_DIRS[@]}"; do
  if ! timeout -k 1 "${PROBE_TIMEOUT}" test -d "${HELM}/${d}" 2>/dev/null; then
    die "${HELM}/${d} did not answer in ${PROBE_TIMEOUT}s — mount down? refusing to capture"
  fi
done

tmp="$(mktemp)"
trap 'rm -f "${tmp}"' EXIT
{
  echo "# HelmCortex shim manifest — generated by hx-capture, do not hand-edit."
  echo "# Consumed by hx-apply to generate ~/.local/hx/bin/ shims."
  echo "# NAME DIR"
} > "${tmp}"

count=0
skipped=0
for d in "${SCAN_DIRS[@]}"; do
  while IFS= read -r f; do
    [ -n "${f}" ] || continue
    name="$(basename "${f}")"
    # Editing a tool in place leaves an executable sibling behind — a timestamped
    # backup, an editor swap file, a merge leftover. Those are not tools and must
    # not become shims: they would be shimmed onto PATH, and deleting the backup
    # later would leave an orphan that only hx-apply notices. Filter at the source.
    case "${name}" in
      *.backup-*|*.bak|*.orig|*.rej|*.save|*.disabled|*~|.*|\#*)
        skipped=$((skipped + 1)); continue ;;
    esac
    printf '%s %s\n' "${name}" "${d}" >> "${tmp}"
    count=$((count + 1))
  done < <(find "${HELM}/${d}" -maxdepth 1 -type f -executable -printf '%p\n' 2>/dev/null | sort)
done
[ "${skipped}" -eq 0 ] || echo "hx-capture: skipped ${skipped} backup/editor artefact(s)"

if [ "${count}" -lt "${MIN_TOOLS}" ]; then
  die "found only ${count} tools (floor is ${MIN_TOOLS}) — refusing to write a short manifest"
fi

# Duplicate tool names across directories would make the shim ambiguous: two
# manifest rows, one output file, last writer wins silently. Catch it here.
dupes="$(awk '!/^#/ {print $1}' "${tmp}" | sort | uniq -d)"
if [ -n "${dupes}" ]; then
  die "duplicate tool names across scan dirs, shim would be ambiguous: $(echo ${dupes} | tr '\n' ' ')"
fi

mkdir -p "$(dirname "${MANIFEST}")" "${CACHE_DIR}"
cp -f "${tmp}" "${MANIFEST}"
cp -f "${tmp}" "${CACHE}"
echo "hx-capture: ${count} tools -> ${MANIFEST}"
echo "hx-capture: cache refreshed -> ${CACHE}"
#+END_SRC

* Apply — generate the shims

#+BEGIN_SRC bash :tangle all/.local/bin/hx-apply :shebang "#!/usr/bin/env bash" :tangle-mode (identity #o755)
# hx-apply — generate local router shims from the manifest. Works with the
# mount DOWN, by falling back to the machine-local cache. See
# services-fleet-router.org for the generated route registry.
set -euo pipefail

HELM="${HELMCORTEX_ROOT:-$HOME/HelmCortex}"
MANIFEST="${HELM}/ROOTS/DotCortex/helmcortex-shims.ssv"
CACHE_DIR="${XDG_DATA_HOME:-$HOME/.local/share}/dotcortex/hx"
CACHE="${CACHE_DIR}/manifest.ssv"
SHIM_DIR="${HOME}/.local/hx/bin"
ROUTER="${HOME}/.local/libexec/hx-router"
PROBE_TIMEOUT=2

die() { echo "hx-apply: $*" >&2; exit 1; }

[ -x "${ROUTER}" ] || die "missing ${ROUTER} — tangle helmcortex-shims.org first"

# Prefer the authoritative manifest; fall back to the cache. Announce which was
# used — a run whose source of truth is ambiguous is worse than one that fails.
src=""
if timeout -k 1 "${PROBE_TIMEOUT}" test -r "${MANIFEST}" 2>/dev/null; then
  src="${MANIFEST}"
  mkdir -p "${CACHE_DIR}"
  cp -f "${MANIFEST}" "${CACHE}" 2>/dev/null || true
  echo "hx-apply: source = HelmCortex manifest (mount up, cache refreshed)"
elif [ -r "${CACHE}" ]; then
  src="${CACHE}"
  echo "hx-apply: source = local cache (HelmCortex unreachable)"
else
  die "no manifest and no cache — run hx-capture on a machine that can see HelmCortex"
fi

mkdir -p "${SHIM_DIR}"

wanted="$(mktemp)"; trap 'rm -f "${wanted}"' EXIT
added=0; kept=0

while read -r name dir; do
  case "${name}" in ''|\#*) continue ;; esac
  [ -n "${dir}" ] || continue
  echo "${name}" >> "${wanted}"
  target="${SHIM_DIR}/${name}"
  new="$(mktemp)"
  cat > "${new}" <<SHIM
#!/usr/bin/env bash
# hx shim — ${name} (generated by hx-apply; edit helmcortex-shims.org)
set -euo pipefail
ROUTER="\$HOME/.local/libexec/hx-router"
REGISTRY="\${HX_ROUTER_REGISTRY:-\$HOME/.config/agent-session/fleet-router.json}"
DIR="\$HOME/HelmCortex/${dir}"
TOOL="${name}"
REAL="\$DIR/\$TOOL"

if ! timeout -k 1 2 test -x "\$ROUTER" 2>/dev/null; then
  echo "hx: router missing or not executable at \$ROUTER" >&2
  exit 127
fi
if ! timeout -k 1 2 test -r "\$REGISTRY" 2>/dev/null; then
  echo "hx: fleet router registry missing at \$REGISTRY" >&2
  exit 78
fi
export HX_CALLER_PWD="\$PWD"
exec "\$ROUTER" "\$REGISTRY" "\$TOOL" "\$REAL" "\$HOME/HelmCortex/${dir}/${name}" "\$@"
SHIM
  chmod 755 "${new}"
  if [ -f "${target}" ] && cmp -s "${new}" "${target}"; then
    kept=$((kept + 1)); rm -f "${new}"
  else
    mv -f "${new}" "${target}"
    added=$((added + 1)); echo "  + ${name}  (${dir})"
  fi
done < "${src}"

# Prune orphans: shims whose tool is no longer in the manifest.
removed=0
if [ -d "${SHIM_DIR}" ]; then
  while IFS= read -r existing; do
    [ -n "${existing}" ] || continue
    n="$(basename "${existing}")"
    if ! grep -qxF "${n}" "${wanted}"; then
      rm -f "${existing}"; removed=$((removed + 1)); echo "  - ${n}  (orphan)"
    fi
  done < <(find "${SHIM_DIR}" -maxdepth 1 -type f 2>/dev/null)
fi

echo "hx-apply: ${added} written, ${kept} unchanged, ${removed} pruned -> ${SHIM_DIR}"
#+END_SRC

* Router runtime — bounded SSH bridge with exact argv

#+BEGIN_SRC python :tangle all/.local/libexec/hx-router :shebang "#!/usr/bin/env python3" :tangle-mode (identity #o755)
"""Execute one HX tool according to the generated Fleet Nervous System registry."""
import base64
import json
import os
import subprocess
import socket
import sys

CLASSES = {"hub", "client-fanout-safe", "client-fanout-reconcile"}


def fail(message, code):
    print(f"hx-router: {message}", file=sys.stderr)
    raise SystemExit(code)


def load(path):
    try:
        with open(path, encoding="utf-8") as stream:
            return json.load(stream)
    except (OSError, ValueError) as exc:
        fail(f"cannot load registry {path}: {exc}", 78)


def route_class(entry, argv):
    for rule in entry.get("rules", []):
        prefix = rule.get("argv_prefix")
        if prefix is not None and argv[:len(prefix)] != prefix:
            continue
        indexed = rule.get("argv_index_equals")
        if indexed is not None:
            index = indexed.get("index", -1)
            if index < 0 or index >= len(argv) or argv[index] != indexed.get("value"):
                continue
        return rule.get("class")
    return entry.get("class")


def machine_role(machine_registry):
    wanted = os.environ.get("HX_ROUTER_HOSTNAME") or socket.gethostname()
    for machine in machine_registry.get("machines", []):
        if wanted == machine.get("key") or wanted in machine.get("hostnames", []):
            return machine.get("key"), machine.get("role", "client")
    return wanted, "client"


def guard_local(real):
    tool_dir = os.path.dirname(real)
    guard = ["/usr/bin/timeout", "-k", "1", "2", "test"]
    if subprocess.run([*guard, "-d", tool_dir], stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL).returncode != 0:
        fail(f"HelmCortex unreachable — {tool_dir} did not answer in 2s", 69)
    if subprocess.run([*guard, "-x", real], stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL).returncode != 0:
        fail(f"tool missing or not executable at {real}", 127)


def route_stack(tool):
    stack = [item for item in os.environ.get("HX_ROUTER_STACK", "").split(":") if item]
    if tool in stack:
        fail(f"recursion protection: {tool} already appears in HX_ROUTER_STACK", 125)
    return ":".join([*stack, tool])


def run_local(real, tool, argv, guarded):
    if guarded:
        guard_local(real)
    caller_pwd = os.environ.get("HX_CALLER_PWD", os.getcwd())
    os.chdir(os.path.dirname(real))
    env = os.environ.copy()
    env["HX_CALLER_PWD"] = caller_pwd
    env["HX_ROUTER_STACK"] = route_stack(tool)
    try:
        os.execvpe(real, [real, *argv], env)
    except OSError as exc:
        fail(f"local tool {real} could not execute: {exc}", 127)


def ssh_executable():
    override = os.environ.get("HX_SSH_BIN")
    if override:
        if os.environ.get("HX_ROUTER_TEST") != "1":
            fail("HX_SSH_BIN is test-only; set HX_ROUTER_TEST=1", 64)
        return override
    return "/usr/bin/ssh"


def isolate_ssh_stdin():
    fd = os.open(os.devnull, os.O_RDONLY)
    try:
        os.dup2(fd, 0)
    finally:
        if fd != 0:
            os.close(fd)


def main():
    if len(sys.argv) < 5:
        fail("usage: hx-router REGISTRY TOOL LOCAL_REAL REMOTE_REAL [ARGV ...]", 64)
    registry_path, tool, local_real, remote_real, *argv = sys.argv[1:]
    registry = load(registry_path)
    if registry.get("schema") != "dotcortex.fleet-router.v2":
        fail(f"unsupported registry schema in {registry_path}", 78)
    entry = registry.get("tools", {}).get(tool)
    if entry is None:
        route = registry.get("defaults", {}).get("class", "client-fanout-safe")
    else:
        route = route_class(entry, argv)
    reconcile = None
    if entry and "reconcile" in entry:
        sys.dont_write_bytecode = True
        try:
            import hx_reconcile as reconcile
        except ImportError as exc:
            fail(f"local reconcile runtime unavailable: {exc}", 78)
        try:
            reconcile.check_policy(entry)
            route, source_root = reconcile.classify(argv)
        except reconcile.Refusal as exc:
            fail(str(exc), exc.code)
    if route not in CLASSES:
        fail(f"tool {tool} declares invalid route class {route!r}", 64)
    if route == "client-fanout-reconcile" and reconcile is None:
        fail(f"tool {tool} is client-fanout-reconcile; reconcile engine is not implemented", 78)
    if route == "client-fanout-safe":
        run_local(local_real, tool, argv, guarded=True)

    machine_registry_path = os.environ.get(
        "HELM_ROUTER_MACHINE_REGISTRY",
        os.path.expanduser("~/.config/agent-session/version-registry.json"),
    )
    machines = load(machine_registry_path)
    machine_key, role = machine_role(machines)
    hub_key = registry["transport"]["hub_machine_key"]
    if route == "client-fanout-reconcile":
        stack = route_stack(tool)
        try:
            result = reconcile.dispatch(
                registry["transport"], tool, argv, source_root,
                local_real if role == "hub" and machine_key == hub_key else remote_real,
                stack, role == "hub" and machine_key == hub_key, ssh_executable(),
            )
        except reconcile.Refusal as exc:
            fail(str(exc), exc.code)
        raise SystemExit(result)
    if role == "hub" and machine_key == hub_key:
        run_local(local_real, tool, argv, guarded=False)

    transport = registry["transport"]
    alias = transport.get("hub_ssh_alias")
    if not alias:
        fail("hub route has no SSH alias", 78)
    options = []
    for key, value in transport.get("ssh_options", {}).items():
        options.extend(["-o", f"{key}={value}"])
    payload = {
        "real": remote_real,
        "argv": argv,
        "caller_pwd": os.environ.get("HX_CALLER_PWD", os.getcwd()),
        "router_stack": route_stack(tool),
    }
    encoded = base64.b64encode(json.dumps(payload, ensure_ascii=False, separators=(",", ":")).encode()).decode()
    code = ("import base64,json,os,sys;d=json.loads(base64.b64decode(sys.argv[2]));"
            "os.environ[\"HX_CALLER_PWD\"]=d[\"caller_pwd\"];os.environ[\"HX_ROUTER_STACK\"]=d[\"router_stack\"];"
            "os.chdir(os.path.dirname(d[\"real\"]));os.execvpe(d[\"real\"],[d[\"real\"],*d[\"argv\"]],os.environ)")
    command = "python3 -c '" + code + "' -- " + encoded
    executable = ssh_executable()
    isolate_ssh_stdin()
    os.execv(executable, [executable, *options, alias, command])


if __name__ == "__main__":
    main()
#+END_SRC

* Reconcile runtime — caller snapshot and verified framed input

=hx_reconcile.py= is deployed alongside =hx-router= on both endpoints. It uses only local Python standard-library code. Source capture never imports FORGE, checks the real tool target, or reads caller stdin. Linux mount-table admission precedes descriptor-relative, no-follow source opens; unknown/remote filesystems, symlink components and nested mounts are refused. No Git object or index filtering occurs: the selected root's admitted working-tree bytes, including dirty and untracked Org, are authoritative for this request. This is a per-file capture, not an atomic filesystem snapshot; a file that changes during its read fails admission.

The public admission contract =dotcortex-operational-root-org-v1= includes immediate, case-sensitive =*.org= names, excluding =README.org=, =CODE_OF_SOVEREIGNTY.org=, =agents.org=, =agents-hooks.org=, =agents-mcp.org=, =loom.org=, =dotcortex.org=, =claude.org=, and =agents-skills*.org=. Files sort by =(name.lower(), name)=. Paths are basenames, never extraction destinations. Protocol v1 limits are 4096 files, 8 MiB/file, 64 MiB content, 1 MiB manifest, 64 KiB invocation envelope, and 600 seconds for transfer/finalization. Invalid input returns 65; usage 2; unsupported policy/protocol/locality 78; timeout 124. Application and SSH exit status and output streams propagate without a fallback or success receipt.

** Hub receiver contract

The SSH command imports the hub's =~/.local/libexec/hx_reconcile.py= and calls =receive(encoded_envelope)=. The base64 canonical-JSON envelope has exactly =protocol, tool, real, argv, caller_pwd, router_stack=. Protocol is =dotcortex-root-org-v1=; =real= is the absolute real entrypoint supplied by the shim, never the shim again. The receiver validates the entire bounded stdin frame before invoking that entrypoint in its own directory with argv =hub-finalize --snapshot-protocol dotcortex-root-org-v1 -- ORIGINAL_ARGV...= and the exact verified frame on stdin. =HX_CALLER_PWD= and =HX_ROUTER_STACK= are preserved. The source-root argument remains caller provenance; the hub must never resolve it or re-read it. Direct =hub-finalize= and =--logs-only= invocations remain ordinary hub routes with SSH stdin isolated; only the reconcile receiver opts into framed input.

Frame bytes are =b"HXRC\x00\x01\n"=, an unsigned 8-byte big-endian manifest length, canonical ASCII JSON (sorted keys, separators comma/colon, =ensure_ascii=True=), concatenated file contents in manifest order, then the raw 32-byte SHA-256 of all preceding frame bytes, followed by EOF. Manifest keys are exactly =protocol, admission, source, files=; =source= is exactly ={host, checkout, mode}= with actual source hostname, absolute lexical checkout path and =working-tree=. Each file is exactly ={path, bytes, sha256}=. Both per-file digests and the frame digest must validate. =decode_frame(stream)= returns =(manifest, [(record, bytes), ...], frame)= for the later private finalizer to consume without any source reread. It must render, lock and publish canonical state in HelmCortex; those private operations are outside this public runtime. Unsupported receiver/finalizer versions must fail before publication. The finalizer's CLI must recognize the exact internal invocation above; this change does not deploy or implement it.

SECONDS = 600
EXCLUDED = frozenset({
    "README.org", "CODE_OF_SOVEREIGNTY.org", "agents.org", "agents-hooks.org",
    "agents-mcp.org", "loom.org", "dotcortex.org", "claude.org",
})
LOCAL_FS = frozenset({"ext2", "ext3", "ext4", "btrfs", "xfs", "zfs", "f2fs",
                      "tmpfs", "ramfs", "overlay", "ubifs"})


class Refusal(Exception):
    def __init__(self, message, code=65):
        super().__init__(message)
        self.code = code


def require(condition, message, code=65):
    if not condition:
        raise Refusal(message, code)


def canonical(value):
    return json.dumps(value, sort_keys=True, ensure_ascii=True,
                      separators=(",", ":"), allow_nan=False).encode("ascii")


def admitted(name):
    return (isinstance(name, str) and name not in {"", ".", ".."}
            and "/" not in name and "\\" not in name and "\x00" not in name
            and len(name.encode("utf-8")) <= 255 and name.endswith(".org")
            and name not in EXCLUDED and not name.startswith("agents-skills"))


def check_policy(entry):
    require(entry == {"class": "client-fanout-reconcile",
                      "reconcile": {"protocol": PROTOCOL}},
            "unsupported reconcile declaration", 78)


def classify(argv):
    require(isinstance(argv, list) and all(isinstance(a, str) and "\x00" not in a for a in argv),
            "invalid argv", 2)
    flags, root, finalize = set(), None, False
    index = 0
    while index < len(argv):
        arg = argv[index]
        if arg == "hub-finalize":
            require(not finalize, "duplicate hub-finalize", 2)
            finalize = True
        elif arg == "--source-root" or arg.startswith("--source-root="):
            require(root is None, "duplicate source-root", 2)
            if arg == "--source-root":
                index += 1
                require(index < len(argv), "source-root requires a path", 2)
                root = argv[index]
                require(not root.startswith("--"), "source-root requires a path", 2)
            else:
                root = arg.split("=", 1)[1]
            require(bool(root), "source-root requires a path", 2)
        elif arg in {"--source-only", "--logs-only", "--dry-run", "--skip-validate", "--help", "-h"}:
            flags.add(arg)
        else:
            raise Refusal(f"unsupported export argument: {arg!r}", 2)
        index += 1
    require(not {"--source-only", "--logs-only"} <= flags, "source-only conflicts with logs-only", 2)
    require(not (root is not None and ("--logs-only" in flags or finalize)),
            "source-root conflicts with logs-only/hub-finalize", 2)
    require(not (finalize and flags & {"--source-only", "--logs-only"}),
            "hub-finalize conflicts with source/log selection", 2)
    route = "hub" if finalize or flags & {"--logs-only", "--help", "-h"} else "client-fanout-reconcile"
    return route, root


def local_root(root, cwd):
    selected = os.path.expanduser(root) if root is not None else os.path.expanduser("~/DotCortex")
    require(".." not in selected.split(os.sep), "parent traversal in source-root", 2)
    path = os.path.abspath(os.path.join(cwd, selected))
    require(sys.platform.startswith("linux"), "source locality admission requires Linux", 78)
    # Read kernel metadata, never stat a remote target to determine locality.
    with open("/proc/self/mountinfo", "rb") as stream:
        raw = stream.read(MAX_MANIFEST + 1)
    require(len(raw) <= MAX_MANIFEST, "mount table exceeds admission bound", 78)
    mounts = []
    for line in raw.decode().splitlines():
        left, right = line.split(" - ", 1)
        mount = re.sub(r"\\([0-7]{3})", lambda m: chr(int(m[1], 8)), left.split()[4])
        mounts.append((mount, right.split()[0]))
    covering = [(m, fs) for m, fs in mounts if path == m or path.startswith(m.rstrip("/") + "/")]
    require(bool(covering), "unknown source filesystem", 78)
    require(max(covering, key=lambda item: len(item[0]))[1] in LOCAL_FS,
            "source-root is not on an admitted local filesystem", 78)
    require(not any(m.startswith(path.rstrip("/") + "/") for m, _ in mounts),
            "source-root contains nested mounts", 78)
    return path


def open_root(path):
    flags = os.O_RDONLY | os.O_DIRECTORY | os.O_NOFOLLOW | os.O_CLOEXEC
    fd = os.open("/", flags)
    try:
        for component in path.split("/"):
            if component:
                child = os.open(component, flags, dir_fd=fd)
                os.close(fd)
                fd = child
        return fd
    except BaseException:
        os.close(fd)
        raise


def read_source(fd, name):
    with os.fdopen(os.open(name, os.O_RDONLY | os.O_NOFOLLOW | os.O_NONBLOCK | os.O_CLOEXEC,
                           dir_fd=fd), "rb") as stream:
        before = os.fstat(stream.fileno())
        require(stat.S_ISREG(before.st_mode), f"nonregular source: {name!r}")
        require(before.st_size <= MAX_FILE, f"oversized source: {name!r}")
        content = stream.read(MAX_FILE + 1)
        after = os.fstat(stream.fileno())
    require(len(content) == before.st_size and len(content) <= MAX_FILE,
            f"source size changed: {name!r}")
    require((before.st_size, before.st_mtime_ns, before.st_ctime_ns) ==
            (after.st_size, after.st_mtime_ns, after.st_ctime_ns), f"source changed: {name!r}")
    return content


def snapshot(root, cwd):
    try:
        path = local_root(root, cwd)
        fd = open_root(path)
        try:
            names = []
            with os.scandir(fd) as entries:
                for count, entry in enumerate(entries, 1):
                    require(count <= MAX_FILES * 4, "too many source-root entries")
                    if entry.name.endswith(".org") and entry.name not in EXCLUDED and not entry.name.startswith("agents-skills"):
                        require(admitted(entry.name), "invalid root Org name")
                        names.append(entry.name)
            require(0 < len(names) <= MAX_FILES, "empty or oversized source admission")
            records, contents, total = [], [], 0
            for name in sorted(names, key=lambda n: (n.lower(), n)):
                content = read_source(fd, name)
                total += len(content)
                require(total <= MAX_CONTENT, "source content exceeds bound")
                records.append({"path": name, "bytes": len(content),
                                "sha256": hashlib.sha256(content).hexdigest()})
                contents.append(content)
        finally:
            os.close(fd)
        manifest = {"protocol": PROTOCOL, "admission": ADMISSION,
                    "source": {"host": socket.gethostname(), "checkout": path, "mode": "working-tree"},
                    "files": records}
        header = canonical(manifest)
        require(len(header) <= MAX_MANIFEST, "manifest exceeds bound")
        body = MAGIC + len(header).to_bytes(8, "big") + header + b"".join(contents)
        return body + hashlib.sha256(body).digest()
    except (OSError, UnicodeError, ValueError) as exc:
        raise Refusal(f"source capture refused: {exc}") from exc


def decode_frame(stream):
    frame = stream.read(MAX_FRAME + 1)
    require(len(frame) <= MAX_FRAME, "frame exceeds bound")
    prefix = len(MAGIC) + 8
    require(len(frame) >= prefix + 32 and frame.startswith(MAGIC), "invalid frame protocol", 78)
    size = int.from_bytes(frame[len(MAGIC):prefix], "big")
    require(0 < size <= MAX_MANIFEST and prefix + size + 32 <= len(frame), "invalid/truncated manifest")
    header = frame[prefix:prefix + size]
    try:
        manifest = json.loads(header)
        require(canonical(manifest) == header, "manifest is not canonical JSON")
    except (ValueError, UnicodeError, RecursionError) as exc:
        raise Refusal("invalid manifest JSON") from exc
    require(isinstance(manifest, dict) and set(manifest) == {"protocol", "admission", "source", "files"},
            "unknown manifest fields")
    require(manifest["protocol"] == PROTOCOL and manifest["admission"] == ADMISSION,
            "unsupported snapshot protocol/admission", 78)
    source = manifest["source"]
    require(isinstance(source, dict) and set(source) == {"host", "checkout", "mode"}, "invalid source identity")
    require(all(isinstance(v, str) and v and "\x00" not in v and len(v) <= 4096 for v in source.values()),
            "invalid source identity values")
    require(source["mode"] == "working-tree" and source["checkout"].startswith("/")
            and ".." not in source["checkout"].split("/"), "invalid checkout identity")
    records = manifest["files"]
    require(isinstance(records, list) and 0 < len(records) <= MAX_FILES, "invalid file count")
    position, total, names, contents = prefix + size, 0, [], []
    for record in records:
        require(isinstance(record, dict) and set(record) == {"path", "bytes", "sha256"}, "invalid file record")
        try:
            valid_name = admitted(record["path"])
        except UnicodeError:
            valid_name = False
        require(valid_name, "unadmitted file path")
        count = record["bytes"]
        require(type(count) is int and 0 <= count <= MAX_FILE, "invalid file size")
        total += count
        require(total <= MAX_CONTENT and position + count <= len(frame) - 32, "truncated/oversized content")
        content = frame[position:position + count]
        require(hashlib.sha256(content).hexdigest() == record["sha256"], "file integrity failure")
        position += count
        names.append(record["path"])
        contents.append((record, content))
    require(names == sorted(set(names), key=lambda n: (n.lower(), n)), "duplicate/unsorted paths")
    require(position == len(frame) - 32, "trailing/truncated frame content")
    require(hashlib.sha256(frame[:-32]).digest() == frame[-32:], "frame integrity failure")
    return manifest, contents, frame


def envelope(payload):
    require(isinstance(payload, dict) and set(payload) ==
            {"protocol", "tool", "real", "argv", "caller_pwd", "router_stack"}, "invalid invocation fields", 78)
    require(payload["protocol"] == PROTOCOL, "unsupported invocation protocol", 78)
    for key in ("tool", "real", "caller_pwd", "router_stack"):
        require(isinstance(payload[key], str) and payload[key] and "\x00" not in payload[key],
                "invalid invocation identity", 78)
    require(payload["real"].startswith("/") and payload["caller_pwd"].startswith("/"),
            "invocation paths must be absolute", 78)
    require(payload["router_stack"].split(":").count(payload["tool"]) == 1, "invalid recursion stack", 125)
    route, _ = classify(payload["argv"])
    require(route == "client-fanout-reconcile", "receiver requires source invocation", 78)
    data = canonical(payload)
    require(len(data) <= MAX_ENVELOPE, "invocation exceeds bound", 78)
    return base64.b64encode(data).decode("ascii")


def run_bounded(argv, frame, **kwargs):
    try:
        result = subprocess.run(argv, input=frame, timeout=SECONDS, **kwargs)
        return result.returncode if result.returncode >= 0 else 128 - result.returncode
    except subprocess.TimeoutExpired as exc:
        raise Refusal("reconcile deadline exceeded", 124) from exc
    except OSError as exc:
        raise Refusal(f"reconcile execution failed: {exc}", 127) from exc


def finalize(payload, stream):
    envelope(payload)
    _, _, frame = decode_frame(stream)
    env = os.environ.copy()
    env["HX_CALLER_PWD"] = payload["caller_pwd"]
    env["HX_ROUTER_STACK"] = payload["router_stack"]
    return run_bounded([payload["real"], "hub-finalize", "--snapshot-protocol", PROTOCOL,
                        "--", *payload["argv"]], frame,
                       cwd=os.path.dirname(payload["real"]), env=env)


def receive(encoded):
    def expired(signum, current):
        raise Refusal("receiver deadline exceeded", 124)
    signal.signal(signal.SIGALRM, expired)
    signal.alarm(SECONDS)
    try:
        require(len(encoded) <= 4 * ((MAX_ENVELOPE + 2) // 3), "invocation exceeds bound", 78)
        try:
            payload = json.loads(base64.b64decode(encoded, validate=True))
        except (ValueError, UnicodeError, RecursionError) as exc:
            raise Refusal("invalid invocation encoding", 78) from exc
        require(envelope(payload) == encoded, "noncanonical invocation encoding", 78)
        status = finalize(payload, sys.stdin.buffer)
    except Refusal as exc:
        print(f"hx-reconcile: {exc}", file=sys.stderr)
        status = exc.code
    finally:
        signal.alarm(0)
    raise SystemExit(status)


def dispatch(transport, tool, argv, root, real, stack, local, ssh):
    caller = os.environ.get("HX_CALLER_PWD", os.getcwd())
    payload = {"protocol": PROTOCOL, "tool": tool, "real": real, "argv": argv,
               "caller_pwd": caller, "router_stack": stack}
    encoded = envelope(payload)
    alias = transport.get("hub_ssh_alias")
    require(isinstance(alias, str) and alias and not alias.startswith("-"), "invalid hub alias", 78)
    options = transport.get("ssh_options", {})
    required = {"BatchMode": "yes", "PasswordAuthentication": "no",
                "KbdInteractiveAuthentication": "no", "PreferredAuthentications": "publickey",
                "ConnectTimeout": "10", "ConnectionAttempts": "1"}
    require(options == required and transport.get("kind") == "ssh-exec", "unsupported reconcile transport", 78)
    frame = snapshot(root, caller)
    if local:
        return finalize(payload, io.BytesIO(frame))
    code = ('import os,sys;sys.dont_write_bytecode=True;'
            'sys.path.insert(0,os.path.expanduser("~/.local/libexec"));'
            'import hx_reconcile;hx_reconcile.receive(sys.argv[1])')
    command = "python3 -c " + shlex.quote(code) + " " + shlex.quote(encoded)
    ssh_options = [item for key, value in required.items() for item in ("-o", f"{key}={value}")]
    return run_bounded([ssh, "-T", *ssh_options, alias, command], frame)

#+BEGIN_SRC bash :tangle all/.local/bin/hx-diff :shebang "#!/usr/bin/env bash" :tangle-mode (identity #o755)
# hx-diff — report drift: manifest vs generated shims, and (when the mount is up)
# manifest vs live HelmCortex. Read-only. See helmcortex-shims.org.
set -euo pipefail

HELM="${HELMCORTEX_ROOT:-$HOME/HelmCortex}"
SCAN_DIRS=(FORGE/bin FORGE/VoxForge/bin FORGE/PixelForge/bin)
MANIFEST="${HELM}/ROOTS/DotCortex/helmcortex-shims.ssv"
CACHE="${XDG_DATA_HOME:-$HOME/.local/share}/dotcortex/hx/manifest.ssv"
SHIM_DIR="${HOME}/.local/hx/bin"

src=""
if timeout -k 1 2 test -r "${MANIFEST}" 2>/dev/null; then src="${MANIFEST}"
elif [ -r "${CACHE}" ]; then src="${CACHE}"
else echo "hx-diff: no manifest and no cache"; exit 1; fi
echo "manifest: ${src}"

m="$(mktemp)"; s="$(mktemp)"; trap 'rm -f "${m}" "${s}"' EXIT
awk '!/^#/ && NF {print $1}' "${src}" | sort > "${m}"
find "${SHIM_DIR}" -maxdepth 1 -type f -printf '%f\n' 2>/dev/null | sort > "${s}"

echo "manifest tools: $(wc -l < "${m}")   generated shims: $(wc -l < "${s}")"
if diff -q "${m}" "${s}" >/dev/null; then
  echo "  shims in sync with manifest"
else
  comm -23 "${m}" "${s}" | sed 's/^/  missing shim: /'
  comm -13 "${m}" "${s}" | sed 's/^/  orphan shim:  /'
fi

# The timeout guard in every generated shim is only load-bearing on a 'soft' NFS
# mount. On a 'hard' mount stat() blocks uninterruptibly, no signal can bound it,
# and every guard in this system becomes decorative. Check the invariant rather
# than trusting the comment that asserts it. Deliberately reports only soft/hard —
# never echoes the raw options, which carry addresses.
# The '|| true' is load-bearing: findmnt exits nonzero when the target does not
# resolve, and under 'set -e' + pipefail that would kill hx-diff on a dead mount —
# precisely the situation it exists to report on.
mnt="$(timeout -k 1 2 findmnt -no FSTYPE,OPTIONS -T "${HELM}" 2>/dev/null | tail -1 || true)"
if [ -z "${mnt}" ]; then
  echo "mount check: could not read mount info for ${HELM}"
elif ! printf '%s' "${mnt}" | grep -q 'nfs'; then
  echo "mount check: not NFS — shim timeout guards are not load-bearing here"
elif printf '%s' "${mnt}" | grep -qw 'soft'; then
  echo "mount check: NFS mount is 'soft' — shim timeout guards are effective"
else
  echo "mount check: WARNING — NFS mount is NOT 'soft'." >&2
  echo "  A hard mount blocks stat() uninterruptibly. Every hx guard becomes" >&2
  echo "  decorative and a wedged server will hang the shim exactly like the bare" >&2
  echo "  PATH entries these replaced. Restore 'soft' before relying on the shims." >&2
fi

# Live comparison only when HelmCortex actually answers.
if timeout -k 1 2 test -d "${HELM}/FORGE/bin" 2>/dev/null; then
  l="$(mktemp)"
  # Same artefact filter as hx-capture. If these two ever disagree, hx-diff reports
  # permanent phantom drift for files capture is right to ignore.
  for d in "${SCAN_DIRS[@]}"; do
    find "${HELM}/${d}" -maxdepth 1 -type f -executable \
      ! -name '*.backup-*' ! -name '*.bak' ! -name '*.orig' ! -name '*.rej' \
      ! -name '*.save' ! -name '*.disabled' ! -name '*~' ! -name '.*' ! -name '#*' \
      -printf '%f\n' 2>/dev/null
  done | sort > "${l}"
  echo "live HelmCortex tools: $(wc -l < "${l}")"
  if diff -q "${m}" "${l}" >/dev/null; then
    echo "  manifest matches live HelmCortex"
  else
    comm -13 "${m}" "${l}" | sed 's/^/  NEW in HelmCortex (run hx-capture): /'
    comm -23 "${m}" "${l}" | sed 's/^/  gone from HelmCortex: /'
  fi
  rm -f "${l}"
else
  echo "live comparison skipped — HelmCortex unreachable"
fi
