#+TITLE: Fleet health ingest: forced-command receiver for pushed client-zone health documents
#+DESCRIPTION: fleet-health-ingest stores one client host's pushed, allowlisted health JSON for the fleet doctor; no login, no pull
#+AUTHOR: Mètsàtron — Sovereign Weaver
#+LANGUAGE: en
#+OPTIONS: toc:2

* Why this exists

Some hosts in the fleet are client zones: the machine belongs to someone else and the fleet holds no monitoring access into it (Honey is the first). Such a host pushes one allowlisted health document (schema =honey.health.v1=) to the doctor's host every morning, over a key whose forced command is =fleet-health-ingest=. The receiver reads stdin only, ignores =SSH_ORIGINAL_COMMAND=, and can write only the slot of the host pinned in the key line, so a client can't spoof another seat. The doctor reads the stored file; a missing or stale file makes that seat =UNKNOWN=. This is the push variant of the fleet's forced-command keys (=borg serve= for backups, =agent-peer receive --origin-host= for peer envelopes): the client decides exactly what leaves, and the fleet gets no new login on the client.

* What it stores

- =~/.local/state/fleet-health/<host>.json=: the latest accepted document, mode 600, written atomically.
- =~/.local/state/fleet-health/history/<host>-YYYY-MM-DD.json=: one per day of =generated_at=, newest 14 kept.
- =~/.local/state/fleet-health/ingest.log=: one line per attempt (OK or REJECT with a reason), never document content.

It refuses with exit 3 any input over 256 KB, and with exit 4 anything that is not a JSON object, has a schema other than =honey.health.v1= or a =schema_version= other than 1, a =host= other than the pinned one, unknown top-level keys, a =generated_at= without a timezone, in the future or older than the stored document (replay), an invalid =summary.verdict= or check status, or any string that looks like an IPv4 address or a home path (defence in depth: the client already allowlists its document). Exit 2 is usage, exit 5 a write failure.

* Doctor-host side: the key line

Per-host and private, so documented here rather than tangled (rule 21). One line per client in the doctor account's =~/.ssh/authorized_keys=:

#+BEGIN_SRC text
command="/usr/bin/python3 <home>/.local/bin/fleet-health-ingest --host beelink",from="<client tailnet address>",restrict ssh-ed25519 AAAA... <user>@<client> <client>-health-push
#+END_SRC

Name the interpreter and use an absolute path: a forced command runs without an interactive =PATH=. =restrict= disables PTY, agent, X11 and port forwarding, which a forced command alone does not. =from= pins the client's tailnet address. A new client host is added to =HOSTS= below (and its schema to =SCHEMAS=), never taken from the document.

* Client side

The client keeps a dedicated key (for Honey =~/.ssh/id_ed25519_honey_health=) and a host alias with =IdentitiesOnly yes=, =BatchMode yes= and a short =ConnectTimeout=, and runs =ssh -T <alias> < YYYY-MM-DD.json= after its own deterministic collector, with a timeout and one retry. A failed push only logs and never breaks the client's local report. The client's collector and push script belong to the client, not to DotCortex.

* The receiver

#+BEGIN_SRC python :tangle all/.local/bin/fleet-health-ingest :shebang "#!/usr/bin/env python3" :tangle-mode (identity #o755)
"""fleet-health-ingest: forced-command receiver for one client host's health JSON.

Runs as the forced command of a single restricted SSH key, for example:

  command="/usr/bin/python3 <home>/.local/bin/fleet-health-ingest --host beelink",from="<client tailnet address>",restrict ssh-ed25519 AAAA... <comment>

The host is pinned by the key's forced command, never by the document or by
SSH_ORIGINAL_COMMAND (which is ignored), so a client can only write its own slot.

It reads stdin (capped), checks that it is a JSON object of schema
honey.health.v1 for the pinned host, and atomically writes
~/.local/state/fleet-health/<host>.json plus a dated copy under history/
(newest 14 kept). It does nothing else. Exit codes: 0 stored, 2 usage,
3 too large, 4 invalid document, 5 write failure.
"""
import datetime
import fcntl
import hashlib
import json
import os
import re
import sys
import tempfile

MAX_BYTES = 256 * 1024
KEEP = 14
STATE = os.path.join(os.path.expanduser("~"), ".local", "state", "fleet-health")
SCHEMAS = {"honey.health.v1"}
HOSTS = {"beelink"}
TOP_KEYS = {"schema", "schema_version", "host", "generated_at", "checks", "summary",
            "cleared", "previous_run", "redactions", "collector"}
REQUIRED = {"schema", "schema_version", "host", "generated_at", "checks", "summary"}
STATUSES = {"ok", "warn", "crit", "unknown"}
VERDICTS = {"green", "amber", "red", "unknown"}
# Defence in depth: the client allowlists its document; refuse anything that still carries an address or a home path.
FORBIDDEN = re.compile(r"\b\d{1,3}(?:\.\d{1,3}){3}\b|/home/|/root/", re.I)


class Reject(Exception):
    def __init__(self, code, msg):
        super().__init__(msg)
        self.code = code


def log(line):
    try:
        with open(os.path.join(STATE, "ingest.log"), "a") as f:
            f.write(datetime.datetime.now().astimezone().isoformat(timespec="seconds") + " " + line + "\n")
    except OSError:
        pass


def strings(obj):
    if isinstance(obj, str):
        yield obj
    elif isinstance(obj, dict):
        for k, v in obj.items():
            yield str(k)
            yield from strings(v)
    elif isinstance(obj, list):
        for v in obj:
            yield from strings(v)


def reject_constant(name):
    raise ValueError("non-finite number " + name)


def validate(raw, host):
    try:
        doc = json.loads(raw.decode("utf-8"), parse_constant=reject_constant)
    except (UnicodeDecodeError, ValueError) as e:
        raise Reject(4, "not valid JSON: %s" % type(e).__name__)
    if not isinstance(doc, dict):
        raise Reject(4, "top level is not an object")
    missing = REQUIRED - doc.keys()
    if missing:
        raise Reject(4, "missing keys: " + ",".join(sorted(missing)))
    extra = doc.keys() - TOP_KEYS
    if extra:
        raise Reject(4, "unknown top-level keys: %d" % len(extra))
    if doc["schema"] not in SCHEMAS or doc["schema_version"] != 1:
        raise Reject(4, "wrong schema")
    if doc["host"] != host:
        raise Reject(4, "host does not match the key's pinned host")
    try:
        gen = datetime.datetime.fromisoformat(doc["generated_at"])
    except (TypeError, ValueError):
        raise Reject(4, "generated_at is not ISO 8601")
    if gen.tzinfo is None:
        raise Reject(4, "generated_at has no timezone")
    summary = doc["summary"]
    if not isinstance(summary, dict) or summary.get("verdict") not in VERDICTS:
        raise Reject(4, "summary.verdict missing or invalid")
    checks = doc["checks"]
    if not isinstance(checks, list) or not checks:
        raise Reject(4, "checks is not a non-empty list")
    for c in checks:
        if not isinstance(c, dict) or not isinstance(c.get("id"), str) or c.get("status") not in STATUSES:
            raise Reject(4, "a check lacks a string id or a valid status")
    if any(FORBIDDEN.search(s) for s in strings(doc)):
        raise Reject(4, "document carries an address or home path")
    return gen


def write_atomic(path, data):
    fd, tmp = tempfile.mkstemp(dir=os.path.dirname(path), prefix=".ingest-")
    try:
        with os.fdopen(fd, "wb") as f:
            f.write(data)
            f.flush()
            os.fsync(f.fileno())
        os.chmod(tmp, 0o600)
        os.replace(tmp, path)
    except BaseException:
        try:
            os.unlink(tmp)
        except OSError:
            pass
        raise


def main(argv):
    if len(argv) != 3 or argv[1] != "--host" or argv[2] not in HOSTS:
        print("usage: fleet-health-ingest --host <pinned host>", file=sys.stderr)
        return 2
    host = argv[2]
    os.umask(0o077)
    os.makedirs(os.path.join(STATE, "history"), mode=0o700, exist_ok=True)
    raw = sys.stdin.buffer.read(MAX_BYTES + 1)
    try:
        if len(raw) > MAX_BYTES:
            raise Reject(3, "input exceeds %d bytes" % MAX_BYTES)
        gen = validate(raw, host)
        with open(os.path.join(STATE, ".lock"), "w") as lock:
            fcntl.flock(lock, fcntl.LOCK_EX)
            if gen > datetime.datetime.now().astimezone() + datetime.timedelta(hours=1):
                raise Reject(4, "generated_at is in the future")
            try:
                with open(os.path.join(STATE, host + ".json"), "rb") as f:
                    current = datetime.datetime.fromisoformat(json.load(f)["generated_at"])
            except (OSError, ValueError, KeyError, TypeError):
                current = None
            if current is not None and gen < current:
                raise Reject(4, "older than the stored document (replay)")
            try:
                write_atomic(os.path.join(STATE, host + ".json"), raw)
                write_atomic(os.path.join(STATE, "history", "%s-%s.json" % (host, gen.date().isoformat())), raw)
            except OSError as e:
                raise Reject(5, "write failed: %s" % type(e).__name__)
            hist = sorted(n for n in os.listdir(os.path.join(STATE, "history"))
                          if re.fullmatch(re.escape(host) + r"-\d{4}-\d{2}-\d{2}\.json", n))
            for old in hist[:-KEEP]:
                os.unlink(os.path.join(STATE, "history", old))
    except Reject as e:
        log("REJECT host=%s bytes=%d code=%d %s" % (host, len(raw), e.code, e))
        print("rejected: %s" % e, file=sys.stderr)
        return e.code
    digest = hashlib.sha256(raw).hexdigest()[:12]
    log("OK host=%s bytes=%d generated_at=%s sha256=%s" % (host, len(raw), gen.isoformat(), digest))
    print("stored %s %d bytes sha256:%s" % (host, len(raw), digest))
    return 0


if __name__ == "__main__":
    sys.exit(main(sys.argv))
#+END_SRC

* Deterministic tests

=fleet-health-ingest-test= runs the receiver against a scratch =HOME= with synthetic documents (the real state directory is never touched) and checks: a valid document is stored with mode 600, an unpinned host is usage, and a wrong host, wrong schema, unknown key, bad status, address, home path, non-JSON, empty input, oversized input, replay, future and timezone-less document are each refused; history keeps 14; the log carries reasons but no content. Set =FLEET_HEALTH_INGEST= to test another copy.

#+BEGIN_SRC bash :tangle all/.local/bin/fleet-health-ingest-test :shebang "#!/usr/bin/env bash" :tangle-mode (identity #o755)
set -euo pipefail
# Deterministic tests for fleet-health-ingest against a scratch HOME; the real state dir is never touched.
here="$(cd "$(dirname "$0")" && pwd)"
ingest="${FLEET_HEALTH_INGEST:-$here/fleet-health-ingest}"
scratch="$(mktemp -d)"
trap 'rm -rf "$scratch"' EXIT
state="$scratch/.local/state/fleet-health"
pass=0 fail=0

doc() { # doc <generated_at> [python mutation on d]
  python3 - "$1" "${2:-}" <<'PY'
import json, sys
d = {"schema": "honey.health.v1", "schema_version": 1, "host": "beelink", "generated_at": sys.argv[1],
     "summary": {"verdict": "green", "counts": {"ok": 1, "warn": 0, "crit": 0, "unknown": 0}},
     "checks": [{"id": "disk.root", "group": "disk", "status": "ok", "value": 40, "threshold": "warn>85",
                 "detail": None, "scope": "host"}],
     "cleared": [], "previous_run": None, "redactions": 0, "collector": {"name": "test", "duration_ms": 1}}
exec(sys.argv[2])
print(json.dumps(d))
PY
}
expect() { # expect <name> <rc> <stdin-file> [args...]
  local name="$1" want="$2" input="$3"; shift 3
  local got=0
  HOME="$scratch" "$ingest" "$@" < "$input" > /dev/null 2>&1 || got=$?
  if [ "$got" -eq "$want" ]; then pass=$((pass + 1)); echo "ok   $name"; else fail=$((fail + 1)); echo "FAIL $name (rc $got, want $want)"; fi
}

now="$(date +%Y-%m-%dT%H:%M:%S%z | sed -E 's/([0-9]{2})([0-9]{2})$/\1:\2/')"
doc "$now" > "$scratch/good.json"
expect "stores a valid document" 0 "$scratch/good.json" --host beelink
[ "$(stat -c %a "$state/beelink.json")" = 600 ] && { pass=$((pass + 1)); echo "ok   mode 600"; } || { fail=$((fail + 1)); echo "FAIL mode"; }
expect "unknown pinned host is usage" 2 "$scratch/good.json" --host nosuchhost
doc "$now" 'd["host"] = "t480s"' > "$scratch/bad-host.json";      expect "host must match the key" 4 "$scratch/bad-host.json" --host beelink
doc "$now" 'd["schema"] = "evil.v1"' > "$scratch/bad-schema.json"; expect "schema must match" 4 "$scratch/bad-schema.json" --host beelink
doc "$now" 'd["extra"] = 1' > "$scratch/extra.json";              expect "unknown top-level key" 4 "$scratch/extra.json" --host beelink
doc "$now" 'd["checks"][0]["status"] = "fine"' > "$scratch/st.json"; expect "invalid check status" 4 "$scratch/st.json" --host beelink
addr="$(printf '%d.%d.%d.%d' 10 0 0 1)"
doc "$now" "d['checks'][0]['detail'] = 'via $addr'" > "$scratch/addr.json"; expect "refuses an address" 4 "$scratch/addr.json" --host beelink
doc "$now" 'd["checks"][0]["detail"] = "/home/someone"' > "$scratch/home.json"; expect "refuses a home path" 4 "$scratch/home.json" --host beelink
echo 'not json' > "$scratch/garbage";                             expect "refuses non-JSON" 4 "$scratch/garbage" --host beelink
: > "$scratch/empty";                                             expect "refuses empty input" 4 "$scratch/empty" --host beelink
head -c 300000 /dev/zero | tr '\0' ' ' > "$scratch/big";          expect "refuses oversized input" 3 "$scratch/big" --host beelink
doc "2020-01-01T07:25:00+10:00" > "$scratch/old.json";            expect "refuses a replayed older document" 4 "$scratch/old.json" --host beelink
doc "2999-01-01T07:25:00+10:00" > "$scratch/future.json";         expect "refuses a future document" 4 "$scratch/future.json" --host beelink
doc "2026-09-25T07:25:00" > "$scratch/naive.json";                expect "refuses a naive timestamp" 4 "$scratch/naive.json" --host beelink
rm -f "$state/beelink.json" "$state"/history/*.json
for day in $(seq -w 1 16); do
  doc "2026-01-${day}T07:25:00+10:00" > "$scratch/d.json"
  HOME="$scratch" "$ingest" --host beelink < "$scratch/d.json" > /dev/null
done
n="$(ls "$state/history" | grep -c '^beelink-2026-01-')"
[ "$n" -eq 14 ] && [ ! -e "$state/history/beelink-2026-01-01.json" ] && { pass=$((pass + 1)); echo "ok   history keeps 14"; } || { fail=$((fail + 1)); echo "FAIL history ($n kept)"; }
grep -q 'REJECT' "$state/ingest.log" && ! grep -q "$addr" "$state/ingest.log" && { pass=$((pass + 1)); echo "ok   log has reasons, no content"; } || { fail=$((fail + 1)); echo "FAIL log"; }
echo "fleet-health-ingest-test: $pass passed, $fail failed"
[ "$fail" -eq 0 ]
#+END_SRC
