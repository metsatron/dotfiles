* Sanctuary: sanctuary-godzilla-xs — SX-Window XLibre/X11 Habitat

An XFCE-based XLibre/X11 habitat for a living continuation of Sharp X68000 SX-Window and Ko-Window visual culture. It uses XFCE as a flexible, manually tuneable chassis, beginning from a Windows-3.1-adjacent visual baseline and evolving toward a bespoke Japanese early-1990s workstation grammar. It is intended to host native Linux applications alongside future machine-islands for X68000, PC-98, FM Towns, DOSBox-X, Wine, ScummVM, and related God-PC-era environments.

Stack: Guix base + XFCE desktop stack (no source build required; packages come from host =/gnu/store=).
Guix profiles sourced: =desktop-common= + =sanctuary-godzilla-xs= (xfce4-session, xfwm4, xfconf, panel, settings, desktop, appfinder, thunar, xfce4-terminal).

Host virtual desktop: current host desktop. Xephyr display: =:94=.
Agent doorway: =distrobox enter sanctuary-godzilla-xs -- <cmd>=
Launch: =sanctuary-godzilla-xs-launch=
Capture: =sanctuary-godzilla-xs-capture= (dry-run by default; =--apply= to write to DotCortex source)

Guest home: =$XDG_DATA_HOME/dotcortex/guests/sanctuary-godzilla-xs/home/=

** Visual Grammar and Baseline

The initial payload is stock XFCE, started cleanly inside the Xephyr display. The intended visual grammar — woven cross-hatched grey root-desktop texture, narrow black keylines, restrained bevels, horizontal segmented titlebars, compact controls, a fixed vertical left device/tool rail, grayscale bitmap-style icons with selective Sharp/X68000 green accents, and Japanese and English labels living together — is built by the user manually through XFCE's own configuration tools. The sanctuary is designed for manual exploration and iteration, not automated theming.

The initial XFCE session starts from its own defaults. A Windows-3.1-adjacent XFWM4 theme provides the starting geometry; the user tunes from there toward the SX/Ko grammar.

** Declarative desktop state workflow

The live guest home remains writable so XFCE can be shaped normally through
its own settings tools.  Durable state flows back through a reviewable Org
snapshot instead of allowing =xfconfd= to write directly into tangled output:

#+BEGIN_EXAMPLE
live guest home -> sanctuary-godzilla-xs-capture -> sanctuary-godzilla-xs-state.org
                -> tangle -> sanctuary-godzilla-xs-config-apply -> guest home
#+END_EXAMPLE

=sanctuary-godzilla-xs-capture= is a dry-run by default.  It inventories every stable
XFCE channel, the complete panel launcher tree, desktop accelerator/icon-layout
state, and every image below the guest =Pictures/= directory referenced by that
state.  =--apply= promotes the reviewed snapshot into
=sanctuary-godzilla-xs-state.org=, tangles it, backs up the mutable guest configuration,
and applies the declared result back to the guest home.

The capture normalizes Guix store hashes out of panel launcher commands, rejects
secret-like material and network addresses, and excludes only runtime or
hardware state: session/window restore, notification history, display probing,
power management, and transient keyboard-device channels.

Future manual changes follow one loop:

1. Shape the running desktop through XFCE.
2. Close =sanctuary-godzilla-xs= so all writers have flushed and stopped.
3. Run =sanctuary-godzilla-xs-capture= and review the Org diff.
4. Run =sanctuary-godzilla-xs-capture --apply=.
5. Review =git diff -- sanctuary-godzilla-xs-state.org linux/.config/sanctuary-godzilla-xs/=.
6. Commit the canonical Org source and its tangled output with =/commit=.

The launcher runs =sanctuary-godzilla-xs-config-apply= before XFCE.  It never overwrites
uncaptured drift: the live desktop is preserved and launch continues with a
promotion reminder.  =--force= is an explicit restore operation and always
writes a timestamped backup first.

** Future Habitat Content

Once the visual grammar is stable, sanctuary-godzilla-xs is intended to host machine-islands for:

- X68000 (Sharp MZ/X68k emulation)
- PC-98 (Neko Project II / np21w)
- FM Towns (Tsugaru)
- DOSBox-X (MS-DOS / Windows 3.x / 9x)

These are future content, not a requirement for the initial declaration.

** Godzilla XS-86000 library, state, and menu foundation

Godzilla XS-86000 is the visible identity of =sanctuary-godzilla-xs=.  The technical
identifier remains =sanctuary-godzilla-xs= for containers, guest homes, manifests,
helpers, and Xephyr display wiring.

Shared media lives in =~/RetroPie= and is treated as a durable media library,
not a RetroPie OS installation.  Emulator configuration, Wine prefixes, saves,
caches, shader cache, Lutris state, and generated thumbnails stay in
=XDG_DATA_HOME/godzilla-xs= and =XDG_CONFIG_HOME/godzilla-xs= inside the
sanctuary guest home.

Bus policy:
- X68 BUS: XEiJ primary; XM6 under Wine fallback only.
- DRIVE A: PC-98: NP2Kai primary; T98-Next under Wine fallback only.
- DRIVE B: PC-88: QUASI88 primary; MAME fallback only, not the front end.
- FM TOWNS: Tsugaru primary; ScummVM supplement; UNZ under Wine fallback only.
- ARCADE BUS: MAME only.  Neo Geo is SNK Neo Geo MVS arcade hardware.
- PC COMPATIBILITY BOARD: Wine/Lutris Japanese and period PC software.

No Saturn bus, no Nintendo/Super Famicom bus, no FBNeo/FinalBurn Alpha arcade
runtime, and no private/adult quarantine category.

#+BEGIN_SRC bash :tangle linux/.local/bin/godzilla-xs-wine :shebang "#!/bin/sh" :mkdirp yes
# Run Wine against a named Godzilla XS-86000 sanctuary-local prefix.
set -eu

if [ "$#" -lt 2 ]; then
  echo "Usage: godzilla-xs-wine <prefix-name> <wine-args...>" >&2
  exit 2
fi

prefix="$1"
shift

case "${prefix}" in
  xm6-typeg|t98-next|unz|sega-pc-9x|capcom-pc-9x|konami-pc-9x|jpwin9x|mugen|romlab-win32|mgs2-xp) ;;
  *) echo "godzilla-xs-wine: unknown prefix: ${prefix}" >&2; exit 2 ;;
esac

export WINEARCH=win32
export WINEPREFIX="${XDG_DATA_HOME:-${HOME}/.local/share}/godzilla-xs/wine/${prefix}"
exec wine "$@"
#+END_SRC

#+BEGIN_SRC bash :tangle linux/.local/bin/godzilla-xs-winetricks :shebang "#!/bin/sh" :mkdirp yes
# Apply one approved winetricks verb to one named Godzilla XS-86000 prefix.
set -eu

if [ "$#" -lt 3 ]; then
  echo "Usage: godzilla-xs-winetricks <prefix-name> <verb> <reason...>" >&2
  exit 2
fi

prefix="$1"
verb="$2"
shift 2
reason="$*"

case "${prefix}" in
  xm6-typeg|t98-next|unz|sega-pc-9x|capcom-pc-9x|konami-pc-9x|jpwin9x|mugen|romlab-win32|mgs2-xp) ;;
  *) echo "godzilla-xs-winetricks: unknown prefix: ${prefix}" >&2; exit 2 ;;
esac

case "${verb}" in
  corefonts|directplay|directmusic|dinput|dsound|quartz|mfc42|mfc42u|vcrun6|vcrun2005|d3dx9) ;;
  *) echo "godzilla-xs-winetricks: verb not allow-listed: ${verb}" >&2; exit 2 ;;
esac

data_home="${XDG_DATA_HOME:-${HOME}/.local/share}/godzilla-xs"
log_dir="${data_home}/logs/winetricks/${prefix}"
mkdir -p "${log_dir}"
manifest="${data_home}/wine/${prefix}/winetricks.tsv"
timestamp="$(date -Iseconds)"
printf '%s\t%s\t%s\n' "${timestamp}" "${verb}" "${reason}" >> "${manifest}"

export WINEARCH=win32
export WINEPREFIX="${data_home}/wine/${prefix}"
winetricks "${verb}" 2>&1 | tee "${log_dir}/${timestamp}-${verb}.log"
#+END_SRC

#+BEGIN_SRC bash :tangle linux/.local/bin/godzilla-xs-wine-prefix-init :shebang "#!/bin/sh" :mkdirp yes
# Initialize Godzilla XS-86000 Wine prefixes with recorded Windows versions.
set -eu

data_home="${XDG_DATA_HOME:-${HOME}/.local/share}/godzilla-xs"
log_root="${data_home}/logs/wine-prefix-init"
mkdir -p "${log_root}"

init_prefix() {
  prefix="$1"
  winver="$2"
  shift 2
  prefix_dir="${data_home}/wine/${prefix}"
  marker="${prefix_dir}/.godzilla-xs-initialized"
  mkdir -p "${prefix_dir}"
  if [ -f "${marker}" ]; then
    echo "godzilla-xs: prefix already initialized: ${prefix}"
    return 0
  fi
  echo "godzilla-xs: initializing ${prefix} as ${winver}"
  export WINEARCH=win32
  export WINEPREFIX="${prefix_dir}"
  WINEDEBUG=-all wineboot --init 2>&1 | tee "${log_root}/${prefix}-wineboot.log"
  WINEDEBUG=-all winecfg -v "${winver}" 2>&1 | tee "${log_root}/${prefix}-winecfg.log"
  for verb in "$@"; do
    godzilla-xs-winetricks "${prefix}" "${verb}" "baseline ${prefix} compatibility"
  done
  date -Iseconds > "${marker}"
}

game_verbs="corefonts directplay directmusic dinput dsound"

init_prefix xm6-typeg win98 ${game_verbs}
init_prefix t98-next win98 ${game_verbs}
init_prefix unz win98 ${game_verbs}
init_prefix sega-pc-9x win98 ${game_verbs}
init_prefix capcom-pc-9x win98 ${game_verbs}
init_prefix konami-pc-9x win98 ${game_verbs}
init_prefix jpwin9x win98 ${game_verbs}
init_prefix mugen win98 ${game_verbs}
init_prefix romlab-win32 win98
init_prefix mgs2-xp winxp ${game_verbs} d3dx9
#+END_SRC

** Godzilla XS shell identity — Human68k A:\ prompt

The Godzilla XS sanctuary imports Redstone 9X's proven dual-shell grammar —
drive-letter path mapping, Bash prompt-escape protection, login-shell loading,
global Zsh configuration chaining, and one banner per terminal — then skins it
with the white/grey/red device-driver palette and wording of the sanctuary's
Human68k Fastfetch output.

#+BEGIN_SRC bash :tangle linux/.config/sanctuary-godzilla-xs/shell/bashrc :comments no :mkdirp yes
# Godzilla XS-86000 sanctuary bash rc — Human68k drive-letter shell identity.
# Shared sanctuary grammar: symlinked to ~/.bashrc by sanctuary-godzilla-xs-launch.
# Interactive shells only.
case $- in *i*) ;; *) return ;; esac

# Map the Unix path to a Human68k drive path: $HOME collapses to A:\ , anything
# above $HOME shows as a C:\ path, forward slashes become backslashes. The final
# result is doubled ('\' -> '\\') because it lands in PS1, which bash re-expands as
# prompt escapes — an un-doubled '\h' '\s' '\d' '\w' '\u' would render as the
# hostname/shell/date/cwd/user. (Verified via ${PS1@P} rendering, 2026-07-15.)
_godzilla_xs_dospath() {
  local p="${PWD}" rel dos
  if [ "${p}" = "${HOME}" ]; then
    dos='A:\'
  elif [ "${p#${HOME}/}" != "${p}" ]; then
    rel="${p#${HOME}/}"; dos="A:\\${rel//\//\\}"
  else
    rel="${p#/}"; dos="C:\\${rel//\//\\}"
  fi
  printf '%s' "${dos//\\/\\\\}"
}

# Match the Human68k Fastfetch palette: dim device label, bright path, red
# command marker.  \[...\] keeps Bash's line editor aware that ANSI bytes do not
# consume columns.
PROMPT_COMMAND='PS1="\[\033[90m\]BASH \[\033[97m\]$(_godzilla_xs_dospath)\[\033[91m\]>\[\033[0m\] "'

_godzilla_xs_banner() {
  printf '\033[97mGODZILLA XS-86000 SYSTEM DRIVER version 0.86\033[0m\n'
  printf '\033[90mSHARP / NEC / FUJITSU / ARCADE COMPATIBILITY BUS\033[0m\n'
  printf '\033[97mASK68K / Human68k shell channel  \033[91mREADY\033[0m\n\n'
}

# First interactive shell in each terminal: open at HOME, print the boot banner.
if [ -z "${GODZILLA_XS_SHELL_INIT:-}" ]; then
  export GODZILLA_XS_SHELL_INIT=1
  cd "${HOME}" 2>/dev/null || true
  _godzilla_xs_banner
fi

** Declared font projection

The SX desktop names private/vendor font families that are provisioned into the
host's merged font corpus.  Some of those host entries are symlinks into mounted
HelmCortex storage, and those backing mounts are intentionally not propagated
into the container.  Resolve and checksum the required families on the host,
then materialize only those declared payloads into the persistent guest home.
The public repository owns the contract, not the private font binaries.

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-godzilla-xs-fonts-apply :shebang "#!/usr/bin/env bash" :mkdirp yes
# Materialize the exact fonts declared by sanctuary-godzilla-xs into its persistent home.
set -euo pipefail

GUESTS_DIR="${XDG_DATA_HOME:-$HOME/.local/share}/dotcortex/guests"
GUEST_HOME="${GUESTS_DIR}/sanctuary-godzilla-xs/home"
FONT_ROOT="${GUEST_HOME}/.local/share/fonts"
HOST_FONT_ROOT="${HOME}/.local/share/fonts"
HOST_LINK_BACKUP="${GUEST_HOME}/.local/share/fonts.host-link-pre-declarative"

FC_MATCH="$(command -v fc-match 2>/dev/null || true)"
if [[ -z "${FC_MATCH}" ]]; then
  echo "sanctuary-godzilla-xs-fonts-apply: fc-match is unavailable on the host" >&2
  exit 1
fi

# vm-homes-init historically made the whole guest font root one host symlink.
# Preserve that link once, replace it with a real persistent directory, and
# retain the merged host view beneath it for directly accessible host fonts.
if [[ -L "${FONT_ROOT}" ]]; then
  if [[ ! -e "${HOST_LINK_BACKUP}" && ! -L "${HOST_LINK_BACKUP}" ]]; then
    mv -T "${FONT_ROOT}" "${HOST_LINK_BACKUP}"
  else
    unlink "${FONT_ROOT}"
  fi
fi
if [[ -e "${FONT_ROOT}" && ! -d "${FONT_ROOT}" ]]; then
  echo "sanctuary-godzilla-xs-fonts-apply: refusing to replace non-directory ${FONT_ROOT}" >&2
  exit 1
fi

DECLARED_ROOT="${FONT_ROOT}/declared"
mkdir -p "${DECLARED_ROOT}"
ln -sfnT "${HOST_FONT_ROOT}" "${FONT_ROOT}/host"

# FAMILY|SHA256.  A family mismatch catches fontconfig fallback; a checksum
# mismatch catches silent replacement of the private payload.
font_specs=(
  "PxPlus IBM VGA 9x14|03c0a9a7d169fdac7c4f2c1a4aeb2a9c6f19175325d250e2765c6365e6eb588b"
  "D2CodingLigature Nerd Font|aacf7394f52574abcc126221543dbe7c6afe319ad300688490ca94b92d9856cf"
)

for spec in "${font_specs[@]}"; do
  family="${spec%%|*}"
  expected_sha="${spec##*|}"
  resolved_family="$(${FC_MATCH} -f '%{family[0]}' "${family}")"
  source_file="$(${FC_MATCH} -f '%{file}' "${family}")"

  if [[ "${resolved_family}" != "${family}" || ! -f "${source_file}" ]]; then
    echo "sanctuary-godzilla-xs-fonts-apply: required host font unavailable: ${family}" >&2
    exit 1
  fi
  actual_sha="$(sha256sum "${source_file}" | awk '{print $1}')"
  if [[ "${actual_sha}" != "${expected_sha}" ]]; then
    echo "sanctuary-godzilla-xs-fonts-apply: checksum mismatch for ${family}" >&2
    echo "  expected: ${expected_sha}" >&2
    echo "  actual:   ${actual_sha}" >&2
    exit 1
  fi

  destination="${DECLARED_ROOT}/$(basename "${source_file}")"
  if [[ ! -f "${destination}" ]] || ! cmp -s "${source_file}" "${destination}"; then
    install -m0644 "${source_file}" "${destination}.new"
    mv -f "${destination}.new" "${destination}"
    echo "sanctuary-godzilla-xs-fonts-apply: projected ${family}"
  fi
done

# Build the same user cache XFCE consumes, without requiring a running
# container.  The sanctuary profile pins the fontconfig implementation; env -i
# prevents host fontconfig overrides from leaking into the guest cache.
FONTCONFIG_BIN="${HOME}/.guix-extra-profiles/sanctuary-godzilla-xs/sanctuary-godzilla-xs/bin"
if [[ ! -x "${FONTCONFIG_BIN}/fc-cache" || ! -x "${FONTCONFIG_BIN}/fc-match" ]]; then
  echo "sanctuary-godzilla-xs-fonts-apply: sanctuary fontconfig profile is unavailable" >&2
  exit 1
fi
guest_font_env=(
  "HOME=${GUEST_HOME}"
  "XDG_DATA_HOME=${GUEST_HOME}/.local/share"
  "XDG_CACHE_HOME=${GUEST_HOME}/.cache"
  "PATH=${FONTCONFIG_BIN}:/usr/bin:/bin"
)
env -i "${guest_font_env[@]}" "${FONTCONFIG_BIN}/fc-cache" "${FONT_ROOT}" >/dev/null

for spec in "${font_specs[@]}"; do
  family="${spec%%|*}"
  guest_family="$(env -i "${guest_font_env[@]}" "${FONTCONFIG_BIN}/fc-match" -f '%{family[0]}' "${family}")"
  guest_file="$(env -i "${guest_font_env[@]}" "${FONTCONFIG_BIN}/fc-match" -f '%{file}' "${family}")"
  if [[ "${guest_family}" != "${family}" || "${guest_file}" != "${DECLARED_ROOT}/"* ]]; then
    echo "sanctuary-godzilla-xs-fonts-apply: guest verification failed for ${family}" >&2
    echo "  resolved family: ${guest_family}" >&2
    echo "  resolved file:   ${guest_file}" >&2
    exit 1
  fi
done
echo "sanctuary-godzilla-xs-fonts-apply: declared font payload verified"
#+END_SRC

    records+=("asset"$'\t'"${rel}"$'\t'"${asset}")
  fi
done

mapfile -t records < <(printf '%s\n' "${records[@]}" | LC_ALL=C sort -t $'\t' -k2,2)

tmp_dir="$(mktemp -d)"
trap 'rm -rf -- "${tmp_dir}"' EXIT
candidate="${tmp_dir}/sanctuary-godzilla-xs-state.org"
new_manifest="${tmp_dir}/state.manifest"

normalize_text() {
  local rel="$1" src="$2"
  case "${rel}" in
    desktop/icons.screen0.yaml)
      # xfdesktop rewrites this mapping in arbitrary key order.  Canonicalize
      # only the icon-entry order; preserve monitor identity and every value.
      perl -0777 -e '
        my $text = do { local $/; <> };
        $text =~ /\A(.*?^  icons:\n)(.*)\z/ms or die "missing icons map\n";
        my ($head, $body) = ($1, $2);
        my @blocks = ($body =~ /(^    "[^"]+":\n(?:^      .*\n?)*)/mg);
        die "unparsed icons map\n" unless join("", @blocks) eq $body;
        print $head, sort @blocks;
      ' "${src}"
      ;;
    panel/*.desktop)
      sed -E \
        -e 's#^(Exec=)/gnu/store/[^/]+/bin/#\1#' \
        -e '/^X-XFCE-Source=file:\/\/\/gnu\/store\//d' \
        "${src}"
      ;;
    *) cat "${src}" ;;
  esac
}

validate_text() {
  local rel="$1" src="$2" mime
  mime="$(file -b --mime-type "${src}")"
  case "${mime}" in text/*|application/xml|application/x-desktop|application/x-yaml|inode/x-empty) ;; *)
    echo "sanctuary-godzilla-xs-capture: refusing non-text config ${rel} (${mime})" >&2; exit 1 ;;
  esac
  if rg -n '^#\+END_SRC[[:space:]]*$' "${src}" >/dev/null; then
    echo "sanctuary-godzilla-xs-capture: Org terminator found in ${rel}" >&2; exit 1
  fi
  if rg -ni '(api[_-]?key|access[_-]?token|bearer[[:space:]]+[A-Za-z0-9]|BEGIN [A-Z ]*PRIVATE KEY)' "${src}" >/dev/null; then
    echo "sanctuary-godzilla-xs-capture: secret-like content found in ${rel}" >&2; exit 1
  fi
  if rg -n '(^|[^0-9])([0-9]{1,3}\.){3}[0-9]{1,3}([^0-9]|$)' "${src}" >/dev/null; then
    echo "sanctuary-godzilla-xs-capture: network address found in ${rel}" >&2; exit 1
  fi
}

org_lang() {
  case "$1" in *.xml) echo xml ;; *) echo conf ;; esac
}

{
  sed 's/^|//' <<'EOF'
|#+TITLE: sanctuary-godzilla-xs — Captured XFCE Desktop State
|#+DESCRIPTION: Machine-generated declarative snapshot of the Godzilla XS-86000 XFCE desktop
|#+PROPERTY: header-args :mkdirp yes :results silent
|
|* Captured desktop state
|
|This file is generated by =sanctuary-godzilla-xs-capture --apply=.  Shape the desktop
|inside =sanctuary-godzilla-xs=, close the sanctuary, review =sanctuary-godzilla-xs-capture=, and
|then promote the live state into this canonical Org source.  Do not edit the
|tangled files under =linux/.config/sanctuary-godzilla-xs/= directly.
|
|** State manifest
|
EOF

  printf '%s\n' '#+BEGIN_SRC text :tangle linux/.config/sanctuary-godzilla-xs/state.manifest :comments no :mkdirp yes'

  for record in "${records[@]}"; do
    IFS=$'\t' read -r kind rel src <<< "${record}"
    if [[ "${kind}" == text ]]; then
      printf 'text\t%s\t%s\n' "${rel}" "${rel}"
    else
      printf 'asset\t%s\tassets-base64/%s.b64\n' "${rel}" "${rel}"
    fi
  done

  printf '%s\n\n' '#+END_SRC'

  for record in "${records[@]}"; do
    IFS=$'\t' read -r kind rel src <<< "${record}"
    printf '** =%s=\n\n' "${rel}"
    if [[ "${kind}" == text ]]; then
      normalized="${tmp_dir}/normalized"
      normalize_text "${rel}" "${src}" > "${normalized}"
      validate_text "${rel}" "${normalized}"
      printf '#+BEGIN_SRC %s :tangle linux/.config/sanctuary-godzilla-xs/%s :comments no :mkdirp yes\n' "$(org_lang "${rel}")" "${rel}"
      cat "${normalized}"
      [[ "$(tail -c 1 "${normalized}" | od -An -t x1 | tr -d ' ')" == 0a ]] || printf '\n'
    else
      printf '#+BEGIN_SRC text :tangle linux/.config/sanctuary-godzilla-xs/assets-base64/%s.b64 :comments no :mkdirp yes\n' "${rel}"
      base64 -w 76 "${src}"
    fi
    printf '#+END_SRC\n\n'
  done
} > "${candidate}"

# The block loop separates entries with a blank line; remove only the final
# separator so the generated Org source ends with exactly one newline.
truncate -s -1 "${candidate}"

awk '
  /^#\+BEGIN_SRC text :tangle linux\/\.config\/sanctuary-godzilla-xs\/state\.manifest / { in_manifest=1; next }
  in_manifest && /^#\+END_SRC/ { exit }
  in_manifest { print }
' "${candidate}" > "${new_manifest}"

set +e
if [[ -f "${STATE_ORG}" ]]; then
  diff -u --label a/sanctuary-godzilla-xs-state.org --label b/sanctuary-godzilla-xs-state.org "${STATE_ORG}" "${candidate}"
  diff_status=$?
else
  diff -u --label /dev/null --label b/sanctuary-godzilla-xs-state.org /dev/null "${candidate}"
  diff_status=$?
fi
set -e

if (( diff_status == 0 )); then
  echo "sanctuary-godzilla-xs-capture: live desktop matches canonical state"
  exit 0
elif (( diff_status != 1 )); then
  echo "sanctuary-godzilla-xs-capture: diff failed" >&2
  exit "${diff_status}"
elif (( APPLY == 0 )); then
  echo "sanctuary-godzilla-xs-capture: live desktop differs; review above, then run --apply"
  exit 1
fi

if sx_session_running; then
  echo "sanctuary-godzilla-xs-capture: XFCE is still running on :94" >&2
  echo "  Close sanctuary-godzilla-xs before promoting its state." >&2
  exit 1
fi

while IFS= read -r dirty; do
  case "${dirty}" in
    sanctuary-godzilla-xs.org|sanctuary-godzilla-xs-state.org|linux/.config/sanctuary-godzilla-xs/*|linux/.local/bin/sanctuary-godzilla-xs-*) ;;
    *) echo "sanctuary-godzilla-xs-capture: unrelated unstaged path blocks apply: ${dirty}" >&2; exit 1 ;;
  esac
done < <(git -C "${REPO}" diff --name-only)

mkdir -p "${BACKUP_ROOT}"
timestamp="$(date +%Y%m%d-%H%M%S)"
if [[ -f "${STATE_ORG}" ]]; then
  cp -a "${STATE_ORG}" "${BACKUP_ROOT}/sanctuary-godzilla-xs-state.org.backup-${timestamp}"
  if ! git -C "${REPO}" diff --quiet -- sanctuary-godzilla-xs-state.org; then
    git -C "${REPO}" add -- sanctuary-godzilla-xs-state.org
  fi
fi

old_manifest="${tmp_dir}/old.manifest"
[[ -f "${DECLARED}/state.manifest" ]] && cp -a "${DECLARED}/state.manifest" "${old_manifest}"
install -m0644 "${candidate}" "${STATE_ORG}.new"
mv -f "${STATE_ORG}.new" "${STATE_ORG}"
cmp -s "${candidate}" "${STATE_ORG}" || { echo "sanctuary-godzilla-xs-capture: source verification failed" >&2; exit 1; }

(cd "${REPO}" && "${REPO}/all/.local/bin/tangle-one" sanctuary-godzilla-xs-state.org)

if [[ -f "${old_manifest}" ]]; then
  awk -F '\t' '$1 == "text" {print $3} $1 == "asset" {print $3}' "${old_manifest}" | LC_ALL=C sort > "${tmp_dir}/old.outputs"
  awk -F '\t' '$1 == "text" {print $3} $1 == "asset" {print $3}' "${new_manifest}" | LC_ALL=C sort > "${tmp_dir}/new.outputs"
  while IFS= read -r stale; do
    case "${stale}" in xfconf/*|panel/*|desktop/*|assets-base64/*) rm -f -- "${DECLARED}/${stale}" ;; esac
  done < <(comm -23 "${tmp_dir}/old.outputs" "${tmp_dir}/new.outputs")
fi

"${REPO}/linux/.local/bin/sanctuary-godzilla-xs-config-apply" --force

echo "sanctuary-godzilla-xs-capture: canonical desktop state updated"
echo "  source backup: ${BACKUP_ROOT}/sanctuary-godzilla-xs-state.org.backup-${timestamp}"
echo "  review: git diff -- sanctuary-godzilla-xs-state.org linux/.config/sanctuary-godzilla-xs/"

** sanctuary-godzilla-xs wallpaper

Set the sanctuary-godzilla-xs XFCE wallpaper directly via xfconf, bypassing the broken
XFCE 4.20 folder-picker UI (\"Unable to load images from folder '(null)' — Operation was cancelled\").

Usage: =sanctuary-godzilla-xs-wallpaper /path/to/image.png=

Requirements: sanctuary-godzilla-xs container must be running with an XFCE session;
Xephyr display =:94= must be up; xfconf-query in PATH.

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-godzilla-xs-wallpaper :shebang "#!/usr/bin/env bash" :mkdirp yes
# Apply the given PNG as sanctuary-godzilla-xs (:94) desktop wallpaper.
# Usage: sanctuary-godzilla-xs-wallpaper /absolute/or/relative/path.png
set -euo pipefail

DISPLAY=":94"
GUESTS_DIR="${XDG_DATA_HOME:-$HOME/.local/share}/dotcortex/guests"
GUEST_HOME="${GUESTS_DIR}/sanctuary-godzilla-xs/home"
PROFILE_BIN="${HOME}/.guix-extra-profiles/sanctuary-godzilla-xs/sanctuary-godzilla-xs/bin"
XFCONF="${PROFILE_BIN}/xfconf-query"

usage() {
  echo "Usage: sanctuary-godzilla-xs-wallpaper <image-path>" >&2
  echo "  Applies the wallpaper through xfconf on the running sanctuary-godzilla-xs XFCE session." >&2
  echo "  Image must be a PNG readable inside the guest container namespace." >&2
  exit 1
}

(( $# == 1 )) || usage

wallpaper="$(readlink -f "$1")"
[[ -f "${wallpaper}" ]] || { echo "ERROR: not a file: ${wallpaper}" >&2; exit 1; }
[[ -r "${wallpaper}" ]] || { echo "ERROR: not readable: ${wallpaper}" >&2; exit 1; }

# --- locate the running session's D-Bus address ---
dbus_addr=""
for _pid in $(pgrep -f 'xfce4-session' 2>/dev/null || true); do
  _env=$(cat "/proc/${_pid}/environ" 2>/dev/null | tr '\0' '\n' || true)
  _dis=$(echo "${_env}" | grep '^DISPLAY=' | head -1 | cut -d= -f2)
  [[ "${_dis}" == ":94" ]] || continue
  _bus=$(echo "${_env}" | grep '^DBUS_SESSION_BUS_ADDRESS=' | head -1 | cut -d= -f2-)
  [[ -n "${_bus}" ]] && { dbus_addr="${_bus}"; break; }
done

[[ -n "${dbus_addr}" ]] || { echo "ERROR: sanctuary-godzilla-xs XFCE session not found on :94" >&2; exit 1; }
export DBUS_SESSION_BUS_ADDRESS="${dbus_addr}"

# --- verify xfconf-query works ---
if ! "${XFCONF}" -c xfce4-desktop -lv >/dev/null 2>&1; then
  echo "ERROR: xfconf-query cannot reach xfconfd on session D-Bus" >&2
  exit 1
fi

# --- get the xrandr output name ---
output="$(DISPLAY="${DISPLAY}" xrandr --query 2>/dev/null | awk '/ connected/{print $1; exit}')"
[[ -n "${output}" ]] || { echo "ERROR: no connected xrandr output on :94" >&2; exit 1; }

# --- apply the wallpaper ---
prop="/backdrop/screen0/monitor${output}/workspace0/last-image"
style_prop="/backdrop/screen0/monitor${output}/workspace0/image-style"

"${XFCONF}" -c xfce4-desktop -p "${prop}" -t string -s "${wallpaper}" --create
"${XFCONF}" -c xfce4-desktop -p "${style_prop}" -t int -s 2 --create  # 2 = tiled

# --- restart xfdesktop if it's running on :94 ---
xfdesk_pid=""
for _pid in $(pgrep xfdesktop 2>/dev/null || true); do
  _env_dis=$(cat "/proc/${_pid}/environ" 2>/dev/null | tr '\0' '\n' | grep '^DISPLAY=' | head -1 | cut -d= -f2)
  [[ "${_env_dis}" == ":94" ]] && { xfdesk_pid="${_pid}"; break; }
done
if [[ -n "${xfdesk_pid}" ]]; then
  DISPLAY="${DISPLAY}" "${PROFILE_BIN}/xfdesktop" --quit 2>/dev/null || true
  # Wait for it to actually die
  for _i in $(seq 1 10); do
    kill -0 "${xfdesk_pid}" 2>/dev/null || break
    sleep 0.3
  done
fi

nohup env \
  DBUS_SESSION_BUS_ADDRESS="${dbus_addr}" \
  DISPLAY="${DISPLAY}" \
  XDG_CONFIG_HOME="${GUEST_HOME}/.config" \
  XDG_DATA_HOME="${GUEST_HOME}/.local/share" \
  HOME="${GUEST_HOME}" \
  XDG_CACHE_HOME="${GUEST_HOME}/.cache" \
  XDG_STATE_HOME="${GUEST_HOME}/.local/state" \
  "${PROFILE_BIN}/xfdesktop" -D \
  >/dev/null 2>&1 &

sleep 2
# Verify xfdesktop is alive by scanning /proc (DISPLAY=:94 is in environ, not cmdline)
new_pid=""
for _pid in $(pgrep xfdesktop 2>/dev/null || true); do
  _env_dis=$(cat "/proc/${_pid}/environ" 2>/dev/null | tr '\0' '\n' | grep '^DISPLAY=' | head -1 | cut -d= -f2)
  [[ "${_env_dis}" == ":94" ]] && { new_pid="${_pid}"; break; }
done
if [[ -n "${new_pid}" ]]; then
  echo "Wallpaper applied: ${wallpaper}"
  echo "  xrandr output: ${output}"
  echo "  xfconf property: ${prop}"
  echo "  image-style: 2 (tiled)"
else
  echo "WARNING: wallpaper property set but xfdesktop did not start." >&2
  exit 2
fi
#+END_SRC

** Sanctuary SYSINFO grid

Script invoked by fastfetch's Command module. Runs inside the container at
display time, queries /proc, hostname, xfconf, gsettings live.

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-godzilla-xs-fastfetch-grid :shebang "#!/bin/bash" :mkdirp yes
# Output the Human68k-style two-column SYSINFO grid for fastfetch Command module.
# Runs inside the sanctuary container — values reflect the container's view.
# Uses /proc and /sys directly; no external tools needed beyond coreutils (grep, awk, etc.).
set -euo pipefail

_col() { printf '%-49s' "$1"; }

# --- Habitat class detection (Virtual Habitat taxonomy) ---
if [[ -f /run/.containerenv ]] || [[ "${container:-}" != "" ]]; then
  _habitat="Sanctuary (Distrobox)"
elif [[ "$(cat /sys/class/dmi/id/product_name 2>/dev/null || true)" == *KVM* ]]; then
  _habitat="Enclave (KVM)"
elif [[ -d /sys/hypervisor ]] && grep -q . /sys/hypervisor/type 2>/dev/null; then
  _habitat="Enclave ($(head -1 /sys/hypervisor/type 2>/dev/null))"
else
  _habitat="Baremetal"
fi

# --- Substrate (package manager) ---
if [[ -d /gnu/store ]]; then
  _pkg="Guix"
elif [[ -f /etc/debian_version ]]; then
  _pkg="Apt/Debian"
else
  _pkg="Unknown"
fi

# --- Display layer ---
_res="${DISPLAY:-:0}"
if grep -qi xephyr /proc/*/cmdline 2>/dev/null; then
  _dis="Xephyr ${_res}"
else
  _dis="X11 ${_res}"
fi

# --- System basics ---
_host="$(cat /proc/sys/kernel/hostname 2>/dev/null || uname -n)"
_kernel="$(uname -r)"
_cpu="$(grep -m1 'model name' /proc/cpuinfo 2>/dev/null | cut -d: -f2 | xargs)"
[[ -z "${_cpu}" ]] && _cpu="Unknown"

# Memory from /proc/meminfo
_mem_kb="$(awk '/^MemTotal:/{print $2}' /proc/meminfo 2>/dev/null)"
if [[ -n "${_mem_kb}" ]]; then
  if (( _mem_kb >= 1048576 )); then
    _mem="$(awk "BEGIN {printf \"%.0fG\", ${_mem_kb}/1048576}")"
  else
    _mem="$(awk "BEGIN {printf \"%.0fM\", ${_mem_kb}/1024}")"
  fi
else
  _mem="Unknown"
fi

# Uptime from /proc/uptime
_uptime_sec="$(awk -F. '{print $1}' /proc/uptime 2>/dev/null)"
if [[ -n "${_uptime_sec}" ]]; then
  _days=$((_uptime_sec / 86400))
  _hours=$(((_uptime_sec % 86400) / 3600))
  _mins=$(((_uptime_sec % 3600) / 60))
  if (( _days > 0 )); then
    _uptime="${_days}d ${_hours}h ${_mins}m"
  elif (( _hours > 0 )); then
    _uptime="${_hours}h ${_mins}m"
  else
    _uptime="${_mins}m"
  fi
else
  _uptime="Unknown"
fi

_shell="$(basename "${SHELL:-/bin/sh}")"
_shell_ver=""

# GPU from /sys
_gpu="Unknown"
for p in /sys/class/drm/card*/device/vendor; do
  [[ -f "$p" ]] || continue
  _dev="$(dirname "$p")"
  _vendor="$(cat "$p" 2>/dev/null)"
  [[ "$_vendor" != "0x10de" ]] || _gpu="NVIDIA"
  break
done

# Screen from /sys
_res_str="?x?"
for fb in /sys/class/graphics/fb*/modes; do
  [[ -f "$fb" ]] || continue
  _res_str="$(head -1 "$fb" 2>/dev/null)"
  break
done

# DE/WM/theme — static for sanctuary-godzilla-xs
_de="XFCE"
_wm="xfwm4"
_wm_theme="Default"
_gtk="Default"
_icons="Default"
_font="Monospace"

# --- Output the grid ---
printf '%s\n%s\n\n' \
  "$(_col " Host        ${_host}")" \
  "$(_col " Display     ${_res_str}")"

printf '%s\n%s\n\n' \
  "$(_col " CPU         ${_cpu}")" \
  "$(_col " GPU         ${_gpu}")"

printf '%s\n%s\n\n' \
  "$(_col " Memory      ${_mem}")" \
  "$(_col " Uptime      ${_uptime}")"

printf '%s\n%s\n\n' \
  "$(_col " Kernel      ${_kernel}")" \
  "$(_col " Shell       ${_shell} ${_shell_ver}")"

printf '%s\n%s\n\n' \
  "$(_col " Desktop     ${_de}")" \
  "$(_col " WM          ${_wm}")"

printf '%s\n%s\n\n' \
  "$(_col " WM Theme    ${_wm_theme}")" \
  "$(_col " GTK         ${_gtk}")"

printf '%s\n%s\n\n' \
  "$(_col " Icons       ${_icons}")" \
  "$(_col " Font        ${_font}")"

printf '\n%s\n%s\n%s' \
  "$(_col " Habitat     ${_habitat}")" \
  "$(_col " Substrate   ${_pkg}")" \
  "$(_col " Display     ${_dis}")"
#+END_SRC
