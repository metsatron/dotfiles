* Sanctuary: sanctuary-godzilla-xs — SX-Window XLibre/X11 Habitat

An XFCE-based XLibre/X11 habitat for a living continuation of Sharp X68000 SX-Window and Ko-Window visual culture. It uses XFCE as a flexible, manually tuneable chassis, beginning from a Windows-3.1-adjacent visual baseline and evolving toward a bespoke Japanese early-1990s workstation grammar. It is intended to host native Linux applications alongside future machine-islands for X68000, PC-98, FM Towns, DOSBox-X, Wine, ScummVM, and related God-PC-era environments.

Stack: Guix base + XFCE desktop stack (no source build required; packages come from host =/gnu/store=).
Guix profiles sourced: =desktop-common= + =sanctuary-godzilla-xs= + =room-retropie= (the
dedicated Godzilla profile is authoritative; room-retropie supplies an explicit
fallback for already-built RetroPie cores).

Host virtual desktop: current host desktop. Xephyr display: =:94=.
Agent doorway: =distrobox enter sanctuary-godzilla-xs -- <cmd>=
Launch: =sanctuary-godzilla-xs-launch=
Capture: =sanctuary-godzilla-xs-capture= (dry-run by default; =--apply= to write to DotCortex source)

Guest home: =$XDG_DATA_HOME/dotcortex/guests/sanctuary-godzilla-xs/home/=

** Visual Grammar and Baseline

The initial payload is stock XFCE, started cleanly inside the Xephyr display. The intended visual grammar — woven cross-hatched grey root-desktop texture, narrow black keylines, restrained bevels, horizontal segmented titlebars, compact controls, a fixed vertical left device/tool rail, grayscale bitmap-style icons with selective Sharp/X68000 green accents, and Japanese and English labels living together — is built by the user manually through XFCE's own configuration tools. The sanctuary is designed for manual exploration and iteration, not automated theming.

The initial XFCE session starts from its own defaults. A Windows-3.1-adjacent XFWM4 theme provides the starting geometry; the user tunes from there toward the SX/Ko grammar.

** Declarative desktop state workflow

The live guest home remains writable so XFCE can be shaped normally through
its own settings tools.  Durable state flows back through a reviewable Org
snapshot instead of allowing =xfconfd= to write directly into tangled output:

#+BEGIN_EXAMPLE
live guest home -> sanctuary-godzilla-xs-capture -> sanctuary-godzilla-xs-state.org
                -> tangle -> sanctuary-godzilla-xs-config-apply -> guest home
#+END_EXAMPLE

=sanctuary-godzilla-xs-capture= is a dry-run by default.  It inventories every stable
XFCE channel, the complete panel launcher tree, desktop accelerator/icon-layout
state, and every image below the guest =Pictures/= directory referenced by that
state.  =--apply= promotes the reviewed snapshot into
=sanctuary-godzilla-xs-state.org=, tangles it, backs up the mutable guest configuration,
and applies the declared result back to the guest home.

The capture normalizes Guix store hashes out of panel launcher commands, rejects
secret-like material and network addresses, and excludes only runtime or
hardware state: session/window restore, notification history, display probing,
power management, and transient keyboard-device channels.

Future manual changes follow one loop:

1. Shape the running desktop through XFCE.
2. Close =sanctuary-godzilla-xs= so all writers have flushed and stopped.
3. Run =sanctuary-godzilla-xs-capture= and review the Org diff.
4. Run =sanctuary-godzilla-xs-capture --apply=.
5. Review =git diff -- sanctuary-godzilla-xs-state.org linux/.config/sanctuary-godzilla-xs/=.
6. Commit the canonical Org source and its tangled output with =/commit=.

The launcher runs =sanctuary-godzilla-xs-config-apply= before XFCE.  It never overwrites
uncaptured drift: the live desktop is preserved and launch continues with a
promotion reminder.  =--force= is an explicit restore operation and always
writes a timestamped backup first.

** Godzilla XS-86000 library, state, and menu foundation

Godzilla XS-86000 is the visible identity of =sanctuary-godzilla-xs=.  The technical
identifier remains =sanctuary-godzilla-xs= for containers, guest homes, manifests,
helpers, and Xephyr display wiring.

Shared media lives in =~/RetroPie= and is treated as a durable media library,
not a RetroPie OS installation.  Emulator configuration, Wine prefixes, saves,
caches, shader cache, Lutris state, and generated thumbnails stay in
=XDG_DATA_HOME/godzilla-xs= and =XDG_CONFIG_HOME/godzilla-xs= inside the
sanctuary guest home.

Bus policy:
- X68 BUS: XEiJ primary; XM6 under Wine fallback only.
- DRIVE A: PC-98: NP2Kai primary; T98-Next under Wine fallback only.
- DRIVE B: PC-88: QUASI88 primary; MAME fallback only, not the front end.
- FM TOWNS: Tsugaru primary; ScummVM supplement; UNZ under Wine fallback only.
- ARCADE BUS: MAME remains the preservation and broad-archive branch.  Neo Geo
  is an SNK Neo Geo MVS arcade branch over FinalBurn Neo.
- X68 EXPANSION BUS: CPS 1 / CPS 2 / CPS 3 are the aftermarket 2026 bus
  branches over FinalBurn Neo, sharing the declared CPS archive roots without
  copying or reclassifying the user's curated media.
- PC COMPATIBILITY BOARD: Wine/Lutris Japanese and period PC software.

No Saturn bus, no Nintendo/Super Famicom bus, no FinalBurn Alpha runtime, and no
private/adult quarantine category.  MAME remains available as the separate
preservation branch; FBNeo is the approved CPS/Neo Geo playability branch.

#+BEGIN_SRC bash :tangle linux/.local/bin/godzilla-xs-winetricks :shebang "#!/bin/sh" :mkdirp yes
# Apply one approved winetricks verb to one named Godzilla XS-86000 prefix.

  echo "Usage: godzilla-xs-winetricks <prefix-name> <verb> <reason...>" >&2

  xm6-typeg|t98-next|unz|sega-pc-9x|capcom-pc-9x|konami-pc-9x|jpwin9x|mugen|romlab-win32|mgs2-xp) ;;

  corefonts|directplay|directmusic|dinput|dsound|quartz|mfc42|mfc42u|vcrun6|vcrun2005|d3dx9) ;;

# Initialize Godzilla XS-86000 Wine prefixes with recorded Windows versions.

init_prefix() {
  prefix="$1"
  winver="$2"
  shift 2
  prefix_dir="${data_home}/wine/${prefix}"
  marker="${prefix_dir}/.godzilla-xs-initialized"
  mkdir -p "${prefix_dir}"
  if [ -f "${marker}" ]; then
    echo "godzilla-xs: prefix already initialized: ${prefix}"
    return 0
  fi
  echo "godzilla-xs: initializing ${prefix} as ${winver}"
  export WINEARCH=win32
  export WINEPREFIX="${prefix_dir}"
  WINEDEBUG=-all wineboot --init 2>&1 | tee "${log_root}/${prefix}-wineboot.log"
  WINEDEBUG=-all winecfg -v "${winver}" 2>&1 | tee "${log_root}/${prefix}-winecfg.log"
  for verb in "$@"; do
    godzilla-xs-winetricks "${prefix}" "${verb}" "baseline ${prefix} compatibility"
  done
  date -Iseconds > "${marker}"
}

    return 1
  fi

media_path() {
  local candidate resolved root
  candidate="$1"
  resolved="$(realpath -e -- "${candidate}" 2>/dev/null || true)"
  # Older generated entries used the logical guest-home path.  Resolve those
  # against the live bind when the guest-home link is absent or stale.
  if [[ -z "${resolved}" && "${candidate}" == "${HOME}/RetroPie/"* && -d "${RETROPIE}/roms" ]]; then
    resolved="$(realpath -e -- "${RETROPIE}/${candidate#"${HOME}/RetroPie/"}" 2>/dev/null || true)"
  fi
  root="$(realpath -e -- "${RETROPIE}" 2>/dev/null || true)"
  [[ -n "${resolved}" && -n "${root}" ]] || {
    echo "godzilla-xs-apps: media does not exist: ${candidate}" >&2
    return 1
  }
  case "${resolved}" in
    "${root}/roms/"*) printf '%s\n' "${resolved}" ;;
    *) echo "godzilla-xs-apps: media is outside RetroPie rom roots: ${candidate}" >&2; return 1 ;;
  esac
}

media_count() {
  local root="$1"
  [[ -d "${root}" ]] || { printf '0'; return; }
  find "${root}" -maxdepth 1 -type f -print 2>/dev/null | wc -l | tr -d ' '
}

media_archive_count() {
  local root="$1"
  [[ -d "${root}" ]] || { printf '0'; return; }
  find "${root}" -maxdepth 1 -type f \( -iname '*.zip' -o -iname '*.7z' \) -print 2>/dev/null | wc -l | tr -d ' '
}

slug() {
  local value
  value="$(printf '%s' "$1" | tr '[:upper:]' '[:lower:]' | sed -E 's/[^a-z0-9]+/-/g; s/^-+//; s/-+$//')"
  [[ -n "${value}" ]] || value=untitled
  printf '%s' "${value}"
}

media_key() {
  local title
  title="$(basename -- "$1")"
  title="${title%.*}"
  title="${title//%/ percent}"
  # The SX-Window dump uses both `Hiryu` and `Hiryuu` for Strider.  Treat
  # that romaji spelling variant as one catalogue identity so the playable
  # three-disk M3U suppresses the misleading standalone HDF entry.
  title="${title//Hiryuu/Hiryu}"
  title="${title//hiryuu/hiryu}"
  slug "${title}"
}

load_media_keys() {
  local bus root file ext
  for bus in cps1 cps2 cps3 neogeo; do
    root="$(bus_root "${bus}")"
    [[ -d "${root}" ]] || continue
    while IFS= read -r -d '' file; do
      ext="${file##*.}"
      case "${bus}:${ext,,}" in
        cps1:zip|cps1:7z|cps2:zip|cps2:7z|cps3:zip|cps3:7z|neogeo:zip|neogeo:7z)
          MEDIA_KEYS["${bus}:$(media_key "${file}")"]=1 ;;
      esac
    done < <(find "${root}" -maxdepth 1 -type f -print0 2>/dev/null | sort -z)
  done
}

  [[ -n "${file}" && -z "${METADATA_FILES_SEEN["${file}"]+present}" ]] || return 0
  METADATA_FILES_SEEN["${file}"]=1
  while IFS=$'\t' read -r relative_path metadata_name genre developer publisher releasedate players; do
    [[ -n "${relative_path}" && -n "${metadata_name}" ]] || continue
    relative_path="$(xml_unescape "${relative_path}")"
    metadata_name="$(xml_unescape "${metadata_name}")"
    genre="$(xml_unescape "${genre}")"
    developer="$(xml_unescape "${developer}")"
    publisher="$(xml_unescape "${publisher}")"
    releasedate="$(xml_unescape "${releasedate}")"
    players="$(xml_unescape "${players}")"
    detail=""
    [[ -n "${genre}" ]] && detail="${genre}"
    [[ -n "${developer}" ]] && detail="${detail:+${detail}; }${developer}"
    [[ -n "${publisher}" && "${publisher}" != "${developer}" ]] && detail="${detail:+${detail}; }${publisher}"
    [[ -n "${releasedate}" ]] && detail="${detail:+${detail}; }${releasedate:0:4}"
    [[ -n "${players}" ]] && detail="${detail:+${detail}; }${players} players"
    for bus in cps1 cps2 cps3 neogeo; do
      key="${bus}:$(media_key "${relative_path}")"
      [[ -n "${MEDIA_KEYS["${key}"]+present}" ]] || continue
      [[ -n "${MEDIA_TITLES["${key}"]+present}" ]] && continue
      MEDIA_TITLES["${key}"]="${metadata_name}"
      MEDIA_DETAILS["${key}"]="${detail}"
    done
  done < <(awk '
    function field(line, tag, value) {
      value = line
      sub(".*<" tag ">", "", value)
      sub("</" tag ">.*", "", value)
      return value
    }
    /<path>/ { path = field($0, "path") }
    /<name>/ { name = field($0, "name") }
    /<genre>/ { genre = field($0, "genre") }
    /<developer>/ { developer = field($0, "developer") }
    /<publisher>/ { publisher = field($0, "publisher") }
    /<releasedate>/ { releasedate = field($0, "releasedate") }
    /<players>/ { players = field($0, "players") }
    /<\/game>/ {
      if (path != "") print path "\t" name "\t" genre "\t" developer "\t" publisher "\t" releasedate "\t" players
      path = name = genre = developer = publisher = releasedate = players = ""
    }
  ' "${file}")
}

write_desktop() {
  local id="$1" name="$2" comment="$3" exec_line="$4" icon="$5" category="$6" terminal="$7"
  local destination="${APPLICATIONS_DIR}/${GENERATED_PREFIX}${id}.desktop"
  local temporary main_category
  case "${category}" in
    X-GodzillaX68*|X-GodzillaPC98*|X-GodzillaPC88*|X-GodzillaFMTowns*|X-GodzillaArcade|X-GodzillaFBNeo|X-GodzillaCPS1|X-GodzillaCPS2|X-GodzillaCPS3|X-GodzillaNeoGeo|X-GodzillaMedia|X-GodzillaXS)
      main_category=Game ;;
    X-GodzillaRomLab)
      main_category=Utility ;;
    X-GodzillaSoundModules)
      main_category=AudioVideo ;;
    *)
      main_category=Utility ;;
  esac
  category="${main_category};${category}"
  temporary="$(mktemp "${destination}.tmp.XXXXXX")"
  {
    printf '# DotCortex generated Godzilla XS catalogue entry; do not edit.\n'
    printf '[Desktop Entry]\nType=Application\nName=%s\nComment=%s\n' "${name}" "${comment}"
    printf 'Exec=%s\nIcon=%s\nTerminal=%s\nCategories=%s;\nStartupNotify=true\n' "${exec_line}" "${icon}" "${terminal}" "${category}"
  } >"${temporary}"
  mv -f -- "${temporary}" "${destination}"
}

backend_status() {
  local bus="$1"
  case "${bus}" in
    x68000)
      [[ -n "$(profile_bin retroarch 2>/dev/null || true)" ]] && profile_core px68k >/dev/null 2>&1 && x68000_bios_ready && printf 'runnable' || printf 'unavailable' ;;
    pc98) [[ -n "$(profile_bin np2kai 2>/dev/null || true)" ]] && printf 'runnable' || printf 'unavailable' ;;
    pc88)
      [[ -n "$(profile_bin retroarch 2>/dev/null || true)" ]] && profile_core quasi88 >/dev/null 2>&1 && printf 'runnable' || printf 'unavailable' ;;

      [[ -n "$(profile_bin retroarch 2>/dev/null || true)" ]] && profile_core fbneo >/dev/null 2>&1 && printf 'runnable' || printf 'unavailable' ;;
    *) printf 'catalogue-only' ;;
  esac
}

mame_launch() {
  local bus="$1" media="${2:-}" root mame game
  root="$(bus_root "${bus}")"
  root="$(realpath -e -- "${root}" 2>/dev/null || true)"
  [[ -n "${root}" && -d "${root}" ]] || { echo "godzilla-xs-apps: media root is absent: ${root}" >&2; return 1; }
  mame="$(profile_bin mame)"
  if [[ -n "${media}" ]]; then
    case "${media}" in
      "${root}"/*) ;;
      *) echo "godzilla-xs-apps: ${bus} media is outside its declared archive: ${media}" >&2; return 1;;
    esac
    game="$(basename -- "${media}")"
    game="${game%.*}"
    exec "${GAMEMODE_RUNNER}" "${mame}" -rompath "${root}" "${game}"
  fi
  exec "${GAMEMODE_RUNNER}" "${mame}" -rompath "${root}"
}

fbneo_launch() {
  local bus="$1" media="${2:-}" root retroarch core runtime_config
  root="$(realpath -e -- "$(bus_root "${bus}")" 2>/dev/null || true)"
  [[ -n "${root}" && -d "${root}" ]] || {
    echo "godzilla-xs-apps: media root is absent: ${root}" >&2
    return 1
  }
  retroarch="$(profile_bin retroarch)"
  core="$(profile_core fbneo)"
  if [[ -n "${media}" ]]; then
    case "${media}" in
      "${root}"/*) ;;
      *) echo "godzilla-xs-apps: ${bus} media is outside its declared archive: ${media}" >&2; return 1;;
    esac
  fi
  local -a retroarch_args=("${retroarch}" -L "${core}")
  runtime_config="${TMPDIR:-/tmp}/godzilla-xs-fbneo-${bus}.cfg"
  printf 'joypad_autoconfig_dir = "%s"\n' "${HOME}/.config/retroarch/autoconfig" >"${runtime_config}"
  local append_cfg="${runtime_config}"
  [[ -f "${FBNEO_CONFIG}" ]] && append_cfg="${append_cfg}|${FBNEO_CONFIG}"
  retroarch_args+=(--appendconfig "${append_cfg}")
  if [[ -n "${media}" ]]; then
    LIBRETRO_SYSTEM_DIRECTORY="${RETROPIE}/bios" LIBRETRO_AUTOCONFIG_DIRECTORY="${HOME}/.config/retroarch/autoconfig" exec "${GAMEMODE_RUNNER}" "${retroarch_args[@]}" "${media}"
  fi
  # A bus desktop entry is a content picker.  A contentless RetroArch
  # invocation exits immediately; --menu keeps the FBNeo branch open so the
  # user can choose an archive from RetroArch's Load Content screen.
  retroarch_args+=(--menu)
  LIBRETRO_SYSTEM_DIRECTORY="${RETROPIE}/bios" LIBRETRO_AUTOCONFIG_DIRECTORY="${HOME}/.config/retroarch/autoconfig" exec "${GAMEMODE_RUNNER}" "${retroarch_args[@]}"
}

px68k_profile_config() {
  local profile="${1:-normal}" config
  case "${profile}" in
    normal) return 0 ;;
    baseline|threaded|no-vsync|no-audio-sync) ;;
    *)
      echo "godzilla-xs-apps: unknown PX68K profile: ${profile}" >&2
      echo "  Choose: baseline, threaded, no-vsync, no-audio-sync" >&2
      return 2
      ;;
  esac
  config="${PX68K_PROFILE_DIR}/px68k-test-${profile}.cfg"
  [[ -f "${config}" ]] || {
    echo "godzilla-xs-apps: PX68K profile is not installed: ${config}" >&2

launch() {
  local bus="$1" media="" profile=normal profile_config=""
  shift
  while (( $# )); do
    case "$1" in
      --media)
        [[ $# -ge 2 ]] || { echo 'godzilla-xs-apps: --media requires a path' >&2; return 2; }
        media_path "$2" >/dev/null
        media="$(media_path "$2")"
        shift 2
        ;;
      --profile)
        [[ $# -ge 2 ]] || { echo 'godzilla-xs-apps: --profile requires a name' >&2; return 2; }
        profile="$2"
        shift 2
        ;;
      *)
        echo "godzilla-xs-apps: unknown launch option: $1" >&2
        return 2
        ;;
    esac
  done
  case "${bus}" in
    x68000)
      local retroarch core
      retroarch="$(profile_bin retroarch)"
      core="$(profile_core px68k)"
      [[ -n "${media}" ]] || { echo 'godzilla-xs-apps: choose an X68000 image from the catalogue.' >&2; return 2; }
      if ! x68000_bios_ready; then
        echo "godzilla-xs-apps: PX68k needs X68000 BIOS files under ${RETROPIE}/bios/x68000/keropi/." >&2
        echo "  Supply one IPL ROM (iplrom.dat, iplrom30.dat, iplromco.dat, or iplromxv.dat)" >&2
        echo "  plus cgrom.dat or cgrom.tmp; add legally obtained files and try again." >&2
        return 1
      fi
      local -a retroarch_args=("${retroarch}" -L "${core}")
      local runtime_input="${TMPDIR:-/tmp}/godzilla-xs-px68k-input.cfg"
      printf 'joypad_autoconfig_dir = "%s"\n' "${HOME}/.config/retroarch/autoconfig" >"${runtime_input}"
      local append_cfg="${runtime_input}"
      [[ -f "${PX68K_WINDOW_CONFIG}" ]] && append_cfg="${append_cfg}|${PX68K_WINDOW_CONFIG}"
      if ! profile_config="$(px68k_profile_config "${profile}")"; then
        return 1
      fi
      if [[ -n "${profile_config}" ]]; then
        append_cfg="${append_cfg}|${profile_config}"
        echo "godzilla-xs-apps: PX68K profile=${profile} (FPS overlay enabled)" >&2
      fi
      retroarch_args+=(--appendconfig "${append_cfg}")
      LIBRETRO_SYSTEM_DIRECTORY="${RETROPIE}/bios/x68000" LIBRETRO_AUTOCONFIG_DIRECTORY="${HOME}/.config/retroarch/autoconfig" exec "${GAMEMODE_RUNNER}" "${retroarch_args[@]}" "${media}" ;;
    pc98)
      local np2kai
      np2kai="$(profile_bin np2kai)"
      [[ -n "${media}" ]] || { echo 'godzilla-xs-apps: choose a PC-98 disk image from the catalogue.' >&2; return 2; }
      exec "${GAMEMODE_RUNNER}" "${np2kai}" "${media}" ;;
    pc88)
      local retroarch core
      retroarch="$(profile_bin retroarch)"
      core="$(profile_core quasi88)"
      [[ -n "${media}" ]] || { echo 'godzilla-xs-apps: choose a PC-88 disk image from the catalogue.' >&2; return 2; }
      local ext="${media##*.}"
      ext="${ext,,}"
      case "${ext}" in
        t88|cmt)
          echo "godzilla-xs-apps: tape media (.${ext}) requires standalone QUASI88; the libretro core supports .d88/.u88/.m3u only." >&2
          return 1 ;;
      esac
      local -a retroarch_args=("${retroarch}" -L "${core}")
      local runtime_input="${TMPDIR:-/tmp}/godzilla-xs-pc88-input.cfg"
      printf 'joypad_autoconfig_dir = "%s"\n' "${HOME}/.config/retroarch/autoconfig" >"${runtime_input}"
      local append_cfg="${runtime_input}"
      retroarch_args+=(--appendconfig "${append_cfg}")
      LIBRETRO_SYSTEM_DIRECTORY="${RETROPIE}/bios/pc88" LIBRETRO_AUTOCONFIG_DIRECTORY="${HOME}/.config/retroarch/autoconfig" exec "${GAMEMODE_RUNNER}" "${retroarch_args[@]}" "${media}" ;;
    fmtowns)
      local tsugaru
      tsugaru="$(profile_bin Tsugaru_CUI)"
      [[ -n "${media}" ]] || { echo 'godzilla-xs-apps: FM Towns media is not present yet.' >&2; return 2; }
      exec "${GAMEMODE_RUNNER}" "${tsugaru}" "${media}" ;;
    scummvm) exec "${GAMEMODE_RUNNER}" "$(profile_bin scummvm)" --path "${SCUMMVM_ROOT}" ;;
    mame) mame_launch arcade ;;
    cps1|cps2|cps3|neogeo) fbneo_launch "${bus}" "${media}" ;;
    *) echo "godzilla-xs-apps: unknown launch bus: ${bus}" >&2; return 2;;
  esac
}

emit_media_entry() {
  local bus="$1" role="$2" file="$3" status backend title fingerprint id category comment metadata_key
  backend="$(backend_status "${bus}")"
  status="${backend}"
  # FBNeo's active DAT is independent of MAME.  A ZIP's presence is therefore
  # not enough to call a game verified.  Keep the ledger honest, but expose
  # every curated archive as a direct launcher when the FBNeo core exists; the
  # core performs the authoritative content audit at launch time.
  case "${bus}" in cps1|cps2|cps3|neogeo) status=catalogue-only ;; esac
  title="$(basename "${file}")"
  title="${title%.*}"
  metadata_key="${bus}:$(media_key "${file}")"
  [[ -n "${MEDIA_TITLES["${metadata_key}"]+present}" ]] && title="${MEDIA_TITLES["${metadata_key}"]}"
  # Do not stream ROM archives over the shared NFS bind just to create a
  # generated-entry ID.  Size and mtime are sufficient to invalidate a menu
  # entry when the curated archive changes and keep refresh responsive.
  fingerprint="$(stat -c '%s-%Y' -- "${file}")"
  id="${bus}-$(slug "${title}")-${fingerprint}"
  category="$(media_category "${bus}" "${role}")"
  comment="Launch ${bus} media"
  case "${bus}" in
    cps1|cps2|cps3|neogeo) comment="Launch ${bus} archive through FBNeo; the core validates the current set" ;;
  esac
  [[ -n "${MEDIA_DETAILS["${metadata_key}"]:-}" ]] && comment="${comment}; ${MEDIA_DETAILS["${metadata_key}"]}"
  record game "${status}" "${title}" "${bus}" "${file}"
  if [[ "${MODE}" == refresh && ( "${backend}" == runnable || ( "${bus}" == x68000 && "${status}" == unavailable ) ) ]]; then
    write_desktop "${id}" "${title}" "${comment}" \
      "$(desktop_quote "${APP_CMD}") launch ${bus} --media $(desktop_quote "${file}")" applications-games "${category}" false
  fi
}

scan_media() {
  local bus="$1" root="$2" file ext resolved key
  [[ -d "${root}" ]] || return 0
  if [[ "${bus}" == x68000 ]]; then
    while IFS= read -r -d '' file; do
      key="$(media_key "${file}")"
      PLAYLIST_TITLES["${key}"]=1
      while IFS= read -r member || [[ -n "${member}" ]]; do
        member="${member%$'\r'}"
        [[ -n "${member}" && "${member}" != \#* ]] || continue
        resolved="$(realpath -e -- "$(dirname "${file}")/${member}" 2>/dev/null || true)"
        [[ -n "${resolved}" ]] && PLAYLIST_MEMBERS["${resolved}"]=1
      done < "${file}"
    done < <(find "${root}" -maxdepth 1 -type f -iname '*.m3u' -print0 | sort -z)
  fi
  while IFS= read -r -d '' file; do
    ext="${file##*.}"
    if [[ "${bus}" == x68000 && "${ext,,}" != m3u ]]; then
      resolved="$(realpath -e -- "${file}" 2>/dev/null || true)"
      [[ -n "${resolved}" && -n "${PLAYLIST_MEMBERS["${resolved}"]+present}" ]] && continue
      key="$(media_key "${file}")"
      [[ -n "${PLAYLIST_TITLES["${key}"]+present}" ]] && continue
    fi
    case "${bus}:${ext,,}" in
      x68000:m3u|x68000:dim|x68000:img|x68000:d88|x68000:88d|x68000:hdm|x68000:dup|x68000:2hd|x68000:xdf|x68000:hdf|x68000:cmd|x68000:zip|x68000:7z)
        [[ "${ext,,}" == m3u ]] && emit_media_entry x68000 playlist "${file}" || emit_media_entry x68000 disk "${file}";;
      pc98:hdi|pc98:fdi|pc98:hdm|pc98:d88|pc98:2hd|pc98:zip|pc98:7z)
        emit_media_entry pc98 disk "${file}";;
      pc88:d88|pc88:88d|pc88:2hd|pc88:hdm|pc88:zip|pc88:7z)
        emit_media_entry pc88 disk "${file}";;
      cps1:zip|cps1:7z|cps2:zip|cps2:7z|cps3:zip|cps3:7z)
        emit_media_entry "${bus}" game "${file}";;
      neogeo:zip|neogeo:7z)
        emit_media_entry neogeo game "${file}";;
    esac
  done < <(find "${root}" -maxdepth 1 -type f -print0 | sort -z)
}

emit_accessories() {
  local binary name category icon
  if [[ "${MODE}" == refresh ]]; then
    write_desktop retro-pie-library 'RetroPie Media Root' 'Browse the shared durable media tree' \
      "$(desktop_quote "${APP_CMD}") browse retropie" system-file-manager X-GodzillaXS false
    for binary in imhex ghex gimp mtpaint ristretto audacity audacious qjackctl qsynth; do
      command -v "${binary}" >/dev/null 2>&1 || continue
      name="${binary^}"
      category=X-GodzillaRomLab
      [[ "${binary}" == audacious || "${binary}" == qsynth || "${binary}" == qjackctl ]] && category=X-GodzillaSoundModules
      write_desktop "accessory-${binary}" "${name}" "Godzilla XS accessory: ${name}" \
        "$(desktop_quote "$(command -v "${binary}")")" applications-accessories "${category}" false
    done
    write_desktop archive-tools 'Archive and Patch Tools' 'Open a terminal with the ROM lab inventory' \
      "$(desktop_quote "${APP_CMD}") inventory" utilities-terminal X-GodzillaRomLab true
  fi
}

inventory_or_refresh() {
  if [[ "${MODE}" == refresh ]]; then
    mkdir -p "${APPLICATIONS_DIR}" "$(dirname "${LEDGER}")"
    rm -f -- "${APPLICATIONS_DIR}/${GENERATED_PREFIX}"*.desktop
    : >"${LEDGER}"
    printf 'kind\tstatus\tname\tbackend\tpath\n' >>"${LEDGER}"
  fi
  printf 'kind\tstatus\tname\tbackend\tpath\n'
  emit_runtime_entries
  load_media_keys
  load_emulationstation_metadata
  scan_media x68000 "${X68_ROOT}"
  scan_media pc98 "${PC98_ROOT}"
  scan_media pc88 "${PC88_ROOT}"
  scan_media cps1 "${CPS1_ROOT}"
  scan_media cps2 "${CPS2_ROOT}"
  scan_media cps3 "${CPS3_ROOT}"
  scan_media neogeo "${NEOGEO_ROOT}"
  record media ready 'X68000 media files' x68000 "$(media_count "${X68_ROOT}")"
  record media ready 'PC-98 media files' pc98 "$(media_count "${PC98_ROOT}")"
  record media ready 'PC-88 media files' pc88 "$(media_count "${PC88_ROOT}")"
  record media ready 'FM Towns media files' fmtowns "$(media_count "${FMTOWNS_ROOT}")"
  record media ready 'ScummVM media files' scummvm "$(media_count "${SCUMMVM_ROOT}")"
  record media ready 'Arcade media files' arcade "$(media_count "${ARCADE_ROOT}")"
  record media ready 'CPS 1 ROM archives' cps1 "$(media_archive_count "${CPS1_ROOT}")"
  record media ready 'CPS 2 ROM archives' cps2 "$(media_archive_count "${CPS2_ROOT}")"
  record media ready 'CPS 3 ROM archives' cps3 "$(media_archive_count "${CPS3_ROOT}")"
  record media ready 'Neo Geo ROM archives' neogeo "$(media_archive_count "${NEOGEO_ROOT}")"
  emit_accessories
  if [[ "${MODE}" == refresh ]]; then
    update-desktop-database "${APPLICATIONS_DIR}" >/dev/null 2>&1 || true
    echo "Godzilla XS catalogue refreshed: ${LEDGER}" >&2
  fi
}

check() {
  local result=0 desktop
  inventory_or_refresh >/dev/null
  if [[ -d "${APPLICATIONS_DIR}" && -x "$(command -v desktop-file-validate 2>/dev/null || true)" ]]; then
    while IFS= read -r -d '' desktop; do
      desktop-file-validate "${desktop}" || result=1
    done < <(find "${APPLICATIONS_DIR}" -maxdepth 1 -type f -name "${GENERATED_PREFIX}*.desktop" -print0)
  fi
  return "${result}"
}

case "${MODE}" in
  -h|--help|help) usage;;
  inventory) inventory_or_refresh;;
  refresh|menu) MODE=refresh; inventory_or_refresh;;
  check) check;;
  browse) browse "${1:?browse requires a bus}";;
  launch) launch "${1:?launch requires a bus}" "${@:2}";;
  *) usage >&2; exit 2;;
esac

** Godzilla XS shell identity — Human68k A:\ prompt

The Godzilla XS sanctuary imports Redstone 9X's proven dual-shell grammar —
drive-letter path mapping, Bash prompt-escape protection, login-shell loading,
global Zsh configuration chaining, and one banner per terminal — then skins it
with the white/grey/red device-driver palette and wording of the sanctuary's
Human68k Fastfetch output.

#+BEGIN_SRC bash :tangle linux/.config/sanctuary-godzilla-xs/shell/bashrc :comments no :mkdirp yes
# Godzilla XS-86000 sanctuary bash rc — Human68k drive-letter shell identity.
# Shared sanctuary grammar: symlinked to ~/.bashrc by sanctuary-godzilla-xs-launch.
# Interactive shells only.
case $- in *i*) ;; *) return ;; esac

# Map the Unix path to a Human68k drive path: $HOME collapses to A:\ , anything
# above $HOME shows as a C:\ path, forward slashes become backslashes. The final
# result is doubled ('\' -> '\\') because it lands in PS1, which bash re-expands as
# prompt escapes — an un-doubled '\h' '\s' '\d' '\w' '\u' would render as the
# hostname/shell/date/cwd/user. (Verified via ${PS1@P} rendering, 2026-07-15.)
_godzilla_xs_dospath() {
  local p="${PWD}" rel dos
  if [ "${p}" = "${HOME}" ]; then
    dos='A:\'
  elif [ "${p#${HOME}/}" != "${p}" ]; then
    rel="${p#${HOME}/}"; dos="A:\\${rel//\//\\}"
  else
    rel="${p#/}"; dos="C:\\${rel//\//\\}"
  fi
  printf '%s' "${dos//\\/\\\\}"
}

# Match the Human68k Fastfetch palette: dim device label, bright path, red
# command marker.  \[...\] keeps Bash's line editor aware that ANSI bytes do not
# consume columns.
PROMPT_COMMAND='PS1="\[\033[90m\]BASH \[\033[97m\]$(_godzilla_xs_dospath)\[\033[91m\]>\[\033[0m\] "'

_godzilla_xs_banner() {
  printf '\033[97mGODZILLA XS-86000 SYSTEM DRIVER version 0.86\033[0m\n'
  printf '\033[90mSHARP / NEC / FUJITSU / ARCADE COMPATIBILITY BUS\033[0m\n'
  printf '\033[97mASK68K / Human68k shell channel  \033[91mREADY\033[0m\n\n'
}

# First interactive shell in each terminal: open at HOME, print the boot banner.
if [ -z "${GODZILLA_XS_SHELL_INIT:-}" ]; then
  export GODZILLA_XS_SHELL_INIT=1
  cd "${HOME}" 2>/dev/null || true
  _godzilla_xs_banner
fi

** Declared font projection

The SX desktop names private/vendor font families that are provisioned into the
host's merged font corpus.  Some of those host entries are symlinks into mounted
HelmCortex storage, and those backing mounts are intentionally not propagated
into the container.  Resolve and checksum the required families on the host,
then materialize only those declared payloads into the persistent guest home.
The public repository owns the contract, not the private font binaries.

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-godzilla-xs-fonts-apply :shebang "#!/usr/bin/env bash" :mkdirp yes
# Materialize the exact fonts declared by sanctuary-godzilla-xs into its persistent home.
set -euo pipefail

GUESTS_DIR="${XDG_DATA_HOME:-$HOME/.local/share}/dotcortex/guests"
GUEST_HOME="${GUESTS_DIR}/sanctuary-godzilla-xs/home"
FONT_ROOT="${GUEST_HOME}/.local/share/fonts"
HOST_FONT_ROOT="${HOME}/.local/share/fonts"
HOST_LINK_BACKUP="${GUEST_HOME}/.local/share/fonts.host-link-pre-declarative"

FC_MATCH="$(command -v fc-match 2>/dev/null || true)"
if [[ -z "${FC_MATCH}" ]]; then
  echo "sanctuary-godzilla-xs-fonts-apply: fc-match is unavailable on the host" >&2
  exit 1
fi

# vm-homes-init historically made the whole guest font root one host symlink.
# Preserve that link once, replace it with a real persistent directory, and
# retain the merged host view beneath it for directly accessible host fonts.
if [[ -L "${FONT_ROOT}" ]]; then
  if [[ ! -e "${HOST_LINK_BACKUP}" && ! -L "${HOST_LINK_BACKUP}" ]]; then
    mv -T "${FONT_ROOT}" "${HOST_LINK_BACKUP}"
  else
    unlink "${FONT_ROOT}"
  fi
fi
if [[ -e "${FONT_ROOT}" && ! -d "${FONT_ROOT}" ]]; then
  echo "sanctuary-godzilla-xs-fonts-apply: refusing to replace non-directory ${FONT_ROOT}" >&2
  exit 1
fi

DECLARED_ROOT="${FONT_ROOT}/declared"
mkdir -p "${DECLARED_ROOT}"
ln -sfnT "${HOST_FONT_ROOT}" "${FONT_ROOT}/host"

# FAMILY|SHA256.  A family mismatch catches fontconfig fallback; a checksum
# mismatch catches silent replacement of the private payload.
font_specs=(
  "PxPlus IBM VGA 9x14|03c0a9a7d169fdac7c4f2c1a4aeb2a9c6f19175325d250e2765c6365e6eb588b"
  "D2CodingLigature Nerd Font|aacf7394f52574abcc126221543dbe7c6afe319ad300688490ca94b92d9856cf"
)

for spec in "${font_specs[@]}"; do
  family="${spec%%|*}"
  expected_sha="${spec##*|}"
  resolved_family="$(${FC_MATCH} -f '%{family[0]}' "${family}")"
  source_file="$(${FC_MATCH} -f '%{file}' "${family}")"

  if [[ "${resolved_family}" != "${family}" || ! -f "${source_file}" ]]; then
    echo "sanctuary-godzilla-xs-fonts-apply: required host font unavailable: ${family}" >&2
    exit 1
  fi
  actual_sha="$(sha256sum "${source_file}" | awk '{print $1}')"
  if [[ "${actual_sha}" != "${expected_sha}" ]]; then
    echo "sanctuary-godzilla-xs-fonts-apply: checksum mismatch for ${family}" >&2
    echo "  expected: ${expected_sha}" >&2
    echo "  actual:   ${actual_sha}" >&2
    exit 1
  fi

  destination="${DECLARED_ROOT}/$(basename "${source_file}")"
  if [[ ! -f "${destination}" ]] || ! cmp -s "${source_file}" "${destination}"; then
    install -m0644 "${source_file}" "${destination}.new"
    mv -f "${destination}.new" "${destination}"
    echo "sanctuary-godzilla-xs-fonts-apply: projected ${family}"
  fi
  done

# NP2kai's standalone SDL2 frontend resolves its UI font as default.ttf in
# its XDG configuration directory.  Keep that path inside the declared guest
# payload, using the Japanese-capable font already checksum-verified above.
NP2_CONFIG_DIR="${GUEST_HOME}/.config/np2kai"
NP2_FONT="${NP2_CONFIG_DIR}/default.ttf"
NP2_FONT_SOURCE="${DECLARED_ROOT}/D2CodingLigatureNerdFont-Regular.ttf"
if [[ ! -f "${NP2_FONT_SOURCE}" ]]; then
  echo "sanctuary-godzilla-xs-fonts-apply: NP2kai font payload is missing: ${NP2_FONT_SOURCE}" >&2
  exit 1
fi
mkdir -p "${NP2_CONFIG_DIR}"
if [[ -e "${NP2_FONT}" && ! -L "${NP2_FONT}" ]]; then
  mv -T "${NP2_FONT}" "${NP2_FONT}.pre-declarative-$(date +%Y%m%d-%H%M%S)"
fi
ln -sfnT "${NP2_FONT_SOURCE}" "${NP2_FONT}"

# Build the same user cache XFCE consumes, without requiring a running
# container.  The sanctuary profile pins the fontconfig implementation; env -i
# prevents host fontconfig overrides from leaking into the guest cache.
FONTCONFIG_BIN="${HOME}/.guix-extra-profiles/sanctuary-godzilla-xs/sanctuary-godzilla-xs/bin"
if [[ ! -x "${FONTCONFIG_BIN}/fc-cache" || ! -x "${FONTCONFIG_BIN}/fc-match" ]]; then
  echo "sanctuary-godzilla-xs-fonts-apply: sanctuary fontconfig profile is unavailable" >&2
  exit 1
fi
guest_font_env=(
  "HOME=${GUEST_HOME}"
  "XDG_DATA_HOME=${GUEST_HOME}/.local/share"
  "XDG_CACHE_HOME=${GUEST_HOME}/.cache"
  "PATH=${FONTCONFIG_BIN}:/usr/bin:/bin"
)
env -i "${guest_font_env[@]}" "${FONTCONFIG_BIN}/fc-cache" "${FONT_ROOT}" >/dev/null

for spec in "${font_specs[@]}"; do
  family="${spec%%|*}"
  guest_family="$(env -i "${guest_font_env[@]}" "${FONTCONFIG_BIN}/fc-match" -f '%{family[0]}' "${family}")"
  guest_file="$(env -i "${guest_font_env[@]}" "${FONTCONFIG_BIN}/fc-match" -f '%{file}' "${family}")"
  if [[ "${guest_family}" != "${family}" || "${guest_file}" != "${DECLARED_ROOT}/"* ]]; then
    echo "sanctuary-godzilla-xs-fonts-apply: guest verification failed for ${family}" >&2
    echo "  resolved family: ${guest_family}" >&2
    echo "  resolved file:   ${guest_file}" >&2
    exit 1
  fi
done
echo "sanctuary-godzilla-xs-fonts-apply: declared font payload verified"
#+END_SRC

normalize_text() {
  local rel="$1" src="$2" temporary
  temporary="$(mktemp "${tmp_dir}/normalize.XXXXXX")"
  case "${rel}" in
    desktop/icons.screen0.yaml)
      # xfdesktop rewrites this mapping in arbitrary key order.  Canonicalize
      # only the icon-entry order; preserve monitor identity and every value.
      perl -0777 -e '
        my $text = do { local $/; <> };
        $text =~ /\A(.*?^  icons:\n)(.*)\z/ms or die "missing icons map\n";
        my ($head, $body) = ($1, $2);
        my @blocks = ($body =~ /(^    "[^"]+":\n(?:^      .*\n?)*)/mg);
        die "unparsed icons map\n" unless join("", @blocks) eq $body;
        print $head, sort @blocks;
      ' "${src}" > "${temporary}"
      ;;
    panel/*.desktop)
      sed -E \
        -e 's#^(Exec=)/gnu/store/[^/]+/bin/#\1#' \
        -e '/^X-XFCE-Source=file:\/\/\/gnu\/store\//d' \
        "${src}" > "${temporary}"

    *) cat "${src}" > "${temporary}" ;;
  esac
  GUEST_HOME="${GUEST_HOME}" perl -pe 's/\Q$ENV{GUEST_HOME}\E/\@GUEST_HOME\@/g' "${temporary}"
  rm -f -- "${temporary}"
}

validate_text() {
  local rel="$1" src="$2" mime
  mime="$(file -b --mime-type "${src}")"
  case "${mime}" in text/*|application/xml|application/x-desktop|application/x-yaml|inode/x-empty) ;; *)
    echo "sanctuary-godzilla-xs-capture: refusing non-text config ${rel} (${mime})" >&2; exit 1 ;;
  esac
  if rg -n '^#\+END_SRC[[:space:]]*$' "${src}" >/dev/null; then
    echo "sanctuary-godzilla-xs-capture: Org terminator found in ${rel}" >&2; exit 1
  fi
  if rg -ni '(api[_-]?key|access[_-]?token|bearer[[:space:]]+[A-Za-z0-9]|BEGIN [A-Z ]*PRIVATE KEY)' "${src}" >/dev/null; then
    echo "sanctuary-godzilla-xs-capture: secret-like content found in ${rel}" >&2; exit 1
  fi
  if rg -n '(^|[^0-9])([0-9]{1,3}\.){3}[0-9]{1,3}([^0-9]|$)' "${src}" >/dev/null; then
    echo "sanctuary-godzilla-xs-capture: network address found in ${rel}" >&2; exit 1
  fi
}

org_lang() {
  case "$1" in *.xml) echo xml ;; *) echo conf ;; esac
}

{
  sed 's/^|//' <<'EOF'
|#+TITLE: sanctuary-godzilla-xs — Captured XFCE Desktop State
|#+DESCRIPTION: Machine-generated declarative snapshot of the Godzilla XS-86000 XFCE desktop

  printf '%s\n' '#+BEGIN_SRC text :tangle linux/.config/sanctuary-godzilla-xs/state.manifest :comments no :mkdirp yes'

    elif [[ "${kind}" == asset-file ]]; then
      printf 'asset-file\t%s\t%s\n' "${rel}" "${src}"
    else
      printf 'asset\t%s\tassets-base64/%s.b64\n' "${rel}" "${rel}"
    fi
  done

  printf '%s\n\n' '#+END_SRC'

  for record in "${records[@]}"; do
    IFS=$'\t' read -r kind rel src <<< "${record}"
    if [[ "${rel}" == xfconf/xfce4-session.xml ]]; then
      printf '** =xfconf/xfce4-session.xml= (room policy)\n\n'

      printf 'path and leaves host SSH credentials outside this room.\n\n'

      [[ "$(tail -c 1 "${normalized}" | od -An -t x1 | tr -d ' ')" == 0a ]] || printf '\n'
      printf '#+END_SRC\n\n'

      printf 'Theme-owned binary asset: =%s=.\n\n' "${src}"
    elif [[ "${kind}" == asset-file ]]; then

      printf 'Repo-owned binary asset: =linux/.config/sanctuary-godzilla-xs/assets/%s=.\n\n' "${asset_name}"
    else
      printf '#+BEGIN_SRC text :tangle linux/.config/sanctuary-godzilla-xs/assets-base64/%s.b64 :comments no :mkdirp yes\n' "${rel}"

      printf '#+END_SRC\n\n'
    fi
  done
} > "${candidate}"

# The block loop separates entries with a blank line; remove only the final
# separator so the generated Org source ends with exactly one newline.
truncate -s -1 "${candidate}"

awk '
  /^#\+BEGIN_SRC text :tangle linux\/\.config\/sanctuary-godzilla-xs\/state\.manifest / { in_manifest=1; next }
  in_manifest && /^#\+END_SRC/ { exit }

** sanctuary-godzilla-xs wallpaper

Set the sanctuary-godzilla-xs XFCE wallpaper directly via xfconf, bypassing the broken
XFCE 4.20 folder-picker UI (\"Unable to load images from folder '(null)' — Operation was cancelled\").

Usage: =sanctuary-godzilla-xs-wallpaper /path/to/image.png=

Requirements: sanctuary-godzilla-xs container must be running with an XFCE session;
Xephyr display =:94= must be up; xfconf-query in PATH.

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-godzilla-xs-wallpaper :shebang "#!/usr/bin/env bash" :mkdirp yes
# Apply the given PNG as sanctuary-godzilla-xs (:94) desktop wallpaper.
# Usage: sanctuary-godzilla-xs-wallpaper /absolute/or/relative/path.png
set -euo pipefail

DISPLAY=":94"
GUESTS_DIR="${XDG_DATA_HOME:-$HOME/.local/share}/dotcortex/guests"
GUEST_HOME="${GUESTS_DIR}/sanctuary-godzilla-xs/home"
PROFILE_BIN="${HOME}/.guix-extra-profiles/sanctuary-godzilla-xs/sanctuary-godzilla-xs/bin"
XFCONF="${PROFILE_BIN}/xfconf-query"

usage() {
  echo "Usage: sanctuary-godzilla-xs-wallpaper <image-path>" >&2
  echo "  Applies the wallpaper through xfconf on the running sanctuary-godzilla-xs XFCE session." >&2
  echo "  Image must be a PNG readable inside the guest container namespace." >&2
  exit 1
}

(( $# == 1 )) || usage

wallpaper="$(readlink -f "$1")"
[[ -f "${wallpaper}" ]] || { echo "ERROR: not a file: ${wallpaper}" >&2; exit 1; }
[[ -r "${wallpaper}" ]] || { echo "ERROR: not readable: ${wallpaper}" >&2; exit 1; }

# --- locate the running session's D-Bus address ---
dbus_addr=""
for _pid in $(pgrep -f 'xfce4-session' 2>/dev/null || true); do
  _env=$(cat "/proc/${_pid}/environ" 2>/dev/null | tr '\0' '\n' || true)
  _dis=$(echo "${_env}" | grep '^DISPLAY=' | head -1 | cut -d= -f2)
  [[ "${_dis}" == ":94" ]] || continue
  _bus=$(echo "${_env}" | grep '^DBUS_SESSION_BUS_ADDRESS=' | head -1 | cut -d= -f2-)
  [[ -n "${_bus}" ]] && { dbus_addr="${_bus}"; break; }
done

[[ -n "${dbus_addr}" ]] || { echo "ERROR: sanctuary-godzilla-xs XFCE session not found on :94" >&2; exit 1; }
export DBUS_SESSION_BUS_ADDRESS="${dbus_addr}"

# --- verify xfconf-query works ---
if ! "${XFCONF}" -c xfce4-desktop -lv >/dev/null 2>&1; then
  echo "ERROR: xfconf-query cannot reach xfconfd on session D-Bus" >&2
  exit 1
fi

# --- get the xrandr output name ---
output="$(DISPLAY="${DISPLAY}" xrandr --query 2>/dev/null | awk '/ connected/{print $1; exit}')"
[[ -n "${output}" ]] || { echo "ERROR: no connected xrandr output on :94" >&2; exit 1; }

# --- apply the wallpaper ---
prop="/backdrop/screen0/monitor${output}/workspace0/last-image"
style_prop="/backdrop/screen0/monitor${output}/workspace0/image-style"

"${XFCONF}" -c xfce4-desktop -p "${prop}" -t string -s "${wallpaper}" --create
"${XFCONF}" -c xfce4-desktop -p "${style_prop}" -t int -s 2 --create  # 2 = tiled

# --- restart xfdesktop if it's running on :94 ---
xfdesk_pid=""
for _pid in $(pgrep xfdesktop 2>/dev/null || true); do
  _env_dis=$(cat "/proc/${_pid}/environ" 2>/dev/null | tr '\0' '\n' | grep '^DISPLAY=' | head -1 | cut -d= -f2)
  [[ "${_env_dis}" == ":94" ]] && { xfdesk_pid="${_pid}"; break; }
done
if [[ -n "${xfdesk_pid}" ]]; then
  DISPLAY="${DISPLAY}" "${PROFILE_BIN}/xfdesktop" --quit 2>/dev/null || true
  # Wait for it to actually die
  for _i in $(seq 1 10); do
    kill -0 "${xfdesk_pid}" 2>/dev/null || break
    sleep 0.3
  done
fi

nohup env \
  DBUS_SESSION_BUS_ADDRESS="${dbus_addr}" \
  DISPLAY="${DISPLAY}" \
  XDG_CONFIG_HOME="${GUEST_HOME}/.config" \
  XDG_DATA_HOME="${GUEST_HOME}/.local/share" \
  HOME="${GUEST_HOME}" \
  XDG_CACHE_HOME="${GUEST_HOME}/.cache" \
  XDG_STATE_HOME="${GUEST_HOME}/.local/state" \
  "${PROFILE_BIN}/xfdesktop" -D \
  >/dev/null 2>&1 &

sleep 2
# Verify xfdesktop is alive by scanning /proc (DISPLAY=:94 is in environ, not cmdline)
new_pid=""
for _pid in $(pgrep xfdesktop 2>/dev/null || true); do
  _env_dis=$(cat "/proc/${_pid}/environ" 2>/dev/null | tr '\0' '\n' | grep '^DISPLAY=' | head -1 | cut -d= -f2)
  [[ "${_env_dis}" == ":94" ]] && { new_pid="${_pid}"; break; }
done
if [[ -n "${new_pid}" ]]; then
  echo "Wallpaper applied: ${wallpaper}"
  echo "  xrandr output: ${output}"
  echo "  xfconf property: ${prop}"
  echo "  image-style: 2 (tiled)"
else
  echo "WARNING: wallpaper property set but xfdesktop did not start." >&2
  exit 2
fi
#+END_SRC

** Sanctuary SYSINFO grid

Script invoked by fastfetch's Command module. Runs inside the container at
display time, queries /proc, hostname, xfconf, gsettings live.

#+BEGIN_SRC bash :tangle linux/.local/bin/sanctuary-godzilla-xs-fastfetch-grid :shebang "#!/bin/bash" :mkdirp yes
# Output the Human68k-style two-column SYSINFO grid for fastfetch Command module.
# Runs inside the sanctuary container — values reflect the container's view.
# Uses /proc and /sys directly; no external tools needed beyond coreutils (grep, awk, etc.).
set -euo pipefail

_col() { printf '%-49s' "$1"; }

# --- Habitat class detection (Virtual Habitat taxonomy) ---
if [[ -f /run/.containerenv ]] || [[ "${container:-}" != "" ]]; then
  _habitat="Sanctuary (Distrobox)"
elif [[ "$(cat /sys/class/dmi/id/product_name 2>/dev/null || true)" == *KVM* ]]; then
  _habitat="Enclave (KVM)"
elif [[ -d /sys/hypervisor ]] && grep -q . /sys/hypervisor/type 2>/dev/null; then
  _habitat="Enclave ($(head -1 /sys/hypervisor/type 2>/dev/null))"
else
  _habitat="Baremetal"
fi

# --- Substrate (package manager) ---
if [[ -d /gnu/store ]]; then
  _pkg="Guix"
elif [[ -f /etc/debian_version ]]; then
  _pkg="Apt/Debian"
else
  _pkg="Unknown"
fi

# --- Display layer ---
_res="${DISPLAY:-:0}"
if grep -qi xephyr /proc/*/cmdline 2>/dev/null; then
  _dis="Xephyr ${_res}"
else
  _dis="X11 ${_res}"
fi

# --- System basics ---
_host="$(cat /proc/sys/kernel/hostname 2>/dev/null || uname -n)"
_kernel="$(uname -r)"
_cpu="$(grep -m1 'model name' /proc/cpuinfo 2>/dev/null | cut -d: -f2 | xargs)"
[[ -z "${_cpu}" ]] && _cpu="Unknown"

# Memory from /proc/meminfo
_mem_kb="$(awk '/^MemTotal:/{print $2}' /proc/meminfo 2>/dev/null)"
if [[ -n "${_mem_kb}" ]]; then
  if (( _mem_kb >= 1048576 )); then
    _mem="$(awk "BEGIN {printf \"%.0fG\", ${_mem_kb}/1048576}")"
  else
    _mem="$(awk "BEGIN {printf \"%.0fM\", ${_mem_kb}/1024}")"
  fi
else
  _mem="Unknown"
fi

# Uptime from /proc/uptime
_uptime_sec="$(awk -F. '{print $1}' /proc/uptime 2>/dev/null)"
if [[ -n "${_uptime_sec}" ]]; then
  _days=$((_uptime_sec / 86400))
  _hours=$(((_uptime_sec % 86400) / 3600))
  _mins=$(((_uptime_sec % 3600) / 60))
  if (( _days > 0 )); then
    _uptime="${_days}d ${_hours}h ${_mins}m"
  elif (( _hours > 0 )); then
    _uptime="${_hours}h ${_mins}m"
  else
    _uptime="${_mins}m"
  fi
else
  _uptime="Unknown"
fi

_shell="$(basename "${SHELL:-/bin/sh}")"
_shell_ver=""

# GPU from /sys
_gpu="Unknown"
for p in /sys/class/drm/card*/device/vendor; do
  [[ -f "$p" ]] || continue
  _dev="$(dirname "$p")"
  _vendor="$(cat "$p" 2>/dev/null)"
  [[ "$_vendor" != "0x10de" ]] || _gpu="NVIDIA"
  break
done

# Screen from /sys
_res_str="?x?"
for fb in /sys/class/graphics/fb*/modes; do
  [[ -f "$fb" ]] || continue
  _res_str="$(head -1 "$fb" 2>/dev/null)"
  break
done

# DE/WM/theme — static for sanctuary-godzilla-xs
_de="XFCE"
_wm="xfwm4"
_wm_theme="Default"
_gtk="Default"
_icons="Default"
_font="Monospace"

# --- Output the grid ---
printf '%s\n%s\n\n' \
  "$(_col " Host        ${_host}")" \
  "$(_col " Display     ${_res_str}")"

printf '%s\n%s\n\n' \
  "$(_col " CPU         ${_cpu}")" \
  "$(_col " GPU         ${_gpu}")"

printf '%s\n%s\n\n' \
  "$(_col " Memory      ${_mem}")" \
  "$(_col " Uptime      ${_uptime}")"

printf '%s\n%s\n\n' \
  "$(_col " Kernel      ${_kernel}")" \
  "$(_col " Shell       ${_shell} ${_shell_ver}")"

printf '%s\n%s\n\n' \
  "$(_col " Desktop     ${_de}")" \
  "$(_col " WM          ${_wm}")"

printf '%s\n%s\n\n' \
  "$(_col " WM Theme    ${_wm_theme}")" \
  "$(_col " GTK         ${_gtk}")"

printf '%s\n%s\n\n' \
  "$(_col " Icons       ${_icons}")" \
  "$(_col " Font        ${_font}")"

printf '\n%s\n%s\n%s' \
  "$(_col " Habitat     ${_habitat}")" \
  "$(_col " Substrate   ${_pkg}")" \
  "$(_col " Display     ${_dis}")"
#+END_SRC
