#+TITLE: Honey sync conflicts lane: deterministic Syncthing conflict handling for Gillean
#+DESCRIPTION: An hourly cron script on Honey purges conflict copies that are byte-identical to a surviving file, converts the differing ones to text and diffs them, and surfaces them to Gillean (or Aura) as Obsidian notes with a safe resolve command.
#+AUTHOR: Honey Badger (Claude Sonnet 5.5), for Mètsàtron's DotCortex
#+LANGUAGE: en
#+PROPERTY: header-args :mkdirp yes :results silent
#+PROPERTY: header-args:bash :comments no
#+PROPERTY: header-args:python :comments no

* Why

Gillean's folders sync between Honey, her Windows PCs ("Gills", "ideacentre") and haggis. When two devices save the same file before they sync, Syncthing keeps both: the loser is renamed =NAME.sync-conflict-DATE-TIME-DEVICE.ext=. On 2026-11-02 there were 58 of them (21 in the Obsidian Vault, 37 in HEEA) and none of them is ever resolved, which overwhelms her. Mètsàtron asked (2026-11-02) for a deterministic cron job that purges byte-identical copies, diffs the rest as markdown, and surfaces them so Gillean or Aura can settle them.

Survey that shaped the design (read-only, names only, 2026-11-02): none of the 58 was byte-identical to its original. 20 of the 21 in the Obsidian Vault come from the Cowork exporter (=Cowork/_NEEDS_LOGIN.md=, =Cowork Sessions.md=, =Scripts/cowork-export/export.log=), which is written by Windows Task Scheduler on the one PC ("Gills"), not by Honey. There is no second writer: every conflict copy of =export.log= is an exact older prefix of the current log. A handler cleans up after the symptom; the cause is below. Syncthing versioning is not enabled on any folder, so a deleted file cannot be recovered from Syncthing, which is why the purge rule below is strict.

* Root cause of the Cowork conflicts (found 2026-11-02, from Syncthing's own event log and version vectors)

Each time Gills writes the Cowork files, Honey's Syncthing logs a =LocalChangeDetected= on the same files 8 to 15 minutes later, at :00:11, :15:11 or :30:11, and the file's version vector gains a Honey entry. The 15-minute rhythm is =honey-private-perms.sh= (cron =*/15=, approved 2026-09-17), which runs =chmod o-rwx= on anything in the vault with "other" bits. Syncthing wrote the received file with those bits, the script clears them, and with =ignorePerms=false= Syncthing treats that as a local edit by Honey. If Gills writes again before it has absorbed Honey's metadata-only version, the two are concurrent and Syncthing keeps the loser as =sync-conflict= (an older prefix of the log, because nothing differs in content). 61 of 80 sampled vault files carry the same Honey bump, so this is systematic and is not specific to Cowork. The exporter, the Windows side and the perms script are unchanged. Fix: =ignorePerms=true= on Honey's =obsidian-vault= and =heea= folders (applied 2026-11-02 through the REST API after backing up =config.xml= to =~/.local/state/syncthing-config.pre-ignoreperms-20261102.xml=; the installer now ensures it). The perms script still closes the files to other local accounts. *Consequence, deliberate:* genuine permission changes on Honey no longer propagate to the other devices (nor the reverse); permissions on Honey are managed locally by =honey-private-perms.sh=. Never set =ignorePerms= back to =false= to "fix" a propagation problem, because that restores this loop. Verification: after the next export (21:51 AEDT) no =LocalChangeDetected= should follow it.

* What it does

| Step | Rule |
|---|---|
| Scope | The Syncthing folders =Obsidian Vault=, =HEEA=, =Documents=, =Logseq-Gill=, =Sync=, =Pictures=. A folder is skipped unless its =.stfolder= marker exists. =Secret Vault= is not in the list and is refused by name: this job never opens it. |
| Purge | A conflict copy is deleted only when another file in the same folder has exactly the same bytes (an ordinary file first, otherwise an earlier-named conflict copy), the copy is at least 10 minutes old, the original at least 2 minutes old, and =cmp= confirms the match immediately before the unlink. So the content always survives. Every purge is logged with its sha256. At most 200 per run. |
| Clean names | A conflict copy whose original is gone is the only copy. It gets the clean name back (=NAME.ext=, no =sync-conflict= and no timestamp) by a rename that never overwrites an existing file; with several such copies the latest takes the name and the older ones stay listed as conflicts. Office =~$= lock files are skipped. Logged as =sanitised=. |
| Generated files | (Scope is deliberate: this list of three named files may not grow without Mètsàtron's word.) The Cowork exporter regenerates =Cowork/_NEEDS_LOGIN.md=, =Cowork/Cowork Sessions.md= and =Scripts/cowork-export/export.log=. For these the newest version is the truth by construction, so an old conflict copy is merged away automatically: =export.log= (append-only) when the conflict copy is an exact prefix of the main file, the two notes when the main file is at least as new. The old version goes to the 30-day trash (not deleted), and anything that does not fit the rule stays as a normal conflict. Logged as =merged-generated=. |
| Duplicates finder | =honey-sync-conflicts duplicates [--root NAME]= is read-only and on demand (not on the hourly cron). It combines two signals. *Content:* each readable document (=.docx .odt .pptx .xlsx .pdf .md .txt .rtf .csv=; read from the package files, never stored) is reduced to a sketch of its 5-word shingles, cached by path, size and mtime (hashes only, in =~/.local/state/sync-conflicts/dupcache-*.json=), so two files that overlap are found even when saved under completely different names. Shingles that occur in many documents are ignored as template text, so forms built from one template do not match each other, and a cluster larger than 8 is counted as a template cluster, not listed. *Name:* copy markers, version words, dates and trailing counters are removed from the file name; a name look-alike is kept only when the content backs it up, or when the content cannot be compared (old =.doc/.xls/.ppt=, scans, very short files). *Thresholds:* a name match plus 20% shared text (or half of the smaller file contained) counts as a heavily edited version of one file; content alone needs 55% shared text, and a content-only group with median overlap under 75% goes to a *weaker evidence* section listed last (often separate documents written from one form). Each group says how it was found. Output is =Sync Conflicts/Duplicate candidates.md= inside each folder: *revisions* (same document, real differences, with the percentage of shared text and how much of the smaller is contained in the larger), *re-saves* (same text, different bytes), *exactly the same bytes* (documents only), and *look-alike names that cannot be compared*. Noise is counted, not listed: images, plugin assets, scripts, databases, temp and Word autosave files, the generated Cowork exports and Mètsàtron's notes folder. A self-check reports how many of the real conflict pairs the content signal paired up. It never deletes, moves or renames; a candidate is a judgement and a human confirms it. Pictures are skipped unless named. |
| Review pages | =honey-sync-conflicts report [--html DIR]= (also run at the end of every hourly run) writes static HTML to =~/.local/state/sync-conflicts/review/= (mode 0700, because it names Gillean's files): an overview, *What was cleaned up* (every purge, rename and move to the trash from the log, newest first, with the trash size), each folder's open conflicts with the diff pages, and the duplicate candidates. Links are relative so the directory can sit behind any path prefix. It is read-only and starts no server: hosting it is the job of whatever fronts Honey's web apps (the planned Caddy profile for Gillean), with her login. Until then it can be viewed over an ssh tunnel: =cd ~/.local/state/sync-conflicts/review && python3 -m http.server 8765 --bind 127.0.0.1= and =ssh -L 8765:127.0.0.1:8765 honey=, then http://localhost:8765. The pages carry no resolve buttons: acting on a conflict needs an authenticated front first. |
| Secret Vault (explicit, restricted) | The hourly job, =report= and the default =duplicates= run never include the Secret Vault. =honey-sync-conflicts duplicates --root secret-vault= is the only way in, and it is *restricted*: file names, sizes and checksums only (files are read only to compute a checksum; no text is extracted, compared or stored; no content cache). It finds *exactly-the-same-bytes* groups and *name look-alikes* and writes =Secret Vault/Sync Conflicts/Duplicate candidates.md= inside the vault, stating that revisions cannot be shown; stdout carries counts only. It is not in the review pages. The full content comparison (=--content=) is for Aura alone and is refused unless =HSC_SECRET_VAULT_CONTENT=aura-only= is set, which is a speed bump and not authentication: agents other than Aura must not set it. First run 2026-11-02: 261 documents, 14 same-bytes groups, 43 look-alike groups. |
| Never purged | A conflict copy that differs from its original. Symlinks are never followed. |
| Diff | The differing pair is turned into text: markdown/text as-is, =.docx/.odt/.rtf/.epub= through =pandoc -t gfm=, =.pdf= through =pdftotext -layout=. Anything else (xlsx, ppt, edb, images) is reported as "binary" with sizes and times. A unified diff is written (300 lines max). Identical text with different bytes is reported "same text". Word/Excel =~$= lock files are reported as junk. |
| Surface | Per folder: =Sync Conflicts/Sync Conflicts.md= (a table with an id, the file, what differs, which device made the other version, when, and a link) and =Sync Conflicts/diffs/ID.md=. Notes are rewritten only when their text changes, via a Syncthing temp name, so the job does not itself create sync churn. When there are no conflicts the note says so. |
| Resolve | A conflict is two different versions of one file: the *main* file (the normal name) and the *other* version from another device. =honey-sync-conflicts resolve ID keep-main= keeps the main file and moves the other version to the trash; =keep-other= moves the main file to the trash and renames the other version to the normal name. Either way exactly one file is left, with the clean name. It is not a dedupe: identical copies are handled automatically and never need a decision. The trash is =~/.local/state/sync-conflicts/trash/=, outside every synced folder, kept 30 days. Gillean asks Aura; Aura or Mètsàtron runs the command. There is no automatic merge: without a common ancestor a three-way merge would only guess. |
| Kill switch | =touch ~/.config/sync-conflicts/DISABLED= (the job exits 3 and does nothing). |

* Boundaries

- No Secret Vault, ever. Aura has 4 conflict copies there; she handles them herself.
- The diff notes contain text from Gillean's working documents. They are written inside the same Syncthing folder as the document, never copied across folders, so no content moves to a wider audience. HEEA's notes stay in HEEA.
- Conflict copies are never deleted unless their bytes survive elsewhere. Anything else is a human or Aura decision, and the discarded side is kept for 30 days.
- Files in the folders are Gillean's. The job writes only the =Sync Conflicts/= directory in each folder and removes only byte-identical conflict copies.

* The script

#+BEGIN_SRC python :tangle all/.local/share/dotcortex/honey-sync-conflicts/bin/honey-sync-conflicts :tangle-mode (identity #o755)
#!/usr/bin/python3 -I
# honey-sync-conflicts: deterministic Syncthing conflict handling for Gillean's folders.
#
#   run [--dry-run]            purge byte-identical conflict copies, write the report notes
#   list                       print every open conflict with its id
#   report [--html DIR]        static HTML pages: cleanup ledger, open conflicts with diffs, duplicate candidates
#   duplicates [--root NAME]   read-only: find duplicate and name-variant families (same bytes under other
#                              names; "(2)", "v3", "final", date stamps) and write them to a note in each folder
#   resolve ID keep-main       the file with the normal name stays; the other version goes to the trash
#   resolve ID keep-other      the other version takes the normal name; the old one goes to the trash
#
# Never reads ~/Secret Vault. Never deletes a file on its own unless another file with the very same
# bytes survives in the same folder, checked by cmp immediately before the unlink. A conflict copy
# that is the only copy gets its clean name back (never over an existing file). Anything else
# is a human decision, and the version not chosen is kept in the trash for 30 days.
import difflib, hashlib, json, os, re, shutil, subprocess, sys, time, xml.etree.ElementTree as ET
from collections import Counter
from datetime import datetime

HOME = os.path.expanduser("~")
STATE = os.path.join(HOME, ".local/state/sync-conflicts")
LOG = os.path.join(STATE, "log")
TRASH = os.path.join(STATE, "trash")
KILL = os.path.join(HOME, ".config/sync-conflicts/DISABLED")
ROOTS = [  # (name, path) -- Secret Vault is deliberately absent and refused below
    ("obsidian-vault", "Obsidian Vault"), ("heea", "HEEA"), ("documents", "Documents"),
    ("logseq-gill", "Logseq-Gill"), ("sync", "Sync"), ("pictures", "Pictures"),
]
REPORT_DIR = "Sync Conflicts"
SKIP_DIRS = {".stfolder", ".stversions", ".git", "node_modules", REPORT_DIR}
PAT = re.compile(r"^(.*)\.sync-conflict-(\d{8}-\d{6})-([A-Z0-9]{7})(\.[^.]*)?$")
MIN_AGE = float(os.environ.get("HSC_MIN_AGE", "600"))  # a conflict copy must be this old (s)
BASE_AGE = float(os.environ.get("HSC_BASE_AGE", "120"))
MAX_PURGE = 200
# Files the Cowork exporter regenerates. For these the newest version is the truth by construction, so a
# conflict copy is merged away automatically (moved to the 30-day trash, never deleted outright):
#   append = an append-only log: merge when the conflict copy is an exact prefix of the main file
#   latest = a regenerated note/index: merge when the main file is at least as new as the conflict copy
GENERATED = {
    ("obsidian-vault", "Cowork/_NEEDS_LOGIN.md"): "latest",
    ("obsidian-vault", "Cowork/Cowork Sessions.md"): "latest",
    ("obsidian-vault", "Scripts/cowork-export/export.log"): "append",
}
TEXT_EXT = {".md", ".txt", ".log", ".csv", ".tsv", ".json", ".yaml", ".yml", ".org", ".py", ".sh", ".html", ".htm"}
PANDOC_EXT = {".docx": "docx", ".odt": "odt", ".rtf": "rtf", ".epub": "epub"}
MAX_BYTES = 8 * 1024 * 1024
MAX_DIFF_LINES = 300
MAX_NOTES = 300


def log(msg):
    os.makedirs(STATE, mode=0o700, exist_ok=True)
    if os.path.exists(LOG) and os.path.getsize(LOG) > 1_000_000:
        os.replace(LOG, LOG + ".1")
    with open(LOG, "a") as f:
        f.write(f"{datetime.now():%Y-%m-%d %H:%M:%S} {msg}\n")


def roots():
    out = []
    for name, rel in ROOTS:
        p = os.path.join(HOME, rel)
        if "Secret Vault" in p:
            continue
        if os.path.isdir(os.path.join(p, ".stfolder")):  # not a live Syncthing folder -> skip
            out.append((name, p))
    return out


def devices():
    for cfg in (".local/state/syncthing/config.xml", ".config/syncthing/config.xml"):
        try:
            return {d.get("id")[:7]: d.get("name") for d in ET.parse(os.path.join(HOME, cfg)).getroot().iter("device")}
        except Exception:
            continue
    return {}


def sha(path):
    h = hashlib.sha256()
    with open(path, "rb") as f:
        for b in iter(lambda: f.read(1 << 20), b""):
            h.update(b)
    return h.hexdigest()


def same_bytes(a, b):
    try:
        return os.path.getsize(a) == os.path.getsize(b) and subprocess.run(["cmp", "-s", a, b]).returncode == 0
    except OSError:
        return False


def scan(root):
    """Yield (dirpath, files) for every folder, skipping bookkeeping dirs and symlinks."""
    for d, dirs, files in os.walk(root):
        dirs[:] = [x for x in dirs if x not in SKIP_DIRS and not os.path.islink(os.path.join(d, x))]
        yield d, [f for f in files if not os.path.islink(os.path.join(d, f)) and not f.startswith(".syncthing.")]


def cid(root_name, rel):
    return hashlib.sha1(f"{root_name}\0{rel}".encode()).hexdigest()[:8]


def purge_identical(root_name, root, dry):
    """Delete conflict copies whose bytes survive in another file of the same folder."""
    purged = []
    now = time.time()
    for d, files in scan(root):
        conflicts = sorted(f for f in files if PAT.match(f))
        if not conflicts:
            continue
        others = [f for f in files if not PAT.match(f)]
        alive = set(files)
        for c in conflicts:
            cp = os.path.join(d, c)
            if now - os.path.getmtime(cp) < MIN_AGE:
                continue
            m = PAT.match(c)
            base = m.group(1) + (m.group(4) or "")
            if base in alive and now - os.path.getmtime(os.path.join(d, base)) < BASE_AGE:
                continue
            # keepers: any ordinary file first, then an earlier-named conflict copy still alive
            cands = [f for f in others if f in alive] + [f for f in conflicts if f < c and f in alive]
            size = os.path.getsize(cp)
            keeper = next((k for k in cands if os.path.getsize(os.path.join(d, k)) == size
                           and same_bytes(os.path.join(d, k), cp)), None)
            if not keeper:
                continue
            if len(purged) >= MAX_PURGE:
                log(f"purge cap {MAX_PURGE} reached in {root_name}, rest next run")
                return purged
            rel = os.path.relpath(cp, root)
            if dry:
                purged.append((rel, keeper))
                continue
            if not same_bytes(os.path.join(d, keeper), cp):  # last look before the unlink
                continue
            digest = sha(cp)
            os.unlink(cp)
            alive.discard(c)
            log(f"purged {root_name}:{rel} identical to {keeper} sha256={digest}")
            purged.append((rel, keeper))
    return purged


def sanitise_orphans(root_name, root, dry):
    """A conflict copy whose original is gone is the only copy: give it the clean name back."""
    now = time.time()
    done = []
    for d, files in scan(root):
        groups = {}
        for f in files:
            m = PAT.match(f)
            if not m:
                continue
            base = m.group(1) + (m.group(4) or "")
            if base in files or base.startswith("~$"):  # original exists, or an Office lock file
                continue
            if now - os.path.getmtime(os.path.join(d, f)) < MIN_AGE:
                continue
            groups.setdefault(base, []).append((m.group(2), f))
        for base, items in groups.items():
            stamp, newest = max(items)  # the latest version takes the name; older ones stay as conflicts
            src, dst = os.path.join(d, newest), os.path.join(d, base)
            if os.path.lexists(dst):
                continue
            rel = os.path.relpath(dst, root)
            if not dry:
                os.rename(src, dst)
                log(f"sanitised {root_name}:{os.path.relpath(src, root)} -> {rel} (original was gone)")
            done.append((os.path.relpath(src, root), rel))
    return done


def merge_generated(root_name, root, dry):
    """Settle conflict copies of files the Cowork exporter regenerates, per the GENERATED rules."""
    now = time.time()
    done = []
    for p in pairs(root_name, root):
        rule = GENERATED.get((root_name, p["rel"]))
        if not rule or not p["current"] or now - os.path.getmtime(p["conflict"]) < MIN_AGE:
            continue
        cur, con = p["current"], p["conflict"]
        if rule == "append":
            if os.path.getsize(con) > os.path.getsize(cur):
                continue
            with open(cur, "rb") as a, open(con, "rb") as b:
                ok = all(a.read(len(chunk)) == chunk for chunk in iter(lambda: b.read(1 << 20), b""))
        else:
            ok = os.path.getmtime(cur) >= os.path.getmtime(con)
        if not ok:
            continue
        if not dry:
            dest = trash(root_name, root, con)
            log(f"merged-generated {root_name}:{os.path.relpath(con, root)} ({rule}); old version in trash {dest}")
        done.append(os.path.relpath(con, root))
    return done


def pairs(root_name, root):
    """Open conflicts: dicts with id, rel, current path (or None), conflict path, device, stamp."""
    devs = devices()
    out = []
    for d, files in scan(root):
        for f in files:
            m = PAT.match(f)
            if not m:
                continue
            base = m.group(1) + (m.group(4) or "")
            cp, bp = os.path.join(d, f), os.path.join(d, base)
            stamp = datetime.strptime(m.group(2), "%Y%m%d-%H%M%S")
            out.append(dict(id=cid(root_name, os.path.relpath(cp, root)), root=root_name, rootpath=root,
                            rel=os.path.relpath(bp, root), conflict=cp, current=bp if os.path.exists(bp) else None,
                            device=devs.get(m.group(3), m.group(3)), stamp=stamp))
    out.sort(key=lambda p: (p["rel"], p["stamp"]))
    return out


def to_text(path):
    ext = os.path.splitext(path)[1].lower()
    try:
        if os.path.getsize(path) > MAX_BYTES:
            return None
        if ext in TEXT_EXT:
            with open(path, "rb") as f:
                raw = f.read()
            return None if b"\0" in raw[:8192] else raw.decode("utf-8", "replace")
        if ext in PANDOC_EXT:
            r = subprocess.run(["pandoc", "-f", PANDOC_EXT[ext], "-t", "gfm", "--wrap=none", path],
                               capture_output=True, text=True, timeout=45)
            return r.stdout if r.returncode == 0 else None
        if ext == ".pdf":
            r = subprocess.run(["pdftotext", "-layout", path, "-"], capture_output=True, text=True, timeout=45)
            return r.stdout if r.returncode == 0 else None
    except (OSError, subprocess.TimeoutExpired):
        pass
    return None


def fmt(ts):
    return datetime.fromtimestamp(ts).strftime("%Y-%m-%d %H:%M")


def describe(p):
    """Return (verdict, diff note body)."""
    cp = p["conflict"]
    if os.path.basename(p["rel"]).startswith("~$"):
        return "Office lock file", "\n".join([f"# {os.path.basename(p['rel'])}", "",
            f"Conflict id: `{p['id']}`. This is the temporary lock file Word or Excel leaves while a document is open, "
            "not a document. It is safe to discard.", ""])
    head = [f"# {os.path.basename(p['rel'])}", "", f"Folder: `{os.path.dirname(p['rel']) or '.'}`", "",
            f"Conflict id: `{p['id']}`. The second version was made by **{p['device']}** at "
            f"{p['stamp']:%Y-%m-%d %H:%M} and kept next to the file instead of overwriting it.", ""]
    if not p["current"]:
        size = os.path.getsize(cp)
        return "only copy", "\n".join(head + [
            "The original file is no longer there (renamed, moved or deleted on another device), so this "
            f"conflict copy ({size} bytes, saved {fmt(os.path.getmtime(cp))}) is the only copy. Nothing to compare.", ""])
    cur = p["current"]
    head += ["| | Size | Last saved |", "|---|---|---|",
             f"| Main file (normal name) | {os.path.getsize(cur)} bytes | {fmt(os.path.getmtime(cur))} |",
             f"| Other version ({p['device']}) | {os.path.getsize(cp)} bytes | {fmt(os.path.getmtime(cp))} |", ""]
    a, b = to_text(cur), to_text(cp)
    if a is None or b is None:
        return "binary", "\n".join(head + [
            "This kind of file cannot be shown as text. Open both versions and keep the one you want.", ""])
    if a == b:
        return "same text", "\n".join(head + [
            "The text is the same in both versions; only hidden file details differ (formatting, metadata or "
            "timestamps). Safe to keep either one.", ""])
    lines = list(difflib.unified_diff(a.splitlines(), b.splitlines(), "current", f"conflict ({p['device']})", lineterm="", n=2))
    added = sum(1 for l in lines if l.startswith("+") and not l.startswith("+++"))
    removed = sum(1 for l in lines if l.startswith("-") and not l.startswith("---"))
    body = lines[:MAX_DIFF_LINES]
    if len(lines) > MAX_DIFF_LINES:
        body.append(f"... {len(lines) - MAX_DIFF_LINES} more diff lines not shown")
    return f"text differs (+{added}/-{removed})", "\n".join(head + [
        "Lines starting with `-` are only in the main file; lines starting with `+` are only in the other version.",
        "", "```diff", *body, "```", ""])


def write_if_changed(path, text):
    if os.path.exists(path):
        with open(path, encoding="utf-8") as f:
            if f.read() == text:
                return False
    os.makedirs(os.path.dirname(path), exist_ok=True)
    tmp = os.path.join(os.path.dirname(path), f".syncthing.{os.path.basename(path)}.tmp")
    with open(tmp, "w", encoding="utf-8") as f:
        f.write(text)
    os.chmod(tmp, 0o640)
    os.replace(tmp, path)
    return True


def report(root_name, root, plist):
    rd = os.path.join(root, REPORT_DIR)
    dd = os.path.join(rd, "diffs")
    keep = set()
    rows = []
    for p in plist[:MAX_NOTES]:
        verdict, body = describe(p)
        note = f"{p['id']}.md"
        keep.add(note)
        write_if_changed(os.path.join(dd, note), "---\ntags:\n  - sync-conflicts\n---\n\n" + body)
        rows.append((p, verdict, note))
    if not plist and not os.path.isdir(rd):
        return 0
    if os.path.isdir(dd):
        for f in os.listdir(dd):
            if f not in keep:
                os.unlink(os.path.join(dd, f))
    order = {"text differs": 0, "same text": 1, "binary": 2, "only copy": 3, "Office lock file": 4}
    rows.sort(key=lambda r: (order.get(r[1].split(" (")[0], 9), r[0]["rel"]))
    out = ["---", "tags:", "  - sync-conflicts", *(["  - action-required"] if plist else []), "---", "", "# Sync conflicts", ""]
    if not plist:
        out.append("No open sync conflicts. Nothing needs doing.")
    else:
        out += [f"{len(plist)} file(s) have two versions because two devices saved the same file before they synced. "
                "Nothing has been lost: both versions are kept. Files that were byte-for-byte identical have "
                "already been tidied away automatically.", "",
                "Each one is two different versions of the same file: the one with the normal name (the *main* file) and the "
                "*other* version saved by another device. To settle one, ask Aura: *resolve sync conflict `ID`, keep the "
                "main file* (or *keep the other version*). Whichever you choose ends up with the normal name; the version "
                "you do not choose is held for 30 days before it is deleted.", "",
                "| ID | File | What differs | Other version from | Made | Diff |", "|---|---|---|---|---|---|"]
        for p, v, note in rows:
            name = p["rel"].replace("|", "\\|")
            out.append(f"| `{p['id']}` | {name} | {v} | {p['device']} | {p['stamp']:%Y-%m-%d %H:%M} | "
                       f"[[{REPORT_DIR}/diffs/{note[:-3]}|diff]] |")
        if len(plist) > MAX_NOTES:
            out += ["", f"{len(plist) - MAX_NOTES} more not listed; run `honey-sync-conflicts list`."]
    write_if_changed(os.path.join(rd, "Sync Conflicts.md"), "\n".join(out) + "\n")
    return len(plist)


def expire_trash():
    cutoff = time.time() - 30 * 86400
    if not os.path.isdir(TRASH):
        return
    for r in os.listdir(TRASH):
        for stampdir in os.listdir(os.path.join(TRASH, r)):
            p = os.path.join(TRASH, r, stampdir)
            if os.path.getmtime(p) < cutoff:
                shutil.rmtree(p)
                log(f"trash expired {r}/{stampdir}")


def trash(root_name, root, path):
    dest = os.path.join(TRASH, root_name, datetime.now().strftime("%Y%m%d-%H%M%S"), os.path.relpath(path, root))
    os.makedirs(os.path.dirname(dest), mode=0o700, exist_ok=True)
    shutil.move(path, dest)
    return dest


def cmd_run(dry):
    if os.path.exists(KILL):
        print("disabled (kill switch)")
        return 3
    total_p = total_c = 0
    for name, root in roots():
        purged = purge_identical(name, root, dry)
        renamed = sanitise_orphans(name, root, dry)
        merged = merge_generated(name, root, dry)
        plist = pairs(name, root)
        if dry:  # the dry run reports what would be settled but the pairs list is still the pre-run view
            plist = [q for q in plist if os.path.relpath(q["conflict"], root) not in merged]
        if not dry:
            report(name, root, plist)
        total_p += len(purged)
        total_c += len(plist)
        print(f"{name}: purged {len(purged)} identical, renamed {len(renamed)} to clean names, "
              f"merged {len(merged)} generated, {len(plist)} open"
              f"{' (dry run)' if dry else ''}")
    if not dry:
        expire_trash()
        try:
            cmd_report([])
        except Exception as e:  # the pages are a convenience; a rendering problem must never fail the clean-up run
            log(f"report pages failed: {type(e).__name__}: {e}")
    print(f"total: purged {total_p}, open {total_c}")
    return 0

def cmd_resolve(pid, choice, dry):
    if choice not in ("keep-main", "keep-other"):
        print("choice must be keep-main or keep-other")
        return 2
    for name, root in roots():
        for p in pairs(name, root):
            if p["id"] != pid:
                continue
            base = os.path.join(root, p["rel"])
            if choice == "keep-main" and not p["current"]:
                print("the normal-named file is missing; use keep-other to give the other version its name")
                return 2
            if dry:
                print(f"would {choice} {name}:{p['rel']}")
                return 0
            if choice == "keep-main":
                dest = trash(name, root, p["conflict"])
            else:
                dest = trash(name, root, base) if p["current"] else "-"
                os.replace(p["conflict"], base)
            log(f"resolved {name}:{p['rel']} {choice} (discarded copy in trash: {dest})")
            report(name, root, pairs(name, root))
            print(f"done: {choice} {name}:{p['rel']}")
            return 0
    print(f"no open conflict with id {pid}")
    return 1


# ---- duplicate / overlap finder (read-only; never deletes, moves or renames anything) ---------------------
# Two independent signals are combined: (1) the file NAME with copy markers, version words and dates removed, and
# (2) the file CONTENT, as a small sketch of 5-word shingles (no text is stored), so two files that overlap are found
# even when they were saved under completely different names. Name look-alikes only count as the same document when
# the content backs them up; content overlap needs no name match.
NOISE = [  # stripped, in this order, from a lower-cased stem to find files that are variants of one document
    r"\.sync-conflict-\d{8}-\d{6}-[a-z0-9]{7}", r"\bcopy( of)?\b", r"\(\d+\)", r"\b(final|draft|latest|new|old|backup|bak|signed|revised?|updated?|edited?)\b",
    r"\bv(er(sion)?)?\.? ?\d+(\.\d+)*\b", r"\brev\.? ?[a-z0-9]\b", r"\b\d{4}[-_. ]\d{1,2}[-_. ]\d{1,2}\b", r"\b\d{1,2}[-_. ]\d{1,2}[-_. ]\d{2,4}\b",
    r"\b(19|20)\d{2}[-_. ]\d{2}\b", r"\b\d{8}\b", r"\b\d{6}\b",
    r"\b\d{1,2} (jan|feb|mar|apr|may|jun|jul|aug|sep|sept|oct|nov|dec)[a-z]* (19|20)?\d{2,4}\b",
    r"\b(jan|feb|mar|apr|may|jun|jul|aug|sep|sept|oct|nov|dec)[a-z]*\.? ?(19|20)?\d{0,4}\b", r"\b(19|20)\d{2}\b", r"\s-?\s?\d{1,2}$",
]
NOISE_RE = [re.compile(x) for x in NOISE]
DUP_SKIP_DIRS = SKIP_DIRS | {".obsidian", ".trash", "__pycache__", "FileHistory", "plugins", "themes", "snippets", "site-packages", "dist-packages"}
# Never listed: generated exports, Mètsàtron's own niche, and the report folder itself.
DUP_SKIP_PATHS = ("Cowork/", "Scripts/cowork-export/", "Metsatron - IT & Tech Notes/", REPORT_DIR + "/")
TEXT_KINDS = {".docx", ".odt", ".pptx", ".xlsx", ".ods", ".odp", ".pdf", ".md", ".txt", ".rtf", ".csv"}   # content can be compared
UNREADABLE_DOCS = {".doc", ".xls", ".ppt"}                                                                # documents, content cannot be read
NOISE_EXT = {".css", ".svg", ".js", ".mjs", ".map", ".py", ".json", ".yml", ".yaml", ".conf", ".cfg", ".ini", ".dll", ".exe", ".tmp", ".asd",
             ".wbk", ".download", ".bak", ".lock", ".db", ".edb", ".log", ".kdbx", ".ttf", ".woff", ".woff2", ".html", ".htm", ".url", ".lnk",
             ".sqlite", ".png", ".jpg", ".jpeg", ".gif", ".webp", ".heic", ".bmp", ".mp3", ".mp4", ".mov", ".zip", ".sh", ".bat", ".ps1"}
K = 400            # sketch size (bottom-K of the shingle hashes)
SHINGLE = 5        # words per shingle
MIN_WORDS = 40     # shorter documents are too small to judge by content
J_RESAVE, J_OVERLAP, C_OVERLAP = 0.97, 0.55, 0.85
J_NAME_BACKED, C_NAME_BACKED = 0.20, 0.50
J_STRONG = 0.75   # content-only matches (different names) below this median overlap go to the weaker tier   # lower bar when the names also match: a heavily edited version of the same file
GENERIC = 12       # a name family bigger than this is a generic name (templates, indexes)
MAX_GROUP = 8      # a content cluster bigger than this is a set of forms built from one template, not versions of one document


def family_key(name):
    stem, ext = os.path.splitext(name)
    t = stem.lower()
    for rx in NOISE_RE:
        t = rx.sub(" ", t)
    t = re.sub(r"[\W_]+", " ", t).strip()
    return (t, ext.lower())


def _strip_xml(x):
    import html
    x = re.sub(r"</w:p>|<w:br[^>]*/>|<w:tab/>|</text:p>|</a:p>", " ", x)
    return html.unescape(re.sub(r"<[^>]+>", " ", x))


def doc_text(path, ext):
    """Plain text of a document for fingerprinting; never stored. None if it cannot be read."""
    import zipfile
    try:
        if os.path.getsize(path) > MAX_BYTES:
            return None
        if ext in (".md", ".txt", ".csv"):
            return open(path, encoding="utf-8", errors="replace").read(2_000_000)
        if ext == ".pdf":
            r = subprocess.run(["pdftotext", "-q", path, "-"], capture_output=True, text=True, timeout=40)
            return r.stdout if r.returncode == 0 else None
        if ext == ".rtf":
            r = subprocess.run(["pandoc", "-f", "rtf", "-t", "plain", path], capture_output=True, text=True, timeout=40)
            return r.stdout if r.returncode == 0 else None
        with zipfile.ZipFile(path) as z:
            names = z.namelist()
            if ext == ".docx":
                return _strip_xml(z.read("word/document.xml").decode("utf-8", "replace"))
            if ext == ".pptx":
                sl = sorted((n for n in names if re.match(r"ppt/slides/slide\d+\.xml$", n)), key=lambda n: int(re.search(r"(\d+)", n).group(1)))
                return " ".join(" ".join(re.findall(r"<a:t>([^<]*)</a:t>", z.read(n).decode("utf-8", "replace"))) for n in sl)
            if ext == ".xlsx":
                return _strip_xml(z.read("xl/sharedStrings.xml").decode("utf-8", "replace")) if "xl/sharedStrings.xml" in names else ""
            if ext in (".odt", ".ods", ".odp"):
                return _strip_xml(z.read("content.xml").decode("utf-8", "replace"))
    except Exception:
        return None
    return None


def sketch_of(text):
    import zlib
    w = re.findall(r"[a-z0-9]+", text.lower())
    if len(w) < MIN_WORDS:
        return None
    sh = {zlib.crc32(" ".join(w[i:i + SHINGLE]).encode()) for i in range(len(w) - SHINGLE + 1)}
    return sorted(sh)[:K], len(sh)


def load_cache(root_name):
    try:
        with open(os.path.join(STATE, f"dupcache-{root_name}.json")) as f:
            return json.load(f)
    except (OSError, ValueError):
        return {}


def save_cache(root_name, cache):
    os.makedirs(STATE, mode=0o700, exist_ok=True)
    tmp = os.path.join(STATE, f"dupcache-{root_name}.json.tmp")
    with open(tmp, "w") as f:
        json.dump(cache, f)
    os.replace(tmp, os.path.join(STATE, f"dupcache-{root_name}.json"))


def overlap(a, b, na, nb):
    """(jaccard, containment) of two sketches; containment only when both sketches are the full shingle sets."""
    A, B = set(a), set(b)
    if na <= K and nb <= K:
        inter = len(A & B)
        return inter / max(1, len(A | B)), inter / max(1, min(len(A), len(B)))
    union = sorted(A | B)[:K]
    return sum(1 for v in union if v in A and v in B) / max(1, len(union)), None


def duplicates(root_name, root, budget=1200, content=True):
    files, filtered = [], Counter()
    for d, ds, fs in os.walk(root):
        ds[:] = [x for x in ds if x not in DUP_SKIP_DIRS and not os.path.islink(os.path.join(d, x))]
        for f in fs:
            fp = os.path.join(d, f)
            rel = os.path.relpath(fp, root)
            ext = os.path.splitext(f)[1].lower()
            if os.path.islink(fp) or f.startswith((".syncthing.", "~$", ".")) or f in ("desktop.ini", "Thumbs.db"):
                filtered["temp/system files"] += 1
                continue
            if rel.startswith(DUP_SKIP_PATHS):
                filtered["generated or not Gillean's (Cowork exports, Metsatron's notes)"] += 1
                continue
            if ext in NOISE_EXT or (ext not in TEXT_KINDS and ext not in UNREADABLE_DOCS):
                filtered["other file types (images, plugin assets, scripts, databases...)"] += 1
                continue
            try:
                st = os.stat(fp)
            except OSError:
                continue
            files.append((rel, ext, st.st_size, st.st_mtime))
    meta = {rel: (ext, size, mt) for rel, ext, size, mt in files}
    # same bytes, any name or folder (documents only)
    by_size = {}
    for rel, ext, size, mt in files:
        if size > 0:
            by_size.setdefault(size, []).append(rel)
    by_hash = {}
    for size, rels in by_size.items():
        if len(rels) > 1:
            for rel in rels:
                try:
                    by_hash.setdefault(sha(os.path.join(root, rel)), []).append(rel)
                except OSError:
                    pass
    exact = [sorted(r) for r in by_hash.values() if len(r) > 1]
    digest_of = {rel: h for h, rs in by_hash.items() for rel in rs}
    # content sketches (cached by path, size and mtime; the cache holds hashes only, never text)
    cache, deadline, fresh, skipped_budget = (load_cache(root_name) if content else {}), time.time() + budget, 0, 0
    sk = {}
    for rel, ext, size, mt in files:
        if not content or ext not in TEXT_KINDS:   # content=False: names, sizes and checksums only, no text is read
            continue
        c = cache.get(rel)
        if c and c[0] == size and c[1] == mt:
            if c[2]:
                sk[rel] = (c[2], c[3])
            continue
        if time.time() > deadline:
            skipped_budget += 1
            continue
        txt = doc_text(os.path.join(root, rel), ext)
        got = sketch_of(txt) if txt else None
        cache[rel] = [size, mt, got[0] if got else None, got[1] if got else 0]
        fresh += 1
        if got:
            sk[rel] = got
    if content:
        save_cache(root_name, {k: v for k, v in cache.items() if k in meta})
    # boilerplate: a shingle hash present in many documents is template text, not shared content
    df = Counter(v for a, _ in sk.values() for v in a)
    cap = max(5, int(0.003 * max(1, len(sk))))
    boiler = {v for v, n in df.items() if n > cap}
    clean = {rel: ([v for v in a if v not in boiler], n) for rel, (a, n) in sk.items()}
    inv = {}
    for rel, (a, n) in clean.items():
        for v in a:
            inv.setdefault(v, []).append(rel)
    cand = Counter()
    for v, rels in inv.items():
        if 1 < len(rels) <= cap:
            for i in range(len(rels)):
                for j in range(i + 1, len(rels)):
                    cand[(rels[i], rels[j])] += 1
    fam = {}
    for rel, ext, size, mt in files:
        key = family_key(os.path.basename(rel))
        if key[0] and len(key[0]) >= 4:
            fam.setdefault(key, []).append(rel)
    parent = {}
    def find(x):
        while parent.setdefault(x, x) != x:
            parent[x] = parent[parent[x]]; x = parent[x]
        return x
    pair_stats = {}
    for (x, y), shared in cand.items():
        (ax, nx), (ay, ny) = clean[x], clean[y]
        if shared < max(8, 0.2 * min(len(ax), len(ay))) or len(ax) < 8 or len(ay) < 8:
            continue
        j, c = overlap(ax, ay, nx, ny)
        if j >= J_OVERLAP or (c is not None and c >= C_OVERLAP):
            pair_stats[(x, y)] = (j, c)
            parent[find(x)] = find(y)
    # name AND content: the same name pattern needs only partial overlap (a heavily edited version of one file)
    name_backed = set()
    for key, mem in fam.items():
        rd = [m for m in mem if m in clean and len(clean[m][0]) >= 8]
        if 2 <= len(mem) <= MAX_GROUP and len(rd) >= 2:
            for i in range(len(rd)):
                for j2 in range(i + 1, len(rd)):
                    x, y = rd[i], rd[j2]
                    if (x, y) in pair_stats or (y, x) in pair_stats:
                        continue
                    j, c = overlap(clean[x][0], clean[y][0], clean[x][1], clean[y][1])
                    if j >= J_NAME_BACKED or (c is not None and c >= C_NAME_BACKED):
                        pair_stats[(x, y)] = (j, c)
                        name_backed.add((x, y))
                        parent[find(x)] = find(y)
    groups = {}
    for rel in {r for pr in pair_stats for r in pr}:
        groups.setdefault(find(rel), []).append(rel)
    content_groups, template_clusters = [], []
    for members in groups.values():
        if len(members) > MAX_GROUP:
            template_clusters.append(len(members))
            continue
        members.sort(key=lambda r: -meta[r][2])
        newest = members[0]
        rows = []
        for rel in members:
            if rel == newest:
                rows.append((rel, meta[rel][1], meta[rel][2], "newest", None))
                continue
            key = (newest, rel) if (newest, rel) in pair_stats else (rel, newest)
            if key in pair_stats:
                j, c = pair_stats[key]
            else:
                j, c = overlap(*clean[newest][:1], *clean[rel][:1], clean[newest][1], clean[rel][1])
            if digest_of.get(rel) and digest_of.get(rel) == digest_of.get(newest):
                note = "byte-identical to newest"
            else:
                note = f"{round(100 * j)}% shared text" + (f", {round(100 * c)}% of the smaller is contained" if c is not None else "")
            rows.append((rel, meta[rel][1], meta[rel][2], note, j))
        js = [r[4] for r in rows if r[4] is not None]
        kind = "re-save" if js and min(js) >= J_RESAVE else "revision"
        found = "same name pattern and content" if len({family_key(os.path.basename(r[0])) for r in rows}) == 1 else "content only, different names: check these more carefully"
        med = sorted(js)[len(js) // 2] if js else 0
        if kind == "revision" and found.startswith("content only") and med < J_STRONG:
            kind = "weak"
        content_groups.append((kind, rows, found))
    content_groups.sort(key=lambda g: ({"revision": 0, "re-save": 1, "weak": 2}[g[0]], g[2].startswith("content only"), -g[1][0][2]))
    # name look-alikes: kept only if content backs them up, or content cannot be read
    in_content = {r[0] for _, rows, _ in content_groups for r in rows}
    name_only, lookalike_only, generic = [], 0, 0
    for key, mem in fam.items():
        if len(mem) < 2:
            continue
        if len(mem) > GENERIC:
            generic += 1
            continue
        mem = sorted(mem, key=lambda r: -meta[r][2])
        if all(m in in_content for m in mem):
            continue
        readable = [m for m in mem if m in sk]
        if len(readable) == len(mem):
            lookalike_only += 1      # content is readable and does NOT overlap: similar names, different documents
        else:
            name_only.append((key, mem))   # at least one member cannot be compared by content
    stats = dict(scanned=len(files), fresh=fresh, deferred=skipped_budget, readable=len(sk), boilerplate=len(boiler), generic=generic,
                 lookalike_only=lookalike_only, filtered=filtered, template_clusters=template_clusters)
    return exact, content_groups, name_only, stats, meta, pair_stats


def write_duplicates(root_name, root, exact, cgroups, name_only, stats, meta, restricted=False):
    def esc(r):
        return r.replace("|", "\\|")
    def table(rows):
        t = ["| File | Size | Last saved | Compared with the newest |", "|---|---|---|---|"]
        for rel, size, mt, note, _ in rows:
            t.append(f"| {esc(rel)} | {size} | {fmt(mt)} | {note} |")
        return t
    rev = [g for g in cgroups if g[0] == "revision"]
    res = [g for g in cgroups if g[0] == "re-save"]
    weak = [g for g in cgroups if g[0] == "weak"]
    doc_exact = [g for g in exact if len(g) > 1]
    L = ["---", "tags:", "  - sync-conflicts", "  - duplicates", "---", "", "# Duplicate candidates", ""]
    if restricted:
        L += ["**Clinical vault, restricted run.** This report was made from file names, sizes and checksums only. Files were read only to "
              "compute a checksum; no text was extracted or compared, so *revisions* (same document, different content) cannot be shown "
              "here. Only Aura may run the full comparison on this folder.", ""]
    L += [f"Read-only report. Nothing has been changed, moved or deleted. {stats['scanned']} documents scanned; {stats['readable']} could be read "
         "and compared by content. A *candidate* is a judgement from content and names, so a human confirms it. Files are matched by what they "
         "say (so a document saved under a different name is still found) and by name (copy markers like `(2)`, version words like `v3` or "
         "`final`, and dates are ignored). Template text that appears in many documents is ignored, so forms built from one template do not "
         "match each other.", "",
         f"- **Revisions: the same document with real differences:** {len(rev)} groups. Look at these first.",
         f"- **Re-saves: the same text, saved again (different file bytes):** {len(res)} groups.",
         f"- **Possible overlaps, weaker evidence** (different names, only {round(100 * J_OVERLAP)}-{round(100 * J_STRONG)}% shared text; often forms built from a template): {len(weak)} groups, listed last.",
         f"- Of the revisions, {sum(1 for g in rev if g[2].startswith('content only'))} were found by content alone, under different names; the rest match on name and content.",
         f"- **Exactly the same bytes under different names or folders:** {len(doc_exact)} groups.",
         f"- **Name look-alikes whose content cannot be compared** (old `.doc`/`.xls`/`.ppt`, scans, very short files): {len(name_only)} groups.",
         f"- Left out as noise: {stats['lookalike_only']} groups with similar names but clearly different content; {stats['generic']} generic names "
         f"(too many to be one document); {len(stats['template_clusters'])} clusters of forms built from one template "
         f"({sum(stats['template_clusters'])} files); " + "; ".join(f"{n} {k}" for k, n in stats['filtered'].items()) + ".", ""]
    L += ["## Revisions: the same document with real differences", ""]
    for i, (_, rows, found) in enumerate(rev, 1):
        L += [f"### {i}. {os.path.basename(rows[0][0])}", "", f"Found by: {found}.", ""] + table(rows) + [""]
    L += ["## Re-saves: the same text, saved again", ""]
    for i, (_, rows, found) in enumerate(res, 1):
        L += [f"### {i}. {os.path.basename(rows[0][0])}", "", f"Found by: {found}.", ""] + table(rows) + [""]
    L += ["## Possible overlaps, weaker evidence", "", "Different file names and only partly shared text. Many will be separate documents written from the same template or form; some will be real versions. Check these last.", ""]
    for i, (_, rows, found) in enumerate(weak, 1):
        L += [f"### {i}. {os.path.basename(rows[0][0])}", ""] + table(rows) + [""]
    L += ["## Exactly the same bytes", ""]
    for i, rels in enumerate(sorted(doc_exact, key=lambda g: (-len(g), g[0])), 1):
        L += [f"{i}. " + "; ".join(esc(r) for r in rels)]
    L += ["", "## Look-alike names, content could not be compared", ""]
    for i, (key, mem) in enumerate(sorted(name_only, key=lambda x: -meta[x[1][0]][2]), 1):
        L += [f"{i}. " + "; ".join(f"{esc(r)} ({fmt(meta[r][2])})" for r in mem)]
    write_if_changed(os.path.join(root, REPORT_DIR, "Duplicate candidates.md"), "\n".join(L) + "\n")
    return len(rev), len(res), len(doc_exact), len(name_only)

        else:
            restricted = True
        todo = [("secret-vault", sv)]
    for name, root in todo:
        if (name == "pictures" and only != "pictures") or (only and name != only):
            continue
        exact, cgroups, name_only, stats, meta, pair_stats = duplicates(name, root, content=not restricted)
        rev, res, ex, no = write_duplicates(name, root, exact, cgroups, name_only, stats, meta, restricted=restricted)
        if restricted:
            print(f"{name}: RESTRICTED run (file names, sizes and checksums only; no text was extracted or compared). scanned {stats['scanned']} documents; "
                  f"identical-bytes groups {ex}; name look-alike groups {no}; noise left out: {stats['generic']} generic, "
                  f"{sum(stats['filtered'].values())} other files. Report written inside the vault.")
            continue
        # self-check: of the conflict pairs that still exist and are readable, how many did the content signal pair up?
        truth = [p for p in pairs(name, root) if p["current"]]
        got = tot = 0
        in_groups = {}
        for gi, (_, rows, _f) in enumerate(cgroups):
            for r in rows:
                in_groups[r[0]] = gi
        for p in truth:
            a, b = os.path.relpath(p["current"], root), os.path.relpath(p["conflict"], root)
            if os.path.splitext(a)[1].lower() in TEXT_KINDS and a in meta and b in meta:
                tot += 1
                got += 1 if (a in in_groups and in_groups.get(a) == in_groups.get(b)) else 0
        print(f"{name}: scanned {stats['scanned']} documents ({stats['readable']} readable, {stats['fresh']} newly read, {stats['deferred']} deferred); "
              f"revisions {rev}, re-saves {res}, same-bytes {ex}, name-only {no}; noise left out: {stats['lookalike_only']} look-alikes, "
              f"{stats['generic']} generic, {len(stats['template_clusters'])} template clusters, {sum(stats['filtered'].values())} other files; boilerplate hashes ignored {stats['boilerplate']}; "
              f"self-check on conflict pairs: {got}/{tot} found by content")
    return 0

def _page(title, body, crumbs=True, up=""):

def _md_html(path, rel_prefix):
    """Markdown note -> HTML fragment via pandoc, with Obsidian wikilinks turned into relative links."""
    with open(path, encoding="utf-8") as f:
        text = f.read()
    text = re.sub(r"^---\n.*?\n---\n", "", text, count=1, flags=re.S)
    text = re.sub(r"\[\[Sync Conflicts/diffs/([0-9a-f]{8})\|diff\]\]", lambda m: f"[diff]({rel_prefix}diffs/{m.group(1)}.html)", text)
    r = subprocess.run(["pandoc", "-f", "gfm", "-t", "html"], input=text, capture_output=True, text=True, timeout=120)
    return r.stdout if r.returncode == 0 else "<p>(could not render this note)</p>"


def ledger_rows():
    rows = []
    try:
        lines = open(LOG, encoding="utf-8", errors="replace").read().splitlines()
    except OSError:
        return rows
    for l in lines:
        m = re.match(r"(\S+ \S+) (purged|sanitised|merged-generated|resolved|trash expired)\s*(.*)", l)
        if not m:
            continue
        when, act, rest = m.groups()
        rest = re.sub(r"\s*sha256=\S+", "", rest)
        what = {"purged": "Deleted: a conflict copy with exactly the same bytes as another file (nothing lost)",
                "sanitised": "Renamed: the only copy of a file got its clean name back",
                "merged-generated": "Moved to the 30-day trash: an older copy of a file the Cowork exporter regenerates",
                "resolved": "Moved to the 30-day trash: the version you did not choose",
                "trash expired": "Trash emptied after 30 days"}[act]
        rows.append((when, what, rest))
    rows.reverse()
    return rows

# Root cause of the conflicts: honey-private-perms.sh (every 15 min) strips "other" permission bits from
# files Syncthing has just written, and with ignorePerms=false Syncthing counts that chmod as a local edit
# and bumps the file's version, which makes the next write from Gills look concurrent. Ignoring permission
# bits on Honey's side of these folders stops it; the perms script still keeps the files private.
# CONSEQUENCE, on purpose: genuine permission changes on Honey no longer propagate to the other devices
# (and the reverse). Permissions here are managed locally by honey-private-perms.sh. Do NOT flip
# ignorePerms back to false to "fix" a permission-propagation problem: that silently restores the
# conflict loop (chmod every 15 min -> version bump -> Gills' next write looks concurrent).
ensure_ignoreperms() {
    python3 -I - "$DRY" <<'PY'

                       os.path.expanduser("~/.config/syncthing/config.xml")) if os.path.exists(p))
g = ET.parse(cfg).getroot().find("gui")
base = ("https://" if g.get("tls") == "true" else "http://") + g.findtext("address")
key, ctx = g.findtext("apikey"), ssl._create_unverified_context()
def call(method, path, body=None):
    r = urllib.request.Request(base + path, method=method, headers={"X-API-Key": key, "Content-Type": "application/json"},
                               data=json.dumps(body).encode() if body is not None else None)
    with urllib.request.urlopen(r, timeout=30, context=ctx) as x:
        t = x.read()
        return json.loads(t) if t else None
for fid in ("obsidian-vault", "heea"):

        print(f"unchanged: syncthing folder {fid} ignorePerms=true")

        print(f"installed: syncthing folder {fid} ignorePerms=true (undo: PATCH ignorePerms=false)")
PY
}

        "$HOME/.local/state/syncthing-config.pre-ignoreperms-20261102.xml"
fi
