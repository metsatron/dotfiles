* Purpose

Single source of truth for every Virtual Habitat guest: Distrobox sanctuaries, KVM enclaves,
and historical Unix fleet entries. Renderer org files (=distrobox.org=, =qemu.org=)
consume the guest identity declared here — they do not become second registries with
divergent settings.

Vocabulary:
- *Sanctuary* — Distrobox container, shared host kernel, agent enters via =distrobox exec=
- *Enclave* — KVM VM, own kernel, hardware-accelerated CPU, agent enters via SSH
- *Emulation* — QEMU TCG or MAME, software CPU, relay-resident or museum

* Guest Registry

One entry per guest. Fields match the =DotCortex-Scope.md= guest declaration schema.
Renderer-specific details live in the renderer org files and reference these IDs.

* Host-Visible Guest Home Layout

Guest homes live on the host filesystem and are mounted into the guest.
DotCortex tangles directly into these directories.

#+BEGIN_SRC bash :tangle linux/.local/bin/vm-homes-init :shebang "#!/usr/bin/env bash"
# Initialize host-visible guest home directories for all declared guests.
# Run once per machine after first stow. Idempotent.
set -euo pipefail

GUESTS_DIR="${XDG_DATA_HOME:-$HOME/.local/share}/dotcortex/guests"
DOTCORTEX_HOME="${DOTCORTEX_HOME:-$HOME/DotCortex}"
GUEST_REGISTRY="${GUEST_REGISTRY:-$DOTCORTEX_HOME/linux/.config/virtualisation/guests.conf}"

if [[ ! -f "$GUEST_REGISTRY" ]]; then
  echo "vm-homes-init: missing guest registry $GUEST_REGISTRY" >&2
  exit 1
fi

mapfile -t guests < <(awk 'NF >= 6 && $1 !~ /^#/ { print $1 " " $2 }' "$GUEST_REGISTRY")
if [[ "${#guests[@]}" -eq 0 ]]; then
  echo "vm-homes-init: no active guests in $GUEST_REGISTRY" >&2
  exit 1
fi

firedragon_profile=""
for candidate in \
  "$HOME/mnt/x230/.firedragon/flatpak-migrate" \
  "$HOME/.firedragon/flatpak-migrate"
do
  if [[ -d "$candidate" && -f "$candidate/prefs.js" && -f "$candidate/places.sqlite" ]]; then
    firedragon_profile="$candidate"
    break
  fi
done

project_link() {
  local target="$1"
  local link="$2"

  if [[ -e "$link" && ! -L "$link" ]]; then
    echo "vm-homes-init: preserving existing path $link"
    return
  fi
  ln -sfnT "$target" "$link"
}

for guest_record in "${guests[@]}"; do
  read -r guest habitat_type <<<"$guest_record"
  guest_dir="$GUESTS_DIR/$guest"
  guest_home="$guest_dir/home"
  # Migrate legacy lowercase mail dirs (journal/inbox/outbox) to capitalized
  # names in place, preserving any existing data (2026-07-16). Idempotent: only
  # moves a real lowercase dir when the capitalized target does not yet exist,
  # and drops the stale lowercase home symlink so the capitalized link replaces it.
  for _pair in journal:Journal inbox:Inbox outbox:Outbox; do
    _lc="${_pair%%:*}"; _cap="${_pair##*:}"
    if [[ -d "$guest_dir/$_lc" && ! -L "$guest_dir/$_lc" && ! -e "$guest_dir/$_cap" ]]; then
      mv "$guest_dir/$_lc" "$guest_dir/$_cap"
    fi
    [[ -L "$guest_home/$_lc" ]] && rm -f "$guest_home/$_lc"
  done
  mkdir -p \
    "$guest_home" \
    "$guest_dir/dotfiles" \
    "$guest_dir/Journal" \
    "$guest_dir/Inbox" \
    "$guest_dir/Outbox"
  mkdir -p "$guest_home/.config" "$guest_home/.local/bin" "$guest_home/.local/share/applications"
  # Capitalized XDG user dirs in every guest home. Previously missing/inconsistent
  # across sanctuaries (had to be rebuilt by hand); mkdir -p never clobbers the
  # ones already there (2026-07-16).
  mkdir -p "$guest_home"/{Desktop,Documents,Downloads,Music,Pictures,Videos,Public,Templates}

  # Sanctuary-owned mutable state stays under guest_home. Project only the
  # declared host resources and static shell entrypoints into that home.
  # Fonts now live as a host-level union: public NerdFonts still originate from
  # DotCortex, while vendor/private families arrive via helmstow and local
  # triage under ~/.local/share/fonts. Guests should see that merged view.
  project_link "$HOME/.local/share/fonts" "$guest_home/.local/share/fonts"
  project_link "$HOME/DotCortex" "$guest_home/DotCortex"
  project_link "$HOME/HelmCortex" "$guest_home/HelmCortex"
  project_link "$HOME/Applications" "$guest_home/Applications"
  project_link "$HOME/RetroPie" "$guest_home/RetroPie"
  project_link "$HOME/Games" "$guest_home/Games"
  project_link "$HOME/RetroPie/stow/.config/lutris" "$guest_home/.config/lutris"
  project_link "$HOME/RetroPie/stow/.local/share/lutris" "$guest_home/.local/share/lutris"
  if [[ "$habitat_type" == "sanctuary" && -n "$firedragon_profile" ]]; then
    if [[ -e "$guest_home/.firedragon" && ! -d "$guest_home/.firedragon" ]]; then
      echo "vm-homes-init: preserving existing path $guest_home/.firedragon"
    else
      mkdir -p "$guest_home/.firedragon"
      project_link "$firedragon_profile" "$guest_home/.firedragon/flatpak-migrate"
    fi
  fi
  project_link "$HOME/.guix-extra-profiles" "$guest_home/.guix-extra-profiles"
  project_link "$HOME/.config/guix" "$guest_home/.config/guix"
  project_link ../dotfiles "$guest_home/dotfiles"
  project_link ../Journal "$guest_home/Journal"
  project_link ../Inbox "$guest_home/Inbox"
  project_link ../Outbox "$guest_home/Outbox"
  project_link DotCortex/all/.zshenv "$guest_home/.zshenv"
  project_link DotCortex/all/.zprofile "$guest_home/.zprofile"
  project_link DotCortex/all/.zshrc "$guest_home/.zshrc"
  project_link "$HOME/DotCortex/linux/.local/bin/sanctuary-flatpak-run" "$guest_home/.local/bin/sanctuary-flatpak-run"
  project_link "$HOME/DotCortex/linux/.local/bin/firefox" "$guest_home/.local/bin/firefox"

  echo "vm-homes-init: $guest_dir — ok"
done
#+END_SRC

* Transport Policy

| Guest Class                      | Primary    | Fallback    |
|----------------------------------|------------|-------------|
| Distrobox sanctuary (same host)  | bind-mount | —           |
| Modern Linux / Guix KVM enclave  | virtiofs   | NFS         |
| Modern BSD / illumos             | NFS        | SFTP        |
| Vintage commercial Unix          | NFS        | SSH/serial  |
| Museum (weak networking)         | ISO drop   | serial      |
