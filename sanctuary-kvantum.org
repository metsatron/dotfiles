* QTStep-DarkAdobe

NeXTSTEP-geometry Qt widgets ([[https://github.com/andbgr/QTStep][QTStep]], Andreas Berger, GPL-3.0, no CoC) painted with the OneStepBack Adobe Highlights palette (=adobe-cc-dark=, =style.org=). Applied to sanctuary-cortex via stow: =linux/.config/Kvantum/kvantum.kvconfig= is tangled from this file (see below) and stowed into the guest home, selecting this theme as the active Kvantum theme. The generated theme files in =linux/.config/Kvantum/QTStep-DarkAdobe/= are committed alongside it.

** Active theme config

Tangled directly into the stow overlay so the active theme selection is declarative rather than written at stow-script runtime.

#+BEGIN_SRC conf :tangle linux/.config/Kvantum/kvantum.kvconfig
[General]
theme=QTStep-DarkAdobe
#+END_SRC

Upstream ships 20+ palette variants via two-pass hex substitution driven by =colors.*= files (base=default green/yellow; variants replace each role's hex). This variant follows the same mechanism but is generated offline by the Python script below, with the output committed at =linux/.config/Kvantum/QTStep-DarkAdobe/=.

Lineage audit: GPL-3.0 copyleft, no Contributor Covenant or equivalent conduct enforcement mechanism, single independent developer. No captive-foundation or DEI-enforcement infrastructure in the dependency tree.

** Color derivation

Base inputs from =adobe-cc-dark= (=style.org= widget palette):
- =active=/=bg= :: =#454545= (window background)
- =inactive= :: =#303030= (unfocused, =darker= slot)
- =selection= :: =#4b6983= (steel-blue accent, =base0F=)
- =button= :: =#414141= (=button-bg=)
- =view= :: =#1f1f1f= (=base00=, editor-dark)
- =text= :: =#d2d4d4= (=base05=), =selection-text= =#ffffff=

Derived values use QTStep's =shadesimple= formula: =v = k−1= added per channel in 0-1 space (clamped). Key factors: border ×0.333, highlight ×1.333, innerdark ×0.833, hover ×1.042, pressed ×0.833; gradient series ×[1.242, 1.022, 1.022, 1.014, 0.962, 0.982, 0.962, 1.242].

** Generator

Run =qtstepadobe-gen= from any directory after changing the palette to rebuild =linux/.config/Kvantum/QTStep-DarkAdobe/=. The generated directory is committed — consumers stow it with no runtime generation required.

#+BEGIN_SRC python :tangle linux/.local/bin/qtstepadobe-gen :tangle-mode (identity #o755) :shebang "#!/usr/bin/env python3"
"""Generate QTStep-DarkAdobe Kvantum theme from QTStep.source.

Palette: OneStepBack Adobe Highlights (adobe-cc-dark, style.org).
Locates DotCortex root via .git ancestor search; safe to run from any path.
"""
import pathlib
import sys


def find_dotcortex():
    here = pathlib.Path(__file__).resolve().parent
    for p in [here, *here.parents]:
        if (p / ".git").exists():
            return p
    sys.exit("qtstepadobe-gen: cannot find DotCortex root (no .git ancestor found)")


ROOT = find_dotcortex()
SRC_DIR = ROOT / "linux/.config/Kvantum/QTStep.source/kvantum/QTStep.source"
OUT_DIR = ROOT / "linux/.config/Kvantum/QTStep-DarkAdobe"

if not (SRC_DIR / "QTStep.source.kvconfig").exists():
    sys.exit(f"qtstepadobe-gen: submodule not initialised: {SRC_DIR}")

OUT_DIR.mkdir(exist_ok=True)

colors_base = {}
for line in (SRC_DIR / "colors").read_text().splitlines():
    parts = line.split()
    if len(parts) == 2:
        colors_base[parts[0]] = parts[1]

    # Two-pass: replace base hex with unique placeholders, then place target hex.
    # Prevents a target colour from being re-substituted by a later iteration.
    for key, base_hex in colors_base.items():
        content = content.replace(base_hex, f"PLACEHOLDER-{key}-PLACEHOLDER")
    for key, base_hex in colors_base.items():
        tgt = colors_target.get(key, base_hex)
        content = content.replace(f"PLACEHOLDER-{key}-PLACEHOLDER", tgt)
    out_name = tpl.replace("QTStep.source", "QTStep-DarkAdobe")
    (OUT_DIR / out_name).write_text(content)
    print(f"  {(OUT_DIR / out_name).relative_to(ROOT)}")
