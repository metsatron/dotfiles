* Why

Honey (hostname =beelink=) is Gillean's production box and a gated host (=package-host-gates.org=): DotCortex may only ever *add* packages there, and the gate already refuses every removal. This lane goes one step further, as Mètsàtron asked: it *declares* every package Honey's apt has marked manual, so nothing Honey has is ever outside the declared set. If the gate is ever lifted, or a future lane treats "not declared" as "remove", Honey's packages are still not candidates.

Every row has scope =beelink=, which =nala-apply='s =scope_matches= honours on Honey only. The file is read only on Honey, because =host-gates.ssv= names it as Honey's manifest.

Columns are the nala manifest's: =PKG VERSION CATEGORY SCOPE EXTRA=. Versions float (=""=). =CATEGORY= is the group below: =bootstrap= / =dotcortex=, =stack=, =base= or =image=.

- =zcat -f /var/log/apt/history.log*=: every =apt install= since Honey's first logged apt run (2026-06-27), for the stack group

Grouping rules, as implemented by the generator below:

- *Gillean's production stack*: everything installed by hand per apt history, plus the image-shipped layer her stack stands on: init (=openrc=, =sysvinit-core=, =elogind=, =eudev=), boot (both =vendefoul= kernels, =grub=, =initramfs-tools=, firmware), GPU (the Mesa Vulkan/VA/VDPAU drivers), session (=lightdm=, =bspwm=, =sxhkd=, =polybar=, =picom=, =rofi=, =dunst=, =kitty=), and remote access and health (=openssh-server=, =smartmontools=, =acpid=, =preload=, =sudo=).

- *Other*: the rest of the VendefoulWolf image (desktop apps, libraries, tools).

"""Group Honey's apt-mark showmanual set for package-nala-honey.org (read-only inputs)."""
import subprocess, gzip, glob, re, sys
from pathlib import Path

def sh(cmd): return subprocess.run(cmd, shell=True, capture_output=True, text=True, check=True).stdout
manual = sorted(set(sh("apt-mark showmanual").split()))
meta = {}
for line in sh("dpkg-query -W -f='${Package}\\t${Priority}\\n' " + " ".join(manual)).splitlines():
    pkg, prio = line.split("\t"); meta[pkg] = prio
hand = set()
for f in sorted(glob.glob("/var/log/apt/history.log*")):
    text = gzip.open(f, "rt").read() if f.endswith(".gz") else open(f).read()
    for m in re.finditer(r"^Commandline: apt(?:-get)? (.*)$", text, re.M):
        words = re.sub(r"-o \S+", "", m.group(1)).split()
        if "install" not in words: continue
        hand.update(w.split("=")[0] for w in words[words.index("install") + 1:] if not w.startswith("-"))
dotcortex = [l.split()[0] for l in Path(sys.argv[1]).read_text().splitlines() if l.strip() and not l.startswith("#")]
STACK_IMAGE = """openrc sysvinit-core elogind eudev insserv startpar initramfs-tools grub-pc grub-common
linux-image-6.18.32-vendefoul linux-headers-6.18.32-vendefoul lightdm lightdm-gtk-greeter-settings bspwm sxhkd
polybar picom rofi dunst kitty mesa-vulkan-drivers mesa-va-drivers mesa-vdpau-drivers libgl1-mesa-dri
firmware-misc-nonfree firmware-linux-nonfree openssh-server smartmontools acpid preload sudo""".split()
groups = {"stack": [], "base": [], "image": []}
for pkg in manual:
    if pkg in dotcortex: continue
    if pkg in hand or pkg in STACK_IMAGE: groups["stack"].append(pkg)
    elif meta.get(pkg) in ("required", "important", "standard"): groups["base"].append(pkg)
    else: groups["image"].append(pkg)
for g, pkgs in groups.items():
    print(f"== {g} {len(pkgs)}")
    print("\n".join(f'{p} "" {g} beelink ""' for p in pkgs))
#+END_SRC

The three Telegram Claude bots run as the Unix user =metsatron= ([[file:agents-bots-honey.org][agents-bots-honey.org]]). That account must not reach Gillean's Node (=~/.local/bin/node= inside her sealed home), and Honey had no system Node, so the runtime comes from Devuan. Checked 2026-09-25 with =apt-cache policy nodejs npm=: candidates =nodejs 20.19.2+dfsg-1+deb13u2= and =npm 9.2.0~ds1-3= (excalibur main and excalibur-security). Claude Code 2.1.282 declares =engines: node >=22=, but its =claude= is a native binary (=bin/claude.exe=, ELF): Node only runs the package's =postinstall= (=install.cjs=, which uses nothing beyond =fs=, =os=, =path= and =child_process=). Under Node 20 npm prints an =EBADENGINE= warning and installs (it only refuses with =engine-strict=, which DotCortex does not set). =claude-warm= is Python and the Telegram plugin runs under bun, so no running bot needs Node at all. Debian's =npm= pulls about 360 =node-*= packages (=nodejs= alone is 11), all additive. =claude= itself and =bun= are not apt packages here: they come from metsatron's own npm lane (=package-npm.org=, "Account lane: metsatron on Honey").
